# 🖱️ Section "ข้อความใหญ่ + รูปตามเมาส์" (hover-reveal) — 2026-10-23

## ใช้ทำอะไร
คำใหญ่หลายบรรทัด (เช่น NEW ARRIVAL / BEST SELLER / OUR STORY) — ชี้เมาส์ที่คำไหน **รูปของคำนั้นลอยขึ้นตามเมาส์** คำอื่นจางลง · กดคำ = ไปลิงก์
อ้างอิงหน้าเว็บแบรนด์สาย Gen Z (คลิปที่เจ้าของส่งมา นาที 8:14)

- **มือถือ (แตะ):** แตะคำ = รูปขึ้นเหนือคำ (ที่ไม่พอ = ใต้คำ) ยังไม่ไปไหน · แตะคำเดิมซ้ำ = ไปลิงก์ · แตะที่อื่น = รูปหาย · คำที่ไม่มีรูป = แตะครั้งเดียวไปลิงก์เลย
- ดูชนิดของการแตะทีละครั้ง → จอสัมผัสที่มีเมาส์ (โน้ตบุ๊กจอสัมผัส) ใช้ได้ทั้งสองแบบ

## วิธีใช้ (คนจัดหน้า)
ERP › เว็บไซต์ › ร้าน › 🧱 หน้าแรก (หรือหน้าเว็บ) › ＋ เพิ่ม Section › กลุ่ม "เนื้อหา" › **🖱️ ข้อความใหญ่ + รูปตามเมาส์**
- วางใหม่ได้คำตัวอย่าง 3 คำ → แก้ข้อความ ใส่รูป (กด 🔗 ใช้ชุดรูปได้) และลิงก์ทีละคำ · สูงสุด 12 คำ
- ป้ายเล็กข้างคำ เช่น `(12)` หรือ `NEW`

## ตั้งค่า
| กลุ่ม | ช่อง |
|---|---|
| เนื้อหา | คำโปรยเล็กด้านบน · ข้อความเล็กใต้คำ |
| หน้าตาคำ | จัดซ้าย/กลาง/ขวา · ฟอนต์ (ธีม/Google Fonts) · ความหนา · ขนาดคอม/มือถือ (px — จอกลางย่อตามเอง) · ตัวพิมพ์ใหญ่ · ระยะบรรทัด · สี · คำอื่นตอนชี้ (จาง/เหลือเส้นขอบ/เหมือนเดิม) |
| รูป | ขนาดคอม/มือถือ · สัดส่วน · มุมมน · ตามเมาส์ (นุ่ม/ติดเมาส์/กลาง Section) · เอียงตามทิศเมาส์ · ท่าโผล่ (ขยาย/จาง/เผยจากล่าง) · รูปอยู่หน้า/หลังตัวหนังสือ |

ตรวจก่อนเผยแพร่: ไม่มีคำ = ❌ · คำที่ไม่มีรูป = ⚠️ (ชี้แล้วไม่มีรูปขึ้น)

## ทำงานยังไง (คนแก้โค้ด)
- ERP: `lib/website-blocks.ts` (`HoverRevealBlock`) · `lib/website-schema.ts` (`"hover-reveal"` + `starter` คำตั้งต้น) · เทสต์ `lib/__tests__/website-hover-reveal-tabs.test.ts`
- เว็บร้าน: `src/components/home/HoverReveal.tsx` (PURE_REGISTRY → พรีวิวสดในตัวจัดหน้า) · CSS `.hr-*` ใน `globals.css`
  - รูปทุกคำซ้อนในกรอบเดียว `.hr-pos` ที่เลื่อนด้วย `transform` (rAF · หยุดเองเมื่อนิ่ง) → เปลี่ยนคำ = เฟดสลับ ไม่กระโดด · กรอบไม่รับเมาส์
  - นุ่ม = ไล่ตาม 14%/เฟรม · มุมเอียง = ระยะที่ยังตามไม่ทัน (นุ่ม) / ความเร็วเมาส์ (ติดเมาส์) · ขอบซ้ายขวาบีบให้รูปอยู่ใน Section · Section `overflow-x: clip` (หน้าไม่เลื่อนข้าง)
  - แตะ: ของกลาง `src/lib/use-click-guard.ts` ตัดสินที่ window ช่วง capture (ก่อน NavProgress ที่ดักคลิกที่ document)
  - ลดการเคลื่อนไหว = ติดเมาส์ ไม่เอียง จางอย่างเดียว · โฟกัสคีย์บอร์ด = รูปขึ้นกลางคำ
- รูปผูกชุดรูปได้ (ช่องรูปกลาง `imageKey`) — API site/page แทนค่า `imgset/` ให้เหมือนช่องรูปอื่น

## ข้อจำกัดที่รู้แล้ว
- รูปตอนชี้ไม่มีรูปมือถือแยก (ใช้รูปเดียว ครอปตามสัดส่วนที่ตั้ง + จุดสำคัญของชุดรูป)
- รูปที่ล้นขอบล่างของ Section อาจถูก Section ถัดไปทับ ถ้า Section ถัดไปตั้งท่าเคลื่อนไหว (transform) — ปกติไม่เกิด
