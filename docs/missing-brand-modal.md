# ป๊อปอัป "ใส่แบรนด์ให้สินค้าที่ยังไม่มี" (MissingBrandModal)

ของกลาง: `components/missing-brand-modal` + API `app/api/mo/missing-brand`

## ใช้ทำอะไร

งานผลิตที่ไปกองอยู่ในกลุ่ม **"— ไม่มีแบรนด์ —"** เกิดจากสินค้าตัวนั้นยังไม่มีแบรนด์
ป๊อปอัปนี้โชว์ **เฉพาะสินค้าที่ยังไม่มีแบรนด์** ให้เลือกแบรนด์แล้วกดบันทึกได้เลย ไม่ต้องไปหาเองว่าต้องแก้ที่หน้าไหน

## แบรนด์เก็บที่ไหน

แบรนด์เก็บที่ **สินค้าหลัก (Parent SKU)** — `parent_skus_v2.brand_id`
สินค้าแต่ละสี/แต่ละตัวเลือก (SKU) ได้แบรนด์มาจากสินค้าหลักที่ตัวเองผูกอยู่

งานผลิตจึงไม่มีแบรนด์ได้ 3 สาเหตุ และป๊อปอัปจัดการให้ครบในปุ่มเดียว:

| สาเหตุ | ตัวอย่างจากข้อมูลจริง (2026-09-29) | กดบันทึกแล้วระบบทำอะไร |
|---|---|---|
| สินค้าหลักยังไม่ได้ใส่แบรนด์ | CTL104 (15 ใบ), CTL106-03 (2 ใบ) | ใส่แบรนด์ให้สินค้าหลัก |
| SKU ยังไม่ได้ผูกกับสินค้าหลัก — แต่มีสินค้าหลักรหัสเดียวกันอยู่แล้ว | BSD15-01, TTM128-02, WL50-12 | ผูก SKU เข้าสินค้าหลัก (ได้แบรนด์ของสินค้าหลักทันที ไม่ต้องเลือก) |
| SKU ยังไม่ได้ผูก และยังไม่มีสินค้าหลัก | WK46-01…05, PIX42-01, PIX43-01 | สร้างสินค้าหลัก (รหัสหน้า เช่น WK46) + ใส่แบรนด์ + ผูก SKU |
| รหัสในใบสั่งผลิตยังไม่ได้ลงทะเบียนเป็น SKU | WK42-05, 06, 07 | ลงทะเบียน SKU (รหัส + ชื่อจากใบสั่งผลิต) ใต้สินค้าหลัก |

"รหัสหน้า" = ส่วนก่อนขีดสุดท้ายของรหัส (`WK46-01` → `WK46`)

## วิธีใช้ในหน้าอื่น

```tsx
import { MissingBrandModal } from "@/components/missing-brand-modal";

<MissingBrandModal open={open} onClose={() => setOpen(false)} onChanged={reload} />
```

`onChanged` ถูกเรียกตอนปิด ถ้ามีการบันทึกอย่างน้อย 1 แถว — ให้หน้าที่เปิดโหลดข้อมูลใหม่

## สิทธิ์ + ประวัติ

- ดูรายการ = `products.view` · บันทึก = `products.edit` (คนไม่มีสิทธิ์แก้ เห็นรายการแต่กดบันทึกไม่ได้)
- ทุกการสร้าง/แก้ เขียนประวัติลง `audit_logs` ผ่าน `writeAuditMany` (metadata.source = `production-dashboard/missing-brand`)

## ความปลอดภัยของข้อมูล

- Server คำนวณรายการใหม่เองจาก `key` ทุกครั้งที่บันทึก ไม่เชื่อข้อมูลจากหน้าจอ
- ไม่เขียนทับแบรนด์ที่มีอยู่แล้ว (อัปเดตเฉพาะ `brand_id` ที่ยังว่าง)
- ไม่ย้าย SKU ที่ผูกสินค้าหลักอื่นอยู่ (ผูกเฉพาะ SKU ที่ยังไม่มีสินค้าหลัก)
- บันทึกค้างกลางทาง (เช่น เน็ตหลุด) → เปิดป๊อปอัปใหม่ แถวนั้นยังอยู่พร้อมงานที่เหลือ กดซ้ำได้

## ข้อจำกัด

- ดูเฉพาะสินค้าที่อยู่ใน **ใบสั่งผลิตที่ยังใช้งาน** (ไม่รวมใบยกเลิก) — ไม่ใช่สินค้าทั้งคลัง
- SKU ที่ลงทะเบียนจากป๊อปอัปมีแค่รหัส + ชื่อ → ไปเติมรูป/ราคา/รายละเอียดต่อที่หน้า SKU
- เปลี่ยนแบรนด์ที่ใส่ผิด/ลบสินค้าหลักที่สร้างผิด ทำที่หน้า Parent SKU (ป๊อปอัปนี้ใส่ได้เฉพาะที่ยังว่าง)
