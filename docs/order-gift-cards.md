# 💌 เขียนการ์ดของขวัญจากหมายเหตุออเดอร์

> เจ้าของสั่ง 2026-11-24 · เลือก widget แบบ A (ออกแบบแม่แบบครั้งเดียว ใบต่อไปแก้แค่ข้อความ) + ข้อเสนอ 1-10
> หน้า `/order-ops/gift-cards` (แอป ออเดอร์ออนไลน์ · ศูนย์ร้านออนไลน์ › ออเดอร์ · แพ็ก · ส่ง)

## ใช้ทำอะไร

ลูกค้าเขียนหมายเหตุมาในออเดอร์ (เช่น "รบกวนห่อของขวัญเขียนการ์ด Happy Birthday") → หน้านี้รวมออเดอร์ทุกร้านที่มีหมายเหตุ
คัดแยกให้เอง แล้วกด "เขียนการ์ด" ได้การ์ดพร้อมพิมพ์ ข้อความจากหมายเหตุใส่ไว้ให้แล้ว (แก้ได้)

| หน้า | ใช้ทำอะไร |
|---|---|
| `/order-ops/gift-cards` | แท็บ การ์ด/ห่อ · สลักชื่อ · อื่น ๆ · การ์ดทั้งหมด (รวมการ์ดไม่ผูกออเดอร์ + ถังขยะ) · แม่แบบ+ฟอนต์ (ผู้จัดการ) |
| `/order-ops/gift-cards/edit?order=<id>` | เขียนการ์ดใหม่ของออเดอร์ (ยังไม่บันทึกจนกด "บันทึกการ์ด") |
| `/order-ops/gift-cards/edit?id=<การ์ด>` | แก้การ์ด · พิมพ์ · PNG · ติ๊กเขียนมือแล้ว · ย้อนการบันทึกครั้งก่อน · ลบ |
| `/order-ops/gift-cards/edit?new=1` | การ์ดไม่ผูกออเดอร์ (ลูกค้าขอทางแชต) ใส่เลขออเดอร์ทีหลังได้ |
| `/order-ops/gift-cards/template?id=` | ออกแบบแม่แบบ (ลากวางเต็ม) · ผูกแบรนด์ · ตั้งเป็นแม่แบบหลัก |
| `/print/order-gift-cards?ids=` | พิมพ์หลายใบ: A4 มีเส้นประให้ตัด / 1 ใบต่อแผ่น · กดพิมพ์ = ติ๊กพิมพ์แล้ว (เอาออกได้) |

ทางลัด: ศูนย์ออเดอร์ — กดข้อความลูกค้าใต้แถว / ในรายละเอียดออเดอร์ "เขียนการ์ด" · สถานีแพ็ก — กล่องเตือนชมพู "ลูกค้าขอการ์ด"

## หมายเหตุลูกค้าอยู่ไหน (อ่านอย่างเดียว ไม่แตะตัวดึงออเดอร์)

`buyerNoteOf(platform_orders.raw)`: Shopee `raw.shopee.message_to_seller` · TikTok `raw.tiktok.buyer_message` · Lazada `raw.lazada.gift_message/remarks` · สร้างเอง `raw.note`
- ข้อมูลจริง 24 พ.ย. 69: มีหมายเหตุ 46 ใบ (Shopee 35 · TikTok 11) — **เป็นการ์ด/ห่อจริงแค่ 4 ใบ** ที่เหลือส่วนใหญ่สลักชื่อ
- Lazada: ตัวดึงยังไม่เก็บข้อความของขวัญ (remarks ว่างทั้ง 75 ใบ) · LINE ยังไม่มีออเดอร์จริง · เว็บร้านมีระบบการ์ดของตัวเอง (`/print/gift-cards`)

## แท็บสลักชื่อ ดูจากสินค้า (รอบ 2 · เจ้าของเลือก widget 2026-11-25 แบบ B)

ออเดอร์เข้าแท็บ "สลักชื่อ" ได้ 3 ทาง (กติกากลาง `lib/order-ops.ts` → `engraveOfOrder` · เทสต์ `lib/__tests__/order-ops.test.ts`):

1. **รหัสท้าย SKU** เช่น `TTM130-01D/1` (ถอดด้วย `decodeEngraveSku` ตัวเดียวกับหน้าแพ็กของ · ตั้งรหัสที่หน้าตั้งค่าเครื่องสลัก)
2. **รุ่นสินค้าตั้ง "สินค้าสลักชื่อ"** = `parent_skus_v2.engrave_mode` (ช่องใน Parent SKU › รายละเอียด Platform · migration `202612250900_parent_engrave_mode`)
   - `optional` สลักได้ ไม่บังคับ → เข้าแท็บเมื่อมีรหัสท้าย/หมายเหตุบอกสลัก · ไม่เตือน
   - `required` ต้องสลักทุกชิ้น → ทุกออเดอร์เข้าแท็บ · เตือนเมื่อไม่มีหมายเหตุ
   - จับคู่รุ่นจาก `platform_order_items.matched_parent_sku_id` หรือ `matched_sku_id → skus_v2.parent_sku_id`
3. **หมายเหตุลูกค้า** (`classifyNote` แบบเดิม)

- **"สลัก แต่ไม่มีชื่อ"** = มีรหัสท้าย/รุ่นต้องสลัก แต่ไม่มีหมายเหตุ และยังไม่ส่ง/ไม่ยกเลิก → การ์ดตัวเลขสีแดง + ปุ่ม "ทักแชทลูกค้า"
- ปุ่มทักแชท: ถ้าช่องทางนั้นมีตัวต่อใน `lib/chat/registry` (`CHAT_ADAPTERS`) → เปิด `/chat` · ถ้ายังไม่ต่อ (Shopee/TikTok/Lazada ตอนนี้) → บอกตรง ๆ + คัดลอกเลขออเดอร์ + ลิงก์ Seller Centre (ออเดอร์ไม่ได้เก็บชื่อบัญชีผู้ซื้อ จึงลิงก์ตรงห้องไม่ได้)
- กดแถวเปิดลิ้นชัก `OrderDetailView` ของศูนย์ออเดอร์ (ต้องมีสิทธิ์ `platform_orders.view` ถึงเห็นรายละเอียด)
- แถบแนะนำ: รุ่นที่ชื่อมีคำว่า "สลัก" แต่ยังไม่ตั้ง → ลิงก์ไปตั้งเอง (ระบบไม่ตั้งให้)
- เมนู ⋮ ในแถว: ตั้งรุ่นเป็นสินค้าสลักชื่อได้ (`order_ops.manage` · POST action `engrave_mode` · ลง audit `parent_skus_v2` · ย้อนกลับจากแจ้งผลมุมจอ)

- การ์ด: ข้อความจากหมายเหตุ (suggestMessage) + เลือกแม่แบบ (กลุ่ม · การ์ดพิเศษ = เดาการ์ดพับ · ตั้งกลุ่มต่อคำสั่งได้ `extra.template_group`) + ตัวอย่าง → บันทึกคำสั่ง = save_card สร้าง/อัปเดตการ์ดของออเดอร์ (`command_details.card_id`)
- แก้ไซส์เข็มขัด: กล่อง `phrase` · ข้อความลัด kind `command_phrase` ("{n}" ตัวเลข "{u}" นิ้ว/ซม.) เพิ่ม/แก้/ซ่อนได้
- ตัดชื่อออก: กล่อง `none` + คำอธิบาย (ตัดรายการสินค้าบนใบปะหน้า)
- เปลี่ยนสินค้า: SKU รุ่นเดียวกัน (หา SKU จากรหัสร้านด้วย lib/packing bestGuess ตัวเดียวกับหน้าแพ็ก) + สต๊อก · ปุ่มเลือก SKU รุ่นอื่น (SkuPicker)
- API: `/api/order-ops?t=ins_context&order=&sku=` · `?t=stock&ids=` · `?t=parents&codes=` · migration 202612251200

## ป๊อปคำสั่งพิเศษ 2 คอลัมน์ + การ์ดธรรมดา/พิเศษ (รอบ 5 · เจ้าของเลือก widget 2026-11-25: ไอคอนแบบ B + ข้อ 1,2,3,4,6,7,8)

- **หน้าตา** (`app/order-ops/instruction-form.tsx`): ซ้าย = ออเดอร์ · รูปสินค้าทุกชิ้น (ชี้/แตะดูรูปใหญ่ · รูปปก SKU ไม่มีใช้รูปปกรุ่น — `attachItemImages` ใน lib/order-ops-server) · หมายเหตุลูกค้า · ปุ่มคำสั่งใหญ่ (ไอคอน `commandIconOf` ขยับตอนชี้ · ปิดเองถ้าเครื่องตั้งลดการเคลื่อนไหว) · ขวา = รายการคำสั่งที่เลือก (กล่องตั้งค่าเดิม + ปุ่ม × เอาออก) · มือถือเรียงบน-ล่าง
- **ดูออเดอร์** = ลิ้นชัก `OrderDetailView` ของศูนย์ออเดอร์ (โหลดตอนกด) ฟอร์มไม่หาย · มีปุ่ม "เต็มหน้า"
- **อ่านหมายเหตุ** (คำสั่งใหม่เท่านั้น): `classifyNote` + `guessEngraveFromNote` → ติ๊กสลักชื่อ/ใส่ชื่อ และเพิ่มคำสั่งการ์ดธรรมดาให้เอง · แถบม่วง "เพิ่มจากหมายเหตุ" มีปุ่มเอาออก · ไม่ทับที่กรอก/ที่รหัส SKU ตั้งไว้
- **การ์ดพิเศษ**: `gift_card_templates.is_special` (migration `202612251300`) · ติ๊กได้ที่หน้าแก้แม่แบบ หรือปุ่ม "เป็นพิเศษ/เป็นธรรมดา" ในรายการแม่แบบ (ของที่ออกแบบเอง · ย้อนกลับได้) · ยังไม่ตั้ง = การ์ดพับถือเป็นพิเศษ (`isSpecialTemplate`) · คำสั่งที่ชื่อมี "พิเศษ" เห็นเฉพาะแม่แบบพิเศษ ที่เหลือเห็นเฉพาะธรรมดา · ไม่มีแม่แบบในกลุ่มนั้น = เตือน + พิมพ์ข้อความไว้ก่อนได้
- **การ์ดในป๊อป** (`CardBox`): ตัวอย่างสด `CardQuickEdit` ลากกล่องข้อความย้ายได้ · พิมพ์แก้แต่ละกล่อง · เพิ่ม/ลบข้อความ · "คืนค่าแม่แบบ" · "ออกแบบเต็ม" เปิดตัวออกแบบเต็มในป๊อป (โหลดตอนกดเท่านั้น) · บันทึกจริงตอนกดบันทึกคำสั่ง (saveCards)
- **พิมพ์ครั้งเดียว**: ปุ่มพิมพ์ในป๊อป → `/print/engrave-sheets?ids=…&cards=…` มีปุ่ม "พิมพ์ทั้งหมด" (การ์ดเปิดหน้าต่างใหม่ + ใบสลักในหน้านี้ · ติ๊กการ์ดพิมพ์แล้ว + ประวัติพิมพ์) · การ์ดอย่างเดียว → `/print/order-gift-cards`
- ตัวเลือกออเดอร์ (PlatformOrderPicker) โชว์รูปสินค้าย่อ 3 รูปแรกด้วย

## ข้อความการ์ด: ดึงฉลาด + AI + ข้อความสำเร็จรูป + การ์ดสำเร็จรูป (เจ้าของเลือก 2026-11-25 แบบ AB · ข้อ 1-4)

- **ดึงจากหมายเหตุ** `suggestMessages(note)` (lib/gift-card-design · เทสต์กับหมายเหตุจริง): ข้อความในเครื่องหมายคำพูด (ข้ามชื่อที่จะสลัก/ปัก) → คำหลัง "การ์ด…ว่า" → คำอวยพรตามโอกาส (วันเกิด/ครบรอบ/วาเลนไทน์/รับปริญญา/แต่งงาน/ปีใหม่/คริสต์มาส) · สูงสุด 5 แบบ เป็นชิปใต้ช่องข้อความ · `suggestMessage` เดิม = แบบแรก
- **AI คิดให้ 3 แบบ**: ด่าน AI เดิม (POST action `ai` · สิทธิ์ `ai.gift_card`) → ชิปสีม่วงให้กด
- **ข้อความสำเร็จรูป**: `order_ops_options` kind `card_phrase` (value = กลุ่ม) migration `202612251400` · ตั้งต้น 10 ข้อความ 4 กลุ่ม · จัดการที่ จัดการคำสั่ง › คำสั่งการ์ด › "ข้อความสำเร็จรูป" (เพิ่ม/แก้/ย้ายกลุ่ม/เรียง/ซ่อน)
- **การ์ดสำเร็จรูป**: สลับ "ใส่ข้อความ / การ์ดสำเร็จรูป" ในกล่องการ์ด · สำเร็จรูป = แม่แบบที่ไม่มีช่อง "ข้อความจากลูกค้า" (ข้อความตายตัว) ไม่มีช่องกรอก · บันทึกได้แม้ไม่มีข้อความ (`CommandDetail.ready`) · แม่แบบในตัวเพิ่ม 2 แบบ (สำเร็จรูป · Happy Birthday / Thank You)
- แก้ไปพร้อมกัน: API รับชนิดตัวเลือก `command_phrase` / `special_wrap` (เดิมเพิ่มข้อความลัด/รหัสห่อพิเศษไม่ได้ — ขึ้น "กรุณาใส่ชื่อตัวเลือก")

## จัดหน้าใหม่ (เจ้าของสั่ง 2026-11-25 · ข้อ 1-5)

- หน้า คำสั่งพิเศษ & การ์ด เหลือ 2 แท็บ: **งานพิเศษ** · **ตั้งค่า** — เอาแท็บ "การ์ดทั้งหมด" ออก
  - การ์ดไม่ผูกออเดอร์ (ปุ่ม "การ์ดใหม่") ขึ้นเป็นแถวในงานพิเศษ (id `card:<id>` · ช่วงที่เลือก หรือยังไม่พิมพ์) กดแถวเปิดหน้าการ์ด
  - ถังขยะการ์ดอยู่ใน ตั้งค่า (`GiftCardsList trashOnly`) · ถังขยะคำสั่งปุ่มเดิม
- **รอของ** ย้ายไปหน้า `/order-ops/after-sales?kind=wait` (ไฟล์ `app/order-ops/wait-view.tsx`) — หน้าใหม่ชื่อ "รอของ & ซ่อม/เปลี่ยนคืน" แท็บ รอของ · ซ่อม · เปลี่ยน/คืน + ตัวเลขงานค้างบนแท็บ · เมนูเปลี่ยนชื่อ (migration 202612251600)
- ลิงก์เก่า `?s=wait` → หน้าใหม่ · `?s=cards` → งานพิเศษ ชนิดการ์ด
