# ChipOverflow — ชิปยาว โชว์ไม่กี่ตัว แล้วกดดูที่เหลือ

ไฟล์: `components/chip-overflow/index.tsx` · ตัวช่วยแยกบริษัท/สาขา: `lib/company-branch.ts` · เพิ่ม 2026-11-11 (เจ้าของขอ: หน้าแบรนด์ลูกค้า 30 สาขายาวเป็นหน้า)

## ใช้ทำอะไร
รายการชิปที่ยาวมากในแถวตารางหรือการ์ด → ปกติโชว์ `max` ตัวแรก (ค่าเริ่ม 3) + ปุ่ม **"+N ดูทั้งหมด"**
กดแล้วกางทั้งหมด (จัดกลุ่มมีหัวข้อได้) + ปุ่ม **"ย่อ"** กลับ

- ซ่อนแค่ 1 ตัว = โชว์ทั้งหมดเลย (ไม่ทำปุ่ม "+1")
- ตอนย่อโชว์ตามลำดับเดิมของ `items` — ตัวแรกควรเป็นตัวสำคัญสุดของหน้านั้น
- ตัวนี้ไม่เก็บข้อมูล ไม่ยิง API · หน้าตาชิป/ปุ่ม × เป็นของหน้าที่เรียก (`renderChip`)

```tsx
import { ChipOverflow } from "@/components/chip-overflow";
import { groupByCompany } from "@/lib/company-branch";

<ChipOverflow
  items={customers} getKey={(c) => c.id} max={3}
  // ไม่ใส่ groupItems = กางแล้วเรียงต่อกัน
  groupItems={(list) => groupByCompany(list, (c) => c.name).map((g) => ({ label: g.company, items: g.items.map((x) => x.item) }))}
  renderChip={(c, { grouped }) => <span className="...">{grouped ? shortName(c) : c.name}</span>}
/>
```

| ค่า | ความหมาย |
|---|---|
| `items` / `getKey` | รายการ + คีย์ไม่ซ้ำ |
| `renderChip(item, { grouped })` | วาดชิป 1 ตัว · `grouped = true` ตอนกางแบบจัดกลุ่ม (ย่อชื่อให้เหลือส่วนที่ต่างกันได้ เพราะหัวกลุ่มบอกแล้ว) |
| `max` | โชว์กี่ตัวตอนย่อ (ค่าเริ่ม 3) |
| `groupItems` | ตอนกาง: จัดกลุ่มมีหัวข้อ "ชื่อกลุ่ม · จำนวน" (ใช้เฉพาะรายการที่ยาวเกิน `max + 1`) |

## lib/company-branch
- `splitCompanyBranch("บริษัท ก จำกัด ( สาขา 1 ) สาขาที่ 00001")` → `{ company: "บริษัท ก จำกัด", branch: "สาขา 1" }`
- รองรับ: `(สาขา 18)` · `สำนักงานใหญ่` · `สำนักงานใหญ่ (สาขาที่ 00000)` · `สาขาเซ็นทรัลเวิลด์ (สาขาที่ 00001)` · ชื่อไม่มีคำว่าบริษัท
- `groupByCompany(items, nameOf)` — กลุ่มเรียงตามที่เจอก่อน · ในกลุ่มเรียง สำนักงานใหญ่ → สาขาเลขน้อยไปมาก (ไม่ใช่ 1, 10, 2)
- ต่างจาก `customerRoot` (lib/so-bill-match) ที่ทำ "คีย์ไว้เทียบ" — ตัวนี้ทำ "ข้อความไว้โชว์"
