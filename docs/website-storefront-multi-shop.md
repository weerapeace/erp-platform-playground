## API สาธารณะที่เว็บร้านใช้ (ไม่มี guardApi โดยเจตนา + CORS)

| เส้น | ใช้ทำอะไร |
|---|---|
| `GET /api/public/storefront/site?shop=` | ธีม · โครงหน้าแรก · หมวด · **info** (คำโปรย/ติดต่อ/ค่าส่ง/ช่องทางจ่าย) |
| `GET /api/public/storefront/products?shop=` | สินค้าที่เผยแพร่ (ราคาเป็นบาท) |
| `GET /api/public/storefront/page?shop=[&page=]` | หน้าที่สร้างจาก ERP |
| `POST /api/public/storefront/orders` | **ลูกค้ากดสั่งซื้อ** — ราคาคิดใหม่ฝั่งเซิร์ฟเวอร์เสมอ (`lib/website-orders.ts`) |
| `GET /api/public/storefront/orders?shop=&no=&phone=` | ลูกค้าตามออเดอร์ (ต้องรู้ทั้งเลขที่และเบอร์) |

เลขที่ออเดอร์ = `<ตัวย่อ>-<พ.ศ.><เดือน>-<ลำดับ 5 หลัก>` เช่น `LM-256910-00001` · ตัวย่อตั้งในแท็บข้อมูลร้าน

## ตัวจัดหน้าเว็บ (Website Builder) — 2026-10-09

แท็บ "🧱 หน้าแรก" และ "📄 หน้าเว็บ" ใช้ตัวจัดหน้า 3 แผงตัวเดียวกัน (`components/website-builder.tsx`):

| แผง | ทำอะไร |
|---|---|
| ซ้าย | โครงหน้า: Section → Block ย่อย · ลากเรียง · + เพิ่ม Section (คลัง 21 แบบ) · ทำสำเนา · ซ่อน · ลบ · กด ▸ ดู Block ย่อย |
| กลาง | พรีวิวเว็บจริง (iframe `?preview=1`) คลิก Section/Block ในพรีวิวเพื่อเลือก · สลับ คอม/แท็บเล็ต/มือถือ · เต็มจอ |
| ขวา | คุณสมบัติของสิ่งที่เลือก: ฟอร์มจาก Schema · แสดงบนอุปกรณ์ · รูปลักษณ์ (แท็บ ทุกจอ / มือถือ) |

- Section สินค้า "ตารางสินค้า / คอลเลกชัน": เลือกเองทีละรุ่น (Product Picker จากสินค้าบนเว็บ) / ทั้งหมวด / ที่ติ๊กแนะนำ / ทั้งหมด · ตาราง หรือ Carousel

### เพิ่มเติม 2026-10-09 (รอบ "ขยับได้ มีลูกเล่น")
- **🤖 ให้ AI ช่วย** (ปุ่มในตัวจัดหน้า): คัดลอกคำสั่งที่สร้างจาก schema (`lib/website-ai-prompt.ts`) ไปวางใน ChatGPT/Claude → วาง JSON กลับมา → เพิ่มลงหน้า ทุกช่องแก้ต่อได้
- **Custom HTML** (กลุ่ม "ขั้นสูง"): วาง HTML+CSS เอง · ล้างด้วย `lib/website-html.ts` (ไม่รัน JavaScript, ถอด script/iframe/on*) · CSS ถูกจำกัดในกล่อง · ห้าม Tailwind class
- **✨ ลูกเล่น** (แท็บที่ 3 ในแผงรูปลักษณ์ ทุก Section): โผล่ตอนเลื่อนถึง (ลอยขึ้น/จางเข้า/จากซ้าย-ขวา/ซูม) + ความเร็ว + ไล่ทีละชิ้น · ตอนชี้เมาส์ (ยก/ซูมรูป/เรืองแสง) · เคารพ "ลดการเคลื่อนไหว" ของเครื่องผู้ใช้
- Section ใหม่: **โชว์สินค้าเด่น (Spotlight)** รูปใหญ่+ตัวอักษรยักษ์+สลับสินค้า/สี · **ตัวเลขเด่น** นับขึ้น · Hero มี **วิดีโอพื้นหลัง** (ลิงก์ mp4/webm) + **parallax** · แถบประกาศ **วิ่งต่อเนื่อง**
- ⚠️ Spotlight สลับ "สี" ยังไม่เปลี่ยนรูป (API สินค้าส่งรูปหลักรูปเดียว) — ถ้าอยากได้ ต้องให้ products API ส่งรูปต่อสี (web_sku_images) เพิ่ม

## ข้อจำกัดที่รู้อยู่

- ยังไม่มีสลิปอัปโหลด — ลูกค้าโอนแล้วส่งสลิปทางช่องทางติดต่อ แล้วพนักงานกด "ชำระแล้ว" ในแท็บออเดอร์
- ยังไม่มีคูปอง/สมาชิกบนเว็บหน้าร้านชุดนี้ (ของเดิมมีเฉพาะเว็บ Pixiedustie)
- Header/Footer ยังไม่อยู่ในตัวจัดหน้า (ดึงจากแท็บดีไซน์ + ข้อมูลร้าน) · ยังไม่มีการตั้งค่า Typography ต่อบล็อก (ใช้ธีมร้าน)
- หน้า `/about` `/oem` `/gallery` `/quote` เป็น route ที่ฝังในโค้ด → ร้านอื่นสร้างหน้าชื่อซ้ำพวกนี้จาก ERP ไม่ได้ (ERP กันไว้ใน RESERVED แล้ว)
- รายการหน้าในพรีวิวแท็บดีไซน์ (`PAGES` ใน website-theme-panel) ยังเป็นชุดของ IG
