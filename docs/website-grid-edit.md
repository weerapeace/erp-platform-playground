# ▦ แก้ไขทีละมาก (ตาราง) — หน้า "สินค้าบนเว็บ"

แก้หลายสินค้าในตารางเดียว ค่าต่างกันได้ทุกแถว (ต่างจาก ✏️ แก้หลายรายการ ที่ตั้งค่าเดียวให้ทุกตัว)

## อยู่ที่ไหน

- ปุ่ม **▦ แก้ไขทีละมาก** หัวตาราง = ทั้งร้าน
- ติ๊กสินค้า → แถบล่าง **▦ แก้แบบตาราง** = เฉพาะที่ติ๊ก

## ช่องที่แก้ได้ — ห้ามฝังในหน้าจอ

| ระดับ | ช่องมาจาก |
| --- | --- |
| ทีละสินค้า | 🌐 ช่องเว็บของร้านนี้ = `WEB_GRID_FIELDS` ใน `lib/website-listing-fields.ts` · 📦 Parent SKU = ทะเบียนฟิลด์กลาง (`parent-skus-v2`) |
| ทีละสี | 🎨 SKU ลูก = ทะเบียนฟิลด์กลาง (`skus-v2`) |

- เพิ่มช่องที่ทะเบียน → ขึ้นในตัวเลือกช่องเอง · ปิดช่องที่ทะเบียน → หายเอง
- สิทธิ์ตามทะเบียน (`lib/registry-fields.ts`): ฟิลด์ลับ (`sensitive_permission`) + `view_roles` = ไม่มีสิทธิ์ไม่เห็น · `edit_roles` / `is_editable=false` = อ่านอย่างเดียว
- ชนิดที่แก้ในตาราง: ข้อความ · ตัวเลข/เงิน · ใช่/ไม่ · ตัวเลือก · วันที่ · ลิงก์ (RelationPicker) — รูป / แท็ก / รายการย่อย / JSON / คำนวณ ไม่อยู่ในตาราง (แก้ที่หน้าสินค้า)
- ช่อง 📦/🎨 แก้ที่ ERP จริง ทุกร้าน/ทุกหน้าเห็น · ช่อง 🌐 เฉพาะร้านนี้

## ใช้งาน

- **ช่องที่จะแก้** พับ/กางได้ · ป๊อปเลือกช่อง (ของกลาง `FieldChipsPicker` + `groupToggle` เลือกทั้งกลุ่ม) · จำช่องที่เลือก + พับ/กาง ต่อคน (`useUserPref`)
- ช่องสีเหลือง = แก้แล้วยังไม่บันทึก · สีแดง = ค่าผิด (ชี้ดูเหตุผล)
- วางจาก Excel / Google Sheets ทีละหลายช่อง (คลิกช่องเริ่ม → Ctrl+V) — ค่าที่ใช้ไม่ได้ข้าม + บอกจำนวน (`lib/grid-edit.ts`)
- ⤓ หัวคอลัมน์ = ใช้ค่าแถวแรกกับทุกแถวที่เห็น
- ช่องเว็บว่าง = ใช้ค่าอัตโนมัติ (ตัวจางในช่อง)
- กรอง: ค้นหารหัส/ชื่อ · เฉพาะสินค้าที่ต้องแก้ · แสดงทีละ 100 แถว

## บันทึก

- ช่องเว็บ → `POST /api/website/listings/grid` ครั้งเดียวทุกแถว (`listingPatchToRow` · audit ค่าเดิม/ใหม่ต่อรุ่น · ล้างแคชเว็บร้าน)
- ช่อง ERP → `PATCH /api/master-v2/<module>/<id>` ตัวกลางเดิม (สิทธิ์ระดับฟิลด์ · ฟิลด์บังคับ · ประวัติเวอร์ชัน · audit)
- เกิน 20 แถว = พิมพ์ `CONFIRM` · ไม่สำเร็จ = แถวนั้นยังเป็นสีเหลือง + บอกเหตุผล ให้แก้แล้วกดบันทึกอีกครั้ง

## โหลดข้อมูล

`GET /api/website/listings/grid?shopId=&level=product|color&pcols=&scols=` — โหลดเฉพาะคอลัมน์ที่เลือก (ต้องอยู่ในทะเบียน) · เลือกช่องเพิ่ม = โหลดเพิ่มเอง
(Louis ทีละสี ทุกคอลัมน์ = 7.3 MB → เฉพาะที่เลือก ~0.5 MB)
