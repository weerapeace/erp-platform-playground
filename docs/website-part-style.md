# 🎨 ชุดปรับหน้าตาชิ้นส่วน (Part Style Kit) — ของกลาง

## ใช้ทำอะไร
ให้เจ้าของปรับหน้าตาทีละชิ้นในหน้าพิเศษของเว็บร้านได้ละเอียด โดยไม่ต้องแก้โค้ด:
**ตัวอักษร** (ฟอนต์ ขนาด ความหนา สี ระยะตัวอักษร/บรรทัด จัดวาง ตัวพิมพ์ ตัวเอียง) · **กล่อง** (สีพื้น มุมโค้ง ระยะใน เส้นขอบ สีขอบ เงา)
· **ตำแหน่ง** (จัดวาง ระยะห่างข้างใน ระยะด้านบน ความกว้างสูงสุด) · **ไอคอน** (ขนาด สี) · **ตอนถูกเลือก** (ปุ่มเมนู) · **ซ่อน/โชว์**
ทุกค่าตั้งได้ "ทุกจอ" และ "เฉพาะมือถือ" (< 768px) · ไม่ตั้ง = ค่ากลางของร้าน (หน้าตาเดิม)

เริ่มใช้ที่: **👤 หน้าบัญชีของฉัน** (ERP › เว็บไซต์ › ดีไซน์ › 📄 หน้าพิเศษ) · ต่อไป: หน้าเข้าสู่ระบบ/ป๊อปสมัคร · หน้าขอบคุณ · 404 · ป๊อปอัป · คุกกี้

## ใช้ยังไง (เจ้าของ)
1. แท็บดีไซน์ › 📄 หน้าพิเศษ › 🧑 หน้าบัญชีของฉัน › กด "ดูในพรีวิว" (ข้อมูลตัวอย่าง ไม่ต้องล็อกอิน)
2. ตั้งแบบหัว/เมนู/กล่อง/ส่วนเสริม → เห็นผลสดในพรีวิว
3. เปิด "🎨 ปรับละเอียดทีละชิ้น" → **คลิกชิ้นในพรีวิว** (หรือกดชื่อชิ้น) → ปรับในแผง · 📱 เฉพาะมือถือ = ค่าทับเฉพาะจอเล็ก
4. ↺ = กลับค่ากลาง (ทีละช่อง/ทั้งชิ้น) · 📋/📌 คัดลอก–วางสไตล์ระหว่างชิ้น · กดเผยแพร่ของแท็บดีไซน์

## โครงสร้าง (นักพัฒนา)
| ส่วน | ไฟล์ |
|---|---|
| ชนิดค่า + ตัวตรวจ `PartStyles` / `normalizePartStyles` + หน้าบัญชี `AccountLook` / `normalizeAccount` | ERP `lib/website-site-design.ts` ↔ เว็บร้าน `src/lib/site-design.ts` (**มิเรอร์ทั้งไฟล์** — `check:mirrors`) |
| ทะเบียนชิ้นส่วนของแต่ละหน้า + กลุ่มตัวปรับ + ช่วงแถบเลื่อน | ERP `lib/website-page-parts.ts` (`ACCOUNT_PARTS`) |
| แผงปรับ (ของกลาง) | ERP `components/website-part-style-editor.tsx` `<PartStyleEditor parts value onChange colors />` |
| คุยกับพรีวิว (iframe แท็บดีไซน์) | ERP `lib/storefront-preview-bus.ts` (`setPreviewFrame` · `sendToPreview` · `usePreviewMessages` — ฟังเฉพาะข้อความจาก iframe จริง) |
| ตัววาด CSS | เว็บร้าน `src/lib/part-style-css.ts` `partStylesCss(scope, parts)` · ฟอนต์ Google `partStyleFonts` + `partFontsHref` |
| คลิกเลือกชิ้นในพรีวิว | เว็บร้าน `src/components/layout/PartPickBridge.tsx` (ใน layout เฉพาะพรีวิว) — ข้อความ `storefront-part-pick` / `storefront-part-picked` |

- ค่าเก็บเป็น `{ [คีย์ชิ้น]: { all?, mobile? } }` · สี = ชื่อสีร้าน (`PART_COLOR_TOKENS` → `var(--color-…)` เปลี่ยนสีร้านแล้วตาม) / `#hex` / `none` · ฟอนต์ `display`/`body` = ฟอนต์ของร้าน
- CSS ทุกบรรทัด `!important` (ชนะคลาสเดิมของชิ้น) · ออกเฉพาะค่าที่ตั้ง · active = `[aria-selected="true"]`/`[aria-current="page"]` · ไอคอน = `[data-part-icon]`
- คีย์ชิ้นต้องผ่าน `PART_KEY_RE` (กันแทรก CSS) · สูงสุด 80 ชิ้นต่อหน้า · ตัวเลขถูกบีบตาม `PART_RANGES`

## เพิ่มหน้าใหม่ให้ปรับละเอียดได้
1. ERP `lib/website-page-parts.ts`: ประกาศ `XXX_PARTS` (คีย์ · ชื่อไทย · กลุ่ม)
2. เก็บค่า `parts: PartStyles` ในค่าของหน้านั้น (normalize ด้วย `normalizePartStyles`) — แก้ไฟล์มิเรอร์ทั้ง 2 repo
3. เว็บร้าน: ติด `data-part="<คีย์>"` ที่ชิ้นนั้น + ครอบด้วย scope (เช่น `data-xxx`) + `<style>{partStylesCss('[data-xxx]', parts)}</style>`
4. ERP: วาง `<PartStyleEditor parts={XXX_PARTS} … />` ในการ์ดตั้งค่าของหน้านั้น — แผง + คลิกเลือกในพรีวิวได้เอง

## ห้าม / ข้อจำกัด
- ห้ามทำแผงปรับสี/ฟอนต์แยกเองในหน้าใหม่ — ใช้ตัวนี้
- ฟอนต์ที่ไม่ใช่ของร้าน/ที่ฝังมา โหลดจาก Google ตอนเปิดหน้านั้น (อาจกะพริบครั้งแรก)
- หน้าบัญชีมีข้อความภาษาไทยอย่างเดียว (ยังไม่มีช่อง _en)
- พรีวิว ERP ใช้ข้อมูลตัวอย่าง (`src/lib/member/sample.ts`) — ปุ่มบันทึกในพรีวิวไม่มีผลจริง
