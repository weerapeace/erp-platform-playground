# 🛒 ดีไซน์ตะกร้า (Website Cart Design)

ตั้งที่ ERP → เว็บไซต์ → แท็บ 🎨 ดีไซน์ → **🛒 ตะกร้า** · ค่าเก็บใน `shops.theme.cart` (ไม่มีตารางใหม่) · 💌 การ์ดแยก เพิ่มคอลัมน์ `store_orders.gift_card_fee` (2026-10-18)

## ใช้ทำอะไร
ปรับหน้าตา + ฟังก์ชันของตะกร้าบนเว็บร้าน ทั้ง **ลิ้นชักตะกร้า** และ **หน้าตะกร้าเต็มหน้า `/cart`** (ใช้ตัววาดเดียวกัน แก้ที่เดียวเปลี่ยนทั้งคู่)

ค่าเริ่มต้น = หน้าตาเดิมทุกอย่าง (ลิ้นชักขวา กว้าง 448px · ปุ่ม "ดำเนินการสั่งซื้อ" · แถบส่งฟรี · ล้างตะกร้า) — ฟังก์ชันใหม่ปิดไว้จนกว่าจะเปิดเอง

## ตั้งค่าได้
| กลุ่ม | ค่า |
|---|---|
| 🧺 หน้าตา | ลิ้นชักขวา / ซ้าย / หน้าต่างกลางจอ · กว้าง 380/448/560 · หัวข้อ · กดไอคอนตะกร้า = เปิดลิ้นชัก หรือ ไปหน้า `/cart` |
| 🧾 รายการ | ขนาดรูป · ทรงรูป (มน/เหลี่ยม/วงกลม) · เต็มกรอบ/เห็นครบ · โชว์ตัวเลือก · ราคาต่อชิ้น · ราคาเต็มขีดฆ่า + "ประหยัด ฿X" · ♡ ย้ายไปรายการโปรด |
| 🫙 ตอนว่าง | ข้อความ + ปุ่ม (เปิดสินค้าแนะนำไว้ → ตอนว่างก็โชว์) |
| 💳 ท้ายตะกร้า | ปุ่มสั่งซื้อ · ปุ่ม "เลือกซื้อต่อ" · ข้อความใต้ยอดรวม · ล้างตะกร้า |
| 🚚 ส่งฟรี | ข้อความ `{amount}` = ยอดที่ขาด · ข้อความตอนถึงแล้ว (ยอดส่งฟรีตั้งที่ 🏪 ข้อมูลร้าน) |
| 🛍 สินค้าแนะนำ | **ได้ 3 ชุด** (`recsSets`) แต่ละชุด: หัวข้อ · จำนวน 1–12 · อัตโนมัติ / เฉพาะที่ติ๊กแนะนำ / เลือกเอง · หน้าตาแยกลิ้นชัก/หน้า /cart (เลื่อนข้าง · ตาราง · แถวรายการ · ติ๊กเพิ่ม) · ตำแหน่ง (ใต้รายการ/เหนือรายการ/ท้ายตะกร้า) · โชว์เมื่อ (ทุกครั้ง/มีของ/ว่าง) · ขนาด/ทรงรูป · คอลัมน์ · ชื่อ/ราคา/ราคาขีดฆ่า · ข้อความ+หน้าตาปุ่ม · ดันราคาพอดีให้ถึงส่งฟรี |
| ✨ ฟังก์ชันเพิ่ม | 🎟️ โค้ดส่วนลด · ⭐ แต้มที่จะได้ · 🎀 ห่อของขวัญ · 💌 เขียนการ์ดอวยพร (แยกจากห่อ · เขียนข้อความในตะกร้าได้เลย) · 📝 หมายเหตุถึงร้าน — **ไอคอนทุกข้อเปลี่ยนได้** (`icons` · ว่าง = ไม่มี · ใช้ที่หน้าชำระเงินด้วย) + ข้อความห่อ/การ์ด/หมายเหตุ (`labels` · ว่าง = ค่าเริ่ม) |
| 🛡 ความมั่นใจ | สูงสุด 4 ข้อ (ไอคอน + ข้อความ · ลากเรียง) |
| 📅 วันได้รับ | เร็วสุด/ช้าสุด (วันทำการ จ.–ศ.) + ข้อความ `{from}` `{to}` |

## สินค้าแนะนำเลือกยังไง (`pickCartRecs`)
- ไม่โชว์ของที่อยู่ในตะกร้าแล้ว · ข้ามสินค้าหมด / ไม่มีราคา
- **อัตโนมัติ** = คะแนน: หมวดเดียวกับของในตะกร้า +3 · ติ๊กแนะนำ +2 · ขายดี +1~2
- **เลือกเอง** = เรียงตามที่เลือก (รหัสรุ่น)
- ยอดยังไม่ถึงส่งฟรี + เปิด "ดันราคาพอดี" → สินค้าราคา ≥ ยอดที่ขาด (ใกล้สุด) ขึ้นก่อน

## ข้อมูลเก่า → หลายชุด
ข้อมูลก่อนมี `recsSets` = ชุดเดียวจากช่อง `recs*` เดิม (หน้าตาเดิม: ลิ้นชักเลื่อนข้าง · /cart ตาราง · ใต้รายการ) · `normalizeCart` เขียนช่อง `recs*` เป็นสำเนาชุดแรกเสมอ (เว็บรุ่นเก่ายังอ่านได้) · ติ๊กเพิ่ม: ตัวที่ติ๊กจากชุดนั้นค้างในรายการ (☑) · เอาติ๊กออก = เอาออกจากตะกร้า

## 💌 การ์ดอวยพรแยกจากห่อ
- เปิดที่ 🏪 ข้อมูลร้าน กลุ่ม 🎀: `card_enabled` · `card_fee` · `card_title` (+ ดีไซน์ → ตะกร้า ติ๊ก "เขียนการ์ดอวยพร" ถ้าอยากให้เขียนในตะกร้า)
- ออเดอร์: `gift.addCard` → ERP คิด `calcCardFee` ใหม่เสมอ เก็บ `store_orders.gift_card_fee` · ไม่ห่อ + มีข้อความ/การ์ด = ป้าย "💌 ใส่การ์ดอวยพร" ในแท็บออเดอร์ · พิมพ์การ์ดได้เหมือนออเดอร์ห่อ
- ร้านปิดบริการการ์ดระหว่างลูกค้ากรอก = ไม่รับออเดอร์ บอกให้เอาออก (409)

## ส่งต่อหน้าชำระเงิน (`src/lib/cart-handoff.ts` ฝั่งเว็บ)
โค้ดส่วนลด · ติ๊กห่อของขวัญ · 💌 การ์ด + ข้อความ · หมายเหตุ → เก็บใน sessionStorage → หน้าชำระเงินเติมให้เอง (ตรวจโค้ดซ้ำตามยอด/เบอร์) · สั่งสำเร็จ = ล้าง
⚠️ ตะกร้าแค่ "ดูก่อน" — ยอดจริง/ส่วนลด/ค่าห่อ/แต้ม ERP คิดใหม่ตอนรับออเดอร์เสมอ

## ต้องตั้งที่อื่นด้วย (ไม่งั้นฟังก์ชันเงียบ)
- 🎀 ห่อของขวัญ → 🏪 ข้อมูลร้าน เปิดห่อของขวัญ
- 💌 เขียนการ์ด → 🏪 ข้อมูลร้าน เปิด "ขายการ์ดอวยพรแยก" (+ ตั้งค่าการ์ด)
- ⭐ แต้ม → เปิดระบบแต้มในข้อมูลร้าน + ระบบสมาชิก
- ♡ รายการโปรด → ระบบสมาชิก
- 🚚 แถบส่งฟรี → ยอดส่งฟรีในข้อมูลร้าน

## พรีวิว
อยู่แท็บ 🛒 ตะกร้า → หน้าตั้งค่าส่ง `storefront-cart-pin` ให้เว็บในพรีวิวเปิดตะกร้าค้าง · ตะกร้าว่าง = สินค้าตัวอย่าง 2 ชิ้น (ดูอย่างเดียว ไม่ใส่ตะกร้าจริง) · เลือก "ตะกร้า (เต็มหน้า)" ในช่องหน้าพรีวิวเพื่อดู `/cart`

## ข้อจำกัด
- แต้มที่โชว์ = ประมาณ (ไม่รู้ตัวคูณระดับสมาชิกในตะกร้า)
- วันได้รับ = นับวันทำการเฉย ๆ ยังไม่รู้วันหยุดนักขัตฤกษ์
- หน้า `/cart` กด "ใส่ตะกร้า" จากดูด่วน (สินค้าหลายสี) ลิ้นชักจะเด้งขึ้นด้วย (ตามตัวดูด่วนกลาง)
