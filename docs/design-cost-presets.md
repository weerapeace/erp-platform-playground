# ราคากลางค่าใช้จ่ายเพิ่ม + โสหุ้ยแยกรายการ (แท็บตีราคา ใบงานออกแบบ)

เจ้าของขอ 2026-11-07:
- ค่าแรงผลิต: "อยากให้มีรายการอื่นๆ ให้ดูได้ด้วย (อะไรเคยผลิตเท่าไหร่) กดเลือกได้"
- ค่าแรง (ตัด/ปลอก/วาด), ค่าโสหุ้ย: "มีราคากลางแล้ว อยากได้ปุ่มกดใส่ได้เลย (แก้ราคากลางได้ด้วย)"
- ค่าโสหุ้ย: "ใส่รายละเอียดว่ามีอะไรบ้าง ราคาเท่าไหร่ · ถุง/packaging คำนวณตามขนาดสินค้า · ค่าส่งก็คำนวณได้"
- ต้นทุนอื่นๆ: "กดแล้วเลือกได้ (เพิ่ม ลบ แก้ไข)"

## ใช้ทำอะไร (กล่อง "ค่าใช้จ่ายเพิ่ม" ตอนแก้ไข)
| รายการ | ตัวช่วย |
|---|---|
| ค่าแรงผลิต | **ดูที่เคยผลิต** — 3 แหล่ง: สูตรผลิต (ค่าแรงกลางใน BOM รวมต่อรุ่น) · จ่ายจริง (ใบจ่ายงาน ค่าแรง ÷ จำนวน) · ใบงานก่อนหน้า · กดเลือก = ใส่ยอด + จดหมายเหตุ "อ้างอิง …" |
| ค่าแรง (ตัด/ปลอก/วาด) | **ราคากลาง ฿X** กดใส่ต่อใบ · หรือ **ตามจำนวนชิ้น** = จำนวนชิ้นวัตถุดิบที่ไม่ใช่อะไหล่ × ราคาตัดต่อชิ้น (แก้ในใบ → ตามวัสดุ → ราคากลาง) + นับชิ้นงานต่อใบ / ตามจำนวนสั่ง |
| ค่าโสหุ้ย | **แยกรายการ** — ขนาดสินค้าตอนแพ็ก (แยกตามแท็บไซส์) → QC / ค่าแรงแพ็ก (ราคากลางต่อชิ้น) + ถุง + กล่อง + ค่าส่ง · ติ๊กปิดรายการที่งานนี้ไม่มีได้ · ยอดคิดให้เอง (ล็อกช่อง) · "ใส่ยอดเอง" = กลับเป็นแบบเดิม |
| ต้นทุนอื่นๆ | หัวกล่อง **เลือกต้นทุนอื่นๆ** ติ๊กได้หลายอัน → เพิ่มเป็นแถว (แบบหารจำนวนสั่งใช้จำนวนที่สั่งปัจจุบัน) |

หัวกล่องมีปุ่ม **ราคากลาง** (คนที่เห็นต้นทุน + แก้สินค้าได้) → ป๊อปตั้งค่า 7 หมวด

## วิธีคิด (lib/design-cost-presets.ts)
- **ค่าตัดตามชิ้น** (`cutLaborRows`): นับทุกบรรทัดที่มีวัตถุดิบ ยกเว้นอะไหล่ (คิดแบบนับชิ้น / ชนิดมีคำว่า อะไหล่ หรือ ซิป) — ติ๊กเอาเข้า/ออกเองได้ (`cut_skip` บนบรรทัด) · ชิ้นว่าง = 1 · ราคา: `cut_rate` บนบรรทัด → `design_price_items.cut_rate` → ราคากลาง kind `cut_rate` · ยอดตามบรรทัดอัตโนมัติตอนแก้
- **ตั้งค่าตัดตามวัตถุดิบ** (ป๊อปราคากลาง แท็บ "ค่าตัดต่อชิ้นวัตถุดิบ" · `CutRateByMaterial` · 2026-11-09): ค่ากลาง (preset ตัวแรก) + รายการวัตถุดิบตีราคาจัดตามกลุ่ม (`cutMaterialGroups` — ใช้บ่อยก่อน · อะไหล่/ซิปซ่อนไว้) · ใส่ราคารายวัตถุดิบ หรือ "ใส่ทั้งกลุ่ม" (= เขียน `design_price_items.cut_rate` ทุกตัวในกลุ่ม ผ่าน PATCH /api/master-v2/design-price-items — มี audit · ไม่มีคอลัมน์ใหม่) · ✕ = ล้างกลับไปใช้ค่ากลาง · ตัวช่วย ค่าแรงช่างต่อวัน ÷ ชิ้นต่อวัน (`cutRateFromWage` · จำค่าแรงในเครื่อง `cut-rate-wage`) · /api/design-sheets/price-items ส่ง `used_lines/used_pieces` เพิ่ม · ตีราคาคิดอัตโนมัติ (บรรทัด → วัตถุดิบ → ค่ากลาง)
- **แถบจำนวนที่สั่ง** (`OrderQtyBar` บนแท็บตีราคา · 2026-11-09): ใส่จำนวนครั้งเดียวต่อแท็บ (− / ช่อง / + ทีละ 100 · ปุ่มรอบเสนอราคา · ปุ่มลัด 100–5,000) → ใช้ทุกที่: รายการ "หารจำนวนสั่ง" · ค่าตัดทั้งล็อต · ต้นทุนทั้งล็อต (โชว์ต่อใบ/ทั้งล็อตบนแถบ) · บันทึกพร้อมตีราคาที่ `design_sheets.order_qty` jsonb {parentKey: qty} (migration `202611270100_design_sheet_order_qty.sql` · `cleanOrderQty`) · ไม่ได้ใส่ = ใช้จำนวนจากรอบเสนอราคาล่าสุด (ขั้นน้อยสุด) · ช่องเดิมในหัวค่าใช้จ่ายเพิ่มเหลือแค่บอกตัวเลข
- **ถุง**: ถุงใบเล็กสุดที่ กว้างถุง ≥ กว้าง+หนา+2 และ ยาวถุง ≥ ยาว+หนา+2 (หมุนถุงได้)
- **กล่อง**: กล่องใบเล็กสุดที่ใส่ได้ วางทิศไหนก็ได้ (ปิดไว้ก่อน — งานส่วนใหญ่ไม่มีกล่อง)
- **ค่าส่งแบบลัง**: ลองวาง 6 ทิศ เอาทิศที่ใส่ได้มากสุด · ต่อชิ้น = ค่าส่งต่อลัง ÷ จำนวนต่อลัง (ใช้ลังแรกในราคากลาง)
- **ค่าส่งรายชิ้น**: น้ำหนักที่คิด = มากกว่าระหว่าง จริง กับ กว้าง×ยาว×หนา÷5000 → ขั้นราคาแรกที่ไม่เกิน
- ไม่มีขนาด / ไม่มีถุงที่ใส่ได้ / ใหญ่กว่าลัง → แถวนั้นเตือนสีแดง ยอด 0

## เก็บข้อมูลที่ไหน
- ราคากลาง: ตาราง `design_cost_presets` (migration `202611220100_design_cost_presets.sql`) · RLS deny-all → ผ่าน API เท่านั้น
  - API `GET/POST /api/design-sheets/cost-presets` · `PATCH/DELETE /api/design-sheets/cost-presets/[presetId]` (ลบ = ซ่อน is_active=false)
  - สิทธิ์: ดู = `products.cost.view` · แก้ = `products.cost.view` + `products.edit` · audit `cost_preset_create/update/delete` (มี changes)
- ค่าที่ใส่ในใบ: `design_sheets.cost_extra` (เหมือนเดิม) + ช่องเสริมในแต่ละรายการ: `kind` · `note` · `oh` (ขนาดสินค้า / รายการที่ปิด / วิธีค่าส่ง) — `cleanExtra` เก็บให้ · ใบเก่าไม่มีช่องเหล่านี้ = ดูชนิดจากชื่อ (`extraKindOf`)
- **แก้ราคากลางแล้ว ใบที่ใส่ไปแล้วไม่เปลี่ยนเอง** — เปิดใบที่แยกรายการโสหุ้ยไว้ ถ้าราคากลางเปลี่ยนจะมีลิงก์ "ราคากลางเปลี่ยน — กดอัปเดตเป็น ฿X"
- ค่าตัดตามชิ้น: migration `202611220200_cut_labor_rates.sql` — `design_price_items.cut_rate` (แก้ที่ป๊อปจัดการวัสดุตีราคา ช่อง "ค่าตัด/ชิ้น") · `design_sheet_cost_lines.cut_rate / cut_skip` · extra ค่าแรงตัด `cut_by: "pieces"`
- ค่าแรงที่เคยผลิต: `GET /api/design-sheets/labor-refs` อ่านอย่างเดียว (bom_labor_rates · mo_work_orders · design_sheets.cost_extra)
