# MasterCRUD บนมือถือ (จอ ≤ 639px)

> เจ้าของขอ 2026-11-12: "ออกแบบ /master/skus และ drawer เป็น phone responsive" + "อย่าลืม Parent SKU"
> ทำที่ของกลาง (`components/master-crud`) → ทุกหน้า Master Data ที่ใช้ MasterCRUD ได้ด้วย ไม่ใช่แค่ 2 หน้า

## หน้ารายการ
- **การ์ดแทนตาราง** — จอ < 768px ตารางกลางเปิดเป็นการ์ดเอง · ค่า "ตาราง" ที่แอดมินตั้งไว้ (หรือมุมมองที่บันทึกจากจอคอม) **ไม่ทับบนมือถือ** แล้ว (กดสลับเองได้)
- หน้าตาการ์ดต่อหน้า: `config.cardConfig` (ทับค่าตั้งต้น รูปปก · ชื่อ · รหัส)
  - `layout: "horizontal"` = รูปซ้าย ข้อมูลขวา (กินที่น้อย เลื่อนเห็นหลายตัว)
  - `active: "is_active"` = ป้าย "● เปิด / ● ปิดอยู่" (ของใหม่ใน CardConfig)
  - ใส่ได้เฉพาะช่องที่เป็นคอลัมน์ของตาราง · ช่องลับ (เช่นราคา) ที่ผู้ใช้ไม่มีสิทธิ์ = ไม่โชว์เอง
- หัวหน้าเตี้ยลง (ซ่อนคำอธิบาย) · ปุ่มงานโต๊ะทำงาน (⚙ ปรับแต่ง / นำเข้า / เพิ่มหลายรายการ) ซ่อนบนมือถือ · ปุ่มที่เหลือขึ้นบรรทัดใหม่ได้ ไม่ล้นจอ

## ปุ่ม 📷 สแกน (`config.scanOpen`)
- ยิงบาร์โค้ด / เปิดกล้อง / พิมพ์รหัส (ช่องกลาง `ScanInput`) → ถาม `/api/scan/resolve` (ของกลาง) → เปิดลิ้นชักเลย
- `resolve(hit)` คืน id ที่จะเปิดในหน้านี้ · คืน `null` = ของนั้นไม่ได้อยู่หน้านี้ → โชว์ลิงก์ไปหน้าของมัน
- ผลสแกนสินค้ามี `entity` ("sku" / "parent") + `parentId` → หน้า Parent สแกนบาร์โค้ด SKU ลูกแล้วเปิดแม่ได้
- ⚠️ กล้องใช้ไม่ได้ในแอปเดี่ยวที่เปิดในกรอบ (iOS บล็อกกล้องใน iframe) — ยังพิมพ์/ยิงเครื่องสแกนได้

## ลิ้นชัก (Drawer)
| ส่วน | มือถือ |
|---|---|
| หัว | "ชื่อโมดูล · รหัส" บรรทัดเดียว · ซ่อนปุ่ม 🎨 ออกแบบฟิลด์ |
| แถบเครื่องมือ | ภาษา + ป้ายสุขภาพเห็นตลอด · กลุ่มเนื้อหา/แปล พับใต้ปุ่ม "เครื่องมือ" (อยู่ในโหมดลงรายละเอียด = กางเอง) |
| รูป | พับเป็นแถบเล็ก: รูปย่อ + รหัส + สถานะ + "รูปทั้งหมด N · จัดการรูป" (เฉพาะโหมดดู · โหมดแก้/สร้างใหม่โชว์เต็ม) · ไฟล์แนบย้ายไปใต้ช่องข้อมูล |
| แท็บ | แถบแท็บติดหนึบด้านบน · ปัดซ้าย-ขวาเปลี่ยนแท็บ (`useSwipeNav`) · เปลี่ยนแท็บตอนเลื่อนลึก = กลับต้นแท็บ |
| ช่องข้อมูล | 1 คอลัมน์เต็มจอ (ทับความกว้างที่ตั้งในตัวออกแบบ เฉพาะจอ < 640px) |
| แถบล่าง | ◀ ▶ ปุ่มสี่เหลี่ยม 44px · ⋯ (คัดลอก/ลบ/ปุ่มรายแถว) · ✎ แก้ไข ปุ่มใหญ่ · ไม่มี "ปิด" (ใช้ ✕ มุมบน) |

## ของกลางที่แก้ไปพร้อมกัน
- `ScrollTabs` กรอบนอก `min-w-0` — เดิมแถบแท็บยาวดันทั้งลิ้นชักกว้างเกินจอมือถือ
- `useSwipeNav` ไม่นับการปัดที่เริ่มบนของที่เลื่อนแนวนอนได้เอง (ตารางกว้าง) — ให้ตารางเลื่อนตามปกติ
- `Drawer` ขอบแคบลงบนมือถือ · แถบล่างขึ้นบรรทัดใหม่ได้
- แถบหัว "SKU ลูก" (relation-multi) ขึ้นบรรทัดใหม่ได้

## ยังไม่ได้ทำ (ต่อได้)
- ตารางย่อยในแท็บ (MiniTable) เป็นการ์ดอัตโนมัติบนมือถือ
- ชิปกรองด่วน (ไม่มีรูป / ไม่มีราคา) บนหน้ารายการ
