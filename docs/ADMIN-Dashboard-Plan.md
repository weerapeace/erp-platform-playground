## 0. ข่าวดีก่อนเลย 🎉

ระบบ ERP ของพี่ **มีของรองรับอยู่แล้วเยอะมาก** — งานนี้ส่วนใหญ่คือ **"รวมร่าง + เติมส่วนที่ขาด"** ไม่ใช่สร้างใหม่ทั้งหมด

- ✅ **มีหน้า Dashboard อยู่แล้ว** (`app/dashboard/`) มี 4 มุมมอง: ผู้บริหาร / การ์ดระบบ / ปฏิทิน / รายการแจ้งเตือน
- ✅ **มี "Executive Command Center" สำหรับแอดมินอยู่แล้ว** (`executive-view.tsx`) — โชว์ยอดขาย/กำไร/เจ้าหนี้-ลูกหนี้/สต๊อก
- ✅ **มีแดชบอร์ดแยกแต่ละแผนกอยู่แล้ว**: ผลิต, จัดซื้อ, Design, งาน (Tasks)
- ✅ **มีระบบแจ้งเตือน + LINE + สิทธิ์ (permission) + ปฏิทิน** ครบ พร้อมให้หยิบใช้

👉 แปลว่าเราต่อยอดของเดิมได้เลย ไม่ต้องเริ่มศูนย์

## 2. เช็กทีละข้อจากภาพที่พี่วาด (ตรงไหน "มีแล้ว / มีบางส่วน / ต้องทำใหม่")

สัญลักษณ์: ✅ = มีแล้วใช้ได้เลย · ⚠️ = มีข้อมูล/บางส่วนแล้ว ต้องต่อ · ❌ = ยังไม่มี ต้องทำใหม่

### 🏭 ผลิต
| สิ่งที่พี่อยากได้ | สถานะ | ข้อมูลมาจากไหน / ต้องทำอะไร |
|---|---|---|
| งานตอนนี้ใครทำอยู่ + เมื่อไหร่เสร็จ | ✅ | `mo_work_orders` (โต๊ะอยู่ในช่อง `department_name`, กำลังทำ = `status='dispatched'`) มีในแดชบอร์ดผลิตแล้ว · *แต่ "วันเสร็จ" (`due_date`) แทบไม่ได้กรอก* |
| ภาพรวมงานทั้งหมด + ใครทำอะไร | ✅ | แดชบอร์ดผลิตมีอยู่แล้ว (1 การ์ด = 1 ใบสั่งผลิต MO) |
| **ค่าแรงรวมเท่าไหร่** | ⚠️ | คำนวณได้แล้ว (มีสูตรใน `work-board`) แต่ **การ์ดสรุปยังไม่รวมยอดค่าแรงให้** — ต้องเพิ่มการรวมยอด |
| ปฏิทินงาน (deadline) | ⚠️ | มีมุมมองปฏิทินแล้ว **แต่ข้อมูลว่าง** เพราะ MO 123 ใบ กรอกวันเดดไลน์แค่ 3 ใบ → ต้องกรอกก่อนถึงจะมีอะไรโชว์ |
| งานตามแบรนด์ (แยกหลายแบบ) | ⚠️ | แบรนด์ ✅ (จัดกลุ่มได้แล้ว) · "แยกตามประเภท" มีข้อมูล (`category_id`) แต่ **ยังไม่ได้เอามาทำเป็นตัวกรอง** |
| **งานที่ยังไม่จ่าย** | ✅ | **เคลียร์แล้ว: = "ยังไม่ได้แจกงานให้โต๊ะ"** → มีอยู่แล้ว (หมวด "unassigned" ในแดชบอร์ดผลิต, `remaining>0`) ไม่ต้องเพิ่มช่องข้อมูลใหม่ |
| สรุปสิ้นเดือน โต๊ะไหนทำเท่าไหร่ (report) | ⚠️ | ข้อมูลค่าแรงมี (`wo_submissions.wage` + `mo_piecework`) แต่ **ยังไม่มีหน้าสรุปรายเดือนต่อคน** ต้องทำใหม่ |
| Deadline ลูกค้า → เปิดใบกำกับภาษี | ❌ | **ใบสั่งผลิต (MO) ยังไม่ผูกกับลูกค้า/ออเดอร์ขาย** — ต้องเชื่อม MO↔ออเดอร์ขายก่อน แล้วค่อยทำตัวเตือนเปิดใบกำกับ |

### 🛒 ซื้อ (จัดซื้อ)
| สิ่งที่พี่อยากได้ | สถานะ | หมายเหตุ |
|---|---|---|
| ขอซื้อที่ยังค้าง | ✅ | `purchase_requests_v2` (`status='waiting'`) มีในแดชบอร์ดจัดซื้อแล้ว |
| รอจ่ายเงิน → โชว์ว่ายังไม่สั่ง | ⚠️ | ข้อมูลมี (PO ร่าง = ยังไม่สั่ง, `payment_status='unpaid'`) แต่ **ยังไม่มีมุมมองรวมที่ป้ายว่า "รอจ่าย/ยังไม่สั่ง"** ชัด ๆ |
| รอสรุป (ยังไม่สั่ง) + โน้ต | ✅ | มีช่อง `note` + `reason` แล้ว |
| สั่งแล้วรอของ + ใส่ว่าเข้าเมื่อไหร่ | ✅ | หน้า "สินค้าที่รอเข้า" มี ETA (`expected_date`) + นับวันเหลือแล้ว |
| รับของเข้า → เตือนไลน์ | ❌ | **ยังไม่มี** LINE ตอนรับของ (มีแต่ตอนขอซื้อ) |
| ขอซื้อ → เตือนไลน์ | ✅ | มีแล้ว (`create-pr` ยิง LINE) |
| สั่งซื้อแล้ว → เตือนไลน์ | ❌ | **ยังไม่มี** LINE ตอนออก PO |
| ปฏิทิน ของเข้า + จ่ายเงิน | ❌ | ข้อมูลมี (`expected_date`, `paid_date`) แต่ **ยังไม่ต่อเข้าปฏิทิน** |
| สรุปทั้งเดือน (report) | ✅ | แดชบอร์ดจัดซื้อมีกราฟรายจ่าย 6 เดือน + ยอดเดือนนี้ + top ผู้ขาย |

### 💰 ขาย
| สิ่งที่พี่อยากได้ | สถานะ | หมายเหตุ |
|---|---|---|
| รายการสรุปทั้งเดือน (report) | ❌ | ข้อมูลออเดอร์ขายมี (`erp_playground_sales_orders` 42 ใบ) แต่ **ยังไม่มีหน้าสรุปรายเดือน** ต้องทำ |

## 3. สรุป "ของที่ต้องทำใหม่จริง ๆ" (รวมทุกแผนก)

จากตารางข้างบน งานใหม่จริง ๆ มีไม่เยอะ แบ่งเป็น 6 กลุ่ม:

**A. รายงานสรุปรายเดือน (ยังไม่มีตัวรวมยอด)**
- ตัวสร้างสรุปรายเดือน "ของกลาง" (ตอนนี้มีแต่ตัวพิมพ์เอกสาร ไม่มีตัวรวมยอด)
- สรุปผลิตต่อโต๊ะ/คน · สรุปขายรายเดือน · สรุปใบวางบิล · สรุป QC (ของเสีย)

**B. ปฏิทินรวม (โหมดปฏิทิน)**
- ต่อท่อให้ปฏิทินดึงเดดไลน์จริงของทุกแผนก (ผลิต/ของเข้า/จ่ายเงิน/QC/Design) ไม่ใช่แค่จากแจ้งเตือน

**C. เตือนไลน์ที่ยังขาด**
- เพิ่ม LINE ตอน "ออก PO (สั่งซื้อแล้ว)" + ตอน "รับของเข้า"

**D. ช่องข้อมูลที่ยังขาด (ต้องเพิ่มในฐานข้อมูล)**
- ธง "จ่ายค่าแรงแล้ว/ยัง" ในงานผลิต (ถ้าพี่ต้องการติดตามการจ่ายค่าแรง)
- เชื่อม "ใบสั่งผลิต (MO) ↔ ออเดอร์ขาย/ลูกค้า" + ตัวเตือนเปิดใบกำกับภาษี
- ช่อง "วันนัด/วันได้ตัวอย่าง" ใน Design
- ช่อง "เดดไลน์ส่งงาน" ใน QC

**E. หน้า Dashboard ผู้บริหารเอง**
- เพิ่ม/จัดมุมมอง "ผู้บริหาร" ให้ครบตามภาพ (ดึงการ์ด KPI + ลิงก์เจาะเข้าแต่ละแผนก)
- ตัวกรอง "งานตามประเภท" ในผลิต

**F. เก็บกวาดความปลอดภัย**
- 23 ตารางปิด RLS อยู่ (ดูข้อ 6)

## 4. ❓ เรื่องต้องตัดสินใจก่อนเริ่ม (ขอคำตอบพี่)

### 4.1 "งานที่ยังไม่จ่าย" หมายถึงอะไร? ✅ ตอบแล้ว
**= "ยังไม่ได้แจกงานให้โต๊ะ"** → ระบบมีอยู่แล้ว (หมวด "unassigned" ในแดชบอร์ดผลิต) **ไม่ต้องเพิ่มช่องข้อมูลใหม่** 👍

### 4.2 "Deadline ลูกค้า → เปิดใบกำกับภาษี"
ตอนนี้ **ใบสั่งผลิตไม่รู้ว่าเป็นของลูกค้าคนไหน** (ไม่ได้ผูกออเดอร์ขาย)
➡️ งานลูกค้าเริ่มจาก "ออเดอร์ขาย (SO)" แล้วค่อยเปิดใบสั่งผลิตใช่ไหม? หรือทำงานคนละทางกัน? (คำตอบกำหนดว่าเราต้องเชื่อมยังไง)

### 4.3 เดดไลน์งานผลิต
ตอนนี้ MO 123 ใบ กรอกเดดไลน์แค่ 3 ใบ → ปฏิทินผลิตจะว่าง
➡️ ต่อไปจะกรอกเดดไลน์ทุกใบไหม? หรืออยากให้ผมทำให้กรอกง่ายขึ้น?

### 4.4 LINE — กลุ่มไหนเตือนอะไร
มีระบบ LINE + config อยู่แล้ว
➡️ อยากให้ ซื้อ/QC/ผลิต เตือนเข้า **กลุ่มเดียวกัน** หรือ **แยกกลุ่มต่อแผนก**?

### 4.5 ใครเห็น Dashboard ผู้บริหารนี้
➡️ เฉพาะเจ้าของ/แอดมิน หรือให้หัวหน้าแต่ละแผนกเห็นเฉพาะของแผนกตัวเอง?
