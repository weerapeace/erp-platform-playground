# แบ่งจอ 2 หน้า (SplitScreen) — ของกลาง

**ใช้ทำอะไร:** กด **Ctrl** (Mac: ⌘) ค้างไว้ แล้ว **คลิก** แท็บ หรือ **ลาก** แท็บไปขอบขวาของจอ → จอแบ่งเป็น 2 ฝั่ง หน้าเดิมอยู่ซ้าย แท็บนั้นอยู่ขวา (เช่น ปฏิทินซ้าย กระดานขวา)
- ลากเส้นกลางเพื่อปรับขนาด (จำไว้ในเครื่อง) · ปุ่ม "⇱ เปิดเป็นหน้าหลัก" = ให้หน้าฝั่งขวาเป็นหน้าหลักแล้วปิดแบ่งจอ · ✕ = ปิด
- เปลี่ยนหน้าในฝั่งซ้าย ฝั่งขวายังอยู่ · รีเฟรชหน้า = กลับมาแบ่งจอเหมือนเดิม (จำในแท็บเบราว์เซอร์นั้น)
- ใช้ได้เฉพาะจอกว้าง ≥ 1024px (มือถือ/แท็บเล็ตแนวตั้งไม่ทำงาน — ปุ่ม Ctrl ไม่มีและจอแคบเกินแบ่ง)

**ไฟล์:** `components/split-screen/index.tsx` · วางที่ `app/layout.tsx` ครั้งเดียว (`<SplitScreenHost>`) · ฝั่งขวาเป็นหน้าจริงฝัง `?embed=1` (`lib/embed-url`)

## แท็บแบบไหนแบ่งจอได้ (ระบบหาเอง ไม่ต้องแก้ทีละหน้า)
1. `[data-split-tab]` · `[role="tab"]` · ปุ่มใน `[role="tablist"]` · ปุ่ม `[data-tab-key]` (ของกลาง ScrollTabs)
2. ปุ่มในกลุ่มปุ่มสลับแบบ `inline-flex bg-slate-100 … p-0.5` (หลายหน้าเขียนแบบนี้)
- ยกเว้น: อยู่ใน `[data-no-split]` หรือในป๊อป (`role="dialog"`)

**ฝั่งขวาเปิดอะไร:** `data-split-href` (ดีที่สุด — ลิงก์ที่เปิดแท็บนั้นตรง ๆ เช่น `/tasks/plan?view=board`) → ลิงก์ `<a>` ภายใน → ถ้าไม่มีทั้งคู่ = เปิดหน้าเดิมแล้วระบบ "กดแท็บชื่อเดียวกัน" ให้ในฝั่งขวา (รอได้ ~6 วินาที)

**ทำแท็บใหม่ให้แบ่งจอได้ดี:** ใส่ `role="tablist"` ที่กลุ่ม · `role="tab"` + `aria-selected` + `data-split-href="<ลิงก์ที่เปิดแท็บนี้ตรง ๆ>"` ที่ปุ่ม

**เปิดจากโค้ด:** `openSplit("/calendar", "ปฏิทินรวม")` · ปิด `closeSplit()` · อ่านสถานะ `useSplitScreen()`

## ใช้แล้วที่
- `/calendar` (CalendarTabs ทุกแท็บ — แท็บเสริมของหน้าเปิดด้วย `?cal=<key>`)
- `/tasks/plan` แผนงานทีม (ตามความด่วน / ตาราง 4 ช่อง / ปฏิทิน / กระดาน)
- ทุกหน้าที่ใช้ ScrollTabs หรือ role=tab อยู่แล้ว

## ข้อจำกัด
- ฝั่งซ้ายถูกห่อด้วยกล่องที่มี `transform` (ให้แถบเมนู/ปุ่มที่ติดจอ อยู่ในฝั่งซ้าย) → หน้าที่ฟังการเลื่อนของ `window` จะไม่ได้ยิน (เลื่อนในกล่องแทน)
- Ctrl+คลิกบนแท็บ = แบ่งจอ (ไม่เปิดแท็บเบราว์เซอร์ใหม่) · Ctrl+คลิกบนลิงก์ทั่วไป/ปุ่มอื่น ทำงานเหมือนเดิม
- ไม่มีสิทธิ์/ไม่บันทึกข้อมูลอะไร (แค่จัดหน้าจอ) → ไม่มี audit log
- ต่างจาก SplitPanes: ตัวนั้นแบ่ง 2 กล่องในหน้าเดียว · ตัวนี้แบ่งทั้งจอเป็น 2 หน้า
