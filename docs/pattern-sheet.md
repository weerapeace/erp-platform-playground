# แพทเทิร์นจากขนาดชิ้น (Pattern sheet)

เจ้าของขอ 2026-11-07: "อยากลองทำแบบเป็นหน้าแบบ pattern ที่สร้างจากตรงนี้ได้เอง" (ตารางตีราคาในใบงานออกแบบ) — ดู widget แล้วเลือกทำ "ขั้น 1 + 2"

## ใช้ทำอะไร
เอา **กว้าง × ยาว × จำนวนชิ้น** ที่กรอกในตารางตีราคา มาวาดเป็นชิ้นแพทเทิร์นขนาดจริง แล้ว
- พิมพ์ขนาดจริง 1:1 แบ่งหน้า A4 แล้วต่อกัน (หน้าแรกมีวิธีต่อ + กรอบทดสอบ 5 × 5 ซม. + แผนผังหน้า · หน้าว่างไม่พิมพ์)
- ดาวน์โหลด **DXF** (เครื่องตัดเลเซอร์ / CAD · หน่วยมิลลิเมตร · ป้ายเป็นรหัสชิ้นภาษาอังกฤษ เพราะหลายโปรแกรมอ่านภาษาไทยเพี้ยน)
- ดาวน์โหลด **SVG** ขนาดจริง (เปิดใน Illustrator ได้ · ป้ายภาษาไทย)
- ดู "วางบนผ้า" ต่อวัสดุ (ตัววางผ้าตัวเดียวกับเครื่องคิดเลขผ้า `lib/fabric-calc` + `FabricLayoutPreview`) ใส่จำนวนผลิต / หน้าผ้าได้

## เปิดจากไหน
- ใบงานออกแบบ → ปุ่มล่าง **พิมพ์ → แพทเทิร์นจากตีราคา**
- แท็บตีราคา → **เครื่องมือ → หน้าแพทเทิร์น**
- หน้า: `/print/design-sheet/<id>/pattern?parent=<แท็บ>` (ไม่ใส่ = แท็บแรกที่มีบรรทัด)

## กติกา
- เอาเฉพาะบรรทัดที่มี **ทั้งกว้างและยาว** (อะไหล่ / ชิ้นสำเร็จ ไม่วาด — หน้าบอกจำนวนที่ข้าม)
- 1 บรรทัด = 1 แบบ (P1, P2, …) · "ตัด ×N" มาจากช่องจำนวนชิ้น (ว่าง/0 = 1)
- ชิ้นเป็น **สี่เหลี่ยม** ตามกว้าง × ยาว (ยังไม่มีรูปทรงโค้ง)
- ภาพรวม + ไฟล์ DXF/SVG วางบนแผ่นกว้าง ~160 ซม. · แผ่นพิมพ์ A4 กว้างลงตัวกับหน้า (ทับกัน 1 ซม.)
- พิมพ์ต้องตั้ง **100% (ไม่ย่อ)** — วัดกรอบทดสอบให้ได้ 5 ซม.
- บันทึกประวัติพิมพ์ (`usePrintLog("ds_pattern")`)

## ใช้ในโค้ด
```tsx
import { patternPieces, shelfLayout, tilePages, pagesWithPieces, buildPatternDxf } from "@/lib/pattern-sheet";
import { PatternPiecesSvg } from "@/components/pattern-sheet";

const L = shelfLayout(patternPieces(lines), 160);          // ชิ้นจากบรรทัดที่มีกว้าง×ยาว
<PatternPiecesSvg layout={L} />                             // ภาพรวม (ย่อพอดีกล่อง)
<PatternPiecesSvg layout={L} view={{ x: 0, y: 0, w: 19, h: 26.5 }} printMm />   // 1 หน้า A4 ขนาดจริง
download("x.dxf", buildPatternDxf(L));
```

## ✏️ วาดชิ้นวัสดุ (ShapeEditor · 2026-11-09)
เจ้าของขอ "อยากเพิ่มวัสดุแบบวาดได้ สี่เหลี่ยม วงกลม pen tool และ copy จาก Illustrator ได้" + "พิมพ์ขนาดได้ ไม้บรรทัด snap 0.1 / 1 ซม."

**เปิดจากไหน** (แท็บตีราคา ใบงานออกแบบ)
- ปุ่ม **วาดชิ้นวัสดุ** ใต้ตาราง (ข้าง "＋ เพิ่มวัตถุดิบ") หรือในกล่องตอนยังไม่มีบรรทัด → 1 ชิ้น = 1 บรรทัดใหม่ (เลือกวัสดุทีหลัง)
- ปุ่มรูปปากกา/รูปย่อ ในช่อง **กว้าง** ของแต่ละบรรทัด → แก้รูปของบรรทัดนั้น (ชิ้นที่ 2 ขึ้นไป = บรรทัดใหม่ วัสดุเดียวกัน ต่อท้าย)
- สาย/เทป (คิดตามยาว) และอะไหล่ (นับชิ้น) ไม่มีปุ่มวาด

**ในหน้าต่าง**
- เครื่องมือ: สี่เหลี่ยม (R) · วงกลม (O) · ปากกา (P: คลิก = มุม · กดลาก = เส้นโค้ง · กดจุดแรก/ดับเบิลคลิก/Enter = ปิดรูป) · ย้าย (V) · เลื่อนดู (H / Space ค้าง)
- **กดชิ้นที่วาดแล้ว = เปลี่ยนเป็น "ย้าย" ทันที · กดที่ว่าง = วาดต่อด้วยเครื่องมือล่าสุด** (เจ้าของขอ)
- ไม้บรรทัดบน/ซ้าย (ซม. · เส้นแดงตามเมาส์) · ดูดเข้า ไม่ดูด / 0.1 / 0.5 / 1 / 5 ซม. (จำในเครื่อง localStorage `pattern-shape-snap`)
- ซูม −/+/พอดี · Ctrl+ล้อเมาส์ = ซูมที่เมาส์ · ล้อเมาส์ = เลื่อน · Shift ระหว่างวาด = จัตุรัส/วงกลม/เส้น 45° · ลูกศร = ขยับทีละระยะดูด (Shift ×10) · Delete = ลบ
- พิมพ์ กว้าง/สูง/X/Y ของชิ้นที่เลือก (ล็อกสัดส่วนได้) · เพิ่มด้วยตัวเลข (สี่เหลี่ยม/วงกลม กว้าง×สูง)
- ตาราง "ระบบวัดให้": กรอบ ก×ส · พื้นที่จริง · รอบรูป · ใช้กรอบกี่ % · จำนวนชิ้น
- **คิดผ้าจาก**: กรอบสี่เหลี่ยม (ค่าเริ่ม · สูตรเดิม · เผื่อเศษ) หรือ พื้นที่จริง (เช่น หนังคิดตามพื้นที่)

**วางจาก Illustrator**
- Illustrator: Preferences → Clipboard Handling → ติ๊ก **Include SVG Code** (ครั้งเดียว) → เลือกรูป Ctrl+C → มาวาง Ctrl+V ในหน้าต่าง
- หรือ File → Export As → SVG แล้วกดปุ่ม "ไฟล์ SVG" / ลากไฟล์มาวาง (ไม่เกิน 5MB)
- หน่วย: ไม่มีขนาดในไฟล์ = 72 จุดต่อนิ้ว (1 หน่วย = 1 pt แบบ Illustrator) · ไฟล์ที่ระบุ width เป็น mm/cm/in/pt = ใช้ตามไฟล์ — โชว์หน่วยที่ใช้ทุกครั้ง ไม่ตรงพิมพ์ขนาดแก้ได้
- อ่านได้: rect (มุมมน rx) / circle / ellipse / polygon / polyline / path (M L H V C S Q T A Z) + transform (หมุน/ย้าย/ย่อ) · ข้าม defs/clipPath/mask
- path หลายเส้นในตัวเดียว (เช่น รูเจาะ) = แยกเป็นหลายชิ้น (เจาะรูจริง = ขั้นที่ 2)

**เก็บที่ไหน / คิดยังไง**
- `design_sheet_cost_lines.shape` (jsonb · migration 202611260100) = `{ v:1, shape (เริ่ม 0,0 หน่วย ซม.), basis: "box" | "area" }` · API ตรวจด้วย `cleanLineShape`
- กว้าง×ยาว ในบรรทัด = กรอบของรูปทรง · แก้กว้าง/ยาวในตารางเอง → รูปยืดตาม (`refitLineShape`)
- basis "area" → `calcCostQty({ area_cm2 })` / ชนิดชิ้น ใช้พื้นที่จริงแทน กว้าง×ยาว (tooltip ปริมาณบอกไว้)
- หน้าแพทเทิร์น: บรรทัดที่มีรูปทรง = วาด/พิมพ์/DXF/SVG เป็นรูปทรงจริง (`PatternPiece.d` / `outline`)
- สูตร: `lib/pattern-shape.ts` (flattenShape · shapeArea · shapePerimeter · fitShape · parseSvgShapes · snapTo) · เทสต์ `lib/__tests__/pattern-shape.test.ts`

**ขั้นที่ 2 (2026-11-09): แผงรายละเอียดชิ้น + ย้อนกลับ**
- กดชิ้น → แผงขวา (อยู่ตลอด กันพื้นที่วาดขยับ): ชื่อชิ้น · **วัสดุหลายตัว** (SearchableSelect จากวัสดุตีราคา · 1 วัสดุ = 1 บรรทัด) · **เผื่อพับ/เผื่อเย็บ** 0 / 0.3 / 0.5 / 1 / พิมพ์เอง (ชิ้นใหม่ใช้ค่าล่าสุด localStorage `pattern-shape-allow`) · ขนาดสำเร็จ กว้าง/สูง/X/Y + ขนาดตัด · จำนวน
- ภาพ: เส้นทึบ = แนวตัด (ขยายออกตามเผื่อ · `offsetPolygon`) · เส้นประ = แนวเย็บ · รูเจาะหดเข้าตามเผื่อ (รูเล็กกว่า 2×เผื่อ = หาย)
- **เจาะรู**: วาดรูปทับในชิ้น → กดรูปเล็ก → "เจาะเป็นรูใน Pn" (`shapeInside`) · แผงชิ้นมีรายการรู: แยกเป็นชิ้น / ลบรู · SVG path หลายเส้น (compound) = รูให้เอง
- **พับครึ่ง → / ↓** (`foldPiece`): ต้องมีเส้นตรงแนบขอบด้านที่พับ (สี่เหลี่ยมได้เสมอ · วงกลมไม่ได้) · รูสะท้อนตาม · **กลับด้าน ↔ ↕** (`flipPiece`)
- **แก้จุด**: ลากจุด · ลากหูจับ (Alt = แยกหูจับ) · ดับเบิลคลิกจุด = มุม↔โค้ง (`toggleSmooth`) · ดับเบิลคลิกเส้น = เพิ่มจุด (`splitSegment` de Casteljau รูปไม่เปลี่ยน) · Delete = ลบจุด (≥3 จุด) · สี่เหลี่ยม/วงกลม = แปลงเป็นจุดก่อน
- **Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y** + ปุ่ม ย้อน/ทำซ้ำ — ทุกการเปลี่ยน (พิมพ์ตัวเลขติดกัน ≤1.2 วิ = นับครั้งเดียว · ในช่องพิมพ์ใช้ย้อนของช่องเอง) เก็บ 100 ขั้น
- **บันทึกลงตีราคา**: 1 ชิ้น × 1 วัสดุ = 1 บรรทัด · บรรทัดของชิ้นเดียวกันผูก `shape.pid` → เปิดจากบรรทัดไหนก็ได้ทั้งชิ้น · บรรทัดเดิมที่วัสดุตรงกันใช้ต่อ (ราคา/ประวัติอยู่) · เอาวัสดุออก = บรรทัดนั้นหาย · คัดลอกแถว (⧉) = ชิ้นใหม่ (ล้าง pid)
- เก็บใน `shape` เพิ่ม: `holes` · `allow` · `pid` · `name` · กว้าง×ยาวในบรรทัด = **ขนาดตัด** (รวมเผื่อ) · แก้กว้าง/ยาวในตาราง = ยืดรูป (หักเผื่อ 2 ข้าง) · โหมดพื้นที่จริง = พื้นที่ตัดหักรู

### หน้าตาพื้นที่วาด: เครื่องมือลอย (2026-11-09)
- เครื่องมือลอยบนแคนวาส (แทนแถบ 3 แถวด้านบน): ซ้าย = เครื่องมือวาด (ไอคอน ชี้ = ชื่อ+ปุ่มลัด) · บนซ้าย = ย้อน/ทำซ้ำ/คัดลอก/วาง/สำเนา + ดูดเข้าจุด (เมนู) + ตั้งค่าเพิ่ม (ชิ้นทึบ · นำเข้า SVG) · ใต้แถบบน = ไม้บรรทัด/ตั้งขนาดจริง/เลือกรูปอ้างอิง · บนขวา = ขยายเต็มจอ · พับแผง · ล่างซ้าย = ป้ายรูปอ้างอิง (กดกางตัวเลือก) · ล่างขวา = พิกัด + ซูม
- ลากขีดใต้แคนวาส = ปรับความสูง (260–1600px · จำในเครื่อง `pattern-shape-h` · ดับเบิลคลิก = 480) · พับแผงชิ้น (`pattern-shape-panel`) เหลือแถบบาง · คลิกชิ้น (ไม่ลาก) ตอนพับ = กางเอง · ขยายเต็มจอ = ส่วนวาดลอยทับ fixed เต็มจอ แผงเลื่อนในจอ
- สเกลคงเดิมเมื่อขนาดเปลี่ยน (ResizeObserver + sizeRef) → พับแผง/ปรับความสูง ชิ้นไม่กระโดด

### เครื่องมือ vector (2026-11-09)
- **เลือกหลายชิ้น**: Shift+คลิก (เพิ่ม/เอาออก) · Shift+ลากที่ว่าง = กรอบเลือก (เฉพาะชิ้นที่อยู่ในกรอบทั้งชิ้น) · Ctrl+A ทั้งหมด · Esc เลิกเลือก · ลากชิ้นใดในกลุ่ม = ย้ายทั้งกลุ่ม · ลูกศร/Delete ทำกับทุกชิ้นที่เลือก
- **เส้นช่วยจัดแนว** (เส้นชมพู): ลากชิ้น/กลุ่มเข้าใกล้ขอบ/กึ่งกลางของชิ้นอื่น ≤ 6px = ดูดติด (เทียบกรอบตัด)
- **แผงกลุ่ม** (เลือก ≥ 2): จัดแนว 6 แบบ (ซ้าย/กลาง/ขวา/บน/กลาง/ล่าง) · เว้นระยะเท่ากัน ↔ ↕ (≥ 3 ชิ้น) · คัดลอก/ทำสำเนา/ลบทั้งหมด
- **คัดลอก/วาง**: Ctrl+C (หรือปุ่ม) = เก็บในคลิปบอร์ดเป็น SVG หน่วยซม. → วางใน Illustrator ได้ + มีรหัส `pshape:` ให้วางกลับในระบบได้ครบ (เผื่อพับ/วัสดุ/รู/เครื่องหมาย) · Ctrl+V = วาง (เลื่อน 2 ซม.) · Ctrl+D = ทำสำเนา · วางจาก Illustrator ยังใช้ทางเดิม (`parseSvgShapes`)
- **ชิ้นเดียว**: ลบมุมโค้ง (`roundCorners` รัศมีที่พิมพ์ · มุมที่ขอบสั้นลดรัศมีเอง) · สำเนากลับด้าน (คู่ซ้าย/ขวา) · เส้นขนาน ด้านใน/ด้านนอก (`offsetShape` → ชิ้นใหม่ เช่น ผ้ากาว/ซับใน · ตัดห่วงไขว้ตรงมุมด้วย `untangle`)
- **เส้นทางผ้า** (`grain` ลูกศร 2 หัว สีแดง · `defaultGrain` แนวตั้งกลางชิ้น · หมุน 90°) · **รอยบาก** (`notches` จุดบนเส้นเย็บ · โหมดคลิกเพิ่ม/ลบ · กลางทุกขอบตรง ≥ 3 ซม. `midEdgeNotches`) — เก็บใน `LineShape.grain/notches` ย้าย/ยืด/หมุน/กลับด้าน/พับ/พิมพ์ขนาดในตาราง (`refitLineShape`) ไปพร้อมชิ้น
- ใบแพทเทิร์น: เส้นทางผ้า + รอยบาก (ขีด 0.5 ซม. จากเส้นตัดเข้าใน · `notchSegments`) วาดเส้นทึบบาง · DXF layer `GRAIN` / `NOTCH` · SVG มีด้วย
- **รวมรูป** (แผงกลุ่ม · `lib/pattern-boolean.ts` เขียนเอง ไม่ใช้ไลบรารีภายนอก): รวม · ตัดออก (ชิ้นหลัก = P เลขน้อยสุด ถูกเจาะด้วยชิ้นอื่น · เจาะกลางชิ้น = ได้รู · ผ่ากลาง = แยกหลายชิ้น) · ส่วนทับ — ผลเก็บวัสดุ/เผื่อพับ/บรรทัดตีราคาของชิ้นหลัก · ชิ้นอื่นที่เลือกหายไป · โค้งกลายเป็นจุด · Ctrl+Z ย้อนได้ · วิธี: แตกขอบตรงจุดตัด → ดูท่อนใน/นอก/ทับขอบ → ต่อเป็นวง · เทสต์ `lib/__tests__/pattern-boolean.test.ts` (รวมสุ่ม 400 คู่ เช็กพื้นที่ลงตัว)
- **ไม้บรรทัดตามขอบ**: กดลากไปตามขอบทางที่ต้องการ (อ้อมทางยาวได้ · `outlineStep`/`outlineWalk`) ปล่อย = จบ · คลิก-คลิกยังได้
- เทสต์ `lib/__tests__/pattern-vector.test.ts`
