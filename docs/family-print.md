# ใบสั่งผลิตรวมทั้งรุ่น (ของ × สี)

ใบพิมพ์แผ่นเดียวที่รวม **ของที่ต้องซื้อ/เตรียม** และ **บล็อกตัด** ของทุกสี (SKU ลูก) ในรุ่นเดียวกัน (สินค้าแม่) — ทีมเช็กการซื้อ เตรียม และตัดของทั้งรุ่นได้จากกระดาษใบเดียว

## ใช้ทำอะไร / เมื่อไหร่
- รุ่นที่เปิดใบสั่งผลิตหลายสีพร้อมกัน (เช่น PIX25-01…06) → ฝ่ายซื้อดูว่าต้องซื้ออะไรเท่าไหร่ ฝ่ายตัดตัดบล็อกขนาดเดียวกันรวดเดียวทุกสี
- **ไม่ใช่** ใบสั่งงานที่ส่งให้ช่างประกอบ — ใบนั้นยังเป็นใบสั่งงานผลิตรายใบ (`/print/work-order/[id]`)

## หน้าตา
- หัวใบ: รูปรุ่น · รหัส/ชื่อสินค้าแม่ · จำนวนรวม · กำหนดส่งเร็วสุด · การ์ดทุกสี (รูป · รหัส · สี · จำนวน · เลขใบสั่งผลิต)
- **1) ของที่ต้องซื้อ / เตรียม** — คอลัมน์ = สี
  - ของชนิดเดียวกันแต่ต่างสี (ชื่อมีส่วนหน้าเหมือนกัน เช่น "พียูหนังเทียม M638") → แถวเดียว ช่องบอกรหัสย่อ + คำบอกสีของสีนั้น
  - ของที่ใช้ทุกสี/บางสี (รหัสเดียวกัน) → แถวละรหัส
  - คนละของจริง (เช่น รุ่นย่อย M ใช้หางซิป R ใช้หัวซิป) → แยกแถว ไม่รวม
  - ช่องเทา = ขอ/สั่ง/รับ/มีของ/เตรียมแล้ว (มีคำกำกับ พิมพ์ขาวดำก็อ่านได้) · `?` = BOM ยังไม่ใส่จำนวน · ลายขีด = สีนี้ไม่ใช้
  - คอลัมน์รวม: ยอดรวมทั้งรุ่น + "ต้องซื้อ X" ถ้ายังขาด
- **2) บล็อกตัด** — บล็อกขนาดเดียวกันทุกสีเป็นแถวเดียว จัดกลุ่มตามชนิดวัตถุดิบ · ช่องติ๊กทุกช่อง (ติ๊กทีละสีเมื่อตัดเสร็จ) · ตัดเสร็จในระบบแล้วขึ้น "ตัดแล้ว" · อะไหล่ไม่อยู่ในส่วนนี้
- กล่องลงชื่อ: ผู้ซื้อ/เตรียมของ · ผู้ตัด · ผู้ตรวจ (ของกลาง `lib/print-signoff`)

## ทางเข้า
| ที่ | ลิงก์ |
|---|---|
| หน้าพิมพ์ใบสั่งงานใบเดียว → ปุ่ม "พิมพ์รวมทั้งรุ่น" | `?mo=<id>` — ทุกใบที่ยังเปิดของรุ่นเดียวกัน |
| หน้าพิมพ์รวมหลายใบ → ปุ่ม "รวมทั้งรุ่น (ของ × สี)" | `?ids=<id>,<id>` — รุ่นละ 1 แผ่น |
| รายการใบสั่งผลิต → ติ๊กหลายใบ → "พิมพ์รวมทั้งรุ่น (ของ × สี)" | `?ids=…` |
| หัวกลุ่มสินค้าแม่บนบอร์ดจ่ายงาน (ยังไม่ได้ใส่) | `?parent=<รหัสสินค้าแม่>` |

สร้างลิงก์ด้วย `familyPrintUrl({ mo } | { ids } | { parent })` จาก `lib/family-print` เสมอ

## ตัวเลือกบนหน้าพิมพ์
ซื้อ + ตัด / เฉพาะซื้อ / เฉพาะตัด · เฉพาะที่ยังต้องซื้อ · กระดาษอัตโนมัติ (เกิน 4 สี = แนวนอน) / แนวนอน / แนวตั้ง
เส้นตาราง + ขนาดตัวอักษร ใช้ค่ากลางจาก "ตั้งค่าใบพิมพ์" ของใบสั่งงานผลิต (ui_config `wo_print_columns.style`)

## ไฟล์
- `lib/family-print.ts` — ของกลาง: จัดตาราง ของ × สี (`buildFamilySheet`) + HTML + เทมเพลต (ไม่ยิง DB · มีเทสต์ `lib/__tests__/family-print.test.ts`)
- `app/api/mo/family-print/route.ts` — โหลดข้อมูล (สิทธิ์ `products.view`) · สถานะซื้อใช้ `computeMatStatus` / `loadMoPurchaseLinks` (กติกาเดียวกับบอร์ดและหน้าขอซื้อ) · ต้องตัดไหมใช้ `needsCut`
- `app/print/work-order/family/page.tsx` — หน้าพิมพ์ (PrintFrame / buildReportHtmlMulti ของกลาง)

## สิทธิ์ / audit
อ่านอย่างเดียว ต้องมี `products.view` · ไม่มีการแก้ข้อมูล จึงไม่มี audit log

## ข้อจำกัดที่รู้
- สถานะซื้อนับ "ใบขอซื้อที่ผูกกับใบสั่งผลิตนั้น" — ใบขอซื้อที่ผูกไว้แค่สีเดียว (เช่น ห่วงกลม 300 ผูกกับสีดำ) อีกสีจะยังขึ้นว่าต้องซื้อ → ผูกใบขอซื้อกับทุกใบในรุ่น
- รูปวัตถุดิบ = รูปปก SKU วัตถุดิบ (ไม่มีใช้รูปสินค้าแม่ของวัตถุดิบ) — วัตถุดิบที่ยังไม่มีรูปเป็นกรอบเส้นประ
- บล็อกที่ไม่มีรหัสบล็อก จับคู่ข้ามสีด้วย ขนาด กว้าง × ยาว + ชิ้น/ใบ
- สีละหลายรหัสในชนิดเดียวกัน จับคู่ข้ามสีตามลำดับบรรทัดใน BOM — ถ้าแต่ละสีเรียง BOM ไม่เหมือนกัน แถวอาจสลับ

# ใบติดตามงานผลิต (แบบเขียนมือ) — แบบ A + D

ใบลงรายการต่อรุ่น ให้คนหน้างานเขียนตามสถานะงาน แล้วค่อยคีย์เข้าระบบ · เจ้าของเลือกแบบ A + D (2026-10-31)
**ตัวหนา = ข้อมูลที่ระบบรู้แล้ว** (ช่าง/โต๊ะ · วันจ่าย · จำนวน · ค่าแรง · วันรับ) · **เส้นประ = ช่องเขียน** · "ฟอร์มเปล่า" = เหลือแค่สี/เลขใบ/จำนวน

## แบบ A — ตารางเส้นทางงาน
แถวละใบจ่ายงาน จัดกลุ่มตามสี: เตรียม-ตัด → จ่ายงาน → ค่าแรง (เรต/ชิ้น + รวม) → รับงาน (ทุกรอบที่ส่งแล้ว + ช่องเขียนถ้ายังค้าง)
ใบที่ยังจ่ายไม่ครบ มีแถวว่าง "ยังไม่จ่าย X ชิ้น" ให้เขียนการจ่ายรอบต่อไป
ช่องเสริม (เลือกบนหน้าพิมพ์ · จำต่อเครื่อง): ดี/เสีย · รับหลายรอบ · ค้างกี่วัน/กำหนดส่ง · QC/เข้าคลัง · เบิก/คืนวัตถุดิบ · จ่ายเงินค่าแรงแล้ว · ลายเซ็นช่าง

## แบบ D — แยกตามสถานะ
พิมพ์เฉพาะงานที่ต้องทำต่อ 4 กลุ่ม (ใบเดียวอยู่ได้หลายกลุ่มถ้าจ่ายไปบางส่วน):
1. รอของ / เตรียม / ตัด — ยังไม่จ่ายงาน และเตรียม/ตัดยังไม่ครบ
2. รอจ่ายงาน — เตรียม/ตัดครบ (หรือแอดมินข้าม) แต่ยังมีจำนวนที่ไม่จ่าย
3. อยู่ที่ช่าง — ใบจ่ายงานที่ยังรับไม่ครบ + ค้างกี่วัน (เกิน 30 วันตัวแดง)
4. รับแล้ว — รอ QC / เข้าคลัง — ยังไม่ติ๊กเข้าคลังสินค้า

ขั้นเตรียม/ตัดใช้กติกาเดียวกับบอร์ด (`app/master/work-board/mo-steps`): มีสูตร = ติ๊กรายบรรทัดครบ · ไม่มีสูตร = ติ๊กระดับใบ · ข้ามขั้น (`lib/mo-skip`) = ข้าม

## กล่อง "ข้อมูลในระบบที่ควรเช็ก" (ทั้ง A และ D)
ใบจ่ายงานไม่มีวันที่จ่าย · รับงานก่อนวันจ่าย · จ่ายแล้วแต่ยังไม่ติ๊กเตรียม/ตัด · ไม่มีค่าแรงในระบบ · ค้างที่ช่างเกิน 30 วัน · รับครบแล้วแต่ใบยังเปิด/ยังไม่เข้าคลัง
(แค่แจ้ง ไม่แก้ข้อมูลเอง)

## ทางเข้า
`familyPrintUrl({ mo } | { ids } | { parent }, "track")` → `/print/work-order/family?…&sheet=track` (A + D) · `sheet=route` (A) · `sheet=status` (D)
ปุ่ม "ใบติดตามงานทั้งรุ่น" บนหน้าพิมพ์ใบเดียว · bulk action ในรายการใบสั่งผลิต · หรือเลือกแบบบนหน้าพิมพ์รวมทั้งรุ่น

## ไฟล์
- `lib/family-track.ts` — `buildFamilyTrack` · `trackBuckets` · `familyTrackHtmlData` · `TRACK_CSS` (เทสต์ `lib/__tests__/family-track.test.ts` ข้อมูลจริง TTM130)
- ข้อมูล: `/api/mo/family-print` แนบ `track` ต่อใบ (mo_work_orders + wo_submissions + qc_warehouse_items + ติ๊ก/ข้ามขั้น)

## ข้อจำกัด
- "จ่ายเงินค่าแรงแล้ว / งวด" ระบบยังไม่มีที่เก็บ — เป็นช่องเขียนอย่างเดียว
- ดี/เสียตอนรับจากช่าง ระบบยังไม่เก็บ (มีแค่ฝั่ง QC) — เป็นช่องเขียน

# ตั้งค่าใบรวมทั้งรุ่น (ค่ากลาง) — เจ้าของเลือก "ใช้ค่าแนะนำ" (2026-10-31)

ปุ่ม **"ตั้งค่าใบรวมทั้งรุ่น"** บนหน้าพิมพ์ → แผงลอยข้างเอกสาร ปรับแล้วเห็นผลทันที · **บันทึก** = มีผลกับทุกคน (สิทธิ์ products.edit · audit setting_change)
เก็บที่ ui_config key `family_print_settings` · ตัวเลือก/ค่าเริ่ม/อ่านค่าปลอดภัย = `FAMILY_SETTING_FIELDS` / `FAMILY_DEFAULT_SETTINGS` / `normalizeFamilySettings` ใน lib/family-print · แผง = `components/family-print-settings`

| ตั้งค่า | ค่าแนะนำ | ตัวเลือก |
|---|---|---|
| วิธีรวมแถว | อัตโนมัติ | แบบเดิม (เข้ม) · ไม่รวม (แถวละรหัส) |
| จัดหมวด | ตามชนิดวัตถุดิบ | ต่างสี / ใช้ทุกสี |
| ในช่อง | ตัวเลข + รหัสย่อ | ตัวเลขอย่างเดียว · + รหัส + สี |
| ช่องที่ไม่ใช้ | ว่าง | ขีด – · ลายขีด |
| ช่องติ๊ก | หน้าตัวเลข | ท้ายแถว |
| รูปวัตถุดิบ | ซ่อนกรอบว่าง | แสดงทุกช่อง · ไม่มีคอลัมน์รูป |
| บาร์โค้ดเลขใบ | เส้น + QR | เส้น · QR · ไม่แสดง |

## วิธีรวมเป็นแถวเดียว (เจ้าของถาม "รวมจากอะไร")
รวมหลายรหัสเป็นแถว "ต่างสี" เมื่อครบ 3 ข้อ: **ชนิดวัตถุดิบเดียวกัน** (skus_v2 กลุ่มวัตถุดิบ) + **หน่วยเดียวกัน** + **ชื่อขึ้นต้นเหมือนกัน** · จับคู่ข้ามสีตามลำดับบรรทัดใน BOM
- "อัตโนมัติ" รองรับภาษาไทยที่ไม่เว้นวรรค ("ผ้าซับใน FLYNOW…" + "ผ้าซับในตัวบาง…" → "ผ้าซับใน") แต่ไม่ตัดกลางรหัส และตัด "สี" ที่ห้อยท้าย
- ตัวที่ชื่อแปลกแยก (เช่น ชื่อเป็นรหัสล้วน) แยกออกไปแถวเดียว ไม่ทำให้ทั้งแถวแตก (`clusterByName`)
- ชนิดวัตถุดิบว่าง → หมวด "อื่น ๆ (ยังไม่ได้ตั้งชนิดวัตถุดิบ)" · หน่วยไม่ตรง → แยกแถว (รวมยอดข้ามหน่วยไม่ได้)
- บล็อกตัด: ช่องกว้าง/ยาวว่าง = 0 (บางบรรทัด BOM ว่าง บางบรรทัดใส่ 0 — ขนาดเดียวกันอยู่แถวเดียว)

## หน้าตาที่เปลี่ยนตาม feedback
- การ์ดสี + ใบติดตามงาน: **เลขใบเต็ม** MO-YYYY-NNNNN + บาร์โค้ดเส้น (Code128 · `woBarcodeHtml`) + QR (`woQrHtml(scanUrl)`) — สร้างในเบราว์เซอร์ครั้งเดียวต่อการโหลด
  บาร์โค้ดเส้นกว้าง ~6 ซม. → การ์ดแถวละ 3 สี (ไม่มีเส้น = แถวละ 6)
- บล็อกตัด: **ขนาดตัวใหญ่** · รหัสบล็อก + วัตถุดิบตัวเล็กบรรทัดล่าง
- ใบติดตามงาน A: **ไม่มีแถวหัวสี** — ช่องแรก "สี" (รูปใหญ่ + รหัส + สี) คร่อมทุกแถวของสีนั้น · ช่อง "ใบสั่งผลิต" = เลขใบเต็ม + บาร์โค้ด

# ตรวจข้อมูล + แก้จากหน้าพิมพ์ (แบบ A + B) — 2026-10-31

**ปัญหาเดิม:** ค่าวัตถุดิบถูกคัดลอกไว้ 3 ชั้น ข้อมูลวัตถุดิบ (skus_v2) → บรรทัดสูตร (bom_lines) → ใบสั่งผลิต (mo_material_summary / mo_materials) — แก้ชั้นเดียว ใบพิมพ์ไม่เปลี่ยน

- **A แผง "ตรวจข้อมูล (n)"** บนหน้าพิมพ์ (`components/family-data-check`) — การ์ดต่อจุด + ช่องแก้ด่วน (ค่าแนะนำเติมไว้) + ติ๊กชั้นที่จะแก้ + ปุ่มเปิดตัวแก้เต็ม (drawer SKU กลาง / ป๊อป BOM กลาง)
- **B กรอบเหลือง + ปุ่ม "แก้" บนเอกสาร** — กดแล้วแผงเปิดที่การ์ดนั้น · เฉพาะพรีวิวบนจอ (ไฟล์ที่พิมพ์/บันทึก PDF ไม่มีธง)
- ตัวตรวจ (`lib/family-checks` · ไม่ยิง DB): หน่วยไม่ตรงกับของชนิดเดียวกันที่ชื่อคล้ายกัน/ชื่อเป็นรหัส · ไม่มีชนิด (แนะนำจากชื่อ) · ชื่อเป็นรหัสล้วน (แนะนำชื่อจากตัวอื่น + สีในข้อมูลวัตถุดิบ) · ชื่อสีสินค้าซ้ำ (แนะนำจากสีวัตถุดิบหลัก) · BOM ใส่จำนวน 0 (1 การ์ดต่อสูตร + ปุ่ม "อัปเดตใบตามสูตร")
- บันทึก: `POST /api/mo/family-print/fix` — `dry_run` ก่อน (กล่องยืนยันบอกว่าจะแก้อะไรกี่แถว + เตือนถ้ารหัสเคยมีสต๊อก/ใบขอซื้อ) → แก้จริง
  - ชั้นใบสั่งผลิตแก้เฉพาะ หน่วย/ชื่อ/ชนิด — **ไม่กางสูตรใหม่** ติ๊กเตรียม/ตัด จำนวน ใบขอซื้อ ไม่ถูกแตะ
  - หน่วย/ชนิด ต้องมีอยู่จริงในระบบ (ไม่สร้างใหม่) · สิทธิ์ products.edit · audit `update` skus_v2 (ค่าเดิม → ใหม่ + ชั้นที่แก้)
- "อัปเดตใบตามสูตร" = `PATCH /api/mo/[id] {reexplode, preserve}` ตัวเดิมของหน้าใบสั่งผลิต — ใช้ตอนสูตรแก้แล้วแต่ใบเก่ายังถือสำเนาเดิม (เช่น CTL104 ใบ 00035–00040 จำนวน 0 แต่ใบ 00212 มีจำนวนแล้ว)

## ขนาดแต่ละจุด + คอลัมน์ใบติดตามงาน (2026-10-31)
อยู่ในแผง "ตั้งค่าใบรวมทั้งรุ่น" (ค่ากลางเดียวกัน `family_print_settings`) · ปรับแล้วเห็นผลบนเอกสารทันที · บันทึกต้อง products.edit

- **ขนาดแต่ละจุด** (`sizes` · `FAMILY_SIZE_FIELDS` / `FAMILY_SIZE_PRESETS` / `familySizeCss`): หัวใบ (รูป · รหัส · จำนวนรวม) · การ์ดสี (ต่อแถว 0=อัตโนมัติ · รูปสี · เลขใบ · บาร์โค้ดสูง · QR) · ตารางของที่ต้องซื้อ (รูปหัวคอลัมน์ · รูปวัตถุดิบ · ชื่อ · ตัวเลข · รหัส/สี · ช่องติ๊ก · ระยะในช่อง) · บล็อกตัด (ขนาดตัด · รหัสบล็อก) · ขอบกระดาษ
  - ชุดสำเร็จ: ประหยัดกระดาษ / ปกติ / ตัวใหญ่ อ่านง่าย · ค่าเริ่ม = ไม่ปล่อย CSS เพิ่ม (หน้าตาเดิม) · ใช้ค่าเดียวกันบนจอและตอนพิมพ์
  - บาร์โค้ดเส้นปรับได้แค่ความสูง (กว้าง ~55 มม. ตายตัว) · รูป 0 = ซ่อน · คอลัมน์รูปวัตถุดิบกว้างตามขนาดรูป (`imgColW`)
- **คอลัมน์ใบติดตามงาน แบบ A** (`track_cols` · `trackDefaultCols` / `normalizeTrackCols` ใน lib/family-track): ลำดับ (ลาก) · ชื่อหัว · ความกว้าง · เปิด/ปิดช่องหลัก — ใช้ `ColumnRows` ของกลางจาก components/wo-print-columns
  - ช่องเสริม (ดี/เสีย · ค้าง · QC · เบิก · จ่ายเงิน · ลงชื่อ) ยังเปิด/ปิดที่ปุ่มบนแถบ (จำต่อเครื่อง) — แผงคุมแค่ลำดับ/ชื่อ/ความกว้าง
  - ค่าเริ่ม (null) = ลำดับ/ความกว้างเดิม · ช่องเลขใบกว้างตามบาร์โค้ด (เส้น+QR 86 · เส้น 66 · QR 36 · ไม่มี 28) · ปิดหมด = กลับค่าเริ่ม
  - แถวสร้างช่องตามคีย์แล้ววางตามลำดับที่ตั้ง · ช่องคร่อมหลายแถว (สี · เลขใบ · เตรียม-ตัด · เบิก) อยู่แถวแรก

# พิมพ์หลายแผ่นทีเดียว + แยกเตรียม/ตัด + เส้นตาราง (2026-10-31)

- **เลือกแผ่นที่จะพิมพ์** บนแถบหน้าพิมพ์: เตรียม / ซื้อ · ตัด · ติดตามงาน A · ตามสถานะ D (ติ๊กรวมกันได้ → พิมพ์ทีเดียว) · จำที่เลือกไว้ต่อเครื่อง
  - เตรียม + ตัด: **แผ่นเดียว** หรือ **แยกคนละแผ่น** (ส่งคนละแผนก) — แยกแล้วแต่ละแผ่นมีกล่องลงชื่อของตัวเอง (ผู้ซื้อ/เตรียม · ผู้ตัด) + ผู้ตรวจ
  - ลิงก์ `?sheet=` เดิมยังใช้ได้ + `all` = เตรียม+ตัด+ติดตามงาน A
- **หัวกำกับทุกแผ่น**: ชื่อใบ (ใบสั่งผลิตรวมทั้งรุ่น / ใบเตรียมของ / ใบตัด / ใบติดตามงานผลิต / ใบงานตามสถานะ) + ป้าย "แผ่น x/y" (นับต่อรุ่น) + รูปรุ่น + การ์ดสี
- **เส้นตาราง** ("ตั้งค่าใบรวมทั้งรุ่น" → เส้นตาราง): ความหนา บางมาก–หนามาก · สี จางมาก–เข้ม · แบบ ตาราง / เส้นนอน / ไม่มีเส้น
  ใช้กับตาราง + กรอบหัวใบ + การ์ดสี ทุกแผ่น · ค่าเริ่มบางลง (0.08 มม. สีอ่อนมาก) — เดิมกรอบหัวใบดำ 0.25 มม. ดูหนัก
  ไม่ผูกกับเส้นของใบสั่งงานอีกต่อไป (ใบรวมทั้งรุ่นตั้งของตัวเอง) · `familyLineCss` / `normalizeFamilyLine` ใน lib/family-print
