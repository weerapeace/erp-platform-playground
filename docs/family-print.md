# ใบสั่งผลิตรวมทั้งรุ่น (ของ × สี)

ใบพิมพ์แผ่นเดียวที่รวม **ของที่ต้องซื้อ/เตรียม** และ **บล็อกตัด** ของทุกสี (SKU ลูก) ในรุ่นเดียวกัน (สินค้าแม่) — ทีมเช็กการซื้อ เตรียม และตัดของทั้งรุ่นได้จากกระดาษใบเดียว

## ใช้ทำอะไร / เมื่อไหร่
- รุ่นที่เปิดใบสั่งผลิตหลายสีพร้อมกัน (เช่น PIX25-01…06) → ฝ่ายซื้อดูว่าต้องซื้ออะไรเท่าไหร่ ฝ่ายตัดตัดบล็อกขนาดเดียวกันรวดเดียวทุกสี
- **ไม่ใช่** ใบสั่งงานที่ส่งให้ช่างประกอบ — ใบนั้นยังเป็นใบสั่งงานผลิตรายใบ (`/print/work-order/[id]`)

## หน้าตา
- หัวใบ: รูปรุ่น · รหัส/ชื่อสินค้าแม่ · จำนวนรวม · กำหนดส่งเร็วสุด · การ์ดทุกสี (รูป · รหัส · สี · จำนวน · เลขใบสั่งผลิต)
- **1) ของที่ต้องซื้อ / เตรียม** — คอลัมน์ = สี
  - ของชนิดเดียวกันแต่ต่างสี (ชื่อมีส่วนหน้าเหมือนกัน เช่น "พียูหนังเทียม M638") → แถวเดียว ช่องบอกรหัสย่อ + คำบอกสีของสีนั้น
  - ของที่ใช้ทุกสี/บางสี (รหัสเดียวกัน) → แถวละรหัส
  - คนละของจริง (เช่น รุ่นย่อย M ใช้หางซิป R ใช้หัวซิป) → แยกแถว ไม่รวม
  - ช่องเทา = ขอ/สั่ง/รับ/มีของ/เตรียมแล้ว (มีคำกำกับ พิมพ์ขาวดำก็อ่านได้) · `?` = BOM ยังไม่ใส่จำนวน · ลายขีด = สีนี้ไม่ใช้
  - คอลัมน์รวม: ยอดรวมทั้งรุ่น + "ต้องซื้อ X" ถ้ายังขาด
- **2) บล็อกตัด** — บล็อกขนาดเดียวกันทุกสีเป็นแถวเดียว จัดกลุ่มตามชนิดวัตถุดิบ · ช่องติ๊กทุกช่อง (ติ๊กทีละสีเมื่อตัดเสร็จ) · ตัดเสร็จในระบบแล้วขึ้น "ตัดแล้ว" · อะไหล่ไม่อยู่ในส่วนนี้
- กล่องลงชื่อ: ผู้ซื้อ/เตรียมของ · ผู้ตัด · ผู้ตรวจ (ของกลาง `lib/print-signoff`)

## ทางเข้า
| ที่ | ลิงก์ |
|---|---|
| หน้าพิมพ์ใบสั่งงานใบเดียว → ปุ่ม "พิมพ์รวมทั้งรุ่น" | `?mo=<id>` — ทุกใบที่ยังเปิดของรุ่นเดียวกัน |
| หน้าพิมพ์รวมหลายใบ → ปุ่ม "รวมทั้งรุ่น (ของ × สี)" | `?ids=<id>,<id>` — รุ่นละ 1 แผ่น |
| รายการใบสั่งผลิต → ติ๊กหลายใบ → "พิมพ์รวมทั้งรุ่น (ของ × สี)" | `?ids=…` |
| หัวกลุ่มสินค้าแม่บนบอร์ดจ่ายงาน (ยังไม่ได้ใส่) | `?parent=<รหัสสินค้าแม่>` |

สร้างลิงก์ด้วย `familyPrintUrl({ mo } | { ids } | { parent })` จาก `lib/family-print` เสมอ

## ตัวเลือกบนหน้าพิมพ์
ซื้อ + ตัด / เฉพาะซื้อ / เฉพาะตัด · เฉพาะที่ยังต้องซื้อ · กระดาษอัตโนมัติ (เกิน 4 สี = แนวนอน) / แนวนอน / แนวตั้ง
เส้นตาราง + ขนาดตัวอักษร ใช้ค่ากลางจาก "ตั้งค่าใบพิมพ์" ของใบสั่งงานผลิต (ui_config `wo_print_columns.style`)

## ไฟล์
- `lib/family-print.ts` — ของกลาง: จัดตาราง ของ × สี (`buildFamilySheet`) + HTML + เทมเพลต (ไม่ยิง DB · มีเทสต์ `lib/__tests__/family-print.test.ts`)
- `app/api/mo/family-print/route.ts` — โหลดข้อมูล (สิทธิ์ `products.view`) · สถานะซื้อใช้ `computeMatStatus` / `loadMoPurchaseLinks` (กติกาเดียวกับบอร์ดและหน้าขอซื้อ) · ต้องตัดไหมใช้ `needsCut`
- `app/print/work-order/family/page.tsx` — หน้าพิมพ์ (PrintFrame / buildReportHtmlMulti ของกลาง)

## สิทธิ์ / audit
อ่านอย่างเดียว ต้องมี `products.view` · ไม่มีการแก้ข้อมูล จึงไม่มี audit log

## ข้อจำกัดที่รู้
- สถานะซื้อนับ "ใบขอซื้อที่ผูกกับใบสั่งผลิตนั้น" — ใบขอซื้อที่ผูกไว้แค่สีเดียว (เช่น ห่วงกลม 300 ผูกกับสีดำ) อีกสีจะยังขึ้นว่าต้องซื้อ → ผูกใบขอซื้อกับทุกใบในรุ่น
- รูปวัตถุดิบ = รูปปก SKU วัตถุดิบ (ไม่มีใช้รูปสินค้าแม่ของวัตถุดิบ) — วัตถุดิบที่ยังไม่มีรูปเป็นกรอบเส้นประ
- บล็อกที่ไม่มีรหัสบล็อก จับคู่ข้ามสีด้วย ขนาด กว้าง × ยาว + ชิ้น/ใบ
- สีละหลายรหัสในชนิดเดียวกัน จับคู่ข้ามสีตามลำดับบรรทัดใน BOM — ถ้าแต่ละสีเรียง BOM ไม่เหมือนกัน แถวอาจสลับ
