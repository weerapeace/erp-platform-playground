# 🆕 มาใหม่เป็นชุด (New Drops)

ตั้งเวลาปล่อยสินค้าใหม่เป็น "ชุด" — หน้าเว็บร้าน `/new` โชว์ชุดล่าสุด + ชุดก่อน ๆ + "เร็ว ๆ นี้" นับถอยหลัง

## ใช้ทำอะไร

- ร้านอยากปล่อยสินค้าใหม่พร้อมกันตามเวลา (Drop) และมีหน้า "มาใหม่" ให้ลิงก์จากเมนูได้
- ตั้งได้ที่ ERP → จัดการเว็บร้าน → แท็บ **🆕 มาใหม่**

## 1 ชุดมีอะไร

| ช่อง | ความหมาย |
|---|---|
| ชื่อชุด / คำโปรย | 2 ภาษา (ไทย + อังกฤษ ผ่าน RecordLangBar / BilingualText) |
| เวลาเปิด | ก่อนเวลานี้ = "เร็ว ๆ นี้" (รูปปก + นับถอยหลัง · ไม่ส่งรายการสินค้า) |
| หมดช่วงใหม่ | หลังเวลานี้ป้าย "ใหม่" หาย ชุดไปอยู่ "ชุดก่อนหน้า" · ไม่ตั้ง = ไม่หมด (ค่าเริ่ม 30 วัน) |
| ซ่อนสินค้าจนเปิด | ติ๊ก = สินค้าในชุดหายจากทั้งเว็บ (รวม/ค้นหา/หน้าสินค้า/สั่งซื้อ) จนถึงเวลาเปิด |
| สินค้า | รหัสรุ่นจาก "สินค้าบนเว็บ" สูงสุด 60 |
| รูปปก | คอม 16:9 + มือถือ 4:5 (ไม่ใส่มือถือ = ใช้รูปคอม) |

## หน้า /new (storefront `src/app/new/page.tsx`)

1. ชุดล่าสุดที่เปิดแล้ว → แบนเนอร์ใหญ่ + สินค้า
2. ⏳ เร็ว ๆ นี้ → การ์ด + `DropCountdown` (ถึงเวลา = refresh เอง ทุก 20 วิ จนชุดขึ้น)
3. ไม่มีชุดเปิด → "เข้าใหม่ล่าสุด" (24 ตัวที่ขึ้นร้านล่าสุด) — ไม่มีหน้าว่าง
4. ชุดก่อนหน้า

## ของกลางที่เกี่ยวข้อง

- `lib/website-new-drops.ts` (pure · mirror ไป storefront `src/lib/new-drops.ts`) — `dropStatus`, `orderDrops`, `hiddenDropCodes`, `liveDropByCode`, `normalizeDropInput`
- ตาราง `store_new_drops` (RLS เปิด ไม่มี policy → อ่าน/เขียนผ่าน API ฝั่งเซิร์ฟเวอร์เท่านั้น)
- API จัดการ `app/api/website/new-drops` (guardApi products.view / products.edit · writeAudit `store_new_drop`)
- API สาธารณะ `app/api/public/storefront/new-drops?shop=` (upcoming ไม่มี codes)
- API สินค้าสาธารณะ: ข้ามสินค้าที่ถูกซ่อน + ใส่ `newDrop {id,startAt,endAt}` ให้สินค้าในชุดที่เปิดอยู่
- `lib/website-orders.ts`: กันสั่งซื้อสินค้าที่ยังซ่อนอยู่
- Section สินค้า แหล่ง **"🆕 ชุดมาใหม่"** (`source: "newdrop"`) — ใส่หน้าแรกได้ · ไม่มีชุดเปิด = สินค้าขึ้นร้านล่าสุด
- ป้าย "ใหม่" บนการ์ด = ใช้ป้ายเดิมของการ์ดสินค้า (สี/ข้อความเดียวกัน) + สินค้าในชุดที่เปิดอยู่
- ลิงก์ `/new` อยู่ในรายการหน้า (website-links) + แม่แบบเมนู "มาใหม่"

## ข้อจำกัด

- เว็บร้านแคช ~1 นาที → ชุดเปิดช้าสุด ~1 นาทีหลังเวลาที่ตั้ง
- สินค้าที่อยู่ในชุดที่เปิดแล้วชุดอื่น จะไม่ถูกซ่อน (เปิดแล้วถือว่าปล่อยแล้ว)
- หน้า /new ดึงสูงสุด: ชุดเร็ว ๆ นี้ 6 · ชุดที่เปิดแล้ว 12
