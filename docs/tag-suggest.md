# ระบบช่วยเดาแท็ก (TagSuggestModal)

> เจ้าของเลือก 2026-11-15 · หน้า Tags Manager (`/master/tags-manager`) ปุ่ม "ระบบช่วยเดาแท็ก"

## ใช้ทำอะไร

เดาแท็กให้สินค้าที่ยังไม่มีแท็ก แล้วให้คนยืนยันทีละกลุ่ม ไม่ต้องไล่ทีละตัว ระบบเสนออย่างเดียว ไม่บันทึกเองจนกว่าจะมีคนกด
ไม่ใช้ AI จึงไม่มีค่าใช้จ่าย

| ระดับ | ความหมาย | กดยังไง |
|---|---|---|
| แน่นอน | ก๊อปจากข้อมูลที่มีอยู่แล้ว (ช่องแบรนด์ / หมวดหมู่ของ Parent) | "ใส่ทั้งกลุ่ม" แล้วกด ✗ ตัวที่ไม่ใช่ได้ |
| มั่นใจสูง | รหัสนำหน้าหรือคำในชื่อชัด (ZIP → ซิป, LEA → หนัง, พียู → PU, หัวเข็มขัด → อะไหล่) | เหมือนข้างบน |
| ควรเช็ก | คำที่อาจพลาด (ผ้า, สาย/เทป, ตัวเสริม) | ติ๊กทีละตัว |
| ต้องสร้างแท็กก่อน | ยังไม่มีแท็กชื่อนี้ (ด้าย, บรรจุภัณฑ์, อุปกรณ์, โลโก้) | สร้างแท็กในคลังแท็กแล้วกด "โหลดใหม่" |

## ใครถูกเดา

- **SKU**: แบรนด์จาก Parent (เฉพาะตัวที่ยังไม่มีแท็กกลุ่ม Brands) · ชนิดวัตถุดิบจากรหัส/ชื่อ (เฉพาะตัวที่ยังไม่มีแท็กกลุ่ม วัตถุดิบ / หมวดหมู่สินค้า) · ชื่อ SKU ว่าง = ใช้ชื่อ Parent
- **Parent SKU**: หมวดหมู่ และแบรนด์ จากช่องของ Parent เอง (เฉพาะตัวที่ยังไม่มีแท็กกลุ่มนั้น)
- แบรนด์/หมวดที่ยังไม่มีแท็กชื่อเดียวกัน → ป๊อปบอกว่า "ยังไม่มีแท็กชื่อนี้" พร้อมจำนวน

## ความปลอดภัยตอนบันทึก

- เซิร์ฟเวอร์คำนวณใหม่ทุกครั้ง ไม่เชื่อรายการจากหน้าเว็บ (ส่งแค่ "กลุ่มไหน + ตัวที่กด ✗ / ตัวที่ติ๊ก")
- กลุ่ม "ควรเช็ก" ใส่ได้เฉพาะตัวที่ติ๊ก · กลุ่ม "ต้องสร้างแท็กก่อน" ใส่ไม่ได้
- เคารพกลุ่ม "เลือกได้ 1" (วัตถุดิบ) · ไม่ลบแท็กเดิม · trigger roll-up ใส่แท็กแม่ให้เอง
- ใส่ตั้งแต่ 1,000 รายการ ต้องพิมพ์ "ยืนยัน" ก่อน
- audit log 1 แถวต่อการกดบันทึก (`action = bulk_tag`, `metadata.from = tag_suggest`, จำนวนต่อกลุ่ม)
- สิทธิ์: ดู `products.view` · บันทึก `products.edit`

## ไฟล์

- กฎ (pure + เทสต์): `lib/tag-suggest-rules.ts` · `lib/__tests__/tag-suggest-rules.test.ts`
- API: `app/api/product-tags/suggest/route.ts` (GET เดา · POST บันทึก)
- ป๊อป: `components/tag-suggest/index.tsx`

## เพิ่ม / แก้กฎ

- คำ → แท็ก: แก้ `MATERIAL_RULES` (ตัวแรกที่ตรงชนะ เรียงจากเจาะจงไปกว้าง) แล้วเพิ่มตัวอย่างจริงในเทสต์
- คำอะไหล่: แก้ที่ `lib/design-library-hwtags.ts` (`HW_TAG_RULES`) ที่เดียว ใช้ร่วมกับป๊อปแท็กย่อยอะไหล่ของ Design Library · คำเพิ่มเฉพาะระบบนี้อยู่ใน `HW_EXTRA`
- หมวดที่สะกดต่างจากชื่อแท็ก: `CATEGORY_TAG_ALIASES` (เช่น Jelwery → จิวเวลรี)
- หัวซิป/ของที่มีคำ "ซิป" = แท็ก "ซิป" ไม่ใช่อะไหล่ (ตามข้อมูลเดิม)

## กับดักที่เจอในข้อมูลจริง

- "หนังยาง" ไม่ใช่หนัง · "ผ้าใบ…ด้ายขาว" ไม่ใช่ด้าย · "กรรไกรตัดด้าย" / "ถุงห่อด้าย" ไม่ใช่ด้าย
- "ก้นกระเป๋า" / "หัวเข็มขัด" เป็นอะไหล่ ไม่ใช่สินค้าสำเร็จ
- แท็กแบรนด์ไม่ได้แปลว่าเป็นสินค้าสำเร็จแล้ว (IG International ใส่ให้วัตถุดิบด้วย)

## ยังไม่ทำ

- ตั้งกฎคำ → แท็ก เองผ่านหน้าเว็บ (ต้องเพิ่มตารางเก็บกฎ ขออนุญาตเจ้าของก่อน)
- ใช้ AI เดาตัวที่กฎเดาไม่ได้ (ต้องลงทะเบียนศูนย์ AI/API `lib/paid-services`)
- ✗ ได้เฉพาะ 200 ตัวแรกที่แสดงต่อกลุ่ม (เรียงตามรหัส)
