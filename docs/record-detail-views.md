# 🧩 หน้าดูรายละเอียดเฉพาะโมดูล (Record Detail Views)

จุดเสียบของกลางในกล่องดูข้อมูล (MasterCRUD drawer / `MasterRecordDrawer`) — ให้โมดูลที่ต้องการ "ภาพรวมในหน้าเดียว" มีหน้าดูที่ออกแบบเอง
โดยไม่ต้องสร้าง drawer / popup / ฟอร์มใหม่

## ใช้ทำอะไร

- แทน **แถบสลับภาษา + แท็บฟิลด์มาตรฐาน** เฉพาะตอน **"ดู" ระเบียนที่บันทึกแล้ว**
- ของที่ยังเป็นของกลางเหมือนเดิม: หัวกล่อง (ชื่อโมดูล · 🎨 ออกแบบฟิลด์ · ✕) · แถบล่าง (◀ ก่อนหน้า / ถัดไป ▶ · 🗑 ลบ · ปิด · ✎ แก้ไข) · ฟอร์มแก้ไขเต็ม · ฟอร์มสร้างใหม่ · ถามก่อนปิดเมื่อมีของค้าง
- ได้ทุกทางที่เปิดโมดูลนั้น (หน้าตาราง `/m/<module>` · drawer ซ้อนจากป๊อปอื่น) เพราะเลือกตาม `moduleKey`

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่

- ✅ โมดูลฟิลด์น้อย แต่ต้องเห็นสถานะสำคัญทันที (เช่น วัสดุ: ขึ้นลิงก์บนเว็บแล้วหรือยัง · ไทยคู่อังกฤษ)
- ❌ แค่อยากจัดลำดับ / ซ่อน / ย้ายแท็บฟิลด์ → ใช้ **🎨 ออกแบบฟิลด์ (Studio)** แทน
- ❌ ห้ามเขียนบันทึกเอง (fetch ตรง) — บันทึกผ่าน `ctx.save` เท่านั้น

## วิธีเพิ่มโมดูล

1. ทำหน้าดูที่รับ `ctx: DetailViewCtx` (type อยู่ใน `components/master-crud`)
2. ลงทะเบียนใน `components/record-detail-views.tsx` แบบ `next/dynamic` (โค้ดหน้าดูไม่ถ่วงโมดูลอื่น)
3. หรือส่ง `config.detailView` ตรง ๆ ใน config ของหน้า (มาก่อนทะเบียน)

```tsx
// components/record-detail-views.tsx
export const RECORD_DETAIL_VIEWS = {
  product_materials: (ctx) => <MaterialDetailView ctx={ctx} />,
};
```

## ctx ที่ได้

| ค่า | ความหมาย |
| --- | --- |
| `recordId` · `values` | รหัส + ค่าปัจจุบันของระเบียน (อัปเดตทันทีหลังบันทึก) |
| `fields` | ทะเบียนฟิลด์ของโมดูล (ป้าย/คำอธิบาย) |
| `canEdit` | มีสิทธิ์แก้ไหม (ซ่อนปุ่มแก้ถ้าไม่มี) |
| `loading` | กำลังโหลดค่าเต็มตอนเปิด/เลื่อนรายการ |
| `save(patch)` | บันทึกหลายช่องครั้งเดียว → `null` = สำเร็จ / ข้อความผิดพลาด · ค่าในหน้าเปลี่ยนตามที่ระบบบันทึกจริง |
| `edit()` | เปิดฟอร์มแก้ไขเต็มของกลาง |
| `uploadFolder` | โฟลเดอร์อัปโหลดรูป (ใช้กับ `ImageInput`) |

## สิทธิ์ / ประวัติ (audit)

- `ctx.save` = `PATCH /api/master-v2/<module>/<id>` → ด่านสิทธิ์ `products.edit` + สิทธิ์ระดับฟิลด์ + ฟิลด์บังคับ + **audit_logs** ที่ API (เหมือนแก้ในฟอร์มกลาง)
- หน้าดูที่มีกล่องแก้ค้าง ควรฝากปุ่มบันทึกไว้ที่แถบล่างด้วย `useFooterSave` → ปิดกล่องจะถามก่อน

## ข้อจำกัด

- ใช้เฉพาะโหมด "ดู" — สร้างใหม่/แก้ไขเต็ม ยังเป็นฟอร์มกลาง
- ข้อมูลที่เกี่ยวข้อง (360) อัตโนมัติ + `recordSections` ยังต่อท้ายตามเดิม
