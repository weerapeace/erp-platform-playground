# แท็บ "💰 ราคา" ของ Parent SKU

เจ้าของขอ 2026-11-11: ตารางราคาซื้อ+ขาย · ขายมีทุก Platform + ราคากลาง · ปรับทั้งหมดทีเดียว · เตือนถ้าราคาไม่เท่ากัน (ปิดได้) · ต้นทุน/ค่าแรง/ค่ารายการอื่น ๆ (เปิด-ปิดโชว์ได้)

## ไฟล์
- หน้าจอ `components/parent-price-tab.tsx` · ผูกใน `parent-sku-extra-tabs.tsx` (key `prices`, `after: "content"` = ต่อจาก "รายละเอียด Platform" ถ้าตัวออกแบบหน้ายังไม่ได้วาง)
- ข้อมูล `GET /api/parent-skus/[id]/prices` (products.view · ต้นทุนส่งเฉพาะคนมีสิทธิ์ `products.cost.view`)
- กฎ `lib/parent-prices.ts` (+เทสต์) · ต้นทุนวัตถุดิบ = ของกลาง `lib/cost-inputs.ts` (ใช้ร่วมกับเครื่องคิดต้นทุน) · ต้นทุนเต็ม/กำไร = `deriveCost` (lib/cost-calc)

## ราคาขาย
| คอลัมน์ | มาจาก | แก้ที่ไหน |
|---|---|---|
| ราคากลาง | `skus_v2.list_price` | ในตาราง (ออกจากช่อง = บันทึก) หรือ "ปรับราคากลางทั้งรุ่น" (ถามก่อน) |
| ราคาเต็ม | `skus_v2.fake_price` | ในตาราง |
| เว็บร้าน (ต่อร้าน) | `store_listings.web_price` (ว่าง = ตามราคากลาง) | แท็บ "เว็บไซต์" |
| ร้านแพลตฟอร์ม (ต่อรายการ) | ข้อมูลที่ดึงจากร้านล่าสุด (`loadListingVariants` — LINE/Lazada ต่อตัวเลือก · ร้านอื่น = ราคาเดียวของรายการ) | LINE: "ส่งราคากลาง ↑" (ถามก่อน — แตะร้านจริง) · ทุกร้าน: "แก้บนร้าน" (ListingDrawer) |

- ราคาบนร้าน = ราคาที่ลูกค้าจ่าย (ราคาลดถ้ามี) · ต่างจากราคากลาง ≥ ฿1 = ช่องเหลือง + แถบสรุป · ปิดเตือนได้ (จำต่อคน `parent_price_tab`)
- **ราคาบนร้านไม่เปลี่ยนตามราคากลางเอง** (ตั้งใจ — กันส่งราคาผิดขึ้นร้านโดยไม่รู้ตัว) ต้องกดส่ง/แก้บนร้าน

## ต้นทุน / กำไร (เฉพาะคนมีสิทธิ์ดูต้นทุน)
ราคาซื้อ (กด = SkuPriceModal ร้าน/ราคาซื้อ) · วัตถุดิบ (ตามสูตรหลัก → ล่าสุด · "ขาดราคา N" = วัตถุดิบที่ยังไม่มีราคา) · ค่าแรง · ค่าอื่น ๆ · ต้นทุนรวม · กำไร/ชิ้น · %
- ใช้ต้นทุนที่บันทึกไว้ในเครื่องคิดต้นทุน: เฉพาะสี → ทั้งรุ่น → ค่าตั้งต้น (ค่าแรงกลาง + งานเหมาในสูตร) · ไม่มีสูตร = ต้นทุน = ราคาซื้อ
- เปิด/ปิดคอลัมน์ได้ (จำต่อคน)

## ข้อจำกัด
- ราคาร้านมาจากข้อมูลที่ดึงล่าสุด ไม่ยิงร้านสด (กดรีเฟรช/ดึงใหม่ที่หน้าสินค้าบนแพลตฟอร์ม)
- Shopee/TikTok ยังไม่มีราคาต่อตัวเลือก (ไฟล์) · ส่งราคาอัตโนมัติมีแค่ LINE

## เพิ่ม 2026-11-11 (รอบ 2)
- **Shopee ราคาต่อสี**: อ่านจากไฟล์ "ราคา/สต๊อก" (mass_update_sales_info) ที่นำเข้าหน้าสินค้าบนแพลตฟอร์ม → `raw.sales_info.variations` (`shopVariantsOf("shopee")`) · ยังไม่มี API (ไม่มีราคาโปรโมชัน) · TikTok รอระบบเชื่อมร้าน
- **ค่าธรรมเนียมร้าน**: ui_config `platform_fee_rates` = `{ rates: { <platform_code>: { pct, fixed } } }` (website = เว็บร้าน) · ตั้งที่ปุ่ม "⚙ ค่าธรรมเนียมร้าน" (products.edit · audit ที่ /api/ui-config) · ใช้กับทุกสินค้า
- **💵 กำไรจริงต่อร้าน**: ราคาที่ลูกค้าจ่ายบนร้านนั้น − (pct% + บาท/ชิ้น) − ต้นทุน/ชิ้น (`netProfit` ใน lib/parent-prices) · ร้านที่ยังไม่ตั้ง = คิด 0 + ป้ายเตือน
