# ⚙️ ตั้งค่าแอป + 👁 ใครเห็นเมนูไหน (ของกลาง)

## ใช้ทำอะไร
ในแอปเดี่ยว (`/app/<key>` เช่น "จัดการงาน") แอดมินกด **⚙️ ตั้งค่า** ท้ายแถบเมนู แล้วตั้งได้ว่า **ตำแหน่งไหน / ใคร เห็นเมนูอะไรบ้าง**
และเปิดหน้าตั้งค่าเฉพาะของแอปนั้นได้ในที่เดียว (เช่น จัดการงาน → ตั้งค่างาน `/tasks/settings`)

## ใช้ยังไง
1. เปิดแอปเดี่ยว → **⚙️ ตั้งค่า** (มือถือ: ☰ → ตั้งค่า) — เห็นเฉพาะคนที่มีสิทธิ์ `admin.users`
2. แท็บ **👁 ใครเห็นเมนูไหน**: ติ๊กตำแหน่งต่อเมนู — **ไม่ติ๊กเลย = ทุกคนเห็น**
   - **👤 รายคน**: ให้บางคนเห็นเพิ่ม (นอกจากตำแหน่งที่ติ๊ก) · ซ่อนจากบางคน (ชนะทุกข้อ)
   - **👀 ดูแทนตำแหน่ง**: เลือกตำแหน่ง → เมนูที่ตำแหน่งนั้นไม่เห็นจะจางลง
   - แก้แล้วกด **💾 บันทึก** (โหมดร่าง) → แถบเมนูโหลดใหม่ทันที
3. แท็บ **🔧 ตั้งค่า<แอป>**: หน้าตั้งค่าเฉพาะของแอป (ถ้ามี) ฝังในกรอบ

## กติกา (lib/menu-audience.ts — มีเทสต์)
- เก็บที่ `erp_menu_items.audience` = `{ roles?, users?, hide_users? }` · null = ทุกคน (migration 202610230600)
- แอดมินเห็นทุกเมนูเสมอ (ไว้จัดการ)
- มีผลกับ: แถบเมนูแอปเดี่ยว · เมนูซ้าย (PlaygroundShell) · หน้ารวมแอป `/apps`
- **เป็นการซ่อน/โชว์ในเมนูเท่านั้น** — กันเข้าหน้าจริง (พิมพ์ URL ตรง / API) ยังใช้สิทธิ์ตำแหน่ง (`permission_key` ของเมนู / ล็อกแอป) ตั้งที่ `/admin/role-board`
- เมนูที่อยู่หลายแอป (app_keys) ใช้ค่าชุดเดียวกันทุกแอป

## โค้ด
- หน้า: `components/app-settings-panel` (`AppSettingsPanel`, `APP_SETTINGS_PAGES` = แอป → หน้าตั้งค่าเฉพาะ · เพิ่มแอปที่นี่)
- เปิดจาก: `app/app/[appKey]/page.tsx` (ปุ่ม ⚙️ ท้ายแถบ + ใน drawer มือถือ)
- บันทึก: `PATCH /api/menu` (admin.users · ล้างค่าด้วย cleanAudience · มีประวัติ `menu.update` ใน audit_logs)
- ชื่อคน: `GET /api/creative-users?ids=` (คนที่ปิดบัญชีแล้วจะขึ้น "(ผู้ใช้ที่ปิดบัญชีแล้ว)")

## แท็บ 👤 ตามพนักงาน (เพิ่ม 2026-10-30)
มุมกลับของแท็บ 👁 — **เลือกพนักงานก่อน** แล้วติ๊กเมนูที่คนนี้เห็น (ข้อมูล `audience` ชุดเดียวกัน แก้ที่แท็บไหนอีกแท็บก็เห็นตรงกัน)
- ติ๊กตรงกับตำแหน่ง = ไม่เก็บอะไรเพิ่ม · ติ๊กต่างจากตำแหน่ง = **ตั้งเฉพาะคนนี้** (เพิ่มใน `users` หรือ `hide_users`) คนอื่นตำแหน่งเดียวกันเห็นเหมือนเดิม
- ป้ายต่อแถว: ทุกคนเห็น / ตำแหน่งนี้เห็น / ตำแหน่งนี้ไม่เห็น / เห็นเฉพาะคนที่เลือก / ตั้งเฉพาะคนนี้ · ซ่อนทั้งแอป (แท็บ ↕️) · ไม่มีสิทธิ์เข้า (ไม่มี `permission_key` ของเมนู)
- ⚠ **ยังเข้าได้ด้วยลิงก์** = ซ่อนเมนูแล้วแต่คนนี้ยังมีสิทธิ์ → กันจริงที่แท็บสิทธิ์ตามเมนู
- **ตั้งกลับเป็นตามตำแหน่ง** = ล้างค่าเฉพาะคนนี้ทุกเมนูในแอปนี้ · สลับดูหลายคนแล้วบันทึกทีเดียวได้ (โหมดร่าง)
- แอดมินเห็นทุกเมนูเสมอ → ช่องติ๊กของแอดมินล็อก
- กฎ: `explainMenuFor` / `setMenuVisibleFor` / `resetMenuFor` ใน `lib/menu-audience.ts` (เทสต์ `lib/__tests__/menu-audience-person.test.ts` — ตั้งให้คนหนึ่งแล้วคนอื่นต้องเห็นเหมือนเดิมทุกกรณี)
  - เมนูที่เห็นเฉพาะรายชื่อ แล้วเอาคนสุดท้ายออก → เก็บเป็น `roles: ["admin"]` (ยังจำกัดอยู่) ไม่กลายเป็นทุกคนเห็น
- โค้ด: `components/app-settings-panel/by-user.tsx` · บันทึกร่วมกับแท็บ 👁 ที่ `./audience-save.ts` · รายชื่อ `GET /api/admin/users` · สิทธิ์จริงของคน `GET /api/admin/user-permissions?user_id=`
- (2026-11-01) **เมนูที่ต้องมีสิทธิ์** (permission_key เช่น จัดเรียงงานพิมพ์ = `nesting.view`): ติ๊กให้เห็นอย่างเดียวไม่พอ — แท็บ 👤 ตามพนักงาน: แถว "ยังไม่มีสิทธิ์ · ติ๊กเพื่อให้สิทธิ์" ติ๊กแล้วถามก่อน → ให้สิทธิ์เฉพาะคนนั้น (`POST /api/admin/user-permissions` grant · มีประวัติ `user_permission_override`) · แท็บ 👁 เตือนสีเหลืองว่าตำแหน่งไหนที่ให้เห็นแต่ยังไม่มีสิทธิ์ (จาก matrix ของ `/api/admin/roles`)

## แท็บ เมนูและคนเห็น + ดูแบบคนนี้ (เพิ่ม 2026-11-12 · หน้าจัดการแอป รอบ 1)
แท็บแรก (เปิดมาเจอก่อน) ของ ⚙️ ตั้งค่าแอปเดี่ยว — รวมงานที่เคยแยก 3 แท็บไว้ในรายการเดียว
- ลาก ⠿ เรียงเมนู · เลือกที่อยู่ **บนแถบ / ในปุ่ม “เพิ่มเติม” / ซ่อน** · กดปุ่ม **ใครเห็น** ที่แถวเมนู → กางตั้ง ทุกคน / เฉพาะบางตำแหน่ง-บางคน / ซ่อนจากบางคน (เมนูย่อยตั้งแยกได้ ที่อยู่ตามเมนูแม่)
- ป้ายต่อแถว: หน้าแรก · เมนูย่อย N · **อยู่อีก N แอป** (ใครเห็นใช้ค่าเดียวกันทุกแอป) · สิทธิ์ที่เมนูต้องมี
- เลือกให้ตำแหน่งเห็น แต่ตำแหน่งนั้นยังไม่มีสิทธิ์ของเมนู → เตือนสีเหลือง + ปุ่ม “ให้สิทธิ์ด้วย” (ถามก่อน · ต้องมี `admin.roles`)
- **ดูแบบคนนี้**: เลือก “ทั้งตำแหน่ง” หรือ “พนักงาน” → แถบเมนูหน้าตาแบบที่เขาเห็นจริง (รวมค่าร่างที่ยังไม่บันทึก) + เมนูที่ไม่เห็น เพราะอะไร
  - เหตุผล: ซ่อนไว้ในแอปนี้ · เมนูแม่ถูกซ่อน · ตั้งซ่อนจากคนนี้ · ตำแหน่งนี้ไม่ได้ถูกเลือกให้เห็น · เห็นเฉพาะคนในรายชื่อ · ยังไม่มีสิทธิ์ “…”
  - ⚠ **ยังเข้าได้ถ้ามีลิงก์** = ซ่อนเมนูแล้วแต่ยังมีสิทธิ์ · ปุ่ม **ให้สิทธิ์คนนี้ / ให้สิทธิ์ตำแหน่งนี้** (ถามก่อน · มีผลทันที ไม่ต้องกดบันทึก · มีประวัติ)
  - ดูแทนทั้งตำแหน่ง = ไม่นับรายชื่อรายคน · แอดมินเห็นทุกเมนูยกเว้นที่ซ่อนไว้ในแอป
- บันทึกแบบร่าง → 💾 ทีเดียว · ที่เก็บเดิมทั้งหมด (ไม่มีตารางใหม่): ลำดับ/ที่อยู่ = `PATCH /api/menu {app_override}` · ใครเห็น = `PATCH /api/menu {patch.audience}` (ทั้งคู่มีประวัติ `menu.update`)
- กฎ "เห็นไหม เพราะอะไร" = `lib/menu-visibility.ts` (`menuVisibilityFor` / `previewMenusFor`) — รวม 3 ชั้นเดียวกับแถบเมนูจริง `app/app/[appKey]/page.tsx`: ซ่อนในแอป → ใครเห็น → สิทธิ์ · เทสต์ `lib/__tests__/menu-visibility.test.ts` (มีเทสต์เทียบกับกฎของแถบจริงทุกกรณี) — **แก้กฎกรองเมนูของแถบแอปเดี่ยว ต้องแก้ไฟล์นี้ด้วย**
- โค้ด: `components/app-settings-panel/menus-tab.tsx` · แท็บเดิม (ใครเห็นเมนูไหน / ตามพนักงาน / จัดเรียง-ซ่อน) ยังอยู่ ใช้ข้อมูลชุดเดียวกัน

### รอบ 2 (2026-11-12): ＋ เพิ่มเมนู / 🗑 เอาออกแบบปลอดภัย
- **＋ เพิ่มเมนู** (หัวรายการเมนู) 2 แบบ:
  - **เลือกจากหน้าที่มีในระบบ** = เมนูแถวเดิม เติม `app_keys` (ไม่สร้างซ้ำ · สิทธิ์/ใครเห็นติดมา) · รวมเมนูที่ปิดทั้งระบบ (เพิ่ม = เปิดกลับทุกแอปที่เคยอยู่) / ไม่อยู่แอปไหน / อยู่ในแอปแต่ไม่โชว์ในเมนู
  - **ลิงก์ใหม่** = ไอคอน (IconPicker) + ชื่อ + ลิงก์ (`/…` หรือ `https://…`) → `POST /api/menu` ตอนกดบันทึก · **ลิงก์ซ้ำเมนูเดิม** (ไม่สนตัวพิมพ์/ทับขวาท้าย) → บอกชื่อเมนูเดิม + ปุ่ม “เพิ่มเมนูเดิมแทน”
- **🗑 เอาออก** (ท้ายแถว) — ไม่มีลบถาวรในหน้านี้ ทุกแบบกู้คืนได้:
  - **เอาออกจากแอปนี้** (ค่าเริ่ม) = ถอด appKey จาก `app_keys` — แอปอื่นเห็นเหมือนเดิม
  - **ซ่อนไว้ในแอปนี้** = ที่อยู่ “ซ่อน” (เมนูหลักเท่านั้น)
  - **ปิดทั้งระบบ** = `is_active=false` — หายทุกแอป (บอกจำนวนแอป · แถบบันทึกเตือน)
  - เมนูแม่ → เมนูย่อยออกตาม · **หน้าแรกของแอป** → ต้องเลือกหน้าแรกใหม่ก่อน (บันทึกที่ `erp_app_groups.default_href`)
  - เมนูที่เพิ่ม (ยังไม่บันทึก) กดถังขยะ = ยกเลิกการเพิ่มเฉย ๆ
- ส่วน **“เมนูที่เอาออก / ปิดอยู่”** ท้ายหน้า: เอากลับ (ร่าง) · **เปิดกลับ** เมนูที่ปิดทั้งระบบที่เคยอยู่แอปนี้ (คงที่อยู่เดิม เช่น ใน “เพิ่มเติม”)
- บันทึกเรียง: หน้าแรก → ลิงก์ใหม่ → เพิ่ม/เปิดกลับ → เอาออก → ลำดับ/ที่อยู่ → ใครเห็น · ทุกขั้นมีประวัติ (`menu.create` / `menu.update` / `menu_app.update`)
- กฎ = `lib/app-menu-membership.ts` (`addToAppPatch` / `removeFromAppPatch` / `checkNewMenuLink`) + เทสต์ `lib/__tests__/app-menu-membership.test.ts`
- `DELETE /api/menu` (ลบถาวร) มีประวัติ `menu.delete` แล้ว (จดค่าเดิมก่อนลบ) · `POST` มี `menu.create` / `menu.seed` · ปุ่ม 🗑 ลบเมนู ที่ `/admin/menu` เปลี่ยนเป็นกล่องยืนยันกลาง + **พิมพ์ชื่อเมนู** + บอกว่าอยู่แอปไหน + แนะนำทางที่กู้คืนได้
- ยังไม่ทำ (รอบ 3 ถ้าต้องการ): หน้ารวมทุกแอปสำหรับแอดมิน + ถังขยะ (ลบถาวรจากที่เดียว)
