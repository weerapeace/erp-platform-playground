# ⚙️ ตั้งค่าแอป + 👁 ใครเห็นเมนูไหน (ของกลาง)

## ใช้ทำอะไร
ในแอปเดี่ยว (`/app/<key>` เช่น "จัดการงาน") แอดมินกด **⚙️ ตั้งค่า** ท้ายแถบเมนู แล้วตั้งได้ว่า **ตำแหน่งไหน / ใคร เห็นเมนูอะไรบ้าง**
และเปิดหน้าตั้งค่าเฉพาะของแอปนั้นได้ในที่เดียว (เช่น จัดการงาน → ตั้งค่างาน `/tasks/settings`)

## ใช้ยังไง
1. เปิดแอปเดี่ยว → **⚙️ ตั้งค่า** (มือถือ: ☰ → ตั้งค่า) — เห็นเฉพาะคนที่มีสิทธิ์ `admin.users`
2. แท็บ **👁 ใครเห็นเมนูไหน**: ติ๊กตำแหน่งต่อเมนู — **ไม่ติ๊กเลย = ทุกคนเห็น**
   - **👤 รายคน**: ให้บางคนเห็นเพิ่ม (นอกจากตำแหน่งที่ติ๊ก) · ซ่อนจากบางคน (ชนะทุกข้อ)
   - **👀 ดูแทนตำแหน่ง**: เลือกตำแหน่ง → เมนูที่ตำแหน่งนั้นไม่เห็นจะจางลง
   - แก้แล้วกด **💾 บันทึก** (โหมดร่าง) → แถบเมนูโหลดใหม่ทันที
3. แท็บ **🔧 ตั้งค่า<แอป>**: หน้าตั้งค่าเฉพาะของแอป (ถ้ามี) ฝังในกรอบ

## กติกา (lib/menu-audience.ts — มีเทสต์)
- เก็บที่ `erp_menu_items.audience` = `{ roles?, users?, hide_users? }` · null = ทุกคน (migration 202610230600)
- แอดมินเห็นทุกเมนูเสมอ (ไว้จัดการ)
- มีผลกับ: แถบเมนูแอปเดี่ยว · เมนูซ้าย (PlaygroundShell) · หน้ารวมแอป `/apps`
- **เป็นการซ่อน/โชว์ในเมนูเท่านั้น** — กันเข้าหน้าจริง (พิมพ์ URL ตรง / API) ยังใช้สิทธิ์ตำแหน่ง (`permission_key` ของเมนู / ล็อกแอป) ตั้งที่ `/admin/role-board`
- เมนูที่อยู่หลายแอป (app_keys) ใช้ค่าชุดเดียวกันทุกแอป

## โค้ด
- หน้า: `components/app-settings-panel` (`AppSettingsPanel`, `APP_SETTINGS_PAGES` = แอป → หน้าตั้งค่าเฉพาะ · เพิ่มแอปที่นี่)
- เปิดจาก: `app/app/[appKey]/page.tsx` (ปุ่ม ⚙️ ท้ายแถบ + ใน drawer มือถือ)
- บันทึก: `PATCH /api/menu` (admin.users · ล้างค่าด้วย cleanAudience · มีประวัติ `menu.update` ใน audit_logs)
- ชื่อคน: `GET /api/creative-users?ids=` (คนที่ปิดบัญชีแล้วจะขึ้น "(ผู้ใช้ที่ปิดบัญชีแล้ว)")

## แท็บ 👤 ตามพนักงาน (เพิ่ม 2026-10-30)
มุมกลับของแท็บ 👁 — **เลือกพนักงานก่อน** แล้วติ๊กเมนูที่คนนี้เห็น (ข้อมูล `audience` ชุดเดียวกัน แก้ที่แท็บไหนอีกแท็บก็เห็นตรงกัน)
- ติ๊กตรงกับตำแหน่ง = ไม่เก็บอะไรเพิ่ม · ติ๊กต่างจากตำแหน่ง = **ตั้งเฉพาะคนนี้** (เพิ่มใน `users` หรือ `hide_users`) คนอื่นตำแหน่งเดียวกันเห็นเหมือนเดิม
- ป้ายต่อแถว: ทุกคนเห็น / ตำแหน่งนี้เห็น / ตำแหน่งนี้ไม่เห็น / เห็นเฉพาะคนที่เลือก / ตั้งเฉพาะคนนี้ · ซ่อนทั้งแอป (แท็บ ↕️) · ไม่มีสิทธิ์เข้า (ไม่มี `permission_key` ของเมนู)
- ⚠ **ยังเข้าได้ด้วยลิงก์** = ซ่อนเมนูแล้วแต่คนนี้ยังมีสิทธิ์ → กันจริงที่แท็บสิทธิ์ตามเมนู
- **ตั้งกลับเป็นตามตำแหน่ง** = ล้างค่าเฉพาะคนนี้ทุกเมนูในแอปนี้ · สลับดูหลายคนแล้วบันทึกทีเดียวได้ (โหมดร่าง)
- แอดมินเห็นทุกเมนูเสมอ → ช่องติ๊กของแอดมินล็อก
- กฎ: `explainMenuFor` / `setMenuVisibleFor` / `resetMenuFor` ใน `lib/menu-audience.ts` (เทสต์ `lib/__tests__/menu-audience-person.test.ts` — ตั้งให้คนหนึ่งแล้วคนอื่นต้องเห็นเหมือนเดิมทุกกรณี)
  - เมนูที่เห็นเฉพาะรายชื่อ แล้วเอาคนสุดท้ายออก → เก็บเป็น `roles: ["admin"]` (ยังจำกัดอยู่) ไม่กลายเป็นทุกคนเห็น
- โค้ด: `components/app-settings-panel/by-user.tsx` · บันทึกร่วมกับแท็บ 👁 ที่ `./audience-save.ts` · รายชื่อ `GET /api/admin/users` · สิทธิ์จริงของคน `GET /api/admin/user-permissions?user_id=`
