# แผงตรวจสินค้าเร็ว (ProductQuickCheck) + ตัวเช็กข้อมูลลงขาย

ของกลาง `components/product-quick-check` · ตัวเช็ก `lib/product-listing-checks.ts` (pure + เทสต์) · ทะเบียน `product-quick-check`

## ใช้ทำอะไร
ลิ้นชักข้างจอแบบ **ดูอย่างเดียว** ให้คนตรวจดูข้อมูลลงขายของสินค้าครบในที่เดียว ต่อสินค้า 1 รุ่น:
1. **ระบบเช็กเจอ** — รายการจุดที่ควรเช็ก กดแล้วเลื่อนไปจุดนั้น (ไม่เจอ = กล่องเขียว)
2. **รูป** — จำนวนรูป Parent / Description + รูปย่อ 6 รูป + "ดูรูปทั้งหมด" (เปิดตัวดูรูปแบ่งกลุ่ม)
3. **Description** — สลับ ไทย / English ที่หัวแผง · คำนำย่อ 2 บรรทัด (อ่านต่อได้) · บรรทัดซ้ำขึ้นสีเหลือง · ขนาด กว้าง×สูง×หนา
4. **สีและราคา** — สรุปราคาบรรทัดเดียวถ้าทุกสีเท่ากัน (+ % ลด) · ตาราง รหัส / ชื่อสีไทย-อังกฤษ / ราคาขาย / ขีดฆ่า / รูป · ช่องผิดขึ้นสีเหลือง · เกิน 8 SKU และมีแบบย่อย (เช่น WK46-01D/G/N) → รวมตามสีได้
5. **footer** — ช่องให้ผู้เรียกใส่ปุ่มเอง ได้รายการจุดที่เช็กเจอไปใช้ (เช่น เติมเหตุผลตอนตีกลับ)

## ตัวเช็ก (เตือนอย่างเดียว ไม่บล็อก)
| key | เช็กอะไร |
|---|---|
| desc_th_empty / desc_en_empty | ไม่มี Description ไทย / อังกฤษ |
| desc_th_dup / desc_en_dup | บรรทัดซ้ำ (ไม่สนตัวพิมพ์/ช่องว่าง/จุดท้าย) |
| desc_en_short | อังกฤษสั้นกว่าไทยเกินครึ่ง |
| desc_cm_mismatch | ตัวเลข "ซม." ในไทยไม่มีในอังกฤษ (เช่น 42 ซม. vs 40 cm) |
| size_missing | ไม่ใส่ขนาด |
| color_th_empty / color_th_english | ชื่อสีไทยว่าง / เขียนเป็นอังกฤษ |
| color_en_empty / color_en_thai | ชื่อสีอังกฤษว่าง / เขียนเป็นไทย |
| price_missing | ไม่มีราคาขาย |
| fake_missing / fake_low | ไม่มีราคาขีดฆ่า / ขีดฆ่าไม่สูงกว่าราคาขาย |
| parent_no_images / sku_no_images | Parent / SKU ไม่มีรูป |

ฟิลด์ที่ใช้: `parent_skus_v2.introduction · description · english_description · size_*_cm` · `skus_v2.color_th (สำรอง color_platform_th) · color_platform_en · list_price · fake_price`
**ไม่รับต้นทุน (`standard_price`)** — แผงนี้คนทั่วไปเห็น

## ห้ามใช้เมื่อไหร่
- แก้ข้อมูลสินค้า → เปิดหน้าเต็ม (`MasterRecordDrawer`) — แผงมีปุ่ม "เปิดหน้าเต็ม"
- จดปัญหาด้วยมือ → `ParentIssuesPanel`

## ตัวที่ใช้อยู่: ปุ่ม "ตรวจเร็ว" ในลิ้นชักงาน
- `app/tasks/task-quick-check.tsx` · ข้อมูล `GET /api/creative-tasks/[id]/quick-check` (tasks.view)
  - สินค้า/SKU/จำนวนรูป โหลดด้วย `lib/task-images-server` ตัวเดียวกับปุ่ม "ดูรูป" → นับรูปตรงกัน
- ท้ายแผง: **อนุมัติ** (ถามยืนยันในบรรทัดเดิม บอกจำนวนจุดที่ยังเช็กเจอ) · **ตีกลับแก้** (ติ๊กจุดที่เช็กเจอ — ติ๊กไว้ให้หมดตอนเปิด + พิมพ์เพิ่ม · ต้องมีอย่างน้อย 1 อย่าง)
  - ปุ่มชุดเดียวกับท้ายลิ้นชัก: สิทธิ์ `tasks.approve` + เส้นทางสถานะจริง · งานที่สถานะมาจากงานย่อย คนทั่วไปไม่มีปุ่ม
  - เปลี่ยนสถานะผ่าน `applyTaskTransition(task, to, { comment })` — ส่ง comment = ข้ามป๊อปถามเหตุผล · เช็กงานย่อยค้าง + บันทึกประวัติฝั่ง server เหมือนเดิม

## สิทธิ์ / ประวัติ
- ดูข้อมูล = `tasks.view` · อนุมัติ/ตีกลับ = `tasks.approve` (server เช็กซ้ำ) · ประวัติการอนุมัติ/ตีกลับบันทึกที่ `PATCH /api/creative-tasks/[id]` เดิม
- ตัวแผงไม่แก้ข้อมูลสินค้า → ไม่มีประวัติฝั่งสินค้า

## ข้อจำกัด
- ข้อที่ต้องให้ AI อ่าน (เช่น คำนำบอก "หนังแท้" แต่วัสดุบอก PU) ยังไม่ทำ
- SKU แบบย่อยที่ใช้รูปร่วมกับสีหลัก (เช่น สลักชื่อ D/G/N) จะถูกนับว่า "ไม่มีรูป"
