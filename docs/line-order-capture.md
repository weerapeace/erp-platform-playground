# คำสั่งซื้อจากไลน์ (Line Order Capture)

ซื้อของจาก Shopee/Taobao เสร็จ → แคปหน้าคำสั่งซื้อส่งเข้า "กลุ่มส่งรูปคำสั่งซื้อ" → AI อ่าน → พักในกล่อง → คนตรวจแล้วกดยืนยัน (ผูก PO เดิม / เปิด PO ใหม่ / เก็บไว้ก่อน)

## ใช้ทำอะไร / เมื่อไหร่
- เก็บหลักฐานการซื้อออนไลน์ (รูป + ร้าน + เลขคำสั่งซื้อ + รายการ + ราคา + ค่าส่ง + เลขพัสดุ) ไว้ค้นย้อนหลัง
- เอาราคาจริงไปใส่ใบสั่งซื้อที่เปิดไว้ก่อนซื้อ (หลายใบยังเป็นราคา 0) หรือเปิดใบใหม่จากคำสั่งซื้อ
- เตือนเลขคำสั่งซื้อซ้ำ (ส่งรูปซ้ำ / ซื้อซ้ำ)

**ห้ามใช้** เป็นตัวดึงประวัติจาก Shopee/Taobao อัตโนมัติ — ทั้งสองเจ้าไม่มีช่องทางให้ฝั่งผู้ซื้อ และห้ามเก็บรหัสผ่าน

## ตั้งค่า (ครั้งเดียว)
1. สร้างกลุ่มไลน์ใหม่ เชิญบอท "พนักงานลงบิลจีนลูก้า" เข้ากลุ่ม แล้วพิมพ์อะไรก็ได้ 1 ครั้ง
2. หน้า `/purchasing/line-orders` (แอดมิน) กด "ใช้กลุ่มนี้" — หรือศูนย์จัดการ LINE ช่อง "กลุ่มส่งรูปคำสั่งซื้อ (AI อ่าน)" (slot `purchase_capture`)
3. LINE Official Account Manager → ปิดข้อความตอบกลับอัตโนมัติ
4. (แนะนำ) ใส่ Channel secret ที่ ⚙️ ตั้งค่าไลน์ → ระบบตรวจลายเซ็นทุกข้อความ

ไม่ต้องแก้ Webhook URL ใน LINE Developers — ใช้ตัวรับเดิม `/api/china-pay/line-webhook` ซึ่งแยกงานต่อเอง

## ค่าที่สำคัญ
- โมเดล AI: `gpt-4.1-mini` (เปลี่ยนได้ด้วย env `OPENAI_ORDER_MODEL`) · ใช้ `OPENAI_API_KEY` ตัวเดียวกับแคปชั่น AI
- ตอบกลับในไลน์ด้วย **reply** (ฟรี ไม่นับโควตา push 300/เดือน) · 1 ใบ = 1 ข้อความ
- ส่งหลายรูปพร้อมกัน (LINE `imageSet`) = รวมเป็นใบเดียว · รอครบไม่เกิน 3 นาที

## สิทธิ์ / audit / ความเป็นส่วนตัว
- ดู = `po.view` · แก้/ยืนยัน/อัปรูป = `po.edit` · ตั้งกลุ่ม = `admin.users`
- ตาราง RLS เปิด ไม่มี policy + ถอนสิทธิ์ anon/authenticated → อ่านได้ผ่าน API นี้เท่านั้น (รูปมีชื่อ/ที่อยู่ผู้รับ)
- AI ถูกสั่งไม่ให้ถอดชื่อ/ที่อยู่/เบอร์ผู้รับ
- audit: `ai_order_read` (ทุกครั้งที่ AI อ่าน = มีค่าใช้จ่าย) · `create` / `update` / `confirm` / `reject` / `restore` · PO ที่ถูกแก้ลง `purchase_orders_v2` source `line_capture`

## ข้อจำกัดที่รู้แล้ว
- AI อ่านไม่ 100% → ต้องมีคนยืนยันทุกใบ (ผล AI ไม่แตะ PO จนกว่าจะยืนยัน)
- ผูก PO เดิม: ใส่ "ราคา" ให้ แต่ไม่เปลี่ยน "จำนวน" ในใบ (เตือนถ้าไม่ตรง) · สกุลเงินไม่ตรงกับใบ = ไม่ใส่ราคา
- ยืนยันแล้วเปลี่ยนวิธีผูกไม่ได้ (แก้ได้แค่เลขพัสดุ/หมายเหตุ)
- รูปเปิดผ่าน `/api/r2-image` ด้วยชื่อไฟล์สุ่ม (ยังไม่ใช่ลิงก์มีอายุ — อยู่ในรายการงานความปลอดภัย)
