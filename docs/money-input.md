# MoneyInput — ช่องกรอกจำนวนเงินกลาง

`components/money-input/index.tsx`

## ใช้ทำอะไร

ช่องกรอก "จำนวนเงิน" ที่ **โชว์ลูกน้ำคั่นหลักพันตั้งแต่ตอนพิมพ์** — `5124990` จะเห็นเป็น `5,124,990`
แต่ค่าที่ส่งกลับให้ระบบยังเป็นตัวเลขดิบเสมอ (`"5124990"`) เอาไปบันทึกลงฐานข้อมูลได้ตรง ๆ

เหตุผลที่ต้องมี: `<input type="number">` ของเบราว์เซอร์ **ใส่ลูกน้ำไม่ได้** → เลขหลักล้านอ่านยากมาก
ว่าเป็น 5 ล้านหรือ 51 ล้าน (เจ้าของโปรเจกต์แจ้งปัญหานี้จากหน้าสัญญาเงินกู้)

## ใช้เมื่อไหร่

- ทุกช่องที่กรอก "เงิน" — ราคา ต้นทุน ยอดเงิน ค่าแรง เงินต้น ดอกเบี้ย ฯลฯ

## ห้ามใช้เมื่อไหร่

- ตัวเลขที่ **ไม่ใช่เงิน** และไม่ควรมีลูกน้ำ เช่น ปี พ.ศ. เลขที่เอกสาร รหัส จำนวนงวด จำนวนชิ้น
  (ใช้ `<input type="number">` ตามปกติ)

## จุดที่เสียบไว้ให้แล้ว (ไม่ต้องทำเอง)

| ที่ | ผลที่ได้ |
|---|---|
| ฟอร์มกลาง `MasterCRUDPage` / `MasterRecordDrawer` | ฟิลด์ชนิด `currency` ในทะเบียนฟิลด์ (หรือฟิลด์ที่ตั้ง `options.currency` / `options.currency_field`) จะได้ช่องแบบมีลูกน้ำ **ทุกโมดูลอัตโนมัติ** |
| แก้เร็วในหน้ารายละเอียด (ดับเบิลคลิกที่ค่า) | ฟิลด์เงินได้ช่องแบบมีลูกน้ำเหมือนกัน |

ดังนั้นถ้าฟิลด์ถูกลงทะเบียนเป็นชนิด "เงิน (currency)" ที่ `/admin/schema-sync` → **ได้ลูกน้ำเองโดยไม่ต้องแก้โค้ดหน้า**

## ใช้เองในหน้า/ป๊อปที่เขียนมือ

```tsx
import { MoneyInput } from "@/components/money-input";

<MoneyInput
  value={amount}                       // string | number | null
  onChange={(raw) => setAmount(raw)}   // raw = ตัวเลขดิบ ไม่มีลูกน้ำ
  className="w-full h-9 px-3 text-sm text-right tabular-nums border rounded-md"
  placeholder="0.00"
/>
```

### props

| prop | ความหมาย |
|---|---|
| `value` | ค่าที่เก็บจริง (ตัวเลขดิบ) |
| `onChange(raw)` | คืนค่าดิบทุกครั้งที่พิมพ์ |
| `onBlur(raw)` | ออกจากช่อง — ส่งค่าดิบล่าสุดมาด้วย (บันทึกทันทีได้ ไม่ต้องรอ state) |
| `onKeyDown(e)` | ดักปุ่มเอง (เช่น Enter = บันทึก) — เรียกก่อน logic ภายใน |
| `disabled` / `placeholder` / `className` / `style` / `autoFocus` / `title` | เหมือน input ปกติ |

## พฤติกรรมที่ดูแลให้แล้ว

- เคอร์เซอร์ไม่กระโดดไปท้ายช่องตอนที่ระบบเติมลูกน้ำ
- กด Backspace ตรงหน้าลูกน้ำ → ลบ **ตัวเลข** ก่อนหน้า (ไม่ใช่ลบลูกน้ำเปล่า ๆ)
- ตัดศูนย์นำหน้า (`05` → `5`), กันจุดทศนิยมซ้ำ, รับเครื่องหมายลบนำหน้าได้
- ออกจากช่องแล้วเก็บกวาดค่าค้าง เช่น `1234.` → `1234`
- ไม่ปัดเศษ / ไม่เติม `.00` ให้เอง — เก็บค่าตามที่ผู้ใช้พิมพ์

## ฟังก์ชันช่วย (export ให้ใช้ซ้ำ)

- `groupThousands(raw)` — ใส่ลูกน้ำให้ข้อความตัวเลข
- `sanitizeNumeric(raw)` — ตัดให้เหลือเฉพาะรูปแบบตัวเลขที่บันทึกได้

> การ **แสดงผล** จำนวนเงิน (ตาราง / หน้ารายละเอียด / รายงาน) ใช้ `formatAmount()` จาก `lib/money.ts` เหมือนเดิม
> — ตัวนี้ใช้เฉพาะตอน **กรอก** เท่านั้น
