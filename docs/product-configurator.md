# 👜 ตัวประกอบสินค้า (Product Configurator)

## ใช้ทำอะไร
ให้ลูกค้าบนเว็บร้านออกแบบสินค้าเอง (เริ่มที่กระเป๋า IG International): เลือกทรง วัสดุ สี ซิป สาย อะไหล่ ซับใน ปั๊มชื่อ
แล้วเห็นรูปสินค้าที่ **ประกอบจากรูปถ่ายพื้นใสหลายชั้น** ทันที · ดูได้หลายมุม (หน้า / หลัง / ใน / ข้าง) ตั้งทีละทรง
แอดมินตั้งทุกอย่างเองในหลังบ้าน `/admin/product-configurator` ไม่ต้องแก้โค้ด

สถานะ: **ก้อน 1–2 เสร็จ** (ฐานข้อมูล + กฎกลาง + API + สตูดิโอหลังบ้าน + แม่แบบถ่ายรูป) · ยังไม่มีหน้าเว็บลูกค้า (ก้อน 3) / ตะกร้า-ออเดอร์ (ก้อน 4) / ต่อฝ่ายผลิต (ก้อน 5)

## ต่างจาก Belt Builder ยังไง
Belt Builder ล็อกชนิดชิ้นส่วนไว้ในโค้ด 3 ชนิด (สาย/หัว/หู) · ตัวประกอบสินค้า **ทุกอย่างเป็นข้อมูล**: ช่องตัวเลือก ตัวเลือก ชั้นรูป กติกา มุม
→ สินค้าใหม่ (กระเป๋าทรงอื่น เข็มขัด รองเท้า) = เพิ่มข้อมูล ไม่ต้องเขียนโปรแกรมใหม่ · อนาคตย้ายเข็มขัดเข้ามาได้ (ก้อน 6)

## แนวคิด
| คำ | ความหมาย | ตาราง |
|---|---|---|
| ทรง | สินค้า 1 แบบ เช่น กระเป๋าโท้ท · มุมที่เปิด · ผืนผ้าใบ 3000×3000 · ค่าแม่แบบต่อมุม | `configurator_models` |
| ช่อง | คำถาม 1 ขั้น · `single` เลือก 1 / `multi` หลายอย่าง / `text` พิมพ์ข้อความ | `configurator_slots` |
| ตัวเลือก | คำตอบในช่อง + ราคาเพิ่ม + วันผลิตเพิ่ม + สีตัวอย่าง | `configurator_options` |
| ชั้นรูป | รูป 1 ชั้นของมุมหนึ่ง · `depends_on` = รูปเปลี่ยนตามช่องไหน · `show_when` = โชว์เมื่อ · `recolor_slot` = ลงสีจากรูปกลาง · `text_slot` = ตัวอักษรพิมพ์สด | `configurator_layers` |
| รูป | ไฟล์ของชั้นตามคอมโบตัวเลือก (`combo_key` เช่น `PEBBLE_NOIR`) | `configurator_layer_images` |
| กติกา | ถ้าเลือก A ในช่อง X → ช่อง Y `block` เลือกไม่ได้ / `only` ได้เฉพาะ + เหตุผลที่ลูกค้าเห็น | `configurator_rules` |
| แบบของลูกค้า | การเลือกที่ลูกค้าบันทึก + ราคา + รหัสแบบ XXXX-XXXX | `configurator_designs` |

### กฎรูป (สำคัญ)
- **ทุกไฟล์กว้าง×สูงเท่าผืนผ้าใบของทรง พื้นใส** → วางซ้อนตรงกันเอง ไม่ต้องตั้งจุดยึด (ไม่เท่า = อัปโหลดไม่ผ่าน)
- ชื่อไฟล์ = `{ทรง}_{มุม}_{ชั้น}_{ตัวเลือกตามลำดับ depends_on}.png` เช่น `TOTE_FRONT_BODY_PEBBLE_NOIR.png` · ชั้นรูปเดียว = `TOTE_FRONT_SHADOW.png`
- รหัสทุกตัว: ตัวใหญ่ A-Z ตัวเลข `-` · **ห้าม `_`** (ใช้คั่นชื่อไฟล์)
- ลงสีจากรูปกลาง: ถ่ายสีกลาง (เทาอ่อน) รูปเดียว ระบบลงสีด้วย `swatch_hex` (multiply + mask) — เหมาะหนัง/ผ้าสีเรียบ · ลายนูน/ลายพิมพ์ต้องถ่ายจริง

## ใช้ยังไง (แอดมิน)
1. เลือกร้าน → "สร้างทรงตัวอย่าง (โท้ท)" หรือ "เพิ่มทรง"
2. แท็บ **ตัวเลือก**: ช่องทีละขั้น + ตัวเลือก + ราคา (ลากจัดลำดับ)
3. แท็บ **ชั้นรูป**: ชั้นต่อมุม เรียงล่าง→บน · ตั้ง "เปลี่ยนตาม" / "โชว์เมื่อ" / ลงสี
4. แท็บ **กติกา**: คู่ที่จับกันไม่ได้
5. แท็บ **แม่แบบ & รูปที่ต้องถ่าย**: ตั้งเส้นพื้น ไม้บรรทัด จุดวาง → โหลดแม่แบบ PNG/SVG + CSV รายการรูป → ส่งช่างภาพ
6. อัปโหลดหลายรูป (แท็บชั้นรูป) → ระบบจับคู่จากชื่อไฟล์ เช็กขนาด/พื้นใส
7. แท็บ **ข้อมูลทรง**: เปิดให้ลูกค้าใช้ (หน้าเว็บร้าน = ก้อน 3)

## ข้อจำกัดตอนนี้
- ยังไม่มีหน้าเว็บร้าน / ตะกร้า / ออเดอร์ / BOM — ทรงที่เปิดยังไม่โผล่บนเว็บ
- ตัวอักษรปั๊มยังเป็นแบบพื้นฐาน (จม/ทอง/เงิน/สี) — ยังไม่ต่อเอฟเฟกต์ Photoshop ของระบบปั๊มชื่อ (`personalize`)
- ช่องแบบเลือกหลายอย่างใช้เป็น "เงื่อนไขโชว์ชั้น" ได้ แต่ใช้เป็น "เปลี่ยนตาม" ไม่ได้
- ลบช่องที่ชั้นรูป/กติกาอ้างถึง ระบบเตือนแต่ไม่แก้ให้อัตโนมัติ
