# 📥 ลากไฟล์มาวางเพื่ออัปโหลด — `useFileDrop` (ของกลาง)

ไฟล์: `components/file-drop.tsx` (`useFileDrop` + `FileDropHint`)

## ใช้ทำอะไร
ให้ช่อง/แถวที่มีปุ่ม "⬆ อัปโหลด" อยู่แล้ว **ลากรูป/ไฟล์จากเครื่องมาวางได้ด้วย** — ตอนลากผ่านช่องจะมีกรอบประ + ป้าย "วางรูปเพื่ออัปโหลด…"

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ใช้: หน้าใดก็ได้ที่อยากให้ลากไฟล์มาวาง โดยเฉพาะหน้าที่มีหลายช่องรับไฟล์ (เช่น แถวรูปรายสี) — hook ตัวเดียวคุมทุกช่อง
- ไม่ต้องใช้: ช่องที่ใช้ของกลางที่รับลากวางอยู่แล้ว (`ImageAttach`, `AssetLibrary`, `AttachmentPanel` ฯลฯ)
- ไม่ได้อัปโหลดเอง — ส่งไฟล์ให้ callback ของหน้า (หน้าใช้ `uploadResizedImage` หรือช่องทางเดิม → สิทธิ์/บันทึกประวัติตามช่องทางนั้น)

## ตัวอย่าง
```tsx
const drop = useFileDrop((files, key) => upload(key, files), {
  accept: "image/",                       // ขึ้นต้นชนิดไฟล์ · ไม่ใส่ = รับทุกไฟล์
  disabled: !!uploading,                  // กำลังอัปอยู่ = ไม่รับ (ไม่ไฮไลต์)
  onReject: () => toast.error("ลากมาได้เฉพาะไฟล์รูป"),
  onBusy: () => toast.warning("กำลังอัปโหลดอยู่ — รอสักครู่"),
});
<div {...drop.guard}>                                   {/* กรอบนอก: วางพลาดช่อง = ไม่มีอะไรเกิด */}
  <div {...drop.zone("sku-1")} className="relative">
    <FileDropHint show={drop.over === "sku-1"} label="วางรูปเพื่ออัปโหลดเข้าสีนี้" />
    …
  </div>
</div>
```

## พฤติกรรม
- สนใจเฉพาะการลาก **ไฟล์จากเครื่อง** — ลากแถว/การ์ดภายในหน้า (เช่น ลากเรียงลำดับ) ไม่โดน
- `guard` ที่กรอบนอก = เบราว์เซอร์ไม่เปิดไฟล์ทับหน้าเมื่อวางพลาด (ของที่ยังไม่บันทึกไม่หาย)
- ไฟล์ที่ไม่ตรง `accept` ถูกตัดทิ้ง · ไม่เหลือเลย = `onReject` · `accept` ใส่หลายชนิดได้ เช่น `["image/", "video/"]`
- ช่องซ้อนกัน (ช่อง Hero อยู่ในแถวสีที่ลากวางได้) = ช่องในสุดรับไปช่องเดียว ช่องนอกไม่ไฮไลต์/ไม่อัปซ้ำ
