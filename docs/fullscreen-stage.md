# ⛶ FullscreenStage — โหมดเต็มจอของกระดาน/ผัง (ของกลาง)

เจ้าของขอ 2026-11-19: "อยากให้ใหญ่เต็มจอแบบ Miro จะได้ดูได้ง่าย" (เลือก F1 F2 F3 F5 F6 F7)

## ใช้ทำอะไร
- กดปุ่ม "เต็มจอ" หรือคีย์ **F** → กระดานกินพื้นที่ทั้งจอ ซ่อนหัวเว็บ เมนูแอป แถบปุ่มของหน้า
- **Esc** = ออก (ป๊อปที่เปิดทับอยู่ปิดก่อน — ใช้กองกลาง `useEscLayer`)
- **จำต่อคน** (`useUserPref`) → เข้าหน้านี้ครั้งหน้าเปิดเต็มจอเลย ตามไปทุกเครื่อง
- **มือถือ (จอ < 768px) เต็มจอเสมอ** · มีปุ่ม "แผนงาน ←" ออกชั่วคราว (ไม่จำ)
- สลับเต็มจอแล้วกระดาน **ไม่โหลดใหม่** (แค่เปลี่ยนกรอบเป็นชั้นลอย ไม่ย้ายของข้างใน)
- `defaultOn` = คนที่ยังไม่เคยเลือก เปิดมาเต็มจอเลย (กดออกแล้วจำต่อคน)
- **เปิดในแอปเดี่ยว** (/app/<key>) → บอกเชลล์ให้ซ่อนหัวแอปสีเข้ม + แถบเมนูแอปด้วย (`lib/app-shell-bar` · `usePageWantsFullFrame` — ของกลางเรียกให้เอง)

## ซ่อนแถบปุ่มไว้ขอบบน (`autoHide`) — เจ้าของขอ 2026-11-19 "ข้างบนเอาเมาส์ไปวางแล้วค่อยโชว์"
- ห่อแถบปุ่มด้วย `<FullscreenBar order={n}>` (ใช้ในลูกลึก ๆ ได้ · แถบเครื่องมือวาดของ FlowchartBoard ไม่ห่อ — โชว์ค้างเสมอ เจ้าของสั่ง 2026-11-19) → ตอนเต็มจอย้ายไปแถบลอยขอบบน เรียงตาม order · นอกโหมดนี้แสดงที่เดิม
- **ชี้ขอบบน** = แถบเลื่อนลงมา · เมาส์ออก ~1 วิ = ซ่อน (กำลังพิมพ์ในช่องของแถบ = ไม่ซ่อน)
- `<FullscreenPeek>` = ชิปเล็กกลางขอบบนที่ค้างไว้ (เช่น ค้าง 110 · เกิน 37) + ปุ่ม "เครื่องมือ" กดเปิด/ปิดแถบ → **มือถือใช้ทางนี้** · แตะกระดาน = ปิดแถบ
- ปุ่ม **ปักไว้** ท้ายแถบ = แถบโชว์ค้าง (จำต่อคน `<prefKey>_pin`)
- ป๊อปที่เปิดจากปุ่มในแถบควรเป็นชั้นลอยของตัวเอง (ERPModal/portal) — แถบซ่อนแล้วป๊อปไม่ปิดตาม

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ใช้: หน้ากระดานวาด / ผังงาน / canvas ที่อยากได้พื้นที่มากสุด
- ห้ามใช้: ป๊อปฝังหน้าอื่น (ใช้ `EmbedModal`) · ดูรูปเต็มจอ (`ImageLightbox`) · ทั้งแอปไม่มีเมนูข้าง (`StandaloneShell`)

## วิธีใช้
```tsx
import { FullscreenBar, FullscreenPeek, FullscreenStage, FullscreenToggle, useFullscreenStage } from "@/components/fullscreen-stage";

const fs = useFullscreenStage("my_board_fullscreen", { active: isBoardTab, defaultOn: true, autoHide: true });
<FullscreenStage fs={fs}>
  <FullscreenBar order={10}><div className="flex items-center gap-2">…ปุ่มของกระดาน… <FullscreenToggle fs={fs} /></div></FullscreenBar>
  <FullscreenPeek>ค้าง 12 · เกิน 3</FullscreenPeek>
  <MyBoard fill={fs.on} />   {/* fill = ยืดเต็มที่เหลือ: กรอบเป็น flex-1 min-h-0 · กระดานสูง 100% */}
</FullscreenStage>
```
- `active` = หน้านี้กำลังโชว์กระดานไหม (อยู่แท็บอื่น = ไม่เต็มจอ ไม่ฟังคีย์ แม้เป็นมือถือ)
- ลูกข้างในต้องรองรับ "เต็มพื้นที่": `CanvasSketch fill` · `FlowchartBoard height="100%"` (กรอบพ่อเป็น flex column ที่สูงแน่นอน)
- คีย์ F ใช้ตำแหน่งปุ่ม (KeyF) → แป้นไทยก็กดได้ · ไม่ทำงานตอนพิมพ์ในช่อง หรือโฟกัสอยู่ในกระดานวาด Excalidraw (F = เครื่องมือกรอบของมัน)

## ชั้น (z-index)
- ชั้นเต็มจอ = `z-[45]` เหนือเปลือกหน้า (≤ z-40) แต่ **ต่ำกว่าป๊อปอัปกลาง (z-50)** → ป๊อป/ลิ้นชักยังเปิดทับได้ปกติ
- ลิ้นชักมือถือที่เปิดจากในกระดานต้อง ≥ z-50 (เช่น `PlanTray`)

## สิทธิ์ / ประวัติ
- ไม่มีข้อมูลธุรกิจ — เก็บแค่ค่าตั้งส่วนตัว (เต็มจอ · ปักแถบ ใน user_ui_prefs) ไม่ต้องลง audit log

## ใช้อยู่ที่
- แผนงานทีม `/tasks/plan` แท็บ "กระดาน" (ทั้งโหมดผังระบบ และกระดานวาด) — key `team_plan_board_fullscreen` · เปิดมาเต็มจอ + ซ่อนแถบ (แถบโหมด · ตัวกรอง · สรุป · เครื่องมือวาดของผัง)
- กระดานแคนวาสกลาง (CanvasSketch) ผ่าน prop `fullscreen="<key>"` — แบบ **float** (เจ้าของเลือกแบบ B 2026-11-23): กระดานกิน 100dvh (เว้นรอยบาก safe-area) · ปุ่มของกระดาน + `fullscreenBar` ของหน้าย้ายไปแถบลอยล่างกลาง (หุบได้ · มือถือยกเหนือแถบล่างของ Excalidraw) · **Esc 2 จังหวะ** (จังหวะ 1 ล้างการเลือก/ปล่อยให้กระดานยกเลิกเครื่องมือ · จังหวะ 2 ออก — Excalidraw กิน Esc เอง ชั้น Esc กลางไม่ได้ยิน จึงดักที่กรอบกระดาน) · หน้ามีปุ่มเองเรียก `controls.toggleFullscreen()` + `fullscreenButton={false}`
  - แคมเปญ `campaign_board_fullscreen` · เทรนด์ `trend_board_fullscreen` · แคนวาสแบรนด์ (Design dashboard) `design_brand_board_fullscreen`
  - ⚠️ ลูกของชั้นเต็มจอต้องอยู่ช่องเดิม (ช่องที่ 4) ทุกโหมด ไม่งั้นกระดานถูกสร้างใหม่ตอนสลับ (งานที่ยังไม่เซฟหาย)
