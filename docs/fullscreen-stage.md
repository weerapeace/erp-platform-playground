# ⛶ FullscreenStage — โหมดเต็มจอของกระดาน/ผัง (ของกลาง)

เจ้าของขอ 2026-11-19: "อยากให้ใหญ่เต็มจอแบบ Miro จะได้ดูได้ง่าย" (เลือก F1 F2 F3 F5 F6 F7)

## ใช้ทำอะไร
- กดปุ่ม "เต็มจอ" หรือคีย์ **F** → กระดานกินพื้นที่ทั้งจอ ซ่อนหัวเว็บ เมนูแอป แถบปุ่มของหน้า
- **Esc** = ออก (ป๊อปที่เปิดทับอยู่ปิดก่อน — ใช้กองกลาง `useEscLayer`)
- **จำต่อคน** (`useUserPref`) → เข้าหน้านี้ครั้งหน้าเปิดเต็มจอเลย ตามไปทุกเครื่อง
- **มือถือ (จอ < 768px) เต็มจอเสมอ** · มีปุ่ม "แผนงาน ←" ออกชั่วคราว (ไม่จำ)
- สลับเต็มจอแล้วกระดาน **ไม่โหลดใหม่** (แค่เปลี่ยนกรอบเป็นชั้นลอย ไม่ย้ายของข้างใน)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ใช้: หน้ากระดานวาด / ผังงาน / canvas ที่อยากได้พื้นที่มากสุด
- ห้ามใช้: ป๊อปฝังหน้าอื่น (ใช้ `EmbedModal`) · ดูรูปเต็มจอ (`ImageLightbox`) · ทั้งแอปไม่มีเมนูข้าง (`StandaloneShell`)

## วิธีใช้
```tsx
import { FullscreenStage, FullscreenToggle, useFullscreenStage } from "@/components/fullscreen-stage";

const fs = useFullscreenStage("my_board_fullscreen", { active: isBoardTab });
<FullscreenStage fs={fs}>
  <div className="flex items-center gap-2">…ปุ่มของกระดาน… <FullscreenToggle fs={fs} /></div>
  <MyBoard fill={fs.on} />   {/* fill = ยืดเต็มที่เหลือ: กรอบเป็น flex-1 min-h-0 · กระดานสูง 100% */}
</FullscreenStage>
```
- `active` = หน้านี้กำลังโชว์กระดานไหม (อยู่แท็บอื่น = ไม่เต็มจอ ไม่ฟังคีย์ แม้เป็นมือถือ)
- ลูกข้างในต้องรองรับ "เต็มพื้นที่": `CanvasSketch fill` · `FlowchartBoard height="100%"` (กรอบพ่อเป็น flex column ที่สูงแน่นอน)
- คีย์ F ใช้ตำแหน่งปุ่ม (KeyF) → แป้นไทยก็กดได้ · ไม่ทำงานตอนพิมพ์ในช่อง หรือโฟกัสอยู่ในกระดานวาด Excalidraw (F = เครื่องมือกรอบของมัน)

## ชั้น (z-index)
- ชั้นเต็มจอ = `z-[45]` เหนือเปลือกหน้า (≤ z-40) แต่ **ต่ำกว่าป๊อปอัปกลาง (z-50)** → ป๊อป/ลิ้นชักยังเปิดทับได้ปกติ
- ลิ้นชักมือถือที่เปิดจากในกระดานต้อง ≥ z-50 (เช่น `PlanTray`)

## สิทธิ์ / ประวัติ
- ไม่มีข้อมูลธุรกิจ — เก็บแค่ค่าตั้งส่วนตัว (user_ui_prefs) ไม่ต้องลง audit log
