# กดกล่องในใบพิมพ์แล้วแก้หน้าตา (print-part-style)

ของกลาง · เจ้าของขอ 2026-11-20 · ใช้ครั้งแรก: ใบเสนอราคาแบบ "การ์ดรูปใหญ่" (`/print/quotation/[id]`)

## ใช้ทำอะไร
ผู้ใช้กดกล่องไหนก็ได้ในพรีวิวเอกสาร → แผงแก้ (จอคอม = แผงลอยลากได้ · มือถือ = แผ่นล่าง):
- ซ่อน: ทุกการ์ด / เฉพาะการ์ดนี้ (กล่องในการ์ด) · ซ่อนกล่องนี้ (กล่องทั่วไป) — กล่องที่ซ่อนแล้วเอากลับได้จากแถบบน "ซ่อนอยู่ N กล่อง"
- ขนาดตัวอักษร · ฟอนต์ (Google Fonts ภาษาไทย) · ตัวหนา · ตำแหน่ง ซ้าย/กลาง/ขวา · สีตัวอักษร · สีพื้น (กล่อง)
- รูป: ความสูง (mm) · พอดีกรอบ / เต็มกรอบ
- ย้อนกลับ (ปุ่ม + Ctrl+Z ทั้งในหน้าและในพรีวิว) · คืนค่าเดิมทีละกล่อง · คืนค่าทั้งใบ · คัดลอก/วางสไตล์ระหว่างกล่อง
- กรอบเส้นประ/สีฟ้าเป็น `@media screen` → ไม่ติดไปตอนพิมพ์/บันทึก PDF

## วิธีใช้กับเอกสารใหม่
1. ใส่ `data-pp="คีย์"` ที่กล่องใน HTML เอกสาร · การ์ด/แถวที่ซ้ำ ใส่ `data-ci="ลำดับ"` ที่ตัวการ์ด
2. ประกาศทะเบียนกล่อง `PrintPartDef[]` (ดู `QUOTE_CARD_PARTS` ใน `lib/print-part-style.ts`)
3. ใส่ `printPartFontLinks(styles)` ใน `<head>` + `printPartCss(styles, defs)` ท้าย `<style>`
4. หน้าพิมพ์:
```tsx
const pp = usePrintPartEditor({ parts: MY_PARTS, value: layout.partStyles, onChange: (partStyles) => update({ ...layout, partStyles }) });
{pp.bar}
<PrintFrame html={html} onDocLoad={pp.onDocLoad} />
{pp.panel}
```

## ค่าที่เก็บ
- `ReportLayoutSettings.partStyles` = `{ คีย์: { hide, sizePx, font, bold, align, color, bg, imgMm, fit } }` · `"คีย์#ลำดับ"` = เฉพาะการ์ด (เก็บแค่ hide)
- ใบเสนอราคา: จำรายใบในเครื่อง (localStorage `qt-print-view:<id>`) · "บันทึกเป็นค่าเริ่มต้น" = ใบอื่นใช้ด้วย (ตัดค่าเฉพาะการ์ดออก — ลำดับการ์ดแต่ละใบไม่เหมือนกัน)
- ตัวทำความสะอาด `normalizePrintPartStyles` ทิ้งคีย์/ค่าที่ไม่ถูกต้อง (ขนาด 6-60px · รูป 15-140mm · สี #rrggbb · ฟอนต์จากรายการ)

## ห้ามใช้เมื่อ
- แม่แบบในฐานข้อมูล (แบบตาราง) → ตัวออกแบบแม่แบบ
- หน้าเว็บร้าน → `PartStyleEditor` (ผูกธีม/สีร้าน/พรีวิวเว็บ)

## ข้อจำกัด
- ยังไม่ลากย้ายตำแหน่งกล่องอิสระ (เปลี่ยนได้แค่จัดซ้าย/กลาง/ขวา)
- ซ่อนเฉพาะการ์ดอิงลำดับการ์ด — เปลี่ยนการเรียง/เพิ่มลดรายการแล้วการ์ดที่ซ่อนอาจเลื่อน
- ไม่ลง audit log (เป็นค่าหน้าตาการพิมพ์ ไม่ใช่ข้อมูลเอกสาร) · ค่าเริ่มต้นบันทึกผ่าน API เดิมของ report-layout-defaults

## แบบที่บันทึก (PrintPresetMenu · 2026-11-20)
- เมนู "แบบ ▾" ซ้ายสุดของแถบพิมพ์ (`components/print-presets`) — บันทึกหน้าตาทั้งชุดเป็นแบบตั้งชื่อ (ของทีม ต้องมีสิทธิ์ `saved_views.share` / ของฉัน)
- เก็บในระบบมุมมองที่บันทึก `/api/saved-views` (`table_id = "print:qt"`) — ไม่พาค่าเฉพาะใบ (ลำดับที่ลากเอง · ซ่อนเฉพาะการ์ด)
- บันทึกทับ/ลบ ย้อนกลับได้จากแจ้งผล · แก้/ลบได้เฉพาะเจ้าของหรือ `admin.saved_views` (PATCH ตรวจเจ้าของ + จดประวัติแล้ว)
- "ตั้งเป็นค่าเริ่มต้น / ใช้ค่าเริ่มต้น" อยู่ในเมนูนี้ (ค่าเริ่มต้นทั้งระบบเดิม report_layout_defaults)
- หน้าพิมพ์ใบเสนอราคามีปุ่ม "แก้ใบเสนอราคา" (ใบร่างเท่านั้น) เปิดฟอร์มกลาง `QuotationFormModal` ตัวเดียวกับหน้าใบเสนอราคา

## จัดหน้าเอง: ช่องในการ์ด + กล่องบนหน้า (print-blocks · 2026-11-20)
- กติกา/ค่า `lib/print-blocks.ts` · ตัวแก้ `components/print-blocks-editor` (`usePrintBlocksEditor`) · ข้อมูล SKU: `GET /api/quotations/[id]/print-extras` (เฉพาะช่องใน `SKU_FIELD_KEYS` — ไม่มีต้นทุน)
- ช่องในการ์ด: หน้าตา ▾ › ช่องในการ์ด — เพิ่มจาก SKU ที่ผูก / บรรทัด / ข้อความเอง · ลากเรียง (ช่องพื้นฐานเรียงได้ด้วย · รูปบนสุดเสมอ) · แก้ป้าย · ลบ (ย้อนกลับได้) · ค่าว่าง = ไม่วาดแถว
- กล่องบนหน้า: กด "+ เพิ่มกล่องตรงนี้" ในใบ (โชว์เฉพาะบนจอ ไม่ติดตอนพิมพ์) → ข้อความ / รูป (ImageAttachKeys → R2) / เส้นคั่น · วางได้ ใต้หัวกระดาษ · ก่อนรายการ · ท้ายรายการ · ท้ายใบ
- ข้อมูลจากใบ (kind `fields`): ติ๊กช่องของเอกสาร (ลูกค้า เลขที่ใบ วันที่ ยืนราคาถึง พนักงานขาย ยอดรวม …) · จัดแถวเดียว/ทีละบรรทัด/2 คอลัมน์ · แก้ป้าย/ซ่อนป้าย · ค่าว่างไม่พิมพ์ — เอกสารส่ง `pageFields` + `pageValues` (ใบเสนอราคา: `QUOTE_PAGE_FIELDS` / `quotePageValues` ใน lib/quotation-print)
- กล่องข้อความแทรกช่องได้: ปุ่ม "+ ลูกค้า" ใส่ `{ลูกค้า}` → พิมพ์เป็นค่าจริง (`fillPagePlaceholders` · ใช้ `{customer_name}` ก็ได้ · ไม่รู้จัก = คงข้อความไว้)
- กดช่อง/กล่องที่เพิ่ม → แผงแก้หน้าตาเดิม + ปุ่มแก้ข้อความ/เปลี่ยนรูป/ขึ้น-ลง/ย้ายจุดวาง/ลบ
- ค่าเก็บ `cardFields · cardOrder · pageBlocks` ใน ReportLayoutSettings → จำรายใบ + บันทึกเข้า "แบบ" + ค่าเริ่มต้น
- ข้อมูลจริง (2026-11-20): SKU ที่ใช้งาน 12,201 ตัว — มีวัสดุ 15% · ซับใน 12% · อะไหล่ 12% · ซิป 6% · สาย 1% · โลโก้ 0.2% → ช่องพวกนี้มักไม่ขึ้นจนกว่าจะกรอกใน SKU
