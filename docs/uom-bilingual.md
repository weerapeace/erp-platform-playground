# หน่วยนับ 2 ภาษา + รวมหน่วยซ้ำ

เจ้าของสั่ง 2026-11-20: "หลา กับ Yard ซ้ำ ต้องเป็น ไทย = english"

## ใช้ทำอะไร
1 หน่วย = 1 แถวในตาราง `uoms` มีทั้งชื่อไทยและอังกฤษ เช่น **หลา · Yard** · ไม่สร้างแถวแยกตามภาษาอีก

| ช่อง | ความหมาย |
|---|---|
| `name` | ชื่อหลักที่ระบบใช้จับคู่ — เอกสาร ~30 ตาราง (BOM, ใบผลิต, PO/PR, ใบขาย ฯลฯ) เก็บชื่อหน่วยเป็น **ข้อความ** และโค้ดหลายจุดเทียบ "หลา"/"ชิ้น" ตรง ๆ → ห้ามเปลี่ยนชื่อหลักของ หลา/ชิ้น |
| `name_th` / `name_en` | ชื่อที่โชว์ · `display_name` ตั้งอัตโนมัติ (trigger) = "หลา · Yard" |
| `aliases` | ชื่ออื่น คั่นด้วย `,` เช่น `yd, Yard` → ค้นเจอ · ตัวเลือกหน่วยรู้ว่าเอกสารเก่าที่เขียน "Yard" คือหลา · กันสร้างซ้ำ |
| `merged_into` | หน่วยที่ถูกรวมแล้วชี้ไปตัวหลัก (ตัวรอง `active=false` = ถังขยะ) |

## ของกลางที่เกี่ยว
- `lib/uom-names.ts` — `uomLabel` · `normUom` · `findUomClash` (เตือนชื่อชน) · `findDupGroups` (หากลุ่มซ้ำ)
- `components/uom-picker` (UomPicker) — โชว์ 2 ภาษา ค้นได้ทุกชื่อ เก็บ `name`
- `/api/admin/picker?table=uoms` — ค้นใน name/name_th/name_en/aliases อัตโนมัติ + ซ่อนหน่วยที่ `active=false`
- หน้า `/master/uoms` — ปุ่ม "รวมหน่วยซ้ำ" (`app/master/uoms/merge-modal.tsx`) + ช่องชื่อเตือนทันทีถ้าชนหน่วยเดิม

## รวมหน่วย
`POST /api/master/uoms/merge { primary_id, secondary_id }` (สิทธิ์ products.edit) → ฟังก์ชัน DB `uom_merge` ทำทีเดียวจบ:
- ย้าย `skus_v2.uom_id/purchase_uom_id`, `product_skus` (+ชื่อ/odoo_id), `product_families.default_uom_id` + `prefix_defaults` (หน่วยตามประเภทแท็ก) จากตัวรอง → ตัวหลัก
- ชื่อตัวรองเข้าไปเป็น `aliases` ของตัวหลัก · ตัวรอง `active=false`, `merged_into`
- จดลง `uom_merges` (รายการ id ที่ย้าย) + audit `uom_merge`
- **ไม่แก้ข้อความหน่วยในเอกสารเก่า** (เจ้าของเลือก 2026-11-20) — ใช้ aliases แทน

ย้อนกลับ: `POST { undo: merge_id }` → `uom_merge_undo` คืนเฉพาะแถวที่ยังชี้ตัวหลัก (ถ้ามีคนเปลี่ยนหน่วยไปแล้วหลังรวม = ไม่ทับ) + audit `uom_merge_undo` · ปุ่มย้อนในแจ้งผล และในประวัติการรวมของป๊อป

## ห้ามใช้เมื่อไหร่
- ห้ามสร้างหน่วยใหม่เพื่อแปลภาษา — ใส่ `name_en` / `aliases` ในหน่วยเดิม
- หน่วยที่ "ใกล้กัน" แต่ไม่เท่ากัน (ผืน vs แผ่น, cm vs mm) ไม่ใช่หน่วยซ้ำ ห้ามรวม

## ข้อจำกัด
- การแปลงหน่วย (1 หลา = 0.9144 m) ยังไม่อยู่ที่นี่ (`uom_conversions` ยังว่าง · คำนวณผ้าใช้ `lengthUnitCm` ใน lib/design-library-cost)
- ใบพิมพ์/เอกสารเก่าที่เก็บชื่อหน่วยเป็นข้อความ ยังโชว์ชื่อเดิม (เช่น Units)
