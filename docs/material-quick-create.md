# เลือก + เพิ่มวัสดุตีราคาด่วน (`components/material-quick-create`)

เจ้าของขอ 2026-11-17 จากหน้า "แกะจากรูป": ค้นวัสดุแล้วขึ้น "ไม่พบรายการ" ต้องออกไปเพิ่มที่หน้าอื่นก่อน → ตอนนี้เพิ่มได้ในช่องเลย

## ใช้ทำอะไร
- `MaterialAddSelect` = ช่องค้นหาวัสดุตีราคา (`design_price_items`) ใช้ `SearchableSelect` กลาง
  - พิมพ์ชื่อที่ไม่มี → "＋ เพิ่มวัสดุใหม่" → แผงเล็ก: แก้ชื่อ · เลือกชนิดวัสดุ (`material_groups`, เว้นได้) · เตือน "ชื่อคล้ายที่มีอยู่แล้ว" กดใช้ตัวนั้นแทนได้
  - กด "เพิ่ม + เลือกให้ชิ้นนี้" → สร้าง แล้วเรียก `onCreated` + `onPick` ให้เลย
- `MaterialQuickCreate` = แผงสร้างอย่างเดียว (เช่น วัสดุที่ AI อ่านจากตัวเขียนได้แต่ไม่มีในรายการ)
- `lib/material-quick-create`: `similarMaterials(name, list)` (ไม่นับช่องว่าง/เครื่องหมาย · ชื่อหนึ่งอยู่ในอีกชื่อ · พิมพ์ผิด 1-2 ตัว) · `createDesignMaterial(name, groupId?)`

## ใช้เมื่อไหร่ / ห้ามใช้
- ใช้: แผงชิ้นสตูดิโอแพทเทิร์น (กระดาน `ShapeEditor` + `PhotoModal`) · ใบงานออกแบบ (สร้างจาก dropdown ตีราคา ใช้ `createDesignMaterial`)
- ห้ามใช้: วัตถุดิบ/SKU จริงที่ต้องอนุมัติ → `MaterialRequestForm` · เลือกวัตถุดิบ BOM → `MaterialPicker`

## ตั้งค่าสำคัญ
```tsx
<MaterialAddSelect materials={[{ id, name, sub }]} exclude={ids} onPick={(m) => …}
  onCreated={(m) => setMaterials((l) => [...l, m])} />
```
- **ไม่ส่ง `onCreated` = ค้นเลือกอย่างเดียว** · หน้าแม่ต้องต่อวัสดุใหม่เข้ารายการเอง (ไม่งั้นค้นครั้งหน้าไม่เจอ)
- สตูดิโอแพทเทิร์น: `PatternStudio`/`ShapeEditor`/`PhotoModal` รับ `onMaterialCreated` · หน้า `/pattern-studio/[id]` ส่งให้เฉพาะคนที่แก้ได้

## สิทธิ์ / ประวัติ
- สร้างผ่าน `POST /api/master-v2/design-price-items` → ด่าน `products.create` + บันทึก audit อยู่ที่ API กลางแล้ว
- หน้าจอซ่อนปุ่มเพิ่มเมื่อไม่มีสิทธิ์ (`useCanCreateMaterial`) แล้วขึ้น "ให้หัวหน้าเพิ่มที่หน้าวัสดุตีราคา"

## ข้อจำกัด
- สร้างแค่ ชื่อ + ชนิด · ราคา/หน้ากว้าง/หน่วย ไปใส่ทีหลังที่หน้าวัสดุตีราคา
- ตัวเตือนชื่อคล้ายเทียบเฉพาะรายการที่หน้านั้นโหลดมา (วัสดุที่ปิดใช้งานไม่ถูกเทียบ)
