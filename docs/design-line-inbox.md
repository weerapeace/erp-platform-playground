# งานออกแบบจากไลน์ (กล่อง "จากไลน์" บน Design Dashboard)

> ไอเดีย (ยังไม่ใช่งาน) ส่งคนละกลุ่ม → กลุ่ม "ส่งไอเดีย" (slot design_idea) เข้ากล่องรอคัดในหน้าไอเดีย — ดู [design-ideas.md](design-ideas.md)

เจ้าของเลือกแบบ A (2026-11-03): คนส่งงานพิมพ์ข้อความ + ส่งรูปใน **กลุ่มไลน์ "ส่งงานออกแบบ"** → บอทเก็บเป็นร่าง → ทีมออกแบบกด **"เปิดใบงาน"** บน Design Dashboard

## ใช้ทำอะไร

- รับงานออกแบบจากไลน์เข้าระบบโดยไม่ต้องให้ใครพิมพ์ใหม่
- ร่างยังไม่ใช่ใบงานจริง เลข DS เกิดตอนคนกดบันทึกเท่านั้น ข้อความคุยเล่นจึงไม่กินเลข
- บอทตอบกลับในกลุ่มแบบ reply ซึ่ง**ไม่เสียโควตา** 300 ข้อความ/เดือน และไม่มี push แจ้งเตือน เพราะเจ้าของเลือกไม่แจ้งตอนเปิดใบงาน

## เส้นทาง

1. ข้อความ/รูปในกลุ่ม slot `design_intake` เข้า webhook กลาง `/api/china-pay/line-webhook` (งานที่ 3)
2. `lib/design-line-inbox.ts` `handleDesignEvents`
   - รูป: ดึงจากไลน์ด้วยโทเคนบอท (id ปลอมดึงไม่ได้ = ไม่บันทึก) → เก็บใน R2 `design-inbox/YYYY-MM/uuid.ext` → เก็บ sha256 ไว้จับรูปซ้ำ
   - ข้อความ: ต้องเป็นสมาชิกกลุ่มจริง (ถามชื่อคนส่งจากไลน์ไม่ได้ = ไม่บันทึก)
   - RPC `design_line_inbox_ingest` ล็อกต่อ กลุ่ม+คนส่ง: ของคนเดิมห่างกันไม่เกิน 5 นาทีรวมเป็นร่างเดียว (นับจากชิ้นล่าสุด) ส่วนข้อความที่ไลน์ส่งซ้ำจะไม่รับ
   - ข้อความขึ้นต้น **"งานใหม่"** (`#งานใหม่` / `new job` ก็ได้ · `splitNewJobKeyword`) = เปิดร่างใหม่ทันที (`p_force_new`) แล้วตัดคำนำออกจากข้อความที่เก็บ · รูปที่ตามมาเข้าร่างใหม่นี้
3. AI (`gpt-4.1-mini`, env `OPENAI_DESIGN_MODEL`) เดา ชื่องาน / แบรนด์ (เทียบกับรายชื่อแบรนด์ในระบบ) / กำหนดส่ง · `sanitizeDesignAi` ตัดค่าที่ไม่สมเหตุผลทิ้ง
   - อ่าน **ครั้งเดียวตอนจบชุด** (`finishBatchIfDone`): มีข้อความใหม่หลังอ่านครั้งล่าสุด (อ่านทั้งร่าง เฉพาะข้อความ) · ร่างที่มีแต่รูปและยังไม่เคยอ่าน (ตั้งชื่อจากรูปแรก) — ส่งต่อแชตลูกค้า 10 ข้อความ = อ่านรอบเดียว
   - prompt บอกว่าข้อความอาจเป็นแชตลูกค้าที่ส่งต่อมา (ลูกค้าขอสินค้าสั่งทำ = งาน · วันที่ลูกค้าต้องการ = วันส่ง) · อ่านใหม่แล้วไม่เจอค่า = เก็บค่าเดิมไว้ ไม่ล้าง
   - ข้อความล้วนที่ AI ว่าไม่ใช่งาน: บอทเงียบ แล้วย้ายไป "ไม่ใช่งาน" ให้เอง (`rejected_by='AI'`) ถ้าภายใน 5 นาทีส่งรูปหรือข้อความตามมา ระบบคืนร่างเข้ากล่องให้
4. บอทตอบ **1 ครั้งต่อ 1 ชุดที่ส่งติดกัน**: หลังรับแต่ละชิ้นรอเงียบ 6 วินาที (`REPLY_QUIET_MS`) แล้วเช็กว่าชิ้นนี้ยังเป็นชิ้นล่าสุดของร่างไหม — ใช่ = ตอบพร้อมจำนวนรูปรวม · ไม่ใช่ = ให้ชิ้นที่ตามมาตอบแทน
   - `decideDesignReply`: ตอบครั้งแรกเสมอ · ตอบอีกเมื่อมีรูปเพิ่ม ("อัปเดตงานแล้ว · รูปเพิ่ม +N") หรือข้อความแรกมาหลังรูป · ข้อความเพิ่มเติมเฉย ๆ (เช่น "ขอบคุณ") = เงียบ
   - จำสิ่งที่ตอบไปแล้วใน `replied_at / replied_images / replied_text`
5. บน Design Dashboard ปุ่ม **จากไลน์ (n)** (มือถือ = ไอคอนมีตัวเลข + เมนู ⋯) เปิดลิ้นชัก `components/design-dashboard/line-inbox.tsx`
6. กด **เปิดใบงาน** จะเปิดฟอร์มสร้างใบงานเดิม (`DesignSheetsDetail createMode prefill`) ที่กรอกให้แล้ว พอบันทึกจะเป็น `POST /api/design-sheets` + `line_inbox_id`
   - ชื่อ/แบรนด์/วันส่ง = จาก AI · **ข้อความไลน์ทั้งหมด → ช่อง Note** (ตามเดิมทุกบรรทัด มักเป็นแชตลูกค้าที่ส่งต่อมา · กาง "ใส่ข้อมูลอื่น" ให้เห็นเลย · ช่องสูงตามจำนวนบรรทัด) · "รายละเอียดงาน" เว้นว่างให้ทีมสรุปเอง (เจ้าของเลือก 2026-11-03)
   - ⚠️ แชตลูกค้าที่มีเบอร์โทร/ที่อยู่ จะอยู่ใน Note ของใบงาน (คนที่ดูใบงานได้เห็นด้วย)
   - จองร่างก่อนออกเลข (`claimInboxForSheet`) กันสองคนกดพร้อมกัน ถ้าสร้างไม่สำเร็จจะคืนร่างให้
   - ผูกรูปจากไลน์เข้าใบงานใน `erp_playground_attachments` โดยใช้ key เดิม ไม่อัปซ้ำ รูปแรกเป็นรูปหลัก
   - บันทึกเสร็จแล้วกลับไปที่กล่อง ทำงานถัดไปต่อได้เลย
7. กด **รวมกับงาน…** (รูปส่งช้าเกิน 5 นาที / คนอื่นส่งรูปช่วย) — ป๊อปเลือกปลายทาง งานที่ป้าย "อาจซ้ำ" ชี้ไว้ขึ้นก่อนพร้อมป้าย "แนะนำ"
   - ร่างอื่นที่รอ → RPC `design_line_inbox_merge` (ล็อก 2 แถว · ต่อข้อความ/รูป/เลขข้อความไลน์ท้ายร่างปลายทาง) → ร่างนี้เป็น `merged` (`merged_into`) หายจากกล่อง · มีข้อความติดมา = AI อ่านร่างปลายทางใหม่
   - ใบงานที่มีแล้ว (รายการบนบอร์ด ค้นด้วยเลข DS/ชื่อ/แบรนด์) → `attachInboxToSheet` แนบรูปต่อท้าย (ไม่ทับรูปหลัก) · ร่างย้ายไป "เปิดใบงานแล้ว" ผูกใบนั้น · ข้อความไม่แตะรายละเอียดใบงาน

## ตั้งค่า (แอดมิน)

- เลือกกลุ่มที่ลิ้นชักได้เลย (ของกลาง `components/line-group-setup` เป็นตัวเดียวกับหน้าคำสั่งซื้อจากไลน์) หรือที่ศูนย์ LINE ช่อง "กลุ่มส่งงานออกแบบ"
- กลุ่มใหม่: เชิญบอท "พนักงานลงบิลจีนลูก้า" เข้ากลุ่ม → พิมพ์อะไรก็ได้ 1 ครั้ง → 🔄 รีเฟรช → กด "ใช้กลุ่มนี้"
- แนะนำ: ใช้กลุ่มนี้ส่งงานอย่างเดียว เพราะทุกข้อความในกลุ่มเข้ากล่อง · ใส่รหัสลับบอท (Channel secret) ที่ศูนย์ LINE

## ป้าย "อาจซ้ำ"

- รูปเดียวกัน (sha256) กับร่างอื่นหรือใบที่เปิดไปแล้ว ภายใน 90 วัน
- ชื่อคล้ายใบงานที่สร้างใน 90 วัน (≥ 0.75) หรือคล้ายร่างอื่นในกล่อง (≥ 0.8) ใช้ `nameSimilarity` ของกลาง
- ป้ายนี้แค่เตือน ไม่บล็อกการเปิดใบงาน

## ทางสำรอง

ลิงก์ "วางข้อความ/รูปเอง" ท้ายลิ้นชักใช้ตอนไลน์มีปัญหาหรือใช้ทดสอบ วางข้อความ + รูปได้สูงสุด 6 รูป รูปละไม่เกิน 4MB แล้ว AI จะอ่านให้ ร่างที่วางเองจะไม่ถูกตีตกอัตโนมัติ

## ข้อจำกัดที่รู้

- ส่ง 2 งานติดกันภายใน 5 นาที (คนเดิม) โดยไม่พิมพ์ "งานใหม่" นำหน้า จะรวมเป็นร่างเดียว (ยังไม่มีปุ่มแยกรูปออกจากร่าง)
- รูปชุดใหญ่บนเน็ตช้า (รูปถัดไปมาช้ากว่า 6 วินาที) บอทอาจตอบ 2 ครั้ง: ครั้งแรกรูปเท่าที่มา + "อัปเดต · รูปเพิ่ม +N" — จำนวนรวมยังถูก
- บอทมองไม่เห็นรูปใน "อัลบั้ม" / "โน้ต" ของกลุ่ม และไฟล์ที่ส่งแบบ "ไฟล์" — ต้องส่งเป็นรูปในแชต
- ส่งต่อแชตลูกค้า: ไลน์ส่งมาในชื่อคนที่ส่งต่อ (ไม่บอกว่าบรรทัดไหนลูกค้าพิมพ์) → Note เรียงตามลำดับที่ส่งต่อมาเท่านั้น
- ตอบกลับแบบอ้างข้อความบอท (quote) เพื่อเพิ่มรูปใช้ไม่ได้ — ไลน์ไม่บอกว่ารูปอ้างข้อความไหน จึงใช้ปุ่ม "รวมกับงาน…" แทน
- ลิงก์ "ดูในระบบ" ถ้ายังไม่ login หลังเข้าสู่ระบบจะไม่เปิดกล่องให้เอง (หน้า login ตัด `?inbox=1`) กดปุ่ม "จากไลน์" เองได้
- ร่างที่ตีตกแล้วยังเก็บรูปไว้ใน R2 (กู้คืนได้) ยังไม่มีงานลบรูปเก่าอัตโนมัติ
