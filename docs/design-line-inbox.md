# งานออกแบบจากไลน์ (กล่อง "จากไลน์" บน Design Dashboard)

เจ้าของเลือกแบบ A (2026-11-03): คนส่งงานพิมพ์ข้อความ + ส่งรูปใน **กลุ่มไลน์ "ส่งงานออกแบบ"** → บอทเก็บเป็นร่าง → ทีมออกแบบกด **"เปิดใบงาน"** บน Design Dashboard

## ใช้ทำอะไร

- รับงานออกแบบจากไลน์เข้าระบบโดยไม่ต้องให้ใครพิมพ์ใหม่
- ร่างยังไม่ใช่ใบงานจริง เลข DS เกิดตอนคนกดบันทึกเท่านั้น ข้อความคุยเล่นจึงไม่กินเลข
- บอทตอบกลับในกลุ่มแบบ reply ซึ่ง**ไม่เสียโควตา** 300 ข้อความ/เดือน และไม่มี push แจ้งเตือน เพราะเจ้าของเลือกไม่แจ้งตอนเปิดใบงาน

## เส้นทาง

1. ข้อความ/รูปในกลุ่ม slot `design_intake` เข้า webhook กลาง `/api/china-pay/line-webhook` (งานที่ 3)
2. `lib/design-line-inbox.ts` `handleDesignEvents`
   - รูป: ดึงจากไลน์ด้วยโทเคนบอท (id ปลอมดึงไม่ได้ = ไม่บันทึก) → เก็บใน R2 `design-inbox/YYYY-MM/uuid.ext` → เก็บ sha256 ไว้จับรูปซ้ำ
   - ข้อความ: ต้องเป็นสมาชิกกลุ่มจริง (ถามชื่อคนส่งจากไลน์ไม่ได้ = ไม่บันทึก)
   - RPC `design_line_inbox_ingest` ล็อกต่อ กลุ่ม+คนส่ง: ของคนเดิมห่างกันไม่เกิน 5 นาทีรวมเป็นร่างเดียว ส่วนข้อความที่ไลน์ส่งซ้ำจะไม่รับ
3. AI (`gpt-4.1-mini`, env `OPENAI_DESIGN_MODEL`) เดา ชื่องาน / แบรนด์ (เทียบกับรายชื่อแบรนด์ในระบบ) / กำหนดส่ง · `sanitizeDesignAi` ตัดค่าที่ไม่สมเหตุผลทิ้ง
   - ข้อความล้วนที่ AI ว่าไม่ใช่งาน: บอทเงียบ แล้วย้ายไป "ไม่ใช่งาน" ให้เอง (`rejected_by='AI'`) ถ้าภายใน 5 นาทีส่งรูปหรือข้อความตามมา ระบบคืนร่างเข้ากล่องให้
4. บอทตอบครั้งเดียวตอนเปิดร่างใหม่ และตอบอีกครั้งตอนข้อความแรกตามหลังรูป เพื่อให้เห็นชื่อ แบรนด์ และวันส่ง
5. บน Design Dashboard ปุ่ม **จากไลน์ (n)** (มือถือ = ไอคอนมีตัวเลข + เมนู ⋯) เปิดลิ้นชัก `components/design-dashboard/line-inbox.tsx`
6. กด **เปิดใบงาน** จะเปิดฟอร์มสร้างใบงานเดิม (`DesignSheetsDetail createMode prefill`) ที่กรอกให้แล้ว พอบันทึกจะเป็น `POST /api/design-sheets` + `line_inbox_id`
   - จองร่างก่อนออกเลข (`claimInboxForSheet`) กันสองคนกดพร้อมกัน ถ้าสร้างไม่สำเร็จจะคืนร่างให้
   - ผูกรูปจากไลน์เข้าใบงานใน `erp_playground_attachments` โดยใช้ key เดิม ไม่อัปซ้ำ รูปแรกเป็นรูปหลัก
   - บันทึกเสร็จแล้วกลับไปที่กล่อง ทำงานถัดไปต่อได้เลย

## ตั้งค่า (แอดมิน)

- เลือกกลุ่มที่ลิ้นชักได้เลย (ของกลาง `components/line-group-setup` เป็นตัวเดียวกับหน้าคำสั่งซื้อจากไลน์) หรือที่ศูนย์ LINE ช่อง "กลุ่มส่งงานออกแบบ"
- กลุ่มใหม่: เชิญบอท "พนักงานลงบิลจีนลูก้า" เข้ากลุ่ม → พิมพ์อะไรก็ได้ 1 ครั้ง → 🔄 รีเฟรช → กด "ใช้กลุ่มนี้"
- แนะนำ: ใช้กลุ่มนี้ส่งงานอย่างเดียว เพราะทุกข้อความในกลุ่มเข้ากล่อง · ใส่รหัสลับบอท (Channel secret) ที่ศูนย์ LINE

## ป้าย "อาจซ้ำ"

- รูปเดียวกัน (sha256) กับร่างอื่นหรือใบที่เปิดไปแล้ว ภายใน 90 วัน
- ชื่อคล้ายใบงานที่สร้างใน 90 วัน (≥ 0.75) หรือคล้ายร่างอื่นในกล่อง (≥ 0.8) ใช้ `nameSimilarity` ของกลาง
- ป้ายนี้แค่เตือน ไม่บล็อกการเปิดใบงาน

## ทางสำรอง

ลิงก์ "วางข้อความ/รูปเอง" ท้ายลิ้นชักใช้ตอนไลน์มีปัญหาหรือใช้ทดสอบ วางข้อความ + รูปได้สูงสุด 6 รูป รูปละไม่เกิน 4MB แล้ว AI จะอ่านให้ ร่างที่วางเองจะไม่ถูกตีตกอัตโนมัติ

## ข้อจำกัดที่รู้

- ส่ง 2 งานติดกันภายใน 5 นาที (คนเดิม) จะรวมเป็นร่างเดียว ต้องแยกเองตอนเปิดใบงาน
- ลิงก์ "ดูในระบบ" ถ้ายังไม่ login หลังเข้าสู่ระบบจะไม่เปิดกล่องให้เอง (หน้า login ตัด `?inbox=1`) กดปุ่ม "จากไลน์" เองได้
- ร่างที่ตีตกแล้วยังเก็บรูปไว้ใน R2 (กู้คืนได้) ยังไม่มีงานลบรูปเก่าอัตโนมัติ
