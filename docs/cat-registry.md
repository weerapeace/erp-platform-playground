# 🐾 ทะเบียนแมว (แอป "งานอื่นๆ")

หน้า `/misc/cats` · ติดตั้งเป็นแอปบนมือถือได้ (`/solo/misc/cats` — ปุ่ม "ติดตั้งบนมือถือ" ในหน้า)
เจ้าของสั่ง 2026-11-24 · เลือกแบบ A (แมว + วัคซีน/ยา + คลินิก ก่อน) · ใช้ร่วมกันในบ้าน · ข้อเสนอ 1–6 · รูปแมวใหญ่ ๆ

## ใช้ทำอะไร
เก็บข้อมูลแมวแต่ละตัว ติดตามวัคซีน ยาถ่ายพยาธิ ยาหยดกันเห็บหมัด น้ำหนัก และรายชื่อคลินิก
หน้าแรกบอก "ใกล้ถึงกำหนด" (ภายใน 30 วัน รวมที่เลยกำหนด) + แมวทุกตัวเป็นการ์ดรูปใหญ่

## รอบ 1 (ขึ้นแล้ว)
| ส่วน | ทำอะไรได้ |

## กติกาสำคัญ (lib/cats.ts — ที่เดียว)
- **นับครบกำหนดเฉพาะครั้งล่าสุด**: วัคซีนกลุ่มตามชื่อ (ไม่สนตัวพิมพ์/ช่องว่าง) · ยากลุ่มตามชนิด (เปลี่ยนยี่ห้อก็ยังนับรอบเดียวกัน)
- "ฉีดแล้ว" ของวัคซีน: ใช้ช่วงห่างเดิม (วันนัดเดิม − วันที่ฉีดเดิม) ไม่มีวันนัด = 1 ปี · ยาใช้รอบเดิม · ค่าใช้จ่ายไม่คัดลอก
- วันนัดถัดไปต้องไม่ก่อนวันที่ให้ · น้ำหนัก 0–30 กก. · เงินติดลบไม่ได้
- แมวที่อยู่ในถังขยะ: ประวัติยังอยู่ แต่ไม่ขึ้น "ใกล้ถึงกำหนด"

## ข้อมูล
ตาราง `cats` · `cat_clinics` · `cat_vaccinations` · `cat_treatments` · `cat_weights` (migration `202612250600_cat_registry.sql`)

API (ทุกตัว guardApi + audit `changes` จาก → เป็น):
- `GET /api/cats` (`?trash=1`) — ทั้งชุดในครั้งเดียว (ข้อมูลบ้านมีไม่มาก)

- `PATCH /api/cats/<kind>/<id>` (`is_active:true` = กู้คืน) · `DELETE` (ถังขยะ) · `DELETE ?hard=1` (ลบถาวร เฉพาะของในถังขยะ)

## รอบ 2 — อาหาร / ทราย / สต็อก (แท็บ "อาหาร/ทราย" · กติกา `lib/cats-supplies.ts`)
| ส่วน | ทำอะไรได้ |
|---|---|
| ของที่บ้าน | อาหารเม็ด (ขนาดถุง กรัม/กก. · กรัมต่อวัน · ราคาต่อถุง) · อาหารเปียก (เกรวี่/เจลลี่ · ซอง/กระป๋อง · กรัมต่อชิ้น · ชิ้นต่อแพ็ค · ราคาต่อชิ้นหรือต่อแพ็ค) · ทราย (ขนาด · 1 ถุงใช้กี่วัน · ราคา) · ร้านประจำ + ลิงก์สั่งซื้อ · แมวที่ใช้ |
| ตารางมื้อ | มื้อละกี่ชิ้น เกรวี่/เจลลี่ (ครึ่งชิ้นได้ · กองกลางทุกตัว · เพิ่ม/ลบ/ตั้งชื่อมื้อ ≤8) + % อาหารเม็ดเมื่อให้เปียกด้วย |
| สต็อก | เหลือเท่าไหร่ · อีกกี่วันหมด · หมดวันไหน · ต่อเดือนต้องซื้อกี่แพ็ค/ถุง · ค่าใช้จ่ายต่อเดือน · บอกช่องที่ยังไม่ได้ตั้ง · สรุปเกรวี่/เจลลี่แยกกัน |
| ซื้อเข้า | บวกสต็อกเอง (เปียก: กรอกแพ็ค → คิดเป็นชิ้น) · ราคาที่จ่ายเติมให้ (แก้ได้) · นับเป็นค่าใช้จ่ายเดือนนั้น · ลบใบซื้อ = สต็อกลดตาม |
| นับสต็อก | ใส่จำนวนที่นับได้จริง → เริ่มนับวันหมดใหม่จากตอนนี้ (ย้อนกลับได้) |
| หน้าแรก | การ์ดตัวเลข 3 ใบ + "ของใกล้หมด" (ภายในวันเตือน ค่าเริ่ม 7) พร้อมปุ่มสั่งซื้อ/ซื้อเข้า |

**สต็อกไม่ต้องตัดเอง:** คงเหลือ = นับล่าสุด (`stock_base_qty` ณ `stock_base_at`) + ซื้อเข้าที่บันทึกหลังจากนั้น − ใช้ต่อวัน × จำนวนวัน
· เปียกหลายยี่ห้อชนิดเดียวกัน = แบ่งการใช้เท่ากัน · เปลี่ยนตารางมื้อ = วันหมดคิดใหม่ทันที (ย้อนหลังด้วย — นับสต็อกใหม่ถ้าตัวเลขเพี้ยน)

## รอบ 4 — แจ้งเตือน LINE (แท็บ "แจ้งเตือน" · `lib/cats-notify.ts` · `app/api/cron/cat-reminders`)
