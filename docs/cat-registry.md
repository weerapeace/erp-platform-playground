# 🐾 ทะเบียนแมว (แอป "งานอื่นๆ")

หน้า `/misc/cats` · ติดตั้งเป็นแอปบนมือถือได้ (`/solo/misc/cats` — ปุ่ม "ติดตั้งบนมือถือ" ในหน้า)
เจ้าของสั่ง 2026-11-24 · เลือกแบบ A (แมว + วัคซีน/ยา + คลินิก ก่อน) · ใช้ร่วมกันในบ้าน · ข้อเสนอ 1–6 · รูปแมวใหญ่ ๆ

## ใช้ทำอะไร
เก็บข้อมูลแมวแต่ละตัว ติดตามวัคซีน ยาถ่ายพยาธิ ยาหยดกันเห็บหมัด น้ำหนัก และรายชื่อคลินิก
หน้าแรกบอก "ใกล้ถึงกำหนด" (ภายใน 30 วัน รวมที่เลยกำหนด) + แมวทุกตัวเป็นการ์ดรูปใหญ่

## รอบ 1 (ขึ้นแล้ว)
| ส่วน | ทำอะไรได้ |
|---|---|
| แมว | เพิ่ม/แก้ (รูป ชื่อ เพศ วันเกิด สายพันธุ์ สี ทำหมัน ไมโครชิป หมายเหตุ) · รูปกดดูเต็มจอ · มือถือถ่ายรูปได้ |
| วัคซีน | ชื่อ (มีคำแนะนำ) วันที่ฉีด คลินิก วันนัดถัดไป (ปุ่ม +3 สัปดาห์/+1 เดือน/+1 ปี/+3 ปี) ค่าใช้จ่าย |
| ยา | ถ่ายพยาธิ / หยดกันเห็บหมัด · รอบ (ปุ่ม 1/3/6 เดือน/ปี) → คิดวันครบกำหนดให้ |
| ปุ่ม "ฉีดแล้ว / ให้ยาแล้ว" | กดเดียว = บันทึกครั้งใหม่วันนี้ + วันนัดถัดไปตามรอบเดิม (กดพลาดกด "ย้อนกลับ" ในแจ้งผล) |
| น้ำหนัก | ชั่งทีละตัว หรือ "ชั่งทุกตัว" หน้าเดียว · กราฟเส้นแนวโน้ม + ขึ้น/ลงจากครั้งก่อน |
| คลินิก | ชื่อ เบอร์ (กดโทร) ที่อยู่ ลิงก์แผนที่ ฉุกเฉิน 24 ชม. (ขึ้นก่อน) |
| ปฏิทิน | วันนัด (แดง/ส้ม/เขียว) + วันที่ให้ไปแล้ว (เทา) — ของกลาง DocCalendar |
| ถังขยะ | ทุกอย่างที่ลบมาอยู่ที่นี่ก่อน · กู้คืน · ลบถาวร (ลบแมวถาวร = พิมพ์ชื่อยืนยัน) |

## กติกาสำคัญ (lib/cats.ts — ที่เดียว)
- **นับครบกำหนดเฉพาะครั้งล่าสุด**: วัคซีนกลุ่มตามชื่อ (ไม่สนตัวพิมพ์/ช่องว่าง) · ยากลุ่มตามชนิด (เปลี่ยนยี่ห้อก็ยังนับรอบเดียวกัน)
- "ฉีดแล้ว" ของวัคซีน: ใช้ช่วงห่างเดิม (วันนัดเดิม − วันที่ฉีดเดิม) ไม่มีวันนัด = 1 ปี · ยาใช้รอบเดิม · ค่าใช้จ่ายไม่คัดลอก
- วันนัดถัดไปต้องไม่ก่อนวันที่ให้ · น้ำหนัก 0–30 กก. · เงินติดลบไม่ได้
- แมวที่อยู่ในถังขยะ: ประวัติยังอยู่ แต่ไม่ขึ้น "ใกล้ถึงกำหนด"

## ข้อมูล
ตาราง `cats` · `cat_clinics` · `cat_vaccinations` · `cat_treatments` · `cat_weights` (migration `202612250600_cat_registry.sql`)
ทุกตารางมี `is_active` + `deleted_at` (ลบแบบเก็บไว้ก่อน) · RLS เปิด ไม่มี policy → เข้าผ่าน API เท่านั้น

API (ทุกตัว guardApi + audit `changes` จาก → เป็น):
- `GET /api/cats` (`?trash=1`) — ทั้งชุดในครั้งเดียว (ข้อมูลบ้านมีไม่มาก)
- `POST /api/cats/<kind>` · `POST /api/cats/weights {items}` (ชั่งหลายตัว)
- `PATCH /api/cats/<kind>/<id>` (`is_active:true` = กู้คืน) · `DELETE` (ถังขยะ) · `DELETE ?hard=1` (ลบถาวร เฉพาะของในถังขยะ)

## รอบ 2 — อาหาร / ทราย / สต็อก (แท็บ "อาหาร/ทราย" · กติกา `lib/cats-supplies.ts`)
| ส่วน | ทำอะไรได้ |
|---|---|
| ของที่บ้าน | อาหารเม็ด (ขนาดถุง กรัม/กก. · กรัมต่อวัน · ราคาต่อถุง) · อาหารเปียก (เกรวี่/เจลลี่ · ซอง/กระป๋อง · กรัมต่อชิ้น · ชิ้นต่อแพ็ค · ราคาต่อชิ้นหรือต่อแพ็ค) · ทราย (ขนาด · 1 ถุงใช้กี่วัน · ราคา) · ร้านประจำ + ลิงก์สั่งซื้อ · แมวที่ใช้ |
| ตารางมื้อ | มื้อละกี่ชิ้น เกรวี่/เจลลี่ (ครึ่งชิ้นได้ · กองกลางทุกตัว · เพิ่ม/ลบ/ตั้งชื่อมื้อ ≤8) + % อาหารเม็ดเมื่อให้เปียกด้วย |
| สต็อก | เหลือเท่าไหร่ · อีกกี่วันหมด · หมดวันไหน · ต่อเดือนต้องซื้อกี่แพ็ค/ถุง · ค่าใช้จ่ายต่อเดือน · บอกช่องที่ยังไม่ได้ตั้ง · สรุปเกรวี่/เจลลี่แยกกัน |
| ซื้อเข้า | บวกสต็อกเอง (เปียก: กรอกแพ็ค → คิดเป็นชิ้น) · ราคาที่จ่ายเติมให้ (แก้ได้) · นับเป็นค่าใช้จ่ายเดือนนั้น · ลบใบซื้อ = สต็อกลดตาม |
| นับสต็อก | ใส่จำนวนที่นับได้จริง → เริ่มนับวันหมดใหม่จากตอนนี้ (ย้อนกลับได้) |
| หน้าแรก | การ์ดตัวเลข 3 ใบ + "ของใกล้หมด" (ภายในวันเตือน ค่าเริ่ม 7) พร้อมปุ่มสั่งซื้อ/ซื้อเข้า |

**สต็อกไม่ต้องตัดเอง:** คงเหลือ = นับล่าสุด (`stock_base_qty` ณ `stock_base_at`) + ซื้อเข้าที่บันทึกหลังจากนั้น − ใช้ต่อวัน × จำนวนวัน
· เปียกหลายยี่ห้อชนิดเดียวกัน = แบ่งการใช้เท่ากัน · เปลี่ยนตารางมื้อ = วันหมดคิดใหม่ทันที (ย้อนหลังด้วย — นับสต็อกใหม่ถ้าตัวเลขเพี้ยน)

## รอบ 3 — หาหมอ / ค่าใช้จ่าย (`lib/cats-costs.ts`)
- หน้าแมว แท็บ "หาหมอ": วันที่ คลินิก อาการ วินิจฉัย ยาที่ได้ ค่ารักษา รูปใบเสร็จ (กดดูเต็มจอ)
- แท็บ "ค่าใช้จ่าย": เลือกเดือน · รวม · กราฟ 6 เดือน (ของกลาง SimpleBarChart) · แยกหมวด · แยกแมว · รายการทั้งเดือน
  - รวมจาก ซื้อเข้า · วัคซีน · ยา · หาหมอ อัตโนมัติ + "จดค่าใช้จ่าย" เอง (ขนม · ของเล่น · อาบน้ำตัดขน · ค่าหมอ · อื่นๆ · ระบุแมวหรือส่วนกลาง)
  - แยกตามแมว: ของใช้ที่ระบุแมว แบ่งเท่ากันตามรายชื่อ · ส่วนกลาง/ไม่ระบุ แบ่งเท่ากันทุกตัวที่ยังอยู่

## รอบ 4 — แจ้งเตือน LINE (แท็บ "แจ้งเตือน" · `lib/cats-notify.ts` · `app/api/cron/cat-reminders`)
- ทุกเช้า 08:00 (vercel.json `0 1 * * *`) ส่ง **1 ข้อความ** เข้ากลุ่ม LINE ของบ้าน เฉพาะวันที่มีเรื่องถึงจุดเตือน:
  วัคซีน/ยา = อีก N วัน (ค่าเริ่ม 3) · พรุ่งนี้ · วันนี้ · อาหาร/ทราย = อีก N วัน (ค่าเริ่ม 7) · 3 วัน · 1 วัน · หมดวันนี้ (+ลิงก์ร้าน)
  — หมดไปแล้ว/เลยกำหนดไม่เตือนซ้ำทุกวัน (ประหยัดโควตา LINE ที่ทั้ง ERP ใช้ร่วมกัน · 300/เดือน นับตามคนในกลุ่ม)
- ต้องตั้ง 3 อย่าง: เปิดในแท็บแจ้งเตือน · เชิญบอท LINE บริษัทเข้ากลุ่ม แล้วตั้งที่ศูนย์ LINE ช่อง **"กลุ่มแมว (ทะเบียนแมว)"** (slot `cats`) · สวิตช์ "เตือนเรื่องแมว" ในศูนย์ LINE เปิดอยู่ (ค่าเริ่มเปิด)
- ไม่ตั้งกลุ่มแมว = **ไม่ส่ง** (ไม่ตกไปกลุ่มหลักของบริษัท) · ปุ่ม "ส่งทดสอบตอนนี้" ส่งทุกเรื่องในช่วงเตือน (ยืนยันก่อน · ย้อนไม่ได้เพราะส่งออกไปแล้ว)
- ลงทะเบียนแล้วที่ `lib/line-registry` (slot + เหตุการณ์ `cat_reminder`) และแผนผังแจ้งเตือน `lib/flow-map-notify`

ตารางเพิ่ม (migration `202612250800_cat_registry_r2.sql`): `cat_supplies` · `cat_purchases` · `cat_vet_visits` · `cat_expenses` · `cat_settings` (meal_plan · notify)
API เพิ่ม: kinds `supplies` · `purchases` · `vet_visits` · `expenses` ผ่านตัวเดิม · `GET/PUT /api/cats/settings` · `GET /api/cron/cat-reminders` (`?test=1` = ปุ่มทดสอบ, สิทธิ์ cats.edit)
