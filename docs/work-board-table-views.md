# บอร์ดจ่ายงาน · โหมดตาราง — ค้นหาทุกแท็บ · ตาราง/การ์ด/ปฏิทิน · จัดกลุ่มตามช่าง

ไฟล์: `app/master/work-board/page.tsx` (BoardTable) · ปฏิทิน `app/master/work-board/board-calendar.tsx`

## ค้นหาแล้วเห็นผลทุกแท็บ
- พิมพ์ค้นหา → ผลจาก **รอจ่าย / กำลังผลิต / รอ QC** เรียงลงมาเป็นกล่องละแท็บ (แท็บที่ไม่เจอ = บรรทัดเดียว "ไม่พบ") · แต่ละกล่องโชว์ไม่เกิน 50 แถว
- กดแท็บด้านบน หรือ "ดูเฉพาะแท็บนี้ →" = ดูแท็บเดียว (state `searchPinned`) · ลิงก์ "ดูผลค้นหาจากทุกแท็บ" กลับมาได้ · ลบคำค้น = กลับแท็บเดิม
- ระหว่างดูผลทุกแท็บ ไม่มีช่องติ๊กเลือก (กันสั่งงานผิดแท็บ) — กดเข้าแท็บก่อน
- โหมดอัปเดตงานไม่ใช้ (มีแท็บ "ทั้งหมด" ของตัวเอง)
- รอจ่าย = ค้นในมุมมองด่วนที่เลือกอยู่ (หัวกล่องบอกชื่อมุมมองถ้ากรองอยู่)

## ตาราง / การ์ด / ปฏิทิน ต่อแท็บ
- ปุ่มสลับอยู่ในแถบเครื่องมือของตาราง · จำต่อคน `user_ui_prefs "wb_tab_layout"` = `{pend, wip, qc}`
- รอจ่าย: ค่า `auto` = ตามมุมมองด่วน (ตาราง/การ์ดที่ตั้งไว้) · เลือกมุมมองด่วนใหม่ = กลับเป็น auto · iPad แนวตั้ง = การ์ดเสมอ (ไม่มีปุ่ม)
- การ์ด: รอจ่ายใช้การ์ดของมุมมองด่วนเดิม · กำลังผลิต `renderWipCard` · รอ QC `renderQcCard`
- ปฏิทิน = `BoardCalendar` ตัวเดิม โชว์เฉพาะงานของแท็บนั้น (ตามแบรนด์/คำค้น) ผ่าน prop ใหม่:
  - `lockMode` ล็อกปฏิทินเดียว · `hideSearch` ใช้ช่องค้นของบอร์ด
  - `woDate`: `"due"` กำหนดเสร็จ (ลากตั้งวันได้) · `"dispatch"` วันที่จ่าย · `"received"` วันที่ช่างส่ง (สองแบบหลังดูอย่างเดียว ไม่มีแถบสรุปนัด)
  - กำลังผลิตเริ่มที่ **วันที่จ่าย** (ทุกใบมีวัน — กำหนดเสร็จมีแค่ส่วนน้อย ณ 2026-10-31: 6/70) · จำต่อคน `wb_wip_cal_date`
  - รอจ่าย: สลับ นัดส่งลูกค้า / นัดส่งงานภายใน ได้เหมือนหน้าปฏิทินเต็ม · รอ QC: วางตามวันที่ช่างส่ง

## จัดกลุ่มแท็บกำลังผลิต
- เพิ่ม "จัดกลุ่มตามช่าง" + "จัดกลุ่มตามโต๊ะ" (เดิมมี กลุ่ม / สถานะ) · หัวกลุ่ม = จำนวนใบ · ชิ้น · ค้าง (+ ทำร่วมกี่ใบ)
- ช่างมาจาก `assignees` ของใบจ่ายงาน · จ่ายทั้งโต๊ะ = "<โต๊ะ> (ทั้งโต๊ะ)"
- ใบที่ทำร่วมหลายคน **ขึ้นในกลุ่มของทุกคน** (แถวซ้ำ key `id::ชื่อ`) — การเลือกยังนับเป็นใบ (ติ๊กแถวไหน = ทั้งใบ, แถบคำสั่งนับใบไม่ซ้ำ)
