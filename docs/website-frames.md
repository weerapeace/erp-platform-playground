# 🖼 สร้างกรอบเอง (คลังกรอบของร้าน)

## ใช้ทำอะไร
สร้างกรอบรูปของร้านเอง แล้วใช้ซ้ำกับรูปในผืนผ้าใบ (Section ผืนผ้าใบอิสระ) — เปิดจากแผงขวา: ชิ้นรูป → กรอบรูป → **กรอบของฉัน → ＋ สร้างกรอบเอง**

| แบบ | ทำจากอะไร | หมายเหตุ |
|---|---|---|
| 🧩 ประกอบเอง | ทรงที่มี (เหลี่ยม/มุมมน/วงรี/โค้งประตู/หัวใจ/ดาว/หกเหลี่ยม/เมฆ/ทรงอิสระ) + เส้นขอบ (เส้น/จุดไข่ปลา/เส้นคู่) สี หนา ห่างจากรูป | เร็วสุด ไม่ต้องมีไฟล์ |
| ✂️ อัปทรงตัดรูป | **SVG** (แนะนำ — แปลงเป็นเส้นทาง · มีเส้นขอบตามทรงได้) หรือ **PNG / WebP พื้นใส** (ส่วนทึบ = เห็นรูป · ไม่มีเส้นขอบ) | ทำใน Canva / Illustrator / Photoshop · มีทรงตัวอย่างให้ลอง |
| 🖼 อัปกรอบวางทับ | PNG ที่ตรงกลางใส วางทับบนรูป (เลือกจาก "คลังกรอบรูปของร้าน" เดิม) + รูปห่างขอบกรอบ % + ทรงรูปข้างใน | เช่น กรอบลายดอกไม้ กรอบทอง โพลารอยด์ |

- บันทึก: ตั้งชื่อ + เลือก **ใช้ได้ทุกร้าน / เฉพาะร้านนี้** · ปุ่ม "💾 บันทึกเข้าคลัง" หรือ "💾 บันทึก + ใช้กับรูปนี้"
- ไทล์ในคลัง: กด = ใช้กับรูป · ✎ แก้ · ✕ ลบ (ถามก่อน) — **ใช้แล้ว = คัดลอกค่าไปที่รูป** แก้/ลบกรอบในคลังทีหลัง รูปที่ใช้ไปแล้วไม่เปลี่ยน

## ไฟล์
- ของกลาง pure `lib/website-frames.ts` (มิเรอร์ทั้งไฟล์ → เว็บร้าน `src/lib/frames.ts`): `FrameShape` / `normalizeFrameShape` (ตัวกรองเส้นทาง) / `frameShapeMaskCss` / `FrameDef` / `normalizeFrameDef` / `frameDefCanvasPatch`
- แปลง SVG → ทรง: `lib/svg-frame-import.ts` (ในเบราว์เซอร์ · เก็บเฉพาะ path/rect/circle/ellipse/polygon/polyline + ตำแหน่งจริง matrix · ทิ้งสคริปต์/ลิงก์/รูปฝัง/ตัวอักษร)
- ตัวสร้าง + คลัง: `components/website-frame-builder.tsx` (`FrameBuilder` · `FramePreview` · `CustomFrameGrid` · `useShopFrames`) → ใช้ใน `website-canvas-inspector.tsx`
- API: `app/api/website/frames` (GET products.view · POST/PATCH/DELETE products.edit · audit `website_frame`) · ตาราง `website_frames` (RLS เปิด ไม่มี policy · shop_id null = ทุกร้าน)
- ชิ้นรูปในผืนผ้าใบ: `frame: "custom"` + `frameShape` (ชนิดช่อง `frameShape` · ⚠️ ช่อง `shape` = ลายของของตกแต่ง คนละช่อง) + `maskKey` (PNG)
- เว็บร้าน: `CanvasSection` ตัดรูปด้วย mask (เส้นทาง / รูป PNG) + `FrameRing` วาดเส้นตามทรง (รับ `shape` หลายชิ้น)
- `/api/r2-image` ส่ง `Access-Control-Allow-Origin: *` ให้รูป — เว็บร้าน (คนละโดเมน) ใช้รูป PNG เป็น mask ได้

## ข้อจำกัด
- ใช้กับผืนผ้าใบก่อน (Section รูป/แกลเลอรียังเลือกได้แค่ทรงในตัว)
- ทรงจาก PNG ใส่เส้นขอบไม่ได้ (ไม่มีเส้นทางให้วาดตาม) — อยากได้เส้นให้อัปเป็น SVG
- SVG ≤ 1 MB · ≤ 80 ชิ้น · เส้นทางรวม ≤ 40,000 ตัวอักษร (ซับซ้อนเกิน → รวมรูปทรงเป็นชิ้นเดียวก่อนส่งออก) · ตัวอักษรต้องแปลงเป็นเส้น (Create Outlines)
