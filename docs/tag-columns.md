# TagColumns — เลือกแท็กแบบหมวดซ้าย · แท็กขวา

ของกลาง `components/tag-columns` (เจ้าของสั่ง 2026-11-20)

- **ใช้ทำอะไร:** แสดงแท็กสินค้า (product_families) เหมือนเมนูหน้าเว็บ: หมวดชั้นบนสุดอยู่ซ้าย แท็กในหมวดอยู่ขวา หมวดย่อย (↳) เป็นหัวข้อคั่นในคอลัมน์ขวา
- **ค้นหา:** ผู้เรียกถือช่องค้นหาเองแล้วส่ง `query` มา มีคำค้นเมื่อไหร่ คอลัมน์ขวาจะโชว์แท็กที่ตรงจากทุกหมวด พร้อมบอกว่าอยู่หมวดไหน
- **จำหมวดล่าสุด:** ใส่ `storageKey` แล้วระบบจำไว้ในเครื่องผู้ใช้
- **มือถือ:** เห็นรายการหมวดก่อน แตะหมวดแล้วเข้าไปดูแท็ก มีปุ่ม "‹ หมวดทั้งหมด" ไว้กลับ
- **การเลือก:** ผู้เรียกส่ง `renderTag` มาเอง (ติ๊กหลายตัว / เลือกตัวเดียว / ลากวาง) ส่วน `selectedIds` ใช้นับจุดบอกจำนวนที่เลือกในแต่ละหมวด

ใช้ที่:
- ป๊อปเลือกแท็กในฟอร์มสินค้า `components/relation-multi` (เลือกหลายตัว + ลากแท็กทับแท็ก)
- ช่อง "ประเภท (Tag) *" ในป๊อปเพิ่ม SKU `app/master/skus/sku-wizard.tsx` (เลือกตัวเดียว)

ห้ามใช้: กรองตาราง (ใช้ `tag-filter`) · ไล่ดูสินค้าตามแท็ก (ใช้ `sku-tag-browser`)
