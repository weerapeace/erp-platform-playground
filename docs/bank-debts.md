# หนี้ธนาคาร (ภาพรวม) + บัตรเครดิต/วงเงินหมุนเวียน

## /bank-debts — ทะเบียนหนี้ทุกก้อนในหน้าเดียว
- "หน้าครอบ" ของเดิม: `GET /api/bank-debts` รวม `loan_contracts` + `od_facilities` + `debt_cards` เป็น `DebtItem[]` หน้าตาเดียวกัน (ไม่มีตารางใหม่)
- การ์ด 4 ใบ: หนี้คงเหลือรวม / ต้องจ่ายต่อเดือน / ครบกำหนดใน 30 วัน (+เกินกำหนด) / วงเงินที่ยังเบิกได้
- จัดกลุ่มตาม ธนาคาร · บริษัท · ชนิดหนี้ · ใครกู้ + กรองบริษัท (จำต่อคนใน localStorage)
- กดบรรทัด → `MasterRecordDrawer(moduleKey)` ของโมดูลนั้น (บันทึกจ่าย/ตารางผ่อน/ปรับโครงสร้าง อยู่ในฟอร์มเดิม) · "＋ เพิ่มหนี้ใหม่" = drawer สร้างใหม่ของโมดูลที่เลือก
- ป้ายสถานะ = "ต้องทำอะไรต่อ": ขาดตารางผ่อน / ยอดคงเหลือผิด / เกินกำหนด / ใกล้ครบกำหนด / ปรับโครงสร้าง n ครั้ง / ใกล้เต็มวงเงิน / ปกติ
- เมนู: แอปการเงิน หมวดภาพรวม sort −10 (หน้าแรกของแอป) · สิทธิ์ `loan_contracts.view`

## /debt-cards — บัตรเครดิต & วงเงินหมุนเวียน (หนี้แบบเบา)
- ตาราง `debt_cards` (migration `202609071000_debt_cards.sql`): 1 แถว = 1 บัตร เก็บ ยอดตามใบแจ้งยอดล่าสุด + ขั้นต่ำ + วันครบกำหนด + จ่ายแล้ว · trigger ตั้ง status (unpaid/partial/paid) จาก paid_amount
- ไม่มีตารางผ่อน/ใบเบิก — ทุกเดือนแก้ยอด/วันตามใบใหม่ · MasterCRUDPage generic (โมดูล `debt-cards`) · lender_name ใช้ BankPicker + พิมพ์เองได้
- กระดานเงินสด: `/api/cashflow` เพิ่ม source `card` (การ์ด 🔒 วันครบกำหนด ยอด = ใบแจ้งยอด − จ่ายแล้ว · เฉพาะ status ≠ paid)
- ข้อมูลตั้งต้น 4 ใบจากใบแจ้งยอดสแกน (UOB Cash Plus / UOB Mastercard / กรุงเทพ Visa / กรุงศรี Visa)
