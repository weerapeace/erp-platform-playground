# โน้ตส่วนตัว (My Note) — ของกลาง

ไฟล์: `components/my-note/index.tsx` · ใช้ครั้งแรก: บอร์ดจ่ายงาน คอลัมน์ "โน้ตของฉัน" (2026-10-31)

## ใช้ทำอะไร
จดโน้ตสั้น ๆ ติดกับรายการไหนก็ได้ (ใบสั่งผลิต, ใบสั่งซื้อ, SKU ฯลฯ) **เห็นคนเดียว** — ไว้เตือนตัวเอง เช่น "โทรตามช่างก่อนบ่ายสาม"

## ห้ามใช้เมื่อ
- ข้อความที่ทีมต้องเห็นร่วมกัน / เป็นข้อมูลของเอกสาร → ใช้ช่องหมายเหตุของเอกสาร หรือ Activity Feed (มี audit log)

## ที่เก็บ
- `user_ui_prefs` key `my_notes:<scope>` = `{ [id]: { t: ข้อความ, at: ISO } }` ผ่าน `useUserPref` (ต่อคน · ตามไปทุกเครื่อง · cache ในเครื่อง)
- RLS ของ `user_ui_prefs` = เจ้าของเท่านั้น → คนอื่นอ่านไม่ได้ผ่านหน้าเว็บ
- บันทึกแบบอ่านค่าล่าสุดจากเซิร์ฟเวอร์ก่อนแล้วรวม (รายการไหนแก้ทีหลังชนะ) → เปิดสองเครื่องพร้อมกันโน้ตไม่ทับกัน · หน้าจอเปลี่ยนทันทีไม่ต้องรอ
- ข้อความยาวสุด `MY_NOTE_MAX` = 500 ตัวอักษร · เก็บสูงสุด `MY_NOTE_LIMIT` = 2,000 รายการต่อ scope (เกิน = ทิ้งที่แก้นานสุด)
- ไม่ลง audit log (เป็นโน้ตส่วนตัว ไม่ใช่ข้อมูลธุรกิจ)

## ใช้
```tsx
const myNotes = useMyNotes("mo");                                   // scope = ประเภทเอกสาร
<MyNoteCell note={myNotes.notes[moNo]} onSave={(t) => myNotes.setNote(moNo, t)} />
myNotes.text(moNo)                                                  // ข้อความ — ใส่ในข้อความค้นหา / sortValue
```
- ช่อง: มีโน้ต = กระดาษโน้ตสีเหลือง 2 บรรทัด + วันที่แก้ (ชี้ดูเต็ม) · ว่าง = "＋ โน้ต" จาง ๆ
- กด = แก้ · Enter บันทึก · Shift+Enter ขึ้นบรรทัด · Esc ยกเลิก · ลบข้อความหมด = ลบโน้ต
- กด/พิมพ์ในช่องไม่ไหลไปเป็นการกดแถว (ไม่เปิดรายละเอียด/ป๊อป)

## บอร์ดจ่ายงาน
- คอลัมน์ `mynote` ทั้ง 3 แท็บ ผูก **เลขใบสั่งผลิต** → โน้ตเดียวกันขึ้นทั้ง รอจ่าย / กำลังผลิต / รอ QC
- รอจ่ายบนคอม = เปิดไว้ตั้งต้น (มุมมองที่กำหนดคอลัมน์เอง ต้องเพิ่มใน "ตั้งค่ามุมมอง" → คอลัมน์) · iPad = ซ่อนไว้ก่อน
- ค้นหาบนบอร์ดเจอจากข้อความในโน้ตด้วย · แถวสรุปกลุ่มบอก "N โน้ต"

## ข้อจำกัด
- ลบโน้ตบนเครื่องหนึ่ง ขณะอีกเครื่องเปิดค้างและกำลังจดโน้ตอื่น → โน้ตที่ลบอาจกลับมา (ไม่มีบันทึกการลบ) — ลบซ้ำได้
- ยังไม่โชว์ในโหมดการ์ด / ใบพิมพ์
