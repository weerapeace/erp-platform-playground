# จ่ายงานเหมา (บอร์ดจ่ายงาน)

เจ้าของขอ 2026-11-01: "อยากได้หน้า จ่ายงานเหมา โดยสร้างงานเหมาขึ้นมา โดยเลือกงานจาก ใบงานที่มีอยู่ (ที่ยังไม่ส่งเข้า QC) และ save กลับ ใบงานด้วย และ BOM ด้วย" + "อยากให้เพิ่มแบบหลายคนได้ ต้องเลือก ใบงาน (สินค้าก่อน) แล้วเลือกงานเหมา และเพิ่มแบบตารางได้"

## ใช้ทำอะไร
- จ่ายงานเหมารายชิ้น (ยัดนุ่น · เย็บ · ติดดาว · พับชั้น …) ให้คน — หลายใบงาน หลายงาน หลายคน ในตารางเดียว
- รับงานเหมาคืน / กดเสร็จ → ค่าเหมาเข้าสรุปค่าแรงรายเดือน (`/api/mo/labor-summary`)
- พิมพ์ใบจ่ายงานเหมาให้ช่าง (1 คน = 1 แผ่น)

## เปิดจากไหน
- เมนู ⋯ บนบอร์ด → "จ่ายงานเหมา" (ทุกมุมมอง)
- มุมมองตาราง: ติ๊กใบในแท็บรอจ่าย / กำลังผลิต → แถบล่าง "จ่ายงานเหมา" (เปิดมาพร้อมใบที่ติ๊ก)
- เช็กลิสต์ใบสั่งผลิต แท็บ "งานเหมา" → "จ่าย / แบ่งหลายคน"

## หน้าต่าง (`app/master/work-board/piecework-dispatch.tsx` — `PieceworkDispatch`)
**แท็บจ่ายงานเหมา**
1. เลือกใบงาน (สินค้า) ก่อน — ติ๊กมาจากบอร์ด หรือเพิ่มจากช่องค้นหา (เฉพาะใบที่ยังไม่เข้า QC: รอจ่าย + อยู่ที่ช่าง)
2. ตารางแบ่งกลุ่มตามใบงาน (รูป · รหัสสินค้า · จำนวนสั่ง · อยู่ที่ไหน · งานเหมาที่จ่ายไปแล้ว) · **1 แถว = งานเหมา 1 อย่าง × คน 1 คน**
   - งานเหมาใน BOM ขึ้นให้เอง (ป้าย "จาก BOM") เฉพาะส่วนที่ยังไม่จ่าย
   - "สถานะงานนี้" = จ่าย (ก่อนหน้า + รอบนี้) / ต้องจ่าย (ชิ้นต่อใบ × จำนวนสั่ง) · เหลือ → ปุ่ม "+ คนอื่น" (แถวใหม่จำนวนที่เหลือ) · เกิน = แดง (กดจ่ายต้องยืนยัน)
   - เลือกงานจากรายชื่องานเหมากลาง หรือพิมพ์ชื่อใหม่ (สร้างเข้า `piecework_jobs` ตอนบันทึก) · คนรับ = ช่าง/พนักงานทุกคน (โชว์โต๊ะ)
   - "ใส่ทุกใบตามใบแรก" = งาน + คน + ชิ้นต่อใบของใบแรก → ใบที่ยังว่าง (จำนวนคิดตามใบนั้น หักที่จ่ายไปแล้ว)
3. ☑ บันทึกเข้า BOM (งาน + ชิ้นต่อใบ + ราคา · ไม่เก็บชื่อคน · ราคาเปลี่ยน = เก็บ `piecework_rate_history`) · ☐ ใส่ให้ทุกสีของรุ่นเดียวกัน (BOM ล่าสุดของทุก SKU ใน Parent SKU)
4. จ่ายแล้ว → ปุ่ม "พิมพ์ใบจ่ายงานเหมา" / "จ่ายชุดใหม่"

**แท็บรับงานคืน** — งานที่ยังค้างแยกตามคน · ใส่ชิ้นที่รับคืน (ตั้งต้น = เท่าที่จ่าย) · รับไม่ครบ: "ยังให้คนเดิมทำต่อ" (ที่เหลือแยกเป็นแถวใหม่ ยังค้าง) / "ไม่ทำแล้ว" · ปุ่ม "พิมพ์งานค้างของคนนี้"

## กันจ่ายซ้ำ
- นับงานเหมาที่จ่ายไปแล้วของใบนั้นเข้า "สถานะงานนี้" ทุกครั้ง (โชว์ "จ่ายแล้ว … · ชื่อคน" ที่หัวกลุ่มด้วย)
- แถวซ้ำ (งานเดียวกัน ใบเดียวกัน คนเดียวกัน) = ห้ามบันทึก ให้รวมเป็นแถวเดียว
- กดจ่ายซ้ำ / เน็ตช้า: ทุกครั้งที่เปิดมี `batch_id` ใหม่ → เซิร์ฟเวอร์เห็นชุดนี้แล้วไม่บันทึกซ้ำ
- ใบที่ส่งเข้า QC ครบแล้ว / ปิด / ยกเลิก → เซิร์ฟเวอร์ไม่รับ

## ข้อมูล
- `mo_piecework` (เดิม) + ช่องใหม่ (migration `202611100800_mo_piecework_dispatch.sql` — เพิ่มอย่างเดียว): `wo_id` ใบจ่ายงานที่ช่างถือ (ใส่ให้เมื่อใบนั้นมีใบจ่ายเปิดอยู่ใบเดียว) · `assignee_id` · `dispatched_at` · `done_qty` · `batch_id`
- ค่าเหมาที่ได้จริง = ราคา × `done_qty` (ว่าง = เท่าที่จ่าย) — `pwEarned` ใช้ใน `/api/mo/labor-summary`
- กด "ทำเสร็จ" ในเช็กลิสต์ (ของเดิม) = เสร็จทั้งหมด (`done_qty` ว่าง)

## ยังไม่ทำ
- เลือกใบจ่ายงานเองเมื่อใบนั้นมีหลายใบจ่ายเปิดอยู่ (ตอนนี้ไม่ผูก)
- แก้/ยกเลิกแถวที่จ่ายไปแล้วจากหน้าต่างนี้ (ใช้เช็กลิสต์แท็บงานเหมา)
- สแกนบาร์โค้ดเพิ่มใบงาน (ตอนนี้พิมพ์ค้นหา)
