# ดึงใบเสนอราคาเข้าใบสั่งขาย (กติกากลาง)

> เจ้าของขอ 2026-11-03 (จากหน้าแผนผังการทำงาน เส้น S2): "ดึงใบเสนอราคาเข้าใบสั่งขาย — ใบเสนอราคาไม่เปลี่ยนสถานะ ไม่จำว่ามาจากใบไหน · ดึงใบร่าง/ปฏิเสธ/แปลงแล้วซ้ำได้" · เลือก **หลายใบเสนอราคาต่อ 1 ใบสั่งขาย**

## ใช้ทำอะไร

ปุ่ม "ดึงจากใบเสนอราคา" ในหน้าใบสั่งขาย (`/sales/orders`) และกล่องลงออเดอร์หลายรายการ (`OrderBatchEntryModal`) ใช้กติกาเดียวกัน:

| เรื่อง | กติกา |
|---|---|
| ใบไหนดึงได้ | สถานะ **ส่งแล้ว / ตอบรับแล้ว** · ยังไม่แปลงเป็นใบขาย (`converted_so_id` ว่าง) · ไม่อยู่ในใบสั่งขายอื่นที่ยังไม่ยกเลิก |
| หลายใบ | รวมหลายใบเข้าใบสั่งขายเดียวได้ แต่ต้อง **ลูกค้าเดียวกัน** (ใบของลูกค้าอื่น / ใบที่อยู่ในฟอร์มแล้ว ข้ามพร้อมแจ้ง) |
| จำว่ามาจากไหน | ต่อบรรทัด: `so_order_lines.quote_id` + `quote_no` (แบบเดียวกับ `mo_id`/`mo_no`) · หน้าจอโชว์ "จากใบเสนอราคา …" ใต้บรรทัด |
| ตอนไหนเปลี่ยนสถานะ | **ตอนบันทึกใบสั่งขาย** (ไม่ใช่ตอนกดดึงเข้าฟอร์ม) → ใบเสนอราคาเป็น "แปลงแล้ว" + audit `convert_to_so_order` |
| ยกเลิก / ลบ | ยกเลิกหรือลบใบสั่งขาย หรือแก้ใบแล้วลบบรรทัดของใบเสนอราคานั้นออกหมด → กลับ "ตอบรับแล้ว" ดึงใหม่ได้ + audit `release_from_so_order` |
| เปิดใบที่ยกเลิกกลับ | ผูกกลับให้ ถ้าใบเสนอราคายังไม่ถูกใช้ที่อื่น/ไม่ถูกปฏิเสธ · ไม่งั้นปลดออกจากบรรทัดแล้วแจ้งเตือน (รายการยังอยู่) |
| ราคา | คัดลอกราคา + ส่วนลดรายบรรทัด · ลูกค้าผูกกับรายชื่อลูกค้าจริง (มีรหัส) |
| หน้าใบเสนอราคา | ขึ้น "ดึงเข้าใบสั่งขายแล้ว: …" กดไปเปิดใบสั่งขายได้ (`/sales/orders?open=`) |

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `lib/quote-pull.ts` | pure — ตัดสินรายใบ (`quotePullBlock`) · หน้าจอเลือกหลายใบ (`pickQuoteDocs`) · ป้ายสถานะ |
| `lib/quote-convert.ts` | อ่าน/เขียนฐานข้อมูล — `checkQuotePull` (ก่อนบันทึก) · `syncQuoteConversions` (หลังสร้าง/บันทึก/ยกเลิก/เปิดกลับ/ลบ — เรียกซ้ำได้ ผลเหมือนเดิม) · `quotesInOpenOrders` |
| `app/api/so-orders/sources/route.ts` | รายการใบที่ดึงได้ (`?type=quote`) |
| `app/api/so-orders/route.ts` · `[id]/route.ts` | ประตูบันทึก — เรียกกติกาข้างบน |
| ทะเบียน workflow | key `quotation` (`npm run where-used -- quotation`) |

## ไม่แตะ

- ปุ่ม "แปลงเป็นใบขาย" เดิมในหน้าใบเสนอราคา (RPC `erp_playground_quote_to_so` → ใบขายตรง เขียน `converted_so_id`) ใช้ได้เหมือนเดิม
- สถานะปกติ ส่ง/ตอบรับ/ปฏิเสธ/ยกเลิก ยังอยู่ในตาราง `erp_workflow_transitions` (ฐานข้อมูล)

## ข้อจำกัด

- ใบร่างดึงไม่ได้ — ต้องกด "ส่ง" ที่หน้าใบเสนอราคาก่อน
- ช่อง `so_orders.quote_id` (หัวใบ) เป็นช่องเดิมที่ไม่ได้ใช้ — การผูกจริงอยู่ที่บรรทัด
- ดึงเข้าฟอร์มแล้วยังไม่บันทึก = ยังไม่จองใบ คนอื่นดึงใบเดียวกันได้ ใครบันทึกก่อนได้ (อีกคนบันทึกไม่ผ่านพร้อมบอกเหตุผล)
