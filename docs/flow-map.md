# แผนผังการทำงาน (`/master/flow-map`)

> เจ้าของขอ 2026-11-02: "แผนผังที่โชว์การทำงานจริงในระบบ … ซื้อ, ผลิต, จ่ายงาน, ขาย ว่าอะไรเชื่อมอะไร update อันนี้แล้วไปไหน"

## ใช้ทำอะไร

หน้าเดียวดูว่าเอกสาร/หน้าจอในงาน ซื้อ · ผลิต · จ่ายงาน · ขาย ส่งต่อกันยังไง
- **กล่อง** = เอกสาร / หน้าจอ — กดดู: เปิดหน้าไหน · เก็บตารางไหน · สถานะมีอะไร · ตัวเลขตอนนี้ · ช่องโหว่
- **เส้น** = การส่งต่อ แยก 4 แบบ (สี + ลายเส้น): ระบบทำให้เอง · คิดสดตอนเปิดดู · คนต้องไปกด · ยังไม่เชื่อม
- 5 มุมมอง: ภาพรวม / ซื้อ / ผลิต / จ่ายงาน / ขาย · ซ่อน/แสดงเส้นแต่ละแบบได้
- ทางเข้า: เมนู Master Data → "แผนผังการทำงาน" · ปุ่มในหน้า "คู่มือ Flow งาน" (`/master/work-flows`)

ไม่ใช่ "คู่มือ Flow งาน" (`/master/work-flows`) — หน้านั้นบอกว่าแต่ละขั้นเก็บไฟล์ไว้ที่ไหน (เนื้อหาแก้ได้ในเว็บ) ส่วนหน้านี้บอกว่าระบบส่งต่อข้อมูลกันจริงยังไง (อ่านจากโค้ด)

## ชิ้นส่วน

| ชิ้น | ไฟล์ | หน้าที่ |
|---|---|---|
| ทะเบียนแผนผัง | `lib/flow-map.ts` | กล่อง (`FLOW_NODES`) · เส้น (`FLOW_EDGES` + ไฟล์ที่ทำจริง) · ตำแหน่งในแต่ละผัง (`FLOW_VIEWS`) · นิยามตัวเลขสด (`FLOW_METRICS`) — pure ไม่ import อะไร |
| ตัวเลขสด | `app/api/flow-map/health/route.ts` | นับจากฐานข้อมูล (สิทธิ์ `products.view`) ตัวไหนพังคืน `null` ไม่ล้มทั้งหน้า |
| หน้าจอ | `components/flow-map/index.tsx` + `app/master/flow-map/page.tsx` | วาด SVG + แผงรายละเอียด |
| เทสต์ | `lib/__tests__/flow-map.test.ts` | ไฟล์ที่เส้นอ้างต้องมีจริง · กล่อง/เส้น/ผังชี้กันถูก · workflow key มีในทะเบียน workflow · ไม่มีกล่องทับกัน |

## ทำให้ไม่ตกยุค (สำคัญ)

- **แก้ workflow / การส่งต่อเมื่อไร ให้แก้ `lib/flow-map.ts` ด้วย** — คู่กับทะเบียน `lib/workflow-registry.ts` และขั้นตอน `npm run where-used` (CLAUDE.md §46 Step 3)
  - เส้นเปลี่ยนแบบ (เช่น ช่องโหว่ถูกปิด `missing` → `auto`) · ข้อความ `detail` / `warn` · ช่องโหว่ของกล่อง `gaps`
- ย้าย/ลบไฟล์ที่เส้นอ้าง → เทสต์ล้ม ต้องมาแก้ทะเบียน
- ตัวเลขสด (เช่น ใบขายเก่าที่ยังจองของ, ใบขอซื้อไม่มีรหัส) คิดใหม่ทุกครั้งที่เปิดหน้า — ช่องโหว่ที่ข้อมูลจริงยังค้างจะขึ้นจุดแดงเอง

## เพิ่มกล่อง / เส้น / มุมมอง

1. กล่อง: เพิ่มใน `FLOW_NODES` (id สั้น) · `area` = buy/make/dispatch/sell/stock/hr · `href` = หน้าที่เปิด
2. เส้น: เพิ่มใน `FLOW_EDGES` · `files` = ไฟล์ที่ทำการส่งต่อนี้จริง · `workflow` = key ในทะเบียน workflow (ถ้ามี)
3. วางในผัง: `FLOW_VIEWS[].pos` = `[คอลัมน์ 0–3, แถว]` (แถว `"s"` = แถวคลังของภาพรวม) · `edges` = `[id, ด้านออก, เลื่อน, ด้านเข้า, เลื่อน, { c, bf, a, b }]`
   - ด้าน `l r t b` · `c` = แนวเลี้ยวของเส้นหักมุม · `bf` = ตำแหน่งเลขบนเส้น (0–1) · `a`/`b` = ใช้กล่องอื่นเป็นต้น/ปลายในผังนี้
4. ตัวเลขสดใหม่: เพิ่ม key ใน `FlowMetricKey` + `FLOW_METRICS` แล้วเขียนวิธีนับใน `/api/flow-map/health`
5. รัน `npx vitest run lib/__tests__/flow-map.test.ts` แล้วเปิดหน้าดูว่าเส้นไม่ทับกล่อง

## ข้อจำกัด

- ผังวาดด้วยตำแหน่งที่กำหนดเอง (ไม่จัดอัตโนมัติ) — เพิ่มกล่องต้องหาช่องว่างและเส้นทางเอง
- เนื้อหาเป็นภาษาไทย (ป้ายบนหน้าจอแปลได้ผ่าน `t()`)
- ตัวเลขสดเป็นยอดรวม ไม่ได้กดลงไปดูรายการได้ (ใช้ปุ่ม "เปิดหน้า" ไปหน้าเอกสารนั้นแทน)
