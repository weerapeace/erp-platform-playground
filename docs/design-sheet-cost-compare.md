# ตีราคา (Design Sheet) — เตือนราคาวัสดุปรับ + จำวัสดุเดิม (A + B)

ใช้ที่: ป๊อปอัป Design Sheet → แท็บ "ตีราคา" (`components/design-sheet-detail`) · มือถือเห็นแบบอ่านอย่างเดียว (`components/design-sheet-mobile`)

## A — ราคาวัสดุปรับ (เตือนแล้วให้กดเอง ไม่เปลี่ยนให้เงียบ ๆ)
- ทุกบรรทัดที่ผูก "วัสดุตีราคา" (หรือกลุ่ม) ระบบเทียบ **ราคาที่เก็บในบรรทัด** กับ **ราคาฐานปัจจุบัน** (ตามปุ่ม 💰: กรอกเอง / ซื้อจริงล่าสุด / เฉลี่ย / แพงสุด / ถูกสุด)
- ต่างกัน → แถบเหลืองเหนือตาราง (กดขยายดูรายบรรทัด) ไม่โชว์ในแถวแล้ว (เจ้าของขอให้แถวสะอาด): `⚠ ราคาปรับ 200 → 260 +60/หน่วย (+30%) · รวม +1,200 · ตั้งแต่ 3 ต.ค. 69`
  - วันที่: ฐาน "กรอกเอง" = วันแก้ master วัสดุ (`design_price_items.updated_at`) · ฐานจาก SKU = วันรับของล่าสุด
  - ฐาน "กรอกเอง" แต่มีราคาซื้อจริงล่าสุด (บาท) ต่างจากที่ตีไว้ → เตือนด้วย
- ปุ่ม **[เปลี่ยน]** = เปลี่ยน unit_price แล้วคำนวณยอดใหม่ · **[ไม่เปลี่ยน]** = จำถาวรใน `design_sheet_cost_lines.price_ack` `{price, at}` (ราคาฐาน ณ ตอนกด) — เงียบจนกว่าราคาฐานจะเปลี่ยนไปจากค่านั้นอีก
- ปุ่มกดได้โดยไม่ต้องเข้าโหมด ✏️ แก้ไข: โหมดดู = บันทึกลง DB ทันที (`quickApply` → `saveCost(lines)`) · โหมดแก้ไข = ค้างไว้ให้กด 💾 เอง
- แถบสรุปเหนือตาราง: `⚠ ราคาวัสดุปรับ N บรรทัด — ถ้าใช้ราคาใหม่ ต้นทุนรวม +… บาท [ใช้ราคาใหม่ทั้งหมด] [ไม่เปลี่ยนทั้งหมด]`
- ชนิด "ชิ้น" (ราคา/cm²) ไม่เตือน (ราคาคิดจากขนาดแผ่น เทียบตรงไม่ได้)

## B — เปลี่ยนวัสดุ แล้วจำของเดิมไว้ (ถาวรจนกดรับทราบ)
- ตอนเปลี่ยนวัสดุของบรรทัดที่มีวัสดุอยู่แล้ว (เลือกจาก dropdown / SKU คลัง / ตั้งวัสดุให้หลายบรรทัด) ระบบเก็บของเดิมไว้ใน `design_sheet_cost_lines.prev_item` (jsonb)
  - เก็บ: วัสดุ, กลุ่ม, ฐานราคา, ราคา/หน่วย, หน่วย, สูตร, เผื่อเสีย, ตัวหาร, หน้ากว้าง, ยอดเดิม, เวลาเปลี่ยน
  - เคยจำแล้วไม่ทับ (ของเดิม = ตัวแรกเสมอ) · เลือกกลับเป็นวัสดุเดิม = ล้างอัตโนมัติ
- แถบฟ้าเหนือตาราง (กดขยาย): `🔁 เดิม: ผ้า A 200 → ผ้า B 260 (+60/หน่วย (+30%) · รวม +1,200) · 3 ต.ค. 69`
  - **[↶ กลับของเดิม]** คืนวัสดุ/ราคาเดิม (ขนาด/จำนวนที่กรอกไว้คงเดิม) · **[✓ รับทราบ]** ล้างการจำ
- แถบสรุป: `🔁 เปลี่ยนวัสดุ N บรรทัด (ยังไม่รับทราบ) — ต้นทุนต่างจากเดิม +… บาท [✓ รับทราบทั้งหมด]`
- ต้องกด 💾 บันทึกตีราคา จึงจะเก็บ/ล้าง `prev_item` ลง DB (ไปกับบรรทัดตามปกติ)

## C — เวอร์ชันตีราคา (เปรียบเทียบย้อนหลัง)
- ทุกครั้งที่กด 💾 บันทึกตีราคา API `PUT cost-lines` เก็บ snapshot ลง `design_sheet_cost_snapshots` (lines + cost_extra + totals ต่อ Parent + grand_total)
  - กันซ้ำด้วย `fingerprint` (lib/design-sheet-cost-snapshot `costFingerprint`) — บันทึกซ้ำโดยไม่แก้ = ไม่เพิ่มเวอร์ชัน · เก็บล่าสุด 50 เวอร์ชัน/ใบ
- ปุ่ม **🕘 เวอร์ชัน** ในแถบล่างแท็บตีราคา (เห็นทุกโหมด) → `components/design-sheet-detail/cost-versions.tsx`
  - ซ้าย: รายการเวอร์ชัน (วันเวลา/คน/ยอดของ Parent ที่ดู/ต่างจากเวอร์ชันก่อน) · ขวา: เทียบกับ "ปัจจุบันบนหน้าจอ" หรือเวอร์ชันอื่น
  - ตารางเทียบ (MiniTable): เท่าเดิม/เปลี่ยน/เพิ่ม/ลบ · ปริมาณ/ราคา/ยอด เก่า→ใหม่ · ต่าง · สรุป วัสดุ/ค่าใช้จ่ายเพิ่ม/รวม + % · ค่าใช้จ่ายเพิ่มจับคู่ด้วยชื่อ
  - จับคู่บรรทัด: วัสดุเดียวกัน (item_id / item_sku_id / group_code + ชื่อ) ตามลำดับที่พบ (`diffCostLines`)
  - ปุ่ม (products.edit): ✏️ ตั้งชื่อเวอร์ชัน · ↩ ใช้เวอร์ชันนี้ (ใส่กลับเข้าตารางของ Parent ที่ดู → ต้องกด 💾) · 🗑 ลบ (audit `cost_snapshot_delete`)
- API: `GET/PATCH/DELETE /api/design-sheets/[id]/cost-snapshots` · test: `lib/__tests__/design-sheet-cost-snapshot.test.ts`
- ข้อจำกัด: เวอร์ชันเริ่มเก็บตั้งแต่ 2026-10-14 (ใบเก่าจะมีเวอร์ชันแรกเมื่อกดบันทึกครั้งถัดไป)

## D — รอบเสนอราคา: ส่วนต่าง + "ที่เปลี่ยนจากครั้งก่อน" (2026-10-14)
- `design_sheet_quotes.cost_snapshot_id` — ตอน POST รอบใหม่ API ผูกกับเวอร์ชันตีราคาล่าสุดของใบให้เอง (หน้าจอบันทึกตีราคาที่ค้างก่อนเสมอ: addQuote/sendCostToQuote → saveCost)
- GET quotes คำนวณ `changes` ฝั่งเซิร์ฟเวอร์: เทียบเวอร์ชันของรอบนี้กับรอบก่อนหน้า **ไซส์เดียวกัน** ด้วย `summarizeCostChanges()` → ข้อความสั้น "ผ้า 200→260 (+60) · เพิ่ม ซิป +5 · ต้นทุน +67" (เรียงตามผลกระทบ ตัด 4 รายการ)
- ตาราง: คอลัมน์ **ส่วนต่าง (กำไร)** = เสนอ − ตีราคา ต่อชิ้น · % ของราคาที่เสนอ · รวม × จำนวน · เทียบราคาที่เสนอครั้งก่อน (ไซส์เดียวกัน) · คอลัมน์ **ที่เปลี่ยนจากครั้งก่อน** กดแล้วเปิด 🕘 เวอร์ชัน พร้อมเลือกซ้าย/ขวาให้ (`initialA/initialB`)
- รอบเก่าก่อน 2026-10-14 ไม่มี cost_snapshot_id → "—"

## E — รอบเสนอราคาแบบ "1 ครั้ง = 1 การ์ด" (2026-10-14)
- `design_sheet_quotes.batch` = ครั้งที่จริง (1 ครั้ง = หลายไซส์ × หลายขั้นจำนวน; แถว = 1 ช่อง) · backfill แถวเก่า: ใบเดียวกัน+วันที่เดียวกัน = ครั้งเดียวกัน
- UI `components/design-sheet-detail/quote-rounds.tsx`: การ์ดต่อครั้ง (ครั้งล่าสุดอยู่บน) หัว = วันที่/สถานะรวม (◐ ผสม ถ้าต่างกัน)/หมายเหตุ/🗑 ลบครั้ง · แถบ "ที่เปลี่ยนจากครั้งก่อน" ต่อไซส์ · ตารางไขว้ ไซส์ × ขั้นจำนวน: ช่อง = ราคาที่เสนอ (กดแก้) + กำไร/ชิ้น (%) + สถานะช่อง + เทียบครั้งก่อน (ช่องเดียวกัน) · คอลัมน์ "ตีราคา → ปัจจุบัน" ต่อไซส์ · ช่องว่าง ＋ เพิ่มช่องเข้าครั้งเดิม
- เพิ่มครั้งใหม่ = `NewRoundEditor` ตารางไขว้กรอกทีเดียว (เตรียมไซส์/ขั้นจำนวน/ราคาจากครั้งล่าสุด · เติมจากตีราคา · เพิ่ม/ลบขั้นจำนวน · ติ๊กไซส์) → `POST /quotes/batch` (บันทึกตีราคาที่ค้างก่อน)
- API `quotes/batch` POST/PATCH(date/note/status ทั้งครั้ง)/DELETE · `POST /quotes` รับ `batch` (เพิ่มช่องเข้าครั้งเดิม) · GET `changes` เทียบ batch ก่อนหน้าไซส์เดียวกัน
