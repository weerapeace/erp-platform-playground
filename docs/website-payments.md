# 💳 รับเงินเว็บร้าน: แนบสลิป + ตรวจสลิปอัตโนมัติ

เจ้าของเลือกแบบ **A+B** (2026-10-20): ลูกค้าโอนพร้อมเพย์ด้วย QR ที่ใส่ยอดไว้แล้ว → แนบสลิปบนเว็บ → ระบบตรวจสลิปอัตโนมัติ

## ลำดับงาน

```txt
ลูกค้าสั่ง (เลือกพร้อมเพย์) → QR ยอดตรง → โอน → แนบสลิป (หน้าขอบคุณ / หน้าติดตามคำสั่งซื้อ)
  → ตรวจอัตโนมัติ (EasySlip) ผ่าน      → ออเดอร์ "ชำระแล้ว" ทันที (+ อีเมลแจ้ง ถ้าร้านเปิด)
  → ไม่ผ่าน / ตรวจไม่ได้ / ไม่ได้เปิด → ออเดอร์ "แจ้งโอนแล้ว · รอตรวจ" → ERP แท็บ 🧾 ออเดอร์ ตัวกรอง 💳 รอตรวจเงิน
        → พนักงาน ✓ ยืนยันรับเงิน (→ ชำระแล้ว) หรือ ✕ สลิปไม่ถูกต้อง + เหตุผล (→ ยังไม่ชำระ ลูกค้าแนบใหม่ได้)
```

## กติกาความปลอดภัย

- "ผ่าน" ได้ทางเดียว: อ่านสลิปได้ + **ยอดตรง (±1 สตางค์)** + **บัญชีผู้รับตรงกับบัญชีที่ลงทะเบียนไว้ใน EasySlip** + **ไม่ซ้ำ** (เลขอ้างอิงสลิปไม่เคยใช้กับออเดอร์อื่น)
- ระบบ **ไม่ปฏิเสธสลิปเอง** — ไม่ผ่านเมื่อไรส่งให้คนตรวจเสมอ (กันบริการตรวจล่มแล้วลูกค้าที่จ่ายจริงโดนตีกลับ)
- ลูกค้าต้องรู้ทั้งเลขที่ออเดอร์ + เบอร์โทร · ดูหัวไฟล์จริง (JPG/PNG/WEBP) · ≤ 4MB · ≤ 5 สลิป/ออเดอร์
- ไฟล์สลิปอยู่ Supabase Storage bucket `payment-slips` (private) — พนักงานดูผ่านลิงก์ชั่วคราว 15 นาที
- ทุกการเปลี่ยนสถานะเขียน `audit_logs` (entity `store_orders`)

## ตั้งค่า (ERP → 🌐 เว็บไซต์ → ร้าน → 🏪 ข้อมูลร้าน → 🧾 การสั่งซื้อ)

| ช่อง | ความหมาย |
|---|---|
| รับโอนพร้อมเพย์ + เลขพร้อมเพย์ | ต้องมีเลข QR ถึงจะขึ้นให้ลูกค้า |
| 📎 ให้ลูกค้าแนบสลิปบนเว็บ | ค่าเริ่มต้น = เปิด |
| 🤖 ตรวจสลิปอัตโนมัติ (EasySlip) | ค่าเริ่มต้น = ปิด · เปิดแล้วต้องมี env `EASYSLIP_API_KEY` ด้วย (ไม่มี = แท็บออเดอร์ขึ้นแถบเตือน) |

### เปิดตรวจอัตโนมัติ (เจ้าของทำเอง)
1. สมัคร easyslip.com → สร้าง API key (เลือก API v2)
2. ในเว็บ EasySlip ลงทะเบียน **บัญชีรับเงินของร้าน** (บัญชีที่ผูกพร้อมเพย์) — ไม่ลง = ทุกสลิปตกข้อ "บัญชีผู้รับไม่ตรง" ไปให้คนตรวจ
3. Vercel → project ERP → Settings → Environment Variables → `EASYSLIP_API_KEY` = key → Redeploy
4. ERP แท็บข้อมูลร้าน → ติ๊ก 🤖 ตรวจสลิปอัตโนมัติ

- `lib/website-payments-server.ts` — `submitSlip` · `staffDecideSlip` · `slipsForOrders`
- `app/api/public/storefront/orders/slip/route.ts` — ลูกค้าแนบสลิป (สาธารณะ + CORS)
- `app/api/website/orders/route.ts` — GET ส่ง `slips` + `slipAuto` · PATCH `{ slipId, slipAction, reason }`
- `components/website-slip-review.tsx` — กล่องสลิปในรายละเอียดออเดอร์
- ตาราง `store_payments` (migration `202610201700`) · `store_orders.payment_status` เพิ่มค่า `verifying`
- เว็บร้าน (repo storefront): `src/components/checkout/SlipUpload.tsx` ใช้ที่ CheckoutClient (หน้าขอบคุณ) + TrackClient

## ข้อจำกัด / ทำต่อ

- เว็บ Pixiedustie (repo pixiedustie-store) ยังใช้ระบบสลิปเดิมของตัวเอง
- ยืนยันรับเงินแล้ว ยังไม่สร้างใบรับชำระ (`/receipts`) อัตโนมัติ — ทำเมื่อออเดอร์เว็บต่อใบสั่งขาย ERP ครบ
- ยังไม่มีแจ้งเตือนพนักงาน (LINE) ตอนมีสลิปรอตรวจ — ดูจากตัวเลขบนตัวกรอง 💳 รอตรวจเงิน
