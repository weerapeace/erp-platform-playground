# ColResize — ลากขยายคอลัมน์ (ตารางที่เขียนเอง)

ไฟล์: `components/col-resize/index.tsx` · เริ่มใช้ 2026-11-28 (เจ้าของ: "อยากได้ที่ขยาย column ด้วย")

## ใช้ทำอะไร
ให้ตาราง/กริดที่ "เขียนเอง" ลากเส้นหัวคอลัมน์เพื่อปรับความกว้างได้ เหมือนตารางกลาง
- ลากเส้นที่ขอบขวาของหัวคอลัมน์ = ปรับความกว้าง
- ดับเบิลคลิกเส้น = พอดีเนื้อหา (วัดทุกช่องที่มี `data-col` เดียวกัน)
- `cw.reset()` = คืนความกว้างเดิม
- จำต่อคน ตามไปทุกเครื่อง (`useUserPref`) — ไม่ต้องกดบันทึก

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ใช้: ตารางที่เขียนเองและยังย้ายไปตารางกลางไม่ได้ (แถวบิลร้านที่กางแก้ในแถว · ตารางกล่องในใบส่งของ)
- ห้าม: MiniTable / DataTable / LineItemsGrid — มีในตัวแล้ว · ตารางใหม่ให้ใช้ตารางกลางก่อน

## ตัวอย่าง
```tsx
const cw = useColWidths("my_table_cols", { min: 36 });
const COLS: [string, string][] = [["mt_no", "3rem"], ["mt_name", "1fr"], ["mt_qty", "5rem"]];
// กริด
<div className="grid" style={{ gridTemplateColumns: cw.track(COLS) }}>
  <span className="relative">ชื่อ<ColGrip {...cw.grip("mt_name")} /></span>
</div>
// แถว: ช่องที่อยากให้ "พอดีเนื้อหา" ใส่ data-col="mt_name"
// ตาราง <table>: <col style={{ width: cw.px("mt_qty") ?? 80 }} /> + table-fixed
{cw.changed && <button onClick={cw.reset}>คืนความกว้างคอลัมน์</button>}
```
- คีย์คอลัมน์ควรมีคำนำหน้าเฉพาะตาราง (เช่น `sb_`, `db_`) — ดับเบิลคลิกวัดทั้งหน้า จะได้ไม่ชนตารางอื่น
- คอลัมน์ `1fr` ที่ถูกตั้งเป็น px → คอลัมน์สุดท้ายยืดแทน แถวยังเต็ม · `cw.minWidth(COLS)` ไว้ตั้ง min-width ให้เลื่อนซ้ายขวาได้

## สิทธิ์ / ประวัติ
ค่าความกว้างเป็นค่าหน้าจอส่วนตัว ไม่มีสิทธิ์/ไม่ลงประวัติ

## ใช้ที่
- `components/seller-bill-panel` — แถวบิลร้าน (หน้าใบสำคัญรับ / จ่ายร้านจีน)
- `components/delivery-bill-panel` — ตารางกล่องในใบส่งของจากขนส่ง

## ข้อจำกัด
- มือถือ: แถวที่เป็นการ์ด (flex) ไม่ใช้ความกว้างนี้
- ช่องที่เป็นช่องกรอก (input) ดับเบิลคลิกจะพอดีหัวคอลัมน์ ไม่ใช่ค่าที่พิมพ์
