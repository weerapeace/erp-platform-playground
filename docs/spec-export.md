# ส่งออกรายละเอียดสินค้า (หลายรุ่น → Excel)

หน้า: `/master/parent-skus/export` · เปิดจากหน้า Parent SKUs (ปุ่ม "ส่งออกรายละเอียด" บนหัว หรือติ๊กหลายแถวแล้วเลือก "ส่งออกรายละเอียด" ในแถบที่เลือก)

## ใช้ทำอะไร
รวมรายละเอียดสินค้าหลายรุ่นเป็นไฟล์ Excel ส่งลูกค้า/ตัวแทน/แพลตฟอร์ม — เลือกภาษา (ไทย / English / ทั้งคู่) · เลือกช่อง (ทุกช่องในทะเบียนฟิลด์ แบ่งหมวด) · เลือกแบบแสดง

| แบบแสดง | ผล |
|---|---|
| 1 รุ่น = 1 แถว | ไม่มีช่องของ SKU ลูก |
| 1 รุ่น = 1 แถว + สรุปสี | เพิ่มช่อง "สีที่มี" รวมทุกสีในช่องเดียว |
| แยกแถวตาม SKU ลูก (ค่าเริ่มต้น) | 1 สี = 1 แถว · ช่องของรุ่น **รวมเป็นช่องเดียว** (ค่าเริ่มต้น) หรือ **ซ้ำทุกแถว** (กรอง/เรียงใน Excel ง่าย) |

ตัวเลือกอื่น: รูป = ฝังรูปเล็ก (ค่าเริ่มต้น) / ลิงก์รูป / ไม่ใส่ · หัวตาราง 2 ชั้น (ข้อมูลรุ่น / ข้อมูลสี) · ซ่อนสีที่เลิกขาย · ติ๊กออกรายสี

## ชุดช่อง (ใช้ร่วมกันทั้งทีม)
จำ ช่อง + ภาษา + แบบแสดง + รูป ไว้เป็นชื่อ เช่น "ส่งตัวแทนต่างประเทศ" — ตาราง `spec_export_presets` · API `/api/parent-skus/spec-export/presets` · ค่าที่ใช้ล่าสุดจำในเครื่องผู้ใช้ (localStorage)

## ช่องที่ยังไม่แปล
ภาษา English / ทั้งคู่: ช่องที่มีคู่ภาษา (ชื่อสินค้า · Introduction · Description · Name Platform · สีสำหรับลงขาย ฯลฯ) ถ้าฝั่งไทยมีแต่ฝั่งอังกฤษว่าง **หรือฝั่งอังกฤษยังเป็นภาษาไทย** (ข้อมูลจริงหลายตัวคัดลอกสีไทยมาใส่) → ติดสีเหลือง + เตือนจำนวน
ปุ่ม "ให้ AI แปลช่องที่ว่าง" (ต้องมี products.edit) → `/api/ai/translate` (place `fields`) ทีละ 20 ช่อง → บันทึกกลับเข้าสินค้าผ่าน PATCH `/api/master-v2/{parent-skus|skus}/<id>` (audit ของกลาง) → ครั้งหน้าไม่ต้องแปลอีก
คู่ภาษาอ่านจาก `ui_style.lang_en` ในทะเบียนฟิลด์ (ตัวเดียวกับปุ่ม TH/EN ในป๊อป Parent SKU) · ค่าสำรองในโค้ด `FALLBACK_PAIRS` (สีของ SKU ลูก)

## สิทธิ์ / ประวัติ
- ดู/ส่งออก: `products.view` · บันทึกชุดช่อง + AI แปลแล้วบันทึก: `products.edit`
- ช่องที่ทะเบียนติ๊ก `is_sensitive` ต้องมี `sensitive_permission` (ราคา/ต้นทุน = `products.cost.view`) · `view_roles` ในทะเบียนตัดซ้ำ — ตัดที่ server ทั้งรายการช่อง (GET) และข้อมูล (POST)
- กดดาวน์โหลด = บันทึกประวัติ `audit_logs` action `export` entity `parent_skus_v2` (metadata.feature = `spec_export`: รหัสสินค้า · ช่อง · ช่องที่ถูกตัด · ภาษา · แบบแสดง · รูป) · ดูตัวอย่างไม่บันทึก

## ข้อจำกัดที่รู้
- ส่งออกได้ครั้งละไม่เกิน 500 รุ่น · รูปฝังทีละ 6 พร้อมกัน (สินค้าเยอะ + รูปเยอะ = รอนาน ไฟล์ใหญ่ขึ้น ~3-5KB/รูป)
- ยังไม่มี "รูปเพิ่มเติม" (แกลเลอรี 9 รูป) — มีแค่รูปหลัก / รูปตัดพื้น / รูปประจำสี
- ช่องที่ไม่มีคู่ภาษา (เช่น วัสดุ) ส่งค่าเดิมทั้งภาษาไทย/อังกฤษ ไม่เตือน
- ช่องคำนวณแบบตัวเลข (สูตร) ไม่อยู่ในรายการ · ช่อง JSON (จุดเด่น/ใส่อะไรได้/ช่องใส่ของ) แปลงเป็นข้อความคั่นจุลภาค
