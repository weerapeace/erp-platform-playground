# 📂 หมวดหมู่สินค้าบนเว็บ (ต่อร้าน)

## ใช้ทำอะไร
- จัดหมวดของเว็บร้าน (แยกจากหมวดใน ERP) — ชื่อ · คำอธิบาย · **รูปหมวด** · **แบนเนอร์หน้าหมวด** · ลำดับ
- จัดสินค้าลงหมวด — **1 รุ่นอยู่ได้หลายหมวด** (หมวดแรก = หมวดหลัก ใช้เป็นป้ายบนการ์ด)
- หน้าแรกโชว์หมวดได้ 4 แบบ (Section "หมวดสินค้า")

## ใช้ที่ไหน (ERP)
- `/website/<ร้าน>` → แท็บ **📂 หมวดหมู่** (`components/website-categories-panel.tsx`)
  - ซ้าย: รายการหมวด (ลากเรียง · ➕ เพิ่มหมวด) · ขวา: แก้หมวด + สินค้าในหมวด (➕ เพิ่มทีละหลายรุ่น · ✕ เอาออก)
  - รายการหมวดบันทึกเองหลังหยุดแก้ 0.7 วิ · สินค้า↔หมวด บันทึกทันที
  - รหัสหมวด (ใช้ในลิงก์ `/shop?cat=`) ตั้งตอนสร้างแล้วเปลี่ยนไม่ได้ — กันลิงก์/เมนูเดิมเสีย
  - ลบหมวด = ConfirmDialog → เอาหมวดนี้ออกจากสินค้าทุกตัว (สินค้ายังอยู่บนเว็บ)
- แท็บ "สินค้าบนเว็บ": ช่อง "หมวดบนเว็บ" เป็นชิปเลือกหลายหมวด (★ = หมวดหลัก)
- แท็บ "⚙️ จับคู่ฟิลด์" (2026-10-18 ปรับให้โล่ง — `components/website-field-map-panel.tsx`):
  - การ์ด "หมวดสินค้าบนเว็บร้านนี้" = **สรุปอย่างเดียว** (จำนวนหมวดหลัก/ย่อย + ชิปหมวดหลัก) + ปุ่ม "จัดการหมวดที่แท็บ 📂 หมวดหมู่ →" — เดิมเป็นตัวแก้หมวดแบบแบนซ้ำกับแท็บ 📂 และแก้รหัสได้ (แก้แล้วลิงก์เสีย + สินค้าหลุดหมวด) จึงย้ายการแก้ทั้งหมดไปแท็บ 📂 ที่เดียว
  - การ์ด "จับคู่หมวด ERP → หมวดบนเว็บ" (กฎใช้กับสินค้าที่ยังไม่เคยจัดเอง เช่น สินค้าที่เพิ่งเพิ่มขึ้นเว็บ · บอกจำนวนรุ่นที่ใช้กฎจาก `listingStats` ของ `GET /api/website/field-map`): แถบ "ไม่ได้จับคู่ → ไปหมวด" (ค่าเริ่มต้น) · ค้นหา + ปุ่มกรอง ทั้งหมด/จับคู่แล้ว/ยังไม่จับคู่ · เมนู ⋯ = ตั้งทั้งหมดที่เห็นเป็นหมวดเดียวกัน (ป๊อป ERPModal) / ล้างการจับคู่ที่เห็น · ช่องเลือกหมวดเรียงแบบต้นไม้ (↳ หมวดย่อย) · เลือก "ค่าเริ่มต้น" = ลบกฎทิ้ง · บันทึกด้วย SaveBar เหมือนเดิม

## ข้อมูล
| ที่เก็บ | ช่อง | ความหมาย |
|---|---|---|
| `shops.field_map.categories[]` | `key label icon blurb imageKey bannerKey` | รายการหมวดของร้าน (เรียงตามนี้) |
| `store_listings.web_categories` (text[]) | | **null** = ยังไม่เคยจัด → หมวดเดียวแบบเดิม (`web_category` กรอกทับ / กฎจับหมวด ERP / หมวดตั้งต้น) · **array** (รวมว่าง) = จัดเองแล้ว ใช้ตามนี้ · ตัวแรก = หมวดหลัก |

- คำนวณที่ `resolveCategories()` (`lib/website-field-map.ts`) — รหัสที่ไม่มีในรายการหมวดแล้วถูกข้าม
- API: `POST /api/website/listings` `{ action: "setCategories", shopId, category, items: [{ parentId, categories }] }` (guardApi `products.edit` + audit 1 แถวต่อครั้ง)
- API สาธารณะ products ส่ง `category` (หลัก) + `categories` (ทั้งหมด) · site ส่ง `categories` (รวม imageKey/bannerKey)
- migration: `supabase/migrations/202610150100_store_listings_web_categories.sql`

- ERP ช่อง "หมวดที่โชว์" = `components/website-categories-field.tsx` (2026-10-18 แบบ A ที่เจ้าของเลือก): แถวเฉพาะหมวดที่เลือก (รูปย่อ+ชื่อ) ลาก ⠿ เรียง · ✕ เอาออก (ล้างรูปของหมวดนั้นด้วย) · ＋ เลือกหมวด = ป๊อปติ๊กต้นไม้+ค้นหา · 🖼 = ตั้งรูปบนการ์ด: ⬆ อัปโหลด/ลากรูปมาวางที่แถว (เข้าคลังรูป) · คลังรูป (AssetPicker) · รูปสินค้าในหมวด (ImageChooser `initialView="products"` + `categoryKeys` · สลับดูทั้งร้านได้) · ↺ ใช้รูปหมวดเดิม · API layout/pages ส่ง `imageKey`/`icon` ของหมวดมาให้รูปย่อ
- เว็บร้าน: ตัวแสดงผลกลาง `src/components/home/CategoriesView.tsx` ใช้ทั้งเว็บจริง (`MaterialCategories` ดึงหมวด) และพรีวิวสด (`LiveBlocks` ได้รายการหมวดจากเซิร์ฟเวอร์) → แก้แบบแสดงแล้วเห็นทันที
- ไม่มีรูปหมวด = ใช้ไอคอน · รูปใช้ LoadImg + กรอบรอรูป (sf-ph)
- หน้าร้าน (`ShopClient`): เลือกหมวด → หัวหน้าหมวด (แบนเนอร์ + ชื่อ + คำอธิบาย) + ลิงก์ในแถบที่อยู่เปลี่ยนเป็น `?cat=` · กรองหมวดด้วย `categories` (หลายหมวด)

## ลำดับสินค้าในหมวด
- แท็บหมวดหมู่ → สินค้าในหมวด → ลาก ⠿ เรียง → เก็บที่ `field_map.categories[].order` (รหัสรุ่น) — ตัวที่ไม่อยู่ในรายการต่อท้ายตามลำดับรวม
- หน้าร้าน: เลือกหมวด + เรียง "แนะนำ" + ไม่ได้ค้นหา = เรียงตามนี้ (`sortByCategoryOrder` ใน src/lib/products.ts) · Section ตารางสินค้า (ทั้งหมวด) ก็เรียงตามนี้

## เมนูหมวด
- ชนิดเมนูใหม่ `categories` "📂 หมวดทั้งหมด (อัตโนมัติ)" — ลิงก์ /shop + เมนูย่อย = ทุกหมวด (Navbar เติมเอง · เปิด Mega = โชว์รูปหมวด)
- ร้านที่ยังไม่จัดเมนูเอง (ไม่ใช่ร้าน IG เดิม) + มีหมวด: "สินค้าทั้งหมด" มีเมนูย่อยหมวดให้อัตโนมัติ

## Section หมวดสินค้า: ขนาดรูป
- `imgFit` (รูปใหญ่: เต็มการ์ด/เห็นทั้งรูป) · `imgSize` 40–200 % (การ์ดไอคอน/รูปใหญ่/รูปเล็ก)

## ข้อจำกัดที่รู้แล้ว
- ร้าน IG เดิม: สินค้าที่ไม่มีหมวดตกไป "อะไหล่" เหมือนเดิม · ร้านอื่น = ไม่มีป้ายหมวด

## 🔎 หน้าหมวดสำหรับ Google (2026-10-14)
- ทุกหมวดมีหน้าของตัวเอง **`/c/<รหัสหมวด>`** (เว็บร้าน `src/app/c/[key]/page.tsx` → ของกลาง `ShopView` ตัวเดียวกับ `/shop`)
  - title = `seoTitle` (ตั้งเอง ใช้ทั้งประโยค) หรือ "<ชื่อหมวด> — <ชื่อร้าน>" · description = `seoDescription` หรือ `blurb` · canonical = `/c/<รหัส>` (ใช้โดเมนที่ลูกค้าเข้ามา)
  - รหัสที่ไม่มีในร้าน = 404 · sitemap.xml ใส่ `/c/<รหัส>` ทุกหมวด
  - หัวหน้า (h1) = ชื่อหมวด + คำอธิบาย + แบนเนอร์ · สลับหมวดในหน้า → ลิงก์ในแถบที่อยู่เปลี่ยนเป็น `/c/<อีกหมวด>` (ทั้งหมด = `/shop`)
- ลิงก์เก่า `/shop?cat=<รหัส>` ยังเปิดได้ + canonical ชี้ `/c/<รหัส>` (Google ไม่นับเป็นหน้าซ้ำ)
- ERP: `field_map.categories[].seoTitle` (≤70) / `seoDescription` (≤170) — แท็บ 📂 หมวดหมู่ กล่อง "🔎 หน้าหมวดใน Google" (นับตัวอักษร + ตัวอย่างผลค้นหา)
- ลิงก์หมวด = ของกลาง: ERP `categoryHref()` / `categoryKeyOf()` (lib/website-links.ts — อ่านได้ทั้ง /c/ และ /shop?cat=) · เว็บร้าน `src/lib/links.ts categoryHref()`

## 📂 หมวดย่อย (2026-10-17)
- ซ้อนได้ **2 ชั้น** (หมวด → หมวดย่อย) · เก็บที่ `field_map.categories[].parent` (รหัสแม่ · ว่าง = หมวดชั้นบน) — **ไม่ต้องแก้ DB**
- ของกลาง `lib/website-category-tree.ts` (มิเรอร์ → storefront `src/lib/category-tree.ts`): `cleanParents` (แม่ใช้ไม่ได้ → ชั้นบน) · `categoryTree`/`flattenTree` (array เรียงแบบต้นไม้) · `reorderCategoryTree` (ลาก) · `withParentCategories` · `categoryChoiceLabel` (↳) · `categoryPathLabel` ("แม่ › ย่อย")
- ERP แท็บ 📂: รายการแบบต้นไม้ (ลากหมวดชั้นบน = ย้ายทั้งกลุ่ม · ลากหมวดย่อย = เรียงในแม่เดิม) · ➕ หมวดย่อยใน “…” (ท้ายกลุ่มที่เลือก · รหัสเดาเป็น `<แม่>-<ชื่ออังกฤษ>` · ชื่อไทยต้องตั้งรหัสเอง) · ช่อง "อยู่ใต้หมวด" (หมวดที่มีลูกย้ายไม่ได้) · ตัวเลขข้างหมวดแม่ = รวมหมวดย่อย · ลบหมวดแม่ = หมวดย่อยกลายเป็นหมวดหลัก
- **สินค้าในหมวดย่อย = อยู่ในหมวดแม่ด้วย**: API สาธารณะ products เติมหมวดแม่ต่อท้าย `categories` (หมวดหลัก `category` ยังเป็นหมวดย่อย) → ทุกจุดบนเว็บที่กรองหมวด (หน้าหมวด/ค้นหา/เมนู/Section) นับเอง
- เว็บร้าน: หน้าหมวดแม่ = ชิป [ทั้งหมด · หมวดย่อย…] ใต้ชื่อหมวด · หน้าหมวดย่อย = คำเล็ก "‹ หมวดแม่" + ชิปชุดเดียวกัน + แบนเนอร์ของแม่ถ้าตัวเองไม่มี · แถบตัวกรองซ้าย = กางหมวดย่อยใต้แม่ที่เลือก · ปุ่มหมวด/Section หมวด (ไม่เลือก)/รายการอัตโนมัติในแผงเมนู = หมวดชั้นบน · เมนู "📂 หมวดทั้งหมด" = หมวดย่อยเยื้องใต้แม่ (แบบรายการ + แบบการ์ด)
- ตัวเลือกหมวดใน ERP (Section/ลิงก์/แผงเมนู/รายละเอียดสินค้า/หน้ารายการ) โชว์ ↳ หน้าหมวดย่อย · ชิปหมวดใน drawer สินค้าบนเว็บ = "แม่ › ย่อย"

### ↪ ย้ายสินค้าข้ามหมวด + 📂 หมวดย่อยใต้การ์ด (2026-10-17)
- แท็บ 📂 → สินค้าในหมวด: **ลากการ์ดสินค้าไปวางบนหมวดทางซ้าย = ย้าย** (Ctrl/Alt ค้าง = เพิ่มเข้าอีกหมวด · แถวปลายทางไฮไลต์เขียว) · ช่อง **↪ ย้ายไป…** ในการ์ด · ติ๊ก ☐ หลายรุ่น → แถบล่างจอ (ของกลาง BulkActionBar): ย้าย / ＋เพิ่มเข้าอีกหมวด / เอาออก
- ย้าย = แทนที่หมวดนี้ด้วยปลายทาง **ตำแหน่งเดิม** (หมวดหลักยังเป็นหมวดหลัก) · บันทึกผ่าน setCategories (audit เดิม)
- Section หมวดสินค้า: ช่อง `subs` = none (ค่าเริ่ม) / links → หมวดย่อยเป็นลิงก์เล็กใต้การ์ดหมวดแม่ (≤6 + "+N") · เว็บร้าน CategoriesView `withSubs` (ห่อ div — ไม่ซ้อน <a>) · ไม่มีหมวดย่อย = markup เดิม

## ▸/▾ พับ/ขยายหมวดย่อย (รายการหมวดทางซ้าย)
- หมวดแม่ที่มีหมวดย่อยมีปุ่ม ▸/▾ หน้าแถว · พับแล้วแถวแม่บอก "· N หมวดย่อย" · ปุ่ม ▾ ขยายทั้งหมด / ▸ พับทั้งหมด ด้านบนรายการ
- จำแยกต่อร้านในเครื่องนี้ (localStorage `erp-web-cat-collapsed:<ร้าน>`) — ไม่บันทึกลงฐานข้อมูล ไม่กระทบเว็บร้าน
- ลากเรียงยังใช้ลำดับแถวเต็ม (แถวที่พับแค่ไม่วาด) · เลือก/สร้างหมวดย่อยในกลุ่มที่พับ = กางให้เอง

## 🏷️ แท็ก → หมวดบนเว็บ (2026-10-18)
ตั้งได้ว่า "สินค้าที่ติดแท็กไหน ไปอยู่หมวดไหน" ต่อร้าน (เช่น กระเป๋าเป้ → Backpacks) — แก้ได้ 2 ที่ ข้อมูลชุดเดียวกัน:
- ป๊อป 🔗 ของแท็ก (Tags Manager / 🗂️ จัดการแท็ก) → ส่วน 🌐 เว็บไซต์ → "เข้าหมวดอัตโนมัติ" ต่อร้าน
- หน้าจัดเว็บ แท็บ ⚙️ จับคู่ฟิลด์ → การ์ด "🏷️ แท็ก → หมวดบนเว็บ" (ตารางกฎทั้งร้าน · บันทึกทันที)

**กฎ (เจ้าของเลือก):**
1. ติดหลายแท็ก = อยู่ทุกหมวดที่ตรง · **แท็กย่อยเป็นหมวดหลัก** (แท็กลึกกว่ามาก่อน แล้วค่อยตามลำดับกฎ)
2. ลำดับคิดหมวด: จัดเอง (`web_categories` / `web_category`) → **กฎแท็ก** → กฎหมวด ERP (`category.rules`) → หมวดตั้งต้นของร้าน
3. รุ่นที่จัดหมวดเองแล้ว (รวม array ว่าง `[]`) ไม่เปลี่ยนเอง → ปุ่ม **"ใส่หมวดตามกฎให้ N รุ่นที่มีอยู่"** = เพิ่มหมวดอย่างเดียว ไม่ลบ/ไม่สลับของเดิม (ว่าง → หมวดแรกจากกฎเป็นหมวดหลัก)
4. รุ่นที่ยังไม่จัดเอง (`web_categories` null) ใช้กฎแท็กสด ๆ — ติดแท็กเพิ่มทีหลังก็เข้าหมวดเอง

**ข้อมูล:** `shops.field_map.category.tagRules = { [product_families.id]: <รหัสหมวด> }` · normalizeFieldMap เก็บไว้ (cleanTagRules: รหัสแท็กจริง + หมวดที่ยังมี) · `PUT /api/website/field-map` **คงค่าจาก DB** (แก้ได้ทาง `/api/website/tag-categories` เท่านั้น — กันหน้าที่เปิดค้างทับ)

**API:** `GET /api/website/tag-categories?shop=` (products.view: หมวด + กฎ + แท็ก + จำนวนรุ่นบนเว็บต่อแท็ก + พรีวิวใส่หมวด) · `PUT {shop_id, tag_id, key|null}` · `POST {shop_id, action:"apply", tag_id?, dry_run?}` (products.edit · audit `website.tag_rule.set|apply` พร้อมค่าก่อน/หลัง)

**โค้ด:** กฎ pure `lib/website-tag-categories.ts` (+ เทสต์) · โหลดแท็ก/ความลึก `lib/website-tag-categories-db.ts` (ร้านไม่มีกฎ = ไม่ยิง query เพิ่ม) · ใช้ใน API สินค้าหน้าร้าน · หน้าจัดเว็บ (listings) · แท็บเว็บไซต์ในสินค้า (parent-web-listings) · ป๊อป 🔗 · ช่องเลือกหมวด = ของกลาง `components/website-category-select.tsx`

## 🗂 จัดหมวดแบบเร็ว — แท็บสินค้าบนเว็บ › มุมมอง "🗂 จัดหมวด" (2026-10-20)
ใช้ทำอะไร: จัดหมวดทั้งร้านทีเดียว (เช่น ร้านมีสินค้า 260 ตัวที่ยังไม่ได้จัด) — ไม่ต้องเปิดทีละตัว
- **ขั้น 1 ⚡ ใส่หมวดหลักจากหมวด ERP** — สินค้าที่ "ยังไม่ได้จัด" (web_categories ว่าง/null และไม่มี web_category) จัดกลุ่มตามหมวดใน ERP · แต่ละกลุ่มเลือกหมวดเว็บ (กฎเดิม → เดาจากชื่อ `guessWebCategory` → แก้เองได้) → ปุ่มเดียวใส่ทั้งกลุ่ม
  - API `POST /api/website/listings` `{ action: "applyErpMap", map: { ชื่อหมวด ERP: รหัสหมวดเว็บ | "" } }` — จำกฎลง `field_map.category.rules` (สินค้าใหม่ในหมวด ERP เดียวกันเข้าหมวดนี้เอง) + ใส่ `web_categories` ให้ตัวที่ยังไม่ได้จัด (เลือกหมวดย่อย = ใส่ [แม่, ลูก]) · audit `erp_category_map`
- **ขั้น 2 🗂 กระดาน** — ซ้าย = ต้นไม้หมวด + จำนวน (กอง "⚠️ ยังไม่ได้จัด" · "ยังไม่มีหมวดย่อย" ใต้หมวดที่มีหมวดย่อย) · ขวา = รูปสินค้าในกอง
  - คลิก = เลือก · Shift+คลิก = เลือกเป็นช่วง · ชิป "ย้าย N ตัวไป" (เลข 1–9 = ปุ่มลัด) · ลากรูปไปวางบนหมวดทางซ้าย · ✕ เอาออกจากหมวดนี้ · ↩ ย้อน (Ctrl+Z · จำ 20 ครั้ง) · ดับเบิลคลิก = เปิดตั้งค่าเว็บของสินค้า
  - กติกาการย้าย (`lib/website-category-sort` · มีเทสต์): หมวดย่อย = ตัดหมวดย่อยพี่น้อง ใส่ [แม่, ลูก] · หมวดหลักอื่น = แทนทั้งกลุ่มเดิม · หมวดป้าย (ไม่มีหมวดย่อย เช่น Gifts/Men) = เพิ่ม ไม่ลบหมวดเดิม
  - บันทึกทันทีด้วย action `setCategories` (audit เดิม) · ↩ ย้อนกลับเป็น "ยังไม่ได้จัด" ได้จริง (ส่ง `categories: null` = กลับไปใช้กฎ/ค่าเริ่มต้น)
  - **↪ ย้าย / ＋ เพิ่ม (2026-10-22)** — เลือกปลายทาง (ชิป/เลข/ลากวาง/ค้นหา) แล้ว **ถามทุกครั้ง** ว่าย้ายหรือเพิ่ม (ปุ่ม M / A) · ติ๊ก "จำคำตอบ" = ไม่ถามอีก · ปุ่ม ⚙ บนแถบสลับ ถาม → ย้ายเสมอ → เพิ่มเสมอ (จำต่อคน `useUserPref` key `website_sorter_pick_mode`) · มาจากกองยังไม่ได้จัด/ไปกองพิเศษ = ย้ายอย่างเดียว ไม่ถาม
