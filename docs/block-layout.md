# 🧱 จัดกล่องในหน้า (Block Layout) — ของกลาง

> ทำ 2026-11-11 · เจ้าของเห็น widget "ทำคล้าย Figma จับวางเองได้ไหม" แล้วเลือก **แบบจัดกล่อง** (ไม่ใช่วางอิสระ — วางอิสระเพี้ยนเมื่อจอขนาดต่างกัน)
> โค้ด: `lib/block-layout.ts` (กติกา ล้วน ๆ มีเทสต์) · `components/block-layout/index.tsx` (หน้าจอ) · เทสต์ `lib/__tests__/block-layout.test.ts`

## ใช้ทำอะไร
หน้าที่แบ่งเนื้อหาเป็น "กล่อง" → ให้คนจัดเองได้ 3 อย่าง:
- **ลากสลับลำดับ** (หูจับ — ของกลาง `useDragReorder` ใช้นิ้วบนมือถือได้)
- **เปิด/ปิด** กล่อง (`ToggleSwitch`)
- **ขนาดเต็ม / ครึ่ง** (เฉพาะกล่องที่ประกาศว่าเลือกได้) — ครึ่ง 2 ใบติดกัน = วางคู่ในแถวเดียว · ครึ่งที่ไม่มีคู่ = เต็มแถวเอง (ไม่เว้นช่องโหว่)

## 2 ชั้น
| ชั้น | ใครแก้ | เก็บที่ | หมายเหตุ |
|---|---|---|---|
| **ทั้งทีม** | สิทธิ์ `admin.users` | `ui_config` key `admin_block_layout:<pageKey>` (API กลาง /api/ui-config · บันทึกมี audit `setting_change`) | ทุกคนที่ล็อกอินอ่านได้ (หน้าตาเท่านั้น) · แก้แล้วกด "บันทึกให้ทั้งทีม" |
| **ของฉัน** | ทุกคน | `user_ui_prefs` key `block_layout:<pageKey>` (ทุกเครื่องของคนนั้น) | จัดแล้วจำทันที · ปุ่ม "ใช้แบบของทีม" ล้างของตัวเอง |

รวมค่า: **ของฉัน > ทีม > ค่าเริ่มต้นของหน้า** (ลำดับ: ของฉันตั้ง = ใช้ของฉันทั้งชุด) · เก็บเฉพาะที่ต่างจากชั้นล่าง → ทีมเปลี่ยนทีหลัง คนที่ไม่ได้ตั้งเรื่องนั้นเองได้ตามทีม · กล่องใหม่ที่เพิ่มทีหลังโผล่ต่อท้ายตามค่าเริ่มต้นของมัน

## วิธีใช้
```tsx
const DEFS = useMemo<BlockDef[]>(() => [
  { key: "gallery", label: "รูปงาน", icon: "image" },
  { key: "cost", label: "ต้นทุน/ใบ", icon: "calc", sizes: ["half", "full"] },   // เลือกครึ่ง/เต็มได้ (ค่าเริ่ม = ตัวแรก)
  { key: "chat", label: "คุยล่าสุด", icon: "chat", hidden: true },               // ค่าเริ่ม = ซ่อน
], []);                                                                          // ⚠️ ต้อง memo
const layout = useBlockLayout("my_page", DEFS);
<BlockLayoutRows blocks={layout.blocks} render={(key) => …} />   // คืน null = หน้า/ใบนี้ไม่มีข้อมูลกล่องนั้น (ข้าม)
<BottomSheet …><BlockLayoutEditor layout={layout} missing={setของกล่องที่ไม่มีข้อมูล} /></BottomSheet>
```
- `sizeOverride` = บังคับขนาดชั่วคราว (เช่น กล่อง SKU กางดูอยู่ = เต็มแถว)
- เปิดแผ่นจัดจากเมนู BottomSheet อีกอัน → เปิดหลังเมนูปิด ~300ms (ปุ่ม back ของ 2 แผ่นไม่ชนกัน — useBackClose)

## ห้ามใช้เมื่อ
- ฟอร์ม/หน้าข้อมูลของ MasterCRUD → ตัวออกแบบฟอร์ม (StudioPanel) · คอลัมน์ตาราง → Column Manager ของตารางกลาง · แท็บศูนย์แจ้งเตือน → `CENTER_TABS`

## ใช้แล้วที่
- หน้าใบงานออกแบบมือถือ `/master/design-dashboard/sheet/[id]` แท็บภาพรวม (pageKey `design_sheet_mobile`) — docs/design-sheet-mobile.md

## ข้อจำกัด
- ยังไม่มีพรีวิวใน playground (ดูของจริงที่หน้าใบงานมือถือ)
- แบบของทีม = แบบเดียวต่อหน้า (ยังไม่แยกตามแผนก/บทบาท)
