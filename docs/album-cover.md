# ปกอัลบั้ม (AlbumCover)

> รูปรวมบนการ์ดอัลบั้ม/แฟ้ม — เห็นรูปข้างในก่อนกดเปิด
> โค้ด: `components/album-cover` · ตรรกะแบบปก + เทสต์: `lib/album-cover.ts`, `lib/__tests__/album-cover.test.ts`
> เพิ่มเมื่อ 2026-11-14 — เจ้าของอยากให้อัลบั้ม SAMPLE "เป็นเหมือน folder" และเลือก **แบบ C (ปรับตามจำนวนรูป)** จาก widget เทียบ 4 แบบ

## หน้าตา (แบบ C)

ทรงเดียวกับการ์ดอัลบั้มหน้า Contents (ใหญ่ 1 + เล็กด้านขวา) แต่ไม่มีช่องว่าง:

| รูปในอัลบั้ม | ปก |
|---|---|
| 0 | ไอคอนรูปจาง |
| 1 | เต็มปก |
| 2 | ซ้าย-ขวา |
| 3 | ใหญ่ 1 + เล็ก 2 |
| 4 ขึ้นไป | ใหญ่ 1 + เล็ก 3 · ช่องสุดท้ายขึ้น **+N** (รูปที่ไม่ได้โชว์) |

สัดส่วนปก 4:3 · รูปตัดให้เต็มช่อง (object-cover) · รูปจาก R2 ผ่าน `/api/r2-image` ย่อตามขนาดช่อง (`withImageWidth`)

## วิธีใช้

```tsx
import { AlbumCover } from "@/components/album-cover";

<AlbumCover keys={album.preview_keys} total={album.photo_count} />
// keys = r2_key ของรูปที่จะโชว์ (ใช้ 4 ตัวแรก เรียงตามที่อยากให้เห็น) · total = รูปทั้งอัลบั้ม (คิดแบบปก + ป้าย +N)
```

## ใช้ที่ไหน / ห้ามใช้เมื่อไหร่

- ใช้ที่: หน้า **SAMPLE Images** (`/tasks/samples`) การ์ดอัลบั้ม
- หน้า **Contents** (`components/asset-library/contents/index.tsx`) ยังเขียนปกของตัวเอง (ใหญ่ 1 + เล็ก 2 เสมอ) — ย้ายมาใช้ตัวนี้ได้ทีหลังโดยหน้าตาแทบเหมือนเดิม (ตอนทำมีอีกงานแก้หน้า Contents อยู่ เลยยังไม่แตะ)
- ห้ามใช้: แกลเลอรีรูปเต็มในอัลบั้ม (ใช้กริดรูป/ImageManager) · รูปเดี่ยว (ใช้ `<img>` / HoverImage)

## สิทธิ์ / ข้อจำกัด

- โชว์อย่างเดียว ไม่เขียนข้อมูล · ใครเห็นการ์ดก็เห็นปก (ที่ที่เอาไปใช้คุมสิทธิ์เอง)
- ยังไม่มี "ตั้งรูปปกเอง" — ปกใช้รูปแรก ๆ ตามที่หน้าส่งมา (หน้า SAMPLE = รูปที่ลงก่อน)
