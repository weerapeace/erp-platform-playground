# กฎ "เพิ่มได้ ต้องแก้ + ลบได้" และของกลางที่ใช้

เจ้าของกำหนด (2026-09-29): **หน้าไหนเพิ่มข้อมูลได้ ต้องมีที่แก้ไขและที่ลบ (หรือยกเลิก/ปิดใช้งาน) มาด้วยเสมอ**

## เลือกแบบไหน: ลบ / ยกเลิก / ปิดใช้งาน

| ข้อมูลแบบไหน | ใช้ | เหตุผล |
|---|---|---|
| ใบร่าง ที่ยังไม่มีผลกับใคร | **ลบ** (เก็บสำเนาลง audit log ก่อน) | ยังไม่มีเอกสารอื่นอ้างถึง |
| เอกสารที่ยืนยัน/ส่ง/ออกไปแล้ว | **ยกเลิก** | ต้องเหลือร่องรอย + มีเอกสารอื่นอ้างถึง |
| ข้อมูลหลักที่เอกสารเก่าอ้างถึง (ร้าน, บริษัท, ธนาคาร, พนักงาน) | **ปิดใช้งาน** | ลบแล้วเอกสารเก่าจะชี้ไปหาของที่ไม่มี |
| รายการที่กระทบยอด (สต๊อก, เงิน) | **กลับรายการ / แก้ผ่านตัวคิดส่วนต่าง** | ต้องคืนยอดให้ครบทุกที่ที่เคยเขียน |

ทุกแบบต้อง: ถามยืนยันก่อน (ConfirmDialog / ERPModal) · เช็กสิทธิ์ที่เซิร์ฟเวอร์ · เขียน audit log

## ของกลาง

### `components/delete-draft-doc` — ปุ่ม "🗑 ลบใบร่าง"
```tsx
{detail.status === "draft" && (
  <DeleteDraftButton apiPath="/api/quotations" id={detail.id} docLabel="ใบเสนอราคา"
    number={detail.quote_number} onDeleted={(msg) => { flash(msg); setDetailOpen(false); fetchList(); }} />
)}
```
- ปุ่มโผล่เฉพาะคนมีสิทธิ์ `so.delete` (แอดมิน + ผู้จัดการ · ปรับที่ /admin/role-board)
- ลบไม่ได้ → โชว์เหตุผลในหน้าต่างยืนยัน (เช่น มีใบรับชำระอ้างถึง)
- ใช้แล้วที่: ใบเสนอราคา · ใบขาย · ใบวางบิล

### `lib/sales-doc-delete.ts` — ตรรกะลบใบร่างฝั่งเซิร์ฟเวอร์
`deleteDraftSalesDoc(admin, kind, id, actor)` — ลบได้เฉพาะ `status = draft` และไม่มีเอกสารอื่นอ้างถึง
ตรวจ: ใบรับชำระ · ใบวางบิล · ใบลดหนี้ · ใบส่งสินค้า · ใบสั่งขาย · ออเดอร์เว็บ · การจองสต๊อก
เลขของใบที่ลบจะว่าง → ชุดเลขที่เปิด "นำเลขที่ว่างกลับมาใช้" จะให้ใบถัดไปใช้เอง

### `components/gr-detail-modal` — ใบรับสินค้า (ดู / แก้ / ลบ)
แก้จำนวนหรือลบใบรับ = ระบบคืนยอดใบสั่งซื้อ + สต๊อก + ใบสำคัญร่าง ให้ครบ · เปลี่ยนไฟล์แนบได้ (เอาออกให้ว่างไม่ได้ เพราะเป็นเอกสารบังคับ)
ใช้แล้วที่: หน้ารับของ (แถบสำเร็จ + ประวัติการรับ) · หน้าประวัติการรับ (กดแถว) · หน้าใบสำคัญรับ
**ห้ามแก้ใบรับผ่านหน้า `/m/goods-receipts-v2`** — หน้านั้นแก้แถวตรง ๆ ไม่คืนยอดใบสั่งซื้อ/สต๊อก

### `components/po-detail-modal` — ยกเลิกใบสั่งซื้อทั้งใบ
ปุ่ม "❌ ยกเลิกใบสั่งซื้อ" (หรือ "ปิดยอดที่ค้าง" ถ้ารับมาแล้วบางส่วน) → `/api/purchasing/cancel-line` ทุกรายการที่ยังค้าง
เปิดกลับได้ที่หน้ารับของ → แท็บ "รับครบแล้ว" → ↩ เปิดกลับมารอรับ

## หน้าที่เพิ่มปุ่มแก้/ลบแล้ว (รอบ 2026-09-29)

| หน้า | เพิ่ม | แก้ | ลบ / ยกเลิก |
|---|---|---|---|
| รับของเข้า `/purchasing/receive` | บันทึกรับของ | ✎ เลขใบรับ (ในประวัติ / แถบสำเร็จ) | 🗑 ลบใบรับ (ในป๊อปใบรับ) |
| ประวัติการรับ `/purchasing/receive-history` | — | กดแถว → ✎ แก้ไข | กดแถว → 🗑 ลบใบรับ |
| รับชำระเงิน `/receipts` | + บันทึกรับชำระ | ✏️ แก้ไข (เมนูท้ายแถว) | ยกเลิกใบนี้ |
| ใบเสนอราคา / ใบขาย / ใบวางบิล | สร้างใบ | ✎ แก้ไข (ใบร่าง) | 🗑 ลบใบร่าง · ⊘ ยกเลิก |
| รายการ PO `/purchasing/po-list` | เปิด PO | ✎ แก้ไข | ❌ ยกเลิกใบสั่งซื้อ |
| นับสต๊อก `/inventory/count` | เปิดรอบนับ | กรอก/สแกน/เพิ่ม-ลบรายการ | ยกเลิกรอบ · ↩ เปิดกลับ |

## หน้าที่เพิ่มปุ่มแก้/ลบแล้ว (รอบ 2 — หลังบ้านพร้อมอยู่แล้ว ขาดแค่ปุ่ม)

| หน้า | ที่เพิ่ม |
|---|---|
| กระแสเงินสด → รายจ่าย/รายรับประจำ | ✏️ แก้ (เติมค่าลงฟอร์มด้านล่าง แล้วบันทึกทับ) |
| สัญญาเงินกู้ → ค่าธรรมเนียม | ✏️ แก้ + ถามยืนยันก่อนลบ |
| ทะเบียนบริษัท (หัวบิล) | ปิดใช้งาน / ↩ เปิดใช้งานอีกครั้ง (บริษัทตั้งต้นปิดไม่ได้) |
| ขอแก้สูตร · ขอเพิ่มวัตถุดิบ | "ยกเลิกคำขอ" สำหรับคนที่ขอเอง |
| เป้าหมาย | ✏️ แก้ไขเป้าหมาย · 🗑 ลบเป้าหมาย · ขั้นบันได เพิ่ม/แก้/ลบ (ของกลาง GoalRoadmap: `onEditStep` / `onDeleteStep`) |
| แผนงาน (หน้า dashboard) | ✏️ แก้ชื่องานในการ์ด |
| รายการงาน/โน้ต (ของกลาง record-tasks) | ✏️ แก้ข้อความ |
| งาน → ลิงก์แนบ | ✕ ลบลิงก์ (ถามยืนยัน) |
| ตั้งค่างาน → เส้นทางสถานะ | ✎ แก้ (เติมค่าลงแถวเพิ่ม แล้วบันทึกทับ) |
| หมวดกลางแพลตฟอร์ม | ✎ เปลี่ยนชื่อ |
| ชุดฟิลด์ → ตัวเลือก | กดที่ชื่อเพื่อเปลี่ยนชื่อ (แก้เฉพาะป้าย ค่าที่สินค้าเลือกไว้ไม่หลุด) |
| Partners | 🗑 ปิดใช้งาน (กู้คืนที่หน้า ผู้จำหน่าย / ลูกค้า) |
| Tags Manager | ปุ่ม "🗂️ จัดการแท็ก" เปิดของกลาง TagOrganizerModal (แก้ชื่อ / ลบ / ย้ายกลุ่ม) |
| ส่งออกไฟล์เงินเดือน → รายการประจำ ภ.ง.ด.3 / คนนอกประจำ | "จัดการรายการที่บันทึกไว้": ✏️ แก้ · ปิดใช้งาน · ↩ เปิดใช้งาน |
| แม่แบบสัญญา | แก้ค่าในแม่แบบ (กดที่ค่า / ✕) + "บันทึกทับแม่แบบนี้" ในฟอร์มเพิ่มสัญญา |
| จัดซื้อ → กลุ่ม LINE แจ้งขอซื้อ | 🗑 เอากลุ่มออก (หยุดแจ้งเตือน) |

## ข้อจำกัด
- รอบนับสต๊อกที่ "ปรับแล้ว" ยกเลิกไม่ได้ (สต๊อกถูกปรับไปแล้ว) — ยอดผิดให้เปิดรอบใหม่แล้วปรับอีกครั้ง
- ใบรับที่ออกใบสำคัญและ "ยืนยันแล้ว" แก้/ลบไม่ได้ (ราคาถูกเขียนกลับระบบแล้ว)
- ไฟล์แนบของเอกสารที่ถูกลบ ยังค้างอยู่ในที่เก็บไฟล์ (ไม่ลบตาม)
