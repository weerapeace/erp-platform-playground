# ✂️ ตัวแยกชิ้นจากไฟล์ออกแบบ + อัลบั้มย่อย (คลังไฟล์)

เจ้าของสั่ง 2026-11-27 · เลือกจาก widget: ข้อเสนอ 1 (ตั้งชื่ออัตโนมัติ) · 2 (ลบพื้นขาว) · 3 (มาจากไฟล์ไหน) · 6 (ลากรูปลงอัลบั้มย่อย)

## ใช้ทำอะไร
โยนไฟล์ .ai / .eps / .pdf / .svg ที่มีหลายชิ้นในแผ่นเดียว (เช่น หัวใจ 16 แบบ) → เลือกชิ้นที่ต้องการ → ได้ PNG พื้นใสแยกไฟล์เข้าอัลบั้มในคลังไฟล์

## วิธีใช้ (หน้า /master/assets)
1. กดปุ่ม **✂️ แยกชิ้นจากไฟล์ออกแบบ** หรือลากไฟล์ออกแบบมาวางบนหน้าคลัง
2. ระบบหาชิ้นให้อัตโนมัติ (กรอบสีม่วง = เลือกแล้ว) — คลิกกรอบเพื่อติ๊ก/เอาออก · × ลบกรอบ
3. เครื่องมือ: เลือกทั้งหมด · ล้าง · ⬚ ลากกรอบเอง · 🔗 รวมชิ้นที่ติ๊ก · ✂ แยกชิ้นที่ติ๊ก (1 ชิ้น) · ↶ ย้อน (Ctrl+Z)
4. "ลบพื้นขาว" = ไฟล์ที่มีแผ่นขาวรองพื้น (ระบบเปิดให้เองถ้ามุมแผ่นเป็นสีขาว) · "ความห่างของชิ้น" = ขีดเล็ก ๆ รอบชิ้นนับรวมเป็นชิ้นเดียวไหม
5. ตั้งชื่อ (heart_ → heart_01…) แก้รายชิ้นได้ · ขนาด 512/1024/2048/เท่าจริง (300 DPI) · ขอบใส · เลือกอัลบั้ม (สร้างใหม่ได้)
6. กด "แปลง N ชิ้นเข้าคลัง" → มีแถบความคืบหน้า → สรุปผล (ชิ้นที่ไม่สำเร็จบอกสาเหตุ)

## ข้อจำกัด
- **.eps / .ai รุ่นเก่า (PostScript)** — แปลงเป็น PDF ในเครื่องผู้ใช้ด้วย Ghostscript WebAssembly (`lib/eps-convert.ts` · ไฟล์อยู่ `public/vendor/ghostscript-wasm-0.0.2/` = @jspawn/ghostscript-wasm 0.0.2 ไม่ได้แก้) · ครั้งแรกโหลดตัวแปลง ~16MB (เบราว์เซอร์จำไว้) · ไฟล์ไม่ออกนอกเครื่อง · โหลดเฉพาะตอนโยน .eps
  - ลิขสิทธิ์ AGPL-3.0: ใช้ภายในบริษัทได้ · ต้องเปิดแหล่งโค้ดตัวแปลงให้ผู้ใช้ดูได้ → ลิงก์อยู่ใน `README.txt` + `LICENSE.txt` ในโฟลเดอร์เดียวกัน (ถ้าแก้ตัวแปลงเอง ต้องเผยแพร่ส่วนที่แก้ด้วย — ตอนนี้ไม่ได้แก้)
  - แปลงไม่สำเร็จ (ไฟล์เสีย/ฟอนต์ไม่ครบ) → ระบบบอกให้ Save As เป็น .ai/.pdf ใน Illustrator แทน
- ไฟล์ต้นฉบับ ≤ 4MB เก็บในคลัง (ชนิดไฟล์ออกแบบ) · ใหญ่กว่านั้นเก็บ "ภาพรวมแผ่น" แทน (เว็บรับไฟล์ได้ ~4.5MB) — ไฟล์จริงเก็บ NAS/Drive แล้วใส่ path ในรายละเอียด
- PNG แต่ละชิ้นต้อง ≤ 4MB (ภาพลายเส้นปกติไม่ถึง) · ด้านยาวสูงสุด 4096 px
- ชิ้นที่กรอบทับกัน PNG จะติดส่วนของชิ้นข้าง ๆ มาด้วย → ลากกรอบเองให้พอดี
- SVG ที่อ้างรูป/ฟอนต์ภายนอกอาจวาดไม่ครบ

## ข้อมูล
- PNG ผูกต้นฉบับด้วย `assets.source_asset_id` · หน้ารายละเอียดไฟล์ (SplitFamily) โชว์ "แยกมาจากไฟล์" + "ชิ้นอื่นจากไฟล์เดียวกัน" / ไฟล์ต้นฉบับโชว์ "ชิ้นที่แยกออกมา"
- `GET /api/assets?source_asset_id=<id>` = ชิ้นทั้งหมดของไฟล์นั้น · `POST /api/assets` รับ `source_asset_id`
- ทุกไฟล์ลง audit (create asset) ตามระบบคลังเดิม · แก้ชื่อ/ลบ = ใช้หน้ารายละเอียดไฟล์ตามปกติ (ลบ = ถังขยะ 30 วัน)
- โค้ด: `components/vector-splitter` (หน้าจอ + ตัววาด pdf.js/SVG) · `lib/vector-split.ts` (หาชิ้น/ลบพื้นขาว/ตั้งชื่อ/สเกล · เทสต์ `lib/__tests__/vector-split.test.ts`)

# 📁 อัลบั้มย่อยในอัลบั้ม

- แถบซ้ายคลังไฟล์: ปุ่ม ⋯ ข้างอัลบั้ม → ＋ สร้างอัลบั้มย่อย · ✎ เปลี่ยนชื่อ · ↪ ย้ายไปอยู่ใต้อัลบั้มอื่น · 🗑 ลบ
- ลบ = เก็บใน **ถังขยะอัลบั้ม** ทั้งต้น (อัลบั้มย่อยไปด้วย) · ไฟล์ข้างในไม่หาย · มีปุ่ม "ย้อนกลับ" ทันที + กู้คืนได้ภายหลัง (ลิงก์ 🗑 ถังขยะอัลบั้ม ใต้รายการ)
- ย้ายอัลบั้ม = มีปุ่มย้อนกลับ · ห้ามย้ายไปไว้ใต้ตัวเอง/ลูกตัวเอง
- ลากการ์ดไฟล์ (หรือชุดที่ติ๊กไว้) ไปวางบนอัลบั้ม = ใส่เข้าอัลบั้ม (ย้อนกลับได้ — เอาออกเฉพาะไฟล์ที่เพิ่งใส่)
- DB: `asset_collections.parent_id` + `deleted_at` (migration 202612280100) · อัลบั้ม SAMPLE ยังเก็บแม่ในป้าย description → ย้าย/สร้างย่อยที่หน้า SAMPLE Images เท่านั้น
- API `/api/assets/collections`: POST `parent_id` · PATCH `parent_id` / `restore:true` · DELETE = soft · GET `?trash=1` · bulk `remove_from` · กติกาต้นไม้ `lib/album-options` (`albumDescendantIds`, `canMoveAlbum`)
