# กล่องแบ่งซ้าย-ขวา ดันกันได้ (SplitPanes)

เจ้าของขอ 2026-11-07: ใบงานออกแบบ แท็บข้อมูลงาน "เอาข้อมูลอยู่ซ้าย กล่องรายละเอียดงานอยู่ขวา กดฝั่งไหนจะดันอีกฝั่งเพื่อขยายใหญ่ขึ้น" — ดู widget แล้วเลือก **แบบดัน**

## ใช้ทำอะไร
แบ่งพื้นที่เป็น 2 กล่องซ้าย-ขวา ที่ต้องดูคู่กัน แต่บางทีอยากให้ฝั่งหนึ่งกว้างขึ้นชั่วคราว (เช่น พิมพ์รายละเอียดยาว)

## การทำงาน
| สถานะ | ซ้าย | ขวา |
|---|---|---|
| เริ่มต้น | ครึ่ง | ครึ่ง |
| กดกล่องซ้าย (แบบดัน) | 2 ส่วน | 1 ส่วน (ยังเห็นเนื้อหา) |
| กดกล่องซ้าย (แบบพับ) | เต็ม | แถบแคบ 44px (กดแถบเพื่อสลับ) |
| กล่องแม่แคบกว่า `minSplitWidth` (ตั้งต้น 720px) | เรียงบน-ล่าง | |

- กดตรงไหนก็ได้ในกล่อง = ขยายกล่องนั้น · ปุ่ม "คืนครึ่ง-ครึ่ง" หรือกดเส้นกลาง = กลับครึ่ง-ครึ่ง
- สลับ "ดัน / พับ" ได้มุมขวาบน
- **จำต่อคน** (ฝั่งที่ขยาย + แบบ) ใน `user_ui_prefs` ตาม `prefKey` — หน่วงบันทึก 0.6 วิ
- ขยายตอน **click** (ไม่ใช่ตอนกดลง) → ปุ่ม/ช่องที่กดในกล่องแคบทำงานก่อน แล้วค่อยขยาย
- ตอนพับ เนื้อหาไม่ถูกถอด (ซ่อนไว้) → ตัวแก้ข้อความ/ช่องพิมพ์ไม่หาย

## ใช้ยังไง
```tsx
import { SplitPanes } from "@/components/split-panes";

<SplitPanes prefKey="ds_info_split"
  left={{ title: "ข้อมูลงาน", icon: "document", content: (size) => <Fields cols={size === "wide" ? 3 : size === "half" ? 2 : 1} /> }}
  right={{ title: "รายละเอียดงาน", icon: "note", content: <Detail /> }} />
```
- `content` = ReactNode หรือฟังก์ชันรับ `size` (`half` / `wide` / `narrow` / `rail` / `stack`) — ใช้จัดจำนวนคอลัมน์ตามความกว้าง
- `prefKey` แต่ละหน้าใช้ของตัวเอง · `defaultMode` ("push" ตั้งต้น) · `ratio` (ตั้งต้น 2) · `minSplitWidth`

## ห้ามใช้เมื่อไหร่
- เนื้อหาคนละเรื่องที่ไม่ต้องดูพร้อมกัน → ใช้แท็บ
- อยากปรับขนาดหน้าต่างทั้งใบ → ป๊อปอัปกลาง (ERPModal ลากขยายได้อยู่แล้ว)

## ไฟล์
- `components/split-panes/index.tsx` — หน้าจอ
- `lib/split-panes.ts` — ส่วน pure (คิดขนาด/ตรวจค่าที่จำ) · เทสต์ `lib/__tests__/split-panes.test.ts`
- ตัวอย่าง `app/_demos/split-panes-preview` · ทะเบียนของกลาง key `split-panes`

## ใช้ที่ไหนแล้ว
| หน้า | prefKey | ซ้าย | ขวา |
|---|---|---|---|
| ใบงานออกแบบ แท็บข้อมูลงาน (`components/design-sheet-detail`) | `ds_info_split` | ช่องข้อมูล (ขยาย 3 / ครึ่ง 2 / แคบ 1 คอลัมน์) + ตั๋ว Pattern | รายละเอียดงาน (ตัวแก้ข้อความ) + Note |
