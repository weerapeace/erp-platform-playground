# 📂 คัดลอก path (CopyPathButton) + กฎ "พร้อมโพสต์" ของคอนเทนต์

## CopyPathButton — `components/copy-path-button.tsx`

**ใช้ทำอะไร:** ปุ่ม 📂 คัดลอก "path" = ที่อยู่โฟลเดอร์หรือไฟล์ในเครื่อง เช่น `Z:\Work In Process\[01] New Product\PIX27` หรือ `G:\Shared drives\Louis Montini\…`
เอาไปวางในช่องเลือกไฟล์ของ Windows ตอนอัปไฟล์ขึ้น Shopee, Lazada หรือ TikTok แล้วจะเปิดไปที่โฟลเดอร์นั้นทันที

**การทำงาน**
- มี path เดียว: กดแล้วคัดลอกทันที
- มีหลายอัน: เด้งรายการให้เลือก และบอกว่าแต่ละ path มาจากไหน
- ยังไม่มี path และส่ง `onAdd` มา: ขอบปุ่มเป็นเส้นประ กดแล้วเด้งช่องให้วาง path
- ยังไม่มี path และไม่ได้ส่ง `onAdd`: ปุ่มเป็นสีจาง พร้อมคำอธิบายเมื่อชี้เมาส์
- เครื่องหมายคำพูดที่ติดมากับคำสั่ง "Copy as path" ของ Windows จะถูกตัดออกให้อัตโนมัติ (`cleanPath`)

**ตัวอย่าง**
```tsx
<CopyPathButton paths={[{ path: "Z:\\Work In Process\\PIX27", label: "จากงาน · งานรูปภาพ" }]}
  onAdd={(p) => addAttachment({ kind: "path", url: p })} notify={pushToast} />
```

**ของที่ใช้ร่วมกันในไฟล์เดียวกัน:** `AddPathForm` (ช่องวาง path) · `cleanPath` · `isLocalPath`
**คัดลอกข้อความ:** `copyText()` ใน `components/copy-button.tsx` ลอง `navigator.clipboard` ก่อน ถ้าใช้ไม่ได้ (http, in-app browser, ไม่มีสิทธิ์) จะใช้ `execCommand` แทน

**ที่ใช้ตอนนี้:** การ์ดแคปชั่นต่อแพลตฟอร์มในคอนเทนต์ (`app/tasks/content/content.tsx` CaptionCard) และการ์ด 🖼 รูป/วิดีโอ

**path ของคอนเทนต์มาจาก 2 ที่ (ไม่ต้องแก้ DB)**
1. path ที่งานย่อยแนบไว้ตอนส่งงาน: `erp_creative_attachments` kind=`drive_link` (ป๊อปส่งงานคอนเทนต์ใน subtask-manager)
2. path ที่ใส่ในโพสต์เอง: `erp_creative_attachments` kind=`path` (content_id) เพิ่มได้ที่การ์ดรูป/วิดีโอ หรือกดปุ่ม 📂 ตอนยังไม่มี path · ลบได้ด้วย ✕ · มี audit log `attachment:add`

**ข้อจำกัด**
- เบราว์เซอร์ไม่ยอมเปิดโฟลเดอร์ในเครื่องจากเว็บ จึงทำได้แค่ "คัดลอก" ไม่ได้ "เปิด"
- ถ้าต้องการปุ่มเปิดโฟลเดอร์ ให้ดูตัวเปิด `erpfolder:` ของคลังไฟล์ (Artwork)
- ยังไม่แยก path ต่อแพลตฟอร์ม (เจ้าของเลือก 2026-10-16) ทุกแพลตฟอร์มใช้ path ชุดเดียวกันของโพสต์

## กฎ "พร้อมโพสต์" — `lib/content-readiness.ts` (`platformReadiness`)

ใช้ที่ปฏิทินคอนเทนต์: การ์ดลอย, วงสีไอคอนแพลตฟอร์ม และตัวกรอง ⚠ ยังไม่พร้อม
- ถ้าตั้งสถานะไว้แล้ว (โพสต์แล้ว / ตั้งเวลาแล้ว / ข้าม) จะแสดงตามสถานะนั้น
- **แคปชั่น:** ต้องมีข้อความ ยกเว้นแพลตฟอร์มที่ตั้ง "ไม่ใช้แคปชั่น" ไว้ที่ ⚙️ ตั้งค่าแพลตฟอร์ม (`use_caption=false` เช่น Shopee/Lazada) ซึ่งมีรูปอย่างเดียวก็พร้อมโพสต์
- **รูป:** ใช้รูปที่เลือกไว้ต่อแพลตฟอร์มก่อน ถ้ายังไม่เลือกจะใช้รูปแนบของโพสต์ (ตรงกับรูปที่ระบบเลือกให้ตอนกดโพสต์จริง) · รูปที่อยู่แค่ในงานที่ผูกไว้ยังไม่นับ
- ตั้งค่าแพลตฟอร์มใช้แคช key `PLATFORM_SETTINGS_SWR_KEY` ร่วมกัน เมื่อบันทึกใน drawer ปฏิทินจะเปลี่ยนตามทันที
- มี test อยู่ที่ `lib/__tests__/content-readiness.test.ts`

## ประกอบข้อความแคปชั่น (ของกลาง) — `app/tasks/content/caption-assemble.ts`

**ใช้ทำอะไร:** สร้าง "ข้อความที่จะโพสต์" ของแต่ละแพลตฟอร์ม โดยรวม แม่แบบ + แคปชั่น + แฮชแท็ก + ตัวแปรสินค้า (ราคา / สี / ลิงก์ร้าน / หลายสินค้า) เข้าด้วยกัน
ปุ่ม 📋 ใน drawer และปุ่ม 📋 ในการ์ดลอยของปฏิทิน ใช้ตัวนี้ร่วมกัน จึงคัดลอกได้ข้อความเดียวกันเป๊ะ

**ฟังก์ชัน**
- `buildCaptionVars` (คำนวณอย่างเดียว ไม่ยิง API): สร้างตัวแปรแม่แบบ ส่วนค่าราคา/สีที่หน้าจอใช้แสดงจะคืนออกมาด้วย
- `assembleCaption`: ประกอบข้อความของ 1 แพลตฟอร์ม และตัดแคปชั่น/แฮชแท็กออกถ้าตั้งปิดไว้
- `captionTemplateFor`: เลือกแม่แบบของแพลตฟอร์มนั้น
- `captionsForDetail`: แพลตฟอร์มที่ยังไม่มีแถวแคปชั่นจะใช้แฮชแท็กเริ่มต้น
- `loadCaptionTexts(contentId)`: โหลดข้อมูลที่บันทึกไว้แล้วประกอบข้อความครบทุกแพลตฟอร์ม ใช้ในหน้าที่ไม่ได้เปิด drawer

**ปฏิทิน (การ์ดลอย):** แต่ละแพลตฟอร์มมีปุ่ม 📋 คัดลอกแคปชั่น และ ☐ โพสต์แล้ว
- ข้อความแคปชั่นโหลดไว้ตั้งแต่ตอนเปิดการ์ด กดคัดลอกได้ทันที และเก็บไว้ใช้ซ้ำจนกว่าโพสต์จะถูกแก้
- ติ๊กโพสต์แล้วจะบันทึก `post_status` ทันทีเหมือนใน drawer ถ้าบันทึกไม่สำเร็จจะย้อนกลับเอง
- แพลตฟอร์มที่ตั้งข้ามหรือตั้งเวลาไว้แล้ว จะไม่มีปุ่ม ☐ โพสต์แล้ว
