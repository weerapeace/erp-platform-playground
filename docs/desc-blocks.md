# คำอธิบายประกอบเป็นบล็อก (Desc Blocks) — ของกลาง

## ใช้ทำอะไร
ช่องคำอธิบายที่ "ระบบประกอบให้เอง" เช่น **Platform Description** ของ Parent SKU (ข้อความยาวที่ก๊อปไปลงขายตามแพลตฟอร์ม)
ตั้งได้ว่ามีส่วนไหนบ้าง เรียงแบบไหน และแก้ข้อความคงที่ (นโยบายเปลี่ยนสินค้า เงื่อนไขการสั่งซื้อ ฯลฯ) — ไม่ต้องแก้โค้ด

## ใช้ยังไง (แอดมิน)
1. เปิดสินค้า (Parent SKU) → หัวข้อ **Platform Description** → กด **⚙** ข้าง TH/EN
2. แต่ละบล็อก: ติ๊กเปิด/ปิด · ลาก **⠿** สลับลำดับ · เลือก **เว้นบรรทัด** / **ติดบรรทัดบน**
3. บล็อกข้อความ (Notes · รับประกัน · เปลี่ยนสินค้า · สั่งซื้อ · ติดตามร้าน · หัวข้อรายละเอียด) กด **✏️** แก้ไทย/อังกฤษ
   - ปุ่มแทรกตัวแทน: `{แบรนด์}` `{รับประกัน}` `{รหัส}` `{ชื่อสินค้า}` → ระบบใส่ค่าของสินค้านั้นให้
   - **↺ ข้อความตั้งต้น** = กลับไปใช้ข้อความของระบบ
4. **＋ เพิ่มข้อความพิมพ์เอง** ได้หลายอัน (ลบได้) · ช่องอังกฤษว่าง = ไม่ใส่ในฉบับอังกฤษ
5. ดูตัวอย่างสดของสินค้าที่เปิดอยู่ (สลับ TH/EN) → บันทึก → มีผลกับ **ทุกสินค้า** ทั้งไทยและอังกฤษ

**ยังไม่กดบันทึก = สูตรเดิมทุกตัวอักษร** · ค่าตั้งต้นในป๊อป = โครงเดียวกับสูตรเดิม (ต่างแค่ไม่มีเว้นวรรค 2 ช่องหน้าบทนำ)

## บล็อกที่มี
| บล็อก | มาจาก | หมายเหตุ |
|---|---|---|
| บทนำ | Introduction / Introduction En | |
| รายละเอียดสินค้า | หัวข้อ (แก้ได้) + Description / English Description | |
| คำอธิบายขนาด · วิธีวัดขนาด · คำอธิบายพิเศษ | ช่องของสินค้า | มีแต่ภาษาไทย (ฉบับอังกฤษข้าม) |
| ขนาดสินค้า / น้ำหนัก | กว้าง×สูง×หนา หรือขนาดพิมพ์เอง + น้ำหนัก (ถ้าติ๊กโชว์) | คำนวณให้ |
| Notes · เปลี่ยนสินค้า · สั่งซื้อ · ติดตามร้าน | ข้อความ | แก้ได้ |
| รับประกัน | ข้อความ + `{รับประกัน}` | ข้ามเองถ้าไม่มี / "ไม่มีรับประกัน" |
| ข้อความพิมพ์เอง | ข้อความ | เพิ่มได้หลายอัน |

บล็อกที่ข้อมูลว่าง (เช่นสินค้าไม่มีคำอธิบายพิเศษ) ข้ามเอง ไม่เหลือบรรทัดว่าง

## ข้อมูล / โค้ด
- กฎ (pure + เทสต์): `lib/desc-blocks.ts` · `lib/__tests__/desc-blocks.test.ts`
- สูตร computed: `lib/computed-text.ts` (`configurable: "desc_blocks"`) — `platform_description` (ไทย) · `platform_description_en` (อังกฤษ)
- ค่าที่ตั้ง: ทะเบียนฟิลด์ `erp_module_fields.relation_config.desc_blocks` = `{ blocks: [{id, key, on, gap: "blank"|"line", text?, text_en?}] }` (ไม่มีตารางใหม่)
- ป๊อปตั้งค่า: `components/desc-blocks-editor` (`DescBlocksButton`) · MasterCRUD เลือกป๊อปตามชนิดสูตร (`textComputeConfigKind`) — name_parts → Name Parts · desc_blocks → ตัวนี้

## สิทธิ์ + ประวัติ
- ปุ่ม ⚙ โชว์เฉพาะคนที่มีสิทธิ์ `admin.field_registry.edit` (ตอนนี้ = admin)
- บันทึกผ่าน `PATCH /api/admin/field-registry-v2/[id]` (guardApi + ประวัติใน `erp_field_registry_audit`)

## ข้อจำกัด
- เป็น "ค่าที่แสดง/ก๊อป" ในหน้าจอ ไม่ได้เขียนลงคอลัมน์ในฐานข้อมูล
- ตั้งได้ 1 แบบต่อฟิลด์ (ทุกแบรนด์ใช้แบบเดียวกัน — ชื่อแบรนด์เปลี่ยนตามสินค้าผ่าน `{แบรนด์}`)
- ฟิลด์ computed อื่นอยากตั้งเป็นบล็อก → ใส่ `configurable: "desc_blocks"` ในสูตรนั้นที่ `lib/computed-text.ts`
