# คำอธิบายประกอบเป็นบล็อก (Desc Blocks) — ของกลาง

## ใช้ทำอะไร
ช่องคำอธิบายที่ "ระบบประกอบให้เอง" เช่น **Platform Description** ของ Parent SKU (ข้อความยาวที่ก๊อปไปลงขายตามแพลตฟอร์ม)
ตั้งได้ว่ามีส่วนไหนบ้าง เรียงแบบไหน แก้ข้อความคงที่ (นโยบายเปลี่ยนสินค้า เงื่อนไขการสั่งซื้อ ฯลฯ)
ใส่ข้อมูลจาก **ฟิลด์ใดก็ได้** ของสินค้า และตั้ง **เงื่อนไข (ถ้า…)** ว่าบล็อกไหนจะแสดงเมื่อไหร่ — ไม่ต้องแก้โค้ด

## ใช้ยังไง (แอดมิน)
1. เปิดสินค้า (Parent SKU) → หัวข้อ **Platform Description** → กด **⚙** ข้าง TH/EN
2. แต่ละบล็อก: ติ๊กเปิด/ปิด · ลาก **⠿** สลับลำดับ · เลือก **เว้นบรรทัด** / **ติดบรรทัดบน**
3. บล็อกข้อความ (Notes · รับประกัน · เปลี่ยนสินค้า · สั่งซื้อ · ติดตามร้าน · หัวข้อรายละเอียด · ข้อความพิมพ์เอง) กด **✏️** แก้ไทย/อังกฤษ
   - **＋ แทรกข้อมูล ▾** = เลือกได้ทุกฟิลด์ของโมดูล (ค้นหาด้วยชื่อหรือคีย์ · เห็นค่าตัวอย่างของสินค้าที่เปิดอยู่) → ใส่ `{คีย์ฟิลด์}` ตรงเคอร์เซอร์ เช่น `{materials}` `{sale_price}`
   - ใต้ช่องมีคำอธิบายว่า `{คีย์}` แต่ละตัวคือฟิลด์อะไร ค่าตอนนี้เท่าไร (ตัวแดง = พิมพ์คีย์ผิด หาฟิลด์ไม่เจอ → จะว่าง)
   - ตัวแทนพิเศษ ✨ (มีตรรกะเพิ่ม): `{แบรนด์}` · `{รับประกัน}` (อังกฤษแปลให้ · "ไม่มีรับประกัน" = ว่าง) · `{รหัส}` · `{ชื่อสินค้า}` (อังกฤษใช้ Name En)
   - **↺ ข้อความตั้งต้น** = กลับไปใช้ข้อความของระบบ
4. **ถ้า…** (ทุกบล็อก) = แสดงบล็อกนี้เมื่อ… → เลือกฟิลด์ + เงื่อนไข + ค่า · หลายข้อเลือก "ตรงทุกข้อ (และ)" / "ตรงข้อใดข้อหนึ่ง (หรือ)"
   - เงื่อนไข: มีค่า · ว่าง · เท่ากับ · ไม่เท่ากับ · มีคำว่า · ไม่มีคำว่า (ข้อความ) · มากกว่า · น้อยกว่า (ตัวเลข) · ติ๊ก · ไม่ติ๊ก (เปิด/ปิด)
   - แต่ละข้อขึ้น ✓ ตรง / ✗ ไม่ตรง กับสินค้าที่เปิดอยู่ · หัวบล็อกบอก "สินค้านี้: แสดง/ไม่แสดง"
   - บล็อกข้อความ: **ถ้าไม่ตรง ใช้ข้อความนี้แทน** (ไทย/อังกฤษ · แทรกข้อมูลได้) — เว้นว่าง = ไม่แสดงบล็อก
5. **＋ เพิ่มข้อความพิมพ์เอง** ได้หลายอัน (ลบได้) · ช่องอังกฤษว่าง = ไม่ใส่ในฉบับอังกฤษ
6. ดูตัวอย่างสดของสินค้าที่เปิดอยู่ (สลับ TH/EN) → บันทึก → มีผลกับ **ทุกสินค้า** ทั้งไทยและอังกฤษ

**ยังไม่กดบันทึก = สูตรเดิมทุกตัวอักษร** · ค่าตั้งต้นในป๊อป = โครงเดียวกับสูตรเดิม (ต่างแค่ไม่มีเว้นวรรค 2 ช่องหน้าบทนำ)

## ค่าของฟิลด์ที่แทรก / ใช้เทียบ
| ชนิด | ออกมาเป็น |
|---|---|
| เชื่อมโยง (…_id เช่น แบรนด์ คอลเลกชัน หมวด) | **ชื่อ** (จาก `{base}_label` / `{base}_name`) ไม่ใช่ id — "เท่ากับ" เทียบได้ทั้งชื่อและ id |
| ตัวเลข | มีจุลภาค ทศนิยมไม่เกิน 2 (1290 → 1,290) · **0 นับเป็น "ว่าง"** |
| เปิด/ปิด | ใช่ / ไม่ใช่ (อังกฤษ Yes / No) |
| วันที่ | วว/ดด/ปปปป |
| รายการ (json array) | คั่นด้วย , |

ไม่โชว์ในตัวเลือก: ฟิลด์ลับ (ต้นทุน ฯลฯ — `is_sensitive`) · ตารางลูก/แท็ก/รูป · ช่องสูตร (computed)

## บล็อกที่มี
| บล็อก | มาจาก | หมายเหตุ |
|---|---|---|
| บทนำ | Introduction / Introduction En | |
| รายละเอียดสินค้า | หัวข้อ (แก้ได้) + Description / English Description | |
| คำอธิบายขนาด · วิธีวัดขนาด · คำอธิบายพิเศษ | ช่องของสินค้า | มีแต่ภาษาไทย (ฉบับอังกฤษข้าม) |
| ขนาดสินค้า / น้ำหนัก | กว้าง×สูง×หนา หรือขนาดพิมพ์เอง + น้ำหนัก (ถ้าติ๊กโชว์) | คำนวณให้ |
| Notes · เปลี่ยนสินค้า · สั่งซื้อ · ติดตามร้าน | ข้อความ | แก้ได้ |
| รับประกัน | ข้อความ + `{รับประกัน}` | ข้ามเองถ้าไม่มี / "ไม่มีรับประกัน" |
| ข้อความพิมพ์เอง | ข้อความ + ฟิลด์ใดก็ได้ | เพิ่มได้หลายอัน |

บล็อกที่ข้อมูลว่าง (เช่นสินค้าไม่มีคำอธิบายพิเศษ) ข้ามเอง ไม่เหลือบรรทัดว่าง

## ข้อมูล / โค้ด
- กฎ (pure + เทสต์): `lib/desc-blocks.ts` (`fillDescText` · `descFieldValue` · `descRuleTrue` · `descWhenTrue`) · `lib/__tests__/desc-blocks.test.ts`
- สูตร computed: `lib/computed-text.ts` (`configurable: "desc_blocks"`) — `platform_description` (ไทย) · `platform_description_en` (อังกฤษ)
- ค่าที่ตั้ง: ทะเบียนฟิลด์ `erp_module_fields.relation_config.desc_blocks` =
  `{ blocks: [{id, key, on, gap: "blank"|"line", text?, text_en?, when?: {match: "all"|"any", rules: [{field, op, value?}]}, else_text?, else_text_en?}] }` (ไม่มีตารางใหม่)
- ป๊อปตั้งค่า: `components/desc-blocks-editor` (`DescBlocksButton` · prop `fields` = รายชื่อฟิลด์จากทะเบียน) · MasterCRUD เลือกป๊อปตามชนิดสูตร (`textComputeConfigKind`) — name_parts → Name Parts · desc_blocks → ตัวนี้

## สิทธิ์ + ประวัติ
- ปุ่ม ⚙ โชว์เฉพาะคนที่มีสิทธิ์ `admin.field_registry.edit` (ตอนนี้ = admin)
- บันทึกผ่าน `PATCH /api/admin/field-registry-v2/[id]` (guardApi + ประวัติใน `erp_field_registry_audit`)

## ข้อจำกัด
- เป็น "ค่าที่แสดง/ก๊อป" ในหน้าจอ ไม่ได้เขียนลงคอลัมน์ในฐานข้อมูล
- ตั้งได้ 1 แบบต่อฟิลด์ (ทุกแบรนด์ใช้แบบเดียวกัน — แยกตามแบรนด์ได้ด้วย **ถ้า…** แบรนด์ เท่ากับ …)
- dropdown (select) แทรกเป็น "ค่าที่เก็บ" ไม่ใช่ป้ายที่ตั้งใน Studio
- ฟิลด์ computed อื่นอยากตั้งเป็นบล็อก → ใส่ `configurable: "desc_blocks"` ในสูตรนั้นที่ `lib/computed-text.ts`
