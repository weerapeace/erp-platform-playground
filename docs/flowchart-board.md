# กระดาน flowchart กลาง (FlowchartBoard)

> ผังกล่องต่อเส้นแบบ flowchart — เส้นติดกล่องเสมอ หักมุมเอง กล่องเข้าแถวตามตาราง
> โค้ด: `components/flowchart-board` · ตรรกะล้วน + เทสต์: `lib/flowchart.ts`, `lib/__tests__/flowchart.test.ts`
> ตัวเสริม: `@xyflow/react` (React Flow 12 · MIT · ฟรีรวมงานธุรกิจ) — โหลดเฉพาะหน้าที่ใช้
> เพิ่มเมื่อ 2026-11-08 — เจ้าของอยากให้หน้าแผนผังการเก็บไฟล์ "เป็นเหมือน flowchart" (เดิมใช้กระดานวาด Excalidraw)

## ใช้ทำอะไร

- ผังขั้นตอนงาน · ผังตัดสินใจ (ถาม ใช่/ไม่ใช่ แล้วแยกทาง) · ผังว่าข้อมูล/ไฟล์ไปเก็บที่ไหน
- ใช้จริงที่: **แผนผังการเก็บไฟล์** `/master/storage-plan` (entity `storage_plan_flow/main`)
- หน้าทดลอง (ไม่ต้องล็อกอิน · จำลองการบันทึกในเครื่อง): `app/_demos/flowchart-board-preview`

## ห้ามใช้เมื่อไหร่

- อยากวาดมือ แปะรูป วางการ์ดสินค้า/งาน → ใช้ **กระดานวาด** `CanvasSketch` (docs/canvas-sketch.md)
- ผังที่ระบบสร้างจากโค้ดเอง (กดอะไรแล้วไปอัปเดตอะไร) → ใช้ **แผนผังการทำงาน** `/master/flow-map`
- ทะเบียนของกลางบอกไว้: กลุ่ม "กระดานวาด / แผนผัง" = **ใช้คนละงาน เก็บทั้งคู่**

## วิธีใช้

```tsx
const FlowchartBoard = dynamic(() => import("@/components/flowchart-board").then((m) => m.FlowchartBoard), { ssr: false });

<FlowchartBoard
  entityType="storage_plan_flow" entityId="main"   // 1 entity = 1 แผนผัง
  editable={editing}                               // false = บังคับดูอย่างเดียว (ปุ่มของหน้า)
  height="calc(100vh - 170px)"
  starter={(t) => scene}                           // กระดานว่าง + แก้ได้ → วางให้ครั้งแรก + มีปุ่ม "วางแม่แบบ"
  fileName="แผนผังการเก็บไฟล์"                       // ชื่อไฟล์ตอนบันทึกเป็นรูป
  onCanEdit={setCanEdit}                           // รู้ว่าผู้ใช้มีสิทธิ์แก้ไหม (ไว้ซ่อนปุ่มของหน้า)
/>
```

**entity ใหม่ต้องเพิ่มสิทธิ์** ใน map `PERM` ของ `app/api/canvas-sketch/route.ts` (ไม่เพิ่ม = ใช้สิทธิ์สินค้า products.* ซึ่งอาจไม่ใช่ที่ต้องการ)

## ความสามารถ

| ทำอะไร | วิธี |
|---|---|
| เพิ่มกล่อง | ปุ่มบนแถบ: เริ่ม/จบ · ขั้นตอน · คำถาม ใช่/ไม่ใช่ · ที่เก็บ · ไฟล์ · โฟลเดอร์ · หน้าใน ERP · โน้ต · กรอบโซน (วางกลางจอ) |
| หน้าใน ERP | (เพิ่ม 2026-11-13 — เจ้าของอยากให้รู้ว่า "หาไฟล์ได้จากไหนใน ERP") กดปุ่ม "หน้าใน ERP" = ป๊อปกลาง `MenuPagePickerModal` (docs/menu-page-picker.md) เลือกหน้าจากเมนูจริง จัดกลุ่มตามแอป ค้นได้ · กล่องโชว์ "แอป …" + ไอคอนเมนู + ชื่อหน้า + ปุ่ม **เปิด ↗** · กดปุ่มเปิด / ดับเบิลคลิกกล่อง = เปิดหน้านั้นในแท็บใหม่ (ทั้งคนแก้และคนดูอย่างเดียว) · ปุ่ม "เปลี่ยนหน้า" บนแถบกล่อง = เลือกใหม่ (หัวข้อเปลี่ยนเป็นชื่อหน้าใหม่ บรรทัดคำอธิบายคงเดิม) · "แก้" = แก้ข้อความ · ชื่อแอปอ่านจากเมนูล่าสุด · หน้าหลุดจากเมนู = ป้ายเตือน "หน้านี้ไม่อยู่ในเมนูแล้ว" · เก็บ `data.href` (ต้องขึ้นต้น `/` — กันลิงก์นอกระบบ/`javascript:`) · `data.app` · `data.appName` · `data.icon` · บันทึกเป็นรูปมีชื่อแอป + ชื่อหน้า + ลิงก์ · ไม่กรองตามสิทธิ์ (หน้าปลายทางตรวจเอง) |
| ที่เก็บ (ไอคอน) | กดปุ่ม "ที่เก็บ" = ป๊อปเลือกที่เก็บ `place-modal.tsx` (15 แบบจาก `lib/storage-places`: Google Drive · R2 · Supabase = ที่เก็บจริง ดึงชื่อ/คำอธิบายจาก `lib/storage-policy` · Google Photos · OneDrive · Dropbox · NAS · คอมในเครื่อง · ฮาร์ดดิสก์ · USB · มือถือ · ฐานข้อมูล · ตู้เอกสาร · ลบทิ้ง) หรือ "ทรงกระบอก" แบบเดิม · มีไอคอน = ไม่มีกรอบ (ไอคอน + ชื่อ) · ปุ่ม "ไอคอน" บนกล่อง = เปลี่ยน (มีป้าย "แนะนำ" เดาจากชื่อกล่อง) · ปุ่ม "ไฟล์" = ใส่ไอคอนประเภทไฟล์ใต้ชื่อ · เก็บใน `data.place` / `data.exts` |
| ขนาดไอคอน | กล่อง "ไฟล์" + "ที่เก็บ" ที่มีไอคอน: ไอคอนโตตามกล่อง — ลากมุมกล่อง หรือปุ่ม − / % / + บนแถบเครื่องมือ (50% · 75% · 100% · 125% · 150% · 200% ... 400% · กดตัวเลข % = กลับ 100%) · เลือกหลายกล่องแล้วกด − / + = ทุกกล่องที่มีไอคอนขนาดเท่ากัน · ไม่เก็บค่าเพิ่ม คิดจากขนาดกล่องเทียบขนาดตั้งต้น (`lib/flowchart` `flowIconScale` / `flowIconSizes` — บนจอกับบันทึกเป็นรูปใช้สูตรเดียวกัน) · เปลี่ยนประเภทไฟล์/ไอคอนที่เก็บ = ไอคอนคงขนาดเดิม (`refitIconBox`) |
| กรอบโซน | กรอบโปร่งเส้นประ อยู่หลังกล่องอื่น (zIndex -1 · `elevateNodesOnSelect={false}`) · ตัวกรอบกดทะลุไปที่กระดาน (เลือก/ลากคลุมกล่องข้างในได้) · จับได้เฉพาะหัวกรอบ (`dragHandle .fc-zone-handle`) · ลากหัวกรอบ = กล่องที่อยู่ในกรอบทั้งกล่องย้ายตาม (`nodesInsideZone`) · ดับเบิลคลิกหัวกรอบ = แก้ชื่อ · ไม่มีจุดต่อเส้น |
| ต่อเส้น | ลากจากจุดขอบกล่อง (โผล่ตอนชี้) ไปอีกกล่อง — จุดไหนก็ได้ 4 ด้าน |
| ป้ายบนเส้น | เส้นออกจากกล่องคำถาม: เส้นแรก "ใช่" เส้นที่สอง "ไม่ใช่" ให้เอง · คลิกเส้น = ปุ่มลัด ใช่/ไม่ใช่/พิมพ์เอง/ลบ · ดับเบิลคลิกเส้น = พิมพ์ป้าย |
| แก้ข้อความ | ดับเบิลคลิกกล่อง · บรรทัดแรก = หัวข้อ (ตัวหนา) · บรรทัดถัดไป = คำอธิบาย · Ctrl+Enter / คลิกข้างนอก = เสร็จ · Esc = ยกเลิก |
| สี / ลบ / ขนาด | เลือกกล่อง → แถบลอยเหนือกล่อง (7 สี · แก้ · คัดลอก · ทำซ้ำ · ลบ) · ลากมุมม่วง = ย่อขยาย · Delete/Backspace = ลบ |
| เลือกหลายกล่อง | Shift/Ctrl+คลิก · Shift+ลากคลุม · Ctrl+A = ทุกกล่อง → แถบกลุ่มอันเดียวเหนือกลุ่ม ("เลือก N กล่อง" · สี · คัดลอก · ทำซ้ำ · ลบ) — ใช้ได้ในโหมดดูอย่างเดียวด้วย (ไว้คัดลอกไปวางที่อื่น) |
| คัดลอก / ตัด / วาง | Ctrl+C / Ctrl+X / Ctrl+V (เมื่อเมาส์อยู่บนกระดาน) · เอาเส้นที่ต่อ "ระหว่างกล่องที่เลือก" ไปด้วย · วางตรงเมาส์ (วางซ้ำที่เดิม = เลื่อนเฉียงทีละ 40) · ปุ่ม "วาง" บนแถบ (โผล่เมื่อมีของที่คัดลอกไว้) = วางกลางจอ · วางข้ามหน้า/ข้ามแท็บได้ |
| ทำซ้ำ | Ctrl+D หรือปุ่ม "ทำซ้ำ" → ก๊อปไว้ข้าง ๆ เฉียงลงขวา (ไม่ยุ่งคลิปบอร์ด) |
| วางข้อความจากที่อื่น | ข้อความจาก LINE/Word/เว็บ → กล่องใหม่ตรงเมาส์: สั้น (≤2 บรรทัด ≤60 ตัว) = กล่องขั้นตอน · ยาว = โน้ต (สูงตามเนื้อหา) · วางรูป/ไฟล์ = แจ้งว่ายังไม่รองรับ |
| ไฟล์ (ไม่มีกรอบ) | ป๊อปกลาง `FileTypePickerModal` (ไอคอนประเภทไฟล์กลาง `components/file-type-icon` · 65 ชนิด เช่น JPG CR2 PSD AI PDF DXF SEW) เลือกได้หลายชนิด + ตั้งชื่อกล่อง · ดับเบิลคลิก/ปุ่ม "แก้" = เปิดป๊อปเดิมแก้ (กล่องขยายให้พอดีไอคอน ไม่ย่อ) · เก็บใน `data.exts` · บันทึกเป็นรูปวาดไอคอนเดียวกัน (`fileTypeSvg`) |
| โฟลเดอร์ | ป๊อปกลาง `FolderCardModal` · ดับเบิลคลิกกล่อง = เปิดโฟลเดอร์ (`openCanvasFolder`) · แก้ชื่อ/path ผ่านปุ่ม "แก้" |
| ย้อนกลับ | Ctrl+Z · ทำซ้ำ Ctrl+Y / Ctrl+Shift+Z (เมื่อเมาส์อยู่บนกระดาน) · จำได้ 60 ขั้น · คีย์ลัดทุกตัวอ่านปุ่มผ่าน `lib/shortcut-key` (แป้นพิมพ์ไทยก็ใช้ได้ — เดิมเช็ก e.key แล้วได้ "ผ" คีย์ลัดเลยเงียบ) |
| บันทึกเป็นรูป | ปุ่ม "บันทึกเป็นรูป" → PNG ทั้งผัง (ตัวแปลงกลาง `lib/html-to-png` htmlToPngBlob · สีเดียวกับบนจอจาก `FLOW_PALETTE`) |

### คลิปบอร์ดเก็บอะไร (ตรรกะล้วนใน `lib/flowchart.ts`: copyFlowSelection · placeFlowClip · parseFlowClip · textToFlowNode — เทสต์ครบ)

- Ctrl+C ใส่คลิปบอร์ด 2 แบบพร้อมกัน: แบบกระดาน `application/x-erp-flowchart+json` (วางในกระดาน flowchart ได้ทุกหน้า) + ข้อความอ่านง่าย 1 กล่อง 1 บรรทัด (วางใน LINE/Word ได้)
- จำก้อนล่าสุดไว้ใน `localStorage` (`erp-flowchart-clip`) ด้วย — ปุ่ม "คัดลอก" ใส่คลิปบอร์ดได้แค่ข้อความ / บางเบราว์เซอร์ทิ้งแบบกระดาน → ถ้าข้อความที่วางตรงกับที่จำไว้ จะวางเป็นกล่องให้
- วางแล้วได้ id ใหม่ทุกครั้ง (ไม่ชนของเดิม) · วาง = 1 ขั้นย้อนกลับ (Ctrl+Z) · ตอนพิมพ์ในกล่อง (ช่องแก้ข้อความ) คีย์ลัดพวกนี้ไม่ยุ่ง — คัดลอก/วางตัวหนังสือตามปกติ
- ดูอย่างเดียว: เลือก + คัดลอกได้ · ตัด/วาง/ทำซ้ำไม่ได้

## การบันทึก

- เก็บในตารางกลาง `erp_canvas_sketches` ผ่าน `/api/canvas-sketch` (ตัวเดียวกับกระดานวาด) — `scene = { kind: "flowchart", v: 1, nodes, edges }`
- **ไม่ต้องสร้างตารางใหม่** · กระดานวาด (Excalidraw) อ่าน scene แบบ flowchart ไม่ได้และกลับกัน → ใช้ entityType คนละชื่อเสมอ
- บันทึกอัตโนมัติหลังหยุดแก้ ~1 วิ · สลับแท็บ/ปิดหน้า = บันทึกทันที · ยังบันทึกไม่เสร็จแล้วปิดแท็บ = เบราว์เซอร์ถามก่อน
- เช็กเวอร์ชัน (`rev`): มีคนบันทึกแทรก → รวมงาน 3 ทาง `mergeFlowScenes` (เทสต์ครบ) — ของที่เราแก้ชนะ · ของที่เขาเพิ่มเก็บไว้ · ของที่ฝ่ายใดลบ (โดยอีกฝ่ายไม่ได้แก้) ลบตาม
- audit log: ทุกการบันทึกลง `audit_logs` action `canvas_update` (จาก API กลาง)
- ไม่มีแสดงสดหลายคน (realtime) — คนที่เปิดค้างจะเห็นของคนอื่นตอนบันทึกชนแล้วรวมงาน หรือรีเฟรช

## ข้อจำกัด

- ไม่มีปากกาวาดอิสระ / แปะรูป (ตั้งใจ — ใช้กระดานวาดแทน)

- ปุ่ม "React Flow" มุมขวาล่าง = เครดิตของไลบรารี (ใบอนุญาต MIT ไม่บังคับ แต่เขาขอให้คงไว้ถ้าไม่ได้สมัครแบบเสียเงิน)
