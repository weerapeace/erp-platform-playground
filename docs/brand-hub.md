# หน้าแบรนด์ (/brand-hub)

เจ้าของขอ (2026-11-12): "หน้าเลือกแบรนด์ กดแล้วรวมทุกหมวดที่จำเป็นไว้ที่เดียว เหมือนกดจากแบรนด์แล้วเข้าหน้าจัดการ" (ดีไซน์ทางเข้าแบบ animate-ui carousel)

## หน้าตา

1. **`/brand-hub`** — เลือกแบรนด์แบบ carousel
   - การ์ดกลางขยาย · ปัด/ลูกศร/คีย์ ←→ · Enter หรือกดการ์ดกลาง = เข้า
   - การ์ด: โลโก้ · สินค้าในระบบ · รายการบนร้าน · ช่องทางที่เชื่อม
   - **จำแบรนด์ล่าสุด** (`localStorage` `brand-hub:last`) → เปิดครั้งหน้าเข้าแบรนด์นั้นเลย · `?pick=1` = บังคับให้เลือกใหม่ (ปุ่ม "ทุกแบรนด์")
2. **`/brand-hub/<brandId>`** — หน้าจัดการแบรนด์
   - หัว: โลโก้ + ชื่อ · ช่องสลับแบรนด์ (`BrandSelect`) · ปุ่ม "ทุกแบรนด์" · ปุ่ม "จัดหน้า"
   - ตัวเลขหลัก 4 ใบ: สินค้าในระบบ · รายการบนร้าน · ช่องทางที่เชื่อม · งานที่ต้องทำ
   - กล่อง (จัดเรียง/ซ่อน/เต็ม-ครึ่ง ได้ ด้วย `useBlockLayout` — ทีม (แอดมิน) + ของฉัน · key `brand_hub`):
     - **งานที่ต้องทำ**: ออเดอร์รอจัดส่ง · ยังไม่จับคู่ · ยังไม่ลงร้านไหนเลย · ไม่มีรูปปก · ยังไม่ตั้งหมวดกลาง · ไม่อยู่บนร้านแล้ว (โชว์เฉพาะที่มีงาน)
     - **ร้าน / ช่องทาง**: LINE · TikTok · Lazada · Shopee · Facebook+IG — เชื่อมแล้ว (จำนวนสินค้า) / หมดอายุ / นำเข้าไฟล์ / ยังไม่เชื่อม (กด = ไปหน้าเชื่อมต่อ)
     - **6 หมวดเครื่องมือ**: ร้านค้าออนไลน์ · ออเดอร์+ส่งของ · สินค้า · คอนเทนต์+การตลาด · ออกแบบ+ผลิต · ตั้งค่าแบรนด์

## กติกาตัวเลข

- **ออเดอร์รอจัดส่ง** = กฎเดียวกับ `needsAction` (`lib/platform-order-status`): new/confirmed/packed · ไม่นับ source email · ไม่นับ UNPAID/ON_HOLD
- **ยังไม่จับคู่** = รายการบนร้านที่ยังไม่มีคู่ ไม่นับที่กดไม่ต้องจับคู่ / ไม่อยู่บนร้านแล้ว
- **ยังไม่ลงร้านไหนเลย** = Parent SKU เปิดใช้ที่ไม่มีรายการบนร้าน (ที่ยังอยู่บนร้าน) จับคู่อยู่เลย
- **สถานะช่องทาง**: ไม่มีแถว/ตัดการเชื่อม = ยังไม่เชื่อม (Shopee มีสินค้าจากไฟล์ = นำเข้าไฟล์) · `refresh_expires_at` ผ่านแล้ว = หมดอายุ · มีกุญแจ/stage connected = เชื่อมแล้ว
- ข้อมูลจริง ณ วันทำ: Louis Montini 964 รุ่น · บนร้าน 1,831 (LINE 933 + TikTok 898) · ออเดอร์รอส่ง 7 · ยังไม่จับคู่ 320 · ยังไม่ตั้งหมวดกลาง 957 · IG 290 รุ่น · Lazada 232 · Shopee (ไฟล์) 276

## หน้าที่รับแบรนด์จากลิงก์ (`?brand=<id>`)

- `/master/platform-catalog?brand=&platform=<code>&view=shop|match` — ลิงก์ชนะค่าที่จำไว้
- `/master/platform-orders?brand=`
- `/admin/platform-accounts?brand=` (มีอยู่เดิม)
- เฟส 2: หน้าสินค้า · คิวโพสต์ · ใบงานออกแบบ · งานครีเอทีฟ → แก้หน้าให้รับ `?brand=` แล้วตั้ง `brandAware: true` ใน `sections.ts`
