# รับชำระเงินจากลูกค้า (Customer Receipts)

บันทึกว่า "ลูกค้าจ่ายเงินมาแล้ว" → ยอดค้างรับของใบขาย/ใบวางบิลลดลงจริง

- หน้าเว็บ: `/receipts` (เมนู 💵 รับชำระเงิน ในแอป **ขาย** และ **การเงิน**)
- ของกลาง: [`lib/receipts.ts`](../lib/receipts.ts)
- API: [`app/api/receipts/route.ts`](../app/api/receipts/route.ts)
- เทสต์: [`lib/__tests__/receipts.test.ts`](../lib/__tests__/receipts.test.ts)
- ตาราง: `customer_receipts` + `customer_receipt_lines`

## ใช้ทำอะไร

ก่อนมีโมดูลนี้ ระบบไม่มีที่บันทึกว่าเก็บเงินได้แล้ว — ใบขายทุกใบค้างรับเต็มจำนวนตลอดกาล
ทำให้ [หน้ากระแสเงินสด](./cashflow.md) บอกได้แค่ "ประมาณการ"

ใบรับชำระคือสิ่งที่เปลี่ยนตัวเลขพวกนั้นให้เป็นของจริง

## 3 ยอดที่ต้องแยกให้ออก

| ช่อง | คืออะไร | มีผลกับอะไร |
|---|---|---|
| **เงินเข้าบัญชี** (`amount`) | เงินที่เข้าบัญชีเราจริง | กระแสเงินสด |
| **หัก ณ ที่จ่าย** (`wht_amount`) | ลูกค้าหักภาษีไว้ เงินไม่เข้าเรา | ลดยอดหนี้ลูกค้า |
| **ค่าธรรมเนียมธนาคาร** (`fee_amount`) | ถูกหักจากยอดโอน เป็นต้นทุนเรา | ไม่ลดหนี้ลูกค้า |

```txt
ยอดที่ใช้ตัดหนี้  = เงินเข้าบัญชี + หัก ณ ที่จ่าย
เงินเข้าบัญชีจริง = เงินเข้าบัญชี − ค่าธรรมเนียม
```

ถ้าลืมใส่ "หัก ณ ที่จ่าย" ยอดค้างจะไม่ลดครบ และใบจะดูเหมือนเก็บเงินไม่ครบทั้งที่จบแล้ว

## กติกาสำคัญ

1. **ยอดกระจายต้องเท่ากับยอดที่ตัดหนี้เป๊ะ** (ยอมรับส่วนต่างระดับสตางค์ ±0.01)
   ระบบเตือนเป็นภาษาคน เช่น "ยังกระจายยอดไม่ครบอีก 4,000 บาท"
2. **ตัดใบวางบิลถ้ามี** — ใบขายที่ถูกดึงไปอยู่ในใบวางบิลแล้ว จะไม่ขึ้นให้เลือกซ้ำ
3. **ยอดค้างรับคำนวณใหม่จากใบรับชำระเสมอ** ไม่ใช่บวก/ลบทีละครั้ง
   → แก้ใบหรือยกเลิกกี่รอบยอดก็ไม่เพี้ยน (ดู `recomputeDocs()` ใน API)
4. **ยกเลิกใบ = ยอดค้างกลับคืนเต็มจำนวน** และ `paid_at` ของใบวางบิลถูกล้างออก
5. ทุกการสร้าง/แก้/ยกเลิก เขียน audit log ลง `audit_logs`

## ปุ่มที่ช่วยงานจริง

- **⚡ กระจายอัตโนมัติ** — เอายอดที่รับมาตัดใบเก่าสุดก่อนจนหมด (เคสที่เจอบ่อยที่สุด: ลูกค้าโอนก้อนเดียวปิดหลายใบ)
- **เต็ม** ท้ายแต่ละบรรทัด — ใส่ยอดที่ค้างของใบนั้นทั้งก้อน

## สิทธิ์

| สิทธิ์ | ทำอะไรได้ | ให้ใครโดยอัตโนมัติ |
|---|---|---|
| `receipts.view` | ดูรายการ | คนที่ดูใบขายได้ (`so.view`) |
| `receipts.create` | บันทึกรับชำระ | คนที่สร้างใบขายได้ (`so.create`) |
| `receipts.edit` | แก้ใบ | คนที่แก้ใบขายได้ (`so.edit`) |
| `receipts.cancel` | ยกเลิกใบ ⚠️ | คนที่ยกเลิกใบขายได้ (`so.cancel`) |

## เลขเอกสาร

ใช้ระบบเลขกลาง key `rc` — รูปแบบเริ่มต้น `RC{BYYYY}-{MM}-{000}` (รีเซ็ตทุกเดือน)
เปลี่ยนรูปแบบได้ที่ `/admin/numbering` โดยไม่ต้องแก้โค้ด

## ยังไม่ได้ทำ

- แนบสลิป/ใบเสร็จ (ช่อง `attachments` เตรียมไว้แล้ว ยังไม่มี UI)
- พิมพ์ใบเสร็จรับเงิน / ใบกำกับภาษี
- รับชำระเป็นเงินสกุลอื่น
- ตัดเงินมัดจำ (advance) มาใช้กับใบขาย
