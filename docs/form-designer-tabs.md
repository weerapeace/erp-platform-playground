# ตัวออกแบบหน้า (Studio) — แท็บตรงกับหน้าจริง

## ปัญหาที่แก้ (เจ้าของบ่น 2026-10-18 "ไม่เห็นตรงกันเลย ไม่มี website")
ตัวออกแบบหน้า Parent SKU โชว์แท็บไม่ตรงกับ drawer จริง:
- ไม่มีแท็บ 🛍 เว็บไซต์ / 🏬 แพลตฟอร์ม / ⚠️ ปัญหา — เป็น "แท็บพิเศษ" ที่ใส่ในโค้ด (`config.extraTabs`) ตัวออกแบบไม่รู้จัก
- มีแท็บ "รูปภาพ/ไฟล์" (มีแค่รูปปก ซึ่งหน้าจริงแสดงคอลัมน์ซ้าย) และ "ความสัมพันธ์" (ไม่มีฟิลด์) — หน้าจริงซ่อนไว้
- หน้า /master/parent-skus กับ drawer ที่เปิดจากที่อื่นตั้งแท็บพิเศษคนละชุด

## ตอนนี้
- **แท็บพิเศษ Parent SKU ชุดเดียว** `components/master-crud/parent-sku-extra-tabs.tsx` (ภาพรวม · เว็บไซต์ · แพลตฟอร์ม · ปัญหา) ใช้ทั้งหน้าและ MasterRecordDrawer
- **ตัวออกแบบ** (`studio-panel.tsx`) รับ `extraTabs` → แท็บล็อก 🔒 (ชื่อแก้ไม่ได้ · ใส่ฟิลด์ไม่ได้) · กดค้างที่ไอคอนแล้วลากย้ายตำแหน่ง · ปุ่ม 🙈 ซ่อน / 👁 แสดง
- แท็บฟิลด์ที่หน้าจริงไม่โชว์ → จาง + 👻 + บอกเหตุผล (มีแค่รูปปก / ยังไม่มีฟิลด์)
- ส่วนพิเศษที่ฝังท้ายแท็บอื่น (`inTab`) → กล่อง 🔒 บอกไว้ท้ายแท็บนั้น

## ข้อมูล
`erp_modules.config.layout.tabs` เพิ่มแท็บว่างแทนแท็บพิเศษ: `{ key: "x:<key>", label, icon, extra: true, hidden?: true, sections: [] }`
- `LayoutTabs` (master-crud) วางแท็บพิเศษตามตำแหน่งแท็บว่างนี้ · `hidden` = ไม่โชว์ · ไม่มีใน layout = ต่อท้ายแท็บฟิลด์ (แบบเดิม)
- ตัวออกแบบบันทึกให้เองตอนกด "บันทึก" (แท็บพิเศษที่ไม่มีในโมดูลแล้ว ถูกทิ้งตอนบันทึก)

## ข้อจำกัด
- โมดูลอื่นที่หน้าเต็มกับ drawer ตั้ง `extraTabs` คนละชุด (เช่น SKU) ตัวออกแบบเห็นเฉพาะชุดของหน้าที่เปิดตัวออกแบบ — ควรรวมเป็นชุดเดียวแบบ Parent SKU
- ซ่อนได้เฉพาะแท็บพิเศษที่เป็นแท็บของตัวเอง (ไม่รวมส่วนที่ฝัง `inTab`)
