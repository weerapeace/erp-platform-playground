# 📝 โหมดลงรายละเอียด (Entry Modes) — ของกลาง

**ใช้ทำอะไร** — ในป๊อปรายการ (drawer กลาง MasterCRUD) กดปุ่ม **📝 โหมดลงรายละเอียด** แล้วเลือกงาน เช่น "ลงขายเว็บไซต์"
→ ฝั่งรายละเอียดเหลือ **เฉพาะช่องที่งานนั้นต้องลง** + แถบความครบ (%) + ป้ายช่องที่ยังไม่ลง (กดแล้วกระโดดไปช่องนั้น) + **คำแนะนำ/ตัวอย่างต่อช่อง**
แก้ในช่องได้เลย แล้วกด **💾 บันทึก** ที่แถบล่าง (ไม่ต้องกด "แก้ไข" ก่อน)

เจ้าของเคาะ (2026-10-22): เตือนอย่างเดียว **ไม่กันบันทึก** · โหมดใช้กับทุกประเภทสินค้า (ช่องที่ประเภทนั้นซ่อนไว้ไม่นับ) · ตั้งค่าโหมดได้เฉพาะแอดมิน

## ตั้งค่าที่ไหน (แอดมิน)
1. ในป๊อปรายการ → ปุ่ม **📝 โหมดลงรายละเอียด ▾** → **⚙ ตั้งค่าโหมด / เพิ่มโหมดใหม่**
2. หรือ ปุ่ม **🎨 ออกแบบฟิลด์** → แท็บ **✅ โหมดลงข้อมูล**

ต่อโหมดตั้งได้: ชื่อ + ไอคอน · ใครเห็น (role ว่าง = ทุกคน · admin เห็นเสมอ) · ใช้กับประเภทสินค้า (Product Family · ว่าง = ทุกประเภท)
· ช่องที่ต้องลง (ลากเรียง) แต่ละช่องเลือก **ต้องมี / แนะนำ** + คำแนะนำ (ว่าง = ใช้ help_text ของทะเบียนฟิลด์)
· เงื่อนไขพิเศษ **รูปสินค้าอย่างน้อย N รูป** (นับจากแกลเลอรีรูปสินค้า)

ยังไม่เคยบันทึก = ใช้ **ชุดตั้งต้นในโค้ด** (`ENTRY_MODE_DEFAULTS`) · บันทึกแล้วค่าใน DB ชนะ · ปุ่ม "↺ คืนค่าตั้งต้น" ลบค่าใน DB กลับไปใช้ชุดตั้งต้น
ชุดตั้งต้นของ Parent SKU: 🛍 ลงขายเว็บไซต์ · 🏬 ลง Shopee / Lazada · 📏 วัดขนาด + ชั่งน้ำหนัก

## กติกานับ "ลงแล้ว" (`isValueFilled`)
- ข้อความว่าง / ขีด (`-`, `—`, `N/A` ฯลฯ ที่ข้อมูลนำเข้าเก่าใช้แทนค่าว่าง) = **ยังไม่ลง**
- ตัวเลข 0 = ลงแล้ว · รายการ/ออบเจกต์ว่าง (`[]`, `{}`) = ยังไม่ลง
- ช่องติ๊ก (ใช่/ไม่ใช่) = ต้องติ๊ก **ใช่** ถึงนับว่าลงแล้ว
- **ไม่นับ**: ช่องที่ประเภทสินค้าซ่อน (family template) · ช่องที่เงื่อนไขโชว์ไม่ผ่าน · ช่องที่ผู้ใช้ไม่มีสิทธิ์เห็น · ช่องที่ไม่มีในทะเบียน · ช่องตารางลูก (one2many)
- จำนวนรูปยังโหลดไม่เสร็จ = ยังไม่นับข้อรูป (กันขึ้นเตือนผิดระหว่างโหลด)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ✅ งานกรอกข้อมูลเป็นชุด ๆ ที่ต้องรู้ว่า "ครบหรือยัง" เช่น เตรียมลงขาย / วัดของ / ข้อมูลผลิต — ใช้ได้ทุกโมดูลที่เปิดผ่าน drawer กลาง ไม่ต้องเขียนโค้ดเพิ่ม (แค่ตั้งโหมด)
- ❌ อย่าใช้แทน "บังคับกรอก" (is_required / family template required) — โหมดเตือนอย่างเดียว ถ้าต้องกันบันทึกจริงใช้ required ของทะเบียน
- ❌ โมดูลที่มีหน้าดูเฉพาะ (`config.detailView` / record-detail-views) ไม่มีปุ่มโหมด (หน้าดูของมันแทนแท็บฟิลด์ทั้งหมด)

## สิทธิ์ / ประวัติ
- ตั้งค่าโหมด: `admin.module_layout.edit` (เช็กที่ API) · บันทึกแล้วลง audit `module.entry_modes_update` (ก่อน/หลัง เป็นชื่อโหมด + จำนวนช่อง)
- กรอกในโหมด: สิทธิ์แก้ของโมดูลนั้น (ไม่มีสิทธิ์ = ดูได้ ช่องล็อก) · บันทึกผ่าน `PATCH master-v2` เดิม → สิทธิ์ระดับฟิลด์ + audit ของกลางทำงานตามปกติ
- ช่องแท็ก (many2many) ในโหมด → บันทึกผ่านปุ่ม "แท็ก" เดิมที่แถบล่าง

## หน้าตา (แบบ C — เจ้าของเลือกจาก 3 แบบ 2026-10-22 "รก ขอ compact")
- **ปุ่มโหมด** (แถบบนป๊อป) ตอนอยู่ในโหมดโชว์ `🏬 ลง Shopee / Lazada · 6/9` (ต้องมี ลงแล้ว/ทั้งหมด) · เมนูของปุ่ม = ทั้งระบบเหลือกี่ตัว + ลิงก์ดูในตาราง · ติ๊ก "ซ่อนช่องที่ลงแล้ว" · สลับโหมด · ออกจากโหมด · ตั้งค่า
- **แถบบางบรรทัดเดียว** เหนือฟอร์ม: แถบ % · ต้องมี x/y · แนะนำ a/b · "ขาด: ชื่อช่อง · …" (กดชื่อ = กระโดดไปช่อง · โชว์ 4 ชื่อแล้ว +อีก N) · ถัดไปที่ยังไม่ครบ ▶ · ✕
- **ฟอร์ม 2 คอลัมน์** (มือถือ 1) แบบหน้าแก้ไข · ช่องยาว (คำอธิบาย/json/รูป) เต็มแถว · `grid-flow-row-dense` เติมช่องว่าง · ช่องที่ขาด = พื้นแดงจาง+กรอบแดง (ต้องมี *) / เหลือง (แนะนำ) · ลงแล้ว = ✓
- **คำแนะนำ** = ข้อความในช่องว่าง (placeholder ส่งผ่าน `renderInput(key, hint)`) + ปุ่ม ⓘ (ชี้ = tooltip · แตะ = กางบรรทัด 💡)
- ติ๊ก "ซ่อนช่องที่ลงแล้ว" ใช้ร่วมกันระหว่างเมนูกับหน้าจอ (`useHideDone` — localStorage + event)

## ปุ่มช่วยในโหมด
- **🌐 แปลจากไทย** ข้างช่องอังกฤษที่จับคู่ภาษาไว้ (`ui_style.lang_en` ของช่องไทย) → ใส่คำแปลในช่อง (ยังไม่บันทึก ให้ตรวจก่อน)
- **ตัวถัดไปที่ยังไม่ครบ ▶** ไล่รายการถัดไปในลิสต์ที่เปิดอยู่ (สูงสุด 60 ตัวต่อครั้ง) — เช็กเฉพาะช่องข้อมูล (รูป/แท็ก/ช่องที่ประเภทสินค้าซ่อน ต้องเปิดดูถึงรู้ → อาจหยุดที่ตัวที่จริง ๆ ครบแล้ว กดต่อได้) · ถ้ากรองตาราง "ยังไม่ครบ" อยู่ ใช้ ◀ ▶ ปกติได้เลย (ลิสต์มีแต่ตัวที่ไม่ครบ)
- **ซ่อนช่องที่ลงแล้ว** (จำต่อเครื่อง) · ปุ่มโหมดจำโหมดล่าสุดต่อโมดูล → ป้าย "ขาด N" บนปุ่ม
- ออก/สลับโหมดตอนยังไม่บันทึก → ถาม "ออกโดยไม่บันทึก?" (ช่องที่แก้กลับเป็นค่าเดิม)

## 🗂 ทั้งระบบเหลือกี่ตัวที่ยังไม่ครบ (เพิ่ม 2026-10-22)
**"ยังไม่ครบ" = ขาดช่อง "ต้องมี" อย่างน้อย 1 ช่อง** (ขาดแค่ช่องแนะนำ = ถือว่าครบ · นับแยกเป็น `recOnly`) · โหมดที่ไม่มีช่องต้องมีเลย = ขาดอะไรก็ไม่ครบ — `isModeIncomplete()` ใน lib/entry-modes ใช้ทุกที่
- ตัวนับฝั่งเซิร์ฟเวอร์ `lib/entry-modes-server.ts` ใช้กฎเดียวกับป๊อป (`computeModeProgress`) + ข้อมูลที่ป๊อปมีแต่ต้องดึงเอง: จำนวนรูปในแกลเลอรี (`erp_playground_attachments`, เฉพาะ Parent/SKU) · แท็กประเภทสินค้า (ซ่อนช่อง/section ตามเทมเพลต) · ลิงก์แท็กของช่อง many2many — จำไว้ 30 วิ · นับเฉพาะที่เปิดใช้อยู่ · ไม่ตัดช่องตามสิทธิ์ของผู้ดู
- **3 ที่ที่โชว์:**
  1. หน้าจอโหมดในป๊อป: "🗂 ทั้งระบบ: ยังขาดช่องที่ต้องมี X จาก Y ตัว · ขาดแค่ช่องแนะนำ Z ตัว · ดูรายการในตาราง ↗" (`GET /api/entry-modes/stats?module=` · บันทึกแล้วนับใหม่)
  2. ปุ่ม **📝 ความครบตามโหมด** หัวหน้าตาราง (MasterCRUDPage ใส่เองเมื่อโมดูลมีโหมด · `components/entry-modes/status.tsx`) → ต่อโหมด: แถบ % + ขาดมากสุด + [ดูในตาราง] + [📋 รายงาน + พิมพ์ A4]
  3. **ตัวกรองตาราง** `?mode_incomplete=<โหมด>` → `GET master-v2/<entity>?mode_incomplete=` ไล่ทุกแถวที่ตรงตัวกรอง/ค้นหา/เรียงเดิม (ดึงเฉพาะคอลัมน์ที่ใช้ตัดสิน) แล้วแบ่งหน้าใน JS + ดึงแถวเต็มเฉพาะหน้านั้น (ไม่ส่ง id ยาวใน URL) · แถบฟ้า "กำลังแสดงเฉพาะที่ยังไม่ครบ" + ✕ ดูทั้งหมด · **เปิดรายการจากตารางที่กรองอยู่ = เข้าโหมดนั้นให้เลย** (กดออกจากโหมดเอง = ไม่ดึงกลับจนปิดป๊อป)
- **รายงานข้อมูลค้าง** scope `modes:<moduleKey>` (`/api/pending-data` + ใบพิมพ์ `/print/pending-data?scope=modes:parent-skus-v2`) — 1 หัวข้อ/โหมด · คอลัมน์ รหัส/ชื่อ/ยังขาด (ช่องแนะนำมีวงเล็บ) + รูปปก · ปุ่ม ↗ = `/master/parent-skus?open=<id>&entry_mode=<โหมด>` เปิดรายการแล้วเข้าโหมดเลย
- ลิงก์หน้าตารางของโมดูลอยู่ที่ `ENTRY_MODE_LIST_HREF` (ตอนนี้ Parent SKU / SKU) — โมดูลอื่นได้ตัวนับ+ตัวกรองบนหน้าตารางของตัวเอง แต่ลิงก์จากป๊อปที่เปิดจากที่อื่น/รายงานจะไม่มี จนกว่าจะเติม map

ตัวเลขจริงตอนทำ (Parent SKU 1,502 ตัว): ลงขายเว็บไซต์ ไม่ครบ 1,501 (หมวดกลางขาด 1,493 · รูปไม่ถึง 3 รูป 1,451) · ลง Shopee/Lazada ไม่ครบ 1,498 · วัดขนาด ไม่ครบ 28 (ขาดแค่ช่องแนะนำอีก 1,325)

## ข้อจำกัด / ต่อยอดได้
- เงื่อนไขพิเศษมีแค่จำนวนรูป (ยังไม่มี "SKU ลูกมีราคาครบ")
- ช่องคำนวณ (computed) / ช่องแสดงผลจากตารางอื่น (related) / รูปปก / ตารางลูก เลือกใส่โหมดไม่ได้ (คำนวณเอง / ใช้เงื่อนไขจำนวนรูปแทน)
- ตัวกรองตาราง "ยังไม่ครบ" ไล่ได้สูงสุด 50,000 แถวต่อครั้ง (เกินนี้นับไม่ครบ)
