# 📝 โหมดลงรายละเอียด (Entry Modes) — ของกลาง

**ใช้ทำอะไร** — ในป๊อปรายการ (drawer กลาง MasterCRUD) กดปุ่ม **📝 โหมดลงรายละเอียด** แล้วเลือกงาน เช่น "ลงขายเว็บไซต์"
→ ฝั่งรายละเอียดเหลือ **เฉพาะช่องที่งานนั้นต้องลง** + แถบความครบ (%) + ป้ายช่องที่ยังไม่ลง (กดแล้วกระโดดไปช่องนั้น) + **คำแนะนำ/ตัวอย่างต่อช่อง**
แก้ในช่องได้เลย แล้วกด **💾 บันทึก** ที่แถบล่าง (ไม่ต้องกด "แก้ไข" ก่อน)

เจ้าของเคาะ (2026-10-22): เตือนอย่างเดียว **ไม่กันบันทึก** · โหมดใช้กับทุกประเภทสินค้า (ช่องที่ประเภทนั้นซ่อนไว้ไม่นับ) · ตั้งค่าโหมดได้เฉพาะแอดมิน

## ตั้งค่าที่ไหน (แอดมิน)
1. ในป๊อปรายการ → ปุ่ม **📝 โหมดลงรายละเอียด ▾** → **⚙ ตั้งค่าโหมด / เพิ่มโหมดใหม่**
2. หรือ ปุ่ม **🎨 ออกแบบฟิลด์** → แท็บ **✅ โหมดลงข้อมูล**

ต่อโหมดตั้งได้: ชื่อ + ไอคอน · ใครเห็น (role ว่าง = ทุกคน · admin เห็นเสมอ) · ใช้กับประเภทสินค้า (Product Family · ว่าง = ทุกประเภท)
· ช่องที่ต้องลง (ลากเรียง) แต่ละช่องเลือก **ต้องมี / แนะนำ** + คำแนะนำ (ว่าง = ใช้ help_text ของทะเบียนฟิลด์)
· เงื่อนไขพิเศษ **รูปสินค้าอย่างน้อย N รูป** (นับจากแกลเลอรีรูปสินค้า)

ยังไม่เคยบันทึก = ใช้ **ชุดตั้งต้นในโค้ด** (`ENTRY_MODE_DEFAULTS`) · บันทึกแล้วค่าใน DB ชนะ · ปุ่ม "↺ คืนค่าตั้งต้น" ลบค่าใน DB กลับไปใช้ชุดตั้งต้น
ชุดตั้งต้นของ Parent SKU: 🛍 ลงขายเว็บไซต์ · 🏬 ลง Shopee / Lazada · 📏 วัดขนาด + ชั่งน้ำหนัก

## กติกานับ "ลงแล้ว" (`isValueFilled`)
- ข้อความว่าง / ขีด (`-`, `—`, `N/A` ฯลฯ ที่ข้อมูลนำเข้าเก่าใช้แทนค่าว่าง) = **ยังไม่ลง**
- ตัวเลข 0 = ลงแล้ว · รายการ/ออบเจกต์ว่าง (`[]`, `{}`) = ยังไม่ลง
- ช่องติ๊ก (ใช่/ไม่ใช่) = ต้องติ๊ก **ใช่** ถึงนับว่าลงแล้ว
- **ไม่นับ**: ช่องที่ประเภทสินค้าซ่อน (family template) · ช่องที่เงื่อนไขโชว์ไม่ผ่าน · ช่องที่ผู้ใช้ไม่มีสิทธิ์เห็น · ช่องที่ไม่มีในทะเบียน · ช่องตารางลูก (one2many)
- จำนวนรูปยังโหลดไม่เสร็จ = ยังไม่นับข้อรูป (กันขึ้นเตือนผิดระหว่างโหลด)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ✅ งานกรอกข้อมูลเป็นชุด ๆ ที่ต้องรู้ว่า "ครบหรือยัง" เช่น เตรียมลงขาย / วัดของ / ข้อมูลผลิต — ใช้ได้ทุกโมดูลที่เปิดผ่าน drawer กลาง ไม่ต้องเขียนโค้ดเพิ่ม (แค่ตั้งโหมด)
- ❌ อย่าใช้แทน "บังคับกรอก" (is_required / family template required) — โหมดเตือนอย่างเดียว ถ้าต้องกันบันทึกจริงใช้ required ของทะเบียน
- ❌ โมดูลที่มีหน้าดูเฉพาะ (`config.detailView` / record-detail-views) ไม่มีปุ่มโหมด (หน้าดูของมันแทนแท็บฟิลด์ทั้งหมด)

## สิทธิ์ / ประวัติ
- ตั้งค่าโหมด: `admin.module_layout.edit` (เช็กที่ API) · บันทึกแล้วลง audit `module.entry_modes_update` (ก่อน/หลัง เป็นชื่อโหมด + จำนวนช่อง)
- กรอกในโหมด: สิทธิ์แก้ของโมดูลนั้น (ไม่มีสิทธิ์ = ดูได้ ช่องล็อก) · บันทึกผ่าน `PATCH master-v2` เดิม → สิทธิ์ระดับฟิลด์ + audit ของกลางทำงานตามปกติ
- ช่องแท็ก (many2many) ในโหมด → บันทึกผ่านปุ่ม "แท็ก" เดิมที่แถบล่าง

## ปุ่มช่วยในโหมด
- **🌐 แปลจากไทย** ข้างช่องอังกฤษที่จับคู่ภาษาไว้ (`ui_style.lang_en` ของช่องไทย) → ใส่คำแปลในช่อง (ยังไม่บันทึก ให้ตรวจก่อน)
- **ตัวถัดไปที่ยังไม่ครบ ▶** ไล่รายการถัดไปในลิสต์ที่เปิดอยู่ (สูงสุด 60 ตัวต่อครั้ง) — เช็กเฉพาะช่องข้อมูล (รูป/แท็ก/ช่องที่ประเภทสินค้าซ่อน ต้องเปิดดูถึงรู้ → อาจหยุดที่ตัวที่จริง ๆ ครบแล้ว กดต่อได้)
- **ซ่อนช่องที่ลงแล้ว** (จำต่อเครื่อง) · ปุ่มโหมดจำโหมดล่าสุดต่อโมดูล → ป้าย "ขาด N" บนปุ่ม
- ออก/สลับโหมดตอนยังไม่บันทึก → ถาม "ออกโดยไม่บันทึก?" (ช่องที่แก้กลับเป็นค่าเดิม)

## ข้อจำกัด / ต่อยอดได้
- ยังไม่มีตัวเลข "ทั้งระบบเหลือกี่ตัวที่ยังไม่ครบโหมดนี้" → ต่อยอดที่รายงานข้อมูลค้าง (`/api/pending-data`) + ตัวกรองในตาราง
- เงื่อนไขพิเศษมีแค่จำนวนรูป (ยังไม่มี "SKU ลูกมีราคาครบ")
- ช่องคำนวณ (computed) / รูปปก / ตารางลูก เลือกใส่โหมดไม่ได้ (คำนวณเอง / ใช้เงื่อนไขจำนวนรูปแทน)
