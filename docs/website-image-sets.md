# 🖼 ชุดรูปกลาง (Image sets) — เปลี่ยนรูปครั้งเดียว ทุกที่เปลี่ยนตาม (2026-10-22)

## ใช้ทำอะไร
ตั้ง "ชุดรูป" เช่น **New Arrival** (รูปคอม + รูปมือถือ) แล้วผูกไว้หลายที่ — Banner หน้าแรก · รูปในเมนู · รูปคั่นสินค้า · แบนเนอร์หน้าขอบคุณ · ป๊อปอัป ฯลฯ
เปลี่ยนรูปของชุดที่แท็บ **🖼 ชุดรูป** ครั้งเดียว → 📝 เป็นร่างก่อน → 👁 ดูตัวอย่างทุกที่ → ✅ ใช้รูปนี้ = ทุกที่ที่ผูกเปลี่ยนพร้อมกัน (ไม่ต้องเผยแพร่หน้าแต่ละหน้า) · บันทึกไว้ได้หลายชุด (สูงสุด 40 ชุด/ร้าน)

## วิธีใช้ (คนจัดหน้า)
1. ERP › เว็บไซต์ › ร้าน › **🖼 ชุดรูป** → ตั้งชื่อ → ＋ สร้าง → ใส่รูปคอม / รูปมือถือ (ไม่ใส่มือถือ = ใช้รูปคอม)
2. ไปที่ช่องรูปที่อยากผูก (แท็บ 🧱 หน้าแรก / 📄 หน้าเว็บ / 🎨 ดีไซน์ — ทุกช่องที่ใช้ช่องรูปกลาง) → กด **🔗 ใช้ชุดรูป** ใต้ชื่อช่อง → เลือกชุด → เผยแพร่หน้านั้น 1 ครั้ง
3. ต่อจากนี้เปลี่ยนรูปที่แท็บชุดรูปได้เลย · "เลิกผูก" ที่ช่อง = ช่องนั้นใช้รูปปัจจุบันของชุดเป็นรูปของตัวเองต่อ (ไม่หายเป็นช่องว่าง)

## ความสามารถ
- **📝 ร่าง → 👁 ดูตัวอย่าง → ✅ ใช้รูปนี้ (2026-10-22 รอบ 2)**: แก้รูป/จุดสำคัญ = เก็บที่ `draft` (เว็บจริงยังเห็นรูปเดิม) · หน้าต่างตัวอย่าง = เว็บจริงโหมดพรีวิว (`?preview=1` → API แทนค่าด้วยร่าง) แยกตามที่ที่ใช้ (หน้าแรกเลื่อนไปที่ Section · `/shop` · หน้าขอบคุณ) สลับคอม/มือถือ · "ใช้รูปนี้" = `publish` (รูปเดิมเข้าประวัติ + ล้างแคชเว็บร้าน) · "ทิ้งร่าง" = `discard` · ตั้งชื่อ/ลิงก์/alt/ตั้งเวลา ยังมีผลทันทีเหมือนเดิม
- **🎨 รูปในผืนผ้าใบอิสระ (รอบ 2)**: ตัวเลือกรูปของผืน (`ImageChooser` — เพิ่มรูป / เปลี่ยนรูป / รูปพื้นหลังผืน) มี "🔗 ชุดรูป" · ชิ้นได้สัดส่วนจากรูปคอมของชุด · ERP ส่ง `mobileImageKey` ให้ชิ้น (ช่อง `imageKey` ที่ไม่มีคู่มือถือ) → เว็บร้านวาด `<picture>` · ชิ้นที่ยังไม่ได้ครอป = ใช้จุดสำคัญของชุด / ครอปแล้ว = ครอปชนะ · ลิงก์ของชุดทับ `href` ของชิ้น
- **คอม + มือถือ**: ที่ที่มีช่องรูปมือถือคู่ (`imageKey` ↔ `mobileImageKey` เช่น Hero / สไลด์ / รูปคั่นสินค้า / แบนเนอร์หน้าขอบคุณ) ได้รูปมือถือของชุดให้เอง · ชุดไม่มีรูปมือถือ = ที่นั้นใช้รูปมือถือของตัวเองตามเดิม
- **📍 จุดสำคัญของรูป** (แยกรูปคอม/มือถือ): คลิก/ลากบนรูป เห็นตัวอย่างครอป 3 แบบ (แบนเนอร์กว้าง · สี่เหลี่ยม · แนวตั้ง) → เว็บร้าน `LoadImg` ใส่ `object-position` ทุกที่ (ที่ที่ตั้งตำแหน่งรูปเองไว้ เช่น ครอปของสไลด์ = ที่นั้นชนะ)
- **🔗 ลิงก์ของชุด**: ตั้งแล้วทุกที่ที่ผูกลิงก์ไปที่เดียวกัน (ทับช่อง `href`/`link`/`url`/`target` ข้างรูป และลิงก์แบบ `{text, href}`) · ว่าง = แต่ละที่ใช้ลิงก์ของตัวเอง · คำอธิบายรูป (alt) เติมให้ที่ที่ยังไม่ได้ใส่
- **⏰ ตั้งเวลาเปลี่ยน**: อัปรูปชุดถัดไป + วันเวลาเริ่ม (+ "กลับรูปเดิมเมื่อ" = ใช้ชั่วคราว เช่น Sale) สูงสุด 10 รายการ · เว็บร้านเลือกรูปตามเวลาตอนเปิดหน้า (แคช 60 วิ → เปลี่ยนภายใน ~1 นาที · ไม่ต้องมี cron) · เปิดแท็บชุดรูป = รูปตั้งเวลาแบบถาวรที่ถึงเวลาแล้วกลายเป็นรูปหลัก
- **🕘 ประวัติ + ย้อนกลับ**: เปลี่ยนรูป = รูปเดิมเข้าประวัติ (10 รูปล่าสุด) · ↩ ย้อนรูปก่อนหน้า
- **📍 ใช้อยู่ที่ไหนบ้าง**: ไล่หาจากหน้าแรก / หน้าเว็บ / ดีไซน์ ทั้งเผยแพร่และร่าง · ลบชุดที่ยังใช้อยู่ไม่ได้ (บอกว่าใช้ที่ไหน)

## ทำงานยังไง (สำหรับคนแก้โค้ด)
- ผูก = ช่องรูปเก็บค่า `imgset/<uuid>` — หน้าตาเหมือน r2 key จึงผ่านตัวกรองช่องรูปเดิมทุกตัว (ไม่ต้องแก้ normalize ของ Section/ธีม/เมนู/รายการสินค้า)
- API สาธารณะ `site` (layout · theme · collections · info) และ `page` (layout · post · รายการบทความ) เรียก `resolveForStorefront` → `resolveImageSets` แทนค่าก่อนส่ง + ส่ง `imageFocus` {r2key: {x,y}} · ไม่มีค่า imgset/ = ไม่อ่าน DB
- กันพลาด: ค่า `imgset/` ที่หลุดถึงเว็บร้าน (เช่น พรีวิวสดในตัวจัดหน้าก่อนบันทึก) → `/api/r2-image` 302 ไปรูปปัจจุบันของชุด (แคช 60 วิ) · `&m=1` = รูปมือถือ
- เว็บร้าน: `src/lib/image-focus-map.ts` (แผนที่ · ใช้ฝั่งเซิร์ฟเวอร์ได้) + `src/lib/image-focus.tsx` (ตัวครอบ · layout ทั้งเว็บ + หน้า [slug]) · `LoadImg` ดูรูปที่แสดงจริง (`currentSrc`) จึงถูกทั้งรูปคอม/มือถือใน `<picture>`
- แก้ชุด = audit (`store_image_sets` create/update/revert/delete) + สั่งเว็บร้านล้างแคช (`purgeStorefrontCache`)

## ข้อจำกัดที่รู้แล้ว
- ช่องรูปที่ไม่ได้ใช้ช่องรูปกลาง (เช่น รูปสินค้า · ของตกแต่งของ Section) ยังผูกชุดไม่ได้
- ที่ที่ไม่มีช่องรูปมือถือคู่ (เช่น รูปในเมนู) = มือถือเห็นรูปคอม (ครอปตามจุดสำคัญ)
- พรีวิวสดตอนลากแก้ (ก่อนบันทึก) เห็นรูปคอมของชุด แต่ยังไม่มีจุดสำคัญ/รูปมือถือ — บันทึกร่างแล้วเห็นครบ
