# 🩺 เตือน "ไม่ขึ้นเว็บจริง" — เมนู / ท้ายเว็บ (2026-10-20)

## ใช้ทำอะไร
พรีวิวในหน้าตั้งค่าเว็บ (ERP) โชว์หน้าที่ **ยังเป็นร่าง** ด้วย → ดูเหมือนครบ แต่เว็บจริง:
- คอลัมน์ท้ายเว็บ "ศูนย์ช่วยเหลือ" ที่ไม่มีหน้าในกลุ่มที่เผยแพร่แล้ว = **ซ่อนทั้งคอลัมน์** (เว็บร้าน `Footer.tsx` → `hasContent`)
- ลิงก์ชนิด "หน้า" ที่ไปหน้าที่ยังไม่มี/ยังเป็นร่าง = ลูกค้ากดแล้วเจอ **"ไม่พบหน้า"**

## ใช้ที่ไหน
- `lib/website-link-health.ts` (pure + เทสต์) — `pageLinkIssue` · `helpColumnIssue` · `countLinkWarnings`
- `components/website-theme-panel.tsx`
  - `MenuEditor` (ของกลาง: เมนูบน · เมนูมือถือ · ลิงก์ในคอลัมน์ท้ายเว็บ · ลิงก์แถวล่าง) → ⚠️ ใต้แถวลิงก์ + ตัวเลือกหน้าที่เป็นร่างมี "(ร่าง)" + ปุ่ม ✎ มี ⚠️ เมื่อเมนูย่อยมีลิงก์เสีย
  - `FooterColumnsEditor` → ⚠️ ใต้คอลัมน์ที่จะไม่ขึ้น/มีลิงก์เสีย (คอลัมน์ที่ปิดตา 🙈 ไม่เตือน) · รายการหน้าในกลุ่มมีป้าย ร่าง/ขึ้นเว็บแล้ว
  - `FooterHealthSummary` → กล่องสรุปบนการ์ดคอลัมน์ + ลิงก์ไปแท็บ 📄 หน้าเว็บ
- ข้อมูลหน้า = `/api/public/storefront/page?preview=1` (มี `status`) · โหลดพลาด = ไม่เตือน (`PageHealthCtx` = null)

## กติกา (ต้องตรงกับเว็บร้าน)
- หน้าที่เว็บมีแบบเดิมในโค้ด `contact` `privacy` `track` (`BUILTIN_PAGE_SLUGS`) — ไม่มี/ร่าง = เว็บใช้หน้าแบบเดิม → แค่ ℹ️ บอก ไม่นับเป็นลิงก์เสีย
- หน้าที่ API ไม่ส่ง status = ถือว่าเผยแพร่แล้ว
- เพิ่มหน้าแบบเดิมในเว็บร้าน (src/app/<หน้า>) ที่ใช้แทนหน้าจาก ERP ได้ → เพิ่มใน `BUILTIN_PAGE_SLUGS`

## ข้อจำกัด
- ยังไม่ตรวจลิงก์ชนิดอื่น (หมวด/สินค้า/ลิงก์เอง) และคอลัมน์โซเชียลที่ยังไม่กรอกลิงก์
- ไม่เผยแพร่หน้าให้เอง — เจ้าของต้องเผยแพร่ที่แท็บ 📄 หน้าเว็บ
