# WheelSelect — ตัวเลือกเล็ก หมุนลูกกลิ้งปรับได้

`components/wheel-select.tsx`

## ใช้ทำอะไร

ตัวเลือกแบบ **กล่องเล็ก + ▴▾** สำหรับค่าที่ "มีลำดับ" เช่น ระยะห่าง ความกว้าง ขนาด จำนวนคอลัมน์ ความหนา

- **ชี้ที่กล่องแล้วหมุนลูกกลิ้งเมาส์** = เลื่อนไปตัวบน/ตัวล่างในรายการ ไม่ต้องกดเปิดรายการ
- **▴ / ▾** = ทีละขั้น (▴ = ตัวบนในรายการ · ▾ = ตัวล่าง — ทิศเดียวกับรายการที่เปิดดู)
- **กดที่ค่า** = เปิดรายการเต็มเหมือน dropdown เดิม
- เลื่อนหน้าผ่านเฉย ๆ (เมาส์ไม่ขยับ) **ไม่เปลี่ยนค่า** — ต้องขยับเมาส์มาชี้ที่กล่องก่อน กันเผลอเปลี่ยน

เจ้าของโปรเจกต์ขอ: "เวลาปรับอะไรพวกนี้อยากให้เป็นตัวเล็ก แล้ว scroll เมาส์ปรับได้ (จำเป็นของกลาง)"

## ใช้เมื่อไหร่

- ช่องเลือกที่ค่าเรียงเป็นระดับ: เล็ก→ใหญ่, 2→6 คอลัมน์, 300→700 ความหนา, 50%→100%

## ห้ามใช้เมื่อไหร่

- ตัวเลือก "ชนิด/รูปแบบ" ที่ไม่มีลำดับ เช่น ฟอนต์ เลย์เอาต์ ที่มาของข้อมูล → ใช้ `<select>` ปกติ

## วิธีใช้

ใช้แบบเดียวกับ `<select>` เปลี่ยนชื่อแท็กได้เลย

```tsx
import { WheelSelect } from "@/components/wheel-select";

<WheelSelect value={v.spaceTop} onChange={(e) => set({ spaceTop: e.target.value })} highlight={v.spaceTop !== "auto"}>
  {PART_SPACE_OPTIONS.map((o) => <option key={o.value} value={o.value}>{o.label}</option>)}
</WheelSelect>
```

| prop | ความหมาย |
|---|---|
| `value` / `onChange` | แบบเดียวกับ select (`e.target.value` เป็นข้อความ) |
| `highlight` | ขอบฟ้า = ตั้งค่าไว้ต่างจากเดิม (เช่น ค่ามือถือแยก) |
| `warn` | ขอบส้ม = เตือน |
| `className` | กรอบนอก (ไม่ใส่ = กว้างพอดีค่า) |
| `disabled`, `title` | เหมือน select |

ปุ่มแบ่งช่อง `Seg` ของตัวจัดหน้า (`components/website-block-editor.tsx`) ใส่ `wheel` = หมุนลูกกลิ้งเลื่อนซ้าย/ขวาได้ ใช้ตัวจับลูกกลิ้งตัวเดียวกัน (`useWheelStep`)

## จุดที่ใช้แล้ว

- หน้าดีไซน์เว็บ (`components/website-theme-panel.tsx`) — 31 ช่อง: คอลัมน์ ระยะห่างการ์ด จำนวนบรรทัดชื่อ จำนวนจุดสี ขนาดตัวอักษรหน้าสินค้า ขนาดรูปในกรอบ ความมน ขนาดปุ่ม ความหนาเส้น เงา ความกว้าง/ระยะห่างของส่วนหน้าสินค้า แกลเลอรี แบนเนอร์ สินค้าที่เกี่ยวข้อง ช่องซื้อ ป้ายอัตโนมัติ ความหนาชื่อ ระยะตัวอักษร น้ำหนักตัวอักษร
- ตัวจัดหน้า Section (`Seg wheel`) — ระยะห่างบน/ล่าง (คอม+มือถือ) ความกว้าง ขนาดหัวข้อ ความหนา ความเร็วลูกเล่น

## ข้อจำกัด

- ทัชแพด: ปัดยาว ๆ จะเลื่อนหลายขั้น (มีเว้นจังหวะกันกระโดด)
- มือถือไม่มีลูกกลิ้ง → ใช้ ▴▾ หรือกดเปิดรายการ
- ไม่เกี่ยวกับสิทธิ์/ประวัติการแก้ (เป็นแค่ตัวรับค่า — การบันทึกยังผ่านปุ่มบันทึกของหน้านั้นตามเดิม)
