# 🔘 ToggleSwitch — สวิตช์เปิด/ปิด (ของกลาง)

`components/toggle-switch.tsx` · เริ่มใช้ 2026-10-28 (แท็บ 🚚 การจัดส่ง)

## ใช้ทำอะไร
สวิตช์เปิด/ปิดค่าที่เป็นใช่/ไม่ใช่ (เขียว = เปิด) เช่น เปิดให้ลูกค้าเลือกวิธีส่ง · รับเก็บเงินปลายทาง

```tsx
import { ToggleSwitch } from "@/components/toggle-switch";

<ToggleSwitch on={m.enabled} onChange={(v) => set({ enabled: v })} title="เปิดให้ลูกค้าเลือก" />
<ToggleSwitch on={cod} onChange={setCod} label="เก็บเงินปลายทาง" size="sm" />
```

| prop | ความหมาย |
|---|---|
| `on` / `onChange` | ค่าปัจจุบัน / เปลี่ยนค่า |
| `label` | ป้ายข้างสวิตช์ (กดป้ายก็สลับได้) — ไม่ใส่ = สวิตช์อย่างเดียว |
| `title` | คำอธิบายตอนชี้ (ควรใส่เมื่อไม่มี label) |
| `size` | `"md"` ค่าเริ่ม · `"sm"` แถวแน่น/การ์ด |
| `disabled` | กดไม่ได้ (จาง) |

## ควรรู้
- กดแล้ว **ไม่ไหลไปถึงการ์ด/แถวที่ครอบ** (stopPropagation) → วางบนการ์ดที่กดเพื่อเลือกได้ โดยไม่เปิดการ์ดไปด้วย
- ใช้กับค่าที่มีผลทันทีในฟอร์ม (ยังต้องกดบันทึกตามหน้านั้น) — ถ้าต้องถามก่อนปิด ให้ถาม (askConfirm) ใน `onChange` เอง

## ห้ามใช้เมื่อ
- ตัวเลือกมากกว่า 2 ค่า → ใช้ `Seg` (หลังบ้านเว็บ) หรือ select
- รายการติ๊กหลายข้อในลิสต์ยาว → ใช้ checkbox ธรรมดา
