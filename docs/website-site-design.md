## ทำงานยังไง (เว็บร้าน)
- **ฟอนต์อังกฤษ**: ใส่ชื่อฟอนต์อังกฤษไว้หน้าฟอนต์ไทยใน `--font-display` / `--font-body` → ตัวอังกฤษ/ตัวเลขใช้ฟอนต์อังกฤษ ตัวไทยตกไปฟอนต์ไทย (ฟอนต์บทบาทที่ตั้งเองในแท็บตัวอักษรยังชนะ)
- **ความโปร่ง**: `--sec-k` คูณระยะบน-ล่างของ `.section-pad` (0.6 / 1 / 1.45) · Section ที่ตั้งระยะห่างเองคงค่าที่ตั้ง
- **ความกว้าง**: `--maxw` ของ `.container-x`
- **ผิวกระดาษ** = ลาย svg บน `body` (Section ที่มีสีพื้นเองไม่มีลาย) · **เกรนฟิล์ม** = `body::after` ทับทั้งจอ `pointer-events: none`
- **มือถือ**: `html{font-size}` ของจอ < 768px = ขนาดเนื้อหามือถือ × % · ปุ่มใหญ่ = `.btn/.field{min-height:48px}`
- **ราคา**: `formatPrice` / `formatBaht` (src/lib/utils) อ่านรูปแบบที่ `ThemeProvider` ตั้งให้ตอนวาด (`setPriceFormat`) — ทุกจุดที่โชว์ราคาเป็น component ฝั่งเบราว์เซอร์
- **ปุ่ม**: แบบปุ่มใช้กับปุ่มใน Section (`[data-block-id]`) เท่านั้น — ปุ่มซื้อ/ตะกร้า/ชำระเงินคงทึบ · ปุ่มที่วางบนรูป/พื้นเข้มติด `data-on-media` (Hero · สไลด์ที่ตัวหนังสือขาว · การ์ดเข้มของ TwoTracks) → แบบขอบ/เส้นใต้ใช้สีขาว · ลูกเล่นตอนชี้ใช้กับทุกปุ่มหลัก (ลูกศรเฉพาะปุ่มใน Section) ภายใน `@media (hover:hover)`
- **ลิงก์**: `.hover:text-link` (เส้นทางหน้า/ลิงก์เล็ก) · `.hover:underline` · ลิงก์คอลัมน์ท้ายเว็บ — เมนูด้านบนตั้งแยกที่แท็บเมนู
- **ช่องกรอก**: `.field` ทั้งเว็บ
- **ไอคอนหัวเว็บ**: ปุ่มไอคอนติด `data-hdr-icon` · เส้น = CSS `stroke-width` · ตัวหนังสือ = Navbar วาดคำแทนบนจอคอม (มือถือยังเป็นไอคอน)

## ข้อจำกัดที่รู้แล้ว
- ข้อความที่ระบบโปร (`src/lib/promotions.ts`) และค่าส่ง (`src/lib/shipping.ts`) สร้าง ยังเขียน ฿ แบบเดิม — 2 ไฟล์นี้เป็นมิเรอร์ของ ERP ต้องแก้คู่กันทีหลัง
- ลิงก์ตอนชี้: สีตอนชี้ยังตาม "สีลิงก์" ของแท็บสี (อยากให้สีไม่เปลี่ยน ตั้งสีลิงก์ = สีตัวอักษร)
- ลูกศรขยับต่อท้ายปุ่มใน Section ทุกปุ่ม — ถ้าข้อความปุ่มมี → อยู่แล้วจะเห็นลูกศร 2 ตัว
- ชุดลุคสำเร็จรูป (แท็บสี) ยังไม่ตั้งค่าชุดนี้ให้ — กดใช้ชุดแล้วฟอนต์อังกฤษแยกถูกล้างเป็น "ใช้ฟอนต์เดียวกัน" (ต่อยอดในชุด 6)
