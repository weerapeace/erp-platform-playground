## ทำงานยังไง (เว็บร้าน)
- **ฟอนต์อังกฤษ**: ใส่ชื่อฟอนต์อังกฤษไว้หน้าฟอนต์ไทยใน `--font-display` / `--font-body` → ตัวอังกฤษ/ตัวเลขใช้ฟอนต์อังกฤษ ตัวไทยตกไปฟอนต์ไทย (ฟอนต์บทบาทที่ตั้งเองในแท็บตัวอักษรยังชนะ)
- **ความโปร่ง**: `--sec-k` คูณระยะบน-ล่างของ `.section-pad` (0.6 / 1 / 1.45) · Section ที่ตั้งระยะห่างเองคงค่าที่ตั้ง
- **ความกว้าง**: `--maxw` ของ `.container-x`
- **ผิวกระดาษ** = ลาย svg บน `body` (Section ที่มีสีพื้นเองไม่มีลาย) · **เกรนฟิล์ม** = `body::after` ทับทั้งจอ `pointer-events: none`
- **มือถือ**: `html{font-size}` ของจอ < 768px = ขนาดเนื้อหามือถือ × % · ปุ่มใหญ่ = `.btn/.field{min-height:48px}`
- **ราคา**: `formatPrice` / `formatBaht` (src/lib/utils) อ่านรูปแบบที่ `ThemeProvider` ตั้งให้ตอนวาด (`setPriceFormat`) — ทุกจุดที่โชว์ราคาเป็น component ฝั่งเบราว์เซอร์
- **ปุ่ม**: แบบปุ่มใช้กับปุ่มใน Section (`[data-block-id]`) เท่านั้น — ปุ่มซื้อ/ตะกร้า/ชำระเงินคงทึบ · ปุ่มที่วางบนรูป/พื้นเข้มติด `data-on-media` (Hero · สไลด์ที่ตัวหนังสือขาว · การ์ดเข้มของ TwoTracks) → แบบขอบ/เส้นใต้ใช้สีขาว · ลูกเล่นตอนชี้ใช้กับทุกปุ่มหลัก (ลูกศรเฉพาะปุ่มใน Section) ภายใน `@media (hover:hover)`
- **ลิงก์**: `.hover:text-link` (เส้นทางหน้า/ลิงก์เล็ก) · `.hover:underline` · ลิงก์คอลัมน์ท้ายเว็บ — เมนูด้านบนตั้งแยกที่แท็บเมนู
- **ช่องกรอก**: `.field` ทั้งเว็บ
- **ไอคอนหัวเว็บ**: ปุ่มไอคอนติด `data-hdr-icon` · เส้น = CSS `stroke-width` · ตัวหนังสือ = Navbar วาดคำแทนบนจอคอม (มือถือยังเป็นไอคอน)

# ✨ ลูกเล่นทั้งเว็บ (แท็บดีไซน์ ชุด 2 · 2026-10-22)

ERP › เว็บไซต์ › ดีไซน์ › **รูปทรง** — กล่อง "✨ การเคลื่อนไหวทั้งเว็บ" (เปลี่ยนหน้า) + กล่อง "✨ ลูกเล่นทั้งเว็บ" · ปิดทุกตัวเป็นค่าเริ่ม · ลูกค้าที่ตั้งเครื่องให้ลดการเคลื่อนไหวไม่เห็นทั้งหมด

| ตัวเลือก | ที่เก็บ (`theme.page`) | เว็บร้าน |
|---|---|---|
| Section โผล่ตอนเลื่อนถึง (ค่าทั้งเว็บ) + ความเร็ว + ทยอยทีละใบ | `sectionMotion` / `sectionSpeed` / `sectionStagger` | `BlockRenderer` / `LiveBlocks` ส่ง `sectionMotionOf(page)` ให้ `blockWrapProps` → `data-motion` ชุดเดิม (MotionObserver) |
| เปลี่ยนหน้า +ม่านสีแบรนด์ / โลโก้วาบ / ซูมเข้า | `transition` (`fade` `rise` `curtain` `logo` `zoom` `none`) | zoom = `::view-transition-*` · curtain/logo = แผ่นปิดจอ `.sf-pt-cover` (`PageMotion` → `registerPageCover` ใน `lib/page-transition`) |
| หน้าโหลดแรก (โลโก้ / โลโก้+เส้น / ม่านเข้ม) | `intro` | `components/layout/IntroScreen` — สคริปต์เล็กสร้าง `.sf-intro` ก่อนเนื้อหาโผล่ |

| แถบเลื่อนอ่าน + ปุ่มกลับขึ้นบน (วงกลม / + วงแหวน · ซ้าย/ขวา) | `readProgress` / `backToTop` / `backToTopSide` | `components/layout/ScrollAids` |

## กติกา
- **Section**: ลูกเล่นของ Section "ตามค่าทั้งเว็บ" (= ค่า `none` เดิมของทุก Section) ใช้ค่าทั้งเว็บ · เลือกแบบเองคงแบบของตัวเอง · **"ไม่ขยับ"** (`still` ใหม่) = ไม่ขยับแม้เปิดค่าทั้งเว็บ · **Section แรกของหน้าโผล่ทันทีเสมอ** (หน้าแรกไม่ว่างตอนเปิด)
- **ม่าน/โลโก้**: ปิดจอก่อน → `router.push` → รอหน้าใหม่วาด (≤ 2.5 วิ) → เปิดจอ · โลโก้ค้างอย่างน้อย ~0.5 วิ · ใช้ได้ทุกเบราว์เซอร์ (ไม่พึ่ง View Transitions) · ปุ่มย้อนกลับของเบราว์เซอร์ไม่มีม่าน
- **หน้าโหลดแรก**: ครั้งเดียวต่อแท็บ (`sessionStorage sf-intro`) · ไม่ขึ้นใน `?preview=1` / แท็บพรีวิว / iframe / บอท (UA มี bot, headless, lighthouse…) / ลดการเคลื่อนไหว · รวม ≤ ~1.8 วิ · ม่านเข้มใช้โลโก้สำหรับพื้นเข้ม (`logo.imageDarkKey`) ถ้ามี · แผ่นนี้ไม่อยู่ในต้นไม้ React (React 19 ข้ามโหนดที่สคริปต์เติมใน body)
- **เคอร์เซอร์**: `(pointer: fine) and (hover: hover)` เท่านั้น · จุด/"ดู" ซ่อนลูกศรเดิม (`html.sf-cur-hide`) ยกเว้นช่องกรอก · รูปสินค้า = `a[href*="/product/"] img` / `.sf-ph` / `[data-cursor="view"]` · ขาว + `mix-blend-mode: difference` เห็นได้ทุกพื้น
- **ปุ่มกลับขึ้นบน**: โผล่เมื่อเลื่อนเกิน 0.8 จอ · ฝั่งเดียวกับปุ่มแชทลอย → ยกขึ้น 84px (มือถือหน้าสินค้าที่มีแถบซื้อ → 152px) · ไม่โชว์หน้าชำระเงิน · เปิดเลื่อนจอนุ่มอยู่ → ใช้ Lenis

## กติกา
- **แถบล่าง**: จอ < 768px เท่านั้น · ถูกใจ/บัญชีโชว์เมื่อเปิดระบบสมาชิก · แชทโชว์เมื่อเปิดปุ่มแชท (มีในแถบ → ปุ่มแชทลอยบนมือถือซ่อน กดจากแถบแทน) · **ไม่โชว์หน้าสินค้า** (มีแถบใส่ตะกร้าติดล่างแล้ว) / ชำระเงิน / หน้าแก้ผืน · `html.sf-mnav-on` เว้นที่ล่าง 56px + ยกปุ่มแชท/กลับขึ้นบน/แถบคุกกี้ · ปุ่มคุยกันด้วย event `sf-open-search` `sf-open-menu` (Navbar) `sf-open-chat` (FloatingChat)
- **คำยอดนิยม**: ERP site API ส่ง `popularSearches` เมื่อ `searchEmpty ≠ cats` = คำที่ร้านตั้ง (`popularTermsOf` ≤ 10) + คำที่ลูกค้าค้นจริง ≥ 3 ครั้งใน 30 วันและครั้งล่าสุดหาเจอ (`mergePopularTerms`) · ไม่มีข้อมูลจริง = เฉพาะคำที่ตั้ง · สินค้าแนะนำ = แนะนำของร้าน (featured) → ขายดี (salesRank) → มาใหม่ (listedAt) · เฉพาะที่มีราคาและไม่หมด
- **แถบคุกกี้**: ปุ่ม "เฉพาะที่จำเป็น" อยู่ข้าง "ยอมรับทั้งหมด" เสมอทุกแบบ (PDPA) · โผล่เมื่อใส่รหัสวัดผล · ไม่ขึ้นในพรีวิว
- **นับถอยหลัง**: เวลาไทย · เดินในเบราว์เซอร์ (ก่อนโหลดเสร็จโชว์ --:--:--) · ≥ 1 วันโชว์ "N วัน HH:MM:SS"
- **โลโก้**: วาดเป็นตัวหนังสือ + สัญลักษณ์อย่างง่ายเอง (ไม่โหลดรูปจากเว็บอื่น ไม่ใช่ไฟล์โลโก้ทางการ)

## กติกา
- **คูปองครั้งหน้า**: ERP site API (`app/api/public/storefront/site`) ส่ง `thanksCoupon {code,label,endsAt}` เฉพาะเมื่อโค้ดยังใช้ได้จริง (เปิดอยู่ · ไม่หมดอายุ · ไม่ครบจำนวน — `evaluateCoupon` + `couponUsage`) และ **ใช้ได้ทุกคน** (ไม่ใช่เฉพาะสมาชิก/ลูกค้าใหม่/ระดับ/โค้ดชวนเพื่อน) · เว็บร้านโชว์เมื่อ `thanksCoupon.code` ตรงกับที่ตั้ง → คูปองหมดอายุแล้ว กล่องหายเอง ไม่ต้องแก้ธีม · ตัวเลือกใน ERP ดึงจาก `/api/website/coupons` กรองแบบเดียวกัน
- **สินค้าแนะนำ** (404/ขอบคุณ): `src/lib/recommend.ts` `pickRecommended` = แนะนำของร้าน → ขายดี → มาใหม่ · มีราคา · ไม่หมด · หน้าขอบคุณขอจาก `/api/search?recommend=4`
- **404 ยังตอบรหัส 404** (Google ไม่เก็บหน้าเสีย) · ลิงก์ที่ตั้ง "ย้ายลิงก์" ไว้ยังพาไปหน้าใหม่ก่อน (`redirectIfMoved`)
- **ป๊อปอัป**: "กำลังจะออก" = เมาส์ออกขอบบนของหน้า (คอม) · จอสัมผัสใช้ "เลื่อนถึงครึ่งหน้า" แทน · "ทุก 7 วัน" = ปิดไปแล้ว ≥ 7 วันและยังไม่ได้รับโค้ด (`sf-promo-seen-at`) · ตัวอย่าง `?pv=popup` ใช้ได้เฉพาะในพรีวิว ERP (ไม่ส่งอีเมล ไม่จำว่าเคยเห็น · ร้านยังไม่ตั้งโค้ด = โชว์ WELCOME10 ตัวอย่าง)
- **รูปแชร์**: ใช้รูปที่วาดเมื่อเลือก card/frame เท่านั้น · ลิงก์รูปมี `v=` (แบบ/สี/ราคา/รูปแรก) เปลี่ยนเมื่อไร Facebook/LINE ได้รูปใหม่ · รูปสินค้าขอจาก ERP `r2-image?sq=1` (JPEG — ตัววาดอ่าน webp ไม่ได้) · ฟอนต์ไทย Noto Sans Thai จาก Google Fonts · วาดไม่ได้ = ส่งต่อไปรูปแรก (307) · ใช้ธีมที่เผยแพร่แล้ว (ร่างไม่มีผลกับรูปแชร์)
- **รูป** ทุกช่องเก็บเป็นคีย์ R2 (`imgKey` รับเฉพาะ `[\w-./]` ไม่มี `..`) · อัปผ่าน `ImageInput` โฟลเดอร์ `website-pages`
