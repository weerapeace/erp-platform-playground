# โหมดเลือก + Shift เลือกเป็นช่วง (ของกลาง)

`components/select-mode` (`useSelectMode` · `SelectModeBar`) + กฎ pure `lib/range-select` (`clickSelect` · `selectAllVisible` · เทสต์ `lib/__tests__/range-select.test.ts`)

- เจ้าของเลือกจาก widget 2026-11-23: "โหมดเลือก + Shift เลือกช่วง ในตารางกลาง" + ข้อเสนอ 1-5
- **รอบ 2 (2026-11-23 · เจ้าของเลือก A = ทุกตารางในระบบ):** ไม่มีปุ่ม "เลือก" แล้ว — **ติ๊กช่องแรก = เข้าโหมดเอง · ล้างจนไม่เหลือติ๊ก = ออกเอง** (โหมด = "มีรายการที่ติ๊กอยู่" ไม่ใช่สวิตช์แยก)

## ทำอะไร
| วิธีกด | ผล |
|---|---|
| กดช่องติ๊ก | สลับตัวนั้น — **กดได้ทั้งช่อง** (สูงเต็มแถว) ไม่ต้องเล็งกล่องเล็ก · ติ๊กตัวแรก = เข้าโหมดเลือก |
| ในโหมดเลือก (ติ๊กอยู่ ≥ 1) กดแถว/การ์ด | ติ๊ก/เอาติ๊กออก (ไม่เปิดรายละเอียด) · แถบฟ้าบอกวิธี + เลือกทั้งหมด / ล้าง |
| **Shift + กด** (ช่องติ๊ก หรือแถวตอนอยู่โหมดเลือก) | เลือกทั้งช่วงจากตัวที่กดล่าสุด ตามลำดับที่เห็นบนจอ (ข้ามกลุ่มที่พับ) · ตัวตั้งต้นไม่ได้ติ๊ก = **เอาติ๊กออกทั้งช่วง** (แบบ Gmail) · Shift ไม่ลากคลุมข้อความ |
| มือถือ/แท็บเล็ต **กดค้าง** ~0.45 วิ ที่แถว/การ์ด | ติ๊กตัวนั้น (= เข้าโหมด · สั่นเบา ๆ) · เลื่อนนิ้ว = ยกเลิก ไม่ทับการเลื่อนจอ |
| ปุ่ม "ล้าง" ในแถบฟ้า (หรือเอาติ๊กออกจนหมด) | ออกจากโหมด — กดแถวกลับมาเปิดรายละเอียดเหมือนเดิม |
| Ctrl+A (ในโหมดเลือก) | เลือกทั้งหมดที่เห็น (แป้นไทยก็ได้ — shortcutKey) · ไม่แย่งตอนพิมพ์ในช่องกรอก |

- **ไม่ผูก Esc** แล้ว — โหมดผูกกับชุดที่ติ๊ก ถ้า Esc = ออก ก็ต้องล้างชุดที่ติ๊ก กดพลาด (เช่น Esc ปิดป๊อป) แล้วที่ติ๊กไว้หาย

## มีให้ในตัวแล้ว
- **MiniTable** `selectable` — ตาราง + การ์ด (cardPick / การ์ดธรรมดา) · ไม่ต้องทำอะไรเพิ่มในหน้า
- **DataTable** (ตารางที่มีช่องติ๊ก = bulk actions / bulk edit / selectable) — โหมดตาราง · ติ๊กไว้ ≥ 1 แถว = กดแถวเป็นการติ๊ก · ลำดับแถวเก็บตอนวาด (จัดกลุ่ม/พับกลุ่มถูกต้อง) · มุมมองการ์ดของ DataTable ยังไม่มีช่องติ๊ก
- ไม่บันทึกอะไรเอง — หน้าเจ้าของถือชุดที่เลือก (MiniTable `selected/onSelectedChange` · DataTable rowSelection เดิม)

## ใช้เองในรายการที่เขียนเอง
```tsx
const sm = useSelectMode({ order: keysOnScreen, selected, onChange: setSelected });
{sm.mode && <SelectModeBar count={selected.size} total={keysOnScreen.length} onAll={sm.selectAll} onClear={sm.exit} />}
<div onClick={(e) => (sm.mode ? sm.pick(key, e) : openDetail())} {...sm.pressProps(key)}>
  <span onClick={(e) => { e.stopPropagation(); sm.pick(key, e); }}><input type="checkbox" checked={selected.has(key)} readOnly /></span>
</div>
```
- `order` = ลำดับที่เห็นบนจอ หรือฟังก์ชันคืนลำดับ (ตารางที่รู้ลำดับตอนวาดเท่านั้น เช่น DataTable)
- `sm.exit()` = ล้างที่ติ๊ก (= ออกจากโหมด)

## ห้าม
- เขียน shift-click / โหมดเลือก / กดค้างเลือกเองในหน้า — ใช้ตัวนี้
- ทำปุ่ม "เลือก" / สวิตช์โหมดเลือกเองกลับมา — เจ้าของสั่งเอาออก (ติ๊กแล้วเข้าโหมดเอง)
- ⚠️ DataTable: ตัวที่ช่องติ๊กเรียก (`sm.pick`) ต้องประกาศก่อน `withSelectCol` (เคยมีบทเรียน render TDZ)
