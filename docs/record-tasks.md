# ✅ เช็กลิสต์กลาง (Record Tasks) — ของกลาง

เช็กลิสต์ผูกกับ "หน้า/โมดูล" หรือ "เรคคอร์ดใดก็ได้" เก็บที่ตารางเดียว `erp_record_tasks` ผ่าน API กลาง `/api/record-tasks`
สถานะง่าย ๆ: ☐ ค้าง (`open`) / ✓ เสร็จ (`resolved` — ตาราง check constraint ไม่มีค่า `done`)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ใช้: รายการสั้น ๆ ที่ติ๊กเสร็จได้ เช่น "รออะไรอยู่" ของใบงาน · เช็กลิสต์ส่วนกลางของหน้า
- ไม่ใช้: งานเต็มรูปแบบที่มีผู้รับผิดชอบ/กำหนดส่ง/ไฟล์แนบ → โมดูลงาน (erp_creative_tasks) · เช็กลิสต์ผลิตของบอร์ดจ่ายงาน (มีระบบของตัวเอง)

## หน้าตา 3 แบบ (ใช้ hook เดียวกัน `useRecordTasks`)
| แบบ | ใช้ที่ | ไฟล์ |
|---|---|---|
| `RecordTasksButton` ปุ่ม + Drawer | หัวหน้า Design Sheets (เช็กลิสต์ส่วนกลาง) | `components/record-tasks/index.tsx` |
| `RecordChecklist` ฝังในฟอร์ม | ใบงานออกแบบ "⏳ รออะไรอยู่" (คอม + มือถือ) | `components/record-tasks/checklist.tsx` |
| `RecordChecklistChip` แถบบนการ์ด | การ์ดใน Design Dashboard (บอร์ด + แกลเลอรี) | `components/record-tasks/checklist.tsx` |

```tsx
<RecordChecklist moduleKey="design_sheet_waiting" recordType="design_sheet" recordId={sheet.id}
  canEdit={canEdit} presetType="design_sheet_waiting" label="⏳ รออะไรอยู่" />

<RecordChecklistChip moduleKey=... recordId={sheet.id} summary={sheet.waiting_items}
  canEdit={canEdit} onChange={(s) => updateCard(sheet.id, s)} />
```

- **RecordChecklist**: ติ๊ก · กดข้อความเพื่อแก้ · ✕ ลบ (ชี้แถวถึงเห็น · จอสัมผัสเห็นตลอด) · พิมพ์ + Enter เพิ่ม · ปุ่มลัด "ใช้บ่อย" (ซ่อนข้อที่มีอยู่แล้ว) · ⚙️ ตั้งค่าปุ่มลัด · ข้อที่เสร็จพับเป็น "เสร็จแล้ว N ข้อ" · ทุกข้อโชว์ใครเพิ่ม/ใครติ๊ก + เมื่อไหร่ · บันทึกทันทีทีละข้อ (ไม่ผูกกับปุ่มบันทึกของฟอร์ม)
- **RecordChecklistChip**: ไม่มีรายการ = ไม่โชว์ · มีค้าง = "⏳ ข้อแรก +N" กดแล้วเด้งกล่องติ๊ก/เพิ่ม (ข้อที่เพิ่งติ๊กยังโชว์ขีดฆ่าจนปิดกล่อง กดผิดแก้ได้) · เสร็จครบ = "✓ ไม่มีอะไรรอแล้ว" · กันคลิก/พิมพ์ไหลไปเปิดการ์ด
- สรุปบนการ์ดมาจาก API รายการ (`loadChecklistSummaries` ใน `lib/record-tasks-server.ts` — ยิงครั้งเดียวทุกใบ) ไม่ยิงทีละการ์ด · ติ๊กบนการ์ดแล้ว `onChange` ส่งสรุปใหม่ให้หน้าแม่

## 👤 ผู้รับผิดชอบรายข้อ (เพิ่ม 2026-10-23)
- แต่ละข้อใส่ผู้รับผิดชอบได้ 1 คน (`assigned_to` = user id) — กดชิป "👤 ใคร" ท้ายแถว → เลือกจาก `UserPicker` กลาง (คนที่ล็อกอินได้) · ตอนเพิ่มข้อใหม่เลือกก่อนกดเพิ่มได้ · ปิดได้ด้วย `assignable={false}`
- กด "👤 ใคร" แล้วมีปุ่มลัด **3 คนที่เลือกล่าสุด** ให้กดได้เลย (ของกลาง `useRecentUsers` · เพิ่ม 2026-10-25)
- โชว์ชื่อทุกที่: ในฟอร์ม (ชิปวงกลมสีตามชื่อ `WhoChip`) · บนการ์ด/กล่องลอย · อีเมลรายงาน ("รอ: หาผ้า — ฝน") · Discord (ปุ่ม "☐ หาผ้า · ฝน") — ข้อความต่อชื่อใช้ `taskWithWho` (`lib/record-tasks.ts`) ตัวเดียว
- ใส่ชื่อแล้ว → คนนั้นได้แจ้งเตือนในกระดิ่ง "มีงานรอคุณ: …" (`notifyAssignee` — ใส่ชื่อตัวเองไม่แจ้ง) ลิงก์เปิดใบงานตรง (ทะเบียนลิงก์ `TARGETS` ใน `lib/record-tasks-server.ts` — เช็กลิสต์ชนิดใหม่เพิ่มที่นั่น)
- ผู้รับผิดชอบติ๊กข้อของตัวเองได้แม้ไม่มีสิทธิ์ `products.edit` (เฉพาะเปลี่ยนสถานะ · ทั้งในระบบ ป๊อปเตือนงาน และ Discord)
- ป๊อปตอนเข้า ERP: ข้อที่ใส่ชื่อคนนั้นขึ้นก่อนในหัว "👤 งานของคุณ" — ดู [email-reports.md](email-reports.md#-ป๊อปเตือนงานตอนเข้า-erp)

## 🔗 ลิงก์ต่อข้อ (เพิ่ม 2026-10-24)
- ทุกข้อใส่ลิงก์ได้หลายอัน (สูงสุด 10) + ชื่อกำกับไม่บังคับ — ปุ่ม 🔗 ท้ายแถว (ชี้แถวถึงเห็นถ้ายังไม่มีลิงก์) → ช่องวางลิงก์ใต้ข้อ · Enter = เพิ่ม · ✕ = เอาออก
- เก็บใน `erp_record_tasks.metadata.links` = `[{ url, label? }]` (ไม่มีคอลัมน์ใหม่) · รับเฉพาะ http/https (ไม่มี http นำหน้าแต่เป็นชื่อเว็บ = เติม https:// ให้) · ทำความสะอาดที่ `normalizeTaskLinks` (`lib/record-tasks.ts`) ทั้งตอนรับเข้าและตอนอ่านออก
- API: POST/PATCH `/api/record-tasks` ส่ง `links` (PATCH = แทนทั้งชุด · ต้องมี `products.edit` — ผู้รับผิดชอบที่ไม่มีสิทธิ์แก้ติ๊กได้อย่างเดียว) · คืน `links` ในทุกแถว (metadata ไม่ส่งออกทั้งก้อน · `toRecordTask` ใน `lib/record-tasks-server.ts`) · audit เก็บ `links` + `links_before`
- **ค่าที่ใช้บ่อยที่เปิดสวิตช์ 🔗** (`erp_lookups.metadata.links = true` · ตั้งได้ในป๊อป ⚙️ ตั้งค่า ไม่ต้องแก้โค้ด) กดแล้วเปิดช่องวางลิงก์ให้เลย — เช่น "ซื้อของ"
- โชว์ที่: ฟอร์มใบงาน · การ์ด Design Dashboard (ปุ่ม 🔗 / 🔗N เด้งรายการ) · กล่องลอยบนการ์ด · ป๊อปเตือนงานตอนเข้า ERP · Discord (ช่อง "🔗 ลิงก์" ในการ์ด กดได้) · อีเมลรายงาน (กดได้ · ข้อความล้วนมีลิงก์เต็ม) — เฉพาะข้อที่ยังรอ
- ชิ้นกลาง: `TaskLinkList` / `TaskLinksButton` (`components/record-tasks/task-links.tsx` · ไฟล์เล็ก ป๊อปเตือนงานใช้ได้โดยไม่ลากเช็กลิสต์ทั้งก้อน)

## ค่าที่ใช้บ่อย (ปุ่มลัด)
- เก็บเป็นค่ากลาง `erp_lookups` ชนิด `presetType` · ลำดับ = `sort_order` · `metadata.links = true` = กดแล้วเปิดช่องลิงก์ให้เอง (สวิตช์ 🔗 ในป๊อปตั้งค่า)
- แก้ได้จากหน้างานเลย: `LookupValuesEditor` (`components/lookup-values-editor`) — เพิ่ม / กดชื่อแก้ / ✕ เอาออก (ปิดใช้ เรียกคืนได้ที่ ตั้งค่า → ค่ากลาง) / ลากเรียง · ใช้ได้กับค่ากลางชนิดไหนก็ได้
- `useLookupNames(type)` = ชื่อที่เปิดใช้ (แคชร่วมทั้งหน้า แก้แล้วทุกช่องอัปเดตเอง)

## ข้อมูล
- `erp_record_tasks`: `module_key` (ชนิดเช็กลิสต์) · `record_type` · `record_id` (ข้อความ · ส่วนกลางของหน้า = `""` เพราะ NOT NULL) · `title` (≤300) · `status` · `created_by` / `resolved_by` (ชื่อคน) · `resolved_at`
- `assigned_to` = ผู้รับผิดชอบ (มีหน้าจอแล้ว) · `due_at` / `priority` รองรับอยู่แล้ว (ยังไม่มีหน้าจอ — ถ้าจะเพิ่ม "ภายในวันไหน" ต่อยอดได้เลย)
- ใบงานออกแบบ: ค่าคงที่ชุดเดียวที่ `lib/design-sheet-waiting.ts` (`DESIGN_WAITING`) — ใช้ทั้งฟอร์ม/การ์ด/hover/API รายการ/อีเมลรายงาน
- migration `202610300500_design_sheet_waiting_checklist.sql`: สร้างชนิดค่ากลาง + ค่าตั้งต้น 5 ค่า + ย้ายข้อความ `design_sheets.waiting_for` เดิมเป็นข้อแรก (ช่องเดิมไม่ลบ เก็บสำรอง · รันซ้ำได้)

## สิทธิ์ / ประวัติ
- อ่าน `products.view` · เพิ่ม/ติ๊ก/แก้/ลบ `products.edit` (guardApi) · ยกเว้นผู้รับผิดชอบติ๊กข้อของตัวเอง
- audit `record_task` create / update / delete (ลบเก็บข้อความที่ลบไว้ในประวัติ · เก็บ `assigned_to` ด้วย)
- ค่าที่ใช้บ่อย: API ค่ากลางใช้ RLS (ผู้ใช้ที่ login แก้ได้) · ปุ่ม ⚙️ โชว์เฉพาะคนที่แก้ใบงานได้

## ข้อจำกัด
- ฟอร์มกับกล่องบนการ์ดเป็นคนละชุดข้อมูลในเครื่อง — แก้ที่หนึ่ง อีกที่เห็นตอนเปิดใหม่/หน้า Dashboard รีเฟรชหลังปิดใบงาน
- ใบงานใหม่ที่ยังไม่บันทึก เพิ่มสิ่งที่รอไม่ได้ (ยังไม่มีเลขใบ) — บันทึกก่อน
- ติ๊กผ่าน Discord ได้ (การ์ดในรายงาน · ปุ่ม `rt:<id>`) — `lib/discord-checklist.ts` + `/api/discord/interactions` · ดู [discord-setup.md](discord-setup.md) · ติ๊กในระบบแล้วการ์ดใน Discord ยังไม่อัปเดตตาม
- **เพิ่มจาก Discord ได้ (2026-10-24):** ปุ่ม "＋ พิมพ์เพิ่ม" (`rta:<module>:<record>`) เด้งกล่องพิมพ์ใน Discord (`rtm:` · 1 บรรทัด = 1 ข้อ สูงสุด 10 · ช่องผู้รับผิดชอบพิมพ์ชื่อ → `findUserByName` เจอคนเดียวถึงใส่ ไม่งั้นเพิ่มโดยไม่ใส่ชื่อแล้วบอกคนกด) · เมนู "ค่าที่ใช้บ่อย" (`rtp:` · ค่ากลางชุดเดียวกับปุ่มลัดในใบงาน · ซ่อนค่าที่ค้างอยู่แล้ว) · ต้องผูกบัญชี + `products.edit` · บันทึกผ่าน `createRecordTasks` (audit via discord + กระดิ่งแจ้งผู้รับผิดชอบ) · มีเมนู = ปุ่มติ๊กบนการ์ดสูงสุด 15 ข้อ (Discord ให้ 5 แถว) · เช็กลิสต์ชนิดใหม่ต้องลงทะเบียนใน `TARGETS` (entity + presetType) ถึงจะเพิ่มจาก Discord ได้
