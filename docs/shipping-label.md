# ใบปะหน้าจริงจากแพลตฟอร์ม (Shopee) — เฟส 1 · 2026-11-26

## ใช้ทำอะไร
พิมพ์ใบปะหน้าตัวจริงของ Shopee (มีเลขพัสดุ/บาร์โค้ดขนส่ง) จาก ERP แทนการพิมพ์ที่ Seller Centre · กันพิมพ์ซ้ำด้วยประวัติพิมพ์ของเราเอง

## วิธีใช้ (พนักงาน)
1. กด **นัดส่ง** ใน Seller Centre เหมือนเดิม (ERP ยังไม่นัดส่งให้)
2. ศูนย์ออเดอร์ → ติ๊กออเดอร์ → **พิมพ์ใบปะหน้า** (หรือเมนู ⋮ ของแถว)
3. หน้าพิมพ์ตรวจก่อน → ถ้ามีใบที่พิมพ์แล้ว ขึ้นป๊อป "พิมพ์แล้วเมื่อ … โดย …" เลือกพิมพ์ซ้ำหรือข้าม
4. ได้ไฟล์ PDF เดียว เปิดแท็บใหม่ → พิมพ์ "ขนาดจริง 100%"
5. ใบที่ดึงไม่ได้ขึ้นรายชื่อ + เหตุผล + ปุ่มเปิด Seller Centre / ลองใหม่เฉพาะใบที่พลาด
- ตัวกรอง **ใบปะหน้า: ทุกใบ / ยังไม่พิมพ์ / พิมพ์แล้ว** ใต้แท็บในศูนย์ออเดอร์ (นับเฉพาะออเดอร์ที่ยังไม่ส่ง)
- ขนาดกระดาษเลือกในหน้าพิมพ์ จำต่อเครื่อง: สติกเกอร์ 10×15 ซม. (ค่าเริ่ม · ที่ร้านใช้จริง) · A4 ใบละ 4 · ขนาดเดิม
- เปิดหน้าพิมพ์แล้วดึงเองทันที (ไม่ต้องกด) · มีใบที่พิมพ์แล้วขึ้นป๊อปถามก่อน · ได้ไฟล์แล้วแสดงในหน้า + ปุ่ม "พิมพ์"

## ทำงานยังไง
- หน้าจอ `components/shipping-label/real-label-panel.tsx` (ใช้ใน `/print/platform-orders?kind=label` เมื่อออเดอร์มาจาก Shopee API)
- API `/api/shipping-labels` — GET ตรวจ (ดึงได้ไหม + ประวัติพิมพ์) · POST ขอไฟล์ทีละ ≤10 ใบ (คืน base64 ต่อใบ)
- ตัวดึงต่อแพลตฟอร์ม: ทะเบียน `app/api/shipping-labels/adapters.ts` → Shopee = `app/api/shopee/shipping-label.ts`
  - เลขพัสดุว่าง → ถาม `get_tracking_number` (อ่านอย่างเดียว) แล้วเก็บ · ยังว่าง = "ยังไม่นัดส่ง"
  - `get_shipping_document_parameter` (เลือกใบความร้อนก่อน) → `create_shipping_document` → รอ `get_shipping_document_result` = READY (≤ ~10 วิ) → `download_shipping_document` ทีละใบ
- รวม PDF + วางลงกระดาษในเบราว์เซอร์ `components/shipping-label/build-label-pdf.ts` (pdf-lib ใน public/vendor ตัวเดียวกับตัวรวม PDF กลาง)
- กติกาล้วน/ข้อความ/ขนาดกระดาษ `lib/shipping-label.ts` (เทสต์ `lib/__tests__/shipping-label.test.ts`)

## ข้อมูล / สิทธิ์ / ประวัติ
- สิทธิ์ `platform_orders.view`
- **ไม่เก็บไฟล์ PDF** ที่ไหนเลย (มีชื่อ/ที่อยู่/เบอร์ลูกค้า) — ขอใหม่ทุกครั้ง · ไม่ใช่ไฟล์งานพิมพ์สินค้า จึงไม่อยู่ใต้กฎ Drive-only
- "พิมพ์แล้ว" = ประวัติพิมพ์กลาง `print_logs` doc_type `po_label` (usePrintLog · บันทึกตอนเปิดไฟล์ เฉพาะใบที่ได้ไฟล์) — ไม่มีตารางใหม่
- ทุกครั้งที่ขอไฟล์ลง audit_logs `source: shipping_label_fetch` (ใบไหนได้/ไม่ได้ เพราะอะไร)
- ไม่เปลี่ยนสถานะออเดอร์บน Shopee (create_shipping_document แค่สร้างไฟล์) · การพิมพ์ย้อนไม่ได้แต่ไม่มีผลข้างเคียง พิมพ์ซ้ำได้เสมอ

## ข้อจำกัดที่รู้
- พิมพ์จาก Seller Centre/BigSeller ระบบไม่รู้ → กันซ้ำได้เฉพาะที่พิมพ์จาก ERP
- ออเดอร์รวมกล่อง / ขนส่งบางเจ้า (ส่งด่วน) Shopee ไม่ให้พิมพ์ผ่าน API → ขึ้นรายชื่อให้ไปพิมพ์ที่ Seller Centre
- ยังไม่รู้ว่า Seller Centre จะขึ้น "พิมพ์แล้ว" ไหมเมื่อพิมพ์จาก ERP (ทดสอบใบแรกแล้วจดที่นี่)
- ลองจริงใบแรก 2026-11-26 (2611259982AQA0) ได้ไฟล์ — Shopee ให้ชนิด NORMAL_AIR_WAYBILL (ไม่ใช่ใบความร้อน) ระบบย่อให้พอดี 10×15 · ยังต้องเช็กสแกนบาร์โค้ด
