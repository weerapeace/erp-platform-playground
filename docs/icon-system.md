# 🔣 ระบบไอคอนกลาง (ทะเบียนไอคอน + หน้า /admin/icons)

## ใช้ทำอะไร
แทนอีโมจิที่กระจายอยู่ทั้งระบบด้วย **ไอคอนชุดเดียว** ที่แอดมินคุมได้จากหน้าเว็บ ไม่ต้องแก้โค้ด

- เลือกโหมดทั้งระบบ: **อีโมจิแบบเดิม** (ค่าเริ่มต้น ไม่มีอะไรเปลี่ยน) · **ไอคอนเส้น** · **ไอคอนเส้น + สี** (สีตามความหมาย)
- เปลี่ยนไอคอนของแต่ละ "ความหมาย" (เช่น บันทึก, ลบ, ใบเสร็จ) → ทุกจุดที่ใช้ความหมายนั้นเปลี่ยนตาม
- อัปโหลด **ไอคอนของฉัน** (PNG/WebP/JPG หรือ SVG / วางโค้ด SVG) — ติ๊ก "ระบายสีตามตัวหนังสือ" ได้สำหรับไอคอนสีเดียว
- จับคู่อีโมจิที่ระบบยังไม่รู้จักเข้ากับความหมาย (หน้าโชว์อีโมจิในเมนูที่ยังไม่จับคู่ให้)

## ชิ้นส่วน
| ไฟล์ | หน้าที่ |

| `lib/erp-icons.ts` | ชุดไอคอนเส้น (Tabler Icons · MIT) ~230 ตัว — **สร้างอัตโนมัติ** ด้วย `scripts/gen-erp-icons.mjs` ห้ามแก้มือ |
| `lib/icon-registry.ts` | ทะเบียนความหมาย `ICON_MEANINGS` (อีโมจิเดิม → ไอคอน + สี) · `resolveIcon` · `cleanIconSettings` (pure ใช้ได้ทั้งหน้าจอ/API) |
| `components/icon/index.tsx` | `<Icon>` ตัววาดกลาง + ค่าตั้งค่ากลาง (โหลดครั้งเดียว จำในเครื่อง กันกระพริบ) |
| `components/icon/icon-picker-modal.tsx` | `IconPickerModal` ป๊อปเลือกไอคอน (ไอคอนเส้น / ไอคอนของฉัน + อัปโหลด) |

| `app/admin/icons` | หน้าตั้งค่า (ทางเข้า: ปุ่ม 🔣 ในหน้า "จัดการเมนู") |
| `app_settings.icon_settings` | jsonb ที่เก็บค่า (migration `202611050100_app_settings_icon_settings.sql`) |

## วิธีใช้ในโค้ด
```tsx
import { Icon } from "@/components/icon";

<Icon value={item.icon} />      // ค่าเดิม (อีโมจิในเมนู/DB) — ระบบหาความหมายแล้ววาดตามโหมด
<Icon name="save" /> บันทึก      // โค้ดใหม่: เรียกตามความหมาย (ชื่ออยู่ใน ICON_MEANINGS)
<Icon value="i:truck" />        // เจาะจงไอคอนเส้น (วาดทุกโหมด)
```
- ขนาดค่าเริ่ม `1em` = เท่าตัวหนังสือรอบ ๆ (ใส่ใน `<span className="text-lg">` ได้เลย) · สีตาม `currentColor`
- โหมดอีโมจิ = คืนอีโมจิเป็นตัวหนังสือเหมือนเดิมทุกอย่าง → ย้ายจุดไหนมาใช้ `<Icon>` ก็ไม่ทำให้หน้าตาเดิมเพี้ยน

## ค่าไอคอนที่เก็บ (ข้อความเดียว · เข้ากับ `lib/website-icons` ของเว็บร้าน)
- `i:<key>` ไอคอนเส้น · `c:<id>` ไอคอนของฉัน · `img:<r2 key>` รูปตรง ๆ · อื่น ๆ = อีโมจิ/ตัวอักษร

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ✅ ไอคอนในเมนู ปุ่ม หัวข้อ ป้ายสถานะ ป๊อป บนหน้าจอ ERP
- ❌ ข้อความที่ส่งออกนอกระบบ (LINE / Discord / อีเมล / Push) — ช่องทางพวกนั้นวาด SVG ไม่ได้ ใช้อีโมจิต่อ
- ❌ เนื้อหาที่ผู้ใช้พิมพ์เอง (คอมเมนต์ แชท) · เว็บร้าน (มี `SiteIcon`/`SiteIconPicker` ของตัวเอง)
- ❌ ห้ามเพิ่มอีโมจิใหม่ลงโค้ดหน้าจอ — ใช้ `<Icon name=…>` (ถ้าไม่มีความหมายที่ต้องการ ให้เพิ่มใน `ICON_MEANINGS`)

## เพิ่มความหมาย / ไอคอน
- ความหมายใหม่: เพิ่มบรรทัดใน `ICON_MEANINGS` (key ภาษาอังกฤษ, ชื่อไทย, หมวด, อีโมจิหลัก, ไอคอนเริ่มต้น, สี, อีโมจิอื่นที่หมายถึงสิ่งเดียวกัน)
- ไอคอนเส้นใหม่: เพิ่มชื่อจาก tabler.io/icons + คำไทยในรายการของ `scripts/gen-erp-icons.mjs` แล้วรัน
  `npm pack @tabler/icons@3.31.0` → แตกไฟล์ → `node scripts/gen-erp-icons.mjs <โฟลเดอร์ package>`
- เทสต์: `lib/__tests__/icon-registry.test.ts` (ทุกความหมายต้องชี้ไอคอนที่มีจริง)

## สิทธิ์ / ประวัติ
- อ่านค่า: ทุกคน (ใช้วาดไอคอน) · บันทึก: `admin.users`
- ทุกการบันทึกเขียน audit `icon_settings.update` บอกว่าโหมด/ความหมาย/อีโมจิไหนเปลี่ยนจากอะไรเป็นอะไร

## ข้อจำกัด / แผนต่อ
- เฟส 1 (ตอนนี้): เมนูข้าง + แท็บแอป + แถบเมนูล่างมือถือ ใช้ `<Icon>` แล้ว · หน้าอื่นยังพิมพ์อีโมจิตรงในโค้ด (~9,450 จุดใน 888 ไฟล์ ณ 2026-10-28)
- เฟส 2: ของกลาง (ปุ่มแถวในตาราง, หัวป๊อป, แถบคำสั่งหลายรายการ, Empty/Error) · เฟส 3: ทยอยย้ายทีละหน้า เริ่มบอร์ดจ่ายงาน · เฟส 4: ตัวนับอีโมจิกันเพิ่มใหม่
- ไอคอนของฉันเป็นรูป (PNG) — แบบ "ระบายสี" ใช้รูปทรงจากความใสของรูป จึงต้องเป็นรูปพื้นใส
- ค่าใหม่มีผลกับคนอื่นเมื่อเขาเปิดหน้าใหม่ (โหลดค่าครั้งเดียวต่อการเปิดเว็บ)
