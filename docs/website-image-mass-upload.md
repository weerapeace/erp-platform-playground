# 📸 ลงรูปเว็บทีละมาก (Mass image upload)

ลากโฟลเดอร์รูป (หรือหลายไฟล์) มาวาง → ระบบจับคู่ **ชื่อไฟล์ / ชื่อโฟลเดอร์** กับรหัสสินค้าและสีให้เอง → ตรวจก่อนลง → กดลงรูป

## อยู่ที่ไหน

หน้า **เว็บไซต์ → ร้าน → สินค้าบนเว็บ**

- ปุ่ม **📸 ลงรูปทีละมาก** (หัวตาราง) = จับคู่กับสินค้าทั้งร้าน
- ติ๊กสินค้าก่อน → แถบล่าง **📸 ลงรูป** = จับคู่เฉพาะที่ติ๊ก (ไฟล์ของสินค้าที่ไม่ได้ติ๊ก → ขึ้นในรายการ "ไฟล์ที่ต้องดู")

## กติกาตั้งชื่อไฟล์

| ชื่อไฟล์ | ลงที่ |
| --- | --- |
| `JEAN08.jpg` · `JEAN08_2.jpg` | รูปบนเว็บ (รูปรวมของสินค้า) |
| `JEAN08-01.jpg` · `JEAN08-01_2.jpg` · `JEAN08-01 (3).jpg` | รูปสี 01 |
| `JEAN08-01-L_1.jpg` (SKU ไซส์) | รูปสี 01 (สีเดียวกัน) |
| `JEAN08_hero.jpg` / `JEAN08_hero_m.jpg` | Hero คอม / Hero มือถือ ของสินค้า |
| `JEAN08-01_hero.jpg` / `JEAN08-01_hero_m.jpg` | Hero ของสีนั้น |
| 🎬 `JEAN08.mp4` / `JEAN08_m.mp4` (หรือ `_hero_m`) | Hero **วิดีโอ** คอม / มือถือ ของสินค้า |
| 🎬 `JEAN08-01.mp4` / `JEAN08-01_m.mp4` | Hero วิดีโอของสีนั้น |
| โฟลเดอร์ `JEAN08/` หรือ `JEAN08-01/` | ไฟล์ข้างในเข้าที่นั้น (ชื่อไฟล์ไม่มีรหัสก็ได้ เช่น `JEAN08-01/2.jpg`) |

- ไม่สนตัวพิมพ์เล็ก/ใหญ่ · รหัสยาวได้ก่อน (`JEAN08-01` ชนะ `JEAN08`) · หลังรหัสต้องเป็นตัวคั่นหรือจบชื่อ (`JEAN080` ไม่ใช่ `JEAN08`)
- เลขท้าย `_1 _2 (2)` = ลำดับรูป · ไม่มีเลข = มาก่อน
- `JEAN08-03.jpg` แต่สินค้าไม่มีสี 03 → **ไม่เดา** ให้เลือกช่องเอง
- ครั้งละ ≤ 1,000 ไฟล์ (`MAX_WEB_MASS_FILES` · ตัวจัดรูปหลายโฟลเดอร์ยัง 300) · รูป jpg / png / webp (ย่อเหลือ ≤ 2000px อัตโนมัติ)
- 🎬 วิดีโอ mp4 / webm / mov **ลงได้เฉพาะ Hero** (ไม่ต้องใส่ _hero ก็ได้) · ≤ 200 MB (แนะนำ ≤ 15 MB · 6–10 วินาที · ไม่มีเสียง) · .MOV บางไฟล์เล่นบน Chrome/Android ไม่ได้ → แปลงเป็น MP4 (H.264)
- วิดีโอที่จับคู่ไม่ได้ → เลือกช่องเองได้เฉพาะ Hero (ของสินค้าหรือของสี)

## ตรวจก่อนลง

- แยกตามสินค้า → ช่อง → รูปใหม่ตามลำดับ + บอก "เดิม X → รวม Y/เพดาน"
- **รูปเดิมบนเว็บโชว์จางๆ** หน้ารูปใหม่ในแต่ละแถว (ชี้ = ดูชัด) · ต่อท้าย = เลขรูปใหม่ต่อจากของเดิม (เลข 1 = รูปหลัก) · แทนที่/Hero = รูปเดิมขึ้น "✕ ออก · จะเอาออก" (R2 key จาก GET เดิม · รูปย่อ /api/r2-image w=128)
- **ไฟล์ที่ต้องดู**: ไม่พบรหัส · สีไม่มีในรุ่น · เกินเพดาน · Hero ซ้ำ · ข้ามเอง → เลือกสินค้า + ช่องเองได้ในแถวนั้น
- เอาเมาส์ชี้รูป → ✕ = ไม่ลงไฟล์นี้ · **✕ ไม่ลงแถวนี้** (ใต้ชื่อแถว) · **✕ ไม่ลงสินค้านี้** (หัวสินค้า) — เช่น ลงซ้ำของที่มีแล้ว
- **⏭ ข้ามไว้**: ไฟล์ที่ไม่ลงรวมเป็นกลุ่มตามแถว → "↩ เอากลับ" ทีละกลุ่ม / ทั้งหมด (หรือปุ่ม เอากลับ ในแจ้งเตือน 10 วิ) · กลับแถวเดิม ลำดับเดิม (`Item.skip` แยกจาก `manual`)
- **↕ สลับลำดับพร้อมกัน**: ลาก/‹ › แล้วแถวอื่นที่ตำแหน่งเดียวกันสลับตาม — เลือก แถวนี้แถวเดียว / ทุกสีในรุ่นเดียวกัน / ทุกแถวที่ลากมา (ค่าเริ่ม · จำต่อคน `website_mass_upload_link_reorder`) · เฉพาะแถวชนิดเดียวกัน (รูปสี↔รูปสี) ที่มีรูปใหม่ถึงตำแหน่งนั้น
- เพดาน: รูปบนเว็บ 12 รูป/สินค้า · รูปสี 8 รูป/สี · Hero ช่องละ 1 ไฟล์ (รูปหรือวิดีโอ)

## ตัวเลือก

- **เพิ่มต่อท้าย** (ค่าเริ่มต้น): รูปเดิมอยู่ครบ รูปใหม่ต่อท้าย
- **แทนที่ของเดิม**: เฉพาะช่องที่มีรูปใหม่ — ช่องอื่นไม่แตะ · ไฟล์เดิมยังอยู่ในคลัง · เกิน 20 สินค้าต้องพิมพ์ `CONFIRM`
- Hero: ไฟล์ใหม่แทน Hero เดิมเสมอ (หน้าตรวจบอก "แทน Hero เดิม")
- **ลงที่ร้านอื่นด้วย**: ติ๊กร้านที่มีสินค้าเดียวกัน (สินค้าที่ไม่อยู่ในร้านนั้น = ข้าม)

## เบื้องหลัง

| ส่วน | ไฟล์ |
| --- | --- |
| จับคู่ชื่อไฟล์ + วางแผน (pure + test) | `lib/website-image-match.ts` |
| รวมกับรูปเดิม (pure + test) | `lib/website-image-merge.ts` |
| API | `app/api/website/listings/images/route.ts` — GET แผนที่รูปทั้งร้าน · POST ลงรูป |
| หน้าต่าง | `components/website-image-mass-upload.tsx` |
| ลากทั้งโฟลเดอร์ | `useFileDrop(..., { folders: true })` + `filePathOf(file)` ใน `components/file-drop.tsx` |

- **ลงเป็นรอบ** รอบละ 20 สินค้า (`splitRounds` · `ROUND_PRODUCTS`): อัปไฟล์ของรอบนั้นขึ้น R2 (ทีละ 3 ไฟล์ · ไฟล์ที่ไม่ได้ลงจะไม่อัป) → POST เฉพาะ key ของรอบนั้นทันที — เน็ตหลุดกลางทาง รอบก่อนหน้าขึ้นเว็บแล้ว
- **อัปเบื้องหลัง** (`runBackgroundTask`): ปิดหน้าต่าง/ไปหน้าอื่นใน ERP ได้ (กล่องมุมขวาล่าง) · ปิดแท็บ = งานหยุด (มีเตือน beforeunload) · เปิดหน้าต่างกลับมาเห็นสถานะเดิม (ถ้าคอมโพเนนต์ยังไม่ถูกถอด)
- **ลงซ้ำเฉพาะที่พลาด**: ใช้แผนตอนกดลง (`runPlanRef`) · ไฟล์ที่อัปแล้วไม่อัปใหม่ (`keysRef`) · ช่องที่บันทึกแล้วอย่างน้อยครั้งหนึ่ง = POST แบบต่อท้าย (กันโหมดแทนที่ลบของที่เพิ่งลง) · ช่องที่ยังไม่เคยบันทึก = โหมดเดิม
  - รูป = `uploadResizedImage` (โฟลเดอร์ storefront-products)
  - วิดีโอ = `uploadMediaFile` ตัวเดียวกับช่อง Hero ทีละตัว (storefront-hero · ≤ 4 MB ผ่าน ERP · ใหญ่กว่านั้นส่งตรงเข้า R2 มีแถบ %) → POST ส่ง `{ key, kind: "video" }`
- POST อ่านแถว `store_listings` ล่าสุดก่อนรวม (ไม่ทับของที่คนอื่นเพิ่งแก้) · ตรวจว่าสีเป็นของรุ่นนั้นจริง · ผ่านตัวกรองช่องรูปเดียวกับตัวตั้งค่าเว็บของสินค้า (`listingPatchToRow`)
- สิทธิ์: ดู = `products.view` · ลง = `products.edit`
- Audit: `bulk_update` / `store_listing` ต่อร้าน · `metadata.kind = "mass_images"` + `before` (ค่าเดิมทุกสินค้าที่แตะ — ย้อนกลับได้)
- ล้างแคชเว็บร้านหลังบันทึก (`purgeStorefrontCache`) → เว็บเปลี่ยนทันที

## ลากได้ 1,000 ไฟล์ + เตือนรูปซ้ำ (2026-10-29)

- **รูปพรีวิวย่อ** สูง 160px (createImageBitmap · ทำทีละ 3 รูปเบื้องหลัง · ส่งเข้า state ทุก 250 ms) — ไม่เปิดรูปเต็มทุกรูป · ถอดรหัสไม่ได้ (HEIC) = โชว์ไฟล์เต็ม
- แสดงทีละ **30 สินค้า** (ปุ่ม "แสดงอีก") · กล่อง "ไฟล์ที่ต้องดู" ทีละ 50 ไฟล์
- ทดลอง 1,000 ไฟล์ (mock): จับคู่ + พรีวิวครบ · หน่วยความจำหน้า ~97 MB
- 👀 **หน้าตาเหมือนรูปเดิมบนเว็บ** (โหมดต่อท้ายเท่านั้น): ลายนิ้วมือภาพ (`lib/image-similarity` · ถอดรหัสครั้งเดียวพร้อมทำพรีวิว `visualPrintFromSource`) เทียบกับรูปบนเว็บ + รูปสีของสินค้านั้น (รูปย่อ 96px · ทีละ 6 · สูงสุด 800 รูป · ไม่รวม Hero)
  - ป้ายบนรูป "ซ้ำเดิม" / "คล้ายเดิม" (ชี้ = บอกว่าเหมือนรูปไหน) · แถวบอก "หน้าตาเหมือนรูปเดิม n/m" + "ไม่ลงรูปที่ซ้ำ" · หัวบอกรวม + "ไม่ลงรูปที่ซ้ำทั้งหมด" (ข้ามเฉพาะระดับ "ซ้ำ" · "คล้าย" ให้ดูเอง)
  - เตือนอย่างเดียว ไม่ข้ามเอง · ไอคอนใช้ `<Icon name>` กลาง (ไม่เพิ่มอีโมจิ)

## แก้ก่อนลง (หน้าตรวจ · 2026-10-27)

- แต่ละแถวบอกชัดว่า **ลงช่องไหน · SKU อะไร** (🎨 รูปสี · PIX01-01 / ดำ · 🖼 รูปบนเว็บรวมรุ่น · 🎬 Hero) และหัวสินค้าบอก **ลงที่ร้านไหน** · ใต้รูปโชว์ โฟลเดอร์/ชื่อไฟล์
- ↕ **สลับลำดับในแถว**: กดค้างที่รูปแล้วลาก (useDragReorder · ลากข้ามแถวไม่ได้) หรือปุ่ม ‹ › — รูปแรก = รูปหลักของช่องนั้นบนเว็บ · ทับเลขท้ายชื่อไฟล์
- 🔁 **อ่านผิด? เปลี่ยนสินค้า** (หัวสินค้า): ย้ายรูปทั้งรุ่นไปสินค้าอื่น — สีจับคู่ตามเลขสีเดิม (PIX01-02 → PIX04-02) · รุ่นใหม่ไม่มีสีนั้น = ไปรอเลือกช่องในกล่อง "ไฟล์ที่ต้องดู" · ลำดับที่จัดไว้คงเดิม
- ✎ **ย้ายแถวนี้**: เลือกสินค้า + ช่องปลายทาง → ย้ายทั้งแถว (ต่อท้ายแถวปลายทาง)
