# 🧵 ไฟล์ปัก (Embroidery) — `/master/embroidery`

เปิดโลโก้/ลายเวกเตอร์ → ได้ไฟล์เครื่องปัก **.DST** (Tajima — ร้านปักส่วนใหญ่รับ) + **ใบสั่งปัก** ส่งร้าน

เจ้าของสั่ง 2026-11-26 · เลือกทาง **A+B** (เริ่มทำในเบราว์เซอร์ก่อน · Ink/Stitch ค่อยต่อทีหลังถ้าลายไหนไม่สวย) · ปักบนผ้า · ข้อเสนอ 1 เตือนเส้นบาง, 2 ใบสั่งปัก, 3 ผูก Parent SKU

## ใช้งาน
1. หน้า **ไฟล์ปัก** → "เปิดไฟล์โลโก้" (.ai แบบ PDF Compatible / .pdf / .svg)
2. หน้าทำงาน: ตั้ง **กว้าง × สูง (ซม.)** (ล็อกสัดส่วน) · **ความแน่นตามผ้า** (บาง / ทั่วไป / หนา) · ต่อสี: **ชนิดฝีเข็ม** · มุมถม · **รหัสด้าย** · ลำดับปัก · ปิดสีที่ไม่ปัก
3. ดูตัวอย่าง + "เล่นลำดับการปัก" · ดูกล่องเตือน "ส่วนที่อาจปักไม่สวย" (กดเปลี่ยนเป็นเดินเส้น/ไม่ปักได้)
4. **บันทึก** (แถบล่าง / Ctrl+S) → **ดาวน์โหลด .DST** + **ใบสั่งปัก** (พิมพ์/บันทึก PDF)

แก้ได้ทุกช่อง · **ย้อนกลับ** (ปุ่ม / Ctrl+Z ถึง 50 ขั้น · เปิดไฟล์ใหม่ก็ย้อนได้ก่อนบันทึก) · **ลบ** = ย้ายเข้าถังขยะ (กู้คืน/ลบถาวรพิมพ์รหัส) · ทุกการเขียนลง audit log (ค่าตั้งจดรายช่อง จาก → เป็น)

## ชนิดฝีเข็ม
| ชนิด | ทำอะไร | เหมาะกับ |
|---|---|---|
| อัตโนมัติ (ค่าเริ่ม) | ชิ้นที่ความกว้างเฉลี่ย ≤ 6 มม. = ซิกแซก · กว้างกว่า = ถมเต็ม | ทั่วไป |
| ถมเต็ม (tatami) | แถวขนานตามมุมที่ตั้ง ฝีละ 3.5 มม. เหลื่อมแบบก่ออิฐ | พื้นใหญ่ |
| ซิกแซก (satin) | ฝีเดียวพาดข้ามชิ้น ทิศขวางแนวยาวของชิ้น (กว้างเกิน 8 มม. แบ่งกลาง) | ตัวหนังสือ เส้นหนา |
| เดินเส้น | ปักตามขอบ ฝีละ 2.5 มม. | เส้นบาง ขอบ |

ทุกบล็อกมีฝีล็อกด้ายต้น/ท้าย · ย้ายไกลเกิน 2 มม. = ล็อก → ตัดด้าย → กระโดด · ชดเชยผ้าหด 0.2 มม.

- หน้าจอ: `components/embroidery/` (list · editor · stitch-preview · sheet · shared)

## DST ที่เขียน
หัวไฟล์ 512 ไบต์ (LA/ST/CO/+X/-X/+Y/-Y/AX/AY/MX/MY/PD) + คำสั่งละ 3 ไบต์ หน่วย 0.1 มม. แกน y ชี้ขึ้น · ฝียาวสุด 12.1 มม./คำสั่ง (ยาวกว่าแตกให้เอง) · ตัดด้าย = กระโดดเปล่า 3 ครั้ง (ค่าตั้งต้นเครื่อง Tajima ส่วนใหญ่) · เปลี่ยนสี = `00 00 C3` · จบ = `00 00 F3` · ชื่อไฟล์อังกฤษล้วน (เครื่องบางรุ่นอ่านไทยไม่ได้) · ไฟล์ DST **ไม่มีสี** ร้านดูลำดับสีจากใบสั่งปัก

## ข้อจำกัด (แปลงอัตโนมัติ ไม่ใช่คน digitize)
- ไม่มีฝีรองพื้น (underlay) — ผ้ายืด/ผ้าหนาอาจย่น
- ซิกแซกวิ่งทิศเดียวต่อชิ้น (ไม่เลี้ยวตามตัวอักษร) — ตัว S / O จะดูแข็ง
- ไม่ตัดส่วนที่ซ้อนกัน — สีที่ปักทีหลังทับสีก่อน (จัดลำดับสีได้)
- ข้าม: เส้นขอบอย่างเดียว (ต้อง Outline Stroke) · ตัวหนังสือที่ยังไม่ Create Outlines · รูปภาพ · พื้นสีขาว · EPS (Save As PDF ก่อน)
- ตัวหนังสือสูงต่ำกว่า ~5 มม. / เส้นบางกว่า 1.5 มม. ปักไม่ชัด — ระบบเตือนแต่แก้ให้ไม่ได้
- **ควรให้ร้านปักทดสอบ 1 ชิ้นทุกครั้ง**

## ทำต่อได้ (ยังไม่ทำ)
- .PES (Brother) / .JEF (Janome) / .EXP — พอร์ตวิธีเขียนจาก pyembroidery (MIT)
- ฝีรองพื้นอัตโนมัติ · ซิกแซกเลี้ยวตามเส้น
- ทาง B: ส่งลายที่แปลงไม่สวยให้ Ink/Stitch (Inkscape บนเครื่อง · GPL — รันแยก ไม่ฝังในเว็บ)
- ประมาณค่าปักจากจำนวนฝี (ราคาต่อ 1,000 ฝีของร้าน)
