# คัดลอกจากรุ่นอื่น (CopyFromRecordButton)

ของกลาง `components/master-crud/copy-from-record.tsx` · กฎเทียบค่า `lib/copy-record-diff.ts` (+เทสต์)

## ใช้ทำอะไร
เอาค่าจากระเบียนอื่นในโมดูลเดียวกันมาเติมในฟอร์ม โดย **เห็นตารางเทียบก่อน** ว่า "ตอนนี้" กับ "จะได้" ต่างกันตรงไหน แล้วติ๊กเลือกเฉพาะช่องที่จะเอา

## มี 2 ทางเข้า
| ทางเข้า | เปิดด้วย | คัดลอกอะไร |
|---|---|---|
| ปุ่มเล็ก "📋 คัดลอกจากตัวอื่น" ข้างหัวข้อกลุ่ม (โหมดแก้) | `config.copyFromRecord` | เฉพาะช่องในกลุ่มนั้น |
| ปุ่ม "📋 คัดลอกจากรุ่นอื่น" บนแถบเครื่องมือ (กลุ่มม่วง) | `config.copyFromRecordToolbar` (ตอนนี้ Parent SKU) | ทุกกลุ่ม แบ่งหัวข้อตามกลุ่มใน layout |

ปุ่มบนแถบเครื่องมือกดได้ทั้งโหมดดูและโหมดแก้ — โหมดดู: เติมแล้วสลับเป็นโหมดแก้ให้ · อยู่ในโหมดลงรายละเอียด: เติมลงช่องของโหมดเลย

## กติกาในตารางเทียบ (เจ้าของขอ 2026-11-11 "Default เลือกทุกอย่าง")
- **ต่างกัน** → ติ๊กไว้ตั้งแต่แรก · ถ้าช่องนั้นมีค่าอยู่แล้ว มีป้าย "ทับของเดิม"
- **เหมือนกัน** → จาง ติ๊กไม่ได้ (ไม่ต้องคัดลอก) — "9" กับ 9 นับว่าเหมือน
- **ต้นทางว่าง** → จาง ติ๊กไม่ได้ — กันล้างข้อมูลที่กรอกไว้ทิ้งโดยไม่ตั้งใจ
- ติ๊ก/เอาออกทั้งกลุ่มได้ที่หัวกลุ่ม · ปุ่ม "เลือกทั้งหมด / ไม่เลือกเลย"
- ค่าในตาราง: id อ้างอิง → ชื่อ · HTML → ข้อความ · รายการ → คั่นด้วย · (ฟังก์ชัน `copyPreviewValue` ใน master-crud)

## ไม่คัดลอกเด็ดขาด
รหัส/SKU/บาร์โค้ด · รูปปก · สถานะ/เปิดใช้ · วันเวลา/ผู้สร้าง (`NEVER_COPY`) + `config.copyExcludeKeys` · ช่องคำนวณ/รูป/ตารางลูก/แท็ก (`isCopyableField`)

## ความปลอดภัย
เติมลงฟอร์มเท่านั้น ไม่บันทึกเอง → บันทึกผ่านปุ่มบันทึกปกติ (สิทธิ์ระดับฟิลด์ + audit + ประวัติเวอร์ชัน เหมือนแก้เอง)

## ข้อจำกัด
- รูปแกลเลอรี/รูป Description ยังคัดลอกไม่ได้ (เป็นตารางแยก)
- ช่องแบบพิเศษ (ช่องใส่ของ/จุดเด่น) โชว์ในตารางเป็นข้อความย่อ
