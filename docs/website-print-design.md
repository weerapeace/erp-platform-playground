# 🖨 ลายรีดบนกระเป๋า (DTF/UV) — ลูกค้าเลือกลาย/อัปรูป วางบนกระเป๋า

เฟส 1 (2026-10-30) · เจ้าของเลือกแบบ: **B แผงในหน้าสินค้า + ปุ่มขยายเต็มจอ (A) + มือถือทีละขั้น (C)** · ร้านกำหนดวิธีพิมพ์ต่อรุ่น ·
ราคาเพิ่มตามขนาด เล็ก/กลาง/ใหญ่ ต่อ 1 ลาย · ตรวจลายเฉพาะออเดอร์ที่มีรูปอัปเอง · เก็บรูปลูกค้า 90 วันหลังส่งของ

## ใช้ทำอะไร
ลูกค้าเว็บร้านเลือกลายจากคลังของร้าน หรืออัปโหลดรูปตัวเอง → ลาก ย่อ หมุน (มือถือใช้ 2 นิ้ว) บน "ส่วนพิมพ์" ที่ร้านตั้ง →
เห็นราคาเพิ่ม + เตือนความชัด → กดใส่ตะกร้าเดิม → ร้านได้ออเดอร์พร้อมภาพจำลอง ขนาด/ระยะ ซม. และไฟล์

## ตั้งค่า (หลังบ้าน)
Parent SKU › แท็บ 🛍 เว็บไซต์ › ร้าน › กล่อง **🖨 ลายรีดบนกระเป๋า (DTF/UV)** → กด "บันทึก" แถบล่าง
- เปิด/ปิด · วิธีพิมพ์ DTF (ผ้า) / UV (หนัง/PU) · ราคาเพิ่มต่อลาย เล็ก ≤8 / กลาง ≤15 / ใหญ่ >15 ซม. (ด้านยาวสุด)
- ลายสูงสุดต่อ 1 ส่วน · ให้ลูกค้าอัปรูปเองไหม
- **คลังลาย** = อัลบั้มในคลังไฟล์ (Master Data › คลังไฟล์) — ติ๊กอัลบั้ม + ตั้งชื่อที่ลูกค้าเห็น + ราคาบวกเพิ่มต่ออัลบั้ม
  ลูกค้าเห็นรูปตัวอย่างของไฟล์ · ไฟล์พิมพ์ตัวจริง = "ไฟล์พิมพ์ PNG" ของลายนั้นในคลัง (ตารางในออเดอร์บอกว่ามี/ยังไม่มี)
- **ส่วนพิมพ์** (≤6) = ลากกรอบชมพูบนรูปสินค้า + กรอกขนาดจริง ซม. (วัดพื้นที่ที่รีดได้จริง เว้นตะเข็บ/หูหิ้ว)
  รูปทุกสีควรถ่ายมุมเดียวกัน — เว็บสลับรูปตามสีที่ลูกค้าเลือกให้เอง (กฎเดียวกับปั๊มชื่อ `sameAngleImage`)
- รุ่นที่ "เปิดแต่ตั้งไม่ครบ" (ไม่มีส่วนพิมพ์ หรือปิดอัปรูปและไม่มีอัลบั้ม) = เว็บไม่โชว์

## หน้าเว็บร้าน
- หน้าสินค้า classic + showcase: กล่อง "ออกแบบลายเอง (ไม่บังคับ)" เหนือปุ่มใส่ตะกร้า (showcase อยู่กับชิ้นส่วน "ปุ่ม" ทุกจอ — ไม่ต้องตั้งธีมเพิ่ม)
- ปุ่มใส่ตะกร้าเดิม: มีลาย → บันทึกแบบที่ ERP (ราคาคิดที่ ERP) → ต่อรหัสแบบท้ายบรรทัดตะกร้า `…#pd:<id>:<ราคาเพิ่ม>:<จำนวนลาย>`
  ลายเดิม+สีเดิม = ใช้แบบเดิม (กดซ้ำ = เพิ่มจำนวน) · รายการที่มีลาย เปลี่ยนสีในตะกร้าไม่ได้
- รูปลูกค้า: เบราว์เซอร์ขอลิงก์อัปโหลดจาก ERP แล้วส่งไฟล์ตรงเข้า bucket ส่วนตัว (ไม่ติดขีดจำกัด ~4 MB ของ Vercel) · พรีวิวใช้รูปย่อในเครื่อง
- ความชัด: DPI = พิกเซล ÷ (กว้าง ซม. ÷ 2.54) · ≥250 คม · ≥150 พอใช้ · ต่ำกว่า = ไม่ชัด (บอกขนาดที่ยังคม) — เตือน ไม่บล็อก
- มีรูปอัปเอง = ต้องติ๊กยืนยันสิทธิ์ในรูปก่อนใส่ตะกร้า

## ฝั่งร้าน (แท็บออเดอร์เว็บ)
- ป้าย "🖨 รอตรวจลาย / มีลายรีด" ในรายการ + ตัวกรอง "🖨 รอตรวจลาย" (โชว์เมื่อมีงานรอ)
- รายละเอียดออเดอร์ › รายการสินค้า: ภาพจำลองบนรูปสินค้า (กรอบเส้นประ = ส่วนพิมพ์) · ตาราง ขนาด ซม. / กึ่งกลางห่างขอบซ้าย-บนของส่วนพิมพ์ / หมุน · ไฟล์ลูกค้า (ลิงก์ 15 นาที)
- ✓ อนุมัติลาย · ขอรูปใหม่ · ปฏิเสธลาย (ต้องมีเหตุผล + ข้อความแจ้งลูกค้าให้คัดลอก — ระบบยังไม่ส่งเอง) · ทุกครั้งเขียน audit `print_*`
- ลายคลังร้านล้วน = อนุมัติอัตโนมัติตอนสั่ง

## ข้อมูล / สิทธิ์ / ความเป็นส่วนตัว
- ค่าตั้ง `store_listings.web_print` · แบบ `store_print_designs` (สำเนาส่วนพิมพ์ ณ ตอนออกแบบ — ภาพในออเดอร์ไม่เพี้ยนเมื่อร้านแก้ค่า) · รายการออเดอร์ `store_order_items.print_design_id`
- รูปลูกค้า bucket `print-uploads` (ส่วนตัว · ≤25 MB · PNG/JPG/WebP) โฟลเดอร์ `<shop_id>/<yyyymm>/`
- 🧹 cron `/api/cron/print-uploads-purge` ทุกวัน: ออเดอร์ส่งแล้ว/สำเร็จ/ยกเลิก เกิน 90 วัน · แบบที่ไม่ได้สั่งเกิน 14 วัน → ลบไฟล์ (ข้อมูลแบบยังอยู่)
- PDF แผ่นพิมพ์ไป Google Drive ตามกฎเดิม (ไม่ลง R2) — ทำผ่านหน้า "จัดเรียงงานพิมพ์"
- API หลังบ้าน `/api/website/print-designs` = กลุ่มสิทธิ์ "ออเดอร์และลูกค้า" (lib/website-access)
