# 🖨 ลายรีดบนกระเป๋า (DTF/UV) — ลูกค้าเลือกลาย/อัปรูป วางบนกระเป๋า

เฟส 1 + 2 (2026-10-30) · เจ้าของเลือกแบบ: **B แผงในหน้าสินค้า + ปุ่มขยายเต็มจอ (A) + มือถือทีละขั้น (C)** · ร้านกำหนดวิธีพิมพ์ต่อรุ่น ·
ราคาเพิ่มตามขนาด เล็ก/กลาง/ใหญ่ ต่อ 1 ลาย · ตรวจลายเฉพาะออเดอร์ที่มีรูปอัปเอง · เก็บรูปลูกค้า 90 วันหลังส่งของ

## ใช้ทำอะไร
ลูกค้าเว็บร้านเลือกลายจากคลังของร้าน หรืออัปโหลดรูปตัวเอง → ลาก ย่อ หมุน (มือถือใช้ 2 นิ้ว) บน "ส่วนพิมพ์" ที่ร้านตั้ง →
เห็นราคาเพิ่ม + เตือนความชัด → กดใส่ตะกร้าเดิม → ร้านได้ออเดอร์พร้อมภาพจำลอง ขนาด/ระยะ ซม. และไฟล์

## ตั้งค่า (หลังบ้าน)
Parent SKU › แท็บ 🛍 เว็บไซต์ › ร้าน › กล่อง **🖨 ลายรีดบนกระเป๋า (DTF/UV)** → กด "บันทึก" แถบล่าง
- เปิด/ปิด · วิธีพิมพ์ DTF (ผ้า) / UV (หนัง/PU) · ราคาเพิ่มต่อลาย เล็ก ≤8 / กลาง ≤15 / ใหญ่ >15 ซม. (ด้านยาวสุด)
- ลายสูงสุดต่อ 1 ส่วน · ให้ลูกค้าอัปรูปเองไหม
- **คลังลาย** = อัลบั้มในคลังไฟล์ (Master Data › คลังไฟล์) — ติ๊กอัลบั้ม + ตั้งชื่อที่ลูกค้าเห็น + ราคาบวกเพิ่มต่ออัลบั้ม
  ลูกค้าเห็นรูปตัวอย่างของไฟล์ · ไฟล์พิมพ์ตัวจริง = "ไฟล์พิมพ์ PNG" ของลายนั้นในคลัง (ตารางในออเดอร์บอกว่ามี/ยังไม่มี)
- **ส่วนพิมพ์** (≤6) = ลากกรอบบนรูปสินค้า + กรอกขนาดจริง ซม. (วัดพื้นที่ที่รีดได้จริง เว้นตะเข็บ/หูหิ้ว)
  - รูปเดียวเห็นทุกส่วนที่อยู่บนรูปนั้นพร้อมกัน คนละสี (สีมีแค่หลังบ้าน — หน้าร้านเห็นเส้นประสีเดียว) · แถบรูปด้านบน/"เปิดรูปอื่น…" สลับรูป · "เพิ่มอีกส่วน" = ลงรูปที่เปิดอยู่ (ขนาด ซม. เริ่มจากสเกลของส่วนอื่นบนรูปเดียวกัน)
  - ย้าย · ย่อ/ขยาย 8 จุด · หมุน (ใช้ได้ทุกทรง)
  - **ทรง** (`shape`): สี่เหลี่ยม · วงกลม/วงรี (ปุ่ม "ทำเป็นวงกลมพอดี") · สามเหลี่ยม · สี่เหลี่ยมดัดทรง (ลากทีละมุม / จุดกลางด้าน = เลื่อนทั้งด้าน) · ปากกา (คลิก = มุมแหลม · กดค้างลาก = โค้ง · คลิกจุดแรก/Enter = ปิดรูป · ดับเบิลคลิกจุด = สลับแหลม/โค้ง)
  - ทุกทรง **ตัดลายตามขอบ** (เจ้าของเลือกแบบ A 2026-10-30 — ลายไม่บิดตามทรง): ส่วนที่เกินขอบทรงไม่พิมพ์ · หน้าเว็บ/ภาพในออเดอร์วาดส่วนนั้นจาง
  - จุดของทรง (`pts`) เป็นสัดส่วน 0..1 ของกรอบ · กรอบ = สี่เหลี่ยมที่ครอบทรงพอดี (ลากจุดออกนอก → กรอบขยาย + ขนาด ซม. ขยายตาม) · ลายยังถูกจัดให้อยู่ในกรอบครอบ (`fitPlacement`)
  - ข้อมูลเก่าไม่มี `shape` = สี่เหลี่ยม · ปากกาจุดไม่ถึง 3 = กลับเป็นสี่เหลี่ยม
  รูปทุกสีควรถ่ายมุมเดียวกัน — เว็บสลับรูปตามสีที่ลูกค้าเลือกให้เอง (กฎเดียวกับปั๊มชื่อ `sameAngleImage`)
- **✍️ ข้อความ** (เฟส 2 · 2026-10-30): เปิด/ปิด · ฟอนต์ที่ให้เลือก (ปุ่มเขียนด้วยฟอนต์จริง · รายการกลาง `PRINT_TEXT_FONTS` 16 ฟอนต์ Google ไทย+อังกฤษ น้ำหนักเดียวต่อฟอนต์) · สี (≤12) · ยาวสุด (≤40 ตัว)
  - ลูกค้าพิมพ์ 1 บรรทัด → เว็บวาดเป็น PNG พื้นใส (ตัวอักษรสูง ~360px) แล้วอัปเหมือนรูปลูกค้า (`purpose: "text"`) = ไฟล์พิมพ์ · ราคาคิดตามขนาดเหมือนลาย · **ไม่ต้องรอตรวจ** (ตรวจเฉพาะรูปที่ลูกค้าอัปเอง — `printNeedsReview`)
  - ฟอนต์อังกฤษไม่มีตัวไทย → เว็บเตือนลูกค้า · แก้ข้อความ = วาดใหม่ คงตำแหน่ง/ความกว้าง
- รุ่นที่ "เปิดแต่ตั้งไม่ครบ" (ไม่มีส่วนพิมพ์ หรือไม่มีทั้งอัปรูป/อัลบั้ม/ข้อความ) = เว็บไม่โชว์

## หน้าเว็บร้าน
- หน้าสินค้า classic + showcase: กล่อง "ออกแบบลายเอง (ไม่บังคับ)" เหนือปุ่มใส่ตะกร้า (showcase อยู่กับชิ้นส่วน "ปุ่ม" ทุกจอ — ไม่ต้องตั้งธีมเพิ่ม)
- ปุ่มใส่ตะกร้าเดิม: มีลาย → บันทึกแบบที่ ERP (ราคาคิดที่ ERP) → ต่อรหัสแบบท้ายบรรทัดตะกร้า `…#pd:<id>:<ราคาเพิ่ม>:<จำนวนลาย>`
  ลายเดิม+สีเดิม = ใช้แบบเดิม (กดซ้ำ = เพิ่มจำนวน) · รายการที่มีลาย เปลี่ยนสีในตะกร้าไม่ได้
  - ส่ง `views` = URL รูปสีที่ลูกค้าเห็นต่อส่วนพิมพ์ → ERP เก็บ key รูปนั้นในสำเนาส่วนพิมพ์ → ภาพในตะกร้า/ออเดอร์/หลังบ้านเป็นสีที่สั่งจริง
- **🛒 ภาพแบบในตะกร้า**: รูปย่อของบรรทัดที่มีลาย = ภาพแบบบนกระเป๋า + ปุ่ม "ดูแบบลาย" กางภาพเต็ม (`components/print/PrintDesignPreview`)
- **📦 หน้าตามออเดอร์ + บัญชีสมาชิก**: ภาพแบบ + สถานะตรวจลาย + เหตุผล · ร้านขอรูปใหม่ → ปุ่ม "ส่งรูปใหม่" (ยืนยันด้วยเลขออเดอร์ + เบอร์โทร) → รูปใหม่วางที่เดิม กว้างเท่าเดิม → กลับเป็น "รอตรวจลาย" (ไฟล์เก่าถูกลบ · audit `print_customer_reupload` · ราคาเดิม)
- รูปลูกค้า: เบราว์เซอร์ขอลิงก์อัปโหลดจาก ERP แล้วส่งไฟล์ตรงเข้า bucket ส่วนตัว (ไม่ติดขีดจำกัด ~4 MB ของ Vercel) · พรีวิวใช้รูปย่อในเครื่อง
- ความชัด: DPI = พิกเซล ÷ (กว้าง ซม. ÷ 2.54) · ≥250 คม · ≥150 พอใช้ · ต่ำกว่า = ไม่ชัด (บอกขนาดที่ยังคม) — เตือน ไม่บล็อก
- มีรูปอัปเอง = ต้องติ๊กยืนยันสิทธิ์ในรูปก่อนใส่ตะกร้า

## ฝั่งร้าน (แท็บออเดอร์เว็บ)
- ป้าย "🖨 รอตรวจลาย / มีลายรีด" ในรายการ + ตัวกรอง "🖨 รอตรวจลาย" (โชว์เมื่อมีงานรอ)
- รายละเอียดออเดอร์ › รายการสินค้า: ภาพจำลองบนรูปสินค้า (กรอบเส้นประ = ส่วนพิมพ์ตามทรง · ลายส่วนที่เกินขอบทรงวาดจาง) · คอลัมน์ "ส่วน" บอกทรง + "ตัดตามขอบ" · ตาราง ขนาด ซม. / กึ่งกลางห่างขอบซ้าย-บนของส่วนพิมพ์ / หมุน · ไฟล์ลูกค้า (ลิงก์ 15 นาที)
- ✓ อนุมัติลาย · ขอรูปใหม่ · ปฏิเสธลาย (ต้องมีเหตุผล) · ทุกครั้งเขียน audit `print_*`
- **📣 แจ้งลูกค้าอัตโนมัติ** (ติ๊กไว้เป็นค่าเริ่ม) ตอนขอรูปใหม่/ปฏิเสธ — ใช้ช่องทางเดิมของร้าน ไม่มีช่องทางใหม่ (`lib/website-print-notify`):
  LINE OA (ร้านเปิด 🔔 แจ้ง LINE + มี `LINE_OA_TOKEN_<SLUG>` + ลูกค้าเข้าด้วย LINE) และ/หรือ อีเมล (ลูกค้ากรอก + ตั้ง RESEND_API_KEY/EMAIL_FROM)
  · แผงบอกก่อนกดว่าจะไปทางไหน · ส่งไม่ถึง = ได้ข้อความไว้คัดลอก · ถ้อยคำ `printReviewMessage` (lib/customer-messages) · audit `notify` channel line/email
- ลายคลังร้าน/ข้อความล้วน = อนุมัติอัตโนมัติตอนสั่ง
- **📤 ส่งเข้าจัดเรียงพิมพ์** (ลายที่อนุมัติแล้ว · ต้องมีสิทธิ์ `nesting.run`): สร้างงานใหม่ "ลายรีด <เลขออเดอร์>" หรือเพิ่มเข้างานร่างที่มีอยู่
  - แต่ละลาย → PNG ขนาดจริง (ความละเอียดไฟล์ต้นฉบับ ≤600 DPI) **ตัดตามทรงของส่วนพิมพ์** (`printPlacementMask` + sharp) → คลังไฟล์พิมพ์ R2 `nesting-prints/<sha>.png` (`lib/print-store`) → แถวในงานจัดเรียง (กว้างเป็น mm · จำนวน = จำนวนใบ)
  - ไฟล์ต้นทาง: ลายคลัง = "ไฟล์พิมพ์ PNG" ของลาย (ไม่มี = รูปในคลัง ⚠️ อาจไม่คม) · รูปลูกค้า/รูปข้อความ = ที่เก็บส่วนตัว
  - รหัสแถว `pd-<id 8 ตัว>-<ลำดับ>` → ส่งซ้ำเข้างานเดิม = แทนแถวเดิม · ตัวช่วยในเครื่อง (≥1.5) ดึงไฟล์จากคลังเองด้วย sha · PDF แผ่นพิมพ์ยังออก Drive ตามเดิม
  - ไม่แตะ DB schema: "ส่งแล้วไปงานไหน" หาจาก `erp_nesting_jobs.items` ที่มีรหัสแถวของแบบนี้ · audit `print_send_nesting`

## ข้อมูล / สิทธิ์ / ความเป็นส่วนตัว
- ค่าตั้ง `store_listings.web_print` · แบบ `store_print_designs` (สำเนาส่วนพิมพ์ ณ ตอนออกแบบ — ภาพในออเดอร์ไม่เพี้ยนเมื่อร้านแก้ค่า) · รายการออเดอร์ `store_order_items.print_design_id`
- รูปลูกค้า + รูปข้อความ bucket `print-uploads` (ส่วนตัว · ≤25 MB · PNG/JPG/WebP) โฟลเดอร์ `<shop_id>/<yyyymm>/` · `has_upload` = แบบมีไฟล์ในที่เก็บ (ลบตามวันเก็บ) — ต้องตรวจไหมดูจากชนิดลาย
- API สาธารณะ GET `?designs=<id,…>` = ภาพแบบให้ตะกร้า/หน้าออเดอร์ (ลิงก์รูปลูกค้า 1 ชม. · ห้ามแคช CDN · รหัสแบบเป็น uuid สุ่ม = กุญแจของแบบนั้น) · รายการออเดอร์ส่ง `printDesignId`
- 🧹 cron `/api/cron/print-uploads-purge` ทุกวัน: ออเดอร์ส่งแล้ว/สำเร็จ/ยกเลิก เกิน 90 วัน · แบบที่ไม่ได้สั่งเกิน 14 วัน → ลบไฟล์ (ข้อมูลแบบยังอยู่)
- PDF แผ่นพิมพ์ไป Google Drive ตามกฎเดิม (ไม่ลง R2) — ทำผ่านหน้า "จัดเรียงงานพิมพ์"
- API หลังบ้าน `/api/website/print-designs` = กลุ่มสิทธิ์ "ออเดอร์และลูกค้า" (lib/website-access)
