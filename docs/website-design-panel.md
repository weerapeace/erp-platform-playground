# หน้าดีไซน์เว็บร้าน (แท็บ 🎨 ดีไซน์ ใน /website/<ร้าน>)

เจ้าของขอ 2026-10-28: "อยากได้หน้าดีไซน์แบบย่อย ๆ ดูง่ายกว่านี้" → เลือกแบบ A (เมนูซ้ายจัดหมวด) + การ์ดพับได้ + ค้นหา + ภาพรวม

## หน้าตา

```
[แถบสถานะ: ร่าง/เผยแพร่ · "แก้เว็บจริง" บรรทัดเดียว · 🌐 EN x/y · ↶ ↷]
┌ เมนูซ้าย ─────┬ ตั้งค่า (การ์ดพับได้) ─────────┬ พรีวิวเว็บสด ┐
│ ค้นหา        │ หมวด › ชื่อหน้า   [กาง/พับทั้งหมด] │             │
│ ภาพรวม       │ TH | EN                         │             │
│ ทั้งเว็บ  ●   │ ▸ การ์ด 1  (สรุปค่าตอนพับ)       │             │
│ หัว-ท้ายเว็บ │ ▾ การ์ด 2                        │             │
│ สินค้า ซื้อขาย│    …ช่องตั้งค่า…                │             │
└──────────────┴─────────────────────────────────┴─────────────┘
[แถบล่าง: แก้ N หัวข้อ (กดชื่อไปหน้านั้น) · ละทิ้ง · บันทึกร่าง · ⏰ · เผยแพร่]
```

- จอ ≥ 1280px: เมนู | ตั้งค่า | พรีวิว · 1024–1279: พรีวิวอยู่ใต้การตั้งค่า · มือถือ: เมนูเป็นช่องเลือก + ช่องค้นหา
- `?d=<หน้า>` ในลิงก์ = เปิดหน้านั้นตรง ๆ (เช่น `/website/louismontini?tab=design&d=menu`)

## เพิ่มของใหม่ในหน้าดีไซน์

1. **ช่อง/การ์ดใหม่ในหน้าเดิม** → แก้ไฟล์แท็บนั้น ใช้ `<DesignCard title="…" summary={…}>` (summary = สรุปค่าตอนพับ บรรทัดเดียว)
   แล้วเพิ่ม `{ title, keywords }` ใน `cards` ของหน้านั้นใน `lib/website-design-nav.ts` (ค้นหาจะเจอ)
2. **ค่าใหม่ในธีม** → ใส่ path ใน `paths` ของหน้าที่แก้ค่านั้น (เทสต์ `lib/__tests__/website-design-nav.test.ts` ฟ้องถ้าลืม — จุดส้มจะไม่ขึ้น)
   + ถ้าเป็นข้อความ → เพิ่มใน `THEME_TEXT_KEYS` ด้วย (กฎเดิม 2 ภาษา)
3. **หน้าใหม่** → เพิ่มคีย์ใน `DesignPageKey` + `DESIGN_PAGES` + หมวดใน `DESIGN_GROUPS` → render ใน `website-theme-panel.tsx` (`{tab === "x" && <XTab />}`) + สรุปใน `overview.tsx pageSummary`
4. ค่าที่แท็บต้องใช้แต่ยังไม่มีใน `useDesign()` → เพิ่มใน `DesignCtxValue` (context.tsx) + `designCtx` ในเชลล์

## การ์ดพับได้ (DesignCard)

- จำพับ/กางต่อคน: `user_ui_prefs` คีย์ `website_design_cards` (`<หน้า>:<ชื่อการ์ดตัดอีโมจิ>` → true/false)
- ยังไม่เคยกด = ใบแรกของหน้ากาง ที่เหลือพับ (หรือ `defaultOpen`)
- นอก `DesignCardsProvider` = การ์ดธรรมดา กางตลอด
- `Card` ของ `website-cart-settings` (ตะกร้า · ชำระเงิน · แนะนำสินค้า) กลายเป็น DesignCard อัตโนมัติเมื่ออยู่ในหน้าดีไซน์
- ค้นหาเจอการ์ด → เชลล์ยิง event `website-design-focus` (ชื่อการ์ด) → การ์ดนั้นกางเอง แล้วเลื่อนไปหา + กะพริบกรอบ

## ข้อจำกัด / ทีหลัง

- คลิกส่วนในพรีวิว → เปิดหน้าตั้งค่านั้น / พรีวิวเลื่อนไปส่วนที่กำลังแก้ (เช่นท้ายเว็บ) ต้องแก้เว็บร้านด้วย (ตอนนี้พรีวิวแค่เปลี่ยนหน้าตามหัวข้อ)
- หน้าสินค้ายังเป็นการ์ดใหญ่ใบเดียว (ข้างในมี ⚙ ต่อส่วนอยู่แล้ว)
