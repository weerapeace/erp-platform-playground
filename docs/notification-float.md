# 🔔 การ์ดแจ้งเตือนลอย (ของกลาง)

การ์ดรายการแจ้งเตือนลอยมุมขวาล่าง (หรือขวาบน) ของทุกจอทำงาน ERP บนจอคอม — ไม่ต้องกดกระดิ่งเปิดทุกครั้ง

## หน้าตา / การใช้
- หัวการ์ด: 🔔 แจ้งเตือน + ตัวเลขยังไม่อ่าน · **－ ย่อ** เหลือปุ่มกระดิ่งกลม (มีตัวเลข · กระพริบเมื่อมีเรื่องใหม่) · **✕ ซ่อน**
- รายการ 20 เรื่องล่าสุด (จุดฟ้า = ยังไม่อ่าน · ● แดง = ด่วน) · กด = อ่านแล้ว + เปิดเรื่องนั้น
- ท้าย: อ่านหมด · ดูทั้งหมด → /notify
- เปิด/ซ่อน + เลือกมุม: **เมนูโปรไฟล์ → 🔔 การ์ดแจ้งเตือนลอย** (จำต่อคน ตามไปทุกเครื่อง · ค่าตั้งต้น = เปิด ขวาล่าง)

## ไม่โผล่เมื่อ
ยังไม่ล็อกอิน · จอแคบกว่า 1280px (ERP มีแถบเมนูล่าง → ใช้กระดิ่งเดิม/แอป /notify) · อยู่ในกรอบ iframe (แอปเดี่ยว) ·
หน้าที่ไม่ใช่จอทำงาน (`lib/chromeless-routes`: ล็อกอิน พิมพ์ ลิงก์สาธารณะ) · หน้า /notify

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `components/notification-float/index.tsx` | `NotificationFloatHost` (mount ใน app/layout) + `NotifyFloatToggle` (ใน AccountMenu) |
| `components/notification-float/pref.ts` | ค่าตั้งต่อคน `user_ui_prefs` key `notify_float` = `{ enabled, minimized, position: "br" \| "tr" }` |
| `components/notification-bell/feed.ts` | **ตัวดึงแจ้งเตือนกลาง** `useNotificationFeed(userId)` — กระดิ่ง + การ์ดใช้ร่วม ถามครั้งเดียวทุก 30 วิ (เฉพาะแท็บเปิด) · อ่านแล้วอัปเดตทุกตัวพร้อมกัน |
| `lib/use-user-pref.ts` | เพิ่มการบอกต่อในหน้าเดียว (event `erp:userpref`) → สวิตช์ในโปรไฟล์เปลี่ยน การ์ดเปลี่ยนทันที |
| `lib/chromeless-routes.ts` | รายการหน้าที่ของลอยทั้งระบบไม่โผล่ (ใช้ร่วมกับ WorkPopupHost) |

## ข้อจำกัด
- งานเบื้องหลัง (BackgroundTasksHost มุมขวาล่าง) ถ้ามีจะทับการ์ดชั่วคราว — ย่อการ์ดหรือย้ายไปขวาบนได้
- ไม่มีสิทธิ์ใหม่ — เห็นแค่แจ้งเตือนของตัวเอง (เหมือนกระดิ่ง)
