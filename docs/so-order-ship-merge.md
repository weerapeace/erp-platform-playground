# ใบสั่งขาย → ใบขาย → ใบสั่งผลิต (ส่งของ · รวมใบ) — 2026-11-21

เจ้าของสั่งจาก widget: ใบขาย = บิล/ใบกำกับ (หน้า `/sales-orders`) · รวม 010–022 · ข้อเสนอ 1–4

## ส่งของ (เปิดใบขายจากใบสั่งขาย)
- **ลิ้นชักใบสั่งขาย** → แถบ "ส่งแล้ว x / y · ค้างส่ง z" → ปุ่ม **เปิดใบขาย (ส่งของ)** (`app/sales/orders/bill-modal.tsx`)
  เลือกรายการ + จำนวนรอบนี้ (ตั้งเท่าค้าง) → `POST /api/so-orders/bill`
- **หน้ารายการ** ติ๊กหลายใบลูกค้าเดียวกัน → **เปิดใบขายรวม**
- **ป๊อปสร้างใบขาย** (`/sales-orders`) → ปุ่มแรก **ดึงจากใบสั่งขาย** (SourceDocPickerModal mode `so_order`) ดึงเฉพาะที่ค้างส่ง · บันทึกแล้วเรียก `POST /api/so-orders/link-bill`
- ปุ่มเดิม "ส่งแล้ว + ออกใบขาย" = ออกเฉพาะที่ค้าง (ไม่ออกซ้ำของที่ส่งไปแล้ว)

ตัวคิดกลาง `app/api/so-orders/ship-lines.ts`
- `loadLineShipState` — สั่ง/ส่งแล้ว/ค้าง ต่อรายการ (lib/mo-so-rule · "ส่งแล้ว" = `mo_sales_links`)
- `createInvoice` — RPC `erp_playground_so_create` + ยืนยัน + จัดส่ง (ตัดของ)
- `linkBillToSoLines` — บรรทัดใบขาย → ใบสั่งผลิตของรายการ (ใบที่ยังขาดก่อน) · audit `mo.sales_link` · `syncAutoClose` · ส่งครบทุกรายการ = ใบสั่งขาย "ส่งแล้ว"

ส่งไม่ครบ → ผลลัพธ์ถาม "ชิ้นที่เหลืออยู่ขั้นไหน?" → ปุ่มเปิดป๊อป **อัปเดตงาน** ที่บอร์ดจ่ายงาน (`/master/work-board?cu=batch&mos=`) — ทุกขั้นบันทึกผ่านกติกาเดิมของบอร์ด ไม่เขียนสถานะใบสั่งผลิตตรง

ข้อจำกัด: รายการที่ไม่มีใบสั่งผลิต นับ "ส่งแล้ว" ไม่ได้ (ระบบนับผ่านใบสั่งผลิต)

## รวมใบ / แยกคืน / เลื่อนเลข / เติมราคา — `/api/so-orders/tidy` (+ `tidy/plan.ts`)
- GET = กลุ่มที่ควรรวม (ลูกค้า+บริษัท+วันที่เดียวกัน · ใบละ 1 รายการ · ยังไม่ส่ง) → แบนเนอร์หน้ารายการ
- `preview` (ไม่เขียน) → `merge`: ใบหลัก = เลขน้อยสุด · ใบอื่น `cancelled` + `merged_into_id` + `merged_from_no` + `order_no = "<เลขเดิม>·รวม"` (เลขว่างให้ใช้ต่อ) · รายการ `merged_from_order_id` · ใบสั่งผลิตย้ายมาผูกใบหลัก · เลื่อนเลขใบถัดไปลงช่องว่าง
- `unmerge` — แยกคืน (เลขเดิมยังว่าง = ได้เลขเดิม) · รายการที่ส่งแล้วแยกไม่ได้
- `fill_prices` / `merge fill_prices` — ราคาที่เคยขายล่าสุด (`shared.lastPrices`: ลูกค้าเดียวกัน → ใบสั่งขายอื่น → ใบขาย)
- ทุก action audit พร้อม `changes: auditDiff`

⚠️ คอลัมน์ merged_* **ไม่มี foreign key** — FK ตัวที่ 2 ระหว่าง so_order_lines ↔ so_orders ทำให้ select ฝัง `so_orders(...)` เดิมพัง (PGRST201)
