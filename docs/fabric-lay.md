# ✂️ วางแบบบนผ้าลาย (`/master/fabric-lay`)

แอปในกลุ่มออกแบบ (เมนู 🎨 ออกแบบสินค้า · แอปออกแบบ + แอปผลิต) สำหรับวางชิ้นแบบตัดกระเป๋าลงบนผ้าลายผืนใหญ่ (ผ้าทอ/ผ้าพิมพ์ลายภาพ) ให้ได้ลายตรงตำแหน่งที่ต้องการ แล้วโหลดภาพสรุปไปให้ ChatGPT สร้างรูปกระเป๋า

เจ้าของสั่ง 2026-11-28 (widget 2 รอบ → เลือกความหมาย B + ข้อเสนอ 1, 2, 3, 4, 6, 7, 8, 9, 10, 11)

## ใช้ทำอะไร

| แท็บ | ทำอะไร |
|---|---|
| **อัลบั้มผ้า** | ผ้าลายผืนจริง: รูปถ่าย → ใส่ขนาดจริง กว้าง×ยาว → จิ้ม 4 มุมผ้า (ดัดรูปให้ตรง) → ตรวจระยะ 2 จุด · กรองตามประเภท (ตั้งเพิ่ม/แก้ชื่อได้) และขนาด เล็ก/กลาง/ใหญ่ · บอกว่าเหลือผ้ากี่ % หลังตัด |
| **แบบตัด (ต่อสินค้า)** | 1 Parent SKU = 1 แบบตัด (หรือใบงานออกแบบที่ยังไม่มี SKU) · ชิ้น = ส่วนของกระเป๋า (หน้า/หลัง/ข้าง/ก้น/ฝา/…) + ขนาดสำเร็จ + จำนวน + คู่ซ้าย-ขวา + เผื่อเย็บ + โน้ต · รูปกระเป๋า (ไปอยู่ใน JPEG) |
| **แผนวางบนผ้า** | ผ้า 1 ผืน + กระเป๋าหลายใบ · ลาก/หมุน/พลิกชิ้น · เตือนล้นผ้า/ทับกัน/ทับส่วนที่ตัดไปแล้ว · JPEG สรุปต่อใบ + คำสั่ง ChatGPT · ใบตัดผ้า · ปุ่ม “ตัดผ้าตามแผนนี้แล้ว” |

## ขนาดเป๊ะได้ยังไง

1. ผ้า: ดัดรูปด้วย `StraightenModal` (ของกลาง photo-capture) โดยบังคับสัดส่วน = ขนาดจริง (`aspect`) → รูปตรง 1 จุดภาพ = `width_cm / img_w` ซม. · เก็บรูปถ่าย + 4 มุม (`quad`) ไว้ แก้มุมใหม่ได้
2. ตรวจระยะ: คลิก 2 จุดที่รู้ระยะจริง → บอกคลาดกี่ ซม./% (เกิน 1% หรือ 5 มม. = สีเหลือง) · `checkResults`
3. กระดานใช้หน่วย ซม. ตรง ๆ (`viewBox = 0 0 กว้าง ยาว`) · ชิ้นใช้รูปทรงจาก `lib/pattern-shape` (เส้นเย็บ) + `pieceGeometry` (เส้นตัด = บวกเผื่อเย็บ)

## เพิ่มชิ้นแบบ

- ชิ้นสี่เหลี่ยม (ใส่กว้าง×สูง)
- โยนไฟล์ **SVG** (`parseSvgShapes`) · **DXF** (`parseDxfPattern` — ได้ชื่อ/จำนวน/เผื่อเย็บจากไฟล์) · **PNG/JPG** (เป็นรูปอ้างอิงบนชิ้นสี่เหลี่ยม + ใส่ความกว้างจริง)
- **ดึงจากสตูดิโอแพทเทิร์น** (`/api/pattern-projects` · ต้องมีสิทธิ์ pattern_studio.view) — ติ๊กชิ้น · ระบบเดาส่วนของกระเป๋าจากชื่อชิ้น

## แก้ไข · ย้อนกลับ · ลบ

- ทุกช่องแก้ได้ (ชื่อ ประเภท ขนาด มุมผ้า ชิ้น ตำแหน่ง โน้ต) · กระดาน/แบบตัด: ย้อนกลับ Ctrl+Z · ทำซ้ำ Ctrl+Y · บันทึก Ctrl+S · ออกโดยไม่บันทึก = เตือน
- ลบ = ถังขยะ (ปุ่มย้อนกลับ 5 วิ) → กู้คืนได้ · ลบถาวรเฉพาะในถังขยะ + พิมพ์รหัสยืนยัน · ผ้าที่ยังมีแผนลบถาวรไม่ได้ (FK)
- “ตัดแล้ว” ยกเลิกได้ (คืนพื้นที่ผ้า + เปิดให้แก้แผน)

## ภาพสรุป JPEG (`components/fabric-lay/summary-image.ts`)

ต่อกระเป๋า 1 ใบ: หัว (ชื่อใบ/แบบตัด/ผ้า) · รูปกระเป๋า · ผ้าทั้งผืนพร้อมตำแหน่งชิ้น (ใบนี้มีสี + ป้าย A, B… · ใบอื่นเส้นประ) · ชิ้นที่ตัดออกมาจากรูปผ้าจริง (หมุนกลับตั้งตรง คงการพลิก · สเกลเดียวกัน) · คำอธิบายทีละชิ้น (`describePlaced`: ส่วนของกระเป๋า · ขนาด · ตัดจากบริเวณไหน แนวนอน/แนวตั้งกี่ ซม. · หมุน/พลิก · โน้ต)
หน้าพิมพ์ `/print/fabric-lay/<planId>` ใช้ตัววาดเดียวกัน + ช่องเซ็น · ประวัติพิมพ์ `fabric_lay`

คำสั่ง ChatGPT (`chatGptPrompt`) = อังกฤษ + ไทย บอกให้ใช้ลายตามภาพชิ้นที่ตัด ไม่แต่งลายใหม่ — ไม่ได้เรียก AI ในระบบ (เจ้าของไม่เลือกข้อเสนอ AI วาดรูปในระบบ เพราะเสียเงินต่อรูป)

## ห้ามใช้เมื่อ

- คิดผ้าที่ต้องซื้อ / วางอัตโนมัติให้ประหยัด (ผ้าพื้นไม่สนลาย) → `lib/fabric-calc` · `lib/fabric-plan`
- วาดแพทเทิร์นใหม่ → สตูดิโอแพทเทิร์น

## ข้อจำกัดที่รู้

- จิ้มมุมผ้าแม่นแค่ไหน = ขนาดเป๊ะแค่นั้น (รูปใหญ่ 3600 px · ผ้า 1 ม. ≈ 0.3 มม./จุดภาพ) → ใช้ตรวจระยะ 2 จุดยืนยัน
- ผ้าที่ย่น/ไม่เรียบ ดัดตรงด้วย 4 มุมแก้ได้แค่มุมเอียงของกล้อง ไม่แก้รอยย่น
- ยังไม่มีวางอัตโนมัติเลือกตำแหน่งลาย (ต้องลากเอง) · ชิ้นทรงโค้งจาก PNG ยังเป็นกรอบสี่เหลี่ยม (ใช้ SVG/DXF ถ้าต้องการทรงจริง)
