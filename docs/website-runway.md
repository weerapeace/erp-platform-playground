# 🚶 รันเวย์ลุค (Section `runway`)

> เจ้าของขอ (2026-10-21) อ้างอิง Marc Jacobs "Runway Experience" (Pinterest) — ดู widget ตัวอย่างแล้วเลือก "เริ่มทำตามคำแนะนำ 6 ข้อ"

## ใช้ทำอะไร

เดินแบบทีละลุคบนหน้าเว็บ: **ลุคปัจจุบันชัด/ใหญ่ด้านหน้า** · **ลุคถัดไปเรียงแถวด้านหลัง** (เล็กลง + จาง + เบลอ) · **การ์ดสินค้าของลุค** ข้างเวที (♡ รายการโปรด + "+" ใส่ตะกร้า) · มุมล่าง "LOOK 03" + ชื่อลุค + ปุ่ม "Shop the look"

**ไม่ควรใช้** กับรูปที่ไม่ใช่รูปเต็มตัว/พื้นรก — แถวด้านหลังจะดูซ้อนกันเป็นกล่อง ใช้ "ลุคบุ๊กกดซื้อได้" แทน

## วิธีใช้

1. ตัวจัดหน้า → `+ เพิ่ม Section` → 🚶 รันเวย์ลุค (กลุ่มสินค้า)
2. เพิ่ม "ลุค" (สูงสุด 30): รูปเต็มตัว + ชื่อลุค (ถ้ามี) + สินค้าในลุค (≤ 6)
3. **รูป**: ถ่ายเต็มตัว มุม/ขนาดใกล้กันทุกลุค · ดีที่สุด = PNG ตัดพื้น หรือพื้นเรียบสีเดียวกัน (ตั้งสีพื้น Section ให้ตรงที่แผง "รูปลักษณ์")
4. ตั้งค่า: คำหน้าเลขลุค · ปุ่มดูสินค้าทั้งลุค · ลุคด้านหลัง 2–4 · แถวซ้าย/ขวา · เบลอนิด/มาก/ไม่เบลอ · ความสูงเวที · แผงการ์ด ขวา/ซ้าย/ไม่มี · โชว์ราคา · ปุ่ม ♡ · เดินลุคเอง (3–20 วิ)

## ลูกค้าเห็น

- เปลี่ยนลุค: ‹ › · กดลุคในแถว · ปัดซ้าย-ขวา · ปุ่มลูกศรคีย์บอร์ด · เดินเอง (หยุดเมื่อชี้/แตะ/เปิดการ์ด) · ลุคสุดท้าย → วนกลับลุคแรก
- ถัดไป = ตัวหน้าเดินออก แถวด้านหลังขยับขึ้นมา (แถวด้านหลัง = ลุคที่กำลังจะมา)
- มือถือ: เวทีสูง ≤ 72% ของจอ · การ์ดสินค้าเลื่อนข้างใต้เวที · "Shop the look" = แผ่นเลื่อนขึ้นจากล่าง (ของกลาง CanvasShopPop)
- ตั้งเครื่อง "ลดการเคลื่อนไหว" = เปลี่ยนลุคแบบจางเฉย ๆ

## ข้อจำกัด

- รูปกว้างอัตโนมัติตามความสูง → ลุคหน้า/แถว/ถัดไป/ก่อนหน้า โหลดทันที (lazy ไม่ทำงานกับรูปกว้าง 0) · ลุคที่เหลือโหลดเมื่อขยับเข้าใกล้
- ยังไม่มีแบบ "เลื่อนหน้าจอแล้วลุคเดิน" (ตั้งใจ — ลูกค้ามักรู้สึกว่าหน้าค้าง) · เพิ่มเป็นตัวเลือกทีหลังได้
- ปุ่ม ♡ โชว์เมื่อร้านเปิดรายการโปรด
