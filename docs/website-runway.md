# 🚶 รันเวย์ลุค (Section `runway`)

> เจ้าของขอ (2026-10-21) อ้างอิง Marc Jacobs "Runway Experience" (Pinterest) — ดู widget ตัวอย่างแล้วเลือก "เริ่มทำตามคำแนะนำ 6 ข้อ"

## ใช้ทำอะไร

เดินแบบทีละลุคบนหน้าเว็บ: **ลุคปัจจุบันชัด/ใหญ่ด้านหน้า** · **ลุคถัดไปเรียงแถวด้านหลัง** (เล็กลง + จาง + เบลอ) · **การ์ดสินค้าของลุค** ข้างเวที (♡ รายการโปรด + "+" ใส่ตะกร้า) · มุมล่าง "LOOK 03" + ชื่อลุค + ปุ่ม "Shop the look"

**ไม่ควรใช้** กับรูปที่ไม่ใช่รูปเต็มตัว/พื้นรก — แถวด้านหลังจะดูซ้อนกันเป็นกล่อง ใช้ "ลุคบุ๊กกดซื้อได้" แทน

## วิธีใช้

1. ตัวจัดหน้า → `+ เพิ่ม Section` → 🚶 รันเวย์ลุค (กลุ่มสินค้า)
2. เพิ่ม "ลุค" (สูงสุด 30): รูปเต็มตัว + ชื่อลุค (ถ้ามี) + สินค้าในลุค (≤ 6)
3. **รูป**: ถ่ายเต็มตัว มุม/ขนาดใกล้กันทุกลุค · ดีที่สุด = PNG ตัดพื้น หรือพื้นเรียบสีเดียวกัน (ตั้งสีพื้น Section ให้ตรงที่แผง "รูปลักษณ์")
4. ตั้งค่า: คำหน้าเลขลุค · ปุ่มดูสินค้าทั้งลุค · ลุคด้านหลัง 2–4 · แถวซ้าย/ขวา · เบลอนิด/มาก/ไม่เบลอ · ความสูงเวที · แผงการ์ด ขวา/ซ้าย/ไม่มี · โชว์ราคา · ปุ่ม ♡ · เดินลุคเอง (3–20 วิ) · **เลื่อนหน้าจอแล้วลุคเดิน** + ระยะเลื่อนต่อลุค (สั้น/ปกติ/ยาว)

### พื้นหลัง · คน PNG · จุดกด · ซูม (เพิ่ม 2026-10-21)

- **พื้นหลังเวที** (กลุ่ม รูป/สื่อ): สีเดียว / ผนัง + พื้น (สีพื้น + ความสูงพื้น %) / รูปภาพ (+ ทำให้จางด้วยสีพื้นหลัง %) — คลุมทั้งเวที + แผงการ์ด (การ์ดอยู่บนพื้นเดียวกัน โปร่งนิด ๆ)
- **สีพื้นหลังรายลุค**: ลุคตั้งสีเองได้ → เปลี่ยนลุคแล้วสีค่อย ๆ เปลี่ยน (0.8 วิ) · สีเข้ม = ตัวหนังสือบนเวทีเปลี่ยนเป็นสีอ่อนเอง
- **ขนาดคน**: ทั้ง Section (% ความสูงเวที, 50–100) + รายลุค (50–150%) · ยกคนขึ้นทั้ง Section (0–30%) + รายลุค (−20 ถึง +30% ของความสูงรูป — แก้ PNG ที่ขอบล่างเหลือเยอะ)
- **เงาใต้เท้า**: จาง ๆ (ค่าเริ่ม) / ชัด / ไม่มี · อยู่ที่พื้น (ยกรายลุคขยับแค่รูป เงาไม่ลอยตาม)
- **ผนัง + พื้น**: คนยืนกลางแถบพื้นค่อนล่าง · ลุคด้านหลังยืนสูงขึ้นทีละนิด (เหมือนเดินมาจากหลังเวที)
- **ตัวหนังสือใหญ่ด้านหลัง** (เช่น SS26): สีเลือกได้ (ว่าง = จาง ๆ) · บน/กลาง/ล่าง · สองภาษาได้ (`bigText_en`)
- **กดนางแบบตัวหน้า = ดูรูปเต็มจอ** (ของกลาง `ImageLightbox` บน `Overlay` แบบ viewer) · แตะ = ซูม 2.2 เท่าตรงจุด · เลื่อนดูลุคอื่นต่อได้ · ปัดเปลี่ยนลุคไม่นับเป็นกด
- **จุดกดบนตัวนางแบบ** (รายลุค 0–3 จุด · จุดละ ≤ 2 สินค้า): คลิกบนรูปลุคใน ERP เพื่อวาง · ลูกค้ากด = การ์ดเด้ง (CanvasShopPop) · จุดที่ยังไม่เลือกสินค้า = ไม่โชว์ (ERP เตือน)
- กรอบคนใช้สัดส่วนรูปจริง (อ่านหลังโหลด) → จุดกดตรงตำแหน่งบนรูปเสมอ ทุกขนาดจอ

### เลื่อนหน้าจอแล้วลุคเดิน (เพิ่ม 2026-10-21)

- เปิดแล้ว: เวทีค้างบนจอ (ใต้หัวเว็บ) · ลูกค้าเลื่อนลง = ลุคถัดไป · ครบลุคสุดท้ายค้างอีกนิด แล้วหน้าเว็บเลื่อนต่อตามปกติ · แถบเส้นใต้เวที = เลื่อนไปกี่ % แล้ว
- ไม่วนรอบ (ลุคแรก → ลุคสุดท้าย) · ‹ › / กดลุคในแถว / ปัด / คีย์บอร์ด = เลื่อนหน้าไปตำแหน่งของลุคนั้น (ปุ่มจางที่ลุคแรก/สุดท้าย)
- ระยะต่อ 1 ลุค: สั้น 45% · ปกติ 65% · ยาว 95% ของความสูงจอ
- เปิดแล้วซ่อน "เดินลุคเอง" (สองอย่างแย่งกันเปลี่ยนลุค)
- มือถือ: เวทีย่อให้เวที + แถวการ์ด พอดีจอเดียว · การ์ดเล็กลง (34%) · เปลี่ยนลุคแล้วแถวการ์ดกลับการ์ดแรก
- ลุคที่เท่าไร = วัดจากขอบบน Section (ไม่ใช่ตำแหน่งเวที) — หัวเว็บโผล่/ซ่อนตอนเลื่อน ลุคไม่สะดุ้ง

## ลูกค้าเห็น

- เปลี่ยนลุค: ‹ › · กดลุคในแถว · ปัดซ้าย-ขวา · ปุ่มลูกศรคีย์บอร์ด · เดินเอง (หยุดเมื่อชี้/แตะ/เปิดการ์ด) · ลุคสุดท้าย → วนกลับลุคแรก
- ถัดไป = ตัวหน้าเดินออก แถวด้านหลังขยับขึ้นมา (แถวด้านหลัง = ลุคที่กำลังจะมา)
- มือถือ: เวทีสูง ≤ 72% ของจอ · การ์ดสินค้าเลื่อนข้างใต้เวที · "Shop the look" = แผ่นเลื่อนขึ้นจากล่าง (ของกลาง CanvasShopPop)
- ตั้งเครื่อง "ลดการเคลื่อนไหว" = เปลี่ยนลุคแบบจางเฉย ๆ

## ข้อจำกัด

- รูปกว้างอัตโนมัติตามความสูง → ลุคหน้า/แถว/ถัดไป/ก่อนหน้า โหลดทันที (lazy ไม่ทำงานกับรูปกว้าง 0) · ลุคที่เหลือโหลดเมื่อขยับเข้าใกล้
- โหมดเลื่อนจอ: เวทีค้างด้วย `position: sticky` → ห้ามใส่ `overflow` ให้ตัวห่อชั้นนอกของ Section (sticky ตายเงียบ)
- โหมดเลื่อนจอทำให้ Section ยาวขึ้นตามจำนวนลุค (6 ลุค ปกติ ≈ 3.6 เท่าความสูงจอ) — ลุคเยอะ ๆ ควรเลือกระยะ "สั้น"
- ปุ่ม ♡ โชว์เมื่อร้านเปิดรายการโปรด
