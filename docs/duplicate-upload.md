# ตรวจรูปซ้ำก่อนอัปโหลด (ของกลาง)

ไฟล์: `components/duplicate-upload/index.tsx` · API: `POST /api/assets/find-duplicates`
ใช้จริงที่: หน้าตั้งค่าสินค้าเว็บ → "SKU ในรุ่นนี้" (ปุ่ม อัปโหลด + ลากรูปมาวางที่แถวสี / รูปบนเว็บ / แบนเนอร์)

## ใช้ทำอะไร
ก่อนส่งรูปขึ้นที่เก็บไฟล์ ระบบเช็กว่า "รูปนี้มีในคลังกลางอยู่แล้วไหม" — ถ้ามี ถามผู้ใช้ว่า **ใช้รูปเดิม** หรือ **อัปโหลดใหม่**
ใช้รูปเดิม = ไม่ส่งไฟล์ซ้ำ ไม่กินพื้นที่ (เดิม `/api/admin/upload` เก็บไฟล์ลง R2 ก่อนแล้วค่อยกันซ้ำแค่แถวในคลัง → ไฟล์ซ้ำยังกินพื้นที่)

- ซ้ำ 1 รูป → ป๊อปเทียบรูปใหม่กับรูปเดิมแบบเต็ม (ชื่อ / ขนาด / อัปเมื่อ / โดย / แท็ก / ใช้อยู่ที่ไหน)
- ซ้ำหลายรูป → ป๊อปสรุปทุกรูป เลือกรายรูป หรือ "ใช้รูปเดิมทั้งหมดที่ซ้ำ" / "อัปใหม่ทั้งหมด" + บอกว่าประหยัดได้กี่ KB
- รูปที่อยู่ในช่องนี้แล้ว (`existingKeys`) → เสนอ "ข้าม"
- ไม่ซ้ำเลย → อัปทันที ไม่ถาม · ตรวจไม่สำเร็จ (เน็ต/คลังมีปัญหา) → อัปตามปกติ ไม่ขวางงาน

## วิธีใช้
```ts
import { uploadImagesWithDupCheck } from "@/components/duplicate-upload";

const r = await uploadImagesWithDupCheck(files, {
  folder: "storefront-products", max: 2000,      // เหมือน uploadResizedImage
  target: "แถวสี TTM002 · แทน",                    // บอกผู้ใช้ว่ากำลังอัปเข้าที่ไหน
  existingKeys: currentKeys,                       // r2_key ที่อยู่ในช่องนี้แล้ว
  onError: (f, e) => toast.error(`อัปโหลด ${f.name} ไม่สำเร็จ: ${e.message}`),
});
if (!r) return;               // กดยกเลิก → ไม่อัปอะไร
add(r.keys);                  // key รูปเดิม + รูปใหม่ เรียงตามไฟล์ที่เลือก · r.uploaded / r.reused / r.skipped
```
ช่องที่อัปไฟล์เองแบบอื่น (ไม่ย่อด้วย canvas) ใช้ `askDuplicateUploads([{ file, original? }], opts)` → ได้แผนต่อไฟล์ (`reuse` = รูปเดิมในคลัง · `null` = อัปใหม่ · ไฟล์ที่ข้ามไม่อยู่ในผล · `null` ทั้งก้อน = ยกเลิก)

## ตรวจซ้ำแบบไหน
ลายนิ้วมือไฟล์ (sha256) คำนวณในเบราว์เซอร์ ทั้ง **ไฟล์หลังย่อ** และ **ไฟล์ต้นฉบับ** แล้วเทียบกับ `assets.checksum` (มี index)
= จับ "ไฟล์เดียวกันทุกจุด" เท่านั้น — รูปเดียวกันที่เซฟใหม่/ย่อคนละขนาด/มาจาก Odoo จะไม่ถูกจับ (ต่อยอดได้ด้วยลายนิ้วมือหน้าตารูป)
**ห้ามกันซ้ำด้วยชื่อไฟล์** — รูปเว็บชื่อ 1.jpg … 5.jpg ซ้ำกันเป็นร้อยรูป (คนละรูป)

## ข้อควรรู้
- "ใช้รูปเดิม" = หลายที่ใช้ไฟล์ R2 ตัวเดียวกัน (เหมือนเลือกจากคลัง) → ห้ามลบไฟล์ R2 ตอนเอารูปออกจากช่อง
- สิทธิ์ API = `files.upload` (เท่าการอัปโหลด) · อ่านอย่างเดียว ไม่เขียน audit
- ป๊อปอยู่บน root แยก (mountDialog) → ข้อความใช้ `tr()` · ไอคอน `<Icon>`
- "ใช้อยู่ที่ไหน" = `asset_usages` + รูปเว็บร้าน (store_listings: รูปบนเว็บ/รูปรายสี — ค้นเฉพาะตอนเจอรูปซ้ำจากโฟลเดอร์เว็บ)
