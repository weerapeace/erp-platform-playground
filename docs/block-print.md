# 🧱 บล็อกพิมพ์ (Block Print)

เปิดไฟล์ `.ai` → เลือกชิ้นเวกเตอร์ → ตั้งขนาดจริง → ส่งออก PDF (ลาย + เส้นบอกขนาดเท่านั้น) ส่งโรงงานทำบล็อก

- หน้า: `/master/block-print` (รายการงาน) · `/master/block-print/<id>` (หน้าทำงาน) · `/master/block-print/symbols` (คลังสัญลักษณ์)
- เมนู: แอปออกแบบ + แอปผลิต หมวด "🎨 ออกแบบสินค้า"
- เจ้าของขอ 2026-11-24 · ดู widget 3 รอบ · แบบที่เลือก: ทุกชิ้นหน้าเดียว · กระดาษ A4 (เลือก A3 ได้)

## ใช้ทำอะไร

| ขั้น | ผู้ใช้ทำ | ระบบทำ |
|---|---|---|
| 1 เปิดไฟล์ | กด "เปิดไฟล์ .ai" | อ่านไฟล์ในเบราว์เซอร์ แยกเส้นที่เติมสีเป็นเส้นเดี่ยว (1 compound path = 1 เส้น เช่น g ทั้งตัว) · เส้นขอบ/เส้นไกด์ ตัวหนังสือที่ยังไม่แปลงเป็นเส้น รูปภาพ พื้นขาว → ไม่นำเข้า แล้วแจ้งให้รู้ |
| 2 เลือกชิ้น (จัดกลุ่ม) | ดูภาพตามตำแหน่งในไฟล์ · คลิก/แตะ/ลากกรอบเลือก · รวมเป็น 1 ชิ้น · แยกออก · ไม่เอา/เอากลับ · ปรับระยะรวม | จัดกลุ่มให้ก่อน: เส้นที่ทับกัน / ห่างไม่เกิน 0.2 มม. = ชิ้นเดียว · ซ่อนเศษเล็ก (< 0.3 มม.) + เส้นกรอบยาวบาง · กด "ต่อไป" = ใช้ + บันทึกให้เลย |
| 3 ตั้งขนาด | พิมพ์กว้าง/สูง (ซม./มม.) · ล็อกสัดส่วน · ให้ทุกชิ้นสูงเท่ากัน · กลับขนาดเดิม · รวมชิ้น | คำนวณอีกด้านตามสัดส่วนเดิมในไฟล์ |
| 4 ส่งออก | กด "ส่งออก PDF" · "SVG ชิ้นนี้" · "SVG ทุกชิ้นที่ติ๊ก (zip)" | สร้าง PDF/SVG ขนาดจริง 1:1 ในเบราว์เซอร์ + จดประวัติการส่งออก |
| 5 จัดวางในบล็อก (แท็บ) | ตั้งขนาดบล็อก · วางชิ้นจากไฟล์ / ข้อความ / สี่เหลี่ยม / วงกลม / เส้นตรง · ลาก/พิมพ์ตำแหน่ง · จัดแนว · กระจาย · ทำซ้ำเป็นแถว | PDF บล็อก = กรอบ + ลายดำล้วน + ขนาดบล็อก + ระยะตำแหน่งนับจากขอบ (เส้นไกด์ชมพู) · SVG ทั้งบล็อก/รายชิ้น |

## ข้อมูล

ตาราง `block_print_jobs` (RLS เปิด ไม่มี policy = เข้าผ่าน API เท่านั้น)

- `code` ออกเลขเองจาก sequence `BLK-0001`
- `pieces` jsonb = `[{id, name, d, fill, ow, oh, w, h, ax, ay, on}]`
  - `d` = เส้นแบบ pdf.js DrawOPS หน่วย มม. แกน y ชี้ลง: `0 x y` เริ่มเส้น · `1 x y` เส้นตรง · `2 x1 y1 x2 y2 x y` โค้ง · `4` ปิดเส้น · เลื่อนให้มุมซ้ายบนอยู่ 0,0
  - `ow/oh` ขนาดเดิมในไฟล์ · `w/h` ขนาดที่ตั้ง · `ax/ay` ตำแหน่งเดิมในไฟล์ (ใช้เรียงชิ้น + รวมชิ้น) · `on` ส่งออกไหม
  - `parts` (ชิ้นที่รวมจากหลายเส้น) = เส้นเดิมทีละเส้น `[{id, name, d, fill, ow, oh, ax, ay}]` → "แยกออก" คืนได้ และวาดทีละเส้นด้วยวิธีเติมสีของเส้นนั้น (รูในตัวอักษรไม่ถูกถม) · ส่งขึ้น API ไม่ต้องส่ง `d` (เซิร์ฟเวอร์สร้างเส้นรวมใหม่จาก parts เอง)
  - `kind` = `background` (พื้นหลังเต็มอาร์ตบอร์ด) · `dust` (เศษเล็ก) · `frame` (เส้นกรอบ) — แยกไว้ ไม่ติ๊ก
- `layouts` jsonb (แท็บจัดวางในบล็อก) = `[{id, name, w, h, items}]` · item = `{id, t: piece|text|rect|ellipse|line, x, y, w, h, pieceId?, text?, font?, weight?, d?, dw?, dh?, color, fill, stroke, strokeColor, flip?}` — ตำแหน่ง มม. จากมุมซ้ายบนของบล็อก · ข้อความเก็บเส้นที่แปลงแล้ว (`d` ขนาด dw×dh) → PDF/SVG ไม่ต้องมีฟอนต์ · ชิ้นจากไฟล์อ้าง `pieceId` (จัดกลุ่มใหม่แล้วชิ้นหาย = เตือน + ไม่ออก PDF)
- `piece_count` / `piece_on` = คอลัมน์คำนวณเอง (หน้ารายการไม่ต้องดึงเส้นทั้งก้อน)
- ทำไมไม่ใช้รูปทรงของสตูดิโอแพทเทิร์น (`lib/pattern-shape`): ของนั้น 1 ชิ้น = เส้นรอบนอก 1 วง + รู แต่ตัวอักษร/โลโก้มีหลายวงในชิ้นเดียว

## หน้าเลือกชิ้น (จัดกลุ่ม) — เพิ่ม 2026-11-24 รอบ 1.1

ทำไม: ใน Illustrator ตัวอักษร/ลาย 1 ตัวอาจประกอบจากหลายเส้นที่ไม่ได้รวมกัน (i กับจุด · ดอกไม้ 9 กลีบ · หน้ายิ้ม) → ระบบเดิมอ่านเป็นคนละชิ้น

- สูตร: `autoGroup` (lib/block-print) — ทับ/ชนกัน หรือห่างไม่เกิน `gap` มม. = ชิ้นเดียว · `applyGrouping` แปลงกลุ่มกลับเป็นชิ้น (กลุ่มที่ไม่เปลี่ยน = ชิ้นเดิม ขนาด/ชื่อที่ตั้งไว้ไม่หาย)
- **ค่าเริ่มต้น 0.2 มม.** (เจ้าของเลือก 1.5 มม. ใน widget แต่ไฟล์จริง final 2 วางลายห่างกันแค่ 0.25-0.33 มม. ส่วนกลีบดอกห่างแกนกลาง ~0.12 มม. → 1.5 มม. รวมลายทั้งแถวเป็นชิ้นเดียว) · ปรับได้ 0-5 มม.
- ชิ้นพื้นใหญ่ที่ชนเส้นเล็กตั้งแต่ 3 เส้น (เล็กกว่า 10 เท่า เช่น แถบสายเข็มขัด เส้นคั่น กรอบรอบงาน) = ไม่รวมกับใคร (กันทั้งแถวถูกดูดเป็นชิ้นเดียว) · บนจอวาดเป็นสีเทาอ่อนอยู่หลังสุด เลือกจากรายการด้านขวา
- ซูมอัตโนมัติให้ชิ้นทั่วไปใหญ่พอคลิก · ปุ่ม − / + / พอดีจอ · ปุ่ม "เลือกทุกชิ้นที่ติ๊ก" (ลายต่อเนื่องทั้งแผ่น → รวมเป็นบล็อกเดียว · มือถือลากกรอบไม่ได้)
- ทางเข้า: เปิดไฟล์ใหม่ (`?step=group`) · ปุ่ม "จัดกลุ่มชิ้นใหม่" ในหน้าตั้งขนาด

## จัดวางในบล็อก — เพิ่ม 2026-11-24 รอบ 1.2 (เจ้าของเลือกข้อเสนอ 1-6)

- **สีใช้แยกส่วนบนจอเท่านั้น** — PDF/SVG ส่งโรงงานเป็นสีดำล้วนเสมอ (เจ้าของเลือก) · "ความหนา" = ความหนาเส้นขอบ/เส้นตรง (ยังไม่มีทำลายหนาขึ้นทั้งตัว)
- PDF บล็อก: กรอบบล็อกเทา · ลายดำ · เส้นไกด์ชมพูที่ขอบซ้าย/ขวาของทุกชิ้น + ตัวเลขระยะจากขอบซ้าย (หมุนตั้งด้านบน) · ระยะจากขอบบนด้านซ้าย · ขนาดบล็อก กว้างล่าง/สูงขวา · ตัวเลขชิดกันขยับขึ้นชั้นถัดไป · ใหญ่เกินกระดาษ = เตือน ไม่ย่อ
- ฟอนต์: 14 ตัวจาก Google Fonts (ไทย 9) · อัปโหลด .ttf/.otf/.woff/.woff2 ได้ แต่จำไว้แค่ตอนเปิดหน้า (เส้นที่แปลงแล้วไม่หาย · แก้ข้อความต้องอัปโหลดใหม่) · ฟอนต์ไม่มีตัวอักษรที่พิมพ์ = แจ้ง
- ย้าย: ลาก (ทีละ 0.1 มม. ดูดขอบ/กึ่งกลางบล็อกในระยะ 0.6 มม.) · ลูกศร 0.1 มม. (Shift 1 มม.) · พิมพ์ X/Y · ยังหมุนชิ้นไม่ได้

## เพิ่มไฟล์ + คลังสัญลักษณ์ + ปรับขนาด/ซูม — รอบ 1.3 (เจ้าของเลือกข้อเสนอ 1-6)

- **เพิ่มไฟล์เข้างานเดิม:** ปุ่ม "เพิ่มไฟล์" หรือลากไฟล์ .ai/.pdf/.svg มาวางตรงไหนของหน้างานก็ได้ → จัดกลุ่มให้ก่อน → ชิ้นใหม่ต่อท้ายทางขวาของชิ้นเดิม (รหัสใหม่ไม่ชน · `appendOffset`/`shiftPiece`) → หน้าเลือกชิ้น · ชิ้นเดิม/ขนาดที่ตั้งไว้ไม่เปลี่ยน · Ctrl+Z ย้อนได้
- **คลังสัญลักษณ์** (`block_print_symbols`): เก็บเป็นเส้นในฐานข้อมูล (ไม่เก็บไฟล์รูป) · รูปตัวอย่าง/SVG วาดจากเส้น · บันทึกจากชิ้นที่เลือก ("บันทึกเข้าคลัง") · หน้าคลัง: ค้นหา/หมวด · เลือกหลายตัว → ดาวน์โหลด SVG (zip) / แก้ชื่อ-หมวด-ขนาดที่ใช้บ่อย / ถังขยะ · ลากไฟล์ใส่คลัง → หน้าเลือกชิ้น → ตั้งชื่อ+หมวด → บันทึก
- **เลือกจากคลัง:** หน้าตั้งขนาด "เพิ่มจากคลัง" (เป็นชิ้นในงาน) · หน้าจัดวาง "ชิ้นจากคลัง" (ชิ้นชนิด `vector` เก็บเส้นในบล็อกเลย)
- **กล่องปรับขนาด:** จุดจับ 4 มุม + 4 ด้าน (กดได้ 22 จุดบนจอ) · มุม = ล็อกสัดส่วน · Shift = ยืดอิสระ · โชว์ขนาดสด
- **ซูม:** Ctrl+ล้อเมาส์ (ซูมตรงจุดที่ชี้) · ปุ่ม 25%–800% · พอดีจอ · ถ่าง 2 นิ้ว · ตัวเลขระยะบนจอไม่ใหญ่ตามตอนซูม
- **แก้อาการกระตุก:** กรอบภาพหน้าจัดวางคิดจากบล็อกที่บันทึกแล้วและขยายได้อย่างเดียว (เดิมคิดใหม่ทุกครั้งที่ลาก ภาพเลยขยับตาม)
- ไฟล์ SVG ที่มีชิ้นเดียวพอดีกรอบ ไม่ถูกนับเป็น "พื้นหลัง" แล้ว

## แก้ไข · ย้อนกลับ · ลบ

- แก้ได้ทุกช่อง: ชื่องาน ชื่อชิ้น ขนาด ติ๊กส่งออก กระดาษ หน่วย · มีปุ่มกลับเป็นขนาดเดิมในไฟล์
- ย้อนกลับ/ทำซ้ำในหน้า: Ctrl+Z · Ctrl+Shift+Z / Ctrl+Y (100 ขั้น) · รวมชิ้นแล้วมีปุ่ม "ย้อนกลับ" ในแจ้งผล
- จัดวางในบล็อก: ทุกการแก้อยู่ในประวัติย้อนกลับเดียวกับหน้าตั้งขนาด (Ctrl+Z/Y) · ลบชิ้น/ลบบล็อก มีปุ่ม "ย้อนกลับ" ในแจ้งผล · ลบชิ้นในบล็อกไม่กระทบชิ้นต้นฉบับจากไฟล์
- หน้าเลือกชิ้น: ย้อนกลับ/ทำซ้ำของตัวเอง (ปุ่ม + Ctrl+Z/Y) · ชิ้นที่รวมแล้ว "แยกออก" คืนเป็นเส้นเดิมได้เสมอ · "ไม่เอา" = ยังอยู่ ติ๊กกลับได้ · กดกลับโดยไม่ใช้ = ถามก่อน · จัดกลุ่มเสร็จแล้วยังกด Ctrl+Z ในหน้าตั้งขนาดย้อนทั้งชุดได้
- ลบงาน = ย้ายเข้าถังขยะ (ย้อนกลับได้จากแจ้งผล) · ถังขยะ: กู้คืน / ลบถาวร (พิมพ์รหัสงานยืนยัน · API ยอมลบถาวรเฉพาะงานในถังขยะ)
- ออกจากหน้าตอนยังไม่บันทึก = เบราว์เซอร์ถามก่อน

## ข้อจำกัดที่รู้

- ไฟล์ `.ai` ต้องบันทึกแบบติ๊ก "Create PDF Compatible File" (ค่าเริ่มของ Illustrator) — ไม่ติ๊ก = ข้างในเป็น PostScript อ่านไม่ได้ ระบบแจ้งให้บันทึกใหม่
- นำเข้าเฉพาะอาร์ตบอร์ดแรก
- ตัวหนังสือที่ยังไม่ Create Outlines ยังไม่นำเข้า (รอบ 2 จะแปลงให้)
- PDF ใส่ทุกชิ้นในหน้าเดียว — ใส่ไม่พอ = แจ้งเตือน ไม่ย่อลายเองเด็ดขาด
- จุดเส้นรวมไม่เกิน 300,000 ตัวเลข / 500 ชิ้นต่องาน

## รอบถัดไป (ตกลงกับเจ้าของแล้ว)

- รอบ 2: ตัวตรวจเส้นบาง/ช่องแคบเมื่อย่อ (ค่าตั้งต้น 0.4 มม.) · แปลงตัวหนังสือในไฟล์เป็นเส้น
- รอบ 3: เก็บ .ai ต้นฉบับ + PDF ขึ้น Google Drive (กฎไฟล์งานพิมพ์ `lib/print-file-policy.ts`) · SVG ทีละชิ้นเข้าคลังสัญลักษณ์ · ผูก SKU · ประวัติเวอร์ชัน
