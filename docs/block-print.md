# 🧱 บล็อกพิมพ์ (Block Print)

เปิดไฟล์ `.ai` → เลือกชิ้นเวกเตอร์ → ตั้งขนาดจริง → ส่งออก PDF (ลาย + เส้นบอกขนาดเท่านั้น) ส่งโรงงานทำบล็อก

- หน้า: `/master/block-print` (รายการงาน) · `/master/block-print/<id>` (หน้าทำงาน)
- เมนู: แอปออกแบบ + แอปผลิต หมวด "🎨 ออกแบบสินค้า"
- เจ้าของขอ 2026-11-24 · ดู widget 3 รอบ · แบบที่เลือก: ทุกชิ้นหน้าเดียว · กระดาษ A4 (เลือก A3 ได้)

## ใช้ทำอะไร

| ขั้น | ผู้ใช้ทำ | ระบบทำ |
|---|---|---|
| 1 เปิดไฟล์ | กด "เปิดไฟล์ .ai" | อ่านไฟล์ในเบราว์เซอร์ แยกเส้นที่เติมสีเป็นชิ้น (1 compound path = 1 ชิ้น เช่น g ทั้งตัว) |
| 2 เลือกชิ้น | ติ๊กชิ้นที่จะส่ง · Shift/Ctrl+คลิก เลือกหลายชิ้น | เส้นขอบ/เส้นไกด์ ตัวหนังสือที่ยังไม่แปลงเป็นเส้น รูปภาพ พื้นขาว → ไม่นำเข้า แล้วแจ้งให้รู้ |
| 3 ตั้งขนาด | พิมพ์กว้าง/สูง (ซม./มม.) · ล็อกสัดส่วน · ให้ทุกชิ้นสูงเท่ากัน · กลับขนาดเดิม · รวมชิ้น | คำนวณอีกด้านตามสัดส่วนเดิมในไฟล์ |
| 4 ส่งออก | กด "ส่งออก PDF" | สร้าง PDF ขนาดจริง 1:1 ในเบราว์เซอร์ + จดประวัติการส่งออก |

## ข้อมูล

ตาราง `block_print_jobs` (RLS เปิด ไม่มี policy = เข้าผ่าน API เท่านั้น)

- `code` ออกเลขเองจาก sequence `BLK-0001`
- `pieces` jsonb = `[{id, name, d, fill, ow, oh, w, h, ax, ay, on}]`
  - `d` = เส้นแบบ pdf.js DrawOPS หน่วย มม. แกน y ชี้ลง: `0 x y` เริ่มเส้น · `1 x y` เส้นตรง · `2 x1 y1 x2 y2 x y` โค้ง · `4` ปิดเส้น · เลื่อนให้มุมซ้ายบนอยู่ 0,0
  - `ow/oh` ขนาดเดิมในไฟล์ · `w/h` ขนาดที่ตั้ง · `ax/ay` ตำแหน่งเดิมในไฟล์ (ใช้เรียงชิ้น + รวมชิ้น) · `on` ส่งออกไหม
- `piece_count` / `piece_on` = คอลัมน์คำนวณเอง (หน้ารายการไม่ต้องดึงเส้นทั้งก้อน)
- ทำไมไม่ใช้รูปทรงของสตูดิโอแพทเทิร์น (`lib/pattern-shape`): ของนั้น 1 ชิ้น = เส้นรอบนอก 1 วง + รู แต่ตัวอักษร/โลโก้มีหลายวงในชิ้นเดียว

## สิทธิ์ / ประวัติ

- `block_print.view` ดู + ดาวน์โหลด PDF · `block_print.edit` เปิดไฟล์ สร้าง แก้ ลบ (staff/manager/admin ได้ทั้งคู่ตอนเริ่ม)
- audit ทุกการเขียน: create · update (ชื่อ/หน่วย/กระดาษ + รายชิ้น "ชื่อ · กว้าง×สูง มม." จาก → เป็น) · archive · restore · delete (ถาวร) · export

## แก้ไข · ย้อนกลับ · ลบ

- แก้ได้ทุกช่อง: ชื่องาน ชื่อชิ้น ขนาด ติ๊กส่งออก กระดาษ หน่วย · มีปุ่มกลับเป็นขนาดเดิมในไฟล์
- ย้อนกลับ/ทำซ้ำในหน้า: Ctrl+Z · Ctrl+Shift+Z / Ctrl+Y (100 ขั้น) · รวมชิ้นแล้วมีปุ่ม "ย้อนกลับ" ในแจ้งผล
- ลบงาน = ย้ายเข้าถังขยะ (ย้อนกลับได้จากแจ้งผล) · ถังขยะ: กู้คืน / ลบถาวร (พิมพ์รหัสงานยืนยัน · API ยอมลบถาวรเฉพาะงานในถังขยะ)
- ออกจากหน้าตอนยังไม่บันทึก = เบราว์เซอร์ถามก่อน

## ข้อจำกัดที่รู้

- ไฟล์ `.ai` ต้องบันทึกแบบติ๊ก "Create PDF Compatible File" (ค่าเริ่มของ Illustrator) — ไม่ติ๊ก = ข้างในเป็น PostScript อ่านไม่ได้ ระบบแจ้งให้บันทึกใหม่
- นำเข้าเฉพาะอาร์ตบอร์ดแรก
- ตัวหนังสือที่ยังไม่ Create Outlines ยังไม่นำเข้า (รอบ 2 จะแปลงให้)
- PDF ใส่ทุกชิ้นในหน้าเดียว — ใส่ไม่พอ = แจ้งเตือน ไม่ย่อลายเองเด็ดขาด
- จุดเส้นรวมไม่เกิน 300,000 ตัวเลข / 500 ชิ้นต่องาน
