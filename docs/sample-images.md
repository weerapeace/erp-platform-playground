# SAMPLE Images (`/tasks/samples`)

> อัลบั้มรูปตัวอย่าง (Sample) **ประจำแบรนด์** — เลือกรูปส่งเข้าใบงานใน Design Dashboard ได้
> ทางเข้า: เมนู **SAMPLE Images** ในแอป "จัดการงาน" (หมวด 📋 จัดการงาน ต่อจาก Design Dashboard) + ปุ่มทางลัดบนหน้าแรก · เพิ่มเมื่อ 2026-11-13 (เจ้าของขอจากแผนผังการเก็บไฟล์: Sample Photoshoot → แปลง JPEG → R2 → Design Dashboard)
> โค้ด: หน้า `app/tasks/samples/page.tsx` → `components/sample-images` (UI + `api.ts`) · ตรรกะล้วน + เทสต์ `lib/sample-images.ts` · API `app/api/sample-images/route.ts`

## ทำอะไรได้

1. **แถบแบรนด์** ด้านบน: ทุกแบรนด์ · ทุกแบรนด์ที่เปิดใช้ (แบรนด์ของเราขึ้นก่อน แล้วค่อยแบรนด์ที่ติ๊ก "งานลูกค้า" เช่น Good Goods) · ไม่ระบุแบรนด์ (โผล่เมื่อมีอัลบั้มแบบนั้น) — ตัวเลข = จำนวนรูปของแบรนด์ · จำแท็บที่เลือกต่อคน (`user-prefs sample_images_brand`)
2. **หน้าแฟ้ม** = การ์ดอัลบั้มของแบรนด์นั้น เรียงวันที่ลง (1 แบรนด์ 1 วัน = 1 อัลบั้ม ชื่อ `SAMPLE Good Goods 13 พ.ย. 2569` เวลาไทย) · ปกรวมรูปด้วยของกลาง `AlbumCover` แบบ C (docs/album-cover.md — 1 รูปเต็ม · 2 ซ้ายขวา · 3 ใหญ่+2 เล็ก · 4+ ใหญ่+3 เล็ก +N) · บนการ์ด: วันที่ · แบรนด์ · จำนวนรูป · ป้าย "ส่งเข้าใบงาน N" · กดการ์ด = เปิดอัลบั้ม · ปุ่ม "← อัลบั้มทั้งหมด" = กลับ (เพิ่ม 2026-11-14 — เจ้าของอยากให้ "เป็นเหมือน folder")
3. **ลงรูป** — ลากมาวางทีละหลายรูป (ทั้งโฟลเดอร์ก็ได้) หรือกด "เลือกรูป" **ทันที (ไม่มีขั้นรอ)**: **เปิดอัลบั้มอยู่ = เพิ่มเข้าอัลบั้มนั้น** (เหมือนวางลงแฟ้ม · เจ้าของเลือก 2026-11-14) · อยู่หน้าแฟ้ม = อัลบั้มของแบรนด์ + วันนี้
   - อยู่แท็บแบรนด์ = แบรนด์นั้น · แท็บ "ทุกแบรนด์" = ปุ่ม "ลงเข้าแบรนด์" ในกรอบวางรูป (เลือกก่อนวาง · จำแบรนด์ล่าสุด `sample_images_last_brand`) · แท็บ "ไม่ระบุแบรนด์" = อัลบั้มไม่ระบุแบรนด์
   - ย่อด้านยาวไม่เกิน **2,400px** + แปลงเป็น **JPEG** ทุกไฟล์ (`prepareResizedImage(file, 2400, { jpeg: true })` · พื้นโปร่งเป็นขาว · HEIC จาก iPhone แปลงได้)
   - RAW จากกล้อง (CR2/NEF/ARW…) / PSD / AI / TIFF = ข้าม + แจ้ง · ระหว่างลง: แถบ `UploadProgress` (รูป 3/20 · ปุ่มหยุด)
4. **ไม่มีระบบ "รอย้าย"** (เจ้าของสั่ง 2026-11-13 "ไม่ต้องทำเป็นรอ") — รูปอยู่ในอัลบั้มตลอด · รูปที่ส่งเข้าใบงานแล้วมีป้าย `→ DS-xxxx` (กดเปิดใบงาน)
5. เลือกรูป → **ส่งไป Design Dashboard** → ตัวเลือกใบงานกลาง `DesignSheetPickerModal` **เปิดมากรองแบรนด์ของอัลบั้มไว้ให้** (`initialBrand` · กด "ทุกแบรนด์" ดูใบอื่นได้) → รูปไปอยู่ช่องรูปของใบงาน
   - 1 รูปส่งเข้าได้หลายใบงาน · ส่งซ้ำใบเดิม = ข้าม (`photosToMove`)
6. **ลบ** = ไปถังขยะของอัลบั้ม (ปุ่ม "ถังขยะ (N)" โผล่เมื่อมีรูปในถัง · เอากลับได้) · รูปที่อยู่ในใบงานหรือใช้อยู่ที่อื่น ระบบไม่ยอมลบ
7. อัลบั้มที่ลงก่อนมีระบบแบรนด์ (ไม่ระบุแบรนด์) → ปุ่ม **ย้ายอัลบั้มเข้าแบรนด์** · ป้าย "แนะนำ" = แบรนด์ของใบงานที่รูปถูกส่งไป (ทุกใบเป็นแบรนด์เดียวกัน — `inferAlbumBrand`) · แบรนด์นั้นมีอัลบั้มวันเดียวกันแล้ว = รวมรูปเข้าด้วยกัน

## เก็บที่ไหน (ไม่มีตารางใหม่)

| ส่วน | เก็บที่ |
|---|---|
| ไฟล์รูป | R2 ผ่านคลังไฟล์กลาง — `POST /api/assets` (`source = "sample"` · `brand_id` = แบรนด์ของอัลบั้ม) · ไฟล์เดียวกันเป๊ะที่เคยลงแล้ว = ใช้แถวเดิม ไม่อัปซ้ำ |
| ปกการ์ด | รูปแรก ๆ ที่ไม่อยู่ถังขยะ (เรียงเวลาลง สูงสุด 4) — `albumPreviewKeys` · ส่งมากับ GET (`preview_keys`) |
| อัลบั้ม | `asset_collections` · `description = "sample-images"` (ไม่ระบุแบรนด์) หรือ `"sample-images:<brand_id>"` (`sampleAlbumMark` / `parseSampleMark`) + `asset_collection_map` — โผล่ในคลังไฟล์กลางด้วย |
| ส่งเข้าใบงาน | `POST /api/attachments/from-library` → แถวไฟล์แนบของใบงานชี้ไฟล์เดิม (ไม่ก๊อป) + `asset_usages` (กันลบไฟล์ที่ใช้อยู่) |
| ถังขยะ | `assets.status = trashed` (`DELETE /api/assets/[id]`) · เอากลับ `PATCH {restore:true}` |
| ย้ายอัลบั้มเข้าแบรนด์ | `POST /api/sample-images {action:"set_brand"}` — แก้ป้าย+ชื่ออัลบั้ม หรือรวมเข้าอัลบั้มแบรนด์+วันเดียวกัน · เติม `assets.brand_id` ที่ยังว่าง |

ป้าย `→ DS-xxxx` คิดสดจากไฟล์แนบจริงของใบงาน (`erp_playground_attachments` entity `design_sheet` · `file_path = r2_key`) — ใบงานเอารูปออก ป้ายหายเอง

## สิทธิ์ / ประวัติ

| ทำอะไร | สิทธิ์ | ประวัติ (audit) |
|---|---|---|
| ดูหน้า | `assets.view` | — |
| ลงรูป / สร้างอัลบั้มของวัน | `assets.upload` | `create asset` · `create asset_collection` (มี brand_id) |
| ส่งเข้าใบงาน | `attachments.upload` (ตรวจใน DB) + `assets.view` — ไม่มีสิทธิ์ = ไม่เห็นปุ่ม | `attach` ที่ใบงาน (จาก DB) |
| ลบ (ถังขยะ) | `assets.delete` (ตอนทำ: admin · manager) | `delete asset` |
| เอากลับ / ย้ายอัลบั้มเข้าแบรนด์ | `assets.edit` | `restore asset` · `update asset_collection` (set_brand) |

- เมนู: แอปจัดการงาน หมวด "📋 จัดการงาน" ต่อจาก Design Dashboard (erp_menu_items · สิทธิ์เมนู `assets.view`) · สิทธิ์ตามเมนู = `lib/menu-permissions` กฎ `/tasks/samples` (assets.* + attachments.upload)

## ข้อจำกัด

- รายการอัลบั้มโชว์ 100 อัลบั้มล่าสุด
- หน้าเว็บเขียนไฟล์ลงโฟลเดอร์ในเครื่อง/NAS (`Z:\Work In Process\SAMPLE`) ไม่ได้ — ไฟล์ตรงนั้นอยู่เหมือนเดิม หน้านี้เก็บสำเนา JPEG ไว้ใช้ในระบบ
