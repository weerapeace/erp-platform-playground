# SAMPLE Images (`/tasks/samples`)

> อัลบั้มรูปตัวอย่าง (Sample) **ประจำแบรนด์** — เลือกรูปส่งเข้าใบงานใน Design Dashboard ได้
> ทางเข้า: เมนู **SAMPLE Images** ในแอป "จัดการงาน" (หมวด 📋 จัดการงาน ต่อจาก Design Dashboard) + ปุ่มทางลัดบนหน้าแรก · เพิ่มเมื่อ 2026-11-13 (เจ้าของขอจากแผนผังการเก็บไฟล์: Sample Photoshoot → แปลง JPEG → R2 → Design Dashboard)
> โค้ด: หน้า `app/tasks/samples/page.tsx` → `components/sample-images` (UI + `api.ts` · หน้าตาร่วม `parts.tsx` · แท็บในตัวเลือกไฟล์กลาง `picker.tsx`) · ตรรกะล้วน + เทสต์ `lib/sample-images.ts` · API `app/api/sample-images/route.ts`

## ทำอะไรได้

1. **แถบแบรนด์** ด้านบน: ทุกแบรนด์ · ทุกแบรนด์ที่เปิดใช้ (แบรนด์ของเราขึ้นก่อน แล้วค่อยแบรนด์ที่ติ๊ก "งานลูกค้า" เช่น Good Goods) · ไม่ระบุแบรนด์ (โผล่เมื่อมีอัลบั้มแบบนั้น) — ตัวเลข = จำนวนรูปของแบรนด์ · จำแท็บที่เลือกต่อคน (`user-prefs sample_images_brand`)
2. **หน้าแฟ้ม** = การ์ดอัลบั้มของแบรนด์นั้น เรียงวันที่ลง (1 แบรนด์ 1 วัน = 1 อัลบั้ม ชื่อ `SAMPLE Good Goods 13 พ.ย. 2569` เวลาไทย) · ปกรวมรูปด้วยของกลาง `AlbumCover` แบบ C (docs/album-cover.md — 1 รูปเต็ม · 2 ซ้ายขวา · 3 ใหญ่+2 เล็ก · 4+ ใหญ่+3 เล็ก +N) · บนการ์ด: วันที่ · แบรนด์ · จำนวนรูป · ป้าย "ส่งเข้าใบงาน N" · กดการ์ด = เปิดอัลบั้ม · ปุ่ม "← อัลบั้มทั้งหมด" = กลับ (เพิ่ม 2026-11-14 — เจ้าของอยากให้ "เป็นเหมือน folder")
3. **ลงรูป** — ลากมาวางทีละหลายรูป (ทั้งโฟลเดอร์ก็ได้) หรือกด "เลือกรูป" **ทันที (ไม่มีขั้นรอ)**: **เปิดอัลบั้มอยู่ = เพิ่มเข้าอัลบั้มนั้น** (เหมือนวางลงแฟ้ม · เจ้าของเลือก 2026-11-14) · อยู่หน้าแฟ้ม = อัลบั้มของแบรนด์ + วันนี้
   - อยู่แท็บแบรนด์ = แบรนด์นั้น · แท็บ "ทุกแบรนด์" = ปุ่ม "ลงเข้าแบรนด์" ในกรอบวางรูป (เลือกก่อนวาง · จำแบรนด์ล่าสุด `sample_images_last_brand`) · แท็บ "ไม่ระบุแบรนด์" = อัลบั้มไม่ระบุแบรนด์
   - ย่อด้านยาวไม่เกิน **2,400px** + แปลงเป็น **JPEG** ทุกไฟล์ (`prepareResizedImage(file, 2400, { jpeg: true })` · พื้นโปร่งเป็นขาว · HEIC จาก iPhone แปลงได้)
   - RAW จากกล้อง (CR2/NEF/ARW…) / PSD / AI / TIFF = ข้าม + แจ้ง · ระหว่างลง: แถบ `UploadProgress` (รูป 3/20 · ปุ่มหยุด)
4. **ไม่มีระบบ "รอย้าย"** (เจ้าของสั่ง 2026-11-13 "ไม่ต้องทำเป็นรอ") — รูปอยู่ในอัลบั้มตลอด · รูปที่ส่งเข้าใบงานแล้วมีป้าย `→ DS-xxxx` (กดเปิดใบงาน)
4b. **อัลบั้มในอัลบั้ม** (เจ้าของสั่ง 2026-11-14 · ดู widget แล้วอนุมัติ):
   - **ลากรูปไปวางบนอีกรูป** = รวมเป็นอัลบั้มใหม่ (ถามชื่อด้วย askText กลาง) · เลือกหลายรูปแล้วลาก = ไปทั้งชุด
   - **ลากรูปไปวางบนการ์ดอัลบั้มย่อย** = ย้ายเข้า · **วางบนชื่ออัลบั้มในเส้นทางด้านบน** = ย้ายขึ้นไปชั้นนั้น
   - **ลากการ์ดอัลบั้มไปวางบนอีกการ์ด/ชื่อในเส้นทาง** = ย้ายทั้งอัลบั้มเข้าไป (กันวนซ้ำ — ห้ามเข้าตัวเอง/ลูกตัวเอง `canMoveAlbum`)
   - ปุ่มบนแถบเลือกรูป: "สร้างอัลบั้มจากที่เลือก" · "ย้ายไปอัลบั้ม…" (แผงเลือกปลายทาง โชว์เส้นทางเต็ม — ใช้ได้บนมือถือที่ลากไม่สะดวก)
   - ในอัลบั้ม: ปุ่ม "อัลบั้มย่อย" (สร้างเปล่า) · อัลบั้มย่อยมี "เปลี่ยนชื่อ" · "ย้ายอัลบั้มนี้" · "ลบอัลบั้ม (ว่าง)" (ลบได้เฉพาะเมื่อไม่มีรูป/อัลบั้มย่อย)
   - หน้าแฟ้มโชว์เฉพาะอัลบั้มชั้นบนสุด · การ์ดนับรูปรวมอัลบั้มย่อยทุกชั้น + จำนวนอัลบั้มย่อย (`rollupAlbum`) · ปกใช้รูปรวมทุกชั้น
   - ลากภายในหน้าใช้ชนิดข้อมูล `application/x-erp-sample` → ตัวรับไฟล์จากเครื่อง (useFileDrop) ไม่ยุ่ง
5. เลือกรูป → **ส่งไป Design Dashboard** → ตัวเลือกใบงานกลาง `DesignSheetPickerModal` **เปิดมากรองแบรนด์ของอัลบั้มไว้ให้** (`initialBrand` · กด "ทุกแบรนด์" ดูใบอื่นได้) → รูปไปอยู่ช่องรูปของใบงาน
   - 1 รูปส่งเข้าได้หลายใบงาน · ส่งซ้ำใบเดิม = ข้าม (`photosToMove`)
6. **ลบ** = ไปถังขยะของอัลบั้ม (ปุ่ม "ถังขยะ (N)" โผล่เมื่อมีรูปในถัง · เอากลับได้) · รูปที่อยู่ในใบงานหรือใช้อยู่ที่อื่น ระบบไม่ยอมลบ
7. อัลบั้มที่ลงก่อนมีระบบแบรนด์ (ไม่ระบุแบรนด์) → ปุ่ม **ย้ายอัลบั้มเข้าแบรนด์** · ป้าย "แนะนำ" = แบรนด์ของใบงานที่รูปถูกส่งไป (ทุกใบเป็นแบรนด์เดียวกัน — `inferAlbumBrand`) · แบรนด์นั้นมีอัลบั้มวันเดียวกันแล้ว = รวมรูปเข้าด้วยกัน
8. **อัลบั้มที่ตั้งชื่อเอง (ชั้นบนสุด)** — เจ้าของสั่ง 2026-11-15: Louis Batch ส่งรูปแบบ "อัลบั้มใหม่" = สร้างอัลบั้มชั้นบนสุดชื่อตามอัลบั้มในโปรแกรม (เช่น `2026-11-15-002`) ข้าง ๆ อัลบั้มของวัน ไม่ซ้อนข้างใน (`create_top` · แบรนด์+ชื่อซ้ำ = ใช้อันเดิม)
   - แยก **อัลบั้มของวัน** ด้วย `isDayAlbum` = ชั้นบนสุด + ชื่อแบบ `SAMPLE <แบรนด์> <วันที่>` → การ์ดโชว์วันที่ · ชื่อล็อก ลบไม่ได้
   - อัลบั้มอื่นทุกชั้น (ที่ตั้งชื่อเอง / อัลบั้มย่อยที่ย้ายขึ้นมาชั้นบนสุด) = โชว์ชื่อจริง · เปลี่ยนชื่อ · ย้าย · ลบตอนว่างได้ · ย้ายเข้าแบรนด์ = ชื่อเดิม ไม่รวมกับอัลบั้มของวัน
9. **Ctrl (⌘) + หมุนลูกกลิ้ง** บนการ์ดอัลบั้ม (หน้าแฟ้ม · 2–8 ต่อแถว) หรือบนรูปในอัลบั้ม (3–8 ต่อแถว) = ย่อ/ขยาย · จำแยกกัน รายคน (`gallery_cols_sample-albums` / `gallery_cols_sample-images`) — ของกลาง `useGalleryColumns(..., { ctrlWheel: true })` · มือถือการ์ดอัลบั้มคง 1–2 ต่อแถว
10. **ปุ่ม Back ย้อนทีละก้าว** (เบราว์เซอร์ · ปุ่มย้อนของเมาส์ · มือถือ) — เดินมายังไงย้อนกลับทางนั้น: อัลบั้มย่อย → อัลบั้มแม่ → หน้าแฟ้ม แล้วค่อยออกจากหน้า · ปุ่ม "อัลบั้มทั้งหมด" ก็นับเป็นก้าว — ของกลาง `lib/use-step-history` (จดก้าวใน history.state · URL ไม่เปลี่ยน · ปิดลิ้นชัก/ป๊อปด้วย Back ไม่นับ)
11. **เลือกรูป SAMPLE จากตัวเลือกไฟล์กลาง** (เจ้าของสั่ง 2026-11-15 · เลือก "แท็บใหม่" จาก widget) — หน้าต่าง "เลือกไฟล์จากคลังกลาง" (`AssetPicker` · ใช้อยู่ ~19 ช่องรูป เช่น ตัวจัดรูป ใบเสนอ หน้าเว็บร้าน) มีแท็บ **SAMPLE Images** ข้าง "เลือกจากคลัง"
   - หน้าตาเหมือนหน้านี้เป๊ะ — ใช้ชิ้นส่วนร่วม `components/sample-images/parts.tsx` (แถบแบรนด์ · การ์ดอัลบั้ม · เส้นทาง · ช่องรูป) **แก้ที่ parts ทั้งสองที่เปลี่ยนตาม**
   - อัลบั้มล่าสุดก่อน · แบรนด์ที่เลือกจำร่วมกับหน้านี้ (`sample_images_brand`) · เปิดอัลบั้ม → อัลบั้มย่อย + รูป (ไม่โชว์รูปในถังขยะ) · มีลิงก์ "เปิดหน้า SAMPLE Images"
   - **ดู + เลือกอย่างเดียว** (ไม่มีลาก/ย้าย/ลบ/อัปโหลดในหน้าต่างนี้) · ช่องหลายรูป = เลือกข้ามอัลบั้มได้ + ปุ่ม "เลือกทั้งอัลบั้ม" · ช่องรูปเดียว = กดรูปเดียว
   - กด "ใช้รูปที่เลือก" → ดึงแถวคลังตัวจริง `GET /api/assets?ids=…` (ชื่อ/แท็ก/ขนาดครบ) → รูปเดิมในคลัง ไม่อัปซ้ำ · รูปที่ถูกลบระหว่างนั้น = ข้าม + แจ้ง
   - ซ่อนแท็บเมื่อ: ช่องวิดีโอ/เอกสารอย่างเดียว · ล็อกอัลบั้ม (`lockCollectionName`) · ต้องมีโฟลเดอร์ Drive (`requireDriveFolder`)
   - โค้ด `components/sample-images/picker.tsx` โหลดแยกชิ้น (`next/dynamic`) ตอนกดแท็บเท่านั้น

## เก็บที่ไหน (ไม่มีตารางใหม่)

| ส่วน | เก็บที่ |
|---|---|
| ไฟล์รูป | R2 ผ่านคลังไฟล์กลาง — `POST /api/assets` (`source = "sample"` · `brand_id` = แบรนด์ของอัลบั้ม) · ไฟล์เดียวกันเป๊ะที่เคยลงแล้ว = ใช้แถวเดิม ไม่อัปซ้ำ |
| ปกการ์ด | รูปแรก ๆ ที่ไม่อยู่ถังขยะ (เรียงเวลาลง สูงสุด 4) — `albumPreviewKeys` · ส่งมากับ GET (`preview_keys`) |
| อัลบั้ม | `asset_collections` · `description = "sample-images"` (ไม่ระบุแบรนด์) หรือ `"sample-images:<brand_id>"` · อัลบั้มย่อยต่อท้าย `"|in:<parent_id>"` (ไม่แก้ฐานข้อมูล) (`sampleAlbumMark` / `parseSampleMark`) + `asset_collection_map` — โผล่ในคลังไฟล์กลางด้วย |
| ส่งเข้าใบงาน | `POST /api/attachments/from-library` → แถวไฟล์แนบของใบงานชี้ไฟล์เดิม (ไม่ก๊อป) + `asset_usages` (กันลบไฟล์ที่ใช้อยู่) |
| ถังขยะ | `assets.status = trashed` (`DELETE /api/assets/[id]`) · เอากลับ `PATCH {restore:true}` |
| อัลบั้มย่อย | `POST /api/sample-images` action `create_sub` · `move_photos` · `move_album` · `rename` · `delete_album` (เฉพาะอัลบั้มย่อยที่ว่าง) — ย้ายอัลบั้ม = แก้ป้ายทั้งกิ่งให้เป็นแบรนด์ของปลายทาง |
| ย้ายอัลบั้มเข้าแบรนด์ | `POST /api/sample-images {action:"set_brand"}` — แก้ป้าย+ชื่ออัลบั้ม หรือรวมเข้าอัลบั้มแบรนด์+วันเดียวกัน · เติม `assets.brand_id` ที่ยังว่าง |

ป้าย `→ DS-xxxx` คิดสดจากไฟล์แนบจริงของใบงาน (`erp_playground_attachments` entity `design_sheet` · `file_path = r2_key`) — ใบงานเอารูปออก ป้ายหายเอง

## สิทธิ์ / ประวัติ

| ทำอะไร | สิทธิ์ | ประวัติ (audit) |
|---|---|---|
| ดูหน้า | `assets.view` | — |
| ลงรูป / สร้างอัลบั้มของวัน | `assets.upload` | `create asset` · `create asset_collection` (มี brand_id) |
| ส่งเข้าใบงาน | `attachments.upload` (ตรวจใน DB) + `assets.view` — ไม่มีสิทธิ์ = ไม่เห็นปุ่ม | `attach` ที่ใบงาน (จาก DB) |
| ลบ (ถังขยะ) | `assets.delete` (ตอนทำ: admin · manager) | `delete asset` |
| เอากลับ / ย้ายอัลบั้มเข้าแบรนด์ / ย้ายรูป-อัลบั้ม / เปลี่ยนชื่อ / ลบอัลบั้มย่อยที่ว่าง | `assets.edit` | `restore asset` · `update`/`delete asset_collection` |
| สร้างอัลบั้มย่อย | `assets.upload` | `create asset_collection` (parent_id · moved_photos) |
| สร้างอัลบั้มชั้นบนสุดตั้งชื่อเอง (`create_top` · Louis Batch) | `assets.upload` | `create asset_collection` (brand_id · top_level) |

- เมนู: แอปจัดการงาน หมวด "📋 จัดการงาน" ต่อจาก Design Dashboard (erp_menu_items · สิทธิ์เมนู `assets.view`) · สิทธิ์ตามเมนู = `lib/menu-permissions` กฎ `/tasks/samples` (assets.* + attachments.upload)

## ข้อจำกัด

- รายการอัลบั้มโหลด 300 อัลบั้มล่าสุด (รวมอัลบั้มย่อย)
- หน้าคลังไฟล์กลางเห็นอัลบั้มย่อยเป็นอัลบั้มธรรมดา (ไม่ซ้อน) — ถ้าวันหลังหน้าอื่นอยากได้อัลบั้มซ้อน ค่อยเพิ่มช่องอัลบั้มแม่ในตาราง
- หน้าเว็บเขียนไฟล์ลงโฟลเดอร์ในเครื่อง/NAS (`Z:\Work In Process\SAMPLE`) ไม่ได้ — ไฟล์ตรงนั้นอยู่เหมือนเดิม หน้านี้เก็บสำเนา JPEG ไว้ใช้ในระบบ
- เปลี่ยนชื่อแบรนด์ทีหลัง = อัลบั้มวันเดิมที่สร้างไปแล้วคงชื่อเก่า (หาอัลบั้มของวันด้วยชื่อ+ป้ายแบรนด์)
