# ไอเดียงานออกแบบ (หน้า "ไอเดีย" ใน Design Dashboard)

เจ้าของขอ 2026-11-12 (เลือกจาก widget) — จดไอเดียไว้ก่อน ยังไม่ใช่งานจริง แล้วค่อยกด "เริ่มทำงานจริง"

## ใช้ทำอะไร
- จดไอเดีย: ชื่อ · แบรนด์ (ไม่บังคับ) · รายละเอียดเป็นข้อ ๆ · Reference หลายลิงก์ (≤10) · รูปหลายรูป (รูปแรก = รูปปก)
- ไอเดีย **ไม่มีเลข DS** และไม่โผล่บนบอร์ด / สถิติ / อีเมลรายงาน / รายงานงานค้าง (อยู่คนละตาราง `design_ideas`)
- ตัวกรอง: ทั้งหมด · ของฉัน (ที่ตัวเองจด) · พักไว้ · เก็บแล้ว + ช่องค้นหาของ Dashboard + แบรนด์ที่เลือกในแถบซ้าย
- การ์ดต่อแถว (ของกลาง GalleryColumns · จำรายคน `gallery_cols_design_ideas`) · รูปเต็มกรอบ / เห็นทั้งรูป (จำรายคน `design_ideas_fit`) · กดรูป = ดูเต็มจอ
- พักไว้ / เก็บ (กู้คืนได้ — **ไม่มีลบทิ้งจริง**)
- เริ่มทำงานจริง = ป๊อปยืนยัน (บอกว่าระบบจะทำอะไร + เลือกเช็กลิสต์ ⏳ ได้ ตั้งต้น = Checklist งานใหม่) → ได้เลข DS → เปิดใบงานใหม่ให้

## เข้าตรงไหน
Design Dashboard → เมนู "มุมมอง" → "ไอเดีย (ยังไม่ใช่งานจริง)" · มือถือ = ปุ่มรูปหลอดไฟข้างช่องค้นหา (จำมุมมองรายคน `design_dashboard_view_mode`)

## เริ่มทำงานจริง ทำอะไรบ้าง
`POST /api/design-sheets { name, brand_id, detail, idea_id, checklist? }` — ทางสร้างใบงานทางเดียวกับฟอร์มปกติ/กล่องงานจากไลน์
1. จองไอเดีย (`promoting`) ก่อนออกเลข — กดซ้ำ/สองคนกดพร้อมกันไม่ได้ใบซ้ำ · ไอเดียที่เก็บอยู่ต้องกู้คืนก่อน
2. สร้างใบงาน (สถานะแรก) · รายละเอียด = ข้อ ๆ + หัวข้อ Reference + ลิงก์ (`ideaDetailHtml`)
3. รูปไอเดียแนบเข้าไฟล์แนบของใบงาน (R2 key เดิม ไม่อัปซ้ำ · รูปแรก = รูปหลัก)
4. ไอเดียเป็น `promoted` + `promoted_sheet_id` · ลงประวัติ `design_idea` action `promote`
5. สร้างใบไม่สำเร็จ = คืนสถานะไอเดียเดิม

## ไฟล์
- ตาราง `design_ideas` (migration `202611121400_design_ideas.sql` · RLS เปิด ไม่มี policy — อ่าน/เขียนผ่าน API เท่านั้น)
- ค่ากลาง/ตัวทำความสะอาด `lib/design-ideas.ts` (เทสต์ `lib/__tests__/design-ideas.test.ts`) · ฝั่งเซิร์ฟเวอร์ `lib/design-ideas-server.ts`
- API `/api/design-ideas` (GET รายการ · POST จด) · `/api/design-ideas/[id]` (PATCH แก้ / พัก / เก็บ / กู้คืน)
- หน้าจอ `components/design-dashboard/ideas-view.tsx` (โหลดเมื่อเปิดมุมมองนี้)

## สิทธิ์ / ประวัติ
- ดู = `products.view` · จด/แก้/พัก/เก็บ/เริ่มงาน = `products.edit`
- ประวัติ (audit_logs) entity `design_idea`: create · update · pause · archive · restore · promote (มี changes จากอะไรเป็นอะไร)

## ข้อจำกัด
- รูปที่อัปแล้วเอาออกจากไอเดีย ไฟล์ยังอยู่ใน R2 (ไม่ลบทิ้ง — เหมือนช่องแนบรูปอื่นที่ใช้ ImageAttachKeys)
- ไอเดียแสดงสูงสุด 500 รายการล่าสุด
