# เทียบ "สตูดิโอแพทเทิร์น" ของเรา กับ CLO3D — ช่องว่างและลำดับที่ควรทำต่อ

เขียน 2026-11-10 · เจ้าของขอ "อยากให้ปรับได้ละเอียดเหมือน CLO3D"

**เอกสารนี้ทำจากอะไร:** คู่มือทางการของ CLO (support.clo3d.com หมวด Manual) อ้างอิง 139 บทความ — อ่านเนื้อหาช่วงต้นราว 100 บทความ ที่เหลือดูจากชื่อและตำแหน่งในสารบัญ (ลิงก์ทั้ง 139 ตรวจแล้วว่าเปิดได้) เทียบกับเอกสารของเรา [pattern-studio.md](pattern-studio.md) และ [pattern-sheet.md](pattern-sheet.md)

**ข้อจำกัดที่ต้องรู้ก่อนอ่าน**
- **ไม่ได้เปิดโปรแกรม CLO จริง** ไม่ได้ติดตั้ง ไม่ได้สมัครบัญชี ไม่ได้ดาวน์โหลดไฟล์ — อ่านเฉพาะตัวหนังสือในคู่มือ (ภาพและวิดีโอประกอบไม่ได้ดู) ดังนั้น "ความรู้สึกตอนใช้จริง" ของ CLO ยืนยันไม่ได้จากเอกสารนี้
- คู่มือ CLO เขียนสำหรับ**เสื้อผ้าบนหุ่น**เป็นหลัก คู่มือมีเรื่องกระเป๋าโดยตรงแค่ 2 บทความ (ถาม-ตอบว่าทำกระเป๋าได้ไหม และเครื่องมือวัดความจุกระเป๋า)
- ช่อง "ทำบนเว็บได้ไหม" เป็น**การประเมินของผู้เขียน** ยังไม่ได้ทดลองทำจริง ขนาดงานอาจคลาดได้
- "คู่มือผ้า" (CLO Fabric Guide) และ "คู่มืออะไหล่" (CLO Trim Guide) เป็นไฟล์ให้ดาวน์โหลด จึง**ไม่ได้อ่าน** — รายชื่อค่าวัสดุสำเร็จรูป (preset) ของ CLO ทั้งชุดจึงไม่มีในเอกสารนี้

## สรุปสั้น (อ่านแค่ส่วนนี้ก็ตัดสินใจได้)

1. **งานวาดชิ้น 2D เราตามมาได้ราว 2 ใน 3 แล้ว** — ที่ขาดและกระทบงานกระเป๋ามากที่สุดคือ "เส้นในชิ้น" (แนวเย็บกระเป๋าหน้า แนวพับ ตำแหน่งติดอะไหล่) · การแก้ด้วยตัวเลขรายขอบ · ชิ้นคู่ที่แก้ตัวเดียวแล้วอีกตัวตาม
2. **งานเย็บ เราได้แค่แบบพื้นฐาน** — CLO เย็บ "บางช่วงของขอบ" และ "1 ขอบกับหลายขอบ" ได้ และแต่ละตะเข็บมีค่าปรับของตัวเอง (ชนิดตะเข็บ มุมพับ แรงดึง เดินด้ายทับ) ของเราตะเข็บยังเป็น "ทั้งขอบ" และไม่มีค่าปรับ
3. **"ปรับได้ละเอียด" ของ CLO คือ หน้าต่างคุณสมบัติ (Property Editor)** — กดอะไรก็ตาม (ชิ้น · ขอบ · ตะเข็บ · วัสดุ · ซิป) จะมีรายการค่าของสิ่งนั้นให้ปรับ ของเรามีแบบนี้เฉพาะ "ชิ้น" นี่คือช่องว่างที่ตรงกับคำขอของเจ้าของที่สุด และ**ส่วนใหญ่ทำบนเว็บได้**
4. **การจำลองผ้า/หนังให้ทิ้งตัวตรงของจริงระดับ CLO ไม่ควรสัญญา** — CLO ใช้เครื่องคำนวณเฉพาะทางบนเครื่องผู้ใช้ (ซีพียู/การ์ดจอ) กับค่าวัสดุที่วัดด้วยเครื่องมือ ของเราทำได้ระดับ "เห็นแนวโน้มว่าแข็ง/นิ่มต่างกันยังไง"
5. **บางเรื่องเราทำได้ดีกว่า CLO อยู่แล้วสำหรับโรงงานเรา** — ส่งชิ้นไปตีราคาด้วยราคาจริงของ ERP · แม่แบบทรงกระเป๋าที่ได้ตะเข็บครบ · พิมพ์ A4 ขนาดจริง · ใช้บนเว็บไม่ต้องติดตั้ง

**5 ข้อที่ควรทำก่อน** (รายละเอียดในหมวด 3)
1. เย็บบางช่วงของขอบ + 1 ขอบกับหลายขอบ — **เย็บบางช่วงทำแล้ว 2026-11-11** (ดู docs/pattern-studio.md) · **1 ขอบกับหลายชิ้นทำแล้ว 2026-11-11** (เครื่องมือ K · ตัวประกอบ 3D เข้าใจ) — ยังไม่ได้: หลายขอบกับหลายขอบ (M:N) · แบ่งตามสัดส่วนอัตโนมัติ
2. เส้นในชิ้น (แนวเย็บ/แนวพับ/ตำแหน่งติด) และเย็บกับเส้นในได้ — **ทำแล้ว 2026-11-11** (เส้นตรง 2 จุด + ตัวช่วยช่องใส่ของ/ช่องซิป + ชั้นซับใน · ดู docs/pattern-studio.md) · ยังไม่ได้: เส้นโค้ง/รูปปิดข้างในชิ้น · พิมพ์ระยะจากขอบ · ลากย้ายเส้นใน
3. ค่าปรับรายตะเข็บ: ชนิดตะเข็บ + เดินด้ายทับ + ทิศ แล้วออกเป็น "ตารางตะเข็บ" ในใบพิมพ์
4. แก้ด้วยตัวเลขรายขอบ: พิมพ์ความยาวขอบ · แบ่งขอบตามระยะ · รอยบากพิมพ์ระยะได้
5. ชิ้นคู่ผูกกัน (ตัวหน้า = ตัวหลัง · ซ้าย = ขวา แก้ตัวเดียวอีกตัวตาม รวมตะเข็บ) — **ทำแล้ว 2026-11-11** รูปเส้นรอบ (รวมตัวนอก → ซับใน) + คัดลอกตะเข็บให้ชิ้นคู่ตอนสร้าง / ปุ่มเย็บตามต้นแบบ · ยังไม่ได้: ตะเข็บผูกตามตลอดเวลา

| ช่อง | ความหมาย |
|---|---|
| **ของเรา** | **มีแล้ว** = ใช้งานได้เทียบเท่าสำหรับงานกระเป๋า · **บางส่วน** = มีแต่ทำได้น้อยกว่า · **ยังไม่มี** |

## หมวด 3 — ข้อเสนอลำดับทำ 3 ระลอก

เรียงตาม **ความคุ้มสำหรับโรงงานทำกระเป๋า** = ช่วยให้ช่างได้แพทเทิร์นที่ตัดและเย็บได้จริง เร็วขึ้น ผิดน้อยลง — ไม่ใช่เรียงตามความสวยของภาพ 3D

หลักที่ใช้เรียง: ของที่ **ออกไปถึงใบพิมพ์ / ไฟล์ตัด / ตีราคา** มาก่อน · ของที่อยู่แค่ในภาพ 3D มาทีหลัง · ทุกข้อต้องค้นทะเบียนของกลางก่อนสร้างของใหม่ (CLAUDE.md §9 ข้อ 6)

### ระลอก 1 — ปรับละเอียดในงาน 2D และตะเข็บ (ไม่ต้องพึ่งการจำลอง)

|---|---|---|---|

| 2 | **เส้นในชิ้น** (แนวเย็บ แนวพับ ตำแหน่งติดอะไหล่) พิมพ์ระยะจากขอบได้ และเย็บกับเส้นในได้ · ออกในใบพิมพ์และไฟล์ตัดเป็นชั้นใหม่ | ช่างเห็นบนกระดาษว่ากระเป๋าปะ/หู/ป้าย ติดตรงไหน ไม่ต้องวัดเอง | Internal Polygon/Line |

| 5 | **ชิ้นคู่ผูกกัน** (ตัวหน้า = ตัวหลัง · ซ้าย = ขวา) แก้ตัวเดียวอีกตัวตาม รวมตะเข็บ | กระเป๋าเกือบทุกใบมีชิ้นคู่ · ลดงานซ้ำและความผิดพลาดจากแก้ไม่ครบ | Symmetric Pattern (with Sewing) |
| 6 | **วัดความจุ (ลิตร)** และขนาดสำเร็จ จากกระเป๋าที่ประกอบแล้ว | ลูกค้าถามบ่อย "ใส่ของได้เท่าไร" · งานเล็ก · CLO เพิ่งเพิ่มเครื่องมือนี้สำหรับกระเป๋าโดยเฉพาะ | Volume Measurement |
