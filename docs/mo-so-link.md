# ใบสั่งผลิต ↔ ใบสั่งขาย (บังคับสำหรับแบรนด์ลูกค้า)

เจ้าของสั่ง 2026-11-05: "ใบสั่งผลิตต้องมีใบสั่งขาย (สำหรับแบรนด์ลูกค้า) ถ้าตอนเปิดต้องมีให้ผูกเลย และเพิ่มได้หากยังไม่สร้างใบสั่งขาย"

## ใช้ทำอะไร

- เปิดใบสั่งผลิตของ **แบรนด์ลูกค้า** (หน้าแบรนด์ติ๊ก "👤 งานลูกค้า" = `brands.is_customer_job`) ต้องผูกใบสั่งขายเสมอ
  - **เลือกใบที่มีอยู่** — ใบที่มีสินค้านี้และยังเปิดผลิตไม่ครบขึ้นก่อน · กรองตามลูกค้าประจำแบรนด์ (ติ๊ก "แสดงทุกใบ" ได้)
  - **ยังไม่มี สร้างใหม่** — ลูกค้าเติมจากลูกค้าประจำแบรนด์ · ราคาเว้นไว้ได้ (ติดหมายเหตุ "ยังไม่ใส่ราคา")
- **แบรนด์ของเรา** ไม่บังคับ (กด "ผูกใบสั่งขาย (ไม่บังคับ)" ได้)
- **สินค้ายังไม่มีแบรนด์** → ต้องใส่แบรนด์ก่อน (เลือกได้ในป๊อปเลย — ใช้ตัวเดียวกับป๊อป "ใส่แบรนด์" ของแดชบอร์ดผลิต)

## ชิ้นส่วน

| ส่วน | ไฟล์ |
|---|---|
| กติกา (pure ใช้ทั้งหน้าจอ + API) | `lib/mo-so-rule.ts` — `soNeedOf` · `soLinkError` · `soLineProgress` · `soLineQtyState/Text` |
| ส่วน "ใบสั่งขาย" ในป๊อป | `components/mo-so-link` — `MoSoLinkSection` · `soLinkInputOf` · `persistSoLinkExtras` |
| ป๊อปสร้างใบสั่งผลิต (ของกลาง) | `components/mo-create` (หน้าใบสั่งผลิต + บอร์ดจ่ายงาน) |
| ตรวจ + ผูก/สร้างใบสั่งขาย ฝั่งเซิร์ฟเวอร์ | `app/api/mo/so-link.ts` ← `POST /api/mo` (`so_link`) |
| ตัวเลือกใบสั่งขาย | `GET /api/mo/so-options?sku=` (`&all=1`) · `?skus=A,B` = ต้องผูกไหมต่อรหัส |
| ลูกค้าประจำแบรนด์ (หลายสาขาได้ 2026-11-07) | `brands.default_customer_ids` (รายแรก = `default_customer_id`) · กติกา `lib/brand-customers.ts` · หน้า `/master/brands` · `PATCH /api/brands` — ป๊อปสร้างใบผลิต/ลงออเดอร์: รายเดียว = เติมให้ · หลายราย = ปุ่มเลือกสาขา (ไม่เดา) · กรองใบสั่งขายของทุกรายในรายการ |
| ยอดต่อรายการ สั่ง/เปิดผลิต/ส่ง | `GET /api/so-orders/[id]` → `lines[].progress` + `orphan_mos` · หน้าอ่านใบสั่งขาย |

## กติกาสำคัญ

- **เช็กฝั่งเซิร์ฟเวอร์ด้วย** — เรียก `POST /api/mo` โดยไม่ส่ง `so_link` กับสินค้าแบรนด์ลูกค้า = 400 (`need_so: true`)
- ผูก/สร้างใบสั่งขายไม่สำเร็จ → ลบใบผลิตที่เพิ่งสร้างทิ้ง (ยังไม่กางสูตร) ไม่มีใบหลุดกติกา
- ผูกใบเดิม: เลือกรายการมา = ผูกรายการนั้น · ไม่เลือก = รายการรหัสเดียวกันที่ยังไม่มีใบผลิต → ไม่มีก็นับรวมรายการรหัสเดียวกัน → ไม่มีเลย = เพิ่มรายการใหม่ราคา 0 (คิดเงินใหม่ทั้งใบ)
- ผูกแล้ว: สถานะ "ร่าง" → "ยืนยันแล้ว" (กติกาเดียวกับเปิดใบผลิตจากใบสั่งขาย) · กำหนดส่งว่าง = วันส่งลูกค้าของรายการ/ใบ
- สร้างใบสั่งขายใหม่ต้องมีสิทธิ์ `so.create` · audit: `create` (mo) + `create` / `so_order.link_mo` (so_order)
- 1 รายการในใบสั่งขายมีใบผลิตได้หลายใบ: ใบที่รายการอ้าง (`so_order_lines.mo_id`) + ใบอื่นที่ผูกใบสั่งขายนี้รหัสเดียวกัน (แตกใบ/ลดจำนวนติดเลขใบสั่งขายไปเอง)
- ผูกบิล (ใบขาย) กับใบผลิต: ถ้าบิลเป็นคนละลูกค้ากับใบสั่งขาย → **เตือน ไม่บล็อก** (`sales-bill-picker`)

## ห้ามใช้เมื่อไหร่ / ข้อจำกัด

- ไม่ได้ผูกย้อนหลังใบผลิตเก่า (ก่อน 5 พ.ย. 69) — Good Goods ยังไม่ผูก 47 ใบ ต้องทำทีละชุดเมื่อเจ้าของอนุญาต
- ทางเปิดใบผลิตจากใบสั่งขาย (`open-mo`) ผูกอยู่แล้ว ไม่ผ่านป๊อปนี้
- โหมดหลายรายการ: งานลูกค้าต้องเป็นแบรนด์เดียวกันทั้งชุด (คนละแบรนด์ = คนละใบสั่งขาย)
