# FontSelect — เลือกฟอนต์แบบเห็นหน้าตาจริง

`components/font-select.tsx`

## ใช้ทำอะไร

ช่องเลือกฟอนต์ที่ **ปุ่มเขียนชื่อฟอนต์ด้วยฟอนต์นั้นเลย** และ **รายการแต่ละแถวเขียนด้วยฟอนต์ของตัวเอง + ตัวอย่างไทย/อังกฤษ** ไม่ต้องเดาจากชื่อ

- มีช่องค้นหา (รายการเกิน 8 ตัว) · จัดกลุ่ม (เช่น ไทย + อังกฤษ / อังกฤษ)
- ลูกศรขึ้น-ลง + Enter เลือก · Esc ปิด · กดนอกกล่องปิด
- รายการลอยเหนือทุกอย่าง (ไม่โดนกล่องเลื่อนตัด) · ชิดขอบล่างไม่พอ = เปิดขึ้นบน

เจ้าของโปรเจกต์ขอ: "ตรง font สามารถโชว์หน้าตา font เลยได้ไหม ไม่ต้องเดา (เปลี่ยนทุกอันที่เป็นให้เลือก font)"

## ใช้เมื่อไหร่

ทุกช่องที่ให้เลือก "ฟอนต์" — ห้ามใช้ `<select>` ธรรมดากับฟอนต์อีก

## วิธีใช้

```tsx
import { FontSelect } from "@/components/font-select";

<FontSelect
  value={font}
  onChange={setFont}
  options={[{ value: "Kanit", label: "Kanit", family: '"Kanit", sans-serif', group: "ไทย + อังกฤษ" }]}
  googleFonts={["Kanit"]}   // ชื่อฟอนต์ Google ที่ต้องโหลดมาโชว์ (ตัวที่เลือกอยู่โหลดทันที ที่เหลือโหลดตอนเปิดรายการ)
/>
```

| prop | ความหมาย |
|---|---|
| `options` | `{ value, label, family?, group?, note? }` — `family` = CSS font-family ที่ใช้วาดแถวนั้น |
| `googleFonts` | ชื่อ Google Fonts ที่ต้องโหลด (ฟอนต์ในเครื่องไม่ต้องใส่) |
| `sample` | ข้อความตัวอย่างด้านขวาของแต่ละแถว |
| `size` | `"sm"` = ปุ่มเตี้ย (แถบเครื่องมือ) |
| `className` | ความกว้างของปุ่ม (ไม่ใส่ = เต็มช่อง) |

ตัวช่วยของเว็บร้าน (`components/website-text-pickers.tsx`):
- `webFontOptions(first?)` + `WEB_FONT_NAMES` = ฟอนต์ธีมทั้งหมด (GOOGLE_FONTS)
- `canvasFontOptions(fontNames)` + `canvasFontNames(fontNames)` = ฟอนต์ของ Section/ผืนผ้าใบ (CANVAS_FONTS · display/body = ฟอนต์ของธีมร้าน)

## จุดที่ใช้แล้ว

- หน้าดีไซน์เว็บ: ฟอนต์หัวข้อ/เนื้อหา · ฟอนต์รายบทบาท (แท็บตัวอักษร + แท็บเมนู)
- ฟอร์ม Section ในตัวจัดหน้า: ช่องที่ตั้ง `display: "font"` ใน `lib/website-schema.ts` (ฟอนต์ชิ้นในผืนผ้าใบ · ฟอนต์ชื่อสินค้า · ฟอนต์ตัวอักษรยักษ์)
- กระดานงาน (`app/tasks/canvas-board.tsx`) · ปรับแต่งภาพรวมงาน (`app/tasks/overview-customizer.tsx`)
- ที่เป็นรายการโชว์ฟอนต์อยู่แล้ว (ไม่ต้องเปลี่ยน): `FontPickList` (แผงตัวอักษรของ Section/ผืนผ้าใบ) · ฟอนต์การ์ดของขวัญ · ฟอนต์หน้าแอป

## ข้อจำกัด

- ฟอนต์ Google ต้องโหลดจากเน็ตครั้งแรกตอนเปิดรายการ (เสี้ยววินาที) — ระหว่างนั้นแถวจะเป็นฟอนต์ปกติก่อน
- ฟอนต์อังกฤษ: ตัวอย่างภาษาไทยจะใช้ฟอนต์สำรอง (เหมือนบนเว็บจริง)
