# ใบวางบิล — เลือกหลายบิลทีเดียว ออกหลายใบแยกตามลูกค้า + ปรับหน้าพิมพ์

เจ้าของสั่ง 2026-11-03

## 1. สร้างใบวางบิลหลายใบทีเดียว

- ป๊อป "สร้างใบวางบิล" ติ๊กใบกำกับได้หลายลูกค้า → ระบบแยกเป็น **1 ใบวางบิลต่อ 1 ลูกค้า** (แต่ละสาขา = คนละใบ) × บริษัทผู้ขายของเรา (หัวจดหมายต่างกันรวมใบเดียวไม่ได้)
- วันที่ / กำหนดชำระ / หมายเหตุ กรอกครั้งเดียวใช้ทุกใบ · แก้วันครบกำหนดรายใบได้ในการ์ดลูกค้า
- **ทั้งชุดหรือไม่สร้างเลย**: ใบไหนติด (ถูกวางบิลแล้ว / ใบร่าง / คนละลูกค้า) = ไม่สร้างสักใบ และบอกว่าติดใบไหน · ใบร่างเตือนตั้งแต่ในป๊อป
- สร้างได้หลายใบ → ป๊อปผลลัพธ์: เลขที่แต่ละใบ + พิมพ์ทีละใบ + **พิมพ์ทั้งหมด** (`/print/billing-note-bulk?ids=`)
- แก้ไขใบเดิม = ลูกค้าเดียวเหมือนเดิม (1 ใบ = 1 ลูกค้า ทุกกรณี)

ไฟล์: `app/billing-notes/page.tsx` · `app/api/billing-notes/batch/route.ts` (จัดกลุ่มตัวจริง) · RPC `erp_playground_billing_note_create_batch` (`supabase/migrations/202611120200_billing_note_batch_create.sql`)

> แบบ "รวมคนละลูกค้าในใบเดียว + เหตุผล" (202611120100) ถูกถอดออกแล้ว — เจ้าของแจ้งว่าเข้าใจผิด · ใบ 20261102 ที่รวมไว้ถูกแยกเป็น 20261102 (สำนักงานใหญ่) + 20261103 (สาขาคลังสินค้า)

## 2. หน้าพิมพ์ปรับคอลัมน์ได้ (ของกลาง)

- `/print/billing-note/[id]`: พรีวิวซ้าย + แผง `DocPrintPanel` ขวา (ไม่บังพรีวิว · พรีวิวหน่วง 200ms)
  - คอลัมน์: เปิด/ปิด · ชื่อหัว · ลากเรียง · กว้าง (มม.) · ลากขอบหัวคอลัมน์บนกระดาษ (ดับเบิลคลิก = อัตโนมัติ) · "พอดีอัตโนมัติ" วัดฟอนต์จริง · "หมายเหตุ" ได้พื้นที่ที่เหลือ
  - ตัวอักษรในตาราง (pt) · ระยะในแถว (มม.) · เส้นตาราง + ความหนา (มม. — เห็นชัดตอนพิมพ์จริง)
  - ไม่กดบันทึก = ใช้กับใบนี้ · **บันทึกเป็นค่าเริ่มต้น = ทุกคน** (`ui_config.doc_print_billing_note` · อ่าน `so.view` · บันทึก `so.edit` · มีประวัติ setting_change)
- ของกลาง: `lib/doc-print-prefs.ts` (`renderDocTable`, `DOC_TABLE_SETUP`) · `components/doc-print-settings` (`DocPrintPanel`, `measureDocColumns`) · `attachColumnResize({ table, freeze })`
- แม่แบบ: วาง `{{{lines_table}}}` แทนตารางที่เขียนเอง (คง class `bn-lines` → CSS เดิมใช้ได้) · สำเนาแม่แบบเดิม `standard_backup_20261103` (ปิดใช้งาน)
- เพิ่มเอกสารอื่น: เพิ่มคอลัมน์ใน `DOC_COLUMNS` + แถวใน `DOC_TABLE_SETUP` + ให้หน้าพิมพ์ส่ง `lines_table` — ใบกำกับภาษี (so) ยังเป็นแบบเปิด/ปิดคอลัมน์เหมือนเดิม
