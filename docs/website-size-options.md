# 📐 ตัวเลือกชุดที่ 2 บนเว็บร้าน (ไซส์ / แบบพิมพ์ / ขนาดรู)

## ใช้ทำอะไร
สินค้าที่ต้องเลือก 2 อย่างถึงจะได้ของถูกตัว เช่น เข็มขัด = **สี × ไซส์** · กระเป๋าบัตร = สี × แบบพิมพ์ · เครื่องเจาะหนัง = จำนวนรู × ขนาดรู

## ข้อมูลอยู่ที่ไหน
- **ใน ERP (ของจริง)**: SKU ลูก 1 ตัว = 1 คู่ สี×ไซส์ · ช่อง `skus_v2.attribute_values.variant_option = { code, name, value }`
  สร้างด้วยปุ่ม **"＋ เพิ่มแบบ/ไซส์"** ในตาราง SKU ลูกของ Parent SKU (ชุดสำเร็จ S–XXL)
- SKU ที่ไม่มี variant_option = ตัวหลักของสีนั้น (มีรูป) · ถ้าสีนั้นมี SKU ไซส์ → ลูกค้าต้องเลือกไซส์
- **เปิดใช้ต่อร้าน**: เว็บไซต์ → ⚙️ จับคู่ฟิลด์ → "ตัวเลือกชุดที่ 2" = ตัวเลือกที่ 2 ของ SKU ลูก
- **ปิดบางคู่บนเว็บ**: ป๊อปตั้งค่าสินค้าบนเว็บ → 🛒 ขายบนเว็บ → ตาราง สี×ไซส์ → `store_listings.web_variant_off` (id SKU ไซส์ที่ปิด · null = เปิดทุกคู่)

## กติกา
- ไซส์เรียง S < M < L < XL → ตัวเลข → ที่เหลือตามลำดับเดิม
- ชื่อชุดที่ติดมากับ SKU (variant_option.name เช่น "ไซส์") ชนะชื่อสำรองของร้าน — ร้านเดียวมีทั้ง "ไซส์" และ "แบบพิมพ์" ได้
- คู่ที่ไม่มีใน ERP / ปิดไว้ = ขีดฆ่า กดไม่ได้ + "ไซส์ L ไม่มีในสี เทา" · ไซส์ที่ปิดทุกสี = ไม่โชว์ · สีที่ปิดครบทุกไซส์ = สีนั้นไม่ขึ้นเว็บ
- สีที่ไม่มี SKU ไซส์เลย = ขายได้โดยไม่ต้องเลือกไซส์ (ซ่อนแถวไซส์)
- ไม่เลือกไซส์ให้เอง (ยกเว้นมีให้เลือกไซส์เดียว) · กดใส่ตะกร้าตอนยังไม่เลือก = เตือนสีแดง ไม่ใส่ตะกร้า
- การ์ดสินค้าที่มีไซส์: ปุ่มใส่ตะกร้าบนการ์ด = เปิดดูด่วนให้เลือกไซส์ก่อน
- รหัสตัวเลือก `opt2-<8 ตัวแรกของ SKU ตัวแรกที่มีไซส์นั้น>` (ตะกร้าเก่า/ออเดอร์อ้างอยู่ ห้ามเปลี่ยนสูตร)

## 💰 ราคาตาม SKU ที่เลือก
- ใช้เมื่อ: ไม่ได้กรอกราคาเว็บทับ + ร้านตั้งราคาจาก SKU ลูก (sku_max/sku_min) + ไม่ได้กรอกตัวเลือกเอง — `perSkuPricing()`
- ราคาต่อหน่วย = `list_price` ของ SKU ที่ลูกค้าเลือก (SKU ไม่มีราคา = ราคารุ่น) — `skuUnitPrice()` ใช้ทั้งหน้าเว็บและออเดอร์
- products API: `price` = ต่ำสุดของตัวเลือกที่ซื้อได้จริง · `priceVaries` · `variantPrices { "sku-…" | "sku-…|opt2-…": { price, compare? } }` (ส่งเฉพาะเมื่อราคาต่างกัน)
- SKU ที่คิดราคา = ตัวเดียวกับที่ออเดอร์หยิบ: สี = SKU ที่รหัสตัวเลือกอ้าง (สีเดียวกันมีหลาย SKU ก็ไม่สลับ) · สี×ไซส์ = ช่องในตาราง
- เว็บร้าน: `src/lib/variant-price.ts` — หน้าสินค้าเปลี่ยนราคาตามที่เลือก ("เริ่มต้น" เมื่อยังไม่เลือกไซส์และราคาต่างกัน) · ตะกร้าเก็บราคาของตัวเลือกตอนใส่ (cart-context) · การ์ดแบบ SKU ใช้ราคาของสีนั้น
- การ์ดโชว์คำว่า "เริ่มต้น" ต้องเปิดที่ ดีไซน์ → การ์ดสินค้า (theme.card.priceFrom · ค่าเริ่มต้นปิด)

## 📏 ตารางไซส์ (size guide)
- ตั้งที่ เว็บไซต์ → **📏 ตารางไซส์** (`components/website-size-guides-panel.tsx`) · เก็บ store_settings "size_guides" · API `/api/website/size-guides` (products.view/edit + audit + ล้างแคช)
- 1 ตาราง: ชื่อ · หมวดที่ใช้ (หมวดแม่ครอบหมวดย่อย · หมวดย่อยที่มีตารางเองชนะ) · คอลัมน์ ≤6 · แถว = ไซส์ ≤20 · คอลัมน์ "ช่วงใต้ปุ่มไซส์" (พิมพ์ 28–32) · ตัวช่วยแนะนำไซส์ (สิ่งที่กรอก + หน่วย) · วิธีวัด · ช่อง _en
- ทับรายรุ่น: ป๊อปตั้งค่าเว็บ 🛒 → "📏 ตารางไซส์บนหน้าสินค้า" = อัตโนมัติ / เลือกตาราง / ไม่แสดง → `store_listings.web_size_guide`
- กฎ: `lib/website-size-guides.ts` (normalizeSizeGuides · parseFitRange · resolveSizeGuide · publicSizeGuide · แม่แบบเข็มขัด = **ค่าตัวอย่าง**)
- products API ส่ง `sizeGuide` (เฉพาะรุ่นที่มีไซส์) · เว็บร้าน `src/lib/size-guide.ts` + `components/shop/SizeGuide.tsx` (ป๊อปผ่าน Overlay กลาง) · ช่วงใต้ปุ่มใน Option2Picker
- แนะนำไซส์: แถวที่ช่วงครอบค่า · ขอบพอดี (32 = ท้าย S/ต้น M) = ไซส์ใหญ่กว่า · ไซส์ไม่มีในสีนั้น = บอก ไม่เลือกให้ · นอกช่วง = "ไม่มีไซส์ที่พอดี (รองรับ x–y)"

## สิทธิ์ / ประวัติ
- แก้ตารางในป๊อป = `products.edit` · บันทึกผ่าน `/api/parent-web-listings` → writeAudit (patch.webVariantOff) + ล้างแคชเว็บร้าน
- ไม่แตะข้อมูล SKU ใน ERP (ปิด/เปิดเฉพาะบนเว็บร้านนั้น)

## ยังไม่ทำ
- สต๊อกต่อไซส์ · ตัวกรองไซส์ใน /shop · รูปประกอบวิธีวัดในตารางไซส์
