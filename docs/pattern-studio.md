เจ้าของขอ 2026-11-10: "อยากได้โปรแกรมทำ Pattern กระเป๋า คล้าย CLO3D เวลาทำแบบมี Model 3D ให้ดูว่าเย็บแล้วเป็นยังไง และแกะจากรูปได้" + "เราไม่ใช่ช่าง อยากเรียนรู้วิธีทำไปด้วย"
แนวทางทั้งหมดมาจากเอกสาร Bag Pattern CAD Studio (6 เฟส) — ตกลงกันว่า **สร้างต่อจากตัววาดชิ้นวัสดุเดิม ไม่ทำโปรแกรมแยก** แบ่งเป็น 6 รอบ ไฟล์นี้คือรอบ 1

## Bag CAD รอบ A + B: กันงานพัง + ตรวจแบบก่อนผลิต (2026-11-12)
เจ้าของส่งสเปก `Bag_CAD_Upgrade_Complete_Tools_Learn_By_Doing.md` → ทำ Gap Audit + widget ตัวอย่าง → สั่ง "เริ่มรอบ A + B" · ไม่มีตารางฐานข้อมูลใหม่ (ค่าใหม่อยู่ใน `template`)

**รอบ A — ฐานกันงานพัง**
- **หน่วยแสดง มม. / ซม. / นิ้ว** (ปุ่มบนแถบสตูดิโอ · จำในเครื่อง `pattern-studio-unit` · ค่าเริ่ม มม.) — ข้อมูลยังเก็บเป็น ซม. เสมอ เปลี่ยนหน่วยแล้วขนาดจริงไม่เปลี่ยน · `lib/length-units` (parseLength / formatLength)
  - ShapeEditor prop `unit` (ไม่ส่ง = ซม. ทศนิยม 1 แบบเดิม → ใบงานออกแบบหน้าตาเดิม) · ช่องตัวเลขความยาว = `NumField len` รับ `7 mm` `0.7 cm` `1 in` `260/2` `(26+2)*2` (ตัวอ่านเขียนเอง ไม่ใช้ eval) · Enter/ออกจากช่อง = ยืนยัน · Esc = ยกเลิก · ลูกศร = ทีละ step · ผิด = ขอบแดง + บอกเหตุผล
  - ⚠️ ช่องความยาวไม่ส่งค่าทุกตัวอักษรแล้ว (เดิมพิมพ์ "2" ชิ้นหดก่อนพิมพ์ "6" ต่อ) — กด Enter หรือออกจากช่องถึงเปลี่ยน
  - ยังเป็น ซม.: ไม้บรรทัดขอบกระดาน · ช่องตั้งขนาดรูปอ้างอิง · ช่องเพิ่มชิ้นด้วยตัวเลข / รัศมีมุมโค้ง / ระยะเส้นขนาน (มีป้าย ซม. กำกับ) · พื้นที่ ตร.ซม.
- **บันทึกอัตโนมัติ** หยุดแก้ 4 วิ (SaveBar `mode="auto"`) · ไม่สำเร็จ = ลองเองทุก 20 วิ + ปุ่ม "ลองบันทึกอีกครั้ง" + **"ดาวน์โหลดสำรอง"** (.json) · ระหว่างส่งมีการแก้เพิ่ม = ยังค้าง รอบถัดไปบันทึกต่อ
  - API รับ `autosave: true` → แก้รูปชิ้นอย่างเดียว จดประวัติไม่เกิน 1 ครั้ง/10 นาที (กันประวัติท่วม) · เปลี่ยนชื่อ/สถานะ/จำนวนชิ้น จดทุกครั้ง
- **กู้งาน**: ระหว่างแก้เก็บสำเนาในเครื่อง `localStorage pattern-draft:<id>` · เปิดใหม่เจอสำเนาที่ต่างจากฉบับในระบบ = แถบ "กู้คืน / ทิ้ง" (เตือนถ้าฉบับในระบบใหม่กว่า) · บันทึกสำเร็จ = ลบสำเนา
- **เลขรุ่น**: `template.rev` นับครั้งที่บันทึก (โชว์ที่แถบบันทึก + หัวแผ่นพิมพ์) · `template.schema` = `PATTERN_SCHEMA` (2) · ของเก่าไม่มี schema = รุ่น 1 อ่านได้เหมือนเดิม (`templateSchema()` = จุดแปลงรุ่นในอนาคต)
- **ย้อนกลับรวม**: ประวัติเดียว = ชิ้น + ตะเข็บ (เดิมตะเข็บมีประวัติแยก ย้อนได้เฉพาะตอนถือเครื่องมือเย็บ) · ⚠️ ยังไม่รวม: จุดติดหู (แท็บแยกชิ้น) · ค่าวัสดุ · ซิป/อะไหล่ · ค่าคลาด · ล็อก/ซ่อน
- **รายการชิ้น** (ปุ่มบนแถบ): จัดกลุ่มตามชนิดชิ้น (ตัวกระเป๋า / ซับใน / แผ่นเสริม / อะไหล่) · ล็อก (เห็นปกติแต่กด/ลาก/แก้ไม่ได้ · ShapeEditor `lockPids`) · ซ่อน (จาง กดไม่ได้ · ยังถูกตรวจ) · แยกดู (ชั่วคราว) · ทั้งกลุ่มได้ · เก็บใน `template.view {lock, hide}` (`cleanPieceView`)

**รอบ B — ตรวจแบบก่อนผลิต**
- **แผง "ตรวจแบบ"** (ปุ่มบนแถบ มีตัวเลขแดง/เหลือง) · ตัวตรวจ `lib/pattern-check` `checkPattern()` + `describeIssue()` (ข้อความตามหน่วยที่เลือก) — กดแถว = ไปที่ชิ้น/ขอบ (เลื่อนกระดาน + ไฮไลต์เส้นประแดง · ขอบ = เปิดค่าของขอบในเครื่องมือแก้ตะเข็บ) · ShapeEditor `flagged` / `focusEdge`
  - error: ตะเข็บอ้างขอบที่เปลี่ยนไป · ยาวต่างเกินค่าคลาด · เส้นเย็บ/เส้นตัดตัดกันเอง · รูหลุดหรือคร่อมเส้นเย็บ
  - warn: ขอบที่ยังไม่ได้เย็บของชิ้นที่เย็บแล้ว (ไม่นับขอบที่ติ๊ก **ขอบเปิดตั้งใจ** / ขอบพับ / ซิปหรือกุ๊นทั้งขอบ) · รูห่างเส้นเย็บ < 5 มม. · ขอบสั้น < 2 มม. · ไม่มีวัสดุ · info: ตั้งใจรูด · ไม่มีชื่อ
  - ปุ่ม "ตั้งเป็นขอบเปิด" ในแถว = ส่งผ่าน `inject.edgeOpen` → ย้อนกลับได้
- **ค่าคลาดตะเข็บต่อแพทเทิร์น** `template.settings.seamTol` (ค่าเริ่ม 0.5 มม. = `DEFAULT_SEAM_TOL` — ค่าทดลอง ไม่ใช่มาตรฐานโรงงาน · เดิมตายตัว 1 มม.) → สีตะเข็บบนกระดาน (`seamTol`) + ตัวนับหัวหน้า + ด่านพิมพ์ใช้ค่าเดียวกัน
- **ขอบเปิดตั้งใจ** = `EdgeMeta.open` (ติ๊กในค่าของขอบ · เครื่องมือแก้ตะเข็บ B)
- **ตะเข็บตามเมื่อแบ่ง/ลบจุด**: `lib/pattern-edge-map` (`edgePlan` · `migrateSeams` · `remapEdgeValues` · `remapEdgeMeta`) เรียกใน `commit()` ของ ShapeEditor + ตอนชิ้นตามต้นแบบเปลี่ยนรูป — ตะเข็บครอบช่วงใหม่ครบ · เผื่อเย็บรายขอบ/ขอบพับ/ขอบเปิดตามไปทุกช่วง · ซิป/กุ๊นบางช่วงตัดตามช่วงจริง · ลบจุดแล้วปลายตะเข็บหาย = ไม่เดา ขึ้น "ต้องเลือกขอบใหม่" + ข้อความบนกระดาน · วงรี = แบบเดิม · ⚠️ เดิมแบ่งขอบแล้ว "เผื่อเย็บรายขอบ" หลุดทั้งชิ้นเงียบ ๆ — แก้แล้วในงานนี้
- **ด่านตรวจก่อนพิมพ์** `components/pattern-studio/preflight-modal` (ปุ่ม "ใบสเปก / พิมพ์ / ไฟล์ตัด") — กลุ่ม: บันทึกแล้ว/รุ่นเดียวกัน · รูปชิ้น · ตะเข็บ · ขอบเปิด · รู · ชื่อ/วัสดุ · กรอบสอบเทียบ — มีข้อแดง = "พิมพ์แบบร่าง" เท่านั้น (`?draft=1` → `PatternPrintView draft` ลายน้ำทุกหน้า)
- **กรอบสอบเทียบ 100 × 100 มม.** ในหน้าแรกของพิมพ์ A4 (เดิม 5 ซม. · มีผลกับหน้าพิมพ์แพทเทิร์นของใบงานออกแบบด้วย) · แผนผังหน้าเตี้ยลง (90 → 70 มม.) ให้พอหน้า
- **ป้ายระดับภาพ 3D** (หัวช่อง 3D): ดูชิ้น (Preview) / ประกอบตามกติกา (Assembly) / ฟิสิกส์ (ทดลอง) + "ยืนยันได้ / ยังสรุปไม่ได้"
- ลองในเครื่องผ่าน (หน้า zz จำลอง API): ตรวจแบบ · ตั้งขอบเปิด + ย้อน · พิมพ์ 280 mm · สลับ มม.→ซม.→นิ้ว→มม. ค่าเดิม · กดแถวไปที่ขอบ · ล็อก/ซ่อน + บันทึก · ด่านพิมพ์ · บันทึกล้มเหลว → ดาวน์โหลดสำรอง → รีโหลด → กู้คืน · แบ่งขอบล่างที่มีตะเข็บ → ตะเข็บตาม → ย้อนกลับครบ · **ยังไม่ได้ลองด้วยบัญชีจริง และยังไม่ได้ลองพิมพ์หน้าพิมพ์จริง (ต้องล็อกอิน)**
- เทสต์: `lib/__tests__/pattern-bagcad-ab.test.ts` (A02 · A05 · A06 + ตัวอ่านหน่วย + ตัวตรวจ)

## บันทึกภาพ 3 มิติ + ใบสเปกจากแพทเทิร์น (2026-11-11)
เจ้าของสั่ง "ทำต่อเลย" — ของที่ CLO3D มี (Snapshot · Techpack) และใช้ส่งต่อลูกค้า/โรงงาน · ไม่มีฐานข้อมูลใหม่ · ไม่ได้ลงไลบรารีเพิ่ม

- **ปุ่ม "บันทึกรูป"** บนภาพ 3 มิติทุกที่ (ข้างปุ่มมุมมอง): บันทึกภาพที่เห็นอยู่ (มุมและการซูมตามที่ดู) เป็นไฟล์ JPG พื้นขาว · ชื่อไฟล์ = เลขที่ + ชื่อแพทเทิร์น (`Pattern3D saveName` · `PatternStudio imageName`)
  - ตัวถ่ายภาพ `Stage.snapshot(view?)` ใน `components/pattern-3d`: ตั้งมุมชั่วคราว → วาดทันที → คัดลอกลงพื้นขาว → คืนมุมเดิม (ภาพบนจอไม่กระโดด) · `Pattern3D onReady(api)` ให้หน้าอื่นเรียกถ่ายได้
- **ใบสเปก** = แท็บแรกของหน้า "ใบสเปก / พิมพ์ / ไฟล์ตัด" (`/print/pattern-project/<id>` · เดิมชื่อ ภาพรวม + วางบนผ้า): หัวเอกสาร → **ภาพ 3 มิติ 2 มุม** (เฉียงหน้า / เฉียงหลัง) + ขนาดตัวกระเป๋าตอนเย็บแล้ว (กว้าง × สูง × ลึก) + จำนวนชิ้นที่เย็บติด/ตะเข็บ → ตารางชิ้น+วัสดุ → รายละเอียดชิ้น → ซิปและอะไหล่ → อะไหล่ที่วางบนชิ้น → ตารางตะเข็บ → งานขอบ → ภาพชิ้นทั้งหมด → วางบนผ้า · พิมพ์หรือบันทึก PDF ด้วยปุ่มเดิมของหน้าพิมพ์
  - ภาพ 3 มิติสร้างจากข้อมูลที่ **บันทึกแล้ว** (`buildSewn`) วาดนอกจอแล้วถ่ายเป็นรูป → พิมพ์ได้แน่นอน (ไม่ต้องพึ่งการพิมพ์ผืนวาด 3 มิติ) · ยังไม่มีชิ้นไหนเย็บติด = ไม่มีบล็อกภาพ
  - `PatternPrintView` (ของกลาง) เพิ่ม `beforeTable` + `overviewLabel` — หน้าพิมพ์แพทเทิร์นของใบงานออกแบบไม่เปลี่ยน
- ⚠️ ภาพในใบสเปกใช้สีตั้งต้น (ไม่ใช่สีวัสดุจริง) · มุมตายตัว 2 มุม (อยากได้มุมอื่นใช้ปุ่มบันทึกรูป) · ยังไม่มีการส่งออกไฟล์โมเดล 3 มิติ (OBJ/GLB)

## เก็บงานหลังตรวจ: 12 จุดที่ทำงานไม่ตรง / ใช้ยาก (2026-11-11)
เจ้าของสั่ง "เช็คให้หน่อยว่ามีตรงไหนทำงานไม่ตรงหรือใช้ยาก" → ตรวจด้วยการลองกดในหน้าทดลอง → "แก้ทั้งหมด"

**ทำงานไม่ตรง**
1. เย็บทีละขั้น: สายพาดข้างถึงข้าง (`AsmHandle.side = 0`) บอกว่า "เย็บเข้ากับชิ้นข้างซ้ายและขวา" และป้าย "สายพาดข้างถึงข้าง" (เดิมบอกว่าเย็บกับแผ่นหน้า/หลัง และเรียก "หู")
2. แถบซิปบน / ฝาปิด = "ชิ้นปิดปาก / ฝา (เย็บเต็มขอบ)" (`SewnPart.fold`) — เดิมถูกเรียก "ชิ้นเสริม (เย็บบางช่วง)"
3. ชิ้นที่ผูกรูปกับต้นแบบ: ช่องกว้าง/สูงถูกล็อก + ข้อความบอกให้แก้ที่ต้นแบบหรือกดเลิกผูก (เดิมพิมพ์ได้แล้วค่าเด้งกลับเงียบ ๆ)
4. โหมดทิ้งตัว: มีข้อความบอกว่าจำลองเฉพาะตัวกระเป๋า (ไม่รวมแถบซิป ฝาปิด ชิ้นเสริม ซับใน ซิป อะไหล่)
5. ใบพิมพ์: ตาราง "อะไหล่ที่วางบนชิ้น" (ชิ้น · ชนิด · ขนาด · ห่างขอบบน/ซ้าย) + อะไหล่บนรูปชิ้นเป็นวงกลมมีกากบาท · ไฟล์ตัด DXF: อะไหล่ = วงกลมในชั้นใหม่ `HW` (เดิมเป็นเส้นสั้นในชั้น `INNER`) · ตัวนำเข้า DXF ข้ามชั้น `HW`
6. ชิ้นที่เป็นทั้งแผ่นหน้าและแผ่นหลัง (ตัด 2 ชิ้น): ช่องเจาะ ซิป กุ๊น อะไหล่ ขึ้นในภาพทั้งสองแผ่น (`back: true` บน `SewnMark` / `SewnFinish`)

**ใช้ยาก**
1. เกณฑ์เปิดคู่ซ้าย-ขวาของแอปลดจาก 1180 เป็น **860 พิกเซล** (`SPLIT_PX`) — โน้ตบุ๊กทั่วไปไม่ตกไปเป็นบน-ล่างแล้ว · ช่วง 860–1180 ภาพ 3D กินไม่เกิน 33% · ใบงานออกแบบใช้เกณฑ์เดิม
2. แผงชิ้นมีปุ่ม **ตั้งค่าขอบ: ติดซิป · กุ๊น · พับ · เผื่อรายขอบ** → เปลี่ยนเป็นเครื่องมือแก้ตะเข็บ (B) แล้วบอกให้กดขอบ
3. วางแม่แบบที่มีซับใน → กระดานเริ่มที่ **ชั้นนอก** (ซับในจางไว้) และข้อความบอกวิธีสลับ
4. วางแม่แบบลงแพทเทิร์นที่มีกระเป๋าเย็บไว้แล้ว → ข้อความบอกว่าภาพ 3 มิติประกอบได้ทีละ 1 ใบ แนะนำสร้างแพทเทิร์นใหม่
5. กล้องจัดตามตัวกระเป๋า (`SewnScene.bodyH` · ไม่เกิน 2.2 เท่าของความสูงตัว) — สายสะพายยาวไม่ทำให้กระเป๋าเล็ก (ส่วนบนของสายอาจเลยกรอบ ซูมออกดูได้) · **ทรงถัง: สายสะพายพาดข้ามปากถัง** (จุดติด `across` บนตัวถัง → กติกาทรงถังวาดสายเป็นโค้ง) ไม่วางแบนข้างหน้าแล้ว
6. แบบ แยกชิ้น / ทีละขั้น / ทิ้งตัว ในช่องภาพ 3D: กล่องโครงสร้างสูงไม่เกิน ~16 บรรทัด (เลื่อนในกล่อง) · ซ่อนกล่องสีตัวอย่าง

- ยังเหลือ (ไม่ได้แก้รอบนี้): ซิปบนชิ้นโค้ง (ดัฟเฟิล แถบซิป) ยังไม่ขึ้นในภาพ · ภาพก้นกล่อง/หูรูด/กระเป๋าสตางค์ยังเป็นซองแบน · โหมดทิ้งตัวยังไม่จำลองชิ้นปิดปาก

## จอเดียว: ภาพ 3D คู่กับกระดาน + กดที่ว่าง = เลื่อนดู + ไอคอนที่หาย (2026-11-11)
เจ้าของสั่ง (ผ่าน session เอกสารเทียบ CLO · ดูภาพตัวอย่างแล้วตอบ "ทำตามแบบนี้"): "ตรง 3D กับวาดเย็บชิ้นต้องเปิดคู่กันสิ ไม่ใช่ดูแยก" · "เวลากดที่ว่างให้เปลี่ยน tool เป็นเลื่อนดู" · "icon ตรงเย็บหาย"

**1) จอเดียว (แอปสตูดิโอแพทเทิร์น — หน้าที่ส่ง `sew`)**
- ไม่มีแท็บ "วาดชิ้น + เย็บ | ประกอบ 3D" แล้ว · ภาพ 3D เปิดข้างกระดานตั้งแต่เข้าหน้า (จำค่าเปิด/ซ่อนในเครื่องด้วยกุญแจใหม่ `pattern-studio-3d-split` — ค่าที่เคยปิดไว้ของปุ่มเดิมไม่ตามมา)
- **ภาพ 3D ซ้าย กระดานขวา** (แบบ CLO) · เส้นแบ่งกลาง **ลากปรับความกว้าง** (22–60% · ดับเบิลคลิก = ค่าเริ่ม 38%) · ปุ่ม **สลับฝั่ง** · ปุ่ม **ซ่อนภาพ 3D** (แถบบนมีปุ่ม "เปิดภาพ 3D" กลับมา) — ฝั่งและความกว้างจำในเครื่อง
- หัวช่องภาพ 3D: **เย็บติดแล้ว** (ตามกระดานทันที) · **แยกชิ้น · ทีละขั้น · ทิ้งตัว** (= แท็บ "ประกอบ 3D" เดิม: `AssemblyView` แบบ `compact` + `view` · ใช้ชิ้นสดบนกระดาน ไม่ต้องบันทึกก่อน · ติดหู / ปิดหลังช่อง อยู่ในแบบ แยกชิ้น) · **ชิ้นแบน** · ผ่าดูข้างใน
- จอแคบ (กล่องกว้างไม่ถึง 1180px) = ภาพ 3D อยู่บน กระดานอยู่ล่าง
- ใบงานออกแบบ (ไม่ส่ง `sew`) **หน้าตาเดิม**: กระดานซ้าย · ภาพ 3D ขวา · เปิดเมื่อกดปุ่ม
- `StudioSew` เพิ่ม `onAttachesChange` · `pieceStiff` (หน้าแก้แพทเทิร์นส่งมา)

**2) กดที่ว่างบนกระดาน** (`ShapeEditor` — ใช้ร่วมกับแบบวาดในแท็บตีราคาของใบงานออกแบบ เปลี่ยนตามด้วย)
- ถือ **ย้าย** แล้วกด/ลากที่ว่าง → เลิกเลือก + เปลี่ยนเป็น **เลื่อนดู** + เลื่อนกระดานได้ในการกดครั้งเดียวกัน (เดิม: วาดชิ้นใหม่ด้วยเครื่องมือล่าสุด)
- ถือ **เลื่อนดู** แล้วกดบนชิ้น → เลือก/ย้ายชิ้นนั้นได้เลย (กลับเป็น ย้าย เอง) — ไม่ติดอยู่ในเลื่อนดู
- ถือ **สี่เหลี่ยม / วงรี**: ลากที่ว่าง = วาดชิ้นใหม่เหมือนเดิม · คลิกเฉย ๆ ไม่ลาก = เปลี่ยนเป็นเลื่อนดู
- ถือ **ปากกา**: เหมือนเดิม (คลิก = วางจุด) — ไม่เปลี่ยนเป็นเลื่อนดู
- ถือ **เครื่องมือเย็บ (N J K B)**: กด/ลากตรงที่ไม่ใช่ขอบหรือตะเข็บ = เลื่อนกระดาน เครื่องมือเดิม · **เส้นใน (L)**: กดนอกชิ้น = เลื่อนกระดาน · **ไม้บรรทัด วัดตามขอบ**: กดนอกชิ้น = เลื่อนกระดาน
- ⚠️ ไม้บรรทัดแบบ วัดตรง / วัดโค้ง: ลากที่ว่าง = วัด เหมือนเดิม (การลากคือการวัด) — เลื่อนกระดานด้วย Space+ลาก / ปุ่มกลางเมาส์ / เครื่องมือเลื่อนดู (H)
- Shift+ลากที่ว่าง = กรอบเลือก คงเดิม

**3) ไอคอนที่หาย** — ชื่อไอคอนที่ไม่มีในชุด = ปุ่มว่าง ไม่มี error · พบ 7 ตัว (ไม่ใช่ 2): `line-dashed` (เย็บบางช่วง) · `arrows-split-2` (เย็บ 1 ขอบกับหลายชิ้น) · `line` (เส้นในชิ้น) · `layers-subtract` (สร้างซับใน) · `square-plus` (เพิ่มช่อง) · `wind` (ทิ้งตัว) · `checks` (หน้าต่างแกะจากรูป) → เพิ่มเข้า `lib/erp-icons.ts` ครบ
- ก่อนใช้ชื่อไอคอนใหม่ในสตูดิโอ ให้ตรวจว่าชื่อนั้นมีใน `lib/erp-icons.ts` / `lib/website-icons.ts`

## ซิปและอะไหล่ → ส่งไปตีราคา (2026-11-11)
เจ้าของสั่ง "ทำต่อเลย" — โจทย์: ต้นทุนจากแพทเทิร์นต้องมีของที่ไม่ใช่ชิ้นตัดด้วย (ซิป · สาย/เทป · ห่วง ล็อก หมุด) · ไม่มีฐานข้อมูลใหม่ (เก็บในช่อง `template.trims` ของแพทเทิร์น)

- **ปุ่ม "ซิป / อะไหล่"** บนหัวหน้าแก้แพทเทิร์น (แอปสตูดิโอแพทเทิร์น) → `TrimsModal` (`components/pattern-studio/trims-modal.tsx`) · ป้ายบนปุ่ม: จำนวนรายการ + "ขาด N" = ช่องซิปที่ยังไม่เลือกซิป
  1. **ซิปของช่องเจาะ** — ทุกเส้นในชนิด "ช่องเจาะ (ซิป)" ขึ้นให้เอง → เลือกซิป + เผื่อปลาย (ตั้งต้น 2 ซม.) · ยาว = ความยาวช่อง + เผื่อปลาย · จำนวน = จำนวนตัดของชิ้น · **แก้ช่องบนกระดาน ความยาวซิปเปลี่ยนตามเอง** · ลบช่อง = แถวหายตอนบันทึก
  2. **อะไหล่ / สาย / ซิปอื่น** — เพิ่มเอง: วัสดุคิดตามยาว = ยาวต่อเส้น × จำนวน · วัสดุนับชิ้น = จำนวน · ใส่ป้าย "ใช้ตรงไหน" ได้
  3. **รวมต่อกระเป๋า 1 ใบ** ตามวัสดุ = สิ่งที่จะไปเป็นบรรทัดตีราคา
- **วัสดุ** = รายการวัสดุตีราคาเดียวกับของชิ้น (`design_price_items`) — เฉพาะกลุ่มที่ **คิดตามความยาว** หรือ **นับชิ้น** (`material_groups.calc_method` = `length` / `count` · ตอนนี้คือกลุ่ม ซิป · สาย/เทป · อะไหล่) · `/api/pattern-projects/materials` ส่ง `calc` เพิ่ม (ยังไม่ส่งราคา)
- **ส่งไปตีราคา** (ปุ่มเดิม · `POST /api/pattern-projects/<id>/costing`): ซิป/อะไหล่ไปพร้อมชิ้น — **1 วัสดุ = 1 บรรทัด** (รวมความยาว/จำนวนทั้งใบ) ไม่มีรูปทรง จึงไม่ขึ้นเป็นชิ้นบนกระดานของแท็บตีราคา
  - ตามยาว → ช่อง "ยาว (ซม.)" · นับชิ้น → ช่อง "จำนวน" · ปริมาณ/ยอดเงินใช้สูตรเดิมของตีราคา (เผื่อเสียและตัวหารตามกลุ่มวัสดุ)
  - หน้าตัวอย่างก่อนส่งโชว์ทีละบรรทัด: เพิ่ม/อัปเดต · ความยาวหรือจำนวน · ยอดเงิน + คำเตือน (ช่องซิปยังไม่เลือกซิป · ยังไม่ใส่ความยาว · วัสดุถูกย้ายกลุ่ม · วัสดุไม่อยู่ในรายการแล้ว)
  - **ส่งซ้ำ = อัปเดตบรรทัดเดิม** จับคู่ด้วย วัสดุ + ป้าย `[แพทเทิร์น <เลขที่>]` ในหมายเหตุของบรรทัด (บรรทัดอะไหล่ไม่มีรหัสชิ้นให้จับ) → ราคาและหมายเหตุเดิมไม่เปลี่ยน · ⚠️ ลบป้ายนี้ออกจากหมายเหตุ = ส่งครั้งหน้าจะเพิ่มบรรทัดใหม่
  - **ไม่ลบบรรทัดไหนเลย** — เอาวัสดุออกจากรายการแล้วส่งซ้ำ บรรทัดเดิมยังอยู่ (หน้าตัวอย่างบอกจำนวน ให้ไปลบเองในตีราคา) · บรรทัดที่เพิ่มเองในตีราคา (ไม่มีป้าย) ไม่ถูกแตะ แม้เป็นวัสดุเดียวกัน
- **ใบพิมพ์แพทเทิร์น** มีตาราง "ซิปและอะไหล่ (ต่อกระเป๋า 1 ใบ)"
- ช่อง `template` ของแพทเทิร์น: ขนาดสูงสุดเพิ่มเป็น 30,000 ตัวอักษร และ **เกิน = แจ้งให้ลดรายการ** (เดิมเกิน 12,000 = ล้างทั้งช่องเงียบ ๆ) · รายการซิป/อะไหล่สูงสุด 40 แถว
- สูตรทั้งหมด `lib/pattern-trims.ts` (`cleanTrims` · `slitList` · `zipEdgeList` · `bindRuns` · `trimRows` · `trimTotals` · `openTrims` · `pruneTrims` · `planTrimsSend`) · เทสต์ `lib/__tests__/pattern-trims.test.ts`

  - **ติดซิปตามขอบนี้** = ค่าของขอบตัวใหม่ (`EdgeMeta.zip` · อยู่คู่กับ "กุ้นขอบ" ในแผงค่าของขอบ — เครื่องมือ **แก้ตะเข็บ (B)** → กดขอบ) → ขอบนั้นขึ้นในหน้าต่างซิป/อะไหล่ ข้อ 1 ให้เลือกซิป · ยาว = ความยาวขอบ + เผื่อ (ตั้งต้น 0) · **จำนวนใส่เอง ตั้งต้น 1 ไม่คูณจำนวนตัดของชิ้น** (ซิปปากกระเป๋า 1 เส้นติดกับขอบของ 2 ชิ้น → ติ๊กขอบเดียว) · ยืด/หดขอบ ซิปยาวตามเอง · เลิกติ๊ก = แถวหายตอนบันทึก
  - **กุ๊น / หุ้มขอบ** = ข้อ 2 ของหน้าต่าง · 1 แถวทั้งใบ: ขอบที่ติ๊ก "กุ้นขอบ" (× จำนวนตัดของชิ้น) + ตะเข็บที่วิธีเย็บ = "หุ้มขอบ" (นับครั้งเดียว ใช้ด้านที่ยาวกว่า) · ขอบที่อยู่ในตะเข็บหุ้มขอบทั้งขอบแล้วไม่นับซ้ำ · + "เผื่อเพิ่มรวม" (ซม.) → เลือกเทปกุ๊น (วัสดุคิดตามยาว)

  - ช่วงสั้นสุด 0.5 ซม. · ช่วงครอบทั้งขอบ = กลับเป็นทั้งขอบ · ขอบถูกทำให้สั้นลงจนช่วงเลยปลาย = เลื่อนช่วงกลับเข้ามา (คงความยาวช่วง) · ขอบสั้นกว่าช่วง = ทั้งขอบ
  - ⚠️ ขอบละ 1 ช่วงต่อชนิด (ซิป 1 ช่วง + กุ๊น 1 ช่วง) · ต้นขอบ = จุดเริ่มของขอบตามลำดับที่วาด (ไม่รู้ว่าปลายไหน ดูจากภาพบนกระดาน แล้วกด สลับไปอีกปลาย) · ยังลากช่วงบนกระดานไม่ได้ (ใช้ช่องตัวเลข)

## นำเข้าแพทเทิร์นจากไฟล์ DXF (2026-11-11)
เจ้าของสั่ง "ทำต่อเลย" — โจทย์: ย้ายแพทเทิร์นเก่าที่ทำไว้ใน CLO3D เข้ามา ไม่ต้องวาดใหม่ · ไม่มีฐานข้อมูลใหม่ · ไม่ได้ลงไลบรารีเพิ่ม (ค้นแล้วในระบบมีแต่ตัวส่งออก DXF ไม่มีตัวอ่าน)

- **ปุ่ม "นำเข้า DXF"** บนแถบของสตูดิโอ (ทั้งแอปสตูดิโอแพทเทิร์นและแท็บตีราคาของใบงานออกแบบ) → `DxfModal`: เลือก/ลากไฟล์ `.dxf` → อ่านในเครื่อง (ไม่อัปโหลด) → เห็นภาพชิ้น + รายการ (ชื่อ · ขนาด · ตัดกี่ชิ้น · กี่ขอบ · เผื่อเย็บ) → เลือกหน่วย (มม. / ซม. / นิ้ว) → **วางลงกระดาน** (ต่อจากขวาสุดของชิ้นเดิม เรียงตามตำแหน่งในไฟล์ · ย้อนกลับได้)
- **ตัวอ่าน** `lib/pattern-dxf-import.ts` (`parseDxfPattern`) — DXF แบบข้อความ (ASCII) 2 แบบ:
  - แบบโรงงานเสื้อผ้า AAMA / ASTM (ที่ CLO3D ส่งออก): 1 ชิ้น = 1 บล็อก · ชั้น 1 = เส้นตัด · 14 = เส้นเย็บ · 8 = เส้นใน · 4 = รอยบาก · 7 = เส้นทางผ้า · ข้อความ `Piece Name:` / `Quantity:`
  - แบบเส้นล้วน รวมไฟล์ที่ระบบนี้ส่งออกเอง: ชั้น CUT / SEW / HOLE / INNER / FOLD / NOTCH / GRAIN / LABEL · ชั้นที่ไม่รู้จัก = เส้นตัด
  - อ่านเส้นชนิด LINE · POLYLINE · LWPOLYLINE (รวมส่วนโค้ง bulge) · CIRCLE · ARC · ELLIPSE · SPLINE (ใช้จุดควบคุมแทน — ใกล้เคียง ไม่เป๊ะ) · POINT · TEXT · INSERT
- **ได้อะไร**: รูปชิ้น = เส้นเย็บ (ไม่มีเส้นเย็บ = ใช้เส้นตัด) · เผื่อเย็บ = ระยะระหว่างเส้นตัดกับเส้นเย็บ (ไม่เท่ากันทุกด้าน = ใช้ค่าน้อยสุด + เตือน) · รูเจาะ · เส้นใน (เฉพาะแอปสตูดิโอแพทเทิร์น) · รอยบาก · เส้นทางผ้า · ชื่อชิ้น · จำนวนตัด
- **เส้นโค้งกลับมาเป็นขอบโค้ง 1 ขอบ**: DXF เก็บเส้นโค้งเป็นจุดถี่ ๆ → `loopShape` หามุม (หักเกิน 30°) แล้วหาเส้นโค้งที่ทับจุดเดิม (คลาดไม่เกิน 0.4 มม.) → ตัวหน้าทรงโค้งได้ราว 8 ขอบ ไม่ใช่จุดย่อยเป็นร้อย → เย็บขอบกับขอบได้ · สี่เหลี่ยมตรงแกน = สี่เหลี่ยม 4 ขอบ
- **หน่วย**: อ่านจากหัวไฟล์ (`$INSUNITS`) ถ้ามี · ไม่มี = เริ่มที่มิลลิเมตร และหน้าต่างบอกให้ตรวจขนาดชิ้น
- ⚠️ **ยังไม่ได้ทดสอบกับไฟล์ที่ส่งออกจาก CLO3D ของโรงงานจริง** — ทำจากรูปแบบมาตรฐาน + ทดสอบไป-กลับกับไฟล์ที่ระบบนี้ส่งออกเอง · ถ้าไฟล์จริงอ่านไม่ได้/ชิ้นเพี้ยน ให้ส่งไฟล์มาปรับตัวอ่าน
- ไม่ได้: ตะเข็บ (DXF ไม่มีข้อมูลว่าขอบไหนเย็บกับขอบไหน) · วัสดุ · หลายไซซ์ · DXF แบบไบนารี · เผื่อเย็บรายขอบ · ไฟล์เกิน 8 MB

## ชิ้นคู่ผูกกัน (2026-11-11)
เจ้าของสั่ง "ทำต่อเลย" — โจทย์: แก้ตัวนอกแล้วซับในตาม · ชิ้นคู่ซ้าย/ขวา แก้ตัวเดียวอีกตัวตาม · ไม่มีฐานข้อมูลใหม่ (`ProjectPiece.link`)

- **ชิ้นตาม** = ชิ้นที่มี `link { to, mirror? }` (`lib/pattern-link.ts`): รูปเส้นรอบของมันมาจาก **ชิ้นต้นแบบ** เสมอ — ลากจุด / ย่อขยาย / พิมพ์ความยาวขอบ / หมุน ที่ต้นแบบ ชิ้นตามเปลี่ยนตามทันที (รวมระหว่างลาก)
  - ตามเฉพาะ **รูปเส้นรอบ** · ของชิ้นตามเอง: ตำแหน่ง ชื่อ วัสดุ ชนิดชิ้น จำนวนตัด เผื่อเย็บ รูเจาะ รอยบาก เส้นใน (ช่องใส่ของบนซับในไม่ไปโผล่บนตัวนอก)
  - ชิ้นตามอยู่กับที่ (มุมซ้ายบนของกรอบไม่ขยับ) · ย้ายเองได้ · แก้รูปของชิ้นตามตรง ๆ จะเด้งกลับ → ต้อง "เลิกผูก" ก่อน
  - `mirror "x"` = กลับซ้ายขวา · ห้ามผูกเป็นทอด · ต้นแบบถูกลบ = ชิ้นตามเลิกผูกเอง (รูปคงเดิม)
- **กระดาน** (prop `pieceLinks` · ใบงานออกแบบไม่ส่ง): แผงของชิ้นมีหัวข้อ "ชิ้นคู่ผูกกัน" — ปุ่ม **+ สร้างชิ้นคู่ (ผูก)** (กลับซ้ายขวา วางข้าง ๆ) · เลือก "ผูกรูปกับชิ้น…" · ติ๊กกลับซ้ายขวา · **เลิกผูก** · บอกว่าชิ้นนี้ตามใคร / เป็นต้นแบบของใคร
- **สร้างซับใน** ผูกชิ้นซับในกับตัวนอกให้เอง → แก้ตัวนอกแล้วซับในเปลี่ยนตาม
- ซิงก์ด้วย `applyLinks()` ใน effect ของกระดาน: คืนรายการเดิมถ้าไม่มีอะไรเปลี่ยน (ไม่วน) · ไม่บันทึกเป็นขั้นย้อนกลับแยก → Ctrl+Z การแก้ต้นแบบ ชิ้นตามย้อนด้วย
- บันทึก: `cleanProjectPieces` เก็บการผูกเฉพาะที่ต้นแบบมีอยู่จริงและไม่ใช่ชิ้นตามของใคร
- **ตะเข็บตามชิ้นคู่** (เพิ่ม 2026-11-11 · `followerSeams` ใน `lib/pattern-link.ts`): คัดลอกตะเข็บของชิ้นต้นแบบให้ชิ้นตาม **ครั้งละชุด** (ไม่ได้ผูกตลอดเวลา)
  - ปุ่ม **+ สร้างชิ้นคู่ (ผูก)** ทำให้เองหลังสร้าง · ชิ้นตามที่มีอยู่แล้วกด **เย็บตามต้นแบบ** ในแผงของชิ้น
  - ตะเข็บของต้นแบบ (ต้นแบบ ↔ ชิ้นอื่น) → ชิ้นตาม ↔ คู่ของชิ้นอื่น: ชิ้นอื่นมีชิ้นตามแบบเดียวกัน (ชุดซับใน / ชุดซ้าย-ขวา) = เย็บกับตัวนั้น · ไม่มีและชิ้นตามเป็นแบบกลับซ้ายขวา = เย็บกับ **ขอบฝั่งตรงข้ามของชิ้นอื่นตัวเดิม** (หาจากภาพสะท้อนของขอบ — ชิ้นอื่นต้องสมมาตรซ้ายขวา)

## เย็บ 1 ขอบกับหลายชิ้น (2026-11-11)
เจ้าของสั่ง "ทำต่อเลย" (ข้อที่ค้างจากรายการเลิกใช้ CLO3D) — โจทย์: ขอบยาวขอบเดียวมีหลายชิ้นมาต่อกัน เช่น ชิ้นข้าง + ก้น + ข้าง รอบตัวหน้า · แถบซิป + แถบก้น รอบกระเป๋ากลม · ไม่มีฐานข้อมูลใหม่

- **เครื่องมือ "เย็บ 1 ขอบกับหลายชิ้น" (K)** บนกระดาน: กดขอบหลักตรงปลายที่ชิ้นแรกจะเริ่ม → กดขอบของแต่ละชิ้นตามลำดับ ระบบวางช่วงต่อกันไปตามขอบหลัก ยาวเท่าขอบของชิ้นนั้น · ครบทั้งขอบ = จบเอง · Enter / Esc = จบก่อน
  - กดใกล้ปลายไหนของขอบหลัก ระบบไล่ช่วงออกจากปลายนั้น (ผู้ใช้ไม่ต้องรู้ว่าขอบเริ่มนับจากด้านไหน) · กดใกล้ปลายของช่วงที่เย็บไว้แล้ว = ต่อจากของเดิม
  - ชิ้นยาวเกินที่เหลือ = ไม่เย็บ + บอกว่าเหลือเท่าไร (ห้ามปรับขนาดชิ้นเอง)
- **ข้อมูล**: ยังเป็นตะเข็บบางช่วงธรรมดา (ย้าย / ยืดหด / ลบ ทีละแนวได้เหมือนเดิม) + `Seam.group` = รหัสชุดของการเย็บรอบนั้น
- **จำนวนตัด 2 ชิ้น** (เช่น ตัวหน้า/ตัวหลังชิ้นเดียวกัน): ช่วงเดียวกันของขอบเย็บซ้ำได้เท่าจำนวนตัด (`rangeFree(busy, a, b, cap)`) → เย็บรอบแรกให้ตัวหน้า รอบสองให้ตัวหลัง · ใช้กับการลากย้าย/พิมพ์ช่วงด้วย
- **ตัวประกอบ 3D เข้าใจ**: `assemble()` ใช้ตะเข็บที่มี `group` หาชิ้นคั่นกลางได้ (ด้านของชิ้นคั่นกลางต้องเป็นขอบเต็ม) → ชิ้นคั่นกลางหลายชิ้นต่อกันรอบแผ่นเดียวขึ้นเป็นกระเป๋าได้ ทั้งภาพข้างกระดานและแท็บประกอบ 3D / ตัวจำลอง
  - ตะเข็บบางช่วงที่ไม่มี `group` (เครื่องมือ J เช่น โคนหู) ยังไม่ถูกใช้หาทรงเหมือนเดิม — กันสายหูถูกเข้าใจผิดว่าเป็นชิ้นข้าง
- ⚠️ ข้อจำกัด: ช่วงข้ามจุดเริ่มของขอบปิด (วงกลม) ไม่ได้ — ชิ้นที่คร่อมจุดเริ่มต้องเริ่มเย็บจากจุดเริ่มของวง · ขอบหลักต้องเป็นขอบเดียว (ยังไม่รองรับขอบหลักที่เป็นหลายขอบติดกัน) · ยังไม่แบ่งความยาวตามสัดส่วนให้อัตโนมัติเมื่อรวมกันไม่พอดี (CLO ทำได้) — ระบบแค่บอกส่วนที่เหลือ

## งานข้างในกระเป๋า: เส้นในชิ้น + เย็บกับเส้นใน + ซับใน + ช่องใส่ของ / ช่องซิป + ผ่าดูข้างใน (2026-11-11)
เจ้าของตั้งเป้า "อยากเลิกใช้ CLO3D มาใช้อันนี้แทน" → ขอเส้นในชิ้น / เย็บกับเส้นใน / ซับในมีช่องใส่ของ ช่องซิป · ดูภาพตัวอย่างแล้วสั่ง "ทำตามแบบนี้" · ไม่มีฐานข้อมูลใหม่ (เก็บในชิ้นและตะเข็บเดิม)

**เส้นในชิ้น** (`InnerLine` ใน `lib/pattern-shape.ts` · `ProjectPiece.inner`)
- เส้นที่อยู่ข้างในชิ้น ไม่ใช่เส้นตัด: `sew` แนวเย็บ · `slit` ช่องเจาะ (ซิป) · `fold` แนวพับ · `mark` ตำแหน่ง — เป็น "เครื่องหมายของชิ้น" แบบเดียวกับรอยบาก/เส้นทางผ้า (`mapMarks`) → ย้าย ย่อขยาย หมุน กลับด้านชิ้น เส้นในไปตามชิ้นเอง
- กระดาน (เปิดด้วย prop `innerLines` · ใบงานออกแบบไม่ส่ง): เครื่องมือ **เส้นในชิ้น (L)** กด 2 จุดข้างในชิ้น = เส้นตรง 1 เส้น (Shift = 45°) · แผงของชิ้นมีรายการเส้นใน (ตั้งชนิด · ลบ · บอกว่าเย็บแล้วหรือยัง)
- ใบพิมพ์: วาดเป็นเส้นประสั้นสีน้ำเงิน (`innerD`) · ไฟล์ตัด DXF ชั้น **INNER** · SVG มีเส้นประ — เครื่องตัดต้องตั้งให้ "วาด/ไม่ตัด" ชั้นนี้

**เย็บกับเส้นในชิ้น** (`SeamSide.inner` = รหัสเส้นใน)
- ด้านของตะเข็บ = เส้นในทั้งเส้น (ไม่ใช้ลำดับขอบ) · ฟังก์ชันตะเข็บรับ "รูปชิ้น" ได้ 2 แบบ: `Shape` หรือ `{ shape, inner }` (`SeamPiece`) — ต้องส่งแบบหลังถ้าอยากให้ด้านบนเส้นในหาเส้นเจอ (ไม่งั้นขึ้น "ต้องเย็บใหม่")
- ด้านบนเส้นในไม่กินขอบของชิ้น (`edgeBusy` ข้าม) · นับเป็นตะเข็บบางช่วง → `assemble()` ไม่ใช้หาทรง · ยังปรับช่วงของด้านนี้ไม่ได้ (ทั้งเส้นเสมอ)
- เครื่องมือเย็บ N / B กดเส้นในได้ (เย็บกับขอบ หรือเส้นในของอีกชิ้น) · เครื่องมือ J: หลังเลือกช่วงแรกแล้ว กดเส้นในเป็นด้านที่สองได้

**ชั้นซับใน** = ชิ้นที่ `info.role = "lining"` (ชนิดชิ้นเดิม ไม่มีช่องใหม่)
- `AsmPiece.layer = "lining"` · `assemble(pieces, seams, attaches, "lining")` ประกอบซับในแยกจากตัวนอก · `assemble()` ปกติ (ชั้นนอก) ไม่เห็นชิ้นซับในเลย → แท็บประกอบ / ตัวจำลองของตัวนอกเหมือนเดิม
- ปุ่ม **สร้างซับใน** (PatternStudio · `liningPlan`): คัดลอกแผ่นหน้า/หลัง + ชิ้นคั่นกลางที่ระบบประกอบได้ เป็นชิ้นชั้นซับใน **ขนาดเท่าตัวนอก** พร้อมตะเข็บชุดเดียวกัน วางใต้ชิ้นเดิม · มีซับในอยู่แล้ว = ไม่สร้างซ้ำ
  - ไม่ย่อขนาดให้ (ย่อแล้วขอบที่เย็บคู่กันยาวไม่เท่ากัน) · ไม่สร้างตะเข็บปากซับใน–ปากตัวนอก (จะกินขอบปากทั้งขอบ ทำให้เย็บโคนหูบางช่วงไม่ได้) — ระบบถือว่าซับในเย็บกับตัวนอกรอบปาก
- กระดาน: ปุ่มสลับ **ทุกชั้น / ชั้นนอก / ซับใน** (`hidePids` → ชิ้นของชั้นอื่นจางและกดไม่ได้)

**ตัวช่วยเพิ่มช่อง** (ปุ่ม **เพิ่มช่อง** → `PocketModal` · `pocketPlan`) — ช่องอยู่กึ่งกลางซ้ายขวาของชิ้นที่เลือก · "ต่ำจากขอบบน" วัดจากขอบบนของชิ้นบนกระดาน
- **ช่องใส่ของ**: เส้นใน `sew` รูปตัว U (3 ด้าน) + ชิ้นปะ กว้าง × ลึก ที่ขอบบนเผื่อพับ 2 ซม. + ตะเข็บ 1 แนว (ขอบขวา-ล่าง-ซ้ายของชิ้นปะ กับเส้นใน · ยาวเท่ากันพอดี)
- **ช่องซิป**: เส้นใน `slit` ยาวเท่าซิป + ถุงช่องซิป กว้างกว่าซิปข้างละ 1 ซม. ยาว 2 เท่าของความลึก มีเส้นใน `fold` ตรงกลาง + ตะเข็บ 1 แนว (ช่วงกลางของขอบบนของถุง กับช่องเจาะ)
- ทุกอย่างเป็นของจริงบนกระดาน (แก้ต่อ / ย้อนกลับได้ในครั้งเดียว — `inject.inner` + `inject.pieces`) · ⚠️ ซิปยังไม่ถูกส่งไปตีราคาเอง (ต้องใส่เป็นบรรทัดวัสดุในใบตีราคาเอง)

**ภาพ 3 มิติ** (`buildSewn` → `SewnScene.lining / marks` · `Pattern3D` `cut`)
- ซับในที่ประกอบได้ = ถุงอีกใบสีซับใน ย่อ 3.5% ซ้อนอยู่ข้างในตัวนอก (ย่อเฉพาะในภาพ) · แผ่นหน้า/หลังของซับในเป็นชิ้นเดียวกัน (ตัด 2) = ช่องไปอยู่ที่แผ่นหลัง
- ชิ้นที่เย็บกับเส้นใน = **ชิ้นปะ** (`kind "patch"`) แนบผิวแผ่นที่เกาะ: เส้นใน `sew` = ด้านที่มองเห็น (ซับใน = ด้านในกระเป๋า · ตัวนอก = ด้านนอก) · เส้นใน `slit` = ด้านหลังแผ่น (ถุงช่องซิปอยู่ระหว่างซับในกับตัวนอก) · ชิ้นที่มีเส้นใน `fold` = ทบกลับตรงแนวพับ
- ช่องเจาะ (ซิป) วาดเป็นเส้นสีส้มบนแผ่น
- **ผ่าดูข้างใน**: ดูข้างนอก / ผ่าด้านหน้า / ผ่าด้านหลัง (ตัดทุกอย่างที่เลยระนาบใกล้แผ่นฝั่งนั้นออกจากภาพ · ผ่าด้านหลัง = หมุนไปมองจากข้างหลัง) — มีทั้งข้างกระดานและในแท็บประกอบ 3D
- แท็บประกอบ 3D: ขั้นสุดท้าย **ใส่ซับใน** (`AsmStepKey "lining"`) — ซับใน + ช่องที่เกาะซับใน ลอยอยู่เหนือกระเป๋าจนกว่าจะถึงขั้นนี้
- ⚠️ ข้อจำกัด: ถุงช่องซิปอยู่หลังซับใน จึงมองไม่เห็นจากข้างใน (เห็นแต่เส้นซิป) · ซับในประกอบได้เฉพาะโครงเดียวกับตัวนอก (หน้า + หลัง + ชิ้นคั่นกลาง / ซองแบน) · ตัวจำลองวัสดุทิ้งตัวยังไม่รวมซับใน · ช่องที่ตัวช่วยสร้างอยู่กึ่งกลางซ้ายขวา (ย้ายทีหลังได้ — ดูหัวข้อ "ย้ายเส้นใน + พิมพ์ระยะจากขอบ") · เส้นในวาดเองได้แค่เส้นตรง 2 จุด
- ยังไม่ได้ทำในรอบนี้: ส่งซิป/อะไหล่ไปตีราคา · ลากย้ายเส้นใน (เย็บ 1 ขอบกับหลายชิ้น ทำแล้วในหัวข้อบน)

## เย็บบางช่วงของขอบ + ย้ายตะเข็บหลังเย็บ + ภาพ 3 มิติ "เย็บติดแล้ว" (2026-11-11)
เจ้าของดูภาพตัวอย่าง 3 ชุดแล้วสั่ง "ทำตามแบบนี้" — โจทย์: ชิ้นเล็กติดกับส่วนหนึ่งของขอบยาว (โคนหูบนขอบปาก) · ปรับจุดได้หลังวาด · ภาพ 3D ต้องเป็นตอนเย็บติดแล้วและเปลี่ยนตามทันที · ไม่มีฐานข้อมูลใหม่ (เก็บในตะเข็บเดิม)

**ข้อมูล** (`lib/pattern-seams.ts`)
- `SeamSide.t0 / t1` = เย็บแค่ช่วงนั้นของด้าน (ซม. จากจุดเริ่มของด้าน ตามแนวเส้น) · ไม่มี = เย็บเต็มด้านเหมือนเดิม → ตะเข็บเก่าทั้งหมดไม่เปลี่ยน
- ขอบเดียวมีได้หลายตะเข็บ ห้ามทับกัน (`edgeBusy` + `rangeFree` · ชนปลายกันได้) · `rangedSide` คลุมทั้งขอบ = กลับเป็นด้านเต็มขอบ
- `sidePoints` / `sideLength` / `checkSeam` คิดจากช่วงที่เย็บ · ชิ้นถูกแก้จนขอบสั้นกว่าช่วง = ตัดช่วงให้อยู่บนขอบ · ไม่เหลือช่วง = "ต้องเย็บใหม่" · `sideFullPoints` = เส้นเต็มด้าน
- `Seam.ease` = ตั้งใจให้สองด้านยาวต่างกัน (รูด / ย่น) → สีส้ม ไม่นับเป็นตะเข็บที่ต้องแก้ · ใบพิมพ์เขียน "ตั้งใจให้ย่น"
- `assemble()` (ประกอบทรงตามกติกา · แท็บประกอบ 3D · ตัวจำลอง) **ใช้เฉพาะตะเข็บเต็มขอบ** — ตะเข็บบางช่วงถูกข้าม

**เครื่องมือบนกระดาน** (`ShapeEditor` · เฉพาะหน้าที่ส่ง `seams`)
- **เย็บบางช่วงของขอบ (J)**: กดจุดเริ่ม → จุดจบบนขอบเดียวกัน → จุดเริ่มบนขอบของอีกชิ้น ระบบวางด้านที่สองให้ยาวเท่าช่วงแรก (ขอบที่สองสั้นกว่า = เย็บเต็มขอบให้ + เตือน) · จุดลงล็อกทีละ 0.5 ซม. และดูดเข้าปลายขอบ
- **ย้าย/ปรับหลังเย็บ** (เครื่องมือ J และ B): กดเส้นตะเข็บ = เลือก · ลากเส้น = ย้ายทั้งช่วง · ลากจุดกลมที่ปลาย = ยืด/หด (ด้านเต็มขอบลากจุดปลาย = กลายเป็นบางช่วง) · ลากข้ามตะเข็บอื่นได้ (ไม่ยอมให้ทับ) · Ctrl+Z ย้อนได้ 1 ครั้งต่อการลาก
- แผงขวาของตะเข็บที่เลือก: "เริ่มที่ / ยาว" ของแต่ละด้าน · ปุ่ม "เต็มขอบ" · ปุ่ม "ให้ด้านที่ 2 ยาวเท่าด้านที่ 1" (และกลับกัน) · ติ๊ก "ตั้งใจให้ต่างกัน (รูด / ย่น)"
- ด้านที่เป็นหลายขอบติดกัน (Shift+คลิกของเครื่องมือ N) ยังปรับช่วงไม่ได้

**ภาพ 3 มิติ "เย็บติดแล้ว"** (`lib/pattern-sewn.ts` `buildSewn` → `Pattern3D mode="sewn"` · ปุ่มสลับ "เย็บติดแล้ว | ชิ้นแบน" ข้างปุ่มดูภาพ 3D · จำในเครื่อง)
คิดใหม่ทุกครั้งที่ชิ้น/ตะเข็บเปลี่ยน (ระหว่างลากด้วย) · ตาข่ายของชิ้นจำไว้ตามรูปชิ้น → ลากตะเข็บไม่ต้องแตกตาข่ายใหม่ · กล้องไม่กระโดดระหว่างลาก
1. **ตัวกระเป๋า**: ตะเข็บเต็มขอบประกอบเป็นทรงได้ (`assemble`) = ใช้ทรงนั้น (รวมหูจากจุดติดของแม่แบบ) · ไม่ได้ = ตั้ง "ชิ้นหลัก" (ชิ้นใหญ่สุดที่มีตะเข็บ) เป็นแผ่นตั้ง
2. **ชิ้นที่เย็บ 1 ตะเข็บ** กับแผ่นที่วางแล้ว = แผ่นพับเกาะที่ตะเข็บ ยื่นออกนอกแผ่น เอนเข้าในเล็กน้อย (ยาวไม่เท่ากัน = จัดกึ่งกลางช่วง) · ชิ้นที่ยื่นเกิน 12 ซม. และเย็บที่ขอบบน = ห้อยลงมาด้านนอก ส่วนที่ยาวถึงพื้นวางราบ · แผ่นพับเป็นที่เกาะของชิ้นถัดไปได้
3. **ชิ้นที่เย็บ 2 ตะเข็บ** (ปลายสองข้าง เช่น สายหู) = ห่วงโค้งระหว่างสองโคน ยาวเท่าระยะจริงระหว่างสองปลายของชิ้น · แถบบิดให้ราบกับแผ่นที่โคน และโค้งรอบแกนความกว้างตรงกลาง · สายสั้นกว่าระยะระหว่างโคน = ขึงตรง + เตือน "ยาวไม่ถึง"
4. **ที่เหลือ** วางแบนข้างหน้า + หมายเหตุใต้ภาพ: "ยังไม่ได้เย็บ" / "ยังประกอบชิ้นนี้ในภาพไม่ได้" (เย็บ 3 จุดขึ้นไป · เย็บกับชิ้นที่ยังไม่ได้วาง · เย็บกับตัวเอง · เย็บกับชิ้นข้าง/ก้นของตัวกระเป๋า · ด้านที่วนทั้งรอบ)
- เส้นตะเข็บในภาพใช้สีเดียวกับบนกระดาน · ยาวไม่เท่ากันและไม่ได้ตั้งใจ = เส้นแดงหนา
- ยังไม่มีอะไรเย็บติด = ภาพเป็นชิ้นแบนเหมือนเดิม + บอกว่าให้ใช้เครื่องมือเย็บ
- ⚠️ **วางตามสูตร ไม่ใช่การจำลองผ้า**: ตำแหน่งและสัดส่วนถูก การทิ้งตัวเป็นค่าประมาณ · ทิศ "กลับทิศ" ของตะเข็บยังไม่มีผลกับภาพ (ระบบเลือกให้เนื้อชิ้นยื่นออกนอกแผ่นเสมอ) · ชิ้นที่ตั้งจำนวน 2 ขึ้นไปแสดงชิ้นเดียว
- **แท็บ "ประกอบ 3D" แสดงชิ้นที่เย็บบางช่วงด้วย** (เพิ่มรอบถัดมา 2026-11-11 · `AssemblyView` ใช้ `buildSewn`): มีชิ้นเสริม = ภาพใช้ `mode="sewn"` · "เย็บทีละขั้น" มีขั้น **ชิ้นเสริม** (`AsmStepKey "extra"`) แทรกก่อนเย็บชิ้นคั่นกลาง/แผ่นหลัง · ชิ้นเสริมและเส้นตะเข็บขยับตามแผ่นที่เกาะ (`SewnPart.on` / `SewnLine.on` → carrier) · "แยกชิ้นดู" ใช้ได้ · ไม่มีชิ้นเสริม = ภาพเดิมทุกอย่าง
  - ระบบยังไม่เห็นโครงตัวกระเป๋า แต่มีชิ้นเย็บติดกัน (เช่น ตัวหน้า + สายหู) = แสดงเฉพาะชิ้นที่เย็บติด + บอกเหตุผล (เดิมขึ้นหน้าว่าง)
  - ตัวจำลองวัสดุทิ้งตัวยังไม่รวมชิ้นเสริม (บอกไว้ในหน้าจอ)
- ใบงานออกแบบ (ไม่ส่ง `sew`) เหมือนเดิมทุกอย่าง: ไม่มีเครื่องมือเย็บ · ภาพ 3D เป็นชิ้นแบน

## แผงตั้งค่าแบบ CLO ก้อน 2: ค่าของชิ้น + ค่าของวัสดุ (2026-11-10)
เจ้าของสั่ง "ทำต่อเลย" หลังก้อนตะเข็บ + ขอบ — ไม่มีฐานข้อมูลใหม่ (ค่าของชิ้นเก็บในชิ้น · ค่าของวัสดุเก็บใน `template.matProps` ของแพทเทิร์นใบนั้น ไม่แตะข้อมูลวัสดุกลาง)

- **ค่าของชิ้น** (`ProjectPiece.info` · `cleanPieceInfo`) — หัวข้อ "ข้อมูลชิ้นและการอยู่ทรง" ในแผงชิ้น (เปิดด้วย `pieceInfoFields` · ใบงานออกแบบไม่มี):
  รหัสชิ้น · ชนิดชิ้น (ตัวกระเป๋า / ซับใน / ตัวเสริม / อะไหล่) · ติดแผ่นเสริม (ผ้ากาว / โฟม / กระดาษแข็ง) · ปาดขอบ (มม.) · **ชิ้นนี้แข็งอยู่ทรง** · ทิศทางผ้าพิมพ์เป็นองศาได้ (0 = แนวตั้ง)
- **ค่าของวัสดุ** (`MatProps` · `cleanMatProps` · ชุดสำเร็จ `MAT_PRESETS`) — ปุ่มตั้งค่าบนป้ายวัสดุของชิ้น: ชุดค่าสำเร็จ (หนัง PU · หนังแท้หนา · แคนวาสหนา · ไนลอน · ผ้าซับใน · PVC) · ความอยู่ทรง 0–1 · ความหนา มม. · สีในภาพ 3D ของชิ้นแบน — ใช้ทั้งแพทเทิร์นใบนั้น (ทุกชิ้นที่ใช้วัสดุนี้)
- **ตัวจำลองใช้ความอยู่ทรงรายชิ้น** (`pieceStiffness` → `SimParams.perPiece` · `SimMesh.vpid`): แข็งอยู่ทรง = 1 · ไม่งั้น = ค่าของวัสดุแรกที่ตั้งไว้ (ไม่มี = ค่ากลางจากแถบเลื่อน) + แผ่นเสริม (ผ้ากาว +0.2 · โฟม +0.15 อย่างน้อย 0.5 · กระดาษแข็ง อย่างน้อย 0.9) · แท็บประกอบ 3D แสดงรายการว่าแต่ละชิ้นใช้ค่าเท่าไรเพราะอะไร
- ใบพิมพ์ของแอป: ตาราง **รายละเอียดชิ้น** (รหัส · ชนิด · แผ่นเสริม · ปาดขอบ · อยู่ทรง) + รหัสชิ้นในช่องหมายเหตุของตารางชิ้น (`projectPieceRows`)
- ⚠️ ค่าทั้งหมดเป็น **ค่าประมาณให้เห็นภาพ** ไม่ใช่ค่าวัดจริงของวัสดุ · ความหนายังไม่มีผลกับภาพ (จดไว้ + รอใช้) · สีวัสดุใช้กับภาพชิ้นแบนข้างกระดาน ภาพประกอบ/ภาพจำลองยังใช้สีตัวอย่างเดิม · จงใจไม่ใส่: ชั้นนอก/ใน · รวมในใบสั่งตัด · น้ำหนัก · ผิว (ยังไม่มีอะไรใช้ค่า)
- ช่อง `template` ของแพทเทิร์นรับได้ถึง 12,000 ตัวอักษร (เดิม 4,000) เพราะเก็บ ค่าแม่แบบ + จุดติด + เป้าหมายตีราคา + ค่าวัสดุ

## แผงตั้งค่าแบบ CLO: ค่ารายตะเข็บ + ค่ารายขอบ (2026-11-10)
เจ้าของเปิด CLO3D ให้ดู (ถ่ายช่อง Property Editor ของ ชิ้น / เส้นเย็บ / Topstitch / Fabric) แล้วเลือก "ตะเข็บ + ขอบก่อน" จากภาพตัวอย่าง · เอกสารเทียบเต็ม: [pattern-studio-clo-gap.md](pattern-studio-clo-gap.md) (139 บทความคู่มือ CLO)

- เครื่องมือ **แก้ตะเข็บ (B)**: กดขอบไหนก็ได้ → แผงขวาแสดง **ค่าของขอบนั้น** และ **ค่าของตะเข็บ** ถ้าขอบนั้นเย็บไว้ (แบบ Property Editor ของ CLO ที่เปลี่ยนตามสิ่งที่เลือก)
- **ค่ารายตะเข็บ** (`Seam.name` / `kind` / `top` / `rev` · ตรวจด้วย `cleanSeams`): ชื่อตะเข็บ · วิธีเย็บ (เย็บกลับใน / เย็บทับ / หุ้มขอบ — `SEAM_KINDS`) · เดินด้ายทับ (ห่างจากตะเข็บ มม. · 1–2 แถว · ฝีเข็มต่อนิ้ว) · กลับทิศ · ลบ
- **ค่ารายขอบ**: ความยาวขอบพิมพ์ตัวเลขได้ (`setEdgeLength` — สี่เหลี่ยม = กว้าง/สูง · รูปจากจุด = ขอบตรงเท่านั้น เลื่อนจุดปลายตามแนวเดิม · ขอบโค้งแก้ด้วยการลากจุด) · เผื่อของขอบ · พับเข้าใน · **กุ้นขอบ** · **เดินด้ายทับ** ห่างจากขอบ (`ProjectPiece.edgeMeta` 1 ค่าต่อขอบ · `cleanEdgeMeta`) · **วางรอยบาก** แบ่งขอบเท่า ๆ กัน N ช่วง หรือที่ระยะจากปลายขอบ (`pointAlong`)
- บนกระดาน: **เลขความยาวขึ้นข้างเส้นที่เย็บ** ทั้งสองด้าน (แบบ CLO) · ขอบที่เลือกสว่าง
- ใบพิมพ์ของแอป (`/print/pattern-project/<id>`): **ตารางตะเข็บ** (ตะเข็บ · เย็บขอบไหนกับขอบไหน · ยาวสองด้าน + ผลต่าง · วิธีเย็บ · เดินด้ายทับ) + **งานขอบ** (ขอบที่พับ / กุ้น / เดินด้ายทับ) — `projectSeamRows` / `projectEdgeRows` · `PatternPrintView` มีช่อง `afterTable`
- ⚠️ วิธีเย็บ เดินด้ายทับ กุ้นขอบ เป็น **ข้อมูลให้ช่างเย็บ** ออกในใบพิมพ์ ยังไม่เปลี่ยนภาพ 3D · ยังไม่ใส่ มุมพับ / ความแข็งรอยพับ / ความหนาตะเข็บ (ของ CLO มี แต่ของเรายังไม่มีอะไรเอาไปใช้) · ค่ารายขอบ (กุ้น/เดินด้าย) มีเฉพาะในแอป ไม่ไปกับการส่งตีราคา
- ก้อน "ชิ้น + วัสดุ" ทำแล้ว (หัวข้อบน)

## เครื่องมือเย็บแบบ CLO — เย็บบนกระดานเดิม (2026-11-10 · แทนวิธีสลับหน้าของรอบก่อน)
เจ้าของติ: "ทำไมต้องเปลี่ยนหน้า · ดูใช้ยาก เหมือนยังทำไม่เสร็จ · ทำให้เหมือน CLO3D" → ดูภาพตัวอย่างแล้วสั่ง "ทำตามแบบนี้" (อ้างคู่มือ CLO: Segment Sewing / Edit Sewing / Reverse Sewing)

- เย็บเป็น **เครื่องมือของกระดานวาดเอง** (`ShapeEditor` รับ `seams` + `onSeamsChange`): ชิ้นอยู่ที่เดิม แถบเครื่องมือเดิม ไม่สลับหน้า ไม่เปิดกระดานใหม่ → ประวัติ Ctrl+Z ของการวาดไม่หาย
  - **เย็บขอบกับขอบ (N)**: กดขอบแรก → กดขอบคู่ = ได้ตะเข็บทันที · Shift+คลิกขอบที่ติดกัน = ต่อด้านแรกให้ยาวขึ้น (ก่อนกดขอบคู่) หรือต่อด้านที่สองของตะเข็บที่เพิ่งเย็บ · Esc ยกเลิก · Ctrl+Z ย้อนตะเข็บ (ตอนถือเครื่องมือเย็บ)
  - **แก้ตะเข็บ (B)**: กดตะเข็บบนกระดานหรือในรายการ → **กลับทิศ** / **ลบ** (Delete) — ตอนถือเครื่องมือเย็บ ปุ่ม Delete ไม่ลบชิ้น
  - ตะเข็บเห็นบนชิ้น **ตลอด** (แม้ถือเครื่องมือวาด): คู่เดียวกันสีเดียวกัน · เส้นประโยงคู่ · ขีดสั้นบอกจุดเริ่มของแต่ละด้าน (`Seam.rev` = ด้านที่สองเริ่มปลายอีกข้าง)
  - แผงขวาสลับเอง: ถือเครื่องมือเย็บ = รายการตะเข็บ (ความยาว 2 ด้าน · เท่ากัน/ต่างกัน/ต้องเย็บใหม่) · ถือเครื่องมือวาด = รายละเอียดชิ้นเหมือนเดิม
  - ภาพ 3D ข้างกระดาน: ขอบที่เย็บเป็นเส้นสี + เส้นด้ายโค้งโยงระหว่างชิ้น (`Pattern3D` `threads`)
- ใบงานออกแบบไม่ส่ง `seams` → ไม่มีเครื่องมือเย็บ หน้าตาเดิม
- `SewView` (หน้าเย็บแยกของเดิม) **ไม่มีที่ไหนใช้แล้ว** — ยังไม่ลบ รอเจ้าของอนุญาต
- **ยังไม่ได้:** เย็บบางช่วงของขอบ (Free Sewing ของ CLO — ตะเข็บยังเก็บเป็น "ทั้งขอบ") · เย็บ 1 ต่อหลายขอบแบบ M:N · ทิศ (`rev`) ยังไม่มีผลกับการประกอบ 3D
- เทสต์ `lib/__tests__/pattern-seams-rev.test.ts`

## ปรับตามที่เจ้าของขอ (2026-11-10): เย็บรวมในหน้าวาด · รหัสรุ่นเลือกจากสินค้า · ใช้ AI ของตัวเอง
1. **เครื่องมือเย็บอยู่ในหน้าวาดชิ้น** (วิธีสลับหน้าในข้อนี้ถูกแทนด้วยหัวข้อบนแล้ว) — แท็บ "เย็บ" ถูกยุบ เหลือ "วาดชิ้น + เย็บ" กับ "ประกอบ 3D" · ปุ่มรูปเข็มท้ายแถบเครื่องมือซ้าย (มีเลขจำนวนตะเข็บ · แดง = มีแนวที่ต้องแก้) → กระดานสลับเป็นตัวจับคู่ขอบที่เดิม · กดลูกศรหรือ "กลับไปวาดชิ้น" เพื่อกลับ
   - `PatternStudio` รับ `sew?: StudioSew` (ไม่ส่ง = ไม่มีปุ่มเข็ม → ใบงานออกแบบเหมือนเดิม) · `ShapeEditor` มีช่อง `toolExtra` · `SewView` มี `onBack`
   - กลับจากโหมดเย็บ = เปิดกระดานใหม่จากชิ้นล่าสุด (ประวัติ Ctrl+Z ของการวาดเริ่มใหม่ เหมือนตอนสลับแท็บเดิม)

3. **ใช้ AI ของคุณเอง (ฟรี)** — ป๊อปแกะจากรูป แท็บที่ 2 (`lib/bag-ai-import`)
   - คัดลอกคำสั่ง (`AI_PATTERN_PROMPT`) → วางใน ChatGPT / Claude / Gemini พร้อมรูปกระเป๋าหลายมุม + ขนาดจริง → AI ตอบ JSON รูปแบบ `bagpattern/1` → วางกลับ (หรือเลือกไฟล์ .json/.txt) → ระบบตรวจ + แสดงตัวอย่าง → วางเป็นชิ้น + ตะเข็บตั้งต้น
   - รูปทรงที่รับ: rect (มุมมนได้) · circle · polygon · ตะเข็บอ้างขอบ top/right/bottom/left · all · เลขลำดับ (สี่เหลี่ยมมุมมนอ้างขอบไม่ได้ → ข้ามตะเข็บนั้น)
   - ชิ้น/ตะเข็บที่ใช้ไม่ได้ = ข้ามและบอกจำนวน ไม่เดาให้ · ชื่อวัสดุที่ตรงกับรายการวัสดุ = ใส่วัสดุให้ชิ้น · คำตอบผิดรูปแบบ = ข้อความภาษาคนบอกให้ส่งคำสั่งซ้ำ
   - ไม่เรียก AI จากระบบ ไม่ส่งรูปออก ไม่เสียเงิน ไม่ต้องมีสิทธิ์ AI · แท็บ "AI ในระบบ (เสียเงิน)" ของรอบ 5 ยังอยู่
   - ข้อจำกัด: AI วัดขนาดจากรูปไม่ได้จริง = ร่างแรก · โค้งมาเป็นเหลี่ยม · **ยังไม่ได้ลองกับคำตอบจาก AI จริง** (ทดสอบด้วยคำตอบตัวอย่าง)

## รอบ 6: จำลองวัสดุทิ้งตัว — ทดลอง (2026-11-10)
แท็บ **ประกอบ 3D** → ปุ่ม **จำลองวัสดุทิ้งตัว (ทดลอง)** (`lib/pattern-sim` + `Pattern3D mode="sim"`)

- กระเป๋าที่ประกอบแล้วถูกแตกเป็นตาข่ายจุด (~1,000–1,700 จุด): แผ่นหน้า/หลังเป็นสามเหลี่ยมจากรูปชิ้นจริง (มีรูเจาะ) · ชิ้นคั่นกลางเป็นตาราง · จุดตามตะเข็บเป็นจุดเดียวกัน

## รอบ 4: ชนิดช่อง + ขอบพับ + ชั้นในไฟล์เครื่องตัด (2026-11-10)
- **ชนิดช่องบนตัวหน้า** (ตัวสร้างจากแม่แบบทรง · `BagParams.winType`):
  - **หน้าต่างโชว์** = รู (เหลี่ยมมน/หัวใจ/วงกลม) + แผ่น PVC ใสใหญ่กว่ารูรอบละ 1.5 ซม. (ของเดิม)
  - **ช่องซิป** = ช่องยาวตามที่ตั้ง กว้าง 1.2 ซม. ให้ฟันซิปโผล่ + ชิ้น "ถุงกระเป๋าซิป (ซับใน)" อยู่หลังช่อง
  - **ช่องสอด** = รอยกรีดกว้าง 0.4 ซม. + ชิ้น "ถุงช่องสอด (ซับใน)"
  - ถุงซับใน: กว้างกว่าช่องข้างละ 2 ซม. · ลึกเท่าที่เหลือเหนือตะเข็บก้น ~2 ซม. (4–16 ซม.) · ผ้าที่ตัดสูง = 2 × ความลึก + 3 ซม. (พับครึ่งเป็นถุง) — **ค่าสมมติ ให้ช่างยืนยัน** · ซิปที่ใช้ควรยาวกว่าช่อง ~2.5 ซม. (ซิปเป็นอะไหล่ ไม่ใช่ชิ้นแพทเทิร์น)
  - แบบสำเร็จรูปเพิ่ม "Tote มีช่องซิปด้านหน้า"
- **ขอบพับ** (`foldEdges` · 1 ค่าต่อขอบ) — ในแผง "เผื่อรายขอบ / ขอบพับ" ติ๊ก **พับ** ที่ขอบที่พับเข้าใน (เช่น ขอบปาก) → เส้นม่วงประยาว-สั้นบนกระดาน · เส้นพับในหน้าพิมพ์/SVG · ชั้น **FOLD** ในไฟล์ DXF · ชิ้นจากแม่แบบติดธงขอบปากให้เอง
- **ชั้นในไฟล์ DXF** ตอนนี้: `CUT` เส้นตัดรอบชิ้น · `HOLE` รูเจาะ/ช่องซิป/ช่องสอด (**ย้ายจาก CUT** — เครื่องตัดต้องตั้งให้ตัดชั้นนี้ด้วย) · `SEW` เส้นเย็บ · `FOLD` เส้นพับ · `NOTCH` รอยบาก · `GRAIN` ทางผ้า · `LABEL` ป้าย
- ยังไม่ได้: ชนิดช่องของรูที่วาดเอง (ตอนนี้รูที่วาดเอง = รูเจาะธรรมดา) · ช่องบนตัวหลัง/ชิ้นข้าง

## ประกอบเป็น 3D จากตะเข็บ (รอบ 3 · 2026-11-10)
แท็บ **ประกอบ 3D** ในสตูดิโอของแต่ละใบ (`AssemblyView` + `lib/pattern-assembly` + `Pattern3D mode="assembly"`)

- ระบบอ่านตะเข็บแล้วหาโครงสร้างที่เข้าใจ 2 แบบ — **เป็นการประกอบทรงตามกติกา ไม่ใช่การจำลองวัสดุ**
  1. **ตัวหน้า + ตัวหลัง + ชิ้นคั่นกลาง**: ชิ้นคั่นกลาง = ชิ้น 4 ขอบที่ขอบตรงข้ามกันถูกเย็บกับตัวหน้า/ตัวหลัง → ความกว้างของชิ้นนั้น = ความลึกกระเป๋า · ขอบของตัวหน้าที่เย็บกับชิ้นคั่นกลางถูกลากข้ามความลึกเป็นผิวข้าง/ก้น (ใช้รูปตัวหน้าจริง วาดทรงไหนก็ได้)
  2. **ซองแบน**: สองแผ่นเย็บขอบติดกันตรง ๆ
- ขอบของตัวหน้าที่ไม่ได้เย็บ = ปากกระเป๋า → ระบบหมุนให้หันขึ้นเอง (หมุนชิ้นบนกระดานยังไงก็ได้)
- เลือกแกนได้หลายแบบ (ทรงกล่องก้นเหลี่ยม) → เลือกแผ่นที่ใหญ่ที่สุดเป็นตัวหน้า และแผ่นที่มีหูติดอยู่ก่อน
- **หู / แผ่น PVC หลังช่อง** ไม่ได้เย็บขอบชนขอบ → ใช้ "จุดติด" (`Attach`) ที่ได้จากแม่แบบทรง (`bagAttachRefs`) เก็บในช่อง `template: { params, attach }` (ไม่มีฐานข้อมูลใหม่) · ชิ้นที่วาดเอง → กด "ติดเป็นหู" / "ใช้ปิดหลังช่อง" ในรายการ "ยังไม่ได้ประกอบ" (ดูหัวข้อบน)
- ดูได้ 2 แบบ: แถบ **แยกชิ้นดู** หรือ **เย็บทีละขั้น** (แผ่นหลังช่อง → หู → ชิ้นคั่นกลาง → ตัวหลัง) · ชี้ชื่อชิ้น = สว่างในภาพ · สีเป็นสีตัวอย่าง ไม่บันทึก
- ประกอบไม่ได้ = บอกเหตุผล (ยังไม่มีชิ้น / ยังไม่มีตะเข็บ / โครงสร้างไม่เข้ากติกา) พร้อมปุ่มไปแท็บที่ต้องแก้ — ไม่วาดภาพหลอก
- ตะเข็บยาวไม่เท่ากันยังประกอบให้ดูได้ (ตามขอบของตัวหน้า) แต่ขึ้นคำเตือน
- **ข้อจำกัด:** ภาพใช้ขนาดสำเร็จ ส่วนเผื่อเย็บ/พับปากไม่แสดง · ตัวหน้ากับตัวหลังต้องเป็นแผ่นขนานกัน (ทรงกระบอก/ทรงที่มีจีบ ยังไม่ได้) · ชิ้นคั่นกลางต้องมี 4 ขอบ · กระเป๋าหน้า ซิป ซับใน ยังไม่ประกอบ

## ใช้ทำอะไร (รอบ 1 — ในใบงานออกแบบ ยังอยู่เหมือนเดิม)
ในแท็บตีราคาของใบงานออกแบบ มุมมอง **แบบวาด** ตอนนี้มีแถบ "สตูดิโอแพทเทิร์น" อยู่บนกระดาน

1. **สร้างจากแม่แบบทรง** — ใส่ขนาดกระเป๋าตอนเสร็จ (กว้างก้น · ปากบาน · สูง · หนา · มุมก้นโค้ง · หู · เผื่อเย็บ · พับปาก · ช่องโชว์ PVC)
   → เห็นกระเป๋าที่เย็บแล้วเป็นภาพ 3D ทันที (หมุน ซูม แยกชิ้นดู) + ตารางชิ้นที่จะได้ + กล่อง "ช่างคิดยังไง"
   → กด **วางชิ้นลงกระดาน** = ชิ้นไปอยู่บนกระดานเป็นชิ้นจริง แก้จุด/ย้าย/ใส่วัสดุ/ย้อนกลับได้ และลงตารางตีราคาตามปกติ
2. **ดูภาพ 3D** — ชิ้นบนกระดานขึ้นเป็นแผ่น 3D วางบนโต๊ะ (ความหนาสมมติ · รูเจาะจริง · เส้นเย็บประ) ขยับตามทันทีที่แก้
3. **เลือกชิ้นฝั่งไหน อีกฝั่งสว่างตาม** — กดชิ้นบนกระดาน → ชิ้นใน 3D ยกขึ้นเป็นสีเหลือง · คลิกชิ้นใน 3D → กระดานเลือกชิ้นนั้น

ปุ่ม "ดูภาพ 3D" ปิดไว้เป็นค่าเริ่ม (จำในเครื่อง `pattern-studio-3d`) → คนที่ใช้แบบวาดอยู่เดิมเห็นหน้าเดิม เพิ่มแค่แถบปุ่ม 1 แถว

## ทรงที่มี (รอบ 1)
Tote อยู่ทรง = ตัวหน้า + ตัวหลัง + (ข้าง+ก้นชิ้นเดียว หรือ ข้าง 2 + ก้น 1) + หูหิ้ว 2 · ช่องโชว์ เหลี่ยมมน / หัวใจ / วงกลม (เจาะรูจริง + แผ่น PVC)
แบบสำเร็จรูป 3 แบบ: Tote ใบกลาง · กระเป๋าโชว์ ช่องหัวใจ · ช้อปปิ้งใบใหญ่ ก้นเหลี่ยม

## กติกาของสูตร (lib/bag-templates)
- **ขอบที่เย็บติดกันต้องยาวเท่ากัน**: ความยาวชิ้นข้าง+ก้น = เส้นรอบขอบ ข้าง–ก้น–ข้าง ของตัวหน้า (`bagGeometry().Lg` · แยกเป็นช่วงใน `parts`)
- มุมก้นโค้ง > 0 = บังคับข้าง+ก้นชิ้นเดียว · มุมโค้งไม่เกินครึ่งก้น · ระยะโคนหูไม่เกินปากกระเป๋า (ค่าเกิน = ปรับให้เอง)
- รอยบาก: กึ่งกลางก้น · จุดเริ่ม-จบมุมโค้ง (ตำแหน่งตรงกันทั้งบนตัวหน้าและชิ้นข้าง) · แนวพับปาก · จุดที่หูโผล่พ้นปาก
- **พับปาก** (ตัววาดยังเผื่อเย็บได้ค่าเดียวทั้งชิ้น): ต่อรูปชิ้นขึ้นไป (พับปาก − เผื่อเย็บ) แล้วบาก 2 ข้างบอกแนวพับ → เส้นตัดด้านบน = สูง + พับปาก พอดี — รอบ 2 จะมีเผื่อเย็บรายขอบ
- **ค่าที่สมมติ ต้องให้ช่างยืนยัน**: ระยะเย็บโคนหู 4 ซม. (`BAG_HANDLE_ATTACH`) · แถบหูกว้าง 2 เท่าของหู · แผ่น PVC ใหญ่กว่ารูรอบละ 1.5 ซม. (`BAG_PVC_MARGIN`)
