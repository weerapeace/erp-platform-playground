# สตูดิโอแพทเทิร์น (Pattern studio)

เจ้าของขอ 2026-11-10: "อยากได้โปรแกรมทำ Pattern กระเป๋า คล้าย CLO3D เวลาทำแบบมี Model 3D ให้ดูว่าเย็บแล้วเป็นยังไง และแกะจากรูปได้" + "เราไม่ใช่ช่าง อยากเรียนรู้วิธีทำไปด้วย"
แนวทางทั้งหมดมาจากเอกสาร Bag Pattern CAD Studio (6 เฟส) — ตกลงกันว่า **สร้างต่อจากตัววาดชิ้นวัสดุเดิม ไม่ทำโปรแกรมแยก** แบ่งเป็น 6 รอบ ไฟล์นี้คือรอบ 1

## แอปหลัก + เครื่องมือเย็บ (รอบ 2 · 2026-11-10)
เจ้าของสั่ง "เริ่มรอบ 2 แต่ย้าย APP นี้เป็น app หลักเลย" → เลือก: อนุญาตเพิ่มฐานข้อมูล · คงปุ่มแม่แบบ/3D ในใบงานออกแบบไว้ด้วย · เปิดให้ ผู้ดูแลระบบ + ผู้จัดการ + ฝ่ายออกแบบ

- **แอป "สตูดิโอแพทเทิร์น"** ในหน้ารวมแอป (`erp_app_groups.key = pattern-studio`) → `/pattern-studio` รายการแพทเทิร์น (การ์ด + ภาพย่อ) → `/pattern-studio/<id>` สตูดิโอของแต่ละใบ
- แพทเทิร์นเก็บเป็นของตัวเองในตาราง `pattern_projects` (ชิ้น + ตะเข็บ · เลข `PAT-YYYYMM-0001` · ลบ = ซ่อน) — **ไม่ผูกกับตีราคาของใบงานออกแบบ** (ยังไม่มีปุ่มส่งชิ้นไปตีราคา)
- สิทธิ์ `pattern_studio.view / edit / delete` (ชื่อไม่ปนกับ `pattern.*` ของตั๋วงานช่าง) · API `/api/pattern-projects` (+ `/[id]`) · ทุกการสร้าง/แก้/ลบจดประวัติ
- **แท็บ "เย็บ"** (`SewView`): คลิกขอบของชิ้นแรก (คลิกขอบที่ติดกันต่อเป็นด้านยาวได้) → คลิกขอบอีกชิ้น → "เย็บติดกัน" · ระบบวัดความยาวสองด้านจากรูปปัจจุบันเสมอ ต่างกันเกิน 0.1 ซม. = เตือน "ยาวไม่เท่ากัน" (ไม่ปรับชิ้นให้เอง)
- **สร้างจากแม่แบบทรง = ได้ตะเข็บตั้งต้นครบ** (`bagSeamRefs`) ไม่ต้องจับคู่เอง
- กติกาขอบ/ตะเข็บ (`lib/pattern-seams`): ขอบ = เส้นระหว่างจุดที่ติดกันของรูป (สี่เหลี่ยม 4 ขอบ · วงกลม 1 ขอบ) · ตะเข็บจำ "ชิ้น + ขอบเริ่ม + จำนวนขอบ + จำนวนขอบทั้งชิ้นตอนสร้าง" → ย้าย/ย่อขยาย/ขยับจุด ตะเข็บยังอยู่ · เพิ่ม/ลบจุดจนจำนวนขอบเปลี่ยน หรือลบชิ้น = "ต้องกำหนดใหม่"
- แก้สูตรแม่แบบ: ส่วนพับปากของชิ้นข้างวัดตามแนวขอบที่เอียง (เดิมวัดแนวตั้ง → ปากบานมาก ๆ ขอบยาวไม่เท่ากัน 0.3–0.6 ซม.)
- **ยังไม่ได้ทำในรอบ 2 (ยกไปรอบถัดไป):** เผื่อเย็บรายขอบ · ตั้งชื่อขอบเอง · ทิศทางการเย็บ · วัสดุ/รูปอ้างอิงในแอปหลัก · ส่งชิ้นไปตีราคา

## ใช้ทำอะไร (รอบ 1 — ในใบงานออกแบบ ยังอยู่เหมือนเดิม)
ในแท็บตีราคาของใบงานออกแบบ มุมมอง **แบบวาด** ตอนนี้มีแถบ "สตูดิโอแพทเทิร์น" อยู่บนกระดาน

1. **สร้างจากแม่แบบทรง** — ใส่ขนาดกระเป๋าตอนเสร็จ (กว้างก้น · ปากบาน · สูง · หนา · มุมก้นโค้ง · หู · เผื่อเย็บ · พับปาก · ช่องโชว์ PVC)
   → เห็นกระเป๋าที่เย็บแล้วเป็นภาพ 3D ทันที (หมุน ซูม แยกชิ้นดู) + ตารางชิ้นที่จะได้ + กล่อง "ช่างคิดยังไง"
   → กด **วางชิ้นลงกระดาน** = ชิ้นไปอยู่บนกระดานเป็นชิ้นจริง แก้จุด/ย้าย/ใส่วัสดุ/ย้อนกลับได้ และลงตารางตีราคาตามปกติ
2. **ดูภาพ 3D** — ชิ้นบนกระดานขึ้นเป็นแผ่น 3D วางบนโต๊ะ (ความหนาสมมติ · รูเจาะจริง · เส้นเย็บประ) ขยับตามทันทีที่แก้
3. **เลือกชิ้นฝั่งไหน อีกฝั่งสว่างตาม** — กดชิ้นบนกระดาน → ชิ้นใน 3D ยกขึ้นเป็นสีเหลือง · คลิกชิ้นใน 3D → กระดานเลือกชิ้นนั้น

ปุ่ม "ดูภาพ 3D" ปิดไว้เป็นค่าเริ่ม (จำในเครื่อง `pattern-studio-3d`) → คนที่ใช้แบบวาดอยู่เดิมเห็นหน้าเดิม เพิ่มแค่แถบปุ่ม 1 แถว

## ทรงที่มี (รอบ 1)
Tote อยู่ทรง = ตัวหน้า + ตัวหลัง + (ข้าง+ก้นชิ้นเดียว หรือ ข้าง 2 + ก้น 1) + หูหิ้ว 2 · ช่องโชว์ เหลี่ยมมน / หัวใจ / วงกลม (เจาะรูจริง + แผ่น PVC)
แบบสำเร็จรูป 3 แบบ: Tote ใบกลาง · กระเป๋าโชว์ ช่องหัวใจ · ช้อปปิ้งใบใหญ่ ก้นเหลี่ยม

## กติกาของสูตร (lib/bag-templates)
- **ขอบที่เย็บติดกันต้องยาวเท่ากัน**: ความยาวชิ้นข้าง+ก้น = เส้นรอบขอบ ข้าง–ก้น–ข้าง ของตัวหน้า (`bagGeometry().Lg` · แยกเป็นช่วงใน `parts`)
- มุมก้นโค้ง > 0 = บังคับข้าง+ก้นชิ้นเดียว · มุมโค้งไม่เกินครึ่งก้น · ระยะโคนหูไม่เกินปากกระเป๋า (ค่าเกิน = ปรับให้เอง)
- รอยบาก: กึ่งกลางก้น · จุดเริ่ม-จบมุมโค้ง (ตำแหน่งตรงกันทั้งบนตัวหน้าและชิ้นข้าง) · แนวพับปาก · จุดที่หูโผล่พ้นปาก
- **พับปาก** (ตัววาดยังเผื่อเย็บได้ค่าเดียวทั้งชิ้น): ต่อรูปชิ้นขึ้นไป (พับปาก − เผื่อเย็บ) แล้วบาก 2 ข้างบอกแนวพับ → เส้นตัดด้านบน = สูง + พับปาก พอดี — รอบ 2 จะมีเผื่อเย็บรายขอบ
- **ค่าที่สมมติ ต้องให้ช่างยืนยัน**: ระยะเย็บโคนหู 4 ซม. (`BAG_HANDLE_ATTACH`) · แถบหูกว้าง 2 เท่าของหู · แผ่น PVC ใหญ่กว่ารูรอบละ 1.5 ซม. (`BAG_PVC_MARGIN`)

## ใช้ในโค้ด
```tsx
import { PatternStudio } from "@/components/pattern-studio";     // รับค่าชุดเดียวกับ ShapeEditor แบบฝัง
<PatternStudio initial={pieces} materials={mats} readonly={!canEdit} onChange={applyBoard} />

import { Pattern3D } from "@/components/pattern-3d";
<Pattern3D mode="flat" pieces={[{ pid, name, cut, sew, holes }]} selected={pid} onSelect={(pid) => …} />
<Pattern3D mode="bag" bag={bagGeometry(params)} explode={0.5} />

import { bagGeometry, bagPieces } from "@/lib/bag-templates";
const G = bagGeometry({ W: 32, H: 28, D: 12 });   // ปรับค่าเข้าขอบเขต + เรขาคณิตกระเป๋าที่เย็บแล้ว
const pieces = bagPieces(G);                       // ชิ้นแพทเทิร์น (รูปทรงแบบ lib/pattern-shape) + ตำแหน่งวาง
```
ShapeEditor มีช่องเชื่อมเพิ่ม 4 ช่อง (ไม่ส่ง = ทำงานเหมือนเดิม): `inject` (เพิ่มชิ้นจากภายนอก · ย้อนกลับได้) · `onSelChange` · `selectPid` · `onLive` (ชิ้นบนกระดานแบบสด)

## ข้อจำกัดรอบ 1
- ภาพ 3D ของกระดาน = ชิ้นแบน ยังประกอบเป็นกระเป๋าไม่ได้ (ระบบยังไม่รู้ว่าขอบไหนเย็บกับขอบไหน) — กระเป๋าที่ประกอบแล้วดูได้เฉพาะในตัวสร้างจากแม่แบบ
- ชิ้นที่วางลงกระดานแล้วไม่ผูกกับแม่แบบอีก: แก้ขนาดต้องแก้ที่ชิ้น หรือสร้างจากแม่แบบใหม่
- ยังไม่จำลองวัสดุทิ้งตัว/ย่น · ยังไม่แกะจากรูป · ไม่มีฐานข้อมูลใหม่ (ชิ้นเก็บในบรรทัดตีราคาเหมือนเดิม)
- เปิดแบบวาดด้วยสิทธิ์ดูอย่างเดียว = ไม่มีปุ่มสร้างจากแม่แบบ (ดู 3D ได้)
