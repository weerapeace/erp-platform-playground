# 🚚 ระบบขนส่งเว็บร้าน (เฟส 1)

เจ้าของสั่ง 2026-10-20 "ทำเฟส 1" — ทำในระบบเราเองทั้งหมด ไม่ต่อบริการขนส่งภายนอก (เฟส 2 = ต่อตัวรวมขนส่ง ทีหลัง)

## ก้อนที่ 1 — วิธีจัดส่ง + กติกาค่าส่ง

- ERP → 🌐 เว็บไซต์ → ร้าน → แท็บ **🚚 การจัดส่ง** (`components/website-shipping-panel.tsx`)
- ต่อวิธี: ชื่อ (+EN) · ส่งถึงบ้าน/รับเองที่ร้าน · ขนส่ง · ค่าส่ง **เหมา** หรือ **ตามจำนวนชิ้น** (แต่ละขั้นเลือกกล่องมาตรฐาน `parcel_sizes` ให้คนแพ็ก)
  · ส่งฟรีเมื่อยอดถึง · บวกพื้นที่ห่างไกล · ส่งได้ที่ (ทั่วประเทศ / กทม.+สมุทรปราการ / กทม.และปริมณฑล) · เก็บปลายทางได้ไหม + ค่าธรรมเนียม COD
  · ระยะเวลาถึง · รอบตัดส่ง · หมายเหตุ (รับเองที่ร้าน = ที่อยู่/เวลารับ)
- รหัสไปรษณีย์พื้นที่ห่างไกล: 5 หลักตรงตัว หรือ 2–4 หลักขึ้นต้น (มีรายการแนะนำ — ⚠️ เช็กกับขนส่งจริง)
- เก็บที่ `store_settings` key `shipping_methods` (JSON) — **ร้านที่ยังไม่ตั้ง = 1 วิธีจากค่าส่งเหมาเดิม ยอดเท่าเดิมทุกบาท** และเว็บไม่โชว์กล่องเลือกวิธีส่ง (หน้าตาเดิม)

### หน้าตาแท็บ (2026-10-28 — เจ้าของเลือก "แบบ B" จากตัวอย่าง 3 แบบ)
- **3 ช่อง**: ซ้าย = รายการวิธีส่ง (การ์ดสั้น: ชื่อ · ราคาสรุป · ป้าย ส่งฟรี/COD/กทม.เท่านั้น/ตัดรอบ/ปิดอยู่/⚠ จุดควรดู · ป้าย "ค่าเริ่มต้น" = วิธีแรกที่เปิด)
  · กลาง = รายละเอียดวิธีที่เลือก แบ่งกลุ่ม 👀 ลูกค้าเห็นอะไร / 💰 ค่าส่ง / 📍 ส่งที่ไหน · ขนส่ง / 💵 เก็บปลายทาง / ⏱ ระยะเวลา
  · ขวา = 👀 ลูกค้าจะเห็นแบบนี้ (`components/website-shipping-preview.tsx` หน้าตาเหมือนกล่องวิธีจัดส่งในหน้าชำระเงินจริง) + ลองสมมติตะกร้า (ยอด/ชิ้น/รหัสไปรษณีย์/COD)
- แผงแคบกว่า ~1100px = ตัวอย่างลงไปใต้รายละเอียด · แคบกว่า ~720px (มือถือ) = รายการ → แตะ → รายละเอียด (ปุ่ม ‹ ย้อนกลับ) · วัดจากความกว้างแผงจริง (หน้าเว็บไซต์ตั้งความกว้างหน้าได้)
- **ลากเรียง** (useDragReorder) แทนปุ่ม ↑↓ · **สวิตช์เปิด/ปิดบนการ์ด** (ToggleSwitch) · **⧉ ทำซ้ำ** · **+ เพิ่มวิธีส่ง** = เมนูแบบสำเร็จรูป 4 แบบ + ว่าง · ครบ 10 วิธีปิดปุ่มเพิ่ม (normalizeShipping เก็บแค่ 10 วิธีแรก)
- **🏝 พื้นที่ห่างไกล** เป็นเมนูแยกท้ายรายการ (ใช้ร่วมทุกวิธี) + ช่องลองเช็กรหัส
- **⚠️ เตือนตั้งค่าขัดกัน** `lib/website-shipping-checks.ts` (pure · ERP เท่านั้น ไม่ต้องมิเรอร์ · มีเทสต์) — โชว์ในกลุ่มที่ต้องแก้: ไม่มีวิธีที่เปิด · ทุกวิธีส่งแค่ กทม. · ร้านเปิด COD แต่ไม่มีวิธีไหนรับ · ชื่อว่าง/ซ้ำ · รับที่ร้านไม่บอกที่อยู่ · ขั้นหลังถูกกว่าขั้นก่อน · ขั้นไม่ได้เลือกกล่อง · ส่งฟรีแต่ค่าส่ง 0 อยู่แล้ว · บวกห่างไกลแต่ไม่มีรหัส · ติ๊ก COD แต่ร้านปิด · ส่งในเมืองไม่ตั้งรอบตัด
- เปลี่ยนชนิดเป็น "รับเองที่ร้าน" ตอนตั้งตามจำนวนชิ้นอยู่ → แปลงเป็นค่าส่งเหมา = ราคาขั้นแรกให้เห็นทันที (เดิมตอนบันทึกกลายเป็น 0 เงียบ ๆ)
- ข้อมูลที่บันทึก/สูตรคิดค่าส่ง **ไม่เปลี่ยน** — ของกลาง: SaveBar · MoneyInput · askConfirm · useDragReorder · ToggleSwitch · Seg · FloatingDropdown · webForm

### กติกาคิดค่าส่ง (`lib/website-shipping.ts` · มิเรอร์ทั้งไฟล์ → storefront `src/lib/shipping.ts`)
- ส่งฟรีเทียบ "ยอดสินค้าก่อนส่วนลด" (เหมือนของเดิม)
- ส่งฟรีแล้ว **ค่าพื้นที่ห่างไกลยังบวก** (ขนส่งเก็บจริง)
- COD: เลือกได้ต่อเมื่อร้านเปิด "รับเก็บเงินปลายทาง" **และ** วิธีส่งนั้นติ๊กรับ · ค่าธรรมเนียม COD รวมในยอด (`store_orders.cod_fee`)
- วิธีที่ส่งไม่ถึงรหัสไปรษณีย์ = โชว์จาง "ส่งไม่ถึงรหัสไปรษณีย์นี้" · ยังไม่กรอกรหัส = ให้เลือกได้ก่อน
- รับเองที่ร้าน = ไม่บังคับที่อยู่
- ERP คิดใหม่ตอนรับออเดอร์เสมอ (`createStorefrontOrder`) ไม่เชื่อยอดจากหน้าเว็บ

### ออเดอร์
- `store_orders` เพิ่ม `shipping_method` · `shipping_method_label` (ชื่อตอนสั่ง) · `shipping_box` (กล่องแนะนำ) · `cod_fee` (migration `202610201900`)
- แท็บ 🧾 ออเดอร์ โชว์ "🚚 วิธีส่ง · กล่อง X" · ข้อความ/อีเมลถึงลูกค้ามีชื่อวิธีส่ง + ค่า COD
- เว็บร้าน: หน้าขอบคุณ + หน้าติดตามคำสั่งซื้อ โชว์วิธีส่ง + ค่า COD

### เว็บรุ่นเก่า
- site API ยังเติม `info.shipping_flat` / `free_shipping_min` จากวิธีส่งถึงบ้านวิธีแรก → ตะกร้า/ข้อความ "ส่งฟรีเมื่อ…" ของเว็บรุ่นเก่ายังตรง

## ก้อนที่ 2 — เลือกที่อยู่จากรายการ (ตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์)

- ERP `GET /api/public/address/search?q=` (สาธารณะ + CORS + แคช CDN) · `lib/thai-address-search.ts` + ข้อมูล `lib/data/thai-address-db.ts`
  (thai-address-database ISC ← jquery.Thailand.js MIT · ~7,400 ตำบล) — คนละไฟล์กับ `lib/thai-address.ts` (จัดรูปแบบที่อยู่บนเอกสาร)
- เว็บร้าน `AddressSuggest`: ช่องแขวง/ตำบล และรหัสไปรษณีย์ ในหน้าชำระเงิน + ที่อยู่สมาชิก — เลือกแล้วเติมอีก 3 ช่อง · ไม่เจอ = พิมพ์เองได้

## ก้อนที่ 3 — แพ็กและส่งของ (แท็บ 🧾 ออเดอร์)

- ตัวกรอง **📦 พร้อมแพ็ก** = รอดำเนินการ/กำลังเตรียมของ + (จ่ายแล้ว หรือ เก็บปลายทาง) — `lib/website-fulfillment.ts isReadyToPack`
- ติ๊กหลายใบ → แถบล่าง: 🖨 ใบปะหน้า + ใบแพ็ก · 📦 กำลังเตรียมของ · 🚚 ใส่เลขพัสดุ
- **/print/web-orders?shop=&ids=** — ใบปะหน้า (ผู้ส่ง/ผู้รับ/รหัสไปรษณีย์ตัวใหญ่/บาร์โค้ดเลขออเดอร์/วิธีส่ง+กล่อง/COD ตัวใหญ่) + ใบแพ็ก (ติ๊กหยิบของ/ห่อของขวัญ/หมายเหตุ)
  · หรือใบปะหน้าอย่างเดียว 4 ใบ/แผ่น · ไม่ส่ง ids = ทุกออเดอร์พร้อมแพ็ก · ผู้ส่ง = ชื่อร้าน + เบอร์/ที่อยู่จากแท็บ 🏪 ข้อมูลร้าน
- **🚚 ใส่เลขพัสดุหลายใบ**: วางจากไฟล์ขนส่ง/Excel (เลขออเดอร์ + เลขพัสดุ คอลัมน์ไหนก่อนก็ได้) → ดูตัวอย่างจับคู่/เหตุผลที่ไม่ได้/ทับเลขเดิม → บันทึก (+ เปลี่ยนเป็นจัดส่งแล้ว + แจ้งลูกค้า)
- API `PATCH /api/website/orders { bulk }` ทำทีละใบผ่าน `applyOne` เดียวกับแก้ทีละใบ → audit/แต้มสมาชิก/อีเมลแจ้งลูกค้า ครบเหมือนเดิม (สูงสุด 200 ใบ/ครั้ง)

## ทำต่อได้ (เฟส 2)
- ต่อตัวรวมขนส่ง (เช่น SHIPPOP) → ค่าส่งจริง · ออกเลขพัสดุ/ใบปะหน้าของขนส่งอัตโนมัติ · เรียกรถ · สถานะพัสดุอัปเดตเอง
- ค่าส่งตามน้ำหนัก (ต้องเพิ่มน้ำหนักสินค้าก่อน — ตอนนี้ SKU ยังไม่มีช่องน้ำหนัก) · สถานะ "ตีกลับ" · วันหยุดขนส่ง
