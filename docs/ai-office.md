# ออฟฟิศทีม AI (`/master/ai-office`)

หน้ารวม "ผู้ช่วยอัตโนมัติ / AI" ทุกตัวที่ระบบมีอยู่จริง จัดเป็นห้องตามแผนก พร้อมสถานะจากบันทึกการทำงานจริง
(ขั้นที่ 1 = ดูอย่างเดียว · ยังสั่งงาน AI จากหน้านี้ไม่ได้)

## ใช้ทำอะไร

- ดูว่าระบบอัตโนมัติตัวไหน **ทำงานปกติ / ว่าง / ต้องดู / ติดปัญหา / ยังไม่มีบันทึก**
- กล่อง **"ต้องให้คนช่วย"** = เรื่องที่คนต้องไปทำเอง (1 แถว = 1 เรื่อง) พร้อมวิธีแก้เป็นภาษาคน
- **ความเคลื่อนไหวจริง** = รายงานที่ส่งออก, การกดใช้ AI, คิวโพสต์, รอบงานตั้งเวลา ฯลฯ
- กดการ์ดเพื่อดู: ทำอะไร · ทำงานเมื่อไหร่ · ทำอะไรได้ / อะไรล็อกไว้ · สถานะดูจากไหน · ไฟล์โค้ด

## มุมมอง "ออฟฟิศ" (พิกเซล · ค่าเริ่มต้น)

ฉากวาดด้วยโค้ดทั้งหมด (canvas 200×150 แล้วขยายแบบพิกเซล) ไม่โหลดไฟล์รูป · ห้องที่ตัวละครอยู่ = สถานะ
(สลับเป็นมุมมอง "การ์ด" หรือ "ตาราง" ได้ · จำค่าในเครื่อง)

| ท่าทาง (`workerPose`) | อยู่ที่ไหน | เมื่อไร |
|---|---|---|
| `work` | นั่งโต๊ะตัวเอง จอพิมพ์อยู่ | ทำงานปกติ |
| `sleep` | หลับที่โต๊ะ + นาฬิกาปลุกแดง | งานตั้งเวลาที่ติดแค่ยังไม่ตั้ง `CRON_SECRET` |
| `repair` | ห้องซ่อม (ป้าย ! กะพริบ ไฟตู้แดง) | ติดปัญหาเรื่องอื่น |
| `counter` | เคาน์เตอร์ (ป้าย ?) | ต้องดู / รอคน |
| `lounge` | มุมพัก | ว่าง |
| `away` | นั่งโต๊ะ จอดับ (ป้าย ? เทา) | ยังไม่มีบันทึก |

สถานะเปลี่ยน (หน้าโหลดใหม่ทุก 1 นาที) → ตัวละครเดินผ่านทางเดิน+ประตูไปห้องใหม่เอง · ผู้ใช้ที่ตั้งลดภาพเคลื่อนไหว = ย้ายทันทีไม่เดิน

**โหมดตกแต่ง (สิทธิ์ `ai_office.edit` = แอดมิน):** ธีม กลางวัน/กะดึก/มินิมอล · ชนิดตัวละคร แมว/หมา/คน · สีขน-ผม · สีเสื้อ (เริ่มต้น = สีแผนก) · ชื่อเล่น · ย้ายโต๊ะ (สลับกับโต๊ะอื่นหรือโต๊ะว่าง) · แก้เป็นร่าง กดบันทึก/ยกเลิก · ออกโดยยังไม่บันทึก = ถามก่อน · กลับค่าเริ่มต้น = ถามยืนยัน
ค่าที่เก็บไม่ผูกกับสไตล์การวาด → เพิ่มสไตล์ใหม่ภายหลังได้โดยไม่ต้องแต่งใหม่ · ผู้ช่วยใหม่ในทะเบียนได้โต๊ะว่างอัตโนมัติ (`cleanScene`) · โต๊ะมี 20 ตัว (`SCENE_DESKS`, เทสต์บังคับ ≥ จำนวนผู้ช่วย)

## สถานะแต่ละตัวดูจากอะไร

| ประเภท | หลักฐาน |
|---|---|
| งานตั้งเวลาใน `vercel.json` (ทุกตัว) | ยังไม่ตั้ง `CRON_SECRET` = **ติดปัญหา** เสมอ (Vercel ถูกปฏิเสธ) · ตั้งแล้ว = ผลรอบล่าสุดใน `ui_config` key `ai_office_run:<id>` + หลักฐานเสริม (แจ้งเตือนที่ส่ง, จำนวนรูปที่ยังไม่มีลายนิ้วมือ ฯลฯ) |
| ผู้ส่งรายงานตามเวลา | `email_report_runs` (7 วัน) + `email_reports` ที่เปิดใช้ |
| ผู้โพสต์ตามเวลา | `social_publish_jobs` (คิวค้างเลยเวลา 30 นาที = ติดปัญหา) |
| ปุ่ม AI | `audit_logs` action `ai_*` (ใช้ใน 7 วัน = ปกติ · ไม่มีใครใช้ = ว่าง ไม่ใช่เสีย) |
| ผู้อ่านอีเมลออเดอร์ | `platform_email_settings.last_ping_at` (เงียบเกิน 6 ชม. = ติดปัญหา) + `platform_email_inbox` 24 ชม. |
| AI จาก LINE | `purchase_order_captures` / `design_sheet_line_inbox` (มีรายการรอคน = ต้องดู) |
| ผู้ต่ออายุกุญแจ Lazada | `platform_credentials.meta` ผ่าน `lazConnHealth` (หมดอายุ = ต้องเชื่อมร้านใหม่) |
| ผู้คำนวณเงินเดือน | `erp_jobs` type `payroll_calc` |

## เพิ่มงานอัตโนมัติใหม่ (ต้องทำทุกครั้ง)

1. เพิ่มแถวใน `OFFICE_WORKERS` (`lib/ai-office.ts`) — ห้อง, ประเภท (`ai`/`auto`), ทำอะไร, ทำได้/ล็อก, สถานะดูจากไหน, ไฟล์
2. ถ้าเป็น cron ใน `vercel.json` → ใส่ `cron` + เรียก `recordWorkerRun` ตอนจบรอบ (สำเร็จ/ล้ม) — **เทสต์จะล้มถ้า cron ใน vercel.json ไม่มีเจ้าของในทะเบียน**
3. ถ้าเป็นปุ่ม AI → เขียน audit action `ai_*` แล้วเพิ่มใน `AI_AUDIT_ACTIONS` + `AI_ACTION_LABEL`
4. เพิ่มตัวอ่านใน `app/api/ai-office/live.ts` (ห่อด้วย `part([...])` ล้มแล้วไม่พาทั้งหน้าล้ม)

## สิทธิ์ / ความเป็นส่วนตัว

- `ai_office.view` ยังไม่มีแถวใน `erp_permissions` → ตอนนี้เห็นเฉพาะแอดมิน (erp_can ของแอดมิน = true) · จะให้คนอื่นดูต้องเพิ่มแถวสิทธิ์ก่อน
- ความเคลื่อนไหวมีชื่อ/อีเมลคนที่กดใช้ AI (จาก audit) จึงจำกัดเฉพาะผู้มีสิทธิ์
- `CRON_SECRET` ส่งไปหน้าจอแค่ "ตั้งแล้วไหม" ไม่ส่งค่า · ไม่อ่าน/ส่ง token ใด ๆ

## ข้อจำกัด

- ดูอย่างเดียว ยังไม่มีช่องสั่งงาน / กล่องอนุมัติ (ขั้นที่ 2–3)
- ฉากพิกเซล: ยังอัปรูปพื้นหลังเองไม่ได้ · ยังตั้งเองไม่ได้ว่าห้องไหน = สถานะไหน · ผู้ช่วยเกิน 20 ตัวต้องขยายห้องทำงาน (เพิ่มแถวใน `DESK_POS` + `SCENE_DESKS`)
- ตัวตั้งเวลาในฐานข้อมูล (pg_cron: รายงาน 15 นาที, คิวโพสต์ 5 นาที, สรุปโอนจีนรายเดือน) ดูผลจากตารางปลายทาง ไม่ได้อ่าน `cron.job_run_details` (ต้องมี RPC เพิ่ม)
- งานที่ไม่จดอะไรเลย (เช่น แจ้งเตือน LINE กลุ่ม, Discord, ปุ่มแปล/อ่านสลิปด้วย Workers AI) ยังไม่อยู่ในทะเบียน
- งานตั้งเวลา Vercel จะเริ่มมีบันทึกรอบจริงหลังตั้ง `CRON_SECRET` แล้วเท่านั้น
