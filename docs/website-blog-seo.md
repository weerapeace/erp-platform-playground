# 📝 บทความ · 🎯 หน้า Landing · 🔎 SEO รายรุ่น · 🔀 ย้ายลิงก์เก่า (เว็บร้าน · ชุด 7)

ทุกอย่างค่าเริ่ม = ไม่มีผลกับเว็บ จนกว่าจะสร้าง/ตั้งค่าเอง

## 📝 บทความ (Blog)

ERP › เว็บไซต์ › 📄 หน้าเว็บ › **＋ สร้าง** → เลือก **📝 บทความ** (หรือ 📄 หน้าเว็บ แบบเดิม)

- เนื้อหาใช้ Section ชุดเดียวกับหน้าเว็บ (ข้อความ · รูป · วิดีโอ · สินค้า ฯลฯ) — ไม่มีตัวแก้แยก
- ตั้งค่าบทความ: รูปปก · คำโปรย (TH/EN) · แท็ก (≤10) · ผู้เขียน
- เว็บร้าน: `/blog` = รวมบทความ (ใหม่สุดก่อน · กดแท็กกรองได้ `?tag=`) · `/blog/<slug>` = อ่านบทความ + "บทความอื่น" (แท็กเดียวกันก่อน)
- Google: BlogPosting + BreadcrumbList · แชร์ใช้รูปปก · ฟีด RSS `/blog/rss.xml` · อยู่ใน sitemap
- ลิงก์ `/<slug>` ของบทความ พาไป `/blog/<slug>` ให้เอง · ชื่อ blog / review / feeds จองไว้ ตั้งเป็น slug ไม่ได้
- ⚠️ ยังไม่มีลิงก์ไป `/blog` ในเมนู → ต้องเพิ่มเองที่ตั้งค่าเมนูเว็บ

## ⏰ ตั้งเวลาเผยแพร่ (ทั้งหน้าเว็บและบทความ)

ช่อง "เผยแพร่เมื่อ" (เวลาไทย) — ก่อนถึงเวลา หน้านั้นเป็น 404 บนเว็บ ไม่อยู่ในรายการ/sitemap (โหมดพรีวิวยังเปิดดูได้) · รายการใน ERP มีป้าย ⏰
กฎอยู่ที่ `pageLive(meta, now)` ใน `lib/website-help-center.ts` · เว็บร้านแคช 60 วิ → ขึ้นจริงช้าสุด ~1 นาทีหลังเวลาที่ตั้ง

## 🎯 หน้า Landing (ไม่มีหัวเว็บ/ท้ายเว็บ)

ตั้งค่าหน้าเว็บ (แบบ 📄) → ติ๊ก **"หน้า Landing — ซ่อนหัวเว็บ/ท้ายเว็บ"**
ใช้กับหน้าโปรที่ยิงโฆษณา ให้ลูกค้าโฟกัสปุ่มเดียว · ซ่อนแถบประกาศ + เมนูบน + ท้ายเว็บ (ปุ่มแชทลอยยังอยู่)
เว็บร้านทำด้วยตัวบอก `data-bare-page` + กฎใน `globals.css` (ไม่ต้องแยก layout)

## 🔎 SEO ของแต่ละรุ่น

ERP › สินค้าบนเว็บ (หน้าตั้งค่ารุ่น) → กล่อง **🔎 SEO ของรุ่นนี้**: หัวข้อที่ขึ้นใน Google (≤120 ตัว) + คำอธิบาย (≤320 ตัว) ไทย/อังกฤษ มีตัวนับ
ว่าง = ใช้ชื่อสินค้า/คำอธิบายตามเดิม · หัวข้อที่ตั้งเองใช้ตามที่พิมพ์ (ไม่ต่อชื่อร้านท้าย)
เก็บที่ `store_listings.web_seo` (jsonb · migration `202610291600_store_listings_web_seo`) · ล้างแท็ก HTML ที่ `cleanListingSeo` (`lib/website-listing-patch.ts`)

## 🔀 ย้ายลิงก์เก่า (Redirect)

ERP › 🏪 ข้อมูลร้าน › กลุ่ม **🔀 ย้ายลิงก์เก่า** — บรรทัดละ 1 คู่:

```txt
/products/roar-bag -> /product/roar01
/old-blog -> /blog
/promo -> https://line.me/R/ti/p/@shop
```

- ใช้ได้ทั้ง `->` `→` `=>` หรือเว้นวรรค · ตัวเล็ก/ใหญ่ · / ท้ายลิงก์ ไม่มีผล · สูงสุด 300 บรรทัด
- ทำงานเฉพาะลิงก์ที่ **หาไม่เจอ** เท่านั้น (หน้าที่มีอยู่จริงไม่ถูกย้าย) · ย้ายแบบถาวร (308) ให้ Google โอนคะแนนไปหน้าใหม่
  (ลิงก์ `/product/...` ใช้ meta refresh 0 วิ แทน เพราะหน้าสินค้ามี loading — Google นับเป็นย้ายถาวรเหมือนกัน)
- หน้า /en พาไปหน้าใหม่ฉบับ /en ให้เอง · ข้าม "/" และลิงก์ที่ชี้หาตัวเอง
- กฎล้างค่า `cleanRedirects` (`lib/website-site-info.ts`) · เว็บร้านอ่านที่ `src/lib/redirects.ts` + `src/lib/redirects-server.ts`
  (`redirectIfMoved()` ใน `app/not-found.tsx` · `redirectOrNotFound()` แทน `notFound()` ในหน้าที่ดึงข้อมูล: หน้าเว็บ/สินค้า/หมวด/คอลเลกชัน/บทความ/วัสดุ/มาใหม่)
  → **หน้าใหม่ที่หาข้อมูลไม่เจอ ให้เรียก `return redirectOrNotFound()` แทน `notFound()`**

## 🧭 เส้นทาง (Breadcrumb) ให้ Google

หน้าสินค้า (หน้าแรก › หมวด › สินค้า) · หน้าหมวด (› หมวดแม่ › หมวด) · หน้าเว็บ · บทความ — ใส่ BreadcrumbList ใน JSON-LD ให้แล้ว
