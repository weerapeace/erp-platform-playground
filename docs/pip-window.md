# หน้าต่างจิ๋วลอยทับทุกโปรแกรม (`components/pip-window`)

> เริ่มใช้ 2026-11-11 — ตัวแรก: ตัวนับถอยหลังขึ้นเว็บ หน้า `/admin/deploy` ปุ่ม "ลอยไว้มุมจอ"

## ใช้ทำอะไร

ดึงเนื้อหาส่วนเล็ก ๆ ของหน้าออกไปเป็น **หน้าต่างจิ๋วที่ลอยทับทุกโปรแกรม** — สลับไปทำงานในแท็บอื่น / Excel / LINE ก็ยังเห็น
(ใช้ความสามารถ Document Picture-in-Picture ของ Chrome / Edge)

- เนื้อหาในหน้าต่างลอย = ส่วนหนึ่งของหน้าเดิม (ข้อมูลชุดเดียวกัน อัปเดตพร้อมกัน ไม่ต้องดึงซ้ำ)
- ผู้ใช้ลากย้าย / ย่อขยายหน้าต่างได้เอง · มีปุ่ม "กลับไปที่แท็บ" ของเบราว์เซอร์ให้

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่

| ใช้ | ห้ามใช้ (ใช้ตัวนี้แทน) |
|---|---|
| ตัวเลข/สถานะที่อยากเห็นตลอด เช่น นับถอยหลัง จับเวลา สถานะงานยาว | แผงลอยแค่ในหน้าเว็บ → `FloatingPanel` |
| | ฟอร์มที่ต้องกรอกให้เสร็จ → `ERPModal` |
| | แจ้งผลสั้น ๆ → `Toast` |

## วิธีใช้

```tsx
import { PipPortal, usePipWindow } from "@/components/pip-window";

const pip = usePipWindow();
const now = useNow(1000, pip.win);            // ตัวจับเวลาตั้งบนหน้าต่างลอย (ดูข้อ "ตัวจับเวลา")

<button disabled={!pip.supported} onClick={() => void pip.open({ width: 320, height: 170, title: "ขึ้นเว็บ" })}>ลอยไว้มุมจอ</button>
{pip.win && <button onClick={pip.close}>เอากลับ</button>}

<PipPortal win={pip.win}>
  <MyMiniView />   {/* ออกแบบให้เต็มหน้าต่างเล็ก เช่น h-screen */}
</PipPortal>
```

- `open()` ต้องเรียกจากการกดปุ่มเท่านั้น (กฎเบราว์เซอร์) · มีได้ทีละ 1 บานต่อแท็บ (เปิดใหม่ = ปิดบานเก่า)
- `supported = false` บน Safari / Firefox / มือถือ → ปิดปุ่มพร้อมบอกว่า "ใช้ได้ใน Chrome หรือ Edge บนคอมพิวเตอร์"
- หน้าตา: คัด CSS ทั้งหมด + คลาสของ `<html>`/`<body>` จากหน้าหลักไปให้อัตโนมัติ (Tailwind ใช้ได้ปกติ)

## ตัวจับเวลา (สำคัญ)

แท็บหลักที่อยู่เบื้องหลังนาน ๆ เบราว์เซอร์จะหน่วงตัวจับเวลาเหลือนาทีละครั้ง → ตัวเลขนับถอยหลังค้าง
ให้ตั้ง `setInterval` บน **หน้าต่างลอย** แทน (มองเห็นอยู่ ไม่โดนหน่วง): `timerHost(pip.win).setInterval(...)`
— ตัวอย่าง `useNow` / `useDeployStatus` ใน `components/deploy-countdown`

## ข้อจำกัด

- ปิดแท็บหลัก / ออกจากหน้า = หน้าต่างลอยปิดตาม (ต้องเปิดหน้านั้นทิ้งไว้)
- ชิ้นส่วนที่ลอยตัวเองไปแปะ `document.body` (Toast · FloatingDropdown · ป๊อปอัปกลาง · ConfirmDialog) จะไปโผล่ในหน้าหลัก ไม่ใช่ในหน้าต่างลอย
  → ในหน้าต่างลอยให้โชว์ผลเป็นข้อความในตัวเอง · ปุ่มที่เปิดหน้าใหม่ให้ใช้ `pip.win.open(...)` (ไม่งั้นเบราว์เซอร์บล็อกป๊อปอัป)
- สิทธิ์ / audit: ตัวมันเองไม่ทำอะไรกับข้อมูล — ปุ่มข้างในต้องเช็กสิทธิ์และลง audit เหมือนหน้าเดิม
