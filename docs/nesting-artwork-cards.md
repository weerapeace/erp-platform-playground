# งานจัดเรียงพิมพ์ → การ์ดในคลัง Artwork

เจ้าของสั่งเมื่อ 2026-11-16 ว่า "ตรงนี้อยากให้ upload ลง ARTWORK ด้วย และมีปุ่มกดจัดการได้" แล้วเลือกจาก widget: ข้อ 1, 2, 3, 4

## ใช้ทำอะไร
ไฟล์ PNG ที่ลากใส่หน้าจัดเรียง (`/tasks/nesting/<งาน>`) ทั้งแถบซ้ายและป๊อป "จัดการรูป" จะมีการ์ดในคลังไฟล์กลางแบบ artwork
- รูปบนการ์ดเป็นรูปตัวอย่างย่อ ≤1600px
- ไฟล์ PNG ตัวจริงผูกไว้ที่ช่อง "ไฟล์พิมพ์" ของการ์ด (`assets.nest_print_file` · `lib/print-store`)
- งานต่อไปกด "เลือกลายจากคลัง Artwork" แล้วได้ไฟล์พิมพ์มาเอง

## การทำงาน
1. **แถบ "เก็บเข้าคลัง Artwork เป็น: [แบรนด์] [ชนิด]"** (`app/tasks/nesting/artwork-bar.tsx`)
   - การ์ด artwork บังคับต้องมีแบรนด์และชนิด
   - ระบบจำค่าล่าสุดไว้ในเครื่องนี้ (localStorage `nesting.artworkTarget`)
   - ชนิดตั้งต้นคือ "ลายพิมพ์"
2. **กันซ้ำด้วยเนื้อไฟล์พิมพ์ (sha)** — `GET /api/nesting-jobs/asset-by-print?shas=` ต้องมีสิทธิ์ `nesting.view`
   - ไฟล์เดิมเคยผูกกับการ์ดแล้ว ใช้การ์ดเดิม ไม่สร้างการ์ดใหม่
   - **ไม่ดูชื่อไฟล์** (ดู `docs/duplicate-upload.md`)
   - ลำดับคือหาการ์ดเดิมก่อน แล้วค่อยเช็กแบรนด์/ชนิด → ไฟล์ที่มีการ์ดอยู่แล้วผูกได้ แม้ยังไม่ได้เลือกแบรนด์
3. **ใส่ขนาดจริงเป็นไซส์ "ขนาดจริง" ของการ์ด** — เป็น cm ตาม DPI ในไฟล์ นับเฉพาะส่วนที่มีภาพ (`realSize`)
4. **แถวที่ยังไม่มีการ์ด** มีปุ่ม "เก็บเข้าคลัง" ต่อแถว และ "เก็บเข้าคลังทั้งหมด (N)" ข้างปุ่มเลือกลาย
   - ใช้รูปจากตัวช่วยในเครื่อง ไฟล์จึงต้องอยู่ในเครื่องที่กด
   - ชิ้นที่แยกจากภาพเดียวกันได้การ์ดใบเดียว คือการ์ดของภาพต้นฉบับ
5. **ปุ่ม "⚙️ จัดการ"** บนแถวที่มีการ์ด จะเปิด `AssetDetailPopup` = หน้ารายละเอียดไฟล์ตัวเดียวกับคลังไฟล์กลาง
   - แก้ชื่อแล้ว ชื่อแถวเปลี่ยนตาม (`renameByCard` · ชิ้น = "ชื่อ · ลำดับ")
   - รูป/ไซส์อัปเดตตาม
   - การ์ดถูกลบ แถวจะเลิกผูก

## ของกลางที่ใช้
- สร้างการ์ดผ่าน `POST /api/assets` (source=artwork) ทางเดียวกับคลัง ไม่มีทางอัปแยก
- ผูกไฟล์พิมพ์ผ่าน `saveToCloud` → `/api/nesting-jobs/print-files` PUT (มี audit)
- `AssetDetailPopup` · `BrandSelect` · `downscaleImageWidth`

## สิทธิ์
- สร้างการ์ดได้เมื่อมีทั้ง `assets.upload` และ `nesting.run`
- ไม่มีสิทธิ์ = ไม่มีแถบ/ปุ่มเก็บเข้าคลัง ใช้งานจัดเรียงได้เหมือนเดิม (ไฟล์พิมพ์ยังเก็บในคลังไฟล์พิมพ์ตามปกติ)

## ข้อจำกัด
- ป้าย "☁️ เก็บไฟล์พิมพ์แล้ว" (เดิมเขียนว่า "เก็บในคลังแล้ว") = ไฟล์พิมพ์อยู่ใน R2 ซึ่งเป็นคนละเรื่องกับการ์ดในคลัง Artwork
- ตัวช่วยต่ำกว่า v1.5 ส่งไฟล์พิมพ์ขึ้นคลังไม่ได้ → การ์ดจะไม่มีไฟล์พิมพ์ผูก และกันซ้ำรอบหน้าไม่ได้
- ไม่สร้างโฟลเดอร์ Google Drive ให้ (ทำทีหลังในหน้ารายละเอียดได้) · ไม่ติดแท็กชื่องาน
- มือถือ: ป๊อป "จัดการรูป" แสดงเป็นการ์ดแทนตารางกว้าง
