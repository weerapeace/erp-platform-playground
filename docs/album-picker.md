# ตัวเลือกอัลบั้มคลังไฟล์ (AlbumPicker) — ของกลาง

โค้ด: `components/album-picker` · ตรรกะล้วน + เทสต์: `lib/album-options.ts`, `lib/__tests__/album-options.test.ts`

## ทำไมมี
ช่องอัลบั้มเดิมเอา "ทุกอัลบั้มในระบบ" มาเรียงเป็นชิป/ดรอปดาวน์ (~290 อัน · 2026-11-19) เพราะหน้า SAMPLE Images
สร้างอัลบั้มย่อย "Product NNN" และ "Version N" ซ้อนในอัลบั้มของวัน · ชื่อ "Version 1" ซ้ำกันหลายสิบอันเพราะอยู่คนละแม่ แต่หน้าจอไม่บอกแม่

## ใช้ทำอะไร
| ตัว | ใช้ตอน |
|---|---|
| `AlbumMultiPicker` | เลือกหลายอัลบั้ม — ชิปเฉพาะอันที่เลือก (เกิน 6 ย่อ) + ปุ่ม "+ เพิ่มอัลบั้ม" · `onCreate(name) → id` = มีปุ่มสร้างอัลบั้มใหม่ |
| `AlbumSelect` | เลือกอันเดียว / ตัวกรอง (แทน `<select>`) · `noneLabel` = ค่าว่าง · `compact` = สูง 32px |
| `AlbumTree` | ต้นไม้อัลบั้มที่ผู้เรียกวาดแถวเอง (แถบซ้ายคลังไฟล์) |

ทุกตัว: ค้นชื่อหรือชื่อแม่ได้ (ไม่ต้องตรงเป๊ะ · `lib/fuzzy-rank`) · โชว์เส้นทางแม่ · ใช้ล่าสุดขึ้นบน (`RECENT_KEYS.albums` จำในเครื่อง)
· อัลบั้มปกติก่อน แล้วกลุ่ม "SAMPLE · <แบรนด์>" ยุบไว้ กางทีละชั้น · **รายการไหนเกิน 6 อัน = โชว์ 6 + "ดูอีก N"** (เจ้าของสั่ง · `ALBUM_COLLAPSE_AT`)

```tsx
<AlbumMultiPicker albums={collections} value={ids} onChange={setIds} onCreate={async (n) => newId} disabled={readOnly} />
<AlbumSelect albums={collections} value={id} onChange={setId} noneLabel="— ไม่ระบุ —" />
```
`albums` = ผลจาก `/api/assets/collections` (มี `parent_id` + `group` · ไม่มีก็ได้ = ถือเป็นอัลบั้มปกติ)

## ใช้ที่ไหนแล้ว
รายละเอียดไฟล์ · เพิ่ม Artwork · ลง Artwork หลายไฟล์ · สแกน Drive (ผ่าน `CollectionMultiSelect`) · เพิ่มเข้าอัลบั้ม (หลายไฟล์) · อัปโหลด · ตัวกรองใน AssetPicker · แถบซ้ายคลังไฟล์

## ห้ามใช้เมื่อ
- เลือกอัลบั้ม SAMPLE แบบเห็นรูปปก → `SampleAlbumPickerModal`
- อัลบั้มหน้า Contents → แถบ Contents ของมันเอง

## สิทธิ์ / ประวัติ
- สร้างอัลบั้มใหม่ต้องมีสิทธิ์ `assets.manage` (ตั้ง `createPermission` ได้)
- บันทึกอัลบั้มของไฟล์ (`PATCH /api/assets/:id`) ลงประวัติเป็นชื่ออัลบั้ม จากอะไรเป็นอะไร (`changes` + `albums_added/removed`)
- รายละเอียดไฟล์: เอาออกจากอัลบั้มแล้วบันทึก → แจ้งผลมีปุ่ม "ย้อนกลับ" 5 วิ · Ctrl+S = บันทึก
- บันทึกอัลบั้มลบเฉพาะอันที่เอาออก (ไม่ล้างทั้งชุด) → ลำดับรูปที่จัดเองในอัลบั้ม SAMPLE ไม่หาย

## ข้อจำกัด
- รายการล่าสุดจำในเครื่องของแต่ละคน
- แผงลอยกว้างสุด 360px (มือถือ = เต็มจอเว้นขอบ)

## อัปเข้าอัลบั้ม + สร้างอัลบั้มจาก AlbumSelect (2026-11-27)

- `AlbumSelect` รับ `onCreate(name) → id` (ตามสิทธิ์ `createPermission` ค่าเริ่ม assets.manage) — พิมพ์ชื่อที่ไม่มีในรายการ = ปุ่มสร้าง แล้วเลือกให้เลย
- ตัวเลือกรูปกลาง (AssetPicker) แท็บ "อัปโหลดใหม่": ช่อง "อัปเข้าอัลบั้ม" (ค่าเริ่ม = อัลบั้มที่เปิดดูในแท็บคลัง · ไม่ได้เปิด = อัลบั้มที่อัปล่าสุด pref `asset_upload_album`) + ชิป "ใช้ล่าสุด" 3 อัลบั้ม (lib/recent-picks `uploadAlbums`) · ไฟล์เกิน 4 MB / วิดีโอ ยังเข้าคลังกลางเท่านั้น
