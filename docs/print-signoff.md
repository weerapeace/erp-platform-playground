# กล่องลงชื่อบนเอกสารพิมพ์ (ของกลาง)

## ใช้ทำอะไร
ช่องให้คน **เซ็นมือบนกระดาษ** ตอนส่ง-รับงาน: หัวกล่อง · ชื่อ · ลงชื่อ · วันที่ (เขียนมือ `____/____/______` หรือพิมพ์วันที่ที่ระบบรู้)

ต่างจาก `lib/doc-stamps` = รูปลายเซ็น/ตราที่อัปโหลดไว้แปะลงเอกสาร (ใบสั่งซื้อ) — อันนั้นไม่ใช่ช่องให้เซ็น

## ชิ้นส่วน
| ไฟล์ | หน้าที่ |
|---|---|
| `lib/print-signoff.ts` | `SignBox` / `SignLine` · `signBoxHtml` · `signoffHtml(boxes, { title, cols })` · `SIGNOFF_CSS` · `BLANK_DATE` (pure, escape ให้แล้ว) |
| `lib/work-order-print.ts` | ผู้ใช้รายแรก: `woSignoffBoxes(mo, signoff, extras)` สร้างกล่องของใบสั่งงานผลิต |

ชนิดบรรทัด: `write` (ป้าย + เส้นประ) · `sign` ("ลงชื่อ") · `date` · `text` (ข้อความ + ชิดขวา) · `pair` (ดี ___ เสีย ___) · `sep`

## ใช้กับเอกสารใหม่
1. สร้าง `SignBox[]` จากข้อมูลของเอกสาร
2. ใส่ `signoffHtml(boxes, { title: "ลงชื่อรับ-ส่งงาน" })` ลงใน data แล้ววางด้วย `{{{...}}}` ในเทมเพลต
3. ต่อ `SIGNOFF_CSS` ท้าย `custom_css` (ครั้งเดียว) — ขนาดตัวอักษรตาม `.doc` ของเอกสารนั้น

## ใบสั่งงานผลิต — ตั้งค่าได้ (แผง "ตั้งค่าใบพิมพ์" ในหน้าพิมพ์ · ค่ากลาง `ui_config wo_print_columns`)
- **หัวใบ** เปิด/ปิด 15 ช่อง · ขนาดรูป 25–60 มม. · ลากเรียง 4 กล่อง · "เดิม N + เหตุผล" ขึ้นเมื่อเคยแก้จำนวน (`mo_qty_changes` ที่ยังไม่ย้อน)
- **กล่องลงชื่อ** แผนกตัด/เตรียม (ไม่ใส่ / รวม / แยกเตรียม-ตัด) · ช่างรับงาน 1 กล่องต่อใบจ่ายงาน (`mo_work_orders`) รวมโต๊ะเดียวกันได้ · หลายช่างในใบเดียว = เซ็นแยกรายคน/ช่องเดียว · กล่องว่างเมื่อยังไม่จ่าย / เผื่อเพิ่ม · วันที่ เขียนมือ/เติมจากระบบ (วันจ่ายงาน · `prep_done_at`/`cut_done_at` · วันสั่ง) · วางใต้หัวใบ/ท้ายใบ
- **ส่วนเสริม** ผู้สั่งผลิต + หัวหน้าอนุมัติ (แทนช่องลงชื่อท้ายใบแบบเดิม) · QC ตรวจรับ · ตารางส่งคืนงาน 3 แถว · หมายเหตุถึงช่าง · ช่องติ๊กเตรียม (= คอลัมน์ ☑ ตารางสรุป)
- ปิด "กล่องลงชื่อ + ส่วนเสริม" ในข้อ 0 = ไม่พิมพ์ทั้งชุด (ชุดสำเร็จ "เฉพาะสรุปวัตถุดิบ"/"เฉพาะบล็อกตัด" ปิดให้อยู่แล้ว)
- บันทึกต้องมีสิทธิ์ `products.edit` · ข้อมูลมาจาก `/api/mo/[id]` (`work_orders`, `qty_from`, `qty_change_reason`, `split_from`)

## ข้อจำกัด
- ใบที่ใช้เทมเพลตลากวาง (pdfme) ไม่ได้ใช้ตั้งค่านี้
- ในระบบไม่มีข้อมูลว่า "ใครตัด/เตรียม" → ช่องชื่อเว้นให้เขียน
- ข้อมูลจริง 2026-10-31: ใบเปิด 465 ใบ จ่ายงานแล้ว 135 ใบ · มีวันเตรียม/ตัดเสร็จ 12 ใบ → ส่วนใหญ่จะเห็นกล่องว่าง/วันที่เขียนมือ
- `lib/list-print` (ใบพิมพ์แบบรายการ) ยังใช้ `signatureHtml` เส้นเดียวของตัวเอง — ย้ายมาใช้ตัวนี้ได้ถ้าอยากได้ชื่อ/วันที่
