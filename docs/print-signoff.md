# กล่องลงชื่อบนเอกสารพิมพ์ (ของกลาง)

## ใช้ทำอะไร
ช่องให้คน **เซ็นมือบนกระดาษ** ตอนส่ง-รับงาน: หัวกล่อง · ชื่อ · ลงชื่อ · วันที่ (เขียนมือ `____/____/______` หรือพิมพ์วันที่ที่ระบบรู้)

ต่างจาก `lib/doc-stamps` = รูปลายเซ็น/ตราที่อัปโหลดไว้แปะลงเอกสาร (ใบสั่งซื้อ) — อันนั้นไม่ใช่ช่องให้เซ็น

## ชิ้นส่วน
| ไฟล์ | หน้าที่ |
|---|---|
| `lib/print-signoff.ts` | `SignBox` / `SignLine` · `signBoxHtml` · `signoffHtml(boxes, { title, cols })` · `SIGNOFF_CSS` · `BLANK_DATE` (pure, escape ให้แล้ว) |
| `lib/work-order-print.ts` | ผู้ใช้รายแรก: `woSignoffBoxes(mo, signoff, extras)` สร้างกล่องของใบสั่งงานผลิต |

ชนิดบรรทัด: `write` (ป้าย + เส้นประ) · `sign` ("ลงชื่อ") · `date` · `text` (ข้อความ + ชิดขวา) · `pair` (ดี ___ เสีย ___) · `sep`

## ใช้กับเอกสารใหม่
1. สร้าง `SignBox[]` จากข้อมูลของเอกสาร
2. ใส่ `signoffHtml(boxes, { title: "ลงชื่อรับ-ส่งงาน" })` ลงใน data แล้ววางด้วย `{{{...}}}` ในเทมเพลต
3. ต่อ `SIGNOFF_CSS` ท้าย `custom_css` (ครั้งเดียว) — ขนาดตัวอักษรตาม `.doc` ของเอกสารนั้น

## ใบสั่งงานผลิต — ตั้งค่าได้ (แผง "ตั้งค่าใบพิมพ์" ในหน้าพิมพ์ · ค่ากลาง `ui_config wo_print_columns`)
- **หัวใบ** เปิด/ปิด 15 ช่อง · ขนาดรูป 25–60 มม. · ลากเรียง 4 กล่อง · "เดิม N + เหตุผล" ขึ้นเมื่อเคยแก้จำนวน (`mo_qty_changes` ที่ยังไม่ย้อน)
- **กล่องลงชื่อ** แผนกตัด/เตรียม (ไม่ใส่ / รวม / แยกเตรียม-ตัด) · ช่างรับงาน 1 กล่องต่อใบจ่ายงาน (`mo_work_orders`) รวมโต๊ะเดียวกันได้ · หลายช่างในใบเดียว = เซ็นแยกรายคน/ช่องเดียว · กล่องว่างเมื่อยังไม่จ่าย / เผื่อเพิ่ม · วันที่ เขียนมือ/เติมจากระบบ (วันจ่ายงาน · `prep_done_at`/`cut_done_at` · วันสั่ง) · วางใต้หัวใบ/ท้ายใบ
- **ส่วนเสริม** ผู้สั่งผลิต + หัวหน้าอนุมัติ (แทนช่องลงชื่อท้ายใบแบบเดิม) · QC ตรวจรับ · ตารางส่งคืนงาน 3 แถว · หมายเหตุถึงช่าง · ช่องติ๊กเตรียม (= คอลัมน์ ☑ ตารางสรุป)
- **กล่องไหนโชว์ · อยู่แผ่นไหน** (ข้อ 6 ในแผง) — ติ๊กโชว์ทีละกล่อง (แยกเตรียม/ตัดได้) · โหมด "แยกใบ" เลือกแผ่นต่อกล่องได้หลายแผ่น (`signoff.place`) · ค่าเริ่ม: ผู้สั่ง+เตรียม→ใบสรุป · ตัด→ใบบล็อกตัด · กล่องรวมตัด/เตรียม→สรุป+บล็อกตัด · ช่าง/QC/ส่งคืน/หมายเหตุ→ใบรายละเอียด · แผ่นที่เลือกไม่ได้พิมพ์ = ไปแผ่นสุดท้ายที่พิมพ์ (`woBoxSheets`) · ทำงานโดย `buildWoHtmlData` เตรียม `signoff_html_<แผ่น>` แล้ว `woSectionDataList` หยิบใส่แต่ละแผ่น
- ปิด "กล่องลงชื่อ + ส่วนเสริม" ในข้อ 0 = ไม่พิมพ์ทั้งชุด (ชุดสำเร็จ "เฉพาะสรุปวัตถุดิบ"/"เฉพาะบล็อกตัด" ปิดให้อยู่แล้ว)
- บันทึกต้องมีสิทธิ์ `products.edit` · ข้อมูลมาจาก `/api/mo/[id]` (`work_orders`, `qty_from`, `qty_change_reason`, `split_from`)

## ตารางบล็อกตัด: เฉพาะแถวที่มีกว้าง x ยาว (ข้อ 2 ในแผง · `lines_cut_only`)
- ติ๊กแล้วแถวที่มีแค่กว้าง / แค่ยาว / แค่จำนวน (ซิป ด้าย ฯลฯ) ไม่แสดง · ลำดับเรียงใหม่ 1..n · ใต้ตารางบอก "ไม่แสดง N รายการ"
- ใบที่ไม่มีแถวกว้าง x ยาวเลย = ข้อความแจ้งแทนตารางเปล่า · มีผลเฉพาะใบพิมพ์ HTML (ตาราง pdfme ใช้ `woTableRows` ครบเหมือนเดิม)
- ข้อมูลจริง 2026-10-31: 9,125 แถว มีกว้าง x ยาว 6,541 (72%) · ใบสั่งผลิต 75/443 ใบไม่มีแถวกว้าง x ยาวเลย

## ข้อควรระวัง — ปัญหาที่เคยเกิด (`issues` · ข้อ 7 ในแผง)
- กล่องขอบส้ม 2 ฝั่ง: **รุ่นนี้ (ทุกสี)** = `parent_sku_issues` ที่ `sku` ว่าง · **SKU นี้** = `parent_sku_issues.sku` = รหัสนี้ (จดเฉพาะสี) + `defect_logs` ของ SKU นี้ รวมเป็นรายสาเหตุ (กี่ครั้ง · กี่ชิ้น · ล่าสุด)
- ข้อมูลมาจาก `/api/mo/[id]?issues=1` (หน้าพิมพ์ขอเท่านั้น — ป๊อปเช็กลิสต์บอร์ดไม่ต้องจ่าย query เพิ่ม) · `woIssuesHtml()` ใน lib/work-order-print
- ตั้งค่า: โชว์/ไม่โชว์ · ใต้หัวใบ/ท้ายตาราง · สูงสุดต่อกลุ่ม 3/5/ทั้งหมด · จำนวนครั้ง/ชิ้น/ล่าสุด · ยังไม่มีบันทึก = ซ่อนกล่อง / เว้นเส้นให้ช่างเขียน · พิมพ์ทุกแผ่นตอนแยกใบ
- **จดเฉพาะสี**: คอลัมน์ใหม่ `parent_sku_issues.sku` (migration 202611100300, null = ทั้งรุ่นแบบเดิม) · `ParentIssuesPanel` ที่เปิดจากสีใดสีหนึ่ง (ป๊อป QC, หน้าใบสั่งผลิต) มีปุ่ม "ทุกสีในรุ่นนี้ / เฉพาะสีนี้" · ป้ายขอบเขตทุกแถว · GET ?sku= ไม่เอาปัญหาเฉพาะสีอื่น
- QC จดให้อัตโนมัติยังเป็นระดับทั้งรุ่นเหมือนเดิม (กันซ้ำเฉพาะแถว sku ว่าง)
- ขนาดที่ไม่มีตัวเลขจริง ("0 x 0 cm." / ว่าง) ไม่พิมพ์ทั้งหัวใบและส่วนรายละเอียด
- ข้อมูลจริง 2026-10-31: ปัญหารุ่น 0 แถว · ของเสีย QC 4 แถว (2 SKU) → ใบที่เปิดอยู่เห็นกล่องแค่ 2 ใบ จนกว่าจะเริ่มจดปัญหา

## ขนาดหัวใบ (หัวใบ · `header.size` + `header.title_inline`)
- ปกติ (หน้าตาเดิม ไม่ปล่อย CSS เพิ่ม) / กะทัดรัด / เล็กสุด — ย่อระยะขอบบน · ชื่อบริษัท · หัวข้อ · ช่องไฟกล่องหัว · QR · ความสูงบาร์โค้ด (ความกว้างเส้นบาร์โค้ดไม่ย่อ)
- กดปุ่มขนาดในแผง = ตั้งรูปให้ด้วย (46 / 34 / 26 มม.) + บรรทัดเดียว (กะทัดรัด/เล็กสุด) · ปรับต่อเองได้
- "ชื่อบริษัท + หัวข้อ บรรทัดเดียว" = หัวข้อซ้าย บริษัทขวา ประหยัด ~1 ซม.

## บาร์โค้ดเส้นเลขใบ (หัวใบ · `header.show.barcode`, ค่าเริ่ม = เปิด)
- Code128 ของ **เลขใบเปล่า ๆ** (เช่น `MO-2026-00198`) ให้เครื่องยิง USB อ่าน — ห้ามใส่ลิงก์ (ยาว = เส้นถี่ อ่านยาก) · QR เดิมยังอยู่ (มือถือสแกนเปิด /s/<เลขใบ>)
- `woBarcodeHtml(mo_no)` สร้าง SVG ในเบราว์เซอร์ (jsbarcode dynamic import) · เส้นเล็กสุด 0.33 มม. ตายตัว → เลขใบ 13 ตัว = 167 เส้น ≈ 55 มม. + ขอบว่าง 3.5 มม. ซ้ายขวา · สูง 10/9 มม. (จอ/พิมพ์)
- กว้างเกินกล่องเลขที่+QR (44 มม.) จึงวางที่ **แถบล่างของกล่องหัวใบ ซ้ายของกำหนดส่ง** · ตัวเลขใต้เส้นเป็น HTML (ไม่ยืดตามเส้น)
- สร้างไม่ได้ = เหลือเลขใบเป็นตัวหนังสือ ใบพิมพ์ไม่พัง

## ข้อจำกัด
- ใบที่ใช้เทมเพลตลากวาง (pdfme) ไม่ได้ใช้ตั้งค่านี้
- ในระบบไม่มีข้อมูลว่า "ใครตัด/เตรียม" → ช่องชื่อเว้นให้เขียน
- ข้อมูลจริง 2026-10-31: ใบเปิด 465 ใบ จ่ายงานแล้ว 135 ใบ · มีวันเตรียม/ตัดเสร็จ 12 ใบ → ส่วนใหญ่จะเห็นกล่องว่าง/วันที่เขียนมือ
- `lib/list-print` (ใบพิมพ์แบบรายการ) ยังใช้ `signatureHtml` เส้นเดียวของตัวเอง — ย้ายมาใช้ตัวนี้ได้ถ้าอยากได้ชื่อ/วันที่
