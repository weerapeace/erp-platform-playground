# เปิดหน้าให้เช็กหลังส่งขึ้นร้าน (push-open)

> เจ้าของสั่ง 2026-11-21: "กดส่งเสร็จให้เด้งหน้าใหม่เพื่อเช็ก เปิด-ปิดได้ที่ตั้งค่า เลือกได้ว่าจะเปิดหน้าสินค้า หรือหน้าลงสินค้าใน platform"
> เลือกแบบ A (เปิดแท็บรอไว้ตอนกดส่ง) · ค่าหลัก Seller Center · ข้อ 1, 2, 3 · ค่าเริ่มต้น = **ปิด** (ข้อ 4 ไม่ได้เลือก — ใครใช้ไปเปิดเอง)

## ทำงานยังไง
1. กดปุ่มส่งขึ้นร้าน → ระบบเปิดแท็บใหม่รอไว้ทันที ขึ้นว่า "กำลังส่งขึ้นร้าน…" (ถ้ารอส่งเสร็จก่อนค่อยเปิด เบราว์เซอร์จะบล็อก เพราะส่งนานเกิน 5 วินาที)
2. ส่งเสร็จ → พาแท็บไปหน้าที่ตั้งไว้ · ส่งไม่สำเร็จ → ปิดแท็บเอง
3. หน้าสินค้ายังไม่พร้อม (ปิดขาย · ร่างบนร้าน · Lazada รอตรวจ · ไม่มี Shop ID) → เปิด Seller Center แทน และบอกเหตุผลในแจ้งผล (ข้อ 2)
4. ส่งหลายตัว → เปิดอย่างมาก 5 หน้า ที่เหลือเป็นปุ่มในแจ้งผลมุมจอ กดทีละหน้า (ข้อ 1)
   - เบราว์เซอร์ส่วนใหญ่ให้เปิดหน้าต่างใหม่ได้ **1 หน้าต่อการกด 1 ครั้ง** — อยากให้เปิดครบ ให้กดอนุญาตป๊อปอัปให้เว็บนี้ (ไอคอนในช่องที่อยู่เว็บ)
5. หลังร้านที่ไม่มีลิงก์ตรงเข้าหน้าแก้สินค้า (TikTok · LINE) → เปิดหน้าแรกหลังร้าน + คัดลอกรหัสสินค้าไว้ให้ค้น

## ตั้งค่า (ต่อคน · ตามไปทุกเครื่อง)
- เมนูโปรไฟล์ → หัวข้อ "ลงสินค้า" → "หลังส่งขึ้นร้าน: เปิดหน้าให้เช็ก"
- ปุ่ม ⚙ "เปิดหน้าให้เช็ก: …" ในขั้นยืนยันของตัวช่วยลงสินค้า (ข้อ 3)
- เปิด/ปิด · เปิดหน้าไหน (หน้าสินค้าที่ลูกค้าเห็น / หน้าแก้สินค้าใน Seller Center / ทั้งสองหน้า) · ตั้งแยกรายร้านได้ (หรือ "ไม่เปิด")
- เก็บที่ user_ui_prefs key `push_open_after_publish`

## ใช้ในโค้ด (ทุกปุ่มที่ส่งขึ้นร้าน)
```tsx
const pushOpen = usePushOpen();                         // components/push-open
const onClick = async () => {
  const session = pushOpen.prepare([{ code: "shopee" }]);   // ⚠️ ก่อน await ใด ๆ (ยังอยู่ในจังหวะกด)
  const r = await sendToShop();
  session.finish(r.ok ? [{ code: "shopee", shopName: "Shopee", productId: r.itemId, state: "hidden", shopRef }] : []);
};
```
- `state`: live = ขึ้นขายแล้ว · hidden = ปิดขาย · draft = ร่างบนร้าน · review = ร้านยังตรวจ
- เว็บร้าน (ไม่มี Seller Center): ส่ง `links: { sellerCenter: "<หน้าแก้ใน ERP>", sellerExact: true, sellerLabel: "หน้าแก้ใน ERP" }`
- ลิงก์ทั้งหมดมาจาก `lib/platform-links` (listingLinks) — ห้ามสร้างลิงก์ร้านเอง

## ใช้แล้วที่
- ตัวช่วยลงสินค้า (ลงร้านนี้ · ลงทุกร้าน · เปิดขายทันที) — components/platform-listing/add-to-platform-wizard
- อัปเดตให้ตรง (หน้าเทียบ MatchSystemDialog — แท็บแพลตฟอร์มของ Parent SKU + เช็กข้ามร้าน) · TikTok แก้รูป/รายละเอียด/ชื่อตัวเลือก = state review
- เปลี่ยนปกโปรทุกร้าน (ทำเดี๋ยวนี้ · เริ่มเดี๋ยวนี้ · ลองใหม่ · ย้อนปกเดิม · ย้อนทับเลย — กดเองเท่านั้น ตัวตั้งเวลาไม่เปิด) — components/promo-covers/results.tsx · เว็บร้าน = /website/<slug>?tab=listings

## ข้อจำกัด
- แค่เปิดหน้า ไม่ส่งอะไรขึ้นร้าน · งานตั้งเวลา/หลังบ้าน (ไม่มีคนกด) เปิดแท็บไม่ได้
- แอปบนมือถือ (โหมดแอป) บางเครื่องเปิดแท็บใหม่เป็นเบราว์เซอร์ภายนอก
