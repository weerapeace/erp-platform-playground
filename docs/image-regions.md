# ImageRegions — จุดบนรูป (ของกลาง)

`components/image-regions` — วางกรอบสี่เหลี่ยมบนรูปภาพ แล้วผูกกรอบกับข้อมูลอะไรก็ได้

## ใช้ทำอะไร

- แท็บ 🎨 Swatch ในหน้า SKU: รูปการ์ดสีผ้า/ด้าย/อะไหล่ กดที่ชิ้นบนรูปแล้วเปิด SKU
- ใช้ซ้ำได้กับงานอื่น เช่น ชี้ตำหนิบนรูป QC, ชี้ตำแหน่งชิ้นส่วนบนรูปสินค้า

## 2 โหมด

| โหมด | สิ่งที่เห็น | การใช้งาน |
|---|---|---|
| `view` | เห็นแต่รูป **ไม่มีเส้นกรอบ** | ชี้ = ป้ายข้อมูลลอยขึ้น · กด = `onRegionClick` |
| `edit` | เห็นกรอบทุกอัน | ลากที่ว่าง = วาดกรอบใหม่ · ลากกรอบ = ย้าย · ลากมุม = ปรับขนาด |

สีกรอบในโหมด `edit`: เขียว = สมบูรณ์ · ส้มเส้นประ = ยังไม่สมบูรณ์ (`isMuted`) · ม่วง = กำลังเลือก

## กติกาพิกัด

พิกัดทุกตัว (`x, y, w, h`) เป็น **เปอร์เซ็นต์ของรูป (0-100)** ไม่ใช่พิกเซล
กรอบจึงตรงตำแหน่งทุกขนาดจอและทุกระดับซูม · กรอบเล็กกว่า 1.2% ถือว่าเป็นการคลิก ไม่สร้างกรอบ

## ตัวอย่าง

```tsx
<ImageRegions
  src={imageUrl} mode="edit" regions={spots} selectedId={selId}
  onSelect={setSelId}
  onCreate={(rect) => addSpot(rect)}
  onChange={(id, rect) => updateSpot(id, rect)}
  regionLabel={(r) => r.sku?.code ?? "ยังไม่ผูก"}
  isMuted={(r) => !r.sku_id}
/>
```

## ห้าม

- ห้ามเขียนตัวลากกรอบเองในหน้าโมดูล ให้ใช้ตัวนี้
- ตัวนี้ไม่บันทึกข้อมูลเอง หน้าที่เรียกใช้ต้องเก็บ state และยิง API เอง (สิทธิ์ + audit อยู่ที่ API)

## ข้อจำกัด

- กรอบเป็นสี่เหลี่ยมตรง หมุนไม่ได้ รูปที่ถ่ายเอียงจะครอบไม่พอดี
- บนมือถือวาดกรอบได้แต่ทำยาก แนะนำตั้งค่าบนคอม
