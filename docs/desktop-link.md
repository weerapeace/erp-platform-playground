# เชื่อมโปรแกรมบนเครื่องกับ ERP (`/desktop-link`)

> ให้โปรแกรมบนเครื่อง (ตอนนี้: **Louis Batch**) ใช้บัญชี ERP ของคนที่นั่งเครื่องนั้น เช่น ส่งรูป JPG เข้า SAMPLE Images
> เพิ่มเมื่อ 2026-11-14 (Louis Batch 1.0.14 · เจ้าของเลือก "เชื่อมผ่านเบราว์เซอร์")
> โค้ด: หน้า `app/desktop-link/page.tsx` · API `app/api/desktop-link/route.ts` · ตรรกะ + เทสต์ `lib/desktop-link.ts`

## ขั้นตอน (ฝั่งคนใช้)

1. ในโปรแกรมกด **เชื่อม ERP** → เบราว์เซอร์ปกติ (Chrome ที่ล็อกอิน ERP อยู่แล้ว) เปิดหน้านี้
2. ยังไม่ล็อกอิน = ปุ่มไปหน้าเข้าสู่ระบบ แล้วพากลับมา · ล็อกอินแล้ว = เห็นชื่อโปรแกรม + อีเมลบัญชี
3. กด **อนุญาต** → หน้าเว็บส่งการเข้าสู่ระบบกลับไปที่โปรแกรม → โปรแกรมขึ้น "เชื่อมแล้ว"

ใช้ได้กับทุกวิธีล็อกอิน (ลิงก์อีเมล · Google · รหัสผ่าน · PIN) เพราะอาศัยการล็อกอินที่มีอยู่ในเบราว์เซอร์

## ทำงานยังไง

- โปรแกรมเปิด `/desktop-link?app=Louis%20Batch&return=http://127.0.0.1:<port>/erp-linked&state=<รหัสสุ่ม>`
- กดอนุญาต → `POST /api/desktop-link {app}` (Bearer ของคนที่ล็อกอิน) → server สร้าง magic link ของ **อีเมลของคนนั้นเอง** (`auth.admin.generateLink` — ไม่ส่งอีเมล) แล้วยืนยันทันที (`verifyOtp`) = **การเข้าสู่ระบบชุดใหม่ของโปรแกรม**
- หน้าเว็บพาไป `return#state=…&at=…&rt=…&exp=…&email=…&name=…` — ส่วน `#` ไม่ถูกส่งไปเซิร์ฟเวอร์ใดระหว่างทาง · หน้าในโปรแกรมอ่านเองแล้วเช็ก state ตรงกับที่ขอ
- โปรแกรมต่ออายุเองด้วย refresh token ของชุดตัวเอง (`/auth/v1/token?grant_type=refresh_token`)

**ทำไมไม่ส่ง token ของเบราว์เซอร์ไปเลย:** Supabase หมุน refresh token ทุกครั้งที่ต่ออายุ — ใช้ชุดเดียวกันสองที่ ใครต่ออายุก่อนอีกฝั่งหลุด (และอาจโดนตัดทั้งชุดเพราะดูเหมือนโดนขโมย)

## ความปลอดภัย

| กัน | อย่างไร |
|---|---|
| ออกให้คนอื่น | อีเมลมาจาก token ของคนที่เรียก ไม่รับจาก body · ยืนยันแล้วเช็ก `user.id` ตรงกัน |
| ส่ง token ไปเว็บอื่น | `safeReturnUrl` รับเฉพาะ `http://127.0.0.1:<1024-65535>/erp-linked` ตรงตัว |
| ลิงก์ปลอม | `state` สุ่มจากโปรแกรม (16-64 ตัว) — โปรแกรมรับเฉพาะ state ที่ตัวเองเพิ่งสร้าง |
| โปรแกรมแปลก | `DESKTOP_APPS` (เพิ่มโปรแกรมใหม่ที่นี่ที่เดียว) |
| แอบเชื่อม | คนต้องกด "อนุญาต" เองทุกครั้ง · audit `desktop_link` (entity `auth_session`, metadata.app) |

สิทธิ์ของโปรแกรม = สิทธิ์ของบัญชีนั้นเท่าเดิม (ทุก API ยังตรวจ `guardApi` ตามปกติ)

## ข้อจำกัด

- ยกเลิกการเชื่อม = ปุ่ม "เลิกเชื่อม" ในโปรแกรม (ลบการเข้าสู่ระบบที่เก็บในเครื่อง) — ยังไม่มีหน้าดู/ตัดการเชื่อมจากฝั่งเว็บ
- สร้าง magic link ใหม่ = ลิงก์อีเมลเข้าระบบที่ขอค้างไว้ (ถ้ามี) ใช้ไม่ได้แล้ว — ขอใหม่ได้ตามปกติ
