# 🏪 ศูนย์ร้านออนไลน์ (`/master/channel-portal`)

หน้าทางเข้าเดียวของงานร้านออนไลน์ทุกร้าน ทุกแบรนด์ (Shopee · Lazada · TikTok · LINE SHOPPING · เว็บร้านของเรา) — ทำไว้แทนการเข้า BigSeller
เป็นหน้าแรกของแอป "ช่องทางขาย" (`erp_app_groups.key = marketplace`)

เจ้าของเลือก 2026-11-24 (widget 2 รอบ): แบบการ์ดร้าน + งานที่ต้องทำ + ทางลัด · ข้อ 1 หน้าแรกแอป · 2 เพิ่มหน้าที่หลุดเมนู · 3 ปุ่มดึงออเดอร์บนการ์ดร้าน · 4 ปักหมุด = การ์ด "เมนูของฉัน" แถวบน · 6 ซ่อนทางลัดตามสิทธิ์ แบบ B

## มีอะไรบนหน้า
| ส่วน | มาจากไหน (ของเดิม — ไม่เขียนกฎใหม่ซ้ำ) |
|---|---|
| เมนูของฉัน (หมุด) | `useUserPref("channel_portal_pins")` จำแยกแต่ละคน ตามไปทุกเครื่อง · จัดเรียง ← → · เอาออก · ทุกครั้งมีปุ่ม "ย้อนกลับ" (toast.undo) |
| ยอดขายวันนี้ | มูลค่าสินค้า (ราคาหลังส่วนลดร้าน × จำนวน) = ตัวเดียวกับแดชบอร์ด `lib/platform-dashboard-calc` · บรรทัดล่าง = ลูกค้าจ่ายจริง · ไม่นับออเดอร์จากเมล |
| รอจัดส่ง | `needsAction` (`lib/platform-order-status`) ตัวเดียวกับศูนย์ออเดอร์/หน้าแบรนด์ · รวมทุกช่องทาง (รวม LINE OA) |
| การ์ดร้าน | รายชื่อร้าน + ทางดึง + วันต้องเชื่อมใหม่ = `loadPullInputs` (`lib/order-pull-server`) · สถานะดึง = `shopPullHealth` |
| ยังไม่จับคู่ | กฎหน้าแบรนด์ (ไม่นับที่ร้านลบแล้ว / กดไม่ต้องจับคู่) |
| สินค้าซ้ำ | กฎ `/api/platform-catalog/duplicates` (รายการที่ยังอยู่บนร้าน + จับคู่แล้ว ≥ 2 ต่อรุ่น − กลุ่ม "ไม่ใช่ตัวซ้ำ") — นับเป็น "กลุ่ม" |
| ราคา ฿1 หรือต่ำกว่า | **ตัวนับใหม่** — รายการบนร้านที่ราคา ≤ 1 และไม่ได้ปิดขาย (ไม่นับ unlist/inactive เช่น บริการห่อของขวัญที่ปิดไว้) · โชว์รายชื่อใต้กล่องงาน |
| ทางลัดทุกหน้า | `PORTAL_GROUPS` ใน `lib/channel-portal.ts` (5 หมวด: ลงสินค้า · ออเดอร์/แพ็ก/ส่ง · ยอดขาย/ราคา/โปร · ตรวจความถูกต้อง · ตั้งค่า) |

สถานะการ์ดร้าน: เชื่อมแล้ว · เหลือ N วัน (≤ 30 วัน · ≤ 7 วันเป็นสีแดง) · หมดอายุ · นำเข้าไฟล์ (ไม่มี API แต่มีสินค้าจากไฟล์) · ยังไม่เชื่อม · ระบบเรา (เว็บร้าน)
วันต้องเชื่อมใหม่: Lazada/TikTok = refresh token · Shopee = อายุการอนุญาต (refresh ยืดเองทุกวัน)

## ใครเห็นอะไร (แบบ B)
- **ทางลัด**: ต้องมีสิทธิ์ของหน้านั้น (`perm` ในทะเบียน) **และ** ถ้าหน้านั้นเป็นเมนูในแอป "ช่องทางขาย" ต้องผ่านกฎแถบเมนูจริง (`lib/menu-visibility`): ซ่อนในแอป · ใครเห็นเมนู (ตำแหน่ง/รายคน) · สิทธิ์ของเมนู
  → แอดมินซ่อนเมนูจากใครใน ⚙️ ตั้งค่าแอป › เมนูและคนเห็น = ทางลัดใน Portal หายตาม (ตั้งที่เดียว) · หมุดของหน้าที่มองไม่เห็นก็ไม่โชว์
  · ซ่อน ≠ ห้ามเข้า (กันจริงที่ API ของแต่ละหน้า)
- **ตัวเลข** (API ตัดให้ตั้งแต่ server — ไม่มีสิทธิ์ = ได้ null ไม่ส่งออกไป): รายการบนร้าน/จับคู่/ซ้ำ/ราคา ฿1 = `products.platforms.view` · ยอดขาย/ออเดอร์ = `platform_orders.view` · รอจัดส่ง = `platform_orders.view` หรือ `packing.pack` (คนแพ็ก → การ์ดพาไป `/packing`)
- **ปุ่ม "ดึงออเดอร์ตอนนี้"** = `platform_orders.manage` · ยิง `POST /api/platform-orders/pull` ตัวเดิม (ดึงเข้ามาอย่างเดียว ไม่ส่งอะไรขึ้นร้าน · audit ที่ปลายทาง)

## ไฟล์
- กติกา (pure + เทสต์): `lib/channel-portal.ts` · `lib/__tests__/channel-portal.test.ts`
- ตัวนับ: `lib/channel-portal-server.ts` · API `GET /api/channel-portal` (ต้องล็อกอิน · อ่านอย่างเดียว)
- หน้า: `app/master/channel-portal/page.tsx` · `components/channel-portal/portal-view.tsx`
- สิทธิ์ตามเมนู: `lib/menu-permissions.ts` → `/master/channel-portal`

## เพิ่ม/แก้
- **หน้าใหม่ของช่องทางขาย** → เพิ่มลิงก์ใน `PORTAL_GROUPS` ที่เดียว (perm ต้องตรง permission_key ของเมนู/สิทธิ์ที่ API หน้านั้นใช้) — key ห้ามเปลี่ยนภายหลัง (หมุดของแต่ละคนจำด้วย key)
- **ร้านใหม่** → มาเองจาก `loadPullInputs` (ต้องมีใน `PULL_PLATFORMS` + `PORTAL_PLATFORM_LABEL`)
- **งานใหม่ในกล่องงานที่ต้องทำ** → เพิ่มตัวเลขใน `PortalTotals` (server) + การ์ดใน `buildPortalTodos`

## ข้อจำกัด
- หน้านี้ไม่มีตรรกะของหน้าปลายทาง (ลงสินค้า/แก้ราคา/ลบ ทำที่หน้านั้น ๆ)
- เลือกแบรนด์แล้ว ตัวเลขรวม = ผลรวมการ์ดร้านของแบรนด์นั้น (ไม่รวมออเดอร์ช่องทางที่ไม่มีการ์ด เช่น LINE OA) · การ์ดเว็บร้านโชว์ทุกแบรนด์
- โหลด ~2-3 วินาที (นับทุกร้านสด ๆ ทุกครั้ง)
