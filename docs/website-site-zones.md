# 🚪 โซนของเว็บ (siteZones) — เมนูแยกต่อส่วนของเว็บ + แถบสลับโซนบนสุด

> เพิ่ม 2026-10-30 · เฟส 2 ของ "หน้าเปิดแบ่งช่อง" (เฟส 1 = Section `split-entry` ดู `docs/website-block-contract.md` หัวข้อ 🚪)

## ใช้ทำอะไร

แบ่งเว็บร้านเดียวเป็นหลายส่วนที่ **เมนูต่างกัน** เหมือนเข้าคนละเว็บ แต่ยังสลับไปมาได้ เช่น ร้าน IG:

- โซน "รับผลิต" = หน้า `/oem` (และหน้าลูก) → เมนู: บริการ · ขั้นตอนสั่งผลิต · ผลงาน + ปุ่ม "ขอใบเสนอราคา" · ไม่มีตะกร้า
- โซน "ร้านอะไหล่" = หน้าอื่นทั้งหมด (สินค้า ตะกร้า ชำระเงิน) → เมนูหลักของร้าน

ลูกค้าเห็น **แถบสลับโซน** บนสุดเหนือหัวเว็บ (แท็บ = ชื่อโซน · โซนที่อยู่มีเส้นใต้) · หน้าแรก `/` มักเป็นหน้าเปิดแบ่งช่อง จึงซ่อนแถบไว้ (ตั้งให้โชว์ได้)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่

- ✅ ร้านมีธุรกิจหลายแบบที่ลูกค้าคนละกลุ่ม (รับผลิต / ขายปลีก / ขายส่ง) และอยากให้เมนูไม่ปนกัน
- ❌ แค่อยากจัดกลุ่มเมนู → ใช้เมนูย่อย/แผงเมนูใหญ่ (ดีไซน์ › เมนู) พอ
- ❌ อยากให้ 2 ส่วนคนละโดเมน/ตะกร้าแยก → ยังไม่รองรับ (ตอนนี้ทั้งเว็บใช้โดเมน ตะกร้า สมาชิกร่วมกัน)

## ตั้งค่าที่ไหน

ERP › เว็บไซต์ › ดีไซน์ › **เมนู** › การ์ด "โซนของเว็บ" (`components/website-design/zones-card.tsx`) — อยู่ในธีม จึงผ่าน **ร่าง → พรีวิว → เผยแพร่** เหมือนเมนู

ต่อโซน:

| ช่อง | ความหมาย |
|---|---|
| ชื่อโซน (+อังกฤษ) | ชื่อแท็บบนแถบสลับ |
| หน้าแรกของโซน | กดแท็บแล้วไปที่นี่ (ว่าง = หน้าแรกในรายการหน้า) |
| หน้าที่อยู่ในโซนนี้ | ขึ้นต้นด้วย เช่น `/oem` = `/oem` และ `/oem/…` · ว่าง = **โซนหลัก** (หน้าอื่นทั้งหมด) มีได้โซนเดียว · `/` = หน้าแรกอย่างเดียว |
| เมนูของโซน | "ใช้เมนูหลักของร้าน" หรือ "ตั้งเมนูเฉพาะโซนนี้" (เริ่มจากสำเนาเมนูหลัก · ตัวจัด `MenuEditor` เดียวกับเมนูหลัก · ใช้ทั้งคอมและมือถือ) |
| ปุ่มบนหัวเว็บเฉพาะโซน | แทนปุ่มของหัวเว็บในโซนนี้ (ต้องวางชิ้น "ปุ่ม" ในหัวเว็บก่อน — การ์ดเตือนให้) |
| ซ่อนบนหัวเว็บ | ตะกร้า / ค้นหา / รายการโปรด / บัญชีสมาชิก |

แถบสลับ: สี (เข้ม / สีหลักร้าน / เลือกเอง) · จัดแท็บซ้าย/กลาง · ลิงก์กลับหน้าแรกท้ายแถบ (ว่าง = ไม่มี) · โชว์บนหน้าแรกด้วยไหม

กติกา: ต้องเปิดสวิตช์ + มี **≥ 2 โซน** แถบถึงขึ้น · สูงสุด 4 โซน · หน้าเดียวกันอยู่ได้โซนเดียว (โซนบนได้ก่อน) · ที่อยู่ที่ตรงยาวที่สุดชนะ (`/oem/steps` ชนะ `/oem`)

## โค้ด

- กฎกลาง (มิเรอร์ทั้งไฟล์ ไม่มี import): ERP `lib/website-site-zones.ts` ↔ เว็บร้าน `src/lib/site-zones.ts` — `normalizeSiteZones(raw, normItems)` · `siteZoneOf(pathname, cfg)` · `siteZoneBarShown` · `siteZoneHref` · `cleanSiteZonePath` · ลงทะเบียนคู่ใน `scripts/storefront-mirrors.config.mjs` (สำเนาใน wt-mirrors)
- ธีม: `theme.siteZones` (ERP `lib/website-theme.ts` · เว็บร้าน `src/lib/site-config.ts`) — เมนูในโซนผ่าน `normalizeMenuItems` ของแต่ละฝั่ง · คำแปล: `label` / `text` / `homeText` อยู่ใน `THEME_TEXT_KEYS`
- ⚠️ ชื่อ `header.zones` เป็นอีกเรื่อง (ตำแหน่งชิ้นซ้าย/กลาง/ขวาบนหัวเว็บ) — ของใหม่ใช้ชื่อ `siteZones` เสมอ
- เว็บร้าน: `Navbar` เลือกเมนู/ปุ่ม/ชิ้นที่ซ่อนตามโซน · `components/layout/ZoneBar.tsx` วาดแถบใน `<header>` เหนือแถวหัวเว็บ (ลอย/ติดบนไปด้วยกัน) · CSS `.zone-*` + `--zone-bar-h` (32px เมื่อมีแถบ) บวกเข้า `.hdr-spacer` / `--hdr-cover` / ช่องแรกของหน้าเปิดแบ่งช่อง · `layout.tsx` รวมเมนูทุกโซนตอนคัดสินค้าในแผงเมนูใหญ่
- หน้า `/en/...` = โซนเดียวกับหน้าไทย (ตัด `/en` ก่อนเทียบ)
- เทสต์: `lib/__tests__/website-site-zones.test.ts`

## สิทธิ์ / ประวัติ

แก้ผ่านหน้าดีไซน์เดิม (สิทธิ์เดียวกับแก้ธีม) · บันทึก/เผยแพร่ผ่าน API ธีมเดิม → ประวัติเวอร์ชันธีมเก็บให้ · ไม่มีตารางใหม่

## ข้อจำกัดที่รู้

- ตะกร้า/สมาชิก/โดเมนใช้ร่วมกันทั้งเว็บ (แยกไม่ได้)
- โลโก้/สีต่อโซนยังไม่มี (ทั้งเว็บใช้ธีมเดียว)
- ไม่จำว่าลูกค้าเคยอยู่โซนไหน — เข้าหน้าแรกเห็นหน้าเปิดทุกครั้ง
- ท้ายเว็บ (footer) ยังเป็นชุดเดียวทุกโซน
