# ใบแจ้งลูกค้า (ใบงานออกแบบ แท็บ "📣 แจ้งลูกค้า")

เจ้าของขอ 2026-11-06: อยากมีหน้าแจ้งลูกค้า เลือกรูป (บางทีหลายสินค้า) เขียนรายละเอียด แล้วออก PDF / JPEG ส่งลูกค้า
เคสแรก = "ผ้าที่ลูกค้าส่งมา ทำกระเป๋า 3 ไซส์ได้กี่ใบ" และ "ใช้ผ้ากี่หลาต่อใบ"

## ใช้ทำอะไร
- เขียนใบแจ้งลูกค้าจากในใบงานออกแบบ: รูปหลายรูป + **คำอธิบายใต้รูปทีละรูป** + ตารางผ้าต่อไซส์ + ข้อความ
- ออกเป็น **PDF** (หน้าต่างพิมพ์ → บันทึกเป็น PDF) หรือ **JPEG** (ส่ง LINE) — ก่อนออกเลือกได้ละเอียดว่าจะ **โชว์/ซ่อน** อะไร
- 1 ใบงานมีได้หลายใบแจ้ง เก็บเป็นประวัติ (ใคร · เมื่อไหร่) เปิดมาพิมพ์ซ้ำได้หน้าตาเดิม

## แบบแจ้ง (เพิ่มแบบใหม่ที่ `NOTICE_KINDS` ใน `lib/design-sheet-notice.ts` ที่เดียว)
| แบบ | ทำอะไร |
|---|---|
| `yield` ผ้าที่มา ทำได้กี่ใบ | ใส่ผ้าที่ได้รับ → **แบ่งตามที่สั่ง** (ผ้าไม่พอ = ลดทุกไซส์ลงสัดส่วนเดียวกัน + บอกขาดอีกกี่หลา) หรือ **ถ้าทำไซส์เดียว** (ผ้าทั้งหมด ÷ ใช้ต่อใบ) |
| `usage` ใช้ผ้ากี่หลาต่อใบ | ใช้ต่อใบ × จำนวนสั่ง = ต้องเตรียมผ้ารวมเท่าไหร่ |
| `free` แจ้งทั่วไป | รูป + คำอธิบายใต้รูป + ข้อความ (ไม่มีตาราง) |

กติกาตัวเลข: **ปัดลงเสมอ** (ไม่สัญญาลูกค้าเกินที่ทำได้จริง) · "เผื่อเสีย %" คูณเพิ่มจากใช้ต่อใบ · ทำได้รวม = ปัดลงทีละไซส์แล้วค่อยรวม

## ตัวเลข "ใช้ต่อใบ" มาจากไหน
- ปุ่ม **"ดึงใช้ต่อใบจากแท็บตีราคา…"** → `noticeMaterialsFromCost` รวมทุกบรรทัดของวัตถุดิบเดียวกันต่อแท็บ (ไซส์) ด้วย `lib/cost-usage` (ตัวเดียวกับ "ใช้ต่อใบ ≈" ในแท็บตีราคา)
- ผ้า (หลา) ขึ้นก่อน · ใช้เยอะสุด (ผ้าหลัก) ก่อน · ใบแจ้งใหม่เลือกผ้าหลักให้อัตโนมัติ
- จำนวนสั่งตั้งต้น = รอบเสนอราคาล่าสุดของไซส์นั้น (จำนวนน้อยสุดในรอบ) — แก้ได้ทุกช่อง · มีช่อง "จำนวนสั่งเท่ากันทุกไซส์"
- ไม่มีสิทธิ์ดูต้นทุน = แท็บตีราคาว่าง → พิมพ์ใช้ต่อใบเอง

## สิ่งที่เลือกโชว์ตอนส่งออก (หน้า `/print/design-sheet/[id]/notice/[noticeId]?as=pdf|jpg`)
- 4 กลุ่ม 21 อย่าง (`NOTICE_SHOW_GROUPS`): หัวกระดาษ (โลโก้ · ชื่อ-ที่อยู่บริษัท · เลขใบงาน · ชื่องาน · แบรนด์ · วันที่) · รูป (รูป · คำอธิบายใต้รูป · เลขลำดับ) · ตาราง (ชื่อวัตถุดิบ · แต่ละคอลัมน์ · แถวรวม · กล่องพอ/ขาด · หมายเหตุเผื่อเสีย) · ท้าย (ข้อความ · ผู้แจ้ง · เบอร์โทรบริษัท · ช่องลูกค้าเซ็น)
- ชุดสำเร็จ: ครบทุกอย่าง / แบบสั้น ส่ง LINE / รูป + ข้อความ (`NOTICE_PRESETS`)
- PDF: กระดาษ A4/A5 · แนวตั้ง/นอน · JPEG: พอดีเนื้อหา / เท่ากระดาษ · ปกติ / คมชัดสูง (`SaveImageButton scale`)
- หัวกระดาษบริษัท: ทะเบียน `companies` (มีหลายบริษัท = เลือกได้ · ไม่เลือก = บริษัทตั้งต้น)
- ที่ติ๊กไว้ **เก็บกับใบแจ้งใบนั้น** (PATCH display — ค่าการแสดงผล ไม่ลงประวัติ) · ติ๊ก "จำไว้ใช้ครั้งหน้า" = ใบแจ้งใหม่ของคนนี้ตั้งต้นแบบนี้ (`user_ui_prefs` key `ds_notice_display`)

- ดู = `products.view` · สร้าง/แก้/ลบ = `products.edit`
- audit: `notice_create` / `notice_update` (บอกช่องที่แก้) / `notice_delete` (เก็บหัวข้อ/ชนิด/ข้อความย่อ) บน entity `design_sheet`
- ประวัติพิมพ์: `usePrintLog("ds_notice")` จับปุ่ม PDF/พิมพ์/Ctrl+P · **บันทึก JPEG ยังไม่ลงประวัติ** (ตาราง `print_logs` รับแค่ print/pdf/link)

## ข้อจำกัด / ทำต่อได้
- 1 ใบแจ้ง = 1 วัตถุดิบ (อยากแจ้งผ้าหลัก + ซับในพร้อมกัน → ทำ 2 ใบ หรือทำต่อ "หลายวัตถุดิบ + บอกตัวที่ทำให้ได้น้อยสุด")
- คิดจากพื้นที่/ปริมาณในตีราคา ยังไม่ใช่การวางแบบจริงบนผืนผ้า (nesting)
- ยังส่งเข้า LINE ลูกค้าตรง ๆ ไม่ได้ (บันทึก JPEG แล้วส่งเอง)
