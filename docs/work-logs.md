# ใบจดผลงาน (Work Logs)

ใช้วัดผลพนักงานผลิต ว่าขั้นตอนไหน ใครทำ ใช้เวลาเท่าไร และทำได้กี่ชิ้น หัวหน้าจดลงกระดาษ ถ่ายรูปส่งเข้าระบบ ให้ AI อ่านลายมือ แล้วคนตรวจและกดยืนยัน

## ขั้นตอนการใช้งาน

1. **พิมพ์ใบจด**: บอร์ดจ่ายงาน → เช็กลิสต์ → 🪜 พิมพ์ขั้นตอนงาน → 📝 ใบจดผลงาน (หรือเปิด `/print/work-steps/<mo_id>?mode=worklog`)
   - ใบงาน 1 ใบ ได้ใบจด 1 ชุด
   - แถวของใบมาจากขั้นตอนงานในสูตร (`bom_work_steps`) แต่ละขั้นตอนมีหลายบรรทัด
   - ท้ายใบมีช่วง "ขั้นตอนเพิ่ม" ไว้เขียนขั้นตอนที่ไม่มีในสูตร
   - สินค้าที่ยังไม่มีขั้นตอนในสูตร = ทั้งใบเป็นบรรทัดว่าง ให้เขียนชื่อขั้นตอนเอง
2. **หัวหน้าจด**: เขียนชื่อเล่น · วันที่ วว/ดด · เวลาเริ่ม-เลิก (24 ชม.) · ทำได้ (4 หลัก) · เสีย (3 หลัก) · ระบายวงกลมเมื่อขั้นนั้นเสร็จ
3. **ถ่ายรูปส่ง**: เปิด `/master/work-logs` (เมนู จ่ายงาน → ใบจดผลงาน)
   - เบราว์เซอร์ย่อรูปและหา QR ในเครื่องก่อน แล้วอัปรูปขึ้นที่เก็บส่วนตัว (กฎหมวด `work_logs` = Supabase)
   - จากนั้นให้ AI อ่าน
4. **ตรวจ**: เปิดหน้า `/master/work-logs/<id>` จะเห็นรูปคู่กับบรรทัดที่อ่านได้ แก้ได้ทุกช่อง
   - 🟡 เหลือง = AI ไม่แน่ใจ หรือข้อมูลไม่ครบ (ยังบันทึกได้)
   - 🔴 แดง = ผิด ต้องแก้ก่อนบันทึก
5. **ยืนยัน**: บันทึกลง `work_log_entries`
   - ถ่ายใบเดิมซ้ำ (จดต่อวันถัดไป) = บรรทัดเดิมอัปเดต ไม่ซ้ำ เพราะใช้ key `(mo_id, line_key)`

## ไฟล์ที่เกี่ยวข้อง

| ส่วน | ไฟล์ |
|---|---|
| ตัวสร้างใบพิมพ์ + QR | `lib/work-log-sheet.ts` |
| กติกากลาง (QR · จับคู่ชื่อ · นาทีทำงาน · ตรวจบรรทัด) | `lib/work-log-read.ts` |
| เซิร์ฟเวอร์ (โครงหน้า · AI · แปลงผล) | `lib/work-log-server.ts` |
| รูปฝั่งเบราว์เซอร์ (ย่อ · หา QR) | `lib/work-log-image.ts` |
| API | `app/api/work-logs` · `app/api/work-logs/[id]` |
| หน้าจอ | `app/master/work-logs` · `app/master/work-logs/[id]` |
| ตาราง | `work_log_sheets` · `work_log_entries` (migration `202611150300_work_logs.sql`) |

QR บนใบ: `WL1|<mo_id>|<หน้า>/<ทั้งหมด>|<บรรทัดต่อขั้น>|<รหัสขั้นตอนย่อ 8 ตัว คั่นด้วย .>`

## สิทธิ์และประวัติ

- ดูได้ด้วยสิทธิ์ `products.view` · ส่งรูปและยืนยันใช้ `products.edit` (เหมือนบอร์ดจ่ายงาน)
- บันทึก audit ทุก action: `work_log.upload` / `reread` / `confirm` / `discard`
- ประวัติการพิมพ์ใบจดเก็บด้วย doc_type `work_log`

## ข้อจำกัดที่รู้

- ความแม่นของ AI กับลายมือจริงยังไม่ได้วัด ทุกใบจึงต้องผ่านหน้าตรวจ
- โมเดลตั้งต้นคือ `gpt-4.1` (ตั้งทับได้ด้วย `OPENAI_WORKLOG_MODEL`)
- ถ้าจับคู่ชื่อพนักงานไม่ได้ ระบบจะให้คนเลือกพนักงานเอง เทียบเฉพาะคนที่สถานะ active
- หักพักเที่ยง 12:00–13:00 ตายตัว (`WORK_LOG_BREAKS`)
- ยังไม่มี: หน้าสรุปชิ้นต่อชั่วโมง/ค่ามาตรฐาน (เฟส 2b) · ตัดภาพทีละช่อง · ปุ่มเพิ่มขั้นตอนใหม่เข้าสูตร · ใบจดรายวัน (แบบ B)
