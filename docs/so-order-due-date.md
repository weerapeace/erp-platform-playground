# วันนัดส่งใบสั่งขาย (ไลน์บริษัท รอบ 5)

เจ้าของเลือก 2026-11-22: **แบบ B** (ใส่วันทั้งใบ + แยกวันรายรายการ) + ข้อเสนอ 1 ปุ่มลัด · 2 ตั้งหลายใบทีเดียว · 3 อัปเดตใบสั่งผลิตด้วย (ถาม) · 4 ป้าย "ลูกค้าเห็นในไลน์" · 6 ปุ่มกรอง "ยังไม่ใส่วันนัดส่ง"

## ทำไม
ช่องกำหนดส่งมีแต่ซ่อนในฟอร์มตอนสร้าง · ใบที่บันทึกแล้วเปิดเป็นหน้าอ่าน → ไม่มีใครกรอก (ตอนทำ: หัวใบ 0/11 · รายการ 1/155) → ตารางส่งงานในไลน์ลูกค้า (docs/line-company-oa.md รอบ 4) ว่าง

## ใช้ยังไง (หน้า /sales/orders)
- **หน้าสถานะใบ:** กดวันที่ "กำหนดส่ง" ที่หัวใบ (หรือปุ่ม "ใส่วันนัดส่ง") = ตั้งทั้งใบ
- **แยกรายรายการ:** ติ๊กรายการในตาราง → "ตั้งวันนัดส่ง (n)" · คอลัมน์ "นัดส่ง" โชว์วันเฉพาะรายการ / "ตามหัวใบ" · ลบวันของรายการ = กลับไปใช้วันหัวใบ
- **ตารางรายการ:** กดช่อง "ยังไม่ระบุ" / วันที่ = ตั้งได้ทันทีไม่ต้องเปิดใบ · ติ๊กหลายใบ → "ตั้งวันนัดส่ง" ในแถบที่เลือก · ปุ่มกรอง "ยังไม่ใส่วันนัดส่ง (n)" (ใบยืนยันแล้ว ยังไม่ส่ง ไม่ถูกรวม)
- ป๊อป: DateInput + ปุ่มลัด +7/+14/+30 วันจากวันที่สั่ง · ป้าย "ลูกค้าเห็นในไลน์" · ลบวัน · ติ๊ก "อัปเดตวันส่งในใบสั่งผลิตด้วย" (ค่าเริ่มติ๊ก · ไม่มีใบผลิต = ไม่ถาม)

## กติกา (lib/so-due.ts)
- วันที่ใช้จริงของรายการ = รายการ → หัวใบ (ลำดับเดียวกับที่ลูกค้าเห็นในไลน์ `lineDueOf`)
- อัปเดตใบสั่งผลิต: จับคู่รายการ↔ใบผลิตด้วย `soLineProgress` (กติกาเดียวกับหน้าสถานะ) · แก้หัวใบ = ทุกรายการที่ไม่มีวันของตัวเอง · แก้รายการ = เฉพาะใบผลิตของรายการนั้น · ข้ามใบเสร็จ/ปิด/ยกเลิก · ลบวันไม่ล้างวันใบผลิต
- สิทธิ์ `so.create` · ใบยกเลิก/ถูกรวม = แก้ไม่ได้

## แก้ไข · ย้อนกลับ · ลบ
- แก้/ลบวันได้ตลอด · บันทึกแล้วมีปุ่ม "ย้อนกลับ" ในแจ้งผล = คืนวันเดิมทั้งใบสั่งขาย รายการ และใบสั่งผลิต (`mo_restore`)
- ลงประวัติ `so_due_set` / `so_due_undo` ค่าเดิม→ใหม่ (หัวใบ · line:SKU · mo:เลขใบ)
- ⚠️ แก้ไขใบ (บันทึกฟอร์ม) เขียนรายการใหม่ทั้งชุด → ฟอร์มส่ง `due_date` ของรายการกลับไปด้วยแล้ว (เดิมไม่ส่ง = วันรายการจะหาย)
