# บัตร QR สมัครรับสลิปทาง LINE (เฟส A ของระบบส่งสลิป)

## ใช้ทำอะไร

ให้พนักงานผูกบัญชี LINE ของตัวเองเข้ากับข้อมูลพนักงานใน ERP โดยไม่ต้องกรอกอะไร
HR พิมพ์บัตร QR แจกทีละคน → พนักงานสแกนด้วยแอป LINE → ตรวจชื่อ → กด "ยืนยัน" → ผูกเสร็จ

เป็นฐานของการส่งสลิปเงินเดือนทาง LINE (เฟส B–D) — ต้องผูกก่อนถึงจะส่งสลิปถึงตัวได้

## ใช้เมื่อไหร่

- พนักงานใหม่ / พนักงานที่ยังไม่ผูก LINE → หน้า **Payroll › LINE พนักงาน** กด "พิมพ์บัตร QR สมัคร" (ทั้งหมดที่กรองอยู่) หรือ "พิมพ์บัตร QR" รายคน
- พนักงานเปลี่ยนโทรศัพท์/บัญชี LINE → HR กด "ปลดผูก" ก่อน แล้วพิมพ์บัตรใหม่

วิธีเดิม (กรอกรหัสพนักงาน + เบอร์โทรในหน้า `/employee-line`) ยังใช้ได้ แต่ตอนนี้แทบไม่มีพนักงานที่มีเบอร์ในระบบ จึงใช้บัตร QR เป็นหลัก

## ทำงานยังไง

| ส่วน | ไฟล์ |
| --- | --- |
| รหัสลับในบัตร (เซ็น HMAC มีวันหมดอายุ ไม่เก็บ DB) | `lib/line-invite-token.ts` |
| ออกบัตร / พรีวิว / ผูก (ใช้ตัวผูกเดียวกับวิธีกรอกเบอร์) | `lib/line-employee-portal-db.ts` → `issueLineInvites`, `lineInvitePreview`, `registerLineMemberByInvite` |
| API ออกบัตร (HR) | `POST /api/payroll/line-invites` — สิทธิ์ `employees.edit` |
| API สแกน (สาธารณะ) | `GET/POST /api/line-join` |
| หน้าพนักงานสแกน | `/a?join=<token>` (LIFF เดียวกับหน้าอนุมัติเล็ก) → `app/a/join-view.tsx` |
| หน้าพิมพ์บัตร | `/print/payroll-line-invites?ids=...` (A4 ได้ 8 ใบ) |
| ของกลาง LIFF ฝั่งเบราว์เซอร์ | `lib/liff-client.ts` |

ลิงก์ในบัตร = `https://liff.line.me/<LIFF ID>?join=<token>` → เด้งมาที่ `/a?join=...`

## ความปลอดภัย

- บัตรใช้ได้ **14 วัน** และ **ครั้งเดียว**: ผูกแล้วสแกนซ้ำด้วย LINE อื่นไม่ได้ (ขึ้น "บัตรนี้ถูกใช้แล้ว แจ้ง HR")
- HR กด "ปลดผูก" = บัตรทุกใบที่พิมพ์ก่อนหน้านั้นใช้ไม่ได้ทันที (เทียบวันออกบัตรกับเวลาปลดผูกล่าสุด)
- ตัวตน LINE ยืนยันฝั่ง server ด้วย `verifyLineIdToken` (channel "ISG ERP Login") — ไม่เชื่อข้อมูลจากเบราว์เซอร์
- รหัสบัตรแยก key จากโทเคนหน้าอนุมัติ เอาลิงก์อนุมัติมาใช้แทนบัตรไม่ได้
- ออกบัตรให้เฉพาะพนักงานที่ทำงานอยู่และยังไม่ผูก LINE
- Audit log: `line_invite_issued` (ใครพิมพ์บัตรให้ใคร) · `line_register_success` (`metadata.method = "invite"`) · `line_register_failed` (`reason = invite_already_used`)

## ข้อจำกัดที่รู้แล้ว

- ถ้าบัตรหลุดไปถึงคนอื่นแล้วเขาสแกนก่อน → LINE ของเขาจะผูกแทน: HR ดูรูป/ชื่อ LINE ในหน้า LINE พนักงานได้ ถ้าไม่ตรงให้ "ปลดผูก" แล้วพิมพ์ใหม่ (แจกบัตรกับมือเจ้าตัวเสมอ)
- การเตือน "เพิ่มเพื่อน LINE ฝ่ายบุคคล" ในหน้าสแกน รู้ผลได้แน่นอนก็ต่อเมื่อ LINE Login channel ผูกกับ OA ฝ่ายบุคคลแล้ว (ดู `docs/line-hr-oa-setup.md`)
- ยังไม่ได้ส่งข้อความหาใคร — การส่งสลิปอยู่เฟส C
