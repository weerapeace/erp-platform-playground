# 🎨 การ์ดแบบ SKU (Section ตารางสินค้า)

ปกติ Section "ตารางสินค้า / คอลเลกชัน" โชว์ **1 การ์ด / รุ่น** (Parent SKU) + จุดสีใต้การ์ด
เลือกให้โชว์ **1 การ์ด / SKU (สี)** ได้ 2 ทาง:

| ตั้งที่ | ผล |
|---|---|
| ดึงสินค้าจาก = (แหล่งเดิมใดก็ได้) + **การ์ดสินค้า: 1 การ์ด / SKU** | แตกทุกสีของรุ่นที่ดึงมาเป็นการ์ด · เลือก **เรียงการ์ด SKU**: สลับรุ่น (สีแรกของทุกรุ่นก่อน) / เรียงต่อกันทีละรุ่น |
| ดึงสินค้าจาก = **เลือก SKU เองทีละตัว (รุ่น + สี)** | ป๊อป 🎨 เลือก SKU (ค้นรหัส/ชื่อ/สี) · ลาก ⠿ เรียง · โชว์ตามลำดับที่เลือก |

"จำนวนสูงสุด" นับเป็น **การ์ด** (ไม่ใช่รุ่น)

## การ์ด SKU หน้าตายังไง
- รูป = ชุดรูปของสีนั้น · ชื่อ = ชื่อรุ่น + "· สี" (สีอยู่นอกส่วนที่ตัดบรรทัด ชื่อยาวก็ยังเห็นสี) · ไม่มีจุดสี
- กดการ์ด = ไปหน้าสินค้าโดยเลือกสีนั้นไว้ (`?color=`) · ปุ่มใส่ตะกร้า/ดูด่วน = สีนั้น
- ตะกร้า/ออเดอร์ใช้รหัสสินค้าเดิม (id รุ่น + id สี) → ไม่กระทบระบบสั่งซื้อ
- รุ่นที่ไม่มีสี = การ์ดรุ่นปกติ 1 ใบ

## ข้อมูลที่เก็บ
- `cardMode`: `parent` (เดิม) / `sku` · `skuOrder`: `mix` / `group`
- `skus`: `["BELTA003:sku-6d2283cb", …]` = รหัสรุ่น + id ตัวเลือกสี (8 ตัวแรกของ id SKU ลูก · ตัวเดียวกับที่ API สินค้าส่งให้เว็บ) · ไม่มีสี = `"CODE"`
- เก็บใน layout ของหน้า (ไม่มีตาราง/คอลัมน์ใหม่)

## ไฟล์
- ERP: `lib/website-schema.ts` (ช่อง source/skus/cardMode/skuOrder · ชนิดช่อง `skus`) · `lib/website-blocks.ts` (ล้างค่า `skuRefStr`) · `components/website-sku-picker.tsx` (ป๊อปเลือก SKU · ข้อมูลจาก `/api/public/storefront/products`)
- เว็บร้าน: `src/lib/sku-cards.ts` (skuCard · expandSkuCards · pickSkuCards · cardKeyOf) · `ProductsBlockBody` · `ProductCard`/`ProductTile` (โชว์ `skuLabel`)

## ข้อจำกัด
- สถานะสินค้าหมดยังเป็นระดับรุ่น (ทุกสีของรุ่นหมดพร้อมกัน)
- ราคาบนการ์ด = ราคาของรุ่น (ถ้าแต่ละสีราคาไม่เท่ากัน การ์ดยังโชว์ราคาเดียวกันทุกสี)
- ยังใช้ได้เฉพาะ Section ตารางสินค้า (หน้ารวมสินค้า /shop ยังเป็นการ์ดรุ่น)
