# 🔍 ZoomBox — กล่องซูมรูป (ของกลาง)

`components/zoom-box` · เพิ่ม 2026-11-14 (เจ้าของขอ "ต้องซูมรูปได้ ctrl + scroll เมาส์")

## ใช้ทำอะไร
กล่องดูรูป/เนื้อหาที่ซูมได้ — ใช้ตอนต้องดูรายละเอียดหรือตีกรอบชิ้นเล็ก ๆ บนรูป

| ทำอะไร | ผล |
|---|---|
| Ctrl (Mac: ⌘) + หมุนลูกกลิ้ง | ซูมเข้า/ออก **ตรงจุดที่เมาส์ชี้** (100%–600%) |
| หมุนลูกกลิ้งเฉย ๆ | เลื่อนดูส่วนอื่น (เหมือนเดิม) |
| ปุ่ม − / % / + (`ZoomControls`) | ซูมทีละ 25% (ยึดกลางกล่อง) · กด % = กลับพอดีกล่อง |

## ตัวอย่าง
```tsx
const [zoom, setZoom] = useState(1);
<ZoomControls zoom={zoom} onZoom={setZoom} />
<div className="relative h-[60vh]">
  <ZoomBox zoom={zoom} onZoom={setZoom} aspect={w / h} className="absolute inset-0">
    <ImageRegions src={src} mode="edit" className="w-full" … />
  </ZoomBox>
</div>
```

| config | ความหมาย |
|---|---|
| `aspect` | กว้าง/สูง ของเนื้อหา — มีค่า = 100% พอดีทั้งกว้างและสูงของกล่อง · ไม่ส่ง = พอดีความกว้าง |
| `maxFitWidth` | กว้างสุดตอน 100% (px) กันรูปยืดบนจอกว้าง |
| `padding` | ระยะขอบในกล่อง (px · ค่าเริ่ม 8) |
| `className` | ขนาดกล่อง — **ต้องมีความสูง** (เช่น `absolute inset-0` ในกล่องที่สูงตายตัว หรือ `flex-1 min-h-0`) |

## ใช้ที่
แผงผ้า Swatch: ป๊อปเพิ่มแผ่น + โหมดตั้งค่า (`components/sku-swatch-browser/board-editor.tsx`) · โหมดดู (`viewer.tsx`) · ครอปกรอบอิสระ (`ImageFreeCropModal`)

## ห้ามใช้
- ดูรูปเต็มจอ เลื่อนรูปถัดไป → `ImageLightbox`
- วาด/เขียนบนรูป → `ImageMarkup` (มีซูมของตัวเอง)
- อยากจำค่าเลื่อน/ซูมการแสดงผลไว้ใช้ที่อื่น (เช่น รูปพื้นหลัง) → `ImageCropBox`

## ข้อจำกัด
- ไม่มีลากเพื่อเลื่อน (pan) — ใช้แถบเลื่อน/ลูกกลิ้ง/ทัชแพด (เพราะการลากบนรูปใช้ตีกรอบอยู่แล้ว)
- บนมือถือใช้ปุ่ม − % + (ไม่มีลูกกลิ้ง) · การบีบสองนิ้วยังเป็นซูมของเบราว์เซอร์
