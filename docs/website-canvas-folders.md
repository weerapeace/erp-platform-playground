# 🗂 แฟ้มวางอิสระ (ผืนผ้าใบโหมดแฟ้มซ้อน) — 2026-10-23

## ใช้ทำอะไร
แฟ้มกระดาษซ้อนกันลงมา (แบบรูปอ้างอิง "GRATITUDE DIARY / TO DO LIST / LIFESTYLE BLOG") — **แต่ละแฟ้มวางรูป วิดีโอ ข้อความ ปุ่ม ของตกแต่งได้อิสระ**
ชี้ (มือถือแตะ) แฟ้มไหน แฟ้มนั้นกางออกให้เห็นของข้างใน · แฟ้มที่หุบเห็นแค่ขอบ (ของข้างในโผล่นิด ๆ)

## วิธีใช้ (คนจัดหน้า)
1. ＋ เพิ่ม Section › กลุ่ม "พื้นฐาน" › **🗂 แฟ้มวางอิสระ** (มีป้าย "มีตัวอย่าง") → ได้ 3 แฟ้มพร้อมข้อความ + ของตกแต่งตัวอย่าง
   - หรือเปิดที่ผืนผ้าใบเดิม: ช่อง **🗂 แฟ้มซ้อน** ในแผงตั้งค่าของผืน
   - การ์ดนี้โชว์เฉพาะร้านที่เปิดสวิตช์ทดลอง "ผืนผ้าใบอิสระ" (Louis / Pixie Dustie เปิดอยู่)
2. **สลับแฟ้มในพรีวิว:** กดหูแฟ้ม (ตัวจัดหน้าไม่สลับตอนชี้ — กันแฟ้มสลับเองระหว่างลากของ)
3. **เพิ่มของ:** ปุ่มเพิ่มชิ้นเดิมของผืนผ้าใบ (แผงขวา / หน้าแก้เต็มจอ) → ชิ้นใหม่ลงแฟ้มที่เปิดอยู่ในพรีวิว · ลาก ย่อ หมุน แก้ข้อความ ได้เหมือนผืนผ้าใบทุกอย่าง
4. **ย้ายชิ้นไปแฟ้มอื่น:** ช่อง **"อยู่แฟ้มที่"** ของชิ้น (แผงขวา หรือ "ตั้งค่าละเอียด" ในหน้าแก้เต็มจอ)
5. ตั้งป้าย/สีของแต่ละแฟ้ม + หน้าตาแฟ้มทั้งหมด ที่แผงตั้งค่าของผืน

## ตั้งค่า (ผืนผ้าใบ → แฟ้มซ้อน)
| ช่อง | ความหมาย |
|---|---|
| `folderMode` | เปิดแฟ้มซ้อน |
| `folderCount` | 2–6 แฟ้ม |
| `folderOpen` | hover = ชี้เมาส์ (ต้องชี้ค้าง ~0.16 วิ — แค่ลากผ่านไม่เปิด) · click = กดหูแฟ้ม · มือถือแตะเสมอ |
| `folderStart` | แฟ้มที่กางรอไว้ |
| `folder{1-6}Label` / `folder{1-6}Color` | ป้ายบนหู (ว่าง = เลข 01 02…) / สีรายแฟ้ม (ว่าง = ชุดสี) |
| หน้าตาแฟ้ม (ของกลาง `folderLookFields`) | ทรงหู · ตำแหน่งหู · ลายกระดาษ · เงา 0–3 · มุมมน · ชุดสี/สีเอง · ป้าย (สติกเกอร์/ตัวหนังสือ) · ขอบแฟ้มที่หุบ · ดึงแฟ้มขึ้น · แฟ้มปก (ชื่อ 2 ฟอนต์ + โลโก้) — ชุดเดียวกับแกลเลอรีแบบแฟ้ม |
| ความสูงผืน | = ความสูงของผืนในแฟ้มที่กาง (ทุกแฟ้มเท่ากัน) · มือถือเรียงอัตโนมัติ = สูงตามของจริง |
| รูปพื้นหลังผืน | อยู่หลังกองแฟ้มทั้งกอง |

## ✂️ ของตกแต่งสำเร็จรูป (ลายของตกแต่งใหม่ — ใช้ได้กับผืนผ้าใบทุกผืน)
📎 คลิปหนีบกระดาษ (`clip`) · คลิปดำหนีบเอกสาร (`binder`) · เทปกาว (`tape` โปร่ง 60%) · กระดาษโน้ตมุมพับ (`note`) · สติกเกอร์ขอบหยัก (`badge`) · บาร์โค้ด (`barcode`)
กรอบรูปโพลารอยด์ = ทรงรูป "โพลารอยด์" ที่มีอยู่แล้ว · สติกเกอร์มีตัวหนังสือ = ของตกแต่ง + ข้อความ จับกลุ่ม (Ctrl+G)

## ตรวจก่อนเผยแพร่
แฟ้มที่ยังว่าง = ⚠️ · ชิ้นอยู่แฟ้มเกินจำนวนแฟ้ม (ลดจำนวนแฟ้มแล้ว) = ⚠️ ไม่ขึ้นเว็บจนกว่าจะย้าย

## ทำงานยังไง (คนแก้โค้ด)
- **ไม่ใช่ Section ชนิดใหม่** — เป็นโหมดของ `canvas` (เครื่องมือผืนผ้าใบทั้งชุดใช้ได้: ตัวคุยพรีวิว useCanvasBridge · หน้าแก้เต็มจอ · ตัวตรวจ · แม่แบบผืน · มือถือ)
  การ์ดในคลัง = ของกลาง `SECTION_PRESETS` (lib/website-schema · ชนิดเดิม + ค่าตั้งต้น `folderCanvasStarter` ใน lib/website-canvas) — การ์ดสำเร็จรูปอื่นเพิ่มที่เดียวกัน
- ชิ้น: ช่อง `folder` ("1"–"6") โชว์เมื่อผืนเป็นแฟ้มซ้อน (`showIfParent`) · หน้าแก้เต็มจอส่ง `parent` ให้ฟอร์มตั้งค่าละเอียดแล้ว
- ชิ้นใหม่ลงแฟ้มไหน: เว็บร้านส่ง `storefront-canvas-folder {blockId, folder}` ทุกครั้งที่สลับแฟ้มในโหมดแก้ไข → `website-builder` จำไว้ (`canvasFolderRef`) แล้ว `intoOpenFolder()` ใส่ให้ใน addChild / insertChild
- เว็บร้าน: `CanvasSection` = ตัวเลือก (ฟังข้อมูลสดเอง — LiveBlocks ใส่ผืนครั้งเดียวแล้วอัปเดตผ่านข้อความ) → ผืนปกติ `CanvasSurface` หรือ `CanvasFolders`
  - `CanvasFolders` วาดแฟ้ม (CSS `.gt[data-look=folder]` + `.cvf-*`) แล้วใส่ `CanvasSurface folder=n` ทุกแฟ้ม (กรองชิ้นด้วย `canvasFolderRaw` · ตัวจัดหน้าเลือกชิ้นแฟ้มอื่น = แฟ้มนี้เลิกเลือก `canvasForeignIds`)
  - ความสูงแฟ้มที่กาง = วัดผืนจริง (ResizeObserver) · ก่อนวัดประมาณจาก `--cvch` (container query)
  - กล่องตัดขอบอยู่ที่ `.cvf-in` ไม่ใช่ตัวแฟ้ม — ⚠️ ถ้าตัดที่ตัวแฟ้ม หูแฟ้มที่อยู่เหนือขอบ (bottom:100%) หายหมด
  - สลับแฟ้ม: แฟ้มด้านบนหุบ = ของข้างล่างเลื่อนขึ้น → ตรึงขอบบนแฟ้มที่เพิ่งเปิดไว้ที่เดิม (~0.7 วิ · ผ่าน Lenis ถ้ามี) เฉพาะเมื่อขอบบนอยู่บนจอ (แค่เลื่อนผ่าน = ไม่ตรึง)
  - แตะ/กดแฟ้มที่หุบ = เปิดก่อน (ลิงก์ของชิ้นในแฟ้มนั้นยังไม่ทำงาน — `useClickGuard`)
- ลายของตกแต่ง: ERP `CANVAS_SHAPES` + `components/website-canvas-shapes.tsx` ↔ เว็บร้าน `CanvasShapes.tsx` + `CANVAS_SHAPES` ใน src/lib/canvas.ts (ต้องตรงกัน 4 ที่)
- เทสต์: ERP `lib/__tests__/website-canvas-folders.test.ts` · e2e `<scratchpad>/cdp/cvfolders-e2e.mjs` (22 ข้อ: เว็บจริง คอม/มือถือ + หน้าทดสอบตัวจัดหน้า iframe `/harness.html` ใน mock)
