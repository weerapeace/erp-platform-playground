# มุมมองด่วน (Quick Views) — บอร์ดจ่ายงาน แท็บรอจ่าย

ใช้ทำอะไร: ปุ่มบนแถบเหนือตาราง แต่ละปุ่ม = **กรอง + หน้าตา + เรียง + จัดกลุ่ม** กดแล้วโชว์แบบที่ตั้งไว้

## ตั้งได้ (ต่อมุมมอง)
| ส่วน | ตัวเลือก |
|---|---|
| ชื่อ / ไอคอน | อีโมจิ |
| แบรนด์ | หลายอัน (ว่าง = ทุกแบรนด์ · "ไม่ระบุแบรนด์") |
| OEM / แบรนด์เรา | มาจาก brands.pricing_mode (oem) — แบรนด์ใหม่เข้ากลุ่มเอง |
| เงื่อนไข | เกินกำหนด · ส่งภายใน 7 วัน · ติดธงเร่ง · ของยังไม่ครบ · พร้อมจ่าย · ยังไม่มีวันส่ง · ยังไม่ตั้งราคา (แอดมิน) — ตรงทุกข้อ / ข้อใดข้อหนึ่ง |
| แสดงเป็น | ตาราง (คอลัมน์ปกติ หรือกำหนดเฉพาะมุมมอง) / การ์ด (เล็ก-กลาง-ใหญ่ + ช่องบนการ์ด) |
| เรียง | หลัก + รอง (ถ้าเท่ากัน) + ทิศ — ด่วนสุด · เลยกำหนด · กำหนดส่ง · อายุใบ · ขั้นตอน · ของต้องซื้อ · เหลือจ่าย · มูลค่า (แอดมิน) · แบรนด์ · รหัส |
| จัดกลุ่ม | ขั้นตอน · แบรนด์ · กลุ่ม · ความพร้อม |
| โชว์บนแถบ | ติ๊ก + ลากเรียงลำดับปุ่ม |

## เก็บที่ไหน / ใครตั้ง
- อยู่ในชุดหน้าตา `DisplayCfg.views` (`app/master/work-board/table-display.tsx`) → ชุดกลาง ปกติ/โหมดง่าย (ui_config `admin_wb_table_presets`, แอดมินแก้) · คนอื่นปรับ = "กำหนดเอง" ของตัวเอง
- มุมมองที่เลือกล่าสุด + ชิปแบรนด์เสริม: `useUserPref("wb_table_filters")` = `{ view, brand }`
- กติกากรอง/เรียง: `app/master/work-board/quick-views.ts` (test: `lib/__tests__/quick-views.test.ts`) · ตัวตั้งค่า: `quick-views-editor.tsx` (หมวด ⭐ ในแผง 🎛 หน้าตา)

## ค่าตั้งต้น
- ปกติ: ทั้งหมด · เกินกำหนด · ของยังไม่ครบ · พร้อมจ่าย · ยังไม่ตั้งราคา (แอดมิน) · งานเร่ง — ตาราง
- โหมดง่าย: ทั้งหมด (การ์ด) · ของด่วน (เกินกำหนด/ส่งใน 7 วัน/ติดธง · การ์ดใหญ่) · งานลูกค้า OEM · ของยังไม่ครบ (ตาราง จัดกลุ่มแบรนด์) · พร้อมจ่าย (การ์ดเล็ก) · แบรนด์เรา ยังไม่มีวันส่ง · ยังไม่ระบุแบรนด์

## อื่น ๆ
- ＋ บันทึกเป็นมุมมอง = คัดลอกมุมมองที่เปิด (+ แบรนด์ที่กดชิป) เป็นปุ่มใหม่แล้วเปิดแผงตั้งชื่อ
- กดหัวตารางเรียงชั่วคราวทับได้ · ปุ่มจัดกลุ่มปรับชั่วคราวได้ (เปลี่ยนมุมมอง = กลับตามที่ตั้ง)
- การ์ดใช้ MiniTable `layout="cards"` + `cardGrid` (หลายคอลัมน์ตามจอ · การ์ดที่กางเต็มแถว)
