# มุมมองด่วน (Quick Views) — บอร์ดจ่ายงาน แท็บรอจ่าย

ใช้ทำอะไร: ปุ่มบนแถบเหนือตาราง แต่ละปุ่ม = **กรอง + หน้าตา + เรียง + จัดกลุ่ม + ความกว้างคอลัมน์** กดแล้วโชว์แบบที่ตั้งไว้

## 2 ชั้น: มุมมองทีม / มุมมองของฉัน
| | 👥 มุมมองทีม | 👤 มุมมองของฉัน |
|---|---|---|
| ใครสร้าง/แก้ | แอดมินเท่านั้น (เซิร์ฟเวอร์บังคับ `admin.users` ที่คีย์ `admin_*`) | เจ้าของเอง |
| เก็บที่ | ui_config `admin_wb_quick_views` = `{ views: TeamView[] }` | `useUserPref("wb_quick_views_mine")` = `{ views, hidden, widthOverride }` |
| ใครเห็น | ตั้งได้: ทุกคน / เฉพาะตำแหน่ง (admin·manager·staff) / เฉพาะคน | เจ้าของคนเดียว |
| ซ่อนสำหรับตัวเอง | 👁 ในป๊อป → `mine.hidden` (ไม่กระทบคนอื่น) | ลบได้ |

แถบปุ่ม = มุมมองทีมที่ "ใครเห็น" ผ่าน (`qvAudienceOk`) และไม่ได้ซ่อน → ต่อด้วยมุมมองของฉัน → ตัด "ยังไม่ตั้งราคา" ถ้าไม่ใช่แอดมิน (`qvVisible`)

> ⚠️ "ใครเห็น" = จัดหน้าจอให้เรียบ ไม่ใช่ด่านความปลอดภัย — ข้อมูลใบงานทั้งหมดยังเห็นได้จากแท็บ "ทั้งหมด" ตามสิทธิ์ปกติ

## ตั้งได้ (ต่อมุมมอง) — ฟอร์ม `QuickViewForm` (`quick-views-editor.tsx`)
| ส่วน | ตัวเลือก |
|---|---|
| ชื่อ / ไอคอน | อีโมจิ |
| แบรนด์ | หลายอัน (ว่าง = ทุกแบรนด์ · "ไม่ระบุแบรนด์") |
| OEM / แบรนด์เรา | มาจาก brands.pricing_mode (oem) — แบรนด์ใหม่เข้ากลุ่มเอง |
| เงื่อนไข | เกินกำหนด · ส่งภายใน 7 วัน · ติดธงเร่ง · ของยังไม่ครบ · พร้อมจ่าย · ยังไม่มีวันส่ง · ยังไม่ตั้งราคา (แอดมิน) — ตรงทุกข้อ / ข้อใดข้อหนึ่ง |
| แสดงเป็น | ตาราง (คอลัมน์ปกติ หรือกำหนดเฉพาะมุมมอง — **เลือก + จัดลำดับซ้าย→ขวา** ลาก ⠿ / ‹ › / ✕ · ตั้งต้นจากคอลัมน์ที่ตารางปกติโชว์อยู่) / การ์ด (เล็ก-กลาง-ใหญ่ + ช่องบนการ์ด) |
| ความกว้าง | ยืดเต็มจอ / พอดีเนื้อหา (`fit` → MiniTable `fitContent`) + ความกว้างที่ลากไว้ (`widths`, 40–2000px) |
| เรียง | หลัก + รอง (ถ้าเท่ากัน) + ทิศ — ด่วนสุด · เลยกำหนด · กำหนดส่ง · อายุใบ · ขั้นตอน · ของต้องซื้อ · เหลือจ่าย · มูลค่า (แอดมิน) · แบรนด์ · รหัส |
| จัดกลุ่ม | ขั้นตอน · แบรนด์ · กลุ่ม · ความพร้อม |

## ป๊อป ⚙️ จัดการมุมมอง (`quick-views-manager.tsx`)
- เปิดจาก: ชิป "⚙️ จัดการมุมมอง" บนแถบ · ปุ่มในแผง 🎛 หน้าตา · "＋ บันทึกเป็นมุมมอง" (เปิดพร้อมมุมมองของฉันใหม่ในร่าง)
- แก้ทั้งหมดเป็น **ร่าง** → กด 💾 บันทึก ถึงมีผล · ปิดตอนยังไม่บันทึก = ถามก่อน (ERPModal `hasUnsavedChanges`)
- ซ้าย: รายการทีม (แอดมินลากเรียง · 👁 ซ่อนสำหรับตัวเอง · ป้ายใครเห็น) + รายการของฉัน (ลากเรียง)
- ขวา: ทำสำเนาเป็นของฉัน · แชร์เป็นมุมมองทีม (แอดมิน) · ลบ · ตั้งใครเห็น (แอดมิน) · ฟอร์มตั้งค่า (คนทั่วไปเห็นมุมมองทีมแบบอ่านอย่างเดียว)

## ความกว้างคอลัมน์ (ลากเส้นที่หัวคอลัมน์)
- ลาก = ร่าง → แถบเหลือง "ยังไม่บันทึก" เหนือตาราง:
  - มุมมองของฉัน → 💾 บันทึกในมุมมอง
  - มุมมองทีม + แอดมิน → 💾 บันทึกในมุมมอง (ทุกคนที่เห็น) หรือ บันทึกเฉพาะฉัน
  - มุมมองทีม + คนทั่วไป → 💾 บันทึกเฉพาะฉัน (`mine.widthOverride[viewId]`)
  - ย้อนกลับ = ทิ้งร่าง · เปลี่ยนมุมมอง = ทิ้งร่าง
- MiniTable: `widths` + `onWidthsChange` = คุมจากข้างนอก (ไม่ใช้ localStorage) · ระหว่างลากเก็บในตารางเอง ปล่อยเมาส์ค่อยส่งออก · คิดเผื่อ CSS zoom

## ค่าตั้งต้นทีม (`QV_DEFAULT_TEAM`, ทุกคนเห็น)
ทั้งหมด (ตาราง) · ของด่วน (เกินกำหนด/ส่งใน 7 วัน/ติดธง · การ์ดใหญ่) · งานลูกค้า OEM · เกินกำหนด · ของยังไม่ครบ (จัดกลุ่มแบรนด์) · พร้อมจ่าย (การ์ดเล็ก) · ยังไม่ตั้งราคา (แอดมิน) · แบรนด์เรา ยังไม่มีวันส่ง · ยังไม่ระบุแบรนด์

## อื่น ๆ
- มุมมองที่เลือกล่าสุด + ชิปแบรนด์เสริม: `useUserPref("wb_table_filters")` = `{ view, brand }`
- กติกากรอง/เรียง/อ่านค่า: `app/master/work-board/quick-views.ts` (test: `lib/__tests__/quick-views.test.ts`) · โหลด/บันทึก: `use-quick-views.ts`
- ชุดหน้าตา (🎛) เหลือเฉพาะหน้าตา (ขนาด/ส่วนหัว/คอลัมน์ปกติ) — `DisplayCfg.views` เดิมยังอ่านได้แต่ไม่ใช้แล้ว
- กดหัวตารางเรียงชั่วคราวทับได้ · ปุ่มจัดกลุ่มปรับชั่วคราวได้ (เปลี่ยนมุมมอง = กลับตามที่ตั้ง)
- การ์ดใช้ MiniTable `layout="cards"` + `cardGrid` (หลายคอลัมน์ตามจอ · การ์ดที่กางเต็มแถว)
