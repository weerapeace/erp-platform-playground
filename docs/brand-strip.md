# แถบสีแบรนด์ซ้ายการ์ด (BrandStrip)

แถบสีบาง ๆ (4px) ด้านซ้ายของการ์ด บอกว่าการ์ดนี้เป็นงานของแบรนด์ไหน กวาดตาลงคอลัมน์ก็แยกแบรนด์ได้ทันที

เจ้าของเลือกแบบนี้เมื่อ 2026-11-07 จากตัวอย่าง 4 แบบ (ขอบทั้งใบ / แถบซ้าย / เงาสี / ป้ายชื่อ) เพราะ:
- อ่านง่ายสุดตอนการ์ดเยอะ ไม่รก
- ไม่ชนป้ายแดง "เกินกำหนด" และกรอบตอนเลือกการ์ด
- เห็นได้แม้จอสีซีด (เงาสีจะหายไปเลยบนจอแบบนี้)

## ใช้ที่ไหนแล้ว
| ที่ | เปิด/ปิด | ค่าเริ่มต้น |
|---|---|---|
| Design Dashboard (บอร์ด + การ์ดรูปใหญ่ + มือถือ) | ปุ่ม "แถบสีแบรนด์: เปิด/ปิด" บนแถบเครื่องมือ · มือถือ = เมนู ⋯ · จำต่อคน (`user_ui_prefs` key `design_dashboard_brand_strip`) | เปิด |
| บอร์ดงาน /tasks (TaskCard) | ⚙️ ตั้งค่าบอร์ด → ติ๊ก "แถบสีแบรนด์ (ซ้ายการ์ด)" (`KanbanTheme.brandBorder`) | ปิด |

## ตั้งสีแบรนด์ที่ไหน
เมนู **แบรนด์** (`/master/brands`) → กดวงกลมสีข้างชื่อแบรนด์ (ช่อง `brands.color`)

## กติกาสี (`lib/brand-strip.ts` — ที่เดียว)
- สี `#rrggbb` ถูกต้อง → ใช้ได้เลย
- สีอ่อนมาก (ความสว่าง ≥ 0.6 เช่นเหลือง) → เข้มขึ้น 30% อัตโนมัติ ไม่งั้นเส้นบนพื้นขาวมองไม่เห็น
- ไม่มีสี / ไม่ระบุแบรนด์ → เทา `#94a3b8` (Design Dashboard) · บอร์ดงานส่ง `fallback={null}` = ไม่วาด
- ห้ามใช้สีแดงเป็นสีแบรนด์ — แดง = เตือนเกินกำหนด

## วิธีใช้ในการ์ดใหม่
```tsx
import { BrandStrip } from "@/components/brand-strip";

<div className="relative overflow-hidden rounded-lg border ... pl-2.5">  {/* relative + overflow-hidden + เผื่อที่ซ้าย */}
  <BrandStrip color={item.brand_color} title={item.brand_name ?? undefined} />
  ...
</div>
```

## ข้อจำกัด
- การ์ดที่มีรูปเต็มขอบ (รูปปกด้านบน) แถบจะทับขอบซ้ายของรูป 4px — ตั้งใจ ให้แถบต่อเนื่องทั้งใบ
- แบรนด์ที่สีคล้ายกัน (เช่น ส้ม 2 แบรนด์) แยกด้วยแถบไม่ได้ ต้องไปเปลี่ยนสีในเมนูแบรนด์
- ไม่มี audit log (เป็นค่าหน้าตาต่อคน ไม่ใช่ข้อมูลธุรกิจ)
