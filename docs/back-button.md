# ปุ่มย้อนกลับ (BackButton) — ของกลาง

**ใช้ทำอะไร:** ปุ่ม "ย้อนกลับ" พาผู้ใช้กลับหน้าที่เข้ามา (เช่น เปิดหน้าบัญชีแพลตฟอร์มจากปฏิทินคอนเทนต์ → กดแล้วกลับปฏิทิน)

```tsx
import { BackButton } from "@/components/back-button";
<BackButton fallback="/" />            // label="ย้อนกลับ" (เปลี่ยนได้) · className เพิ่มระยะ
```

## ทำงานยังไง
- `components/nav-trail-recorder` (วางใน `app/layout` แล้ว) จดทุกหน้าที่เปิดในแท็บนี้ลง `sessionStorage` (`lib/nav-trail`)
- กดปุ่ม → ไปหน้าก่อนหน้าที่ **ไม่ใช่หน้านี้** (พร้อม query เดิม) แล้วตัดทางเดิน (ไม่วนกลับ)
- ออกไปเว็บนอกแล้วกลับมาหน้าเดิม (เชื่อม Facebook/Lazada) = ไม่นับเป็นก้าวใหม่ → ยังย้อนกลับหน้าต้นทางได้ (`history.back()` ตรง ๆ จะพาไปหน้า Facebook)
- เปิดมาเป็นแท็บใหม่ (ไม่มีประวัติ) → ปิดแท็บ กลับแท็บเดิม · ปิดไม่ได้ → หน้าที่ลิงก์มา (เว็บเดียวกัน) → `fallback`

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ✅ หน้าตั้งค่า/หน้าย่อยที่ถูกเปิดจากหลายที่
- ❌ จอซ้อนที่เปิดด้วย state (ตะกร้า/เช็กลิสต์) → `lib/use-back-close` · drawer → `lib/drawer-history`

## ข้อจำกัด
- query ที่หน้าเปลี่ยนเองด้วย `replaceState` หลังโหลด ไม่ถูกจด (กลับมาจะได้ query ตอนเข้าหน้าครั้งแรก)
- ใช้แล้วที่: `/admin/platform-accounts` · หน้าเก่าที่เขียน `router.back()` เอง (family-groups, family-template, product-families) ย้ายมาใช้ตัวนี้ได้
