# 🎨 ลายของร้าน (ของตกแต่งจาก SVG ที่อัป · เปลี่ยนสีได้)

> เริ่มใช้ 2026-10-24 · เจ้าของถาม "ลายในตัวเพิ่มได้ไหม ต้องเป็นไฟล์อะไรถึงเปลี่ยนสี สีเส้น ความหนาเส้นได้"

## ใช้ทำอะไร

ร้านอัปไฟล์ **SVG** (เช่น โบว์/ดอกไม้/โลโก้ลายเส้นของแบรนด์จาก Illustrator · Figma · Canva) แล้ววางเป็นของตกแต่งที่ **เปลี่ยนสีได้เหมือนลายในตัว**
ใช้ได้ที่: **ผืนผ้าใบอิสระ** · **แฟ้มวางอิสระ** · **ของตกแต่ง Section** (แผงรูปลักษณ์ → 🎀 ตกแต่ง)

เปลี่ยนสีได้ 3 แบบ:

| โหมด | ทำอะไร |
| --- | --- |
| สีเดิมของไฟล์ (ค่าเริ่ม) | วาดตามที่ออกแบบมา |
| สีเดียวทั้งลาย | สีพื้น (หรือ ∅ ไม่เติมพื้น) + สีเส้น + ความหนาเส้น — ชิ้นที่เป็นเส้นล้วนใช้สีเส้น (ไม่มีสีเส้น = ใช้สีพื้น ไม่หายไป) |
| แยกตามสีในไฟล์ | ไฟล์มีกี่สี (สูงสุด 8) ก็เปลี่ยนทีละสีได้ · + เส้นขอบเพิ่มให้ชิ้นที่ไม่มีเส้นในไฟล์ |

สีเลือกเป็น "สีธีม" ได้ (แบรนด์/ตัวอักษร/…) → เปลี่ยนธีมแล้วลายเปลี่ยนตาม

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่

- ✅ ลายเส้น/รูปทรงทึบที่อยากให้เข้ากับสีของร้าน หรือสลับสีตามแคมเปญ
- ❌ รูปถ่าย / ภาพที่มีเงา-ไล่สีซับซ้อน → ใช้ PNG ใน "ของร้าน" แทน (ไล่สีในไฟล์จะกลายเป็นสีเดียว = สีแรก)
- ❌ ตัวหนังสือในไฟล์ → ต้องแปลงเป็นเส้นก่อนส่งออก (Illustrator: Create Outlines · Figma: Outline stroke / Flatten)

## ทำงานยังไง (ของกลาง)

```
คลังของตกแต่ง (DecorLibrary · onPickPattern)
  └ ไฟล์ SVG ในอัลบั้ม "ของตกแต่งเว็บ · <ร้าน>" = หมวด 🎨 ลายของร้าน (ไม่ซ้ำในหมวด "ของร้าน")
     ⬆️ อัป SVG ชิ้นเดียว = วางลงเลย
  └ loadShopPattern → svgTextToShopPattern (lib/svg-frame-import · ในเบราว์เซอร์)
       ทำความสะอาดใน "เอกสารที่ยังไม่อยู่บนหน้า" ก่อน: ทิ้งสคริปต์ · on… · รูปฝัง · ลิงก์ (เก็บรูปทรงข้างใน) · โหลดจากเว็บอื่น (@import/url())
       วางในกล่องแยก (shadow DOM มองไม่เห็น) → อ่านสีพื้น/สีเส้น/ความหนาที่เบราว์เซอร์คำนวณจริง (รวมคลาสใน <style> แบบ Illustrator)
       → { name, vb, parts: [{ d, t?, rule?, f?, s?, w?, o?, lc?, lj? }] } ผ่าน normalizeShopPattern
  └ คัดลอกลายลงชิ้น (แก้/ลบไฟล์ในคลังทีหลังไม่กระทบชิ้นที่วางแล้ว — แบบเดียวกับคลังกรอบ)
```

| ช่องของชิ้น | ความหมาย |
| --- | --- |
| `pattern` | ลาย (null = ลายในตัวตาม `shape` เหมือนเดิม) |
| `patMode` | `orig` · `one` · `slot` |
| `color` / `colorHex` | สีพื้น (โหมดสีเดียว) |
| `outline` | ไม่เติมพื้น |
| `lineColor` / `lineColorHex` | สีเส้น (`none` = ไม่มีเส้นเพิ่ม) |
| `strokeWidth` | ความหนาเส้น — ผืนผ้าใบ = หน่วยผืน (1–24) · Section = ความกว้างชิ้น 100 (0.5–24) |
| `patSlots` | สีใหม่ของแต่ละสีในไฟล์ `["" \| สีธีม \| #rrggbb]` |

- คำนวณสีต่อชิ้น: `shopPatternPaint` / `shopPatternLookOf` ใน `lib/website-frames.ts` (**มิเรอร์** เว็บร้าน `src/lib/frames.ts` — แก้ ERP แล้วคัดลอกทั้งไฟล์)
- วาด: เว็บร้าน `ShopPatternArt` (src/components/home/CanvasShapes.tsx) ↔ ERP สำเนา `components/website-canvas-shapes.tsx`
- แผงตั้งค่า: `components/website-shop-pattern.tsx` (`ShopPatternControls` · `ShopPatternBox` · `patternInsert`) ใช้ทั้งแผงขวาผืนผ้าใบและแผงของตกแต่ง Section
- ฟอร์มละเอียดของผืนผ้าใบ: ชิ้นที่มีลายของร้านซ่อนช่องลายในตัว (ลาย/สี/ไล่สี/เส้น) ด้วย `showIf { key: "pattern", eq: [null, undefined] }`
- โบนัส: ลายในตัวแบบเส้นขอบใน Section ปรับความหนาเส้นได้แล้ว (`strokeWidth` เดิมตายตัว 2)

## ลายในตัว: สีพื้น + สีเส้นแยก (2026-10-24 รอบ 2)

ลายในตัว (โบว์ หัวใจ ดาว ดอกไม้ สี่เหลี่ยม วงรี ซุ้ม มุก กันสาด โน้ต สติกเกอร์ เทป คลิปดำ) ใช้แผงเดียวกับลายของร้านโหมดสีเดียว
= ของกลาง `FillLineControls` (components/website-shop-pattern.tsx) + ตรรกะ `fillLineView` / `fillLinePick` (lib/website-canvas.ts)

| กลุ่ม | ลาย | แผง |
| --- | --- | --- |
| มีพื้น (`canvasShapeHasLine`) | ที่เหลือทั้งหมด | สีพื้น (∅ = ไม่เติม) · สีเส้น (∅ = ไม่มี) · ความหนาเส้น (โชว์เมื่อมีเส้น) |
| เส้นล้วน `CANVAS_LINE_ONLY_SHAPES` | line · wave · lace | สีเดียว + ความหนาเส้น |
| สีเดียว `CANVAS_ONE_COLOR_SHAPES` | clip · barcode | สีเดียว |

- ข้อมูลใช้ช่องเดิม `lineColor` / `lineColorHex` (ไม่มีช่องใหม่) · ไม่ตั้ง = หน้าตาเดิมทุกชิ้น ("แบบเส้น" รุ่นเก่า = เส้นสีของลาย)
- กันชิ้นหาย: เอาพื้นออกตอนไม่มีเส้น = ย้ายสีไปเป็นเส้น · เอาเส้นออกตอนไม่มีพื้น = กลับเป็นทึบด้วยสีเส้นเดิม
- ตัววาด `CanvasShape` รับ `line` (เว็บร้าน + สำเนา ERP) — กลุ่มเส้นล้วน/สีเดียวไม่ใช้ line · ⚠️ รายชื่อลาย 2 กลุ่มต้องตรงกับตัววาด
- ผืนผ้าใบ: ฟอร์ม "ตั้งค่าละเอียด" มีช่องสีเส้นให้ลายที่มีพื้นด้วย · ปุ่ม "ทึบ/เส้น" เดิมถูกแทนด้วยสีพื้น ∅
- ของตกแต่ง Section: กล่องติ๊ก "แบบเส้นขอบ (ไม่ทึบ)" ถูกแทนด้วยสีพื้น ∅

## สิทธิ์ / ประวัติ

- อัปไฟล์ผ่าน `/api/assets` เดิม (สิทธิ์ + ประวัติของคลังไฟล์) · ลายอยู่ในข้อมูลหน้าเว็บ → บันทึกร่าง/เผยแพร่ตามระบบหน้าเว็บเดิม (ไม่มี API / ตารางใหม่)
- เว็บร้านกรองซ้ำ (`normalizeShopPattern`) ก่อนวาด และสร้าง `<path>` จาก JSON (ไม่ใช้ innerHTML) — ข้อมูลแปลกจาก ERP = ไม่วาดลาย (กลับเป็นลายในตัว)

## ข้อจำกัด

- ไฟล์ไม่เกิน 1 MB · ไม่เกิน 400 ชิ้นส่วน / 80,000 ตัวอักษรของเส้นทาง (ลายถูกคัดลอกลงข้อมูลหน้า — ใหญ่ไป = หน้าโหลดช้า)
- ไล่สี / ลาย pattern ในไฟล์ → สีเดียว (สีแรก) · `<use>` / symbol ถูกข้าม (มีคำเตือน)
- ไฟล์ใช้ไม่ได้ (เช่น มีแต่รูปฝัง) → วางเป็นรูปธรรมดาให้แทน (เปลี่ยนสีไม่ได้) พร้อมบอกเหตุผล
