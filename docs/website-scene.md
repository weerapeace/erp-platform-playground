# 🎞️ การ์ดบนฉาก (Section `scene`)

> เจ้าของขอ (2026-10-22) — ส่งรูปอ้างอิง (พื้นหลังภาพบรรยากาศ + การ์ดสินค้ากระจกเลื่อนข้าง) → ดู widget ตัวอย่างแล้วสั่ง "ทำ Section การ์ดบนฉากตามนี้"

## ใช้ทำอะไร

พื้นหลังเต็มจอ (รูปหรือวิดีโอ) + แถวการ์ดสินค้ากระจกเลื่อนข้าง · **เลื่อนการ์ดถึงชิ้นที่ตั้งไว้ → พื้นหลังค่อย ๆ เปลี่ยนเป็นฉากถัดไป** · แท็บด้านบน (สูงสุด 3) แต่ละแท็บมีสินค้าและฉากของตัวเอง

**ไม่ควรใช้** เมื่อไม่มีรูป/วิดีโอบรรยากาศที่ดี (ฉากเป็นตัวชูการ์ด) — ใช้ "ตารางสินค้า" แบบเลื่อนข้างแทน

## วิธีใช้

1. ตัวจัดหน้า → `+ เพิ่ม Section` → 🎞️ การ์ดบนฉาก (กลุ่มสินค้า)
2. **สินค้า**: จำนวนแท็บ 1–3 (1 = ไม่โชว์แท็บ) · แต่ละแท็บ: ชื่อ + สินค้า (มาใหม่ = ขึ้นร้านล่าสุด / ขายดี = อันดับขาย / เลือกเอง ≤ 24) + จำนวน 3–24
3. **ฉากพื้นหลัง** (ชิ้นย่อย ≤ 12): อยู่แท็บไหน + **เริ่มที่สินค้าชิ้นที่** + รูปหรือวิดีโอ (เลือกจากคลัง · วิดีโอใช้รูปเป็นปกตอนคลิปยังโหลด) + ให้เห็นส่วนบน/กลาง/ล่างของภาพ
   - ฉากแรกของแท็บควรเริ่มที่ 1 · แท็บที่ไม่มีฉาก = ใช้ฉากของแท็บ 1 (ERP เตือน)
4. **การ์ดในส่วนนี้**: แบบการ์ด (กระจกฝ้า / Liquid Glass / ทึบ) · สีกระจก (ขาวใส ตัวหนังสือขาว / ดำใส / ขาวขุ่น ตัวหนังสือดำ) · ความขุ่น % · ความเบลอหลังการ์ด · เส้นขอบ · มุมมน · ขนาด · โชว์ยี่ห้อ/หมวด · ราคา · ปุ่ม ♡
5. **การจัดวาง**: ความสูงเวที (ปกติ/สูง/เต็มจอ) · ทำพื้นหลังมืดลง % (ตัวหนังสืออ่านง่ายขึ้น)

## รูปสินค้าพื้นใส

- **รูปตัดพื้น (PNG)** — ช่องรูปใหม่ของ Parent SKU (กลุ่มรูป ถัดจากรูปปก · คอลัมน์ `parent_skus_v2.png_image_r2_key` · ทะเบียนฟิลด์ชนิด image → ส่งเว็บร้านเป็น `imageFields.png_image_r2_key` อัตโนมัติ)
- ไม่มี PNG = เว็บร้าน **ลบพื้นเรียบ (ขาว/เทา/สีเดียว) ของรูปสินค้าให้เองในเบราว์เซอร์** (ของกลาง `src/lib/bg-knockout.ts`: ไล่ลบจากขอบรูปเข้าหาสินค้า + ขอบนุ่ม · ทำทีละรูป · จำผล)
  - พื้นไม่เรียบ (รูปบรรยากาศ/นางแบบ) = ใช้รูปเดิมเต็มกรอบมุมมน · เลือก "รูปเดิม" ได้ในช่อง "รูปสินค้าบนการ์ด"
  - ⚠️ สินค้าสีขาว/เทาอ่อนบนพื้นขาว อาจถูกลบขอบไปบ้าง → ใส่ PNG ตัดพื้นให้รุ่นนั้น

## พฤติกรรม (เว็บร้าน `SceneBody`)

- "ชิ้นที่เลื่อนถึง" = สัดส่วนที่เลื่อนแถว × จำนวนชิ้น → เลื่อนสุดขวา = ชิ้นสุดท้ายเสมอ · การ์ดไม่ล้นแถว (เลื่อนไม่ได้) = ชี้/โฟกัสการ์ดแทน
- เลื่อนได้: ปัด (มือถือ/ทัชแพด) · ลากด้วยเมาส์ · ลูกศร (คอม) · จุดบอกหน้า · ปุ่มลูกศรคีย์บอร์ด
- ฉากโหลดเมื่อถึงคิว + คิวถัดไป · วิดีโอเล่นเฉพาะฉากที่โชว์ + อยู่บนจอ (ของกลาง `AutoLoopVideo` prop `active`) · ลด motion = ไม่ซูมช้า ๆ
- กดการ์ด = ไปหน้าสินค้า · ♡ = รายการโปรดของกลาง (`WishlistHeart` · ร้านปิดสมาชิก = ไม่โชว์)
- มือถือ: แถวการ์ดชิดขอบจอ · ไม่มีลูกศร
