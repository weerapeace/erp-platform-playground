# 📝 แทรกรายละเอียด + 🧵 หน้าวัสดุ (ของกลาง)

เจ้าของเลือก "แบบ A" (2026-10-17): กดเลือกแล้วระบบ **พิมพ์บรรทัดลง Description ตรงตำแหน่งที่เลือก** (เป็นข้อความธรรมดา แก้ต่อได้) + ชื่อวัสดุบนเว็บร้าน **ลิงก์ไปหน้าวัสดุอัตโนมัติ**

## ใช้ทำอะไร

- ปุ่ม **＋ แทรก** ข้างหัวข้อ Description (ฟอร์ม Parent SKU ทั้งหน้าดู/หน้าแก้ไข) → ป๊อป **แบ่งซ้าย-ขวา** (เจ้าของเลือก 2026-10-17): ซ้าย = เลือก · ขวา = ตัวอย่างคำอธิบาย (สลับ ไทย/EN) · มือถือเรียงบน-ล่าง
  - 📝 **ข้อความสำเร็จรูป** — ติ๊กได้หลายข้อ ได้บรรทัดละข้อ (เช่น "- ผลิตในประเทศไทย")
  - 🧵 **วัสดุ** — ติ๊กได้หลายตัว รวมบรรทัดเดียว "- วัสดุ: A และB" · ป้าย 🔗 = มีหน้าวัสดุแล้ว
  - 🔢 **ช่อง (ใส่ตัวเลข)** — พิมพ์แค่จำนวน รวมบรรทัดเดียว "- ช่องใส่บัตรเครดิต 6 ช่อง, ช่องใส่ธนบัตร 2 ช่อง"
  - 📏 **ขนาด/น้ำหนัก** — ดึง กว้าง/สูง/หนา/น้ำหนัก จากช่องของสินค้า → "- ขนาด: กว้าง 30 × สูง 20 × หนา 10 ซม." · "- น้ำหนัก: 450 กรัม" · **แก้ตัวเลขในป๊อป = บันทึกกลับช่องของสินค้า** (ติ๊กไม่ใส่บรรทัดได้ ตัวเลขยังบันทึก)
  - 🎒 **ใส่อะไรได้** — รายการกลาง `product_fit_items` (ไม่รวมตุ๊กตา) + เลือกขนาด → "- ใส่ได้: iPad (11 นิ้ว), เอกสาร A4" · ติ๊กในป๊อป = แก้ช่อง `fits` ของสินค้า · ฝั่งอังกฤษแปลหน่วย (11 นิ้ว → 11")
  - แท็บขนาด/ใส่อะไรได้ โชว์เฉพาะเมื่อฟอร์มมีช่องนั้นและแก้ได้ (master-crud ส่ง `writable`) · มุมขวาสรุป "🔄 บันทึกกลับช่องของสินค้าด้วย: กว้าง 28→30 …"
- ✏️ ทุกแถว = ป๊อปเล็กแก้รายการกลาง: ชื่อไทย/อังกฤษ (ปุ่ม 🌐 แปล) · รูปแบบบรรทัด (ช่อง · มีตัวอย่าง 6 ช่อง) · ขนาดให้เลือก (ของที่ใส่ได้) · ลิงก์เขียนหน้าวัสดุ · **🗑 ลบ = ซ่อนจากรายการ (soft delete ผ่าน DELETE /api/master-v2 · กู้ได้ที่หน้ารายการกลาง)** · ＋ เพิ่มใหม่ใช้ป๊อปเดียวกัน
- เลือกตำแหน่ง: คลิกช่องว่างระหว่างบรรทัดในตัวอย่าง (บรรทัดใหม่สีส้มโผล่ตรงนั้น) หรือปุ่ม บนสุด/ท้ายสุด
- ภาษาอังกฤษ: ติ๊ก "ใส่ภาษาอังกฤษด้วย" → แทรกลง English Description (บรรทัดเท่ากับไทย = ตำแหน่งเดียวกัน · ไม่เท่า = ต่อท้าย) · รายการที่ไม่มีชื่ออังกฤษ = ข้ามฝั่งอังกฤษ
- หน้าดู = บันทึกทันที (PATCH กลางครั้งเดียวทุกช่อง: คำอธิบาย + อังกฤษ + ขนาด/น้ำหนัก/fits + audit) · หน้าแก้ไข = ใส่ค่าในฟอร์ม แล้วกดบันทึกของฟอร์ม
- หน้ารายการกลางเต็ม: `/m/product_highlight_items` (ข้อความ/ช่อง) · `/m/product_materials` (วัสดุ) · `/m/product_fit_items` (ของที่ใส่ได้)

## เว็บร้าน

- ERP `/api/public/storefront/products` ส่ง `materialLinks: [{ slug, terms }]` = วัสดุที่มีหน้าแล้ว + ชื่อ/คำเรียกอื่นโผล่ในคำอธิบาย (ไทย/อังกฤษ) หรือฟิลด์สเปกที่ส่งออกเว็บ
- เว็บร้าน `src/lib/materials.ts` `linkifyMaterials` ทำคำนั้นเป็นลิงก์ (ครั้งแรกที่เจอของแต่ละวัสดุ) ใน 3 ที่: คำอธิบายย่อข้างราคา (ClampText) · หัวข้อแหล่ง "คำอธิบาย" · หัวข้อแหล่ง "ฟิลด์"
- หน้า `/materials/<slug>` (+ `/en/...`) = ชื่อ · รูป · คำอธิบาย · วิธีดูแลรักษา · สินค้าของร้านนี้ที่ใช้วัสดุนี้ · ข้อมูลจาก `/api/public/storefront/materials?slug=`
- sitemap ใส่หน้าวัสดุที่สินค้าของร้านลิงก์ไปจริง

## กฎสำคัญ

- **ลิงก์เฉพาะวัสดุที่เปิดใช้ + มีคำอธิบายแล้ว** — วัสดุตั้งต้น 6 ตัวยังไม่มีคำอธิบาย = ยังไม่ลิงก์ (กันลูกค้าเจอหน้าว่าง)
- `aliases` = คำเรียกอื่นคั่นจุลภาค (เช่น "หนังนัปป้า, Nappa leather") · คำสั้นกว่า 2 ตัวอักษรไม่ใช้
- `slug` ว่าง = สร้างจากชื่ออังกฤษ (trigger ใน DB) · ไม่มีชื่ออังกฤษ = `m-<รหัส>` · เปลี่ยน slug = ลิงก์เก่าเสีย
- ชนิด "ช่อง": `template` / `template_en` ใช้ `{name}` `{n}` · ว่าง = "{name} {n} ช่อง" / "{name} × {n}"
- ช่อง "รายละเอียดเพิ่ม (ติ๊ก)" เดิมยังใช้ได้ (ซ่อนชนิด "ช่อง" เพราะต้องใส่ตัวเลข)
