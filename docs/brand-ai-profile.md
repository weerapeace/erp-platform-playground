# การ์ดรู้จักแบรนด์ (ข้อมูลแบรนด์ให้ AI) — ของกลาง

**ใช้ทำอะไร:** บอก AI ว่าแบรนด์นี้คือใคร ลูกค้าคือใคร ขายอะไรเด่น เขียนแบบไหน ห้ามพูดอะไร — ตั้งครั้งเดียว ทุกปุ่ม AI ใช้ร่วมกัน
(เจ้าของขอ 2026-11-01: "อยากได้ prompt ที่บอกให้ AI รู้จักแบรนด์มากขึ้น")

## ใช้ที่ไหน (อ่านอัตโนมัติ ไม่ต้องตั้งเพิ่ม)
| ปุ่ม AI | ไฟล์ | ใส่อะไร |
|---|---|---|
| วางแผนแบบ Mass (ทั้ง prompt ก๊อปไปถาม และ AI ในระบบ) | `app/api/ai/mass-plan` · `lib/marketing/mass-plan` (`brief.brandProfile`) | การ์ดเต็ม + สินค้าเด่นตอนนี้ |
| AI เขียนแคปชั่น (ทีละช่อง / ทั้งหมด) | `app/api/ai/caption` · `app/api/ai/caption-all` | การ์ดเต็ม (ไม่รวมสินค้าเด่น — เขียนต่อคอนเทนต์อยู่แล้ว) |
| AI รายละเอียดสินค้า | `app/api/ai/product-detail` | การ์ดแบบ `forProduct` — ไม่ใส่แคปชั่นตัวอย่าง + เตือนห้ามเอาจุดขายแบรนด์ไปอ้างเป็นคุณสมบัติสินค้าชิ้นนั้น |

การ์ดว่าง = ไม่ใส่อะไร (ทำงานเหมือนเดิม)

## ช่องในการ์ด
- พิมพ์เอง 6 ช่อง: แบรนด์คือใคร · ลูกค้าหลัก · จุดขายที่พูดบ่อย · โทนภาษา · ต่างจากคู่แข่งยังไง · ข้อห้าม (`BRAND_PROFILE_FIELDS`)
- แคปชั่นตัวอย่างที่ชอบ ≤ 3 — เลือกจากแคปชั่นเก่าของแบรนด์ หรือพิมพ์เอง (AI เลียนโทน ไม่ลอกคำ)
- **สินค้าเด่นตอนนี้ — ระบบเติมสดทุกครั้ง ไม่ได้เก็บในการ์ด:** รุ่นที่ติดป้าย `NEW IN` (ก่อน) แล้ว `Hero` ในหน้า SKU การตลาด ≤ 12 รุ่น (`brandHighlights`)
- ปุ่ม **"ให้ AI ช่วยร่างช่องที่ว่าง"** (`POST /api/ai/brand-profile-draft`) — อ่านชื่อแบรนด์ ช่องทางร้าน โทนแคปชั่นที่ตั้งไว้ prompt AI ของแบรนด์ ชื่อสินค้า แคปชั่นเก่า → ร่าง **เฉพาะช่องที่ว่าง** · ไม่รู้ = เขียนเป็น `[ ]` ให้ทีมเติม · ห้ามแต่งข้อเท็จจริง · ยังไม่บันทึกจนกดบันทึก · ≈ 0.2 บาท/ครั้ง · audit `ai_brand_profile_draft`

## ที่เก็บ + สิทธิ์
- `ui_config` key `brand_ai_profiles` = `{ [brand_id]: BrandProfile }` — **ไม่มีตารางใหม่** (แบบเดียวกับตั้งค่าแพลตฟอร์มต่อแบรนด์)
- API `/api/brand-ai-profile`: GET (ภาพรวมทุกแบรนด์ / ?brand_id= การ์ด+สินค้าเด่น · &captions=1 แคปชั่นเก่า) = `tasks.view` · PUT = `tasks.approve` (เท่ากับแก้ prompt AI) · audit `brand_ai_profile.update` (before/after)
- คนไม่มีสิทธิ์แก้ เปิดดูได้อย่างเดียว

## ทางเข้า
- ปฏิทินคอนเทนต์ → วางแผนแบบ Mass → แถบ "การ์ดรู้จักแบรนด์ กรอกแล้ว x/7" → เปิดการ์ด
- ตั้งค่างาน → แท็บ Prompt แคปชั่น AI → แถว "การ์ดรู้จักแบรนด์" (ปุ่มต่อแบรนด์ + สถานะ)

## ข้อจำกัด
- ณ 2026-11-01 ยังไม่มีแบรนด์ไหนกรอก (คำอธิบายแบรนด์ว่างทั้ง 9) — ต้องให้ทีมทำการ์ดก่อน AI ถึงจะรู้จักแบรนด์มากขึ้น
- สินค้าเด่นขึ้นกับป้ายในหน้า SKU การตลาด (Louis Montini: NEW IN 28 · Hero 81) — แบรนด์ที่ไม่ได้ติดป้ายจะไม่มีสินค้าเด่น
- แก้พร้อมกันสองคนคนละแบรนด์ = ปลอดภัย (อ่านล่าสุดก่อนเขียน) · แบรนด์เดียวกันพร้อมกัน = คนกดทีหลังชนะ
