# ◎ วงแอป — หน้ารวมแอปแบบการ์ดล้อมเป็นวง (ของกลาง)

## ใช้ทำอะไร
หน้ารวมแอป `/apps` แบบใหม่ (เจ้าของเลือก "แบบ B" จากภาพ Pinterest การ์ดลอยเป็นวง — 2026-10-26)
- **จอคอม/แท็บเล็ต:** แอปทั้งหมด (`erp_app_groups`) เรียงเป็นวงรอบแผงกลาง · แผงกลาง = คำทักทาย + ค้นหา + เมนูของแอปที่เลือก + ปุ่ม "เปิดแอป"
- **มือถือ / จอแคบกว่า 700px:** แถบแกลเลอรีเลื่อนซ้ายขวา ใบกลางใหญ่ + รายการเมนูด้านล่าง

## ใช้ยังไง
- กดแอป = หมุนแอปนั้นขึ้นบนสุด + แผงกลางโชว์เมนู · **กดแอปที่เลือกอยู่ซ้ำ** หรือปุ่ม **เปิดแอป…** = เข้าแอป (หน้าแรกของแอป)
- **ลาก** บนวงเพื่อหมุน (ปล่อยแล้วแอปที่อยู่บนสุดถูกเลือก) · ปุ่มลูกศร ← → เลือกแอปข้าง ๆ
- มือถือ: ปัดซ้ายขวา หรือกด ‹ › · กดใบกลาง = เข้าแอป
- **ค้นหา:** พิมพ์แล้วแผงกลางโชว์เมนูที่ตรงจากทุกแอป (ชื่อเมนู / คำค้นเพิ่ม / ชื่อแอป) · แอปที่ไม่เกี่ยวจะจางลง · Enter = เปิดผลแรก
- สลับกลับ **▦ ตารางไอคอน** ได้ที่ปุ่มบนซ้ายของหน้า — จำรายคน (`user_ui_prefs.launcher_prefs.view`, ไม่ตั้ง = วงแอป)
- ⚙️ จัดการหน้าแรก (ปักโปรด/ซ่อน/ตั้งชื่อ) ยังทำในตารางไอคอน — ค่าที่ตั้ง (ซ่อนเมนู/ชื่อเล่น/ไอคอน) มีผลในวงแอปด้วย · ⭐ โปรด + งานของฉัน อยู่ใต้วง

## กติกา (lib/app-orbit.ts — มีเทสต์ lib/__tests__/app-orbit.test.ts)
- **แอปที่โชว์:** เปิดใช้ + ไม่ล็อก/มีสิทธิ์ตาม `permission_key` ของแอป + มีเมนูที่ผู้ใช้เห็นอย่างน้อย 1 อัน
- **เมนูในแอป:** กฎเดียวกับแถบเมนู — `is_active` + `show_in_sidebar` + `app_keys` มีแอปนั้น + `permission_key` รายเมนู + 👁 `menuVisibleTo` + ↕️ ซ่อน/ชื่อ/ลำดับต่อแอป (`app_overrides`) · เมนูย่อยไม่โชว์ซ้ำ · ไม่เอาลิงก์ `/apps` เอง
- **หน้าแรกของแอป** (`appHomeHref`): "หน้าแรก" ที่ตั้งใน ⚙️ ตั้งค่าแอป (`default_href`, ถ้าผู้ใช้เห็นเมนูนั้น) → หน้าสำรองในโค้ด → เมนูตัวบนสุด — **ตัวเดียวกับแท็บแอปด้านบนของ PlaygroundShell**
- เปิดแอป/เมนูจากวง = จำแอปลง `localStorage['erp-active-app']` → แท็บแอปด้านบนตรงกับแอปที่กด
- สีการ์ด = `erp_app_groups.theme_color` (สีอ่อน) · ไอคอน = `icon_url` (รูป) หรืออีโมจิ `icon` — แก้ที่ /admin/menu ไม่ต้องแก้โค้ด
- ทะเบียนเมนู/แอปโหลดไม่ได้ (เช่น ยังไม่ล็อกอิน) → กลับไปใช้ตารางไอคอนอัตโนมัติ
- คนที่ตั้งเครื่องให้ลดภาพเคลื่อนไหว → การ์ดไม่เล่นแอนิเมชันหมุน
