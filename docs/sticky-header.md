# 📌 หัวหน้าติดบนตอนเลื่อน (Sticky Header) — ของกลาง

`components/sticky-header` · hook `useStickyHeader()`

## ใช้ทำอะไร
ให้แถบปุ่มของหน้าค้างอยู่ใต้แถบเมนูของแอป เลื่อนลงไปไหนก็ยังกดได้ — ป้าย/คำอธิบายด้านบนเลื่อนหายไปเอง เหลือแถบบางบรรทัดเดียว

## ทำงานยังไง
- หัวทั้งก้อนเป็น `position: sticky` แบบ **top ติดลบ** → เลื่อนขึ้นไปจนเหลือโชว์แค่ส่วนที่ติด `keepRef` (บวกที่ว่าง `gap`)
- ความสูงหัว**ไม่เปลี่ยน**ตอนติด → เนื้อหาด้านล่างไม่กระตุก · อยากเปลี่ยนหน้าตาตอนติด (พื้นหลัง / ชื่อหน้าแบบย่อ) ใช้ค่า `stuck` แล้วซ่อนของเดิมด้วย `invisible` (ยังกินที่เท่าเดิม) + วางของใหม่แบบ `absolute`
- วัดแถบบนของแอปเองจาก element ที่ติด `data-shell-topbar` — มีแล้วที่ `playground-shell` (หัว fixed จอเล็ก + แถบแท็บแอปจอใหญ่) และ `standalone-shell` · **shell ใหม่ที่มีแถบติดบนต้องติด attribute นี้ด้วย**
- อยู่ในกรอบที่เลื่อนเอง (เช่น กรอบจำลองมือถือ `DevicePreviewFrame`) → ติดขอบบนกรอบแทน

## ตัวอย่าง
```tsx
const sticky = useStickyHeader({ watch: layout });   // watch = ค่าที่เปลี่ยนเมื่อหัวถูกสลับเป็นอีกก้อน
<div ref={sticky.headerRef} style={sticky.style}
  className={`relative z-[15] ${sticky.stuck ? "bg-white/95 border-b shadow-sm backdrop-blur" : ""}`}>
  …ป้าย / ชื่อหน้า / คำอธิบาย…
  <div ref={sticky.keepRef}>…ปุ่มที่ต้องเห็นตลอด…</div>   {/* ไม่ใส่ keepRef = ติดทั้งก้อน */}
</div>
// หัวคอลัมน์/หัวตารางที่ติดต่อด้านล่าง → style={{ top: sticky.below }}
```

## ข้อควรระวัง
- สายแม่ทั้งสายต้องไม่มี `overflow-*` (ใช้ `overflow-x-clip` แทน) ไม่งั้น sticky ตายเงียบ
- z-index หัว = 15 (ต่ำกว่าแถบแอป z-20/30 · สูงกว่าหัวคอลัมน์ z-10)
- ใช้อยู่ที่: Design Dashboard (จอคอม/แท็บเล็ต = แถบบาง ชื่อหน้า + ปุ่ม · มือถือ = ติดทั้งหัว · หัวคอลัมน์บอร์ดติดต่อใต้แถบ)
