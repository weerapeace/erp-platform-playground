# 👤 ประวัติลูกค้าหน้าเดียว (เว็บร้าน · ชุด 8b)

แผงด้านขวา (Drawer กลาง · อ่านอย่างเดียว) รวมทุกอย่างของลูกค้า 1 คน ไม่ต้องไล่หาหลายแท็บ

**เปิดได้จาก**
- ERP › เว็บไซต์ › 👥 สมาชิก → กดแถวสมาชิก (ปุ่มแต้ม/ระงับในแถวยังกดได้ตามเดิม ไม่เปิดแผง)
- ERP › เว็บไซต์ › 🧾 ออเดอร์ → เปิดออเดอร์ → "👤 ประวัติลูกค้าคนนี้" ข้างชื่อผู้รับ (ใช้ได้กับลูกค้าแขกด้วย)

**ในแผงมี:** เบอร์/อีเมล · สมัครเมื่อ/เข้าล่าสุด/เข้าด้วย (สมาชิก) · ชื่อที่เคยใช้สั่ง · รู้จักร้านจากไหน (แหล่งของออเดอร์แรก — ชุด 8)
ตัวเลข: ออเดอร์ (ไม่นับยกเลิก) · ซื้อรวม/เฉลี่ย · ซื้อล่าสุด/ครั้งแรก · แต้มคงเหลือ+ระดับ (สมาชิก) หรือจำนวนที่ถูกใจไว้
ตาราง: ออเดอร์ทั้งหมด (สถานะ+การจ่าย สีเดียวกับแท็บออเดอร์) · 🛍 ซื้อบ่อย (รายรุ่น) · 📍 ที่อยู่ที่เคยส่ง (รวมซ้ำ) · ⭐ รีวิว

**จับคู่ลูกค้า:** สมาชิก + ออเดอร์แขกที่ใช้เบอร์เดียวกัน — เทียบเบอร์หลายรูปแบบ (081-234-5678 · 0812345678 · +66812345678 · 66812345678)
ค้น 2 ทาง (ตามบัญชี · ตามเบอร์) แล้วรวมตัดซ้ำ · ออเดอร์สูงสุด 500 ใบล่าสุด · รีวิว 30 อันล่าสุด
