# แม่แบบเอกสาร (Report Template Designer)

หน้า `/admin/report-templates` — ของกลางสำหรับออกแบบหน้าตาเอกสารที่พิมพ์ (ใบเสนอราคา, ใบวางบิล, ใบกำกับภาษี, ใบสั่งซื้อ, ใบงานออกแบบ ฯลฯ)
แม่แบบเก็บในตาราง `erp_report_templates` (header/body/footer HTML + CSS) แยกตาม `entity_type`

## หน้าตา (3 ช่อง)

- **ซ้าย** รายการแม่แบบ จัดกลุ่มตามเอกสาร · จุดเขียว = ใช้งานอยู่ · จุดเหลือง = ร่าง · "หลัก" = แม่แบบหลักของเอกสารนั้น · "ลากวาง" = แบบ pdfme
- **กลาง** พรีวิว 3 โหมด: ข้อมูลตัวอย่าง · เอกสารจริง · เทียบเวอร์ชัน (แบบลากวาง = ตัวออกแบบ pdfme)
- **ขวา** แท็บ ตั้งค่า (+ ใช้พิมพ์ที่) · ข้อมูล · ตาราง · โค้ด · ประวัติ

## สถานะ + กติกาบันทึก (สำคัญ — กันหน้าพิมพ์จริงพัง)

สถานะดูจาก flag ใน DB (`inferTemplateStatus`): `active` = ใช้งานอยู่ · ไม่ active + เคยกดเก็บ = เก็บแล้ว · นอกนั้น = ร่าง

| ปุ่ม | ผล |
|---|---|
| บันทึก | เก็บเนื้อหา **คง active/is_default เดิม** (ใบที่ใช้อยู่ยังใช้ต่อ) |
| ใช้งานจริง (เฉพาะร่าง) | active + is_default — ถามก่อน บอกว่าจะแทนใบหลักใบไหน (RPC ล้าง default ใบอื่นของเอกสารเดียวกัน) |
| เก็บเข้าคลัง | active=false — ถามก่อนถ้ากำลังใช้งาน |

⚠️ ของเดิม "บันทึก Draft" ทำให้ใบที่ใช้อยู่หยุดใช้ทันที และ Publish ใบรอง (เช่น ใบส่งสินค้า) ไปแย่ง default ของใบกำกับภาษี — แก้แล้ว 2026-11-06

## ของกลางที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|---|---|
| `lib/report-designer.ts` | `REPORT_ENTITY_DEFS` (field + ตาราง + ข้อมูลตัวอย่างต่อเอกสาร), สถานะ, ตัวช่วยสร้างตาราง |
| `lib/report-entity-samples.ts` | field + ข้อมูลตัวอย่างของ ใบวางบิล / ใบสั่งขาย-ใบกำกับภาษี / ใบลดหนี้ / ใบสั่งซื้อ / ใบงานออกแบบ 4 แบบ (ชื่อตัวแปรดึงจากแม่แบบจริง) |
| `lib/report-usage.ts` | **ทะเบียนว่าเอกสารแต่ละประเภทใช้พิมพ์ที่หน้าไหน + หน้านั้นหยิบแม่แบบยังไง** (default / default_or_chosen / chosen / template_key) |
| `lib/report-template-preview.ts` | พรีวิวด้วยเอกสารจริง: หน้าออกแบบฝากแม่แบบที่กำลังแก้ไว้ที่ window → หน้าพิมพ์ใน iframe (`apiFetch`) สลับเนื้อหาให้ ไม่แตะ DB |
| `lib/report-template-history.ts` | ประวัติ: ก่อนบันทึกทับ เก็บสำเนาทั้งใบลง `entity_field_history` (entity_type `erp_report_templates`, field_key `template`) ล่าสุด 30 ครั้ง |
| `components/pdfme-designer` | ตัวออกแบบลากวาง (pdfme) ใช้ทั้งหน้านี้และ `/admin/report-builder` |

API: `GET /api/admin/report-templates/sample-docs?entity_type=&q=` (เอกสารจริง 20 ใบล่าสุด, reports.view) · `GET /api/admin/report-templates/history?id=` (reports.view)

## ทำหน้าพิมพ์ใหม่ที่ใช้แม่แบบ

1. ดึงแม่แบบผ่าน `apiFetch("/api/admin/report-templates?entity_type=…")` (ต้องเป็น apiFetch — พรีวิวเอกสารจริงอาศัยจุดนี้)
2. เพิ่มแถวใน `REPORT_USAGES` (`lib/report-usage.ts`) + แหล่งเอกสารใน `sample-docs/route.ts`
3. ถ้าเป็นเอกสารประเภทใหม่ เพิ่ม field + ข้อมูลตัวอย่างใน `lib/report-entity-samples.ts`

## Template Syntax

- `{{field}}` ค่า field (escape HTML) · `{{{field_html}}}` HTML ที่ระบบสร้างให้ (รูป, ตาราง `lines_table`)
- `{{#lines}} … {{/lines}}` วนรายการ · `{{#flag}} … {{/flag}}` โชว์เมื่อมีค่า

## ข้อจำกัด

- แบบลากวาง (pdfme) ใช้พิมพ์จริงได้เฉพาะ **ใบสั่งงานผลิต** (`/print/work-order` ให้เลือกแม่แบบเองในหน้าพิมพ์)
- พรีวิวเอกสารจริงของใบสั่งงานผลิต: หน้าพิมพ์ให้เลือกแม่แบบเอง → เลือกชื่อแม่แบบที่กำลังแก้ในหน้าพิมพ์
- ประวัติเริ่มเก็บตั้งแต่ 2026-11-06 (ของก่อนหน้านั้นย้อนไม่ได้) · ย้อนเวอร์ชัน = โหลดเข้าเป็นงานที่ยังไม่บันทึก แล้วกดบันทึกเอง
- เทียบเวอร์ชันแบบภาพใช้ได้เฉพาะแม่แบบ HTML
