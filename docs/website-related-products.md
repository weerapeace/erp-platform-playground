# 🔗 แนะนำสินค้า — สินค้าที่เกี่ยวข้อง + 👀 สินค้าที่ดูล่าสุด (หน้าสินค้าบนเว็บร้าน)

> เจ้าของขอ (2026-10-20): "สินค้าที่เกี่ยวข้อง มีหน้า Set ให้ด้วยว่าจะเชื่อมกันด้วยอะไร · สินค้าที่ดูล่าสุดหาปุ่มปิด-เปิดไม่เจอ"
> เลือกครบ 3 อย่าง: กฎหลายชั้นเรียงลำดับได้ · เลือกเองรายสินค้า · หน้าตั้งค่าเด่น ๆ

## ใช้ทำอะไร

- **สินค้าที่เกี่ยวข้อง** — ส่วนท้ายหน้าสินค้า ชวนดูรุ่นอื่น · ตั้ง "เชื่อมด้วยอะไร" เป็นกฎหลายข้อเรียงลำดับ → ระบบทำตามลำดับจนครบจำนวน
- **สินค้าที่ดูล่าสุด** — รุ่นที่ลูกค้าเคยเปิดดูในเครื่องตัวเอง (localStorage) · ยังไม่เคยดูตัวอื่น = ไม่โชว์

## ตั้งที่ไหน

| ที่ | ตั้งอะไร |
|---|---|
| เว็บไซต์ → 🎨 ดีไซน์ → แท็บ **🔗 แนะนำสินค้า** | เปิด/ปิด · หัวข้อ (ไทย/EN) · จำนวน · กฎเชื่อม (ลาก ⠿ เรียง) · รายการกลาง · เติมสินค้าอื่น · ดูล่าสุด เปิด/ปิด/หัวข้อ/จำนวน |
| แท็บ หน้าสินค้า → ลำดับส่วนประกอบ → ⚙️ ของ "สินค้าที่เกี่ยวข้อง" / "👀 สินค้าที่ดูล่าสุด" | การ์ดตัวเดียวกัน (เฉพาะส่วนนั้น) · 👁️ = ซ่อน/แสดง · ลากเรียงตำแหน่งได้ |
| สินค้า → แท็บ 🛍 เว็บไซต์ → "🔤 ปั๊มชื่อ · แบนเนอร์ · รายละเอียด · 🔗 เกี่ยวข้อง" | 🔗 สินค้าที่เกี่ยวข้องของรุ่นนี้ (เลือกเองรายรุ่น ≤ 12 · ต่อร้าน) |

## กฎเชื่อม (`RelatedRule`)

| กฎ | หาจาก |
|---|---|
| 📌 pinned — เลือกเองรายรุ่น | `store_listings.web_related` (products API ส่ง `related`) |
| 🧵 collection | คอลเลกชันเดียวกัน |
| 📂 category | หมวดหลักเดียวกันก่อน → หมวดที่อยู่ร่วมกัน (รวมหมวดแม่) |
| 🧶 material | วัสดุที่ผูกไว้ (materialLinks) ร่วมกัน |
| 💰 price | ราคาห่าง ≤ ±30% ใกล้สุดก่อน |
| ★ featured / 🔥 bestseller / 🆕 new | ติ๊กแนะนำ / ยอดขายเว็บ / ขึ้นเว็บล่าสุด |
| ✋ manual | รายการกลาง (ชุดเดียวกันทุกหน้า) — `parts.related.codes` |
| 🎲 random | สุ่มคงที่ต่อสินค้า (seed = id) |

- ได้ไม่ครบ + **fill** (ค่าเริ่มต้นเปิด) → เติมหมวดเดียวกัน แล้วสินค้าอื่น · ปิด = เท่าที่กฎหาได้
- ธีมเก่า (มีแค่ `source`) → `rules = ["pinned", source]` = หน้าตาเดิม · ERP เก็บ `source` คู่ไว้ให้เว็บรุ่นเก่า (`legacySourceOf`)

- เว็บร้าน: `src/lib/site-config.ts` (มิเรอร์) · `src/lib/related.ts` (`buildRelatedPool` เซิร์ฟเวอร์ · `pickRelated` เบราว์เซอร์ = พรีวิวสด) · `RecentlyViewed` (`count`) · โชว์เคส `nodes.recent` · คลาสสิกเคารพ hidden

## ข้อจำกัด

- ดูล่าสุดจำในเบราว์เซอร์ลูกค้า (ไม่ข้ามเครื่อง) · พรีวิวใน ERP จะว่างถ้าเครื่องนั้นยังไม่เคยเปิดสินค้าอื่น
- ราคาใช้ราคาต่ำสุดของรุ่น (ไม่ดูราคารายสี)
- ตั้งกฎแยกมือถือไม่ได้ (ใช้ร่วมกับคอม) · ซ่อน/เรียงแยกมือถือได้ตามเดิม
