# หน้าใบงานออกแบบบนมือถือ (Design Sheet Mobile)

> เปิดจาก Design Dashboard บนมือถือ/แท็บเล็ต → `/master/design-dashboard/sheet/[id]` · โค้ด `components/design-sheet-mobile/`
> จอคอมยังเป็นป๊อปอัปเดิม (`components/design-sheet-detail`) — ปุ่ม "หน้าเต็ม" บนแถบบนเปิดป๊อปอัปนั้นได้

## หน้าตา (จัดใหม่ 2026-11-10 · เจ้าของเห็น widget แล้วสั่ง "ใบงาน+ตีราคาก่อน")

- **แท็บแทนการเลื่อนยาว:** ภาพรวม · ตีราคา · เสนอราคา · คุยลูกค้า (นับจำนวน) · ไฟล์ — แถบแท็บติดใต้แถบบนตอนเลื่อน
  - ภาพรวม: รูปงาน (ปัดดู) · ข้อมูลสั้น + ⏳ รออะไรอยู่ · โน้ต · รายละเอียดงาน · ทางลัด 3 ช่อง (ต้นทุน/ใบ → แท็บตีราคา · รอบเสนอราคา → แท็บเสนอราคา · SKU → กางดู)
  - แท็บอื่นไม่โชว์รูปใหญ่ด้านบน (เห็นเนื้อหาทันที)
- **แถบปุ่มล่าง (มือถือ):** เปลี่ยนสถานะ · Comment (ไปแท็บคุยลูกค้า + เคอร์เซอร์รอพิมพ์) · ไฟล์ — แท็บตีราคาใช้แถบของตัวเอง
- **ไม่มีสิทธิ์เห็นต้นทุน** (API ส่ง `cost_restricted`) = ไม่มีแท็บตีราคา / ช่องต้นทุน

## จัดใหม่รอบ 2 (2026-11-11 · เจ้าของเห็น widget แล้วเลือก "หน้ามือถือ + จัดกล่อง")
- **หัวหน้า:** ← · ชื่องาน + รหัส · เมนู ⋯ (เปลี่ยนสถานะ · จัดหน้านี้ · ใบนำเสนอ A4 · เปิดแบบจอคอม · คัดลอกลิงก์) — ปุ่ม 📄 / หน้าเต็ม ย้ายเข้าเมนู · การ์ดชื่องานซ้ำเอาออก
- **แถบแท็บติดใต้หัวทุกจอ** = ของกลาง `ScrollTabs`
- **แท็บภาพรวม = กล่องที่จัดเองได้** (ของกลาง `components/block-layout` · docs/block-layout.md · pageKey `design_sheet_mobile`):
  รูปงาน · สถานะ+กำหนดส่ง · รออะไรอยู่ · ต้นทุน/ใบ · เสนอราคา · โน้ต · รายละเอียดงาน · SKU · วันที่สั่ง/นัดลูกค้า · Parent SKU+ไฟล์ Drive
  - ต้นทุน / เสนอราคา / SKU / วันที่ = ครึ่งจอได้ (ค่าเริ่ม ครึ่ง → วางคู่) · SKU กางดู = เต็มแถวชั่วคราว
  - ใบที่ไม่มีข้อมูลกล่องนั้น (ไม่มีสิทธิ์ต้นทุน / ไม่มีรายละเอียด / ไม่มี Parent+Drive) = ไม่วาด · หน้าจัดบอก "ใบนี้ไม่มีข้อมูลส่วนนี้"
  - แท็บเล็ต: รูปงานอยู่คอลัมน์ซ้าย (ปิดกล่องรูป = เต็มจอคอลัมน์เดียว)
  - ทางเข้า: เมนู ⋯ → จัดหน้านี้ หรือปุ่มเส้นประท้ายภาพรวม · แอดมินสลับ "ทั้งทีม" ได้
- **ยังไม่กำหนดส่ง** = ป้ายสีเตือน + "ตั้งวัน" (แตะเปิดปฏิทิน) — ข้อมูลจริงส่วนใหญ่ยังไม่มีวันส่ง
- **แถบล่าง:** คุยลูกค้า (ตัวเลข) · ไฟล์ · ปุ่มหลัก **"ส่งต่อไป <ขั้นถัดไป>"** (กฎกลาง `nextOpenStatus` ใน lib/design-sheets-meta · เทสต์ `design-sheet-next-status.test.ts`)
  - ขั้นถัดไป = สถานะถัดไปตามลำดับ workflow ที่ยังเปิด (แบรนด์เราข้ามสถานะเฉพาะงานลูกค้า) · **ไม่แนะนำสถานะปิดงาน** (ตั้ง SKU แล้ว / ยกเลิก / ทำตัวอย่างใบเดียว) → ไม่มีขั้นถัดไป = ปุ่ม "เปลี่ยนสถานะ"
  - กดแล้วมีแถบ "ย้อนกลับ" 10 วิ (กดพลาดแก้ได้) · ย้อนไม่สำเร็จ = โหลดใบใหม่
  - เดิมปุ่มเปลี่ยนสถานะใช้สีของสถานะปัจจุบัน (ออกแบบ = เทา ดูเหมือนกดไม่ได้) → ตอนนี้สีหลักของระบบ

## แท็บตีราคา (แก้บนมือถือได้) — `cost-tab.tsx`

- การ์ดสรุป = `CostSummaryCard` ตัวเดียวกับหน้าคอม (ต้นทุน/ใบ · แถบสัดส่วน · ถ้าสั่ง N ใบ · เตือนบรรทัดที่ยังไม่มียอด)
- วัสดุจัดกลุ่มตามชนิด (สีตรงกับแถบสัดส่วน) → แตะบรรทัด = แผ่นแก้จากล่าง (`BottomSheet`):
  กว้าง / ยาว / จำนวนชิ้น / เผื่อเสีย / หน้ากว้างผ้า / ปริมาณ (แบบใส่เอง) / ราคาต่อหน่วย / หมายเหตุ · เปลี่ยนวัสดุ · ลบ · บรรทัดถัดไป
  - ช่องที่โชว์ขึ้นกับ "คิดแบบ" ของวัสดุ (ชิ้นสำเร็จ · พื้นที่ · ความยาว · นับชิ้น · ใส่เอง) — กติกาเดียวกับตารางหน้าคอม
  - เปลี่ยนวัสดุแล้ว จำของเดิมไว้ (รับทราบ / กลับของเดิม) เหมือนหน้าคอม
  - ชิ้นที่วาดรูปทรงไว้ = ขนาดคิดจากรูปทรง (แก้รูปทรงที่หน้าคอม)
- ＋ เพิ่มวัสดุ = ค้นจากวัสดุตีราคาชุดเดียวกับหน้าคอม (`/api/design-sheets/price-items`) · กรองตามชนิด · ใช้บ่อยขึ้นก่อน
- ค่าแรง / โสหุ้ย / อื่น ๆ: แก้ชื่อ + ยอดต่อใบ · แบบ "หารจำนวนสั่ง" แก้ยอดจ่ายครั้งเดียว · **ค่าตัดตามจำนวนชิ้น** คิดให้เองเมื่อแก้บรรทัด (`cutLaborRows` + ราคากลาง) · โสหุ้ยแยกรายการ = ดูอย่างเดียว
- **บันทึก** = ชุดเดียวกับหน้าคอม: `PUT /api/design-sheets/[id]/cost-lines` (ทั้งชุด · API เก็บเวอร์ชัน + ประวัติ) + `PATCH /api/design-sheets/[id]` `{ cost_extra }`
  - **กันทับ:** ก่อนบันทึกดึงบรรทัดล่าสุดมาเทียบกับตอนเปิด — มีคนบันทึกระหว่างนั้น = ถาม "บันทึกทับ" หรือ "โหลดของล่าสุด"
  - มีแก้ค้าง: แท็บขึ้นจุด • · ปุ่ม "ทิ้ง" · ย้อนกลับ / เปิดหน้าเต็ม / ปิดแท็บเบราว์เซอร์ = ถามก่อน · สลับแท็บในหน้าไม่หาย (แท็บตีราคาคงไว้หลังเปิดครั้งแรก)
- ยังทำที่หน้าคอม: วาดรูปทรงชิ้น · ตั้งค่าโสหุ้ยแยกรายการ / ค่าตัดรายวัสดุ · เพิ่มแท็บไซส์ใหม่ (แท็บที่มีอยู่ + Parent จริง/ร่าง ใช้ได้) · ดึงจาก BOM · ชุดราคาตั้งต้น · บันทึกจำนวนสั่ง · ตีราคาสั่งจากร้าน

## Design Dashboard บนมือถือ (2026-11-10 รอบ 2 · จอ 1 ใน widget)

- **ตัวเลขสรุป 3 ช่อง** แทนแถวชิปตัวกรอง: เกินกำหนด · ส่งใน 2 วัน · รอลูกค้าตอบราคา — แตะ = กรอง · แตะซ้ำ = เลิก · นับตามแบรนด์ที่เลือก
  - ใต้ตัวเลข: "ยังไม่ตั้งวันส่ง N ใบ" (แตะ = ดูรายการ) — งานไม่มี Deadline นับในช่องเกินกำหนด/ใกล้ส่งไม่ได้
  - กฎ = `passPhoneFilter` (`components/design-dashboard/dashboard-helpers.tsx` · เทสต์ `lib/__tests__/design-dashboard-phone-filter.test.ts`) — งานปิดแล้ว (สถานะ is_terminal เช่น ตั้ง SKU แล้ว / ยกเลิก) ไม่นับ · รอลูกค้าตอบ = เสนอราคาครั้งล่าสุดยัง `pending`
- **การ์ดแถวย่อ** (มือถือ/แท็บเล็ต) มีป้าย ตีราคา / มีราคา / มี SKU เหมือนการ์ดรูปใหญ่
- **กดค้างที่การ์ด = เปลี่ยนสถานะเร็ว** → `DesignStatusSheet` (`components/design-sheet-mobile/status-sheet.tsx` · ตัวเดียวกับหน้าใบงาน) → บันทึกผ่าน `moveSheetToStatus` เดิม (ตัวเดียวกับลากการ์ดบนจอคอม) · เฉพาะคนมีสิทธิ์แก้ · ขยับนิ้ว >10px = ยกเลิก (กำลังเลื่อนจอ) · ของกลาง `lib/use-long-press.ts`
- **แถบล่าง:** บอร์ด · วันนี้ (ป้ายแดง = เกินกำหนด + ส่งใน 2 วัน) · ไลน์ (กล่องงานจากไลน์ + จำนวนรอ) · เมนู (เมนูเดิมจากปุ่ม ⋯ เป็น `BottomSheet`) · ปุ่ม ＋ ยกขึ้นเหนือแถบ · โหมดเลือกใบงาน = ซ่อนแถบ
- **หน้า "วันนี้"** (`components/design-dashboard/phone-today.tsx`): เกินกำหนด · ส่งวันนี้–อีก 2 วัน · เสนอราคาแล้วรอลูกค้าตอบ · ส่งใน 3–7 วัน · ยังไม่ตั้งวันส่ง (พับไว้) — การ์ดแถวย่อตัวเดียวกับบอร์ด

## ข้อจำกัดที่รู้

- บันทึกตีราคาเป็น "ทั้งชุด" (เหมือนหน้าคอม) — ตัวกันทับเทียบเฉพาะบรรทัดวัสดุ ไม่เทียบค่าใช้จ่ายเพิ่ม
- ค่าตัดตามจำนวนชิ้นจะคิดใหม่ตอนแก้บรรทัดเท่านั้น (เปิดดูเฉย ๆ ไม่แตะ — ไม่ขึ้น "แก้ค้าง" เอง)
- ใบงานส่วนใหญ่ยังไม่ตั้ง Deadline (ณ 2026-11-10: 55 จาก 57 ใบที่ยังไม่ปิด · เกินกำหนด 2 · รอลูกค้าตอบราคา 6) → ตัวเลขเกินกำหนด/ใกล้ส่งจะน้อยจนกว่าทีมจะใส่วันส่ง
- กดค้างใช้ได้บนจอสัมผัส/เมาส์ในโหมดมือถือ · จอคอมเปลี่ยนสถานะด้วยการลากการ์ดเหมือนเดิม
