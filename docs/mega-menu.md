# แผงเมนูใหญ่ (Mega menu) — เว็บร้าน

ที่ตั้ง: ERP → เว็บไซต์ → ดีไซน์ → แท็บ **เมนู** → กด ✎ ที่เมนูบนสุด → **หน้าตาเมนูย่อย**

## ใช้ทำอะไร

ให้เมนูบนสุดแต่ละอัน (เช่น "กระเป๋า") เปิดเป็นแผงกว้างใต้หัวเว็บ หน้าตาแบบเว็บแบรนด์ใหญ่ เลือกได้ 3 แบบ แล้วแก้ต่อได้ทุกอย่าง

| แบบ | หน้าตา | ตัวอย่างแนว |
|---|---|---|
| A | รายการลิงก์ + การ์ดสินค้า + รูปเด่น | Jacquemus |
| B | คอลัมน์หัวข้อ + ไอคอน/จุดสี + คำอธิบาย | Samsonite |
| C | แท็บด้านบน + การ์ดคอลเลกชัน | TUMI |

แบบคอลัมน์ (A/B) ประกอบจาก "กล่อง" 5 ชนิด เรียงซ้าย→ขวา ลากสลับได้ ตั้งความกว้างได้ (1-3 ส่วน · หมุนลูกกลิ้งได้):

- **รายการลิงก์** — ข้อความ / ไอคอน + คำอธิบาย / จุดสี + คำอธิบาย / รูปเล็ก + คำอธิบาย · ปุ่ม "เติมจากหมวดของร้าน"
- **กลุ่มหัวข้อย่อย** — หัวข้อ แล้วมีลิงก์ย่อยใต้หัวข้อ (เส้นคั่นซ้าย)
- **การ์ดสินค้า** — อัตโนมัติจากหมวด (มาใหม่/ขายดี · 1-12 ชิ้น) หรือเลือกเอง (สูงสุด 24) · การ์ดต่อแถว · โชว์ราคาได้
- **รูปเด่น** — รูปใหญ่ + ข้อความบนรูป + ลิงก์ · เลือกสัดส่วนรูป
- **การ์ดรูป** — รูป + ชื่อ + คำอธิบาย + ลิงก์

แบบแท็บ (C): แท็บละชุดการ์ด · ชี้ที่แท็บ = สลับ · กดแท็บ = ไปลิงก์ของแท็บ · ปุ่ม "เติมแท็บจากหมวดของร้าน"

ไอคอน: ชุดเส้นในตัว 20 แบบ (กระเป๋าถือ เป้ เอกสาร เดินทาง สตางค์ เข็มขัด ฯลฯ — รูปทรงอ้างอิง Tabler Icons, MIT) หรืออัปโหลด PNG/SVG เอง

## มือถือ

ชั้นพับ-กาง: กดเมนู → (หัวคอลัมน์ → รายการ) · การ์ดสินค้า/การ์ดรูปเลื่อนแนวนอน · แบบแท็บ = ชิปเลื่อน + การ์ดเลื่อน

## แม่แบบที่บันทึก

- ปุ่ม **💾 บันทึกเป็นแม่แบบ** — เก็บแผงทั้งอัน (ตาราง `website_menu_templates`)
- ปุ่ม **📂 แม่แบบที่บันทึก…** — ใช้กับเมนูไหนก็ได้ ร้านไหนก็ได้ (แยก "ร้านนี้ / ร้านอื่น") · ใช้แล้วได้สำเนา
- สินค้าที่เลือกเองจากแม่แบบร้านอื่น ถ้าร้านนี้ไม่มีจะไม่โชว์เอง

## ไฟล์

| ส่วน | ไฟล์ |
|---|---|
| ข้อมูล/ตัวกรอง/แม่แบบตั้งต้น/คัดสินค้า (ฟังก์ชันล้วน) | `lib/website-mega-menu.ts` → มิเรอร์ storefront `src/lib/mega-menu.ts` (คัดลอกทั้งไฟล์) |
| ตัวจัดใน ERP | `components/website-mega-menu-editor.tsx` (ใช้ใน `website-theme-panel` MenuEditor) |
| แม่แบบ | `app/api/website/menu-templates/route.ts` + migration `202610200400_website_menu_templates.sql` |
| เว็บร้าน | `src/components/layout/MegaPanel.tsx` + `Navbar.tsx` + CSS `.mm-*` ใน `globals.css` |
| สินค้าในแผง | storefront `layout.tsx` คัดด้วย `pickMegaProducts` ฝั่งเซิร์ฟเวอร์ ส่งไปเฉพาะตัวที่ใช้ (พรีวิว ERP ส่งทั้งหมด) |

พรีวิว: ระหว่างแก้แผง ERP ส่ง `storefront-menu-pin` ให้เว็บร้านเปิดแผงของเมนูนั้นค้างไว้ (ดูที่จอคอม)

## สิทธิ์ / ประวัติ

- แก้เมนู = บันทึกผ่านธีม (ร่าง → เผยแพร่) ตามเดิม
- แม่แบบ: ดู = `products.view` · บันทึก/แก้ชื่อ/ลบ = `products.edit` · ทุกการกระทำลง audit log

## ข้อจำกัด

- กล่องสูงสุด 6 ต่อแผง · ลิงก์ 30 ต่อกล่อง · แท็บ 8 · การ์ด 12 ต่อชุด
- เมนูย่อยแบบเดิม (รายการเลื่อนลง / แผงรูปหมวด) ยังใช้ได้ — เลือก "เมนูย่อยธรรมดา"

## รอบ 2 (2026-10-16) — ตั้งค่าละเอียดขึ้น

**ลิงก์แต่ละอัน** (ปุ่ม ⋯ ท้ายลิงก์)
- 🖼 รูปตอนชี้ → กล่องรูปเด่นในแผงเปลี่ยนเป็นรูปนั้น + ข้อความบนรูป = ชื่อลิงก์ (ปิดได้ที่กล่องรูปเด่น "เปลี่ยนรูปตามลิงก์ที่ชี้")
- ตัวหนา · สีตัวอักษร (เช่น SALE สีแดง)
- ⏰ ตั้งเวลาแสดง (เวลาไทย) — ใช้ได้กับเมนูทุกชั้นด้วย (ช่อง "แสดงช่วง" ในเมนู)

**คอลัมน์**
- ลิงก์หัวคอลัมน์ + ข้อความ "ดูทั้งหมด →" ท้ายคอลัมน์
- รายการลิงก์: ⚡ อัตโนมัติ หมวดทั้งหมด / คอลเลกชันทั้งหมด / สีทั้งหมด (ต่อท้ายลิงก์ที่ใส่เอง · หมวด/คอลเลกชันที่มีรูป = รูปตอนชี้อัตโนมัติ) · แบ่ง 2–3 คอลัมน์ย่อย · โชว์จำนวนสินค้า
- การ์ดสินค้า: เรียง มาใหม่/ขายดี/ลดมากสุด/ราคาต่ำ-สูง/สูง-ต่ำ/สุ่ม (คงที่ทั้งวัน) · เฉพาะที่ลดราคา · ชี้แล้วสลับรูป · ป้าย · สัดส่วนรูป · พรีวิว "จะโชว์ N ชิ้น"
- ⧉ ทำซ้ำคอลัมน์ · 📋 คัดลอก → ไปวางเมนูอื่น/ร้านอื่น (ปุ่ม "วางคอลัมน์" — เก็บในเครื่องนี้)

**ทั้งแผง** (⚙️ หน้าตาแผง): เต็มจอ/กล่องลอยใต้เมนู · สีพื้น · เส้นคั่นคอลัมน์ · แถบข้อความโปรใต้แผง · 📱 ซ่อนการ์ด/รูปบนมือถือ

**พฤติกรรมเมนู** (ท้ายรายการเมนู · ใช้กับทุกเมนู — `theme.menu.behavior`): ชี้/กดเปิด · หน่วงก่อนเปิด · ฉากหลังมืด · มือถือ พับ-กาง/เลื่อนเข้าหน้าถัดไป · แถบรูปหมวดวงกลม (ต้องมีรูปหมวด)

**ตรวจลิงก์เสีย**: ป้าย ⚠️ ข้างลิงก์ที่ไปหมวด/หน้า/สินค้า/คอลเลกชันที่ไม่มีแล้ว + สรุปจำนวนบนหัวแผง (`megaLinkIssue`)

## ✨ เอฟเฟกต์ตอนชี้ลิงก์ (2026-10-16)

เมนู → หน้าตา + พฤติกรรมเมนู → `menu.behavior`

| ค่า | ตัวเลือก |
|---|---|
| `navHover` (เมนูด้านบน) | `fade` จางลง (เดิม) · `color` เปลี่ยนสี · `underline` เส้นใต้วิ่ง + เปลี่ยนสี · `grow` ขยายนิดหน่อย |
| `subHover` (เมนูย่อย/แผง) | `color` (เดิม) · `underline` · `grow` · `none` |
| `hoverColor` | สีตอนชี้ ("" = สีลิงก์ของธีม) → CSS `--nav-hover` |

- เว็บร้าน: `<header>` ได้คลาส `nav-hv-* mm-hv-*` (drawer มือถือได้ `mm-hv-*`) · CSS ใน `globals.css` ส่วน "✨ เอฟเฟกต์ตอนชี้ลิงก์เมนู"
- ERP มีตัวอย่างสด (HoverDemo) ข้างตัวเลือก — ชี้เมาส์ดูได้

## ☑ เลือกหมวดของร้าน (ติ๊กได้หลายหมวด)
- ในกล่องรายการลิงก์ (ใส่เอง) ปุ่ม "☑ เลือกหมวดของร้าน" → แผงติ๊กแบบต้นไม้ (ของกลาง `components/category-check-list.tsx` CategoryCheckList): หมวดหลัก + หมวดย่อยเยื้อง · ปุ่ม "ทั้งกลุ่ม" · ทั้งหมด / เฉพาะหมวดหลัก / ล้าง
- ติ๊ก = มีลิงก์หมวดนั้น · เอาติ๊กออก = ลบลิงก์หมวดนั้น · ลิงก์ที่ใส่เอง (ไม่ใช่หมวด) ไม่แตะ
- หมวดที่เพิ่งติ๊กแทรกต่อจากหมวดก่อนหน้าในต้นไม้ (หมวดย่อยไปอยู่ใต้แม่) · เกินจำนวนลิงก์สูงสุด = ตัดส่วนเกิน (มีคำเตือน)
