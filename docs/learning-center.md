# 🎓 ศูนย์เรียนรู้ (/misc/learn)

> บทเรียนสอนพนักงานทีละขั้น — อ่าน ดูคลิป ติ๊กเช็กลิสต์ตอนทำงานจริง · แอป "งานอื่นๆ" · รอบ 1 (2026-11-27)
> เจ้าของเลือก: แบบ A (หมวด → บทเรียน → ขั้นตอน) + คลิปยาว Drive/คลิปสั้นในหน้า + เช็กลิสต์ + แปะลิงก์คลิป + ร่างรอตรวจ + ที่มา/นาทีในคลิป · วิธีสรุปลิงก์ = **ข (ส่งลิงก์ในแชตให้ Claude สรุป)**

## ใช้ทำอะไร

- รวบรวมความรู้ไว้สอนงาน เช่น ถ่ายวิดีโอสินค้า แพ็กของ ตอบแชตลูกค้า
- หมวด → บทเรียน → ขั้นตอน · แต่ละขั้นมี: ข้อความ · รูป · ลิงก์คลิป (YouTube/TikTok/Drive) + นาทีเริ่ม · คลิปสั้นอัปเอง · เช็กลิสต์ · ลิงก์
- คลิปหลักของบท = "ลิงก์ที่มา" เล่นบนสุด · ขั้นที่ใส่ "นาที" แต่ไม่มีคลิปของตัวเอง → ปุ่ม "ดูนาที 1:20" กระโดดไปตรงนั้นในคลิปหลัก
- เช็กลิสต์ติ๊กแล้วจำในเครื่องนั้นต่อบท (ไม่ส่งขึ้นระบบ — ยังไม่ใช่ระบบติดตามว่าใครเรียนจบ)

## ข้อมูลอยู่ไหน (ไม่มีตารางใหม่)

ต่อยอดตารางคู่มือวิธีใช้งานเดิม:
- `erp_help_guides` + `kind` (`help` = คู่มือวิธีใช้ระบบ /master/help-guides · `lesson` = บทเรียน) · `status` (`draft`/`published`) · `source_url` `source_title` `drive_folder_url` `deleted_at` `created_by` `updated_by`
- `erp_help_guide_steps` + `video_url` `video_start_sec` `video_r2_key` `checklist` (jsonb array)
- migration `202612280900_learning_center.sql` · `/api/help-guides` กรอง `kind = help` (บทเรียนไม่ปนในคู่มือระบบ) · ค้นหาทั้งระบบเห็นบทเรียนที่เผยแพร่ (ลิงก์ไป `/misc/learn?lesson=<id>`) ร่างไม่โผล่

## สิทธิ์

- `learn.view` อ่านบทที่เผยแพร่ — ให้ทุกตำแหน่ง (admin manager staff designer PR_manager)
- `learn.manage` สร้าง/แก้/เผยแพร่/ลบ + เห็นร่าง + ถังขยะ — admin เท่านั้น (เพิ่มให้ใครได้ที่หน้าสิทธิ์)
- กฎเมนู `lib/menu-permissions` → `/misc/learn` prefixes `learn.`

## แก้ไข · ย้อนกลับ · ลบ

- แก้ได้ทุกช่องที่กรอกตอนสร้าง (ป๊อปแก้ = ERPModal เตือนก่อนปิดถ้ายังไม่บันทึก)
- ย้อนกลับ: สร้าง → ย้ายเข้าถังขยะ · แก้/เผยแพร่ → คืนเวอร์ชันเดิมทั้งบท · ลบ → กู้คืน (ปุ่มในแจ้งผลมุมจอ)
- ลบ = ย้ายเข้าถังขยะก่อน · ลบถาวรเฉพาะในถังขยะ ต้องพิมพ์ชื่อบทยืนยัน (ไฟล์ใน Drive ไม่ถูกลบ)
- audit ทุกการเขียน `entityType = learn_lesson` (changes จาก → เป็น · ขั้นตอนเทียบแบบย่อ)

## ไฟล์/คลิป (กฎที่เก็บไฟล์ `learning_videos`)

- คลิปสั้น ≤200MB ในขั้นตอน → `MediaUploadField` (คลังกลาง R2) เล่นในหน้า
- คลิปยาว/ไฟล์ใหญ่ ≤5GB → `DriveUploadBox` ในป๊อปแก้ → โฟลเดอร์ `<งาน ERP>/ศูนย์เรียนรู้/<ชื่อบท>` (สร้างตอนอัปไฟล์แรก จำลิงก์ที่ `drive_folder_url`) · `/api/learn/[id]/drive`
- รายการไฟล์ Drive ในหน้าอ่านใช้ `DriveFolderFiles` (API นั้นเช็ก `products.view` — คนที่ไม่มีสิทธิ์นี้จะไม่เห็นรายการไฟล์)

## วิธี ข: ส่งลิงก์ในแชตให้ Claude สรุปเป็นบทเรียน

1. เจ้าของแปะลิงก์คลิปในแชต Claude Code + บอกหมวด
2. Claude อ่านคำพูดในคลิป (ซับ/คำบรรยาย/หน้าเว็บ) — **ไม่ได้ดูภาพ** คลิปไม่มีคนพูด/ดึงซับไม่ได้ ให้บอกเจ้าของตรง ๆ ห้ามเดาเนื้อหา
3. เขียนบทลงตาราง (`kind='lesson'`, `status='draft'`, `source_url`, `source_title` = เครดิต, ขั้นตอน + `video_start_sec` ตามนาทีที่พูดเรื่องนั้น + เช็กลิสต์) · `created_by = 'Claude'` · ลง audit `learn_lesson create`
4. เจ้าของเปิด `/misc/learn` แท็บ "ร่างรอตรวจ" → อ่าน แก้ แล้วกด "เผยแพร่"
