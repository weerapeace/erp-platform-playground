# 🎓 ศูนย์เรียนรู้ (/misc/learn)

> บทเรียนสอนพนักงานทีละขั้น — อ่าน ดูคลิป ติ๊กเช็กลิสต์ตอนทำงานจริง · แอป "งานอื่นๆ" · รอบ 1 (2026-11-27)
> เจ้าของเลือก: แบบ A (หมวด → บทเรียน → ขั้นตอน) + คลิปยาว Drive/คลิปสั้นในหน้า + เช็กลิสต์ + แปะลิงก์คลิป + ร่างรอตรวจ + ที่มา/นาทีในคลิป · วิธีสรุปลิงก์ = **ข (ส่งลิงก์ในแชตให้ Claude สรุป)**

## ใช้ทำอะไร

- รวบรวมความรู้ไว้สอนงาน เช่น ถ่ายวิดีโอสินค้า แพ็กของ ตอบแชตลูกค้า
- หมวด → บทเรียน → ขั้นตอน · แต่ละขั้นมี: ข้อความ · รูป · ลิงก์คลิป (YouTube/TikTok/Drive) + นาทีเริ่ม · คลิปสั้นอัปเอง · เช็กลิสต์ · ลิงก์
- คลิปหลักของบท = "ลิงก์ที่มา" เล่นบนสุด · ขั้นที่ใส่ "นาที" แต่ไม่มีคลิปของตัวเอง → ปุ่ม "ดูนาที 1:20" กระโดดไปตรงนั้นในคลิปหลัก
- เช็กลิสต์ติ๊กแล้วจำในเครื่องนั้นต่อบท (ไม่ส่งขึ้นระบบ — ยังไม่ใช่ระบบติดตามว่าใครเรียนจบ)

## 🎞️ ภาพเคลื่อนไหวสอน (รอบ 2 · 2026-11-27)

เจ้าของเลือก แบบ A (ภาพอยู่ในแต่ละขั้น) + คลังสำเร็จรูป + Claude เขียนภาพเฉพาะเรื่อง + **ทุกหัวข้อต้องมีภาพเคลื่อนไหว**

- เก็บที่ `erp_help_guide_steps.animation` (jsonb · migration `202612281000`): `null` · `{type:"preset",key}` · `{type:"custom",html,height}`
- **คลังสำเร็จรูป** = `components/lesson-anim/presets.tsx` + รายชื่อ `lib/lesson-anim.ts` (ANIM_PRESETS 12 ฉาก: light-mood · light-sources · light-falloff · color-temp · iso-noise · key-contrast · hard-soft · light-position · light-types · histogram · diffusion · flag) — เพิ่มฉาก: เพิ่มทั้ง 2 ไฟล์
- **สตูดิโอจำลอง (รอบ 3)** = `components/lesson-anim/studio.tsx` — ผังไฟมองจากด้านบน (ลากไฟได้ · ระยะเป็นเมตร) คู่จอกล้อง (ภาพที่ถ่ายได้: ด้านสว่าง เงา ฉากหลัง สีแสง) · ปุ่ม "ดูตัวอย่าง" เล่นให้ดู · คำอธิบายเปลี่ยนตามที่เล่น · ฉากเรื่องไฟ 9 ฉากใช้ตัวนี้ (ตาราง STUDIO ใน presets.tsx: focus + ค่าเริ่ม + ปุ่มลัด) · กล้องชดเชยแสงอัตโนมัติ ยกเว้น light-falloff (exposure fixed) · ฉาก light-sources / iso-noise / histogram ยังเป็นฉากเดี่ยว
- **สตูดิโอจำลองตัวเต็ม (Master Class · 2026-11-28)** = หน้า `/misc/learn/studio` (ปุ่ม "สตูดิโอจำลอง" หัวหน้าศูนย์เรียนรู้) + ภาพสอน preset `studio-lab` — ไฟหลายดวง ตัวปรับแสง ตัวคุมแสง วัตถุ (กระเป๋า/คน 3 ระยะ) สูตรไฟ 16 สูตร · รายละเอียด `docs/studio-sim.md`
- **เฉพาะเรื่อง (custom)** = HTML/SVG ที่ Claude เขียนตอนสรุปลิงก์ → `<iframe sandbox="allow-scripts">` (ไม่มี allow-same-origin = อ่านคุกกี้/เรียก API ระบบไม่ได้) · สูงสุด 60KB · สูง 120–900px
- หน้าแก้บท: ทุกขั้นมีช่อง "ภาพเคลื่อนไหวสอน" เลือกจากคลัง / ไม่มี / ภาพเฉพาะเรื่อง + ปุ่มดูตัวอย่าง · โค้ดภาพเฉพาะเรื่องแก้ได้ในส่วน "ขั้นสูง"
- ย้อนกลับ/audit ใช้ระบบเดิม (ภาพเคลื่อนไหวเป็นส่วนหนึ่งของขั้นตอน · stepsDigest แสดง [ภาพเคลื่อนไหว: ชื่อ])
- **วิธี ข ตอนนี้ต้องใส่ภาพเคลื่อนไหวทุกขั้น**: เรื่องที่ตรงกับคลัง → preset · ไม่มีในคลัง → เขียน custom (กดเล่น/ลากได้ · ข้อความภาษาไทย · ไม่โหลดอะไรจากข้างนอก) · เรื่องที่เจอบ่อยและใช้ซ้ำได้ → เพิ่มเป็น preset ในโค้ด

## ไฟล์/คลิป (กฎที่เก็บไฟล์ `learning_videos`)

- คลิปสั้น ≤200MB ในขั้นตอน → `MediaUploadField` (คลังกลาง R2) เล่นในหน้า
- คลิปยาว/ไฟล์ใหญ่ ≤5GB → `DriveUploadBox` ในป๊อปแก้ → โฟลเดอร์ `<งาน ERP>/ศูนย์เรียนรู้/<ชื่อบท>` (สร้างตอนอัปไฟล์แรก จำลิงก์ที่ `drive_folder_url`) · `/api/learn/[id]/drive`
- รายการไฟล์ Drive ในหน้าอ่านใช้ `DriveFolderFiles` (API นั้นเช็ก `products.view` — คนที่ไม่มีสิทธิ์นี้จะไม่เห็นรายการไฟล์)

## วิธี ข: ส่งลิงก์ในแชตให้ Claude สรุปเป็นบทเรียน

1. เจ้าของแปะลิงก์คลิปในแชต Claude Code + บอกหมวด
2. Claude อ่านคำพูดในคลิป (ซับ/คำบรรยาย/หน้าเว็บ) — **ไม่ได้ดูภาพ** คลิปไม่มีคนพูด/ดึงซับไม่ได้ ให้บอกเจ้าของตรง ๆ ห้ามเดาเนื้อหา
3. เขียนบทลงตาราง (ทุกขั้นต้องมี `animation` — ดูหัวข้อภาพเคลื่อนไหว) (`kind='lesson'`, `status='draft'`, `source_url`, `source_title` = เครดิต, ขั้นตอน + `video_start_sec` ตามนาทีที่พูดเรื่องนั้น + เช็กลิสต์) · `created_by = 'Claude'` · ลง audit `learn_lesson create`
4. เจ้าของเปิด `/misc/learn` แท็บ "ร่างรอตรวจ" → อ่าน แก้ แล้วกด "เผยแพร่"
