# หน้า Partners + หน้าจัดการเครดิตเทอม (2026-11-22)

เจ้าของเลือกจาก widget: Partners แบบ A (ตารางแน่น คอลัมน์ครบ) + ข้อเสนอ 1-10 · เครดิตเทอมแบบ X (ตารางแก้ในช่อง + แถบเทมเพลต) + ข้อเสนอ 1-9

## หน้า Partners — `/master/partners` (components/partner-manager)

- ตารางกลาง `DataTable` (tableId `master-partners`): ค้น · กรอง · มุมมองที่บันทึกเอง · จัดคอลัมน์ · ส่งออก · มือถือเป็นการ์ด
- คอลัมน์: Partner (โลโก้/ตัวย่อ) · ประเภท · ประเทศ · ติดต่อ (กดโทร / เปิด LINE / คัดลอก WeChat) · จังหวัด · สกุลเงิน · ซื้อขายล่าสุด · ยอดค้าง · ครบกำหนด · เครดิต/วงเงิน · ข้อมูลขาด
- แท็บ: ทั้งหมด / ลูกค้า / ผู้จำหน่าย / ร้านจีน / **ป้ายน่าสงสัย** / ข้อมูลไม่ครบ / **ถังขยะ**
- **ป้ายน่าสงสัย** = ติดป้ายลูกค้าอย่างเดียว แต่มีสินค้า (supplier_items) หรือใบสั่งซื้อผูกอยู่ → กด "เปลี่ยน" / "เป็นทั้งสอง" ทีละราย หรือติ๊กหลายราย · ระบบไม่แก้เอง
- แก้หลายราย (แถบล่าง BulkActionBar): เปลี่ยน/เพิ่มป้าย · ตั้งเครดิต → · ย้ายไปถังขยะ · กู้คืน — ผ่าน `POST /api/master-v2/partners/bulk-update` (โหมด edits · สิทธิ์ products.edit · ลงประวัติรายแถว) · แจ้งผลมุมจอมีปุ่ม "ย้อนกลับ" 10 วินาที
- ถังขยะ = `is_active=false` (ลบแบบเก็บไว้) · เอกสารเก่ายังอ้างถึงได้ · ไม่มีปุ่มลบถาวรในหน้านี้
- โลโก้ร้าน = `partners_v2.logo_url` (LogoPicker ในฟอร์มแก้ไข · โฟลเดอร์ `partner-logos`)
- สรุปต่อราย: `GET /api/partners/summary` (products.view) · ยอดค้าง/ครบกำหนด ตัดทิ้งที่ server ถ้าไม่มี `cashflow.view` · คอลัมน์ยอดค้าง/ครบกำหนดใช้ `meta.permission: "cashflow.view"` · วงเงินในลิ้นชักก็ซ่อนตามสิทธิ์นี้
- แก้บั๊กเดิม: ลิ้นชักลูกค้าเคยโชว์ "เทอมชำระ" จากช่องเทอมของร้านค้า (purchase_credit_term) → ตอนนี้ลูกค้าอ่าน `salesCreditTermOf` และฟอร์มแก้ไขมีช่องเทอมแยกฝั่งลูกค้า/ร้าน

## หน้าจัดการเครดิตเทอม — `/cashflow/credit-terms`

- รวม 2 หน้าเดิม: หน้าตั้งเครดิตของกระแสเงินสด + `/purchasing/shop-terms` (ตอนนี้พามาแท็บร้านค้า `?side=supplier`) · ของกลาง `ShopTermsBoard` ยังอยู่แต่ไม่มีหน้าใช้ (ห้ามลบโดยไม่ถามเจ้าของ)
- ช่องที่เก็บ (เดิมทั้งหมด): ลูกค้า `sales_credit_term` (ค่าเก่า `payment_terms_days` อ่านสำรอง ไม่แตะ) · ร้าน `purchase_credit_term` + `purchase_lead_time` · วงเงิน `credit_limit`
- เรียงซื้อขายบ่อยสุดก่อน · มุมมอง: ยังไม่ตั้ง / ตั้งแล้ว / เกินวงเงิน / เลยกำหนด / มีเอกสาร / ร้านจีน
- เทมเพลต = `app_settings.credit_term_templates` ใช้ร่วมทั้งบริษัท · เพิ่ม/ลบ (ย้อนกลับได้) · แนะนำเทอมที่ใช้บ่อยในข้อมูลจริง
- ติ๊กหลายราย → กดเทมเพลต / ตั้งวงเงิน / ล้างเครดิต · ทุกอย่างใส่ลงช่องก่อน แล้วกด "บันทึกทั้งหมด" ครั้งเดียว → ปุ่ม "ย้อนกลับ" คืนค่าเดิมทุกราย
- "ซื้อวันนี้ ครบกำหนด" ทุกแถว · ครบกำหนดถัดไป · เลยกำหนด/เกินวงเงิน · ประวัติต่อราย (RecordHistoryDrawer)
- API `GET/PATCH/PUT /api/partners/credit-terms` — ดู: cashflow.view หรือ (ร้าน products.edit · ลูกค้า so.edit) · แก้: cashflow.manage หรือ (ร้าน products.edit · ลูกค้า so.edit) · PATCH ตรวจรูปแบบที่ server + ลง audit ทีละราย `changes: auditDiff`
- API เดิม `/api/cashflow/credit-terms` ยังอยู่ (แท็บต้องจ่าย/ต้องรับ ในหน้ากระแสเงินสดใช้ตั้งเครดิตรายเดียว)

## ตัวคำนวณกลาง

- `lib/partner-insights.ts` (pure · เทสต์ `lib/__tests__/partner-insights.test.ts`): วันครบกำหนดต่อใบ (วันในใบชนะ → ไม่มีคิดจากเครดิต) · รวมใบค้าง · ป้ายน่าสงสัย · เกินวงเงิน · เทมเพลต
- `lib/partner-insights-server.ts`: โหลดใบซื้อ/ใบขาย/สินค้าต่อคู่ค้า — ใช้ร่วมทั้งสองหน้า ตัวเลขตรงกัน
