# จัดการใบสั่งผลิตค้าง — `/master/mo-backlog`

หน้ารวมใบสั่งผลิต (MO) ที่ยังเปิดอยู่ทั้งหมด แบ่งเป็นแท็บตาม "สิ่งที่ต้องทำ" แล้วสั่งทีละหลายใบจากแถบด้านล่าง
ทางเข้า: ปุ่ม **🧹 จัดการใบค้าง** บนหัวบอร์ดจ่ายงาน

## กลุ่ม (ไม่ซ้อนกัน — 1 ใบอยู่กลุ่มเดียว) — `lib/mo-backlog.ts`
| กลุ่ม | ความหมาย | ควรทำ |
|---|---|---|
| A ส่งคืนครบ ยังไม่ปิด | ช่างส่งของคืนครบทุกชิ้นแล้ว | ✅ ปิดงาน |
| B อยู่กับช่าง | จ่ายครบแล้ว ยังรอช่างส่งคืน | (ขั้นถัดไป: รับคืนครบ + ปิด) |
| P จ่ายบางส่วน | ยังจ่ายไม่ครบจำนวน | ทำงานต่อตามปกติ |
| C ยังไม่จ่าย เกิน 90 วัน | เก่ามาก | 🚫 ยกเลิก หรือยืนยันว่ายังทำ |
| D / E | ยังไม่จ่าย 61–90 / 31–60 วัน | ทบทวน + 📅 ตั้งวันกำหนด |
| F | ใบใหม่ไม่ถึง 30 วัน | ปกติ |

อายุใบนับจาก `created_at` (เวลาไทย) — `order_date` กรอกไว้แค่บางใบ
แท็บเสริม: ไม่มีวันนัดส่ง · เลยวันนัดส่ง · ไม่มีสูตร

## คำสั่ง (ขั้นที่ 1)
| ปุ่ม | API | กฎ (`lib/mo-workflow.ts`) | สิทธิ์ |
|---|---|---|---|
| ✅ ปิดงาน | `POST /api/mo/bulk-status {action:"close"}` | ช่างส่งคืนครบ + ไม่มีใบจ่ายงานค้าง → `done` | `work_board.dispatch` |
| 🚫 ยกเลิกใบ | `POST /api/mo/bulk-status {action:"cancel", reason}` | ยังไม่จ่ายงานเลย + ต้องมีเหตุผล → `cancelled` | `work_board.dispatch` |
| 📅 ตั้งวันกำหนด | `PATCH /api/mo/bulk-due-date {only_empty}` | เติมเฉพาะใบที่ว่าง (ค่าเริ่ม) หรือทับทุกใบ | `products.edit` |

- หน้าจอเช็กกฎก่อนเพื่อบอก "ทำได้ X ใบ · ข้าม Y ใบ" — **server เช็กซ้ำเสมอ** จากข้อมูลใน DB (ไม่เชื่อหน้าจอ)
- ใบที่ไม่ผ่านกฎ = ข้าม ไม่ล้มทั้งชุด → รายงานผลบอกเหตุผลรายใบ
- กระทบเกิน 20 ใบ ต้องพิมพ์ `CONFIRM` (ConfirmDialog `requireTyped`)
- ปิด/ยกเลิก แก้แค่ `status` + `updated_at` — ไม่แตะใบจ่ายงาน ค่าแรง สต็อก
- ยกเลิก: ใบขอซื้อที่ยังผูกกับใบนั้น **ไม่ถูกยกเลิกตาม** — รายงานผลแจ้งรายชื่อให้ฝ่ายจัดซื้อตรวจ
- ใบที่ปิด/ยกเลิกแล้ว หายจากบอร์ด หน้าขอซื้อ/เตรียมวัตถุดิบ (ทุกหน้ากรอง `status not in (cancelled,done)`)

## Audit
ทุกคำสั่งเขียน `audit_logs` **รายใบ** (`entity_type = "mo"`, `entity_id = id ใบ`) metadata: `mo_no, field, old_value, new_value, reason, bulk, batch_count`
(bulk-due-date เดิมเขียนแถวเดียวโดยต่อ id กัน → ไม่ใช่ uuid ระบบเก็บเป็นค่าว่าง — แก้แล้ว)

## ของกลางที่ใช้
DataTable (`bulkBarPosition="bottom"` → BulkActionBar) · ConfirmDialog · ERPModal (รายงานผล) · MoStatusModal (กดแถว) · DateInput · fetchAllPages

## ยังไม่ทำ (ขั้นถัดไป)
- รับคืนครบ + ปิด (กลุ่ม B) — ต้องตัดสินเรื่องค่าแรงช่างก่อน (สร้าง/ไม่สร้างรายการส่งงาน)
- ติ๊กเตรียม/ตัดครบทั้งใบ
- เมนูซ้าย (`erp_menu_items`) ยังไม่ได้เพิ่ม — เข้าจากปุ่มบนบอร์ด
