# คำแปลภาษาอื่น + โหมดดูคู่กัน 2 ภาษา (ฟอร์มกลาง MasterCRUD)

เจ้าของขอ 2026-11-22: ดูไทย/อังกฤษคู่กัน 2 คอลัมน์ + เพิ่มภาษาญี่ปุ่น (เลือก "ช่องรวมภาษาอื่นช่องเดียว")

## โหมดภาษา (แถบเครื่องมือในลิ้นชัก)
- `ไทย` / `EN` / `日本語` = ภาษาเดียว (ช่องภาษานั้นมานั่งแทนช่องไทย) · สลับทีละช่องได้ที่ปุ่มข้างหัวข้อ
- `ไทย | EN` · `ไทย | 日本語` = **ดูคู่กัน** ไทยครึ่งซ้าย อีกภาษาครึ่งขวา (ui_style.gw = 6) · มือถือเรียงลงมาเอง · แก้ไขได้ทั้งคู่
- ช่องอีกภาษาที่ยังว่าง → ปุ่ม "แปลช่องนี้" · "แปลทั้งหมด" แปลไปภาษาที่เลือกอยู่ (→ 日本語)
- จำโหมดต่อคน (localStorage `mc.lang.<moduleKey>`)

## ที่เก็บ
- ไทย/อังกฤษ = คอลัมน์เดิม (`ui_style.lang_en` บนช่องไทย)
- ภาษาอื่น = คอลัมน์ `translations` jsonb ช่องเดียว `{ ja: { name_th, introduction, description } }` (ตอนนี้มีที่ `parent_skus_v2`)
- ฟอร์มเห็นเป็นช่องเสมือน `i18n_<ภาษา>_<ช่องไทย>` — API master-v2 แตก (GET) / รวมกลับ (POST/PATCH) ให้ (`lib/record-translations`)
- ทะเบียนฟิลด์: ช่องไทยตั้ง `ui_style.lang_ja = "i18n_ja_<ช่อง>"` · ช่องเสมือน column_name = null
- ช่องคำนวณญี่ปุ่น: `name_platform_code_ja` · `platform_description_ja` (lib/computed-text) — ยังไม่มีคำแปล = ว่าง

## เพิ่มภาษาใหม่
1. เพิ่มใน `EXTRA_LANGS` (lib/record-translations) — ปุ่ม/ตัวแปล AI ใช้ทันที
2. เพิ่มแถวทะเบียนช่องเสมือน + `ui_style.lang_<code>` บนช่องไทย (ไม่ต้องแก้ฐานข้อมูล)
3. ตารางอื่นที่จะใช้ → เพิ่มคอลัมน์ `translations jsonb default '{}'` ครั้งเดียว

## ข้อจำกัด
- คำแปลภาษาอื่นยังไม่ส่งขึ้นร้าน/เว็บ (ยังไม่มีร้านญี่ปุ่น) · Platform Description ญี่ปุ่นยังไม่รองรับบล็อก ⚙
- ไม่ลงประวัติเวอร์ชัน (record-versions) — ประวัติการแก้ดูได้ที่ audit (`translations`)
