# หน้าขอซื้อ · รวมตามรุ่น (Parent SKU)

> เจ้าของสั่ง 2026-11-02: "ปุ่ม group เป็น Parent SKU กดเข้าไปรวมวัตถุดิบ ให้กด มีของแล้ว / นับทีเดียว / ขอซื้อทีเดียว"

## ใช้ทำอะไร

แท็บ "ใบสั่งผลิต" หน้าขอซื้อ มีปุ่มสลับมุมมอง **รายใบสั่งผลิต / รวมตามรุ่น** (จำค่าต่อคน)

- **รวมตามรุ่น** = การ์ดละ 1 รุ่น (Parent SKU) บอกจำนวนใบ สี/แบบ กำหนดส่งเร็วสุด แถบความคืบหน้า
- กดการ์ดรุ่น → วัตถุดิบของทุกใบรวมเป็นการ์ดเดียวต่อวัตถุดิบ แบ่งเป็น ใช้ร่วมหลายสี / เฉพาะสี / ขอ-สั่งแล้ว / ครบแล้ว
- ปุ่มต่อวัตถุดิบ:
  - **✓ มีของแล้ว N ใบ** — ทุกใบที่ยังต้องซื้อ: มีอยู่ = ที่ต้องใช้ (ยกเลิกคืนค่าเดิมได้ในรอบนั้น)
  - **🔢 นับ** — ตั้งยอด WH-RAW ครั้งเดียว แล้วแบ่งของให้ใบที่ใกล้กำหนดส่งก่อน
  - **🛒 ขอซื้อรวม** — ตะกร้า 1 บรรทัด ยอดรวมทุกใบ ผูกเลขใบครบ (m2m `source_mo_nos`)
- ติ๊กหลายวัตถุดิบ → มีของแล้วทั้งหมด / ใส่ตะกร้าทั้งหมด
- ชิปสี: ปิดสีที่ยังไม่ทำ ยอดคิดใหม่ทันที · "ใบในรุ่นนี้" กดเปิดทีละใบได้ (ย้อนกลับ = กลับหน้ารวมรุ่น)

## ไฟล์

| ชิ้น | ไฟล์ |
|---|---|
| หน้าจอรวมรุ่น + ป๊อปนับ | `app/purchasing/mo-parent-group.tsx` |
| รวมยอด / แบ่งสต๊อก / มีของแล้วหลายใบ (pure + เทสต์) | `lib/mo-group-materials.ts` · `lib/__tests__/mo-group-materials.test.ts` |
| สถานะวัตถุดิบหลายใบ | `GET /api/mo/material-status?mo_nos=A,B,C` |
| บันทึกหลายแถวคนละค่า (audit 1 รายการ) | `PATCH /api/mo/material { items, label }` |
| แบ่งของจากสต๊อก | `POST /api/mo/material-allocations` (เดิม) |

## กติกา

- ไม่คิดสถานะเอง: แต่ละบรรทัดมาจาก `lib/mo-material-status` แล้วรวมยอด · สถานะการ์ด = ใบที่แย่สุด
- ใบที่ใช้ต่อชิ้นผิดปกติ (`oddMos`) ไม่รวมในขอซื้อรวม — เหมือน "ซื้อรวมทั้งกลุ่ม"
- ใบที่จ่ายงานแล้วไม่อยู่ในรายการ (`lib/mo-dispatch`)
- นับ: ของที่ใช้ได้ = นับได้ − ที่แบ่งให้ใบอื่นไว้ − ที่แบ่งให้ใบในรุ่นนี้ไว้ (ยังไม่จ่ายงาน)
- สิทธิ์: มีของแล้ว = `products.edit` · นับ = `stock.adjust` · ดูประวัติสต๊อก = `stock.view`

## ข้อจำกัด

- ยกเลิก "มีของแล้ว" ทั้งรุ่นได้เฉพาะที่กดในรอบนั้น (ออกจากหน้าแล้ว ยกเลิกรายใบที่หน้าใบเดียว)
- รุ่นละไม่เกิน 40 ใบต่อการโหลด
