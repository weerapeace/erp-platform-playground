# ป้าย "ต้องแก้ N อย่าง" ของ Parent SKU

ท้ายแถบเครื่องมือของลิ้นชัก Parent SKU (ของเสริม `config.toolbarExtra` ของ MasterCRUD) · กดดูรายการ → กดแต่ละข้อพาไปแท็บนั้น (`gotoFormTab` — LayoutTabs ฟัง event `erp:goto-tab` · แท็บที่ผู้ใช้ซ่อนไว้จะเปิดกลับให้)

- หน้าจอ `components/parent-health-badge.tsx` · ข้อมูล `GET /api/parent-skus/[id]/health` (products.view · ไม่ส่งตัวเลขต้นทุน) · กฎ `lib/parent-health.ts` (+เทสต์)
- **แดง (จำเป็น):** ไม่มีรูปปก · ไม่เลือกหมวดหมู่ · ไม่มี SKU ลูก · SKU ที่เปิดขายแต่ไม่มีราคากลาง
- **เหลือง (ควรเติม):** ไม่มีรายละเอียด · ไม่มีน้ำหนัก · ไม่เลือกหมวดกลางสำหรับลงขาย · ไม่มีต้นทุน (ไม่มีสูตรและราคาซื้อ) · ร้านขายที่แบรนด์เชื่อมแล้วแต่ยังไม่ลง
- ไม่เช็ก `name_platform` (ข้อมูลจริงว่าง 1,478/1,509 — หน้าจอใช้ชื่อสินค้าแทน)
- ครบหมด = ป้ายเขียว "✓ ข้อมูลครบ" · โหลดใหม่เมื่อบันทึกสินค้า (updated_at เปลี่ยน)
- ช่องที่อยู่หลายแท็บ: หาแท็บจากกลุ่มของช่องใน layout (`goto({ field })`) · ช่องในคอลัมน์ซ้าย (รูปปก) ไม่มีปุ่มพาไป
