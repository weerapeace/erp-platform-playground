# ตัวตั้งค่าตัวอักษรกลาง (TextStyleControl)

> เจ้าของสั่ง 2026-11-23: "อยากให้ปรับได้แบบมาตรฐาน ทำเป็นของกลางเลยเวลาให้ตั้งค่าตัวอักษร" · เลือกแบบ A (แถบเดียวด้านบน) + "ไม่ให้รก รวมเป็นไอคอน กดแล้วมีให้เลือก"

## ใช้ทำอะไร
แถบไอคอนแถวเดียว กดไอคอนแล้วมีเมนูลอยให้เลือก:

| ไอคอน | เลือกอะไร |
|---|---|
| ฟอนต์ | รายการฟอนต์ที่ส่งเข้ามา (โชว์ตัวอย่างฟอนต์จริง) |
| ขนาด | 6-25 px (พิมพ์เลข · กด − + · เลื่อน · ปุ่มขนาดด่วน) |
| B | หนา · เอียง · ขีดเส้นใต้ · ขีดฆ่า |
| สีตัวอักษร | สีด่วน 10 สี + เลือกได้ทุกสี (ColorPicker กลาง: สีล่าสุด 8 สี + ดูดสีจากจอ) |
| ไฮไลต์ | ไม่มี / สีด่วน / ทุกสี |
| จัดตำแหน่ง | ซ้าย · กลาง · ขวา |
| นำหน้าบรรทัด | ไม่มี · bullets • · เลข 1. 2. 3. |
| ล้างรูปแบบ | กลับค่าเริ่มต้น (ส่ง `onReset`) |

ไฟล์: `components/text-style-control` (หน้าจอ) · `lib/text-style.ts` (กติกา pure + เทสต์ `lib/__tests__/text-style.test.ts`)

## ใช้เมื่อไหร่
ทุกที่ที่ให้ผู้ใช้ตั้งหน้าตาตัวอักษร — ห้ามทำ dropdown ฟอนต์/ขนาด/จุดสี เองในหน้า

## ห้ามใช้เมื่อไหร่
- ช่องพิมพ์เอกสารยาวที่มีหัวข้อ/รูป → ใช้ตัวแก้ข้อความแบบจัดรูปแบบ
- เลือกแค่สีอย่างเดียว → `ColorInput`

## ค่าที่เก็บ (`TextStyle`)
```ts
{ font?, size?, color?, bold?, italic?, underline?, strike?, align?, highlight?, list? }
```
ทุกช่อง optional — ไม่ตั้ง = ค่าเริ่มของที่ที่เอาไปใช้ · อ่านค่าจากที่เก็บผ่าน `cleanTextStyle()` เสมอ · แปลงเป็น CSS ด้วย `textStyleCss()` · bullets/เลขด้วย `applyListPrefix()`

## ตัวอย่าง
```tsx
<TextStyleControl value={style} onChange={setStyle}
  fonts={[{ value: "Sarabun", label: "Sarabun", css: "Sarabun" }]}
  hide={{ list: true }}                                   // ซ่อนส่วนที่ไม่ใช้
  notes={{ italic: "ที่นี่ทำตัวเอียงไม่ได้" }}               // ปุ่มจาง + เหตุผล
  defaults={{ size: 10 }}                                  // โชว์บนปุ่มเมื่อยังไม่ตั้ง
  onReset={() => setStyle({})}
  extra={<ปุ่มเพิ่มเอง />} />
```

## ที่ใช้อยู่
1. **ตั้งค่าการ์ดบนกระดาน** (`components/canvas-cards/card-style-modal.tsx`) — กดแถวบรรทัด → แต่งที่แถบด้านบน · แปรงก๊อปสไตล์ (ไอคอนแปรง) · ปุ่มล้างรูปแบบ = ค่าเริ่มของบรรทัดนั้น · ย้อนกลับทั้งชุดได้จากแจ้งเตือนหลังบันทึก
   - กระดานวาด (Excalidraw) ไม่มีน้ำหนัก/เอียงของฟอนต์: **หนา** = ซ้อนตัวอักษร · **ขีดเส้นใต้/ขีดฆ่า** = วาดเส้น · **ไฮไลต์** = เส้นหนาสีหลังตัวอักษร · **เอียง** = ทำไม่ได้ (เก็บค่าไว้ ปุ่มบอกเหตุผล) — ชิ้นตกแต่งมี `customData.deco` ลบ/วาดใหม่ทุกครั้งที่ตั้งค่า (`setCardTexts` ใน `components/canvas-sketch`)
   - ค่าเก่าแปลงอัตโนมัติ (`normalizeCardStyle`): S/M/L/XL → 12/14/18/22 px · จัดชิดทั้งการ์ด → ทุกบรรทัด · จุดนำหน้า → bullets (ยกเว้นบรรทัดแรก)
   - งานย่อยที่ติ๊กเสร็จ (☑) ขีดฆ่า + จางอัตโนมัติ (ติ๊กปิดได้ในการ์ดงาน)
2. **ป้ายประเภทงาน** (`app/tasks/settings/page.tsx` → `lib/task-type-label-style.ts`) — ไอคอน "ตัวอักษร" ในแถว → ขนาด px · หนา · เอียง · ขีดเส้น · สี · ไฮไลต์ (ซ่อนฟอนต์/จัดตำแหน่ง/bullets) · ค่าเดิม weight/size sm-md-lg ยังอ่านได้

## สิทธิ์ / audit
ตัวตั้งค่าเองไม่บันทึกอะไร — หน้าที่เอาไปใช้เป็นคนบันทึกและลงประวัติตามกติกาของหน้านั้น

## ข้อจำกัด
- รายการฟอนต์ต้องส่งเข้ามาเอง (แต่ละที่มีฟอนต์ไม่เหมือนกัน)
- ไฮไลต์/ขีดเส้นบนกระดานคิดความกว้างตามข้อความทั้งบรรทัด ไม่ตัดคำ
