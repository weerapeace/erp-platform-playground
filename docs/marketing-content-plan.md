# 🗓️ วางแผนคอนเทนต์ (`/marketing/content-plan`)

หน้าวางแผนในแอปการตลาด: **จะลงอะไร · ทำรูป/คลิปแนวไหน · ลงที่ไหน** — ใช้ **ข้อมูลชุดเดียวกับปฏิทินคอนเทนต์** (`erp_creative_content`) ของทีม Creative
วางแผนครั้งเดียว ไหลต่อจนโพสต์ ไม่กรอกซ้ำ (เจ้าของเลือก 2026-10-11: ใช้ชุดเดิม · ไม่มีขั้นอนุมัติ)

## ขั้น (ไม่มีสถานะใหม่ — คิดจากสถานะเดิม)
| ขั้น | มาจาก |
|---|---|
| 💡 ไอเดีย | `status = draft` และยังไม่ผูกงาน |
| 🎬 กำลังทำ | `status = draft` และผูกงานแล้ว (`task_id`) |
| ✅ พร้อมโพสต์ / 🗓️ ตั้งเวลาแล้ว / 📤 โพสต์แล้ว | `ready` / `scheduled` / `published` |
| (ไม่แสดง) | `cancelled` |

## หน้าจอ
- แท็บแบรนด์ (จำแท็บล่าสุด) · มุมมอง **สัปดาห์** (แถว = ช่องทาง, คอลัมน์ = วัน) / **เดือน** / **บอร์ดตามขั้น** (จำรายคน `useViewPref` key `content_plan_view`)
- ชิปแนวคอนเทนต์ = กรอง + **สรุปจำนวนแต่ละแนวในช่วงที่ดูอยู่** (ดูว่าแผนสมดุลไหม)
- กล่อง **💡 ไอเดียยังไม่ลงวัน** (ข้างปฏิทิน)
- **ลากวาง**: การ์ด → ช่องวัน = เปลี่ยนวัน (คงเวลาเดิม; ถ้ายังไม่มีช่องทางจะใส่ช่องทางของแถวที่วาง) · → กล่องไอเดีย = เอาวันออก · บอร์ด: → คอลัมน์ = เปลี่ยนสถานะ (ไป "กำลังทำ" ต้องกดส่งเป็นงาน · ไอเดียที่ผูกงานแล้วถอยกลับไอเดียไม่ได้)
- กด **＋** ในช่อง = ไอเดียใหม่ (เติมวัน + ช่องทาง + แบรนด์ตามแท็บ)

## การ์ดไอเดีย (`plan-modal.tsx`)
หัวข้อ · แบรนด์ · วัน/เวลา (`ERPDateTime24`, ปุ่ม "ไม่ลงวัน") · **แนวคอนเทนต์** · **เป้าหมาย** (ให้รู้จัก/ขายของ/ให้ความรู้/ชวนคุย) · รูปแบบ (POST_TYPES เดิม เลือกหลายอย่าง) · ช่องทาง · สินค้า (ParentSkuPicker) · **บรีฟ** · **รูปอ้างอิง** (FileMultiInput ≤12)
- **🎬 ส่งเป็นงาน** (เฉพาะขั้นไอเดีย): สร้างงาน Creative (`createTask` — ชื่อ/แบรนด์/สินค้า/ช่องทาง, บรีฟ→description, รูปอ้างอิง→reference_images, วันลง→due_date) แล้วผูก `task_id` → ขั้นกำลังทำ
- **📝 รายละเอียด/แคปชั่น** = เปิด `ContentDrawer` เดิม (แคปชั่น/สื่อ/โพสต์)
- **🗑 ลบ** = soft delete (DELETE เดิม) + ConfirmDialog
- โพสต์แล้ว: แก้ได้แค่แนว/เป้าหมาย/บรีฟ/วัน (ระบบเดิมล็อกเนื้อหาหลัก)

## ข้อมูล
- `erp_creative_content` + `pillar_id` (→ `marketing_sku_labels`, kind `pillar`, ลบแนว → null) · `goal` (check 4 ค่า) · `brief` · `ref_image_keys text[]`
- แนวคอนเทนต์ = `marketing_sku_labels.kind = 'pillar'` (ตารางป้ายการตลาดเดียวกับป้ายหลัก/ป้ายเสริมของ SKU) · ตั้งค่าที่ "🧭 ตั้งค่าแนว" (`LabelManagerModal kinds={["pillar"]}`)
- ตั้งต้น 7 แนว: โชว์สินค้า · ไลฟ์สไตล์ · รีวิว/UGC · สอนใช้/ทริค · โปรโมชั่น · เบื้องหลัง · เทรนด์
- migration `202610111000_content_planning.sql` (+ เมนู sort 13 ในแอปการตลาด, permission_key `tasks.view`)
- API: ใช้ `/api/creative-content` เดิม (SELECT/EDITABLE/POST เพิ่ม 4 ช่อง + ตรวจ goal/brief/รูป) · แนว `/api/marketing/sku-labels?kind=pillar`
- ตัวช่วย pure `lib/marketing/content-plan.ts`: stageOf · วันที่ตามเวลาเครื่อง (ห้าม toISOString ตัดวัน) · toScheduledIso

## สิทธิ์
- ดู = `tasks.view` · เพิ่ม = `tasks.create` · แก้/ลาก/ลบ = `tasks.edit` (ชุดเดิมของโมดูลคอนเทนต์ — audit เดิมของ API คอนเทนต์)
- ตั้งค่าแนว = `marketing.label.manage`

## ยังไม่ทำ (ก้อนถัดไป)
- ก้อน 2: เป้ารายเดือนต่อแบรนด์/ช่องทาง + สล็อตประจำสัปดาห์ → สร้างแผนทั้งเดือน
- ก้อน 3: ไอเดียจาก SKU การตลาด (Hero ไม่มีคอนเทนต์ 30 วัน / ป้ายเสริม "ใหม่" / Clearance) + วันสำคัญบนปฏิทิน
- ContentDrawer เดิมยังไม่โชว์บรีฟ/รูปอ้างอิง (ทีม Creative เห็นผ่านงานที่ส่งไปแทน)
