## หน้าจอ
- แท็บแบรนด์ (จำแท็บล่าสุด) · มุมมอง **สัปดาห์** (แถว = ช่องทาง, คอลัมน์ = วัน) / **เดือน** / **บอร์ดตามขั้น** (จำรายคน `useViewPref` key `content_plan_view`)
- ชิปแนวคอนเทนต์ = กรอง + **สรุปจำนวนแต่ละแนวในช่วงที่ดูอยู่** (ดูว่าแผนสมดุลไหม)
- กล่อง **💡 ไอเดียยังไม่ลงวัน** (ข้างปฏิทิน)
- **ลากวาง**: การ์ด → ช่องวัน = เปลี่ยนวัน (คงเวลาเดิม; ถ้ายังไม่มีช่องทางจะใส่ช่องทางของแถวที่วาง) · → กล่องไอเดีย = เอาวันออก · บอร์ด: → คอลัมน์ = เปลี่ยนสถานะ (ไป "กำลังทำ" ต้องกดส่งเป็นงาน · ไอเดียที่ผูกงานแล้วถอยกลับไอเดียไม่ได้)
- กด **＋** ในช่อง = ไอเดียใหม่ (เติมวัน + ช่องทาง + แบรนด์ตามแท็บ)

## ก้อน 2 — เป้ารายเดือน + สล็อตประจำสัปดาห์ (2026-10-12)
- **🎯 เป้ารายเดือน** (`content_plan_targets`): ต่อแบรนด์ × ช่องทาง (× รูปแบบ ถ้าระบุ) = จำนวน/เดือน ใช้ซ้ำทุกเดือน · unique (แบรนด์, ช่องทาง, รูปแบบ)
  - หน้าแผนมีแผง **"🎯 เป้าเดือน…"** (พับได้): วางแผนแล้ว x/y · โพสต์แล้ว · ขาดอีก n / ครบแล้ว ✓ · เดือนของช่วงที่ดู (สัปดาห์ = เดือนของวันพฤหัส) · แท็บทุกแบรนด์ = เป้าทุกแบรนด์
  - นับ (`targetProgress`): แบรนด์ตรง + มีช่องทางนั้น + (รูปแบบตรงถ้าระบุ) + มีวันในเดือน (เวลาไทย) + ไม่ยกเลิก
- **🗓️ สล็อตประจำสัปดาห์** (`content_plan_slots`): ทุกวัน X เวลา HH:MM ช่องทาง รูปแบบ แนว หัวข้อ · เปิด/ปิดชั่วคราวได้
  - ปุ่ม **"⚡ สร้างแผนจากสล็อต"** (ต้องเลือกแท็บแบรนด์) → พรีวิว (จะสร้าง / ข้ามเพราะมีแล้ว / ข้ามเพราะผ่านวันแล้ว) → "ลงแผน N ชิ้น" = สร้างคอนเทนต์ draft (ขั้นไอเดีย) ตามวัน/เวลา
  - กันซ้ำด้วย `erp_creative_content.plan_slot_id` + วัน (เวลาไทย) → กดซ้ำได้ · ลบสล็อต = ไอเดียเดิมยังอยู่ (plan_slot_id → null)
- ตั้งค่าที่ ⚙️ ตั้งค่า → แท็บ 🎯 / 🗓️ (เลือกแบรนด์ในแท็บ · ช่องทาง = ที่ตั้งให้โชว์)
- API: `/api/marketing/content-plan/targets` · `/slots` (GET tasks.view · แก้ marketing.label.manage · audit) · `/generate` (POST tasks.create · dry_run · ≤200 ชิ้น/ครั้ง · เลข CN ต่อเนื่อง ชนแล้วขอใหม่ · audit `marketing.plan.generate`)
- เวลาไทยฝั่งเซิร์ฟเวอร์ (UTC): `bangkokIso` / `bangkokDateKey` (+07:00 ตรง ๆ) · เทสต์ `lib/__tests__/content-plan.test.ts`
- migration `202610121000_content_plan_targets_slots.sql`

## 🔔 รอบเปลี่ยน — "อะไรต้องเปลี่ยนทุกกี่วัน" (2026-10-13)
- กฎ (`content_refresh_rules`): แบรนด์ × ประเภทการลง (ว่าง = ทุกประเภท) × ช่องทาง · ทุก N วัน · เตือนก่อน N วัน · ชื่อเรียก · เปิด/ปิด · unique (แบรนด์, ประเภท, ช่องทาง)
- ตั้งค่า: ⚙️ ตั้งค่า → แท็บ 🔔 รอบเปลี่ยน (`RefreshRulesEditor` · แก้ = `marketing.label.manage` · audit `marketing.refresh_rule.*`)
- คิดสถานะ (pure, `refreshStatus` ใน `lib/marketing/content-plan.ts` · เทสต์ `lib/__tests__/content-refresh.test.ts`):
  - จับคู่คอนเทนต์ = แบรนด์ตรง + `placements` มี `ประเภท:ช่องทาง` (หรือ `platforms` มีช่องทาง ถ้ากฎไม่ระบุประเภท) + มีวัน + ไม่ยกเลิก
  - **ทำแล้ว** = วันถึงแล้ว (เวลาไทย) + สถานะ ready/scheduled/published (แต่งร้านมักลงเองหลังร้าน จึงนับ "พร้อมโพสต์" ด้วย) → ครบรอบถัดไป = ทำล่าสุด + N วัน
  - **เตรียมแล้ว** = มีของใหม่ลงวัน ≥ วันนี้ หลังรอบล่าสุด (ขั้นไหนก็ได้ — เจ้าของเลือก)
  - สถานะ: 🔴 เลยรอบ · ⚪ ยังไม่เคยทำ · ⚠️ ใกล้ถึงรอบ · 🟠 ลงไว้ช้ากว่ารอบ · ⏳ ยังไม่ถึงรอบ · ✅ เตรียมแล้ว
- หน้าแผน: กล่อง **🔔 ต้องเตรียม** (`RefreshPanel`) โชว์ที่ต้องลงมือ + ปุ่ม **＋ เตรียมเลย** = การ์ดไอเดียใหม่ เติมแบรนด์/ที่ลง/วันครบรอบ/ชื่อ · ที่เรียบร้อยพับไว้
- ปฏิทิน: แท็บ 🧭 วางแผน มีตัวเลข 🔔 = เลยรอบ + ยังไม่เคยทำ + ใกล้ถึงรอบ (กฎแคช `content-plan:refresh-rules`)
- เตือนเฉพาะในปฏิทิน (เจ้าของเลือก — ไม่เด้งกระดิ่ง/LINE) · API `/api/marketing/content-plan/refresh-rules` · migration `202610131000_content_refresh_rules.sql`

  - ระบบใส่ให้เอง: วันสำคัญ (วันเลขเบิ้ล · เงินเดือนออก 25 · Black Friday · วันหยุดวันที่ตายตัว — **วันตามจันทรคติ เช่น ลอยกระทง/ตรุษจีน ยังไม่คิดให้**) · เวลาโพสต์ประจำ (`creative_recommended_times`) · แนวทางเขียนของแบรนด์ (พรอมต์แคปชั่น `creative_caption_config`) · กติกาต่อแพลตฟอร์ม (`PLATFORM_WRITING_RULES` + โน้ตรูปจาก ⚙️ ตั้งค่าแพลตฟอร์ม · แพลตฟอร์มที่ "ไม่ใช้แคปชั่น" ขอแค่ไอเดียรูป)
- **ขั้น 2 ร่าง (2 ทาง):**
  - **ขอ prompt (ฟรี):** prompt รวมทุกแพลตฟอร์ม (แนะนำ — เรื่องตรงกันข้ามแพลตฟอร์ม) + แยกทีละแพลตฟอร์ม · ก๊อปไปถาม ChatGPT/Claude/Gemini → วางตารางคำตอบ (Markdown `|` / Tab / CSV) หรืออัปไฟล์ .xlsx/.csv
  - **ให้ AI ในระบบร่างเลย:** `POST /api/ai/mass-plan` (สิทธิ์ `tasks.create` + `ai.caption`) ยิง 2 จังหวะ — วางตาราง 1 ครั้ง (ไอเดียรูป/คลิปใช้ร่วมทุกแพลตฟอร์มของโพสต์) แล้วเขียนแคปชั่นทีละแพลตฟอร์มพร้อมกัน (ข้ามแพลตฟอร์มที่ไม่ใช้แคปชั่น) · ไม่ส่งรูป ≈ 1–3 บาท/ครั้งตามจำนวนโพสต์ · รุ่น = ที่ตั้งไว้ใน `ai_product_model` · คำสั่งถาวรเพิ่มได้ที่ทะเบียน prompt key `mass_plan` (/tasks/settings แท็บ Prompt แคปชั่น AI) · audit `ai_mass_plan` · ยังไม่บันทึกอะไร
- **ขั้น 3 ตรวจ (ใช้ร่วมกันทั้ง 2 ทาง):** `groupMassPlan` รวมแถวที่ "วัน + เวลา + หัวข้อ" ตรงกัน = 1 โพสต์หลายแพลตฟอร์ม (แคปชั่นแยกแถวต่อแพลตฟอร์มตามระบบเดิม) · เติมแฮชแท็กเริ่มต้นของแบรนด์/แพลตฟอร์ม
  - ตรวจ: วันอ่านไม่ออก (ข้ามแถว) · วันที่ผ่านแล้ว (ไม่ลง) · แพลตฟอร์มที่ระบบไม่มี (ตัดออก) · ซ้ำในชุด · ไม่มีแคปชั่น · ยาวเกินลิมิตแพลตฟอร์ม (`captionLimitCheck`) · **หัวข้อ+วันเดียวกับของเดิม = ไม่ติ๊กให้** (กันลงชุดเดิมซ้ำ) · แพลตฟอร์มชนวันกับของเดิม = เตือน "ลงเพิ่ม ไม่ทับ"
  - ตาราง = `MiniTable` กลาง (ค้นหา/เรียง/ติ๊ก) · แก้วัน/เวลา/หัวข้อ (ตรวจใหม่ทันที `checkPost`) · กาง "ดู/แก้แคปชั่น" ต่อแพลตฟอร์ม · ปฏิทินย่อ (จุดสี = ใหม่ · จุดเทา = ของเดิม · กรอบเหลือง = มีคำเตือน)
- **ขั้น 4 ลง:** `POST /api/marketing/content-plan/mass` (สิทธิ์ `tasks.create` · ≤ 200 โพสต์/ครั้ง) → คอนเทนต์สถานะ draft + `pillar_id` + `brief` (ไอเดียรูป/คลิป) + `platform_formats` ของแบรนด์ + แคปชั่น (`caption_type` = แม่แบบตั้งต้นของแพลตฟอร์ม) · เลข CN ต่อเนื่อง ชนแล้วขอใหม่ · ฝั่งเซิร์ฟเวอร์ตรวจซ้ำ (วันผ่าน/วันผิด/แพลตฟอร์มไม่มี/หัวข้อ+วันซ้ำของเดิม) · **ไม่แก้/ไม่ทับของเดิม** · audit `marketing.plan.mass_import` (เก็บ ids)
  - หลังลง: ปุ่ม "ยกเลิกทั้งชุดนี้" (สิทธิ์ `tasks.delete` → `/api/creative-content/bulk` ลบแบบ soft เฉพาะ ids ของชุดนี้) — ⚠️ ย้อนได้เฉพาะตอนป๊อปยังเปิดอยู่ ปิดแล้วต้องลบเองทีละใบ/ติ๊กหลายใบในหน้ารายการคอนเทนต์
- ตัวคิดกลาง: `lib/marketing/mass-plan.ts` (prompt · วันสำคัญ · อ่านตาราง · จับชื่อแพลตฟอร์ม/แนว · รวม/ตรวจ · ตรวจฝั่งเซิร์ฟเวอร์) · เทสต์ `lib/__tests__/mass-plan.test.ts` · อ่านตารางใช้ของกลาง `parseTableText` ([paste-table](paste-table.md))

## บรีฟในป๊อปโพสต์ — "รายการงานที่ต้องการ" (2026-11)
ป๊อปโพสต์ (ContentDrawer) จัดใหม่: **ซ้าย** = รายการงานที่ต้องการ (บรีฟคุยกับพนักงาน + Ref) + สินค้า · **ขวา** = ตั้งเวลาโพสต์ + งานจริงที่ใช้ลง (รูป/วิดีโอ) + แพลตฟอร์ม/แคปชั่น + ลิงก์สินค้า
- การ์ด `app/tasks/content/content-brief.tsx` (`ContentBriefCard`) — ช่องเดียวกับการ์ดไอเดียในหน้าวางแผน (แก้ที่ไหนก็เห็นทั้งสองที่)
- **บรีฟ = โน้ตจัดรูปแบบ** (`RichTextEditor toolbar="basic"`: หนา / เอียง / ธรรมดา / bullet / ลำดับเลข) เก็บ HTML ใน `brief` (จำกัด 20,000 ตัวอักษร) · บันทึกเองตอนคลิกออก/ปิดป๊อป
- ข้อความธรรมดาเดิม (เช่น บรีฟจากวางแผนหลายโพสต์ "เทรนด์: …\nTikTok: …") ยังใช้ได้ — ของกลาง `lib/rich-note.ts`: `noteToHtml` (บรรทัด → ย่อหน้า, "- " → bullet) · `noteToText` (ค้นหา / ส่งเป็นรายละเอียดงาน) · `isEmptyNote`
- **โหมดแปลฟรี:** ปุ่ม "แปลเป็น English" (ต้นฉบับไม่มีภาษาไทย = "แปลเป็นไทย") → `translateNoteHtml(html, to, { free: true })` ใน `lib/content-translate.ts` แปลทีละย่อหน้า/ข้อ (bullet อยู่ครบ · ตัวหนาเฉพาะบางคำจะหาย) · `/api/ai/translate` รับ `engine: "free"` = Google ฟรีอย่างเดียว ไม่เรียก GPT · ไม่บันทึกคำแปล
- **Ref ≤ 6 ช่อง (รูป + ลิงก์รวมกัน):** รูป → `ref_image_keys` (อัปผ่าน `uploadImagesWithDupCheck` ถามซ้ำก่อนอัป + ลากวางได้) · ลิงก์ → คอลัมน์ใหม่ `ref_links jsonb` `[{url,label?}]` (migration `202611011200_content_ref_links`, ทำความสะอาดด้วย `normalizeTaskLinks` เฉพาะ http/https) · ป้ายลิงก์ = หัวข้อจาก `/api/link-preview` · บันทึกทันทีที่เพิ่ม/ลบ
- 🎬 ส่งเป็นงาน: รายละเอียดงาน = `noteToText(บรีฟ)` + ต่อท้าย "Ref:" ลิงก์ทั้งหมด
