หน้าวางแผนในแอปการตลาด: **จะลงอะไร · ทำรูป/คลิปแนวไหน · ลงที่ไหน** — ใช้ **ข้อมูลชุดเดียวกับปฏิทินคอนเทนต์** (`erp_creative_content`) ของทีม Creative

## หน้าจอ
- แท็บแบรนด์ (จำแท็บล่าสุด) · มุมมอง **สัปดาห์** (แถว = ช่องทาง, คอลัมน์ = วัน) / **เดือน** / **บอร์ดตามขั้น** (จำรายคน `useViewPref` key `content_plan_view`)
- ชิปแนวคอนเทนต์ = กรอง + **สรุปจำนวนแต่ละแนวในช่วงที่ดูอยู่** (ดูว่าแผนสมดุลไหม)
- กล่อง **💡 ไอเดียยังไม่ลงวัน** (ข้างปฏิทิน)
- **ลากวาง**: การ์ด → ช่องวัน = เปลี่ยนวัน (คงเวลาเดิม; ถ้ายังไม่มีช่องทางจะใส่ช่องทางของแถวที่วาง) · → กล่องไอเดีย = เอาวันออก · บอร์ด: → คอลัมน์ = เปลี่ยนสถานะ (ไป "กำลังทำ" ต้องกดส่งเป็นงาน · ไอเดียที่ผูกงานแล้วถอยกลับไอเดียไม่ได้)
- กด **＋** ในช่อง = ไอเดียใหม่ (เติมวัน + ช่องทาง + แบรนด์ตามแท็บ)

## ลงที่ไหน แบบแบ่ง "ประเภทการลง" (2026-10-12)
- ประเภทการลง = ชื่อ + ไอคอน + ช่องทางของประเภทนั้น เช่น 🏪 แต่งร้าน → Shopee/Lazada/TikTok · 🛍️ ในสินค้า → Shopee/Lazada/TikTok · 📱 Story → Facebook/IG · 📰 โพสต์ฟีด → Facebook/IG/TikTok (ค่าเริ่มต้น `DEFAULT_PLACEMENTS` ในโค้ด จนกว่าจะบันทึก)
- ตั้งค่าที่ ⚙️ → ช่องทาง (ส่วน "ประเภทการลง": เพิ่ม/แก้ชื่อ-ไอคอน/ติ๊กช่องทาง/เลื่อนลำดับ/ลบ) · เก็บ `ui_config marketing_content_plan.placements` (บันทึกพร้อมช่องทาง)
- คอนเทนต์เก็บ `erp_creative_content.placements text[]` แบบ "ประเภท:ช่องทาง" เช่น `story:instagram` · **`platforms` ยังเก็บช่องทางรวม** (`platformsFromPlacements`) → ปฏิทิน/เป้า/แคปชั่น/โพสต์เดิมทำงานต่อ
- การ์ดไอเดีย: "ลงที่ไหน" = 1 บรรทัดต่อประเภท · **กดชื่อประเภท = เลือกทุกช่องทางของประเภทนั้น** (เลือกครบแล้วกดอีก = เอาออกทั้งหมด · ช่องสี่เหลี่ยมหน้าชื่อ: เต็ม/บางส่วน/ว่าง) · ข้อมูลเก่าที่มีช่องทางแต่ไม่มีประเภท โชว์บรรทัด "ไม่ระบุประเภท" (ไม่หาย)
- มุมมองสัปดาห์: การ์ดในแถวช่องทางโชว์ป้ายประเภท เช่น "🏪 แต่งร้าน · 🛍️ ในสินค้า" (`placementLabelsFor`)

## ก้อน 2 — เป้ารายเดือน + สล็อตประจำสัปดาห์ (2026-10-12)
- **🎯 เป้ารายเดือน** (`content_plan_targets`): ต่อแบรนด์ × ช่องทาง (× รูปแบบ ถ้าระบุ) = จำนวน/เดือน ใช้ซ้ำทุกเดือน · unique (แบรนด์, ช่องทาง, รูปแบบ)
  - หน้าแผนมีแผง **"🎯 เป้าเดือน…"** (พับได้): วางแผนแล้ว x/y · โพสต์แล้ว · ขาดอีก n / ครบแล้ว ✓ · เดือนของช่วงที่ดู (สัปดาห์ = เดือนของวันพฤหัส) · แท็บทุกแบรนด์ = เป้าทุกแบรนด์
  - นับ (`targetProgress`): แบรนด์ตรง + มีช่องทางนั้น + (รูปแบบตรงถ้าระบุ) + มีวันในเดือน (เวลาไทย) + ไม่ยกเลิก
- **🗓️ สล็อตประจำสัปดาห์** (`content_plan_slots`): ทุกวัน X เวลา HH:MM ช่องทาง รูปแบบ แนว หัวข้อ · เปิด/ปิดชั่วคราวได้
  - ปุ่ม **"⚡ สร้างแผนจากสล็อต"** (ต้องเลือกแท็บแบรนด์) → พรีวิว (จะสร้าง / ข้ามเพราะมีแล้ว / ข้ามเพราะผ่านวันแล้ว) → "ลงแผน N ชิ้น" = สร้างคอนเทนต์ draft (ขั้นไอเดีย) ตามวัน/เวลา
  - กันซ้ำด้วย `erp_creative_content.plan_slot_id` + วัน (เวลาไทย) → กดซ้ำได้ · ลบสล็อต = ไอเดียเดิมยังอยู่ (plan_slot_id → null)
- ตั้งค่าที่ ⚙️ ตั้งค่า → แท็บ 🎯 / 🗓️ (เลือกแบรนด์ในแท็บ · ช่องทาง = ที่ตั้งให้โชว์)
- API: `/api/marketing/content-plan/targets` · `/slots` (GET tasks.view · แก้ marketing.label.manage · audit) · `/generate` (POST tasks.create · dry_run · ≤200 ชิ้น/ครั้ง · เลข CN ต่อเนื่อง ชนแล้วขอใหม่ · audit `marketing.plan.generate`)
- เวลาไทยฝั่งเซิร์ฟเวอร์ (UTC): `bangkokIso` / `bangkokDateKey` (+07:00 ตรง ๆ) · เทสต์ `lib/__tests__/content-plan.test.ts`
- migration `202610121000_content_plan_targets_slots.sql`

## 🔔 รอบเปลี่ยน — "อะไรต้องเปลี่ยนทุกกี่วัน" (2026-10-13)
- กฎ (`content_refresh_rules`): แบรนด์ × ประเภทการลง (ว่าง = ทุกประเภท) × ช่องทาง · ทุก N วัน · เตือนก่อน N วัน · ชื่อเรียก · เปิด/ปิด · unique (แบรนด์, ประเภท, ช่องทาง)
- ตั้งค่า: ⚙️ ตั้งค่า → แท็บ 🔔 รอบเปลี่ยน (`RefreshRulesEditor` · แก้ = `marketing.label.manage` · audit `marketing.refresh_rule.*`)
- คิดสถานะ (pure, `refreshStatus` ใน `lib/marketing/content-plan.ts` · เทสต์ `lib/__tests__/content-refresh.test.ts`):
  - จับคู่คอนเทนต์ = แบรนด์ตรง + `placements` มี `ประเภท:ช่องทาง` (หรือ `platforms` มีช่องทาง ถ้ากฎไม่ระบุประเภท) + มีวัน + ไม่ยกเลิก
  - **ทำแล้ว** = วันถึงแล้ว (เวลาไทย) + สถานะ ready/scheduled/published (แต่งร้านมักลงเองหลังร้าน จึงนับ "พร้อมโพสต์" ด้วย) → ครบรอบถัดไป = ทำล่าสุด + N วัน
  - **เตรียมแล้ว** = มีของใหม่ลงวัน ≥ วันนี้ หลังรอบล่าสุด (ขั้นไหนก็ได้ — เจ้าของเลือก)
  - สถานะ: 🔴 เลยรอบ · ⚪ ยังไม่เคยทำ · ⚠️ ใกล้ถึงรอบ · 🟠 ลงไว้ช้ากว่ารอบ · ⏳ ยังไม่ถึงรอบ · ✅ เตรียมแล้ว
- หน้าแผน: กล่อง **🔔 ต้องเตรียม** (`RefreshPanel`) โชว์ที่ต้องลงมือ + ปุ่ม **＋ เตรียมเลย** = การ์ดไอเดียใหม่ เติมแบรนด์/ที่ลง/วันครบรอบ/ชื่อ · ที่เรียบร้อยพับไว้
- ปฏิทิน: แท็บ 🧭 วางแผน มีตัวเลข 🔔 = เลยรอบ + ยังไม่เคยทำ + ใกล้ถึงรอบ (กฎแคช `content-plan:refresh-rules`)
- เตือนเฉพาะในปฏิทิน (เจ้าของเลือก — ไม่เด้งกระดิ่ง/LINE) · API `/api/marketing/content-plan/refresh-rules` · migration `202610131000_content_refresh_rules.sql`
