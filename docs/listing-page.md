หน้าจอ ERP: `components/website-listing-panel.tsx` (+ `website-listing-layout.tsx` ส่วนบน) · เว็บร้าน: `ShopClient.tsx` · `ListingInsertTile.tsx` · `ListingPager.tsx`

| ส่วน | ค่า | หมายเหตุ |
|---|---|---|
| 🏷 หัวหน้า | `header.eyebrow/title/subtitle` ("" = ค่าเดิมของร้าน) · `showSearch` · `showCount` | หน้าหมวดใช้ชื่อ/คำอธิบายหมวด · มีคำค้นจากหัวเว็บ = ช่องค้นหาโชว์เสมอ |
| 📐 ต่อแถว | `columns` = `{desktop, desktopRail, tablet, mobile}` หรือ `null` | null = ใช้ "การ์ดสินค้า" ทั้งเว็บ (แถบซ้ายกาง = ลด 1 ช่อง) · desktopRail = ตอนแถบตัวกรองซ้ายกาง |
| 📄 แบ่งหน้า | `paging` all/more/infinite/pages · `pageSize` | เปลี่ยนตัวกรอง/การเรียง/คำค้น → กลับชุดแรก · กลับจากหน้าสินค้า = อยู่ที่เดิม (sessionStorage `sf-pg:<url>`) · รูปแทรกที่รอยต่อ → ต้นชุดถัดไป |
| ↕ การเรียง | `defaultSort` · `sorts` (ว่าง = ซ่อนช่องเรียง) | "ขายดี" โชว์เมื่อมีข้อมูลยอดขาย · รูปแทรกโชว์ตอนยังเรียงแบบเริ่มต้น + ไม่ค้นหา/กรอง |
| 🚫 สินค้าหมด | `soldOut` last (ค่าเริ่ม)/hide/normal | ตั้งต่อสินค้าที่ สินค้าบนเว็บ → สถานะสต๊อก = สินค้าหมด (`web_stock_status='out'`) · เว็บ: ป้าย + ปุ่มซื้อปิดทุกจุด (`canOrder`/`useProductPurchase.soldOut`) · ออเดอร์ถูกปฏิเสธที่ lib/website-orders |
| 📌 แถบติดจอ | `stickyBar` (ค่าเริ่ม ปิด) | แถบค้นหา/ตัวกรอง/เรียง ติดใต้หัวเว็บ · Navbar ตั้ง CSS `--hdr-cover` = ความสูงที่หัวเว็บบังอยู่ (หัวไม่ติดจอ/ซ่อนตอนเลื่อน = 0) |
| 🧭 ตัวกรอง · 🖼 รูปแทรก | `filters` · `inserts` ฯลฯ | ดูคอมเมนต์ใน lib |

- ของกลางที่แก้: `ProductGrid` รับ `columns` (ทับ คอม/แท็บเล็ต/มือถือ) · `ListingInsertTile` รับ `columns` (ช่องกว้างคิดจากคอลัมน์จริง)
- ค่าเริ่มต้นทั้งหมด = หน้าตาเดิม (all · แนะนำ · ค่าการ์ด · หัวหน้าเดิม)

## 🔔 แจ้งฉันเมื่อมีของ (สินค้าหมด)

- เว็บร้าน: ปุ่ม "🔔 สินค้าหมด — แจ้งฉันเมื่อมีของ" แทนปุ่มซื้อ (`RestockNotify` ของกลาง · หน้าสินค้าทุกแบบ) → ฝาก อีเมล / เบอร์โทร / LINE ID + สีที่อยากได้
- API สาธารณะ `POST /api/public/storefront/restock` (CORS · รับเฉพาะสินค้าที่เผยแพร่ + ตั้งสินค้าหมด · ฝากซ้ำไม่เพิ่มแถว · ช่องทางละ ≤30 รายการ/ร้าน)
- ตาราง `store_restock_requests` (migration 202610210100) · ตรวจค่า `lib/website-restock.ts` (มิเรอร์ → storefront `src/lib/restock.ts`)
- ERP: แท็บ 🏪 ข้อมูลร้าน → "🔔 ลูกค้ารอแจ้งของเข้า" (ทุกสินค้า) · drawer สินค้าบนเว็บ → ป้ายข้างช่องสถานะสต๊อก (`RestockBadge` · ของเข้าแล้ว = ป้ายเขียวกระพริบเตือนให้แจ้ง)
- ร้านติดต่อเอง (ไม่ส่งอัตโนมัติ — เจ้าของเลือก) → ✓ แจ้งแล้ว / ยกเลิก / ↺ กลับเป็นรอ / ลบ (ConfirmDialog) · audit ทุกรายการ

## 📌 รูปแทรกผูกกับสินค้า + 🎬 วิดีโอ (2026-10-28 · ERP 0510edac · storefront eeb202b)

- **ตำแหน่ง** (ตัวจัดรูปแทรกของกลาง `ListingInsertsEditor` — หน้ารายการ + ชุดมาใหม่):
  - ตามลำดับ (เดิม) = หลังสินค้าชิ้นที่ N — โชว์เฉพาะตอนเรียงแบบเริ่มต้น + ไม่กรอง/ค้นหา
  - **ผูกกับสินค้า** (`placeBy: "product"`) = วางก่อน/หลังการ์ดของสินค้าที่เลือก
    - ผูกกับ **Parent** (ทุกสีของรุ่น · `WebsiteProductPicker` เก็บ `"CODE"`) หรือ **SKU** (สีเดียว · `WebsiteSkuPicker` เก็บ `"CODE:sku-xxxxxxxx"`)
    - หลายตัว = การ์ดแรกที่เจอในหน้านั้น (รูปโผล่ครั้งเดียว)
    - หน้าการ์ดแบบรุ่น + ผูก SKU = ติดการ์ดรุ่นของสีนั้น · หน้าการ์ดแตกสี + ผูก Parent = ติดการ์ดสีแรกที่เจอ
    - ไม่เจอ = ไม่โชว์ (`anchorFallback: "hide"`) หรือใช้ตำแหน่งชิ้นที่ N (`"pos"` — เฉพาะมุมมองเริ่มต้น)
    - `anchorFollow` (ค่าเริ่ม เปิด) = ตามสินค้าไปด้วยตอนลูกค้าเรียง/กรอง · ค้นหาด้วยคำ = ไม่โชว์เสมอ
- ตัวคิดตำแหน่งกลาง: `resolveInsertAt` + `cardMatchesAnchor` ใน `lib/website-listing.ts` (มิเรอร์ `src/lib/listing.ts` ของเว็บร้าน — แก้ที่ ERP แล้วคัดลอกทั้งไฟล์) · ใช้ที่ `ShopClient` + `DropBlocks` · test `lib/__tests__/website-listing-inserts.test.ts`
- **🎬 วิดีโอ** `videoKey` / `mobileVideoKey` (`WebsiteVideoField`) — มี = เล่นแทนรูป เงียบ วนซ้ำ เล่นเฉพาะตอนเห็นบนจอ (`InsertVideo` ใน `ListingInsertTile`) · รูป = ภาพปก · ลูกค้าตั้งลดการเคลื่อนไหว = ภาพปก · รูปแทรกที่มีแต่วิดีโอก็โชว์ได้
