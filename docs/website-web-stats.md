# 📈 สถิติเว็บร้าน + 🧪 ทดสอบ A/B (เว็บร้าน · ชุด 8)

ERP › เว็บไซต์ › ร้าน › แท็บ **📈 สถิติ** — นับเองจากเว็บร้าน **ไม่ต้องตั้ง Google Analytics** และไม่ต้องรอลูกค้ากดยอมรับคุกกี้

## นับอะไร (ตัวเลขรวมรายวัน ไม่ระบุตัวคน)

| ตัวนับ | ความหมาย |
|---|---|
| รอบเข้าเว็บ | เข้าเว็บ 1 ครั้ง (เงียบเกิน 30 นาที = รอบใหม่) · แยกตาม **แหล่งที่มา** · อุปกรณ์ · หน้าแรกที่เข้า |
| เปิดหน้า | ทุกครั้งที่เปิด/เปลี่ยนหน้า |
| ขั้นการซื้อ | รอบที่ ดูสินค้า → ใส่ตะกร้า → เริ่มชำระเงิน (นับครั้งเดียวต่อรอบ) |
| สินค้าที่ถูกดู | ดู/ใส่ตะกร้า รายรุ่น → "% ใส่ตะกร้า" (ดูเยอะแต่ใส่น้อย = เช็กราคา/รูป/รายละเอียด) |
| ออเดอร์ / ยอดขาย | **ไม่นับจากเว็บ** — อ่านจากออเดอร์จริง (ไม่นับที่ยกเลิก) ออเดอร์แนบ "มาจากไหน" + กลุ่ม A/B มาด้วย |
| คำค้น | ตารางเดียวกับชุด 2 (สีแดง = ค้นแล้วไม่เจอ) |

**แหล่งที่มา** (ลำดับการตัดสิน): `?utm_source=` ในลิงก์ → รหัสคลิกโฆษณา (gclid=Google · fbclid=Facebook · ttclid=TikTok) → เว็บที่ส่งมา (Google/Facebook/Instagram/LINE/TikTok/YouTube/X/Pinterest/Shopee/Lazada/Bing หรือชื่อเว็บ) → เบราว์เซอร์ในแอป (Facebook/IG/LINE/TikTok) → "พิมพ์เข้าเอง"
→ แนะนำ: ลิงก์ที่แชร์/ยิงแอด ใส่ `?utm_source=ชื่อ` (เช่น `?utm_source=line_oa`) จะแยกได้ละเอียด

**ไม่นับ:** พรีวิวจาก ERP (และทั้งแท็บที่เปิดพรีวิว) · หน้าแก้ผืน · iframe · บอท/เครื่องมือทดสอบ (Lighthouse ฯลฯ)
**PDPA:** ไม่มีรหัสคน/คุกกี้/IP · ในเครื่องลูกค้าจำแค่แหล่งที่มา/ขั้นที่ผ่าน/กลุ่ม A/B ของรอบ (localStorage `sf_stat`) และเลขสุ่มประจำเครื่อง (`sf_ab_seed`)

## 🧪 ทดสอบ A/B

ตัวจัดหน้า (หน้าแรก/หน้าเว็บ) → เลือก Section → แท็บรูปลักษณ์ → **🧪 ทดสอบ A/B** → "สร้างแบบ B จาก Section นี้"
→ ได้สำเนาต่อท้าย (แบบ B) แก้ข้อความ/รูปได้เลย · ชื่อการทดสอบใช้อังกฤษ/ตัวเลข (เปลี่ยนชื่อที่อันไหนก็เปลี่ยนทั้งคู่)

- ลูกค้าครึ่งหนึ่งเห็นแบบ A อีกครึ่งเห็นแบบ B · คนเดิมเห็นแบบเดิมทุกครั้ง · หลายการทดสอบแบ่งกลุ่มแยกกัน
- เลือกกลุ่มก่อนหน้าแสดง (สคริปต์ inline + CSS) → ไม่กระพริบ · ซ่อนตามอุปกรณ์ของ Section ยังทำงาน
- พรีวิวใน ERP เห็นทั้ง 2 แบบ · ต้นไม้ซ้ายมีป้าย "🧪 ชื่อ แบบ A/B" · มีแบบเดียว = เตือนก่อนเผยแพร่
- ผล (แท็บสถิติ): เห็น · ใส่ตะกร้า · ออเดอร์ · อัตราซื้อ · ยอดขาย ต่อแบบ + คำตัดสิน
  - "⏳ คนยังน้อย" จนแต่ละแบบมีคนเห็น ≥ 100 · "🏆 แบบ X ขายดีกว่า" เมื่อต่างกันชัด (z-test มั่นใจ 95%) · ไม่งั้น "ยังไม่ต่างกันชัดเจน"
- จบการทดสอบ: ลบ Section แบบที่แพ้ → กด "เลิกทดสอบ Section นี้" ที่แบบที่ชนะ
