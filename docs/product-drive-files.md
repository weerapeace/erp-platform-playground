# ไฟล์แนบสินค้าใน Google Drive (ProductDriveFiles) + เลือกไฟล์จากโฟลเดอร์กลาง (DriveFilePicker)

เจ้าของขอ 2026-11-16: กล่อง "ไฟล์แนบ" ในป๊อป Parent SKU เดิมเก็บ Supabase จำกัด 50MB → ย้ายไป Google Drive (ใหญ่ถึง 5GB) และเลือกไฟล์จากโฟลเดอร์กลาง (โลโก้ .ai .psd .pdf) มาแนบได้ พร้อมภาพตัวอย่าง

## ใช้ทำอะไร
- **ProductDriveFiles** (`components/product-drive-files`) — กล่องไฟล์แนบของ Parent SKU / SKU ลูก ในลิ้นชัก MasterCRUD
  - อัปจากเครื่อง → โฟลเดอร์ของสินค้าใน Drive (DriveUploadBox → ส่งทีละชิ้น มีแถบ %)
  - "เลือกจากโฟลเดอร์กลาง" → DriveFilePicker → สร้าง **ทางลัด (shortcut)** ในโฟลเดอร์สินค้า — ไฟล์จริงมีที่เดียว แก้โลโก้ทีเดียวทุกสินค้าเห็นตัวใหม่
  - ป้ายที่มา: "ลิงก์จากโฟลเดอร์กลาง" / "อัปเอง" · ไฟล์เดิมใน Supabase โชว์ต่อด้านล่าง ("ไฟล์เดิม") เปิด/ลบได้ ไม่รับอัปเพิ่ม
  - เอาออก: ทางลัด = ลบแค่ทางลัด · ไฟล์ที่อัปเอง = ถังขยะ Drive (กู้ได้) · **ไม่แตะไฟล์กลาง**
  - ยังไม่ได้เชื่อม Drive (ไม่มี env) = กลับไปใช้ RecordFilesField ทั้งหมด
- **DriveFilePicker** (`components/drive-file-picker`) — หน้าต่างเดินดูโฟลเดอร์กลาง ใช้ซ้ำที่อื่นได้ (`onPick(files, brandId)`)

## โครงโฟลเดอร์ใน Drive
```
<โฟลเดอร์แบรนด์>/Parent SKU/<รหัส ชื่อ>     ← ไฟล์ของ Parent
<โฟลเดอร์แบรนด์>/SKU/<รหัส ชื่อ>            ← ไฟล์ของ SKU ลูก (แบรนด์ตาม Parent)
<โฟลเดอร์แบรนด์>/ไฟล์กลาง/...               ← โฟลเดอร์กลาง (สร้างให้เองตอนเปิดหน้าต่างครั้งแรก · ข้างในจัดโฟลเดอร์ย่อยได้อิสระ)
```
โฟลเดอร์แบรนด์ = `brandBaseFolder()` ตัวเดียวกับใบงานออกแบบ (ตั้งค่าแอปจัดการงาน → คลัง Artwork → "งาน ERP")

## API
| เส้นทาง | ทำอะไร | สิทธิ์ | ประวัติ |
|---|---|---|---|
| `GET /api/product-drive/[entity]/[id]` | ไฟล์ในโฟลเดอร์สินค้า (ไม่สร้างโฟลเดอร์) | products.view | — |
| `POST /api/product-drive/[entity]/[id]` | เปิด session อัป 1 ไฟล์ (สร้างโฟลเดอร์ถ้ายังไม่มี) | products.edit | `product.drive_upload` |
| `POST .../link` | สร้างทางลัดจากไฟล์ในโฟลเดอร์กลาง (ตรวจว่าอยู่ใต้ไฟล์กลางของแบรนด์จริง · ซ้ำ = ข้าม) | products.edit | `product.drive_link` |
| `DELETE .../files/[fileId]` | เอาออก (ตรวจว่าอยู่ในโฟลเดอร์สินค้าจริง) → ถังขยะ Drive | products.edit | `product.drive_remove` |
| `GET /api/drive/browse?brand&folder&q` | เดินดูโฟลเดอร์กลาง (กันเปิดโฟลเดอร์นอกไฟล์กลาง) | products.view | — |
| `GET /api/drive/thumb?id&t=1&w` | ภาพตัวอย่างที่ Drive ทำไว้ (ไม่โหลดไฟล์ทั้งก้อน) | ไม่ต้อง login (แบบเดิม) | — |

entity = `parent_skus_v2` | `skus_v2` · ไม่แก้ฐานข้อมูล (ไฟล์อยู่ในโฟลเดอร์ Drive เอง)

## ภาพตัวอย่าง (ตามจริง)
Drive ทำให้: รูปทุกชนิด · PDF · PSD (ปกติได้) · AI ที่เซฟแบบ "PDF Compatible" (ค่าเริ่มต้น Illustrator) · ไม่ได้ = EPS / ZIP / อื่น ๆ → ไอคอนชนิดไฟล์ (FileTypeIcon) · ไฟล์เพิ่งอัปอาจรอภาพสักครู่

## เปิดใช้กับโมดูล
MasterCRUD: `fileAttachments: { entityType: "parent_skus_v2", storage: "drive" }` (รองรับเฉพาะสินค้า) · ลิ้นชักสินค้าที่ไม่ส่ง config ได้ storage drive อัตโนมัติ

## ข้อจำกัด
- เปลี่ยนรหัส/ชื่อ/แบรนด์สินค้า → ระบบหาโฟลเดอร์จากชื่อ จะได้โฟลเดอร์ใหม่ (ไฟล์เก่ายังอยู่โฟลเดอร์เดิมใน Drive)
- ลบสินค้าถาวร ไม่ลบโฟลเดอร์ Drive (ตั้งใจ — ไฟล์งานกู้ได้)
- ค้นชื่อในหน้าต่างเลือก = ค้นเฉพาะโฟลเดอร์ที่เปิดอยู่
