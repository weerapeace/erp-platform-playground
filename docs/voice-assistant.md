# ผู้ช่วยเสียง (Voice Assistant)

ปุ่มไมค์สีน้ำเงินมุมขวาล่างของทุกหน้า: **กดค้างแล้วพูด** คำที่ฟังได้จะขึ้นในช่องข้อความให้แก้ก่อนส่ง จากนั้นผู้ช่วยจะทำงานและตอบกลับเป็นเสียง

รอบแรก (2026-11-27) ช่วยได้ 2 อย่าง · รอบ 2 (2026-11-28) เพิ่ม "ทำรายละเอียดสินค้า" + หน้าตั้งค่า:

| พูดว่า | ระบบทำอะไร |
|---|---|
| "เปิดหน้าใบสั่งซื้อ" / "ไปหน้า SKU" | เปิดหน้านั้นให้ (เลือกได้เฉพาะหน้าที่คนนั้นมีสิทธิ์เห็น) |
| "เพิ่ม SKU ใหม่ กระเป๋าผ้าสีดำ ราคาซื้อ 120" | ขึ้นการ์ดประเภทสินค้าให้เลือก (หรือพูดชื่อประเภท) → เปิดตัวเพิ่ม SKU ของเดิมพร้อมกรอกค่าที่พูดไว้ → **คนตรวจแล้วกดบันทึกเอง** · โหมด "บันทึกเองหลังกดยืนยัน" = การ์ดสรุป (รหัสที่ระบบเสนอ) ในแผงคุย → กด "บันทึกเลย" |
| "ทำรายละเอียดกระเป๋า Ma tote" | หาสินค้าแม่ (เจอหลายตัว = ให้เลือก) → เปิดหน้า Parent SKU + ป๊อป "＋ แทรก" ที่ขั้นจุดเด่น (✨ AI ดูรูป) · โหมด "AI ร่างให้เลย" = AI ร่างทันที ข้อแนะนำติ๊กไว้ → คนกด "แทรกและบันทึก" (ลิงก์ `/master/parent-skus?open=<id>&insert=ai[&insert_auto=1]`) |

## หน้าตั้งค่า — `/admin/voice-assistant` (สิทธิ์ admin.paid_services · ปุ่มเฟืองในแผงคุยสำหรับผู้ดูแล)

- แต่ละคำสั่ง: **เปิด/ปิด** · **ทำได้แค่ไหน** (เปิดฟอร์มให้คนกดบันทึก / บันทึกหลังกดยืนยัน) · **ตัวอย่างคำพูด** (เพิ่ม/แก้/ลบ — ส่งให้ AI เป็นตัวอย่าง)
- **ลองพูดทดสอบ**: พูด/พิมพ์ → ดู "ระบบจะ…" โดยไม่ทำจริง (POST command `dry: true` · ใช้ค่าที่บันทึกแล้ว · ประวัติติดป้าย "ทดสอบ")
- **ประวัติคำสั่ง**: 100 คำสั่งล่าสุดจาก audit `voice_command` (ใคร · พูดว่าอะไร · ระบบจะทำอะไร) · **ประวัติการตั้งค่า**: audit `voice_assistant_settings` (changes ต่อช่อง)
- บันทึกแล้วมีปุ่ม "ย้อนกลับ" (คืนค่าก่อนหน้า) · มีการแก้ค้าง = แถบเตือนล่างจอ + ถามก่อนปิดหน้า
- ที่เก็บ `ui_config` key `voice_assistant_settings` · กติกา `normalizeVoiceSettings` / `VOICE_COMMAND_INFO` ใน `lib/voice-assistant.ts` · API `/api/voice-assistant/settings`
- ยังไม่มีเมนูในแถบ — เข้าจากปุ่มเฟืองในแผงผู้ช่วยเสียง หรือพิมพ์ลิงก์ (เพิ่มเมนูได้ที่จัดการแอป)

## ตั้งค่า (ไม่ต้องแก้โค้ด) — `/admin/paid-services`

- **ai.voice_assistant**: ปิด = ปุ่มไมค์หายทั้งระบบ · เลือกรุ่น AI · ตั้งงบ/โควตาต่อคน · เลือกว่าใครใช้ได้
  - **ช่วงทดลอง ค่าเริ่ม = เฉพาะแอดมิน** (คนที่มีสิทธิ์ `admin.paid_services`) — เปิดให้คนอื่น: "ใครใช้ได้" → "เฉพาะที่เลือก" → เลือกบทบาท/คน (ด่าน `lib/voice-assistant-server.ts`)
- **ai.voice_listen**: เลือกรุ่นถอดเสียง (`gpt-4o-transcribe` ค่าเริ่ม · `gpt-transcribe` · `gpt-4o-mini-transcribe` · `whisper-1`) · ปิด = สลับไปใช้ตัวฟังฟรีของเบราว์เซอร์
- ค่าใช้จ่ายประมาณ: ฟัง ~0.01–0.02 บาท + เข้าใจ ~0.03 บาท ต่อคำสั่ง

## ความปลอดภัย / แก้ไข · ย้อนกลับ · ลบ

- ผู้ช่วย **ไม่บันทึกโดยไม่มีคนกด** — โหมดเปิดฟอร์ม: คนกดบันทึกในฟอร์มเดิม · โหมดยืนยัน: โชว์สรุปให้กด "บันทึกเลย" / "แทรกและบันทึก" ก่อนเสมอ · ทุกทางบันทึกผ่าน API เดิม (`/api/skus/wizard-create` สิทธิ์ `products.create` · PATCH parent SKU สิทธิ์แก้สินค้า) + audit เหมือนกดเอง
- ทำรายละเอียดสินค้าต้องมีสิทธิ์ `products.edit` (ไม่มี = ผู้ช่วยบอกให้ขอสิทธิ์) · AI ร่างใช้โควตา `ai.desc_highlights` ของคนนั้นตามปกติ
- ค่าที่ AI ส่งมาถูกตรวจทุกครั้ง: หน้าต้องอยู่ในรายการที่คนนี้เห็นได้ · ตัวเลือกต้องเป็นตัวที่ระบบส่งไป · ไม่มีสิทธิ์เพิ่มสินค้า = ไม่เปิดฟอร์ม
- **แก้ไข**: ค่าที่ฟังได้แก้ได้ในช่องข้อความก่อนส่ง และแก้ได้ทุกช่องในฟอร์มก่อนบันทึก
- **ย้อนกลับ**: บันทึก SKU แล้วมีปุ่ม "ย้อนกลับ" ในแจ้งผลมุมจอ (15 วิ) = ปิดใช้ SKU นั้น (`is_active=false` ผ่าน API กลาง master-v2 — เก็บไว้ ไม่ลบถาวร)
- **ลบ**: ประวัติคำสั่งเสียงเป็นบันทึกตรวจสอบ (`audit_logs` action `voice_command`) — ลบไม่ได้โดยตั้งใจ · ข้อความในแผงคุยหายเมื่อรีเฟรชหน้า
- เสียงถูกส่งไปถอดที่ OpenAI (หรือ Google ถ้าใช้ตัวฟังฟรีของ Chrome) — ไม่เก็บไฟล์เสียงในระบบ

## เพิ่มคำสั่งใหม่

1. เพิ่มชื่อใน `VOICE_ACTIONS` + `VOICE_COMMANDS`/`VOICE_COMMAND_INFO` (ป้าย · โหมดที่รองรับ · ตัวอย่างเริ่มต้น — หน้าตั้งค่าโผล่เอง) + กติกาใน `buildVoiceSystemPrompt` + ตรวจค่าใน `normalizeVoiceReply` (เทสต์ `lib/__tests__/voice-assistant.test.ts`)
2. ฝั่งหน้าจอ (`components/voice-assistant`) ทำต่อด้วย **ของกลางที่มีอยู่** (เปิดฟอร์ม/ตัวช่วยเดิมพร้อมค่า) — ห้ามให้ผู้ช่วยยิงบันทึกเอง
3. อัปเดตคู่มือนี้

## ข้อจำกัดที่รู้

- ตัวฟังฟรีของเบราว์เซอร์ (ทางสำรอง) ไม่มีใน Firefox → พิมพ์แทน
- รอบแรกยังไม่คุยต่อเนื่องแบบไม่ต้องกด (hands-free) · ยังไม่มีปุ่มลัดคีย์บอร์ด
- ปุ่มไมค์ลอยมุมขวาล่าง อาจบังปุ่มของบางหน้าบนมือถือ — แจ้งได้ถ้าเจอ
