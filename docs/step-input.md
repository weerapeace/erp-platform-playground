# StepInput — ช่องตัวเลข + ปุ่ม −/+ + ลูกกลิ้งเมาส์ (ของกลาง)

`components/step-input.tsx`

## ใช้ทำอะไร
ช่องตัวเลขที่ต้อง "ขยับทีละนิด" บ่อย เช่น ระยะห่าง ขอบแผ่น ความกว้าง/ความยาว — พิมพ์เองได้ และปรับด้วย
- ปุ่ม **−** / **+** สองข้างช่อง
- **หมุนลูกกลิ้งเมาส์** ตอนชี้ที่ช่อง (ขึ้น = เพิ่ม · ลง = ลด)
- ลูกศร **↑ / ↓** บนคีย์บอร์ดตอนอยู่ในช่อง
- กด **Shift** ค้างไว้ = ทีละ step × 10

ลูกกลิ้งใช้ `useWheelStep` ตัวเดียวกับ `WheelSelect` → เลื่อนหน้าผ่าน ๆ ค่าไม่เปลี่ยน (ต้องขยับเมาส์มาชี้ที่ช่องก่อน)

## ใช้เมื่อไหร่ / ห้ามใช้เมื่อไหร่
- ✅ ตัวเลขต่อเนื่องที่ปรับทีละขั้น (mm, cm, องศา, จำนวน)
- ❌ ค่าที่เป็นรายการให้เลือก (ใช้ `WheelSelect`) · เงิน (ใช้ `MoneyInput`) · แถบเลื่อน (ใช้ `RangeInput`)

## Props สำคัญ
| prop | ความหมาย |
|---|---|
| `value` / `onChange` | ตัวเลข หรือ `null` (ช่องว่าง) |
| `step` | ขยับทีละเท่านี้ (ค่าเริ่ม 1) — แสดงเป็น cm แต่อยากได้ทีละ 1 mm ให้ส่ง `0.1` |
| `min` / `max` | ปุ่ม/ลูกกลิ้ง/ลูกศรไม่พาเกินขอบ (พิมพ์เองยังได้ ผู้เรียกตรวจเอง) |
| `unit` | ป้ายหน่วยท้ายช่อง (ไม่ใส่ = ไม่แสดง) |
| `integer` | ปัดเป็นเลขเต็ม |
| `className` | ขนาดทั้งกล่อง เช่น `h-8 w-full` |

## ตัวอย่าง
```tsx
<StepInput className="h-8 w-full" value={spacingCm} step={0.1} min={0}
  onChange={(v) => setSpacingMm(v == null ? 0 : v * 10)} />
```

## ใช้แล้วที่
