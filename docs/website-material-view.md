# 🧵 กดชื่อวัสดุ → แผง / ป๊อป / หน้าเต็ม (เว็บร้าน)

ชื่อวัสดุในรายละเอียดสินค้าเป็นลิงก์อัตโนมัติอยู่แล้ว (ดู `docs/detail-insert-materials.md`)
เอกสารนี้ = **กดแล้วโชว์แบบไหน** + ชิ้นส่วนกลางที่ใช้วาด

## ตั้งค่า

ERP → เว็บไซต์ → ธีม → แท็บ **หน้าสินค้า** → "🧵 กดชื่อวัสดุในรายละเอียดสินค้า → เปิดแบบ"
(`components/website-material-view-setting.tsx` · ค่าเก็บที่ `theme.product.materialView`)

| ค่า | หน้าตา | หมายเหตุ |
|---|---|---|
| `drawer` | แผงเลื่อนจากขวา (คอม) · แผ่นจากล่าง (มือถือ) | แนะนำ — ลูกค้าไม่ออกจากหน้าสินค้า |
| `modal` | ป๊อปกลางจอ รูปซ้ายค้าง ข้อความขวาเลื่อน | สวยสุดเมื่อมีรูปผิววัสดุ |
| `page` | ไปหน้า `/materials/<slug>` | **ค่าเริ่ม** (เหมือนก่อนมีตัวเลือก) |

ทุกแบบมี: รูปผิววัสดุ · เรื่องราว (ย่อหน้าแรกตัวใหญ่) · วิธีดูแลเป็นข้อ + ไอคอน · สินค้าอื่นที่ใช้วัสดุนี้ · ลิงก์หน้าเต็ม
ยังไม่มีรูปวัสดุ → หัวแบบลายทอ + ชื่อตัวใหญ่ (อัปโหลดรูปที่ `/m/product_materials` ช่อง image_key)

## เว็บร้าน (storefront)

- `src/components/ui/Overlay.tsx` — **หน้าต่างลอยกลาง** (drawer/modal · มือถือแผ่นจากล่าง ลากลงปิดได้ · Esc/พื้นหลัง/✕ · ล็อกเลื่อน + ชดเชยแถบเลื่อน · คืนโฟกัส) — ป๊อปใหม่ของเว็บร้านให้ใช้ตัวนี้
- `src/components/materials/MaterialParts.tsx` — ชิ้นส่วนกลาง `MaterialVisual` `MaterialStory` `MaterialCareList` `MaterialProductsRow` (ไม่มี hook → ใช้ได้ทั้งเซิร์ฟเวอร์/เบราว์เซอร์ ส่ง `t` เข้าไป)
- `src/components/materials/MaterialViewer.tsx` — ดักคลิก `a[data-material]` ที่ **window capture** (ต้องมาก่อน NavProgress ที่ดักเปลี่ยนหน้าแบบลื่นที่ document) · Ctrl/⌘/คลิกกลาง = เปิดหน้าเต็มตามปกติ
- `src/lib/material-care.ts` — แยกบรรทัดวิธีดูแล + เลือกไอคอนจากคำ (ไทย/อังกฤษ · คำที่ขึ้นก่อนชนะ · ตำแหน่งเดียวกันคำยาวชนะ · คำอังกฤษต้องขึ้นต้นคำ)
- หน้าสินค้า `app/product/[slug]/page.tsx` โหลดวัสดุ + สินค้าที่ใช้วัสดุเดียวกัน (≤ 8) มาพร้อมหน้า → เปิดทันที ไม่รอโหลด
- หน้าเต็ม `app/materials/[slug]/page.tsx` แบบนิตยสาร (มีรูป = `data-hdr-under` → Header โปร่งใสทับได้ถ้าเปิดแถว "หน้าอื่น ๆ")
- CSS: `globals.css` `.sf-ov-*` + `.mat-*` · ภาษาไทยหัวข้อเล็กชิดตัวอักษร (`html[lang='th']`)

## ข้อจำกัด

- ไอคอนวิธีดูแลเดาจากคำ — บรรทัดที่ไม่มีคำรู้จัก = จุดเล็ก
- แผง/ป๊อปทำงานเฉพาะหน้าสินค้า (ที่อื่นที่มีลิงก์วัสดุ = ไปหน้าเต็ม)
