# BulkActionBar — แถบคำสั่งหลายรายการ ลอยติดขอบล่างจอ (ของกลาง)

`components/bulk-action-bar/index.tsx`

## ใช้ทำอะไร
พอผู้ใช้ติ๊กเลือกแถว/การ์ด → แถบสีเข้มลอยขึ้นที่ขอบล่างจอ บอก "N รายการที่เลือก" + ปุ่มคำสั่ง (เปลี่ยนป้าย/สถานะ/ส่งออก ฯลฯ) + ✕ ล้างที่เลือก
เห็นตลอดไม่ว่าจะเลื่อนหน้าไปถึงไหน (แถบด้านบนแบบเดิมหายเมื่อเลื่อนลง)

## ใช้เมื่อไหร่
- หน้ารายการที่ติ๊กหลายรายการแล้วทำคำสั่งพร้อมกัน — โดยเฉพาะมุมมองการ์ด/รายการยาวที่ต้องเลื่อน
- หน้าที่ใช้ DataTable กลางมีแถบของตัวเองอยู่แล้ว (ด้านบนตาราง) — ไม่ต้องซ้อน

## ตัวอย่าง
```tsx
<BulkActionBar count={selected.size} unit="รุ่น" onClear={() => setSelected(new Set())}
  extra={<button onClick={selectAllFiltered}>เลือกทั้งหมด 250 รุ่นที่กรองอยู่</button>}>
  <button onClick={…}>เปลี่ยนป้าย</button>
</BulkActionBar>
```

| prop | ความหมาย |
|---|---|
| `count` | จำนวนที่เลือก — 0 = ซ่อน (ไม่กินพื้นที่) |
| `unit` | หน่วย เช่น "รุ่น" "ใบ" (default "รายการ") |
| `onClear` | ปุ่ม ✕ ล้างที่เลือก |
| `extra` | ข้อความ/ลิงก์ต่อจากตัวนับ |
| `children` | ปุ่มคำสั่ง (ชิดขวา) — พื้นแถบสีเข้ม: ช่อง input/select ใส่ `text-slate-800` ที่ตัวห่อ |

## พฤติกรรม
- portal ที่ body + `fixed` → ไม่โดน overflow ตัด
- **z-40** = เหนือเนื้อหา/เมนูล่างมือถือ (z-30) แต่ใต้หน้าต่างเด้ง/ยืนยัน (z-50) → เปิด ConfirmDialog จากแถบได้โดยไม่โดนบัง · dropdown ของ SearchableSelect (z-1001) ลอยทับแถบได้
- จอเล็ก (< xl) ยกขึ้นเหนือแถบเมนูล่างของเชลล์ · ใส่ spacer ท้ายตำแหน่งที่วาง (มือถือ 13rem เพราะแถบตัดหลายบรรทัด + ยกเหนือเมนูล่าง · xl 6rem) → **วางไว้ท้ายสุดของเนื้อหา (หลัง Pager)** กันแถบบังรายการสุดท้าย

## permission / audit
ตัวแถบไม่เช็กสิทธิ์เอง — หน้าที่เรียกต้องซ่อนเมื่อไม่มีสิทธิ์ (`{canManage && <BulkActionBar …/>}`) และคำสั่งต้องเขียน audit ฝั่ง API
