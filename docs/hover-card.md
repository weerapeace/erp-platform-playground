# 🪟 Hover Card — ชี้ที่การ์ดแล้วเห็น "รูปใหญ่ + รายละเอียด" (ของกลาง)

ไฟล์: `components/hover-card/index.tsx`

## ใช้ทำอะไร
ชี้เมาส์ค้างที่การ์ด (~0.35 วิ) → กล่องลอยข้างการ์ด โชว์รูปใหญ่ (ซ้าย) + รายละเอียด (ขวา)
แทนแบบเก่าที่ "ชี้ที่รูปแล้วเห็นรูปใหญ่อย่างเดียว" (HoverPreview)

## ใช้ที่ไหนแล้ว
| หน้า | ไฟล์ห่อ | ตั้งค่าที่ไหน | เก็บค่า |
|---|---|---|---|
| บอร์ดงาน (Tasks) | `app/tasks/task-hover-card.tsx` (`TaskHoverWrap`) | ⚙️ ตั้งค่า มุมขวาบนของบอร์ด (กล่องม่วงบนสุด) | ธีมบอร์ดต่อคน `KanbanTheme.hoverCard / hoverFields` |
| Design Dashboard | `components/design-dashboard/sheet-hover.tsx` (`SheetHoverWrap`) | ปุ่ม `⚙️ ตั้งค่า Hover ▾` บนแถบเครื่องมือ (จอคอม) | `user_ui_prefs` key `design_dashboard_hover` = `{ on, fields }` |

## ชิ้นส่วน
- `HoverCardWrap` — ห่อการ์ด · props: `enabled`, `off` (เช่น กำลังลาก), `image` (url รูปใหญ่) หรือ `images` (สูงสุด 4 รูปเล็ก), `details()` (เรียกตอนเปิดเท่านั้น), `hint`
- `HoverRow` — แถว "หัวข้อ : ค่า" ในกล่อง
- `HoverFieldsPicker` — กล่องตั้งค่า: ติ๊กเปิด/ปิด + ชิปเลือกสิ่งที่โชว์ + ↺ ค่าเริ่มต้น (ผู้เรียกเก็บค่าเอง)

## กฎ
- ทัช (มือถือ/แท็บเล็ต) ไม่เด้ง (`useCanHover`) · ลากการ์ดอยู่ไม่เด้ง (`off` + ปิดเองเมื่อ dragstart)
- ปิดเมื่อ: เมาส์ออก · กดเมาส์ · เลื่อนจอ/ล้อเมาส์
- ตำแหน่ง: ขวาของการ์ด → ไม่พอ = ซ้าย → ไม่พอทั้งคู่ = หดลงข้างที่กว้างกว่า (ไม่บังการ์ด) → แคบมากค่อยวางกลางจอ
- เปิดอยู่ = รูปบนการ์ดต้องไม่ใช้ HoverPreview (กันเด้งซ้อน) · ปิด = กลับเป็นชี้ที่รูปแบบเดิม
- เปิดอยู่ = เอา `title` (tooltip ของเบราว์เซอร์) ออกจากการ์ด กันซ้อนกับกล่อง
- กล่องเป็น `pointer-events-none` — คลิก/ลากการ์ดได้ตามปกติ

## ห้ามใช้เมื่อ
- อยากให้กดในกล่องได้ (ปุ่ม/ลิงก์) → ใช้ป๊อปอัป/Drawer กลางแทน
- รายการที่ไม่มีรายละเอียดอะไรนอกจากรูป → ใช้ HoverPreview เดิมพอ

## เพิ่มให้หน้าใหม่
1. ทำไฟล์ห่อของหน้า (เหมือน `sheet-hover.tsx`): รายการ field (`HoverFieldDef[]`) + ค่าเริ่มต้น + hook เก็บค่าต่อคน + `details()`
2. ห่อการ์ดด้วย wrap ของหน้า (ย้าย `key` ไปไว้ที่ wrap) · ส่ง `off` ตอนลาก
3. วางปุ่มตั้งค่าที่หาเจอง่าย และชื่อปุ่มต้องมีคำว่า "ตั้งค่า" + "Hover" (เจ้าของหาไม่เจอมา 2 ครั้ง: ครั้งแรกซ่อนลึกใน ⚙️ · ครั้งที่สองชื่อปุ่ม "🪟 ชี้ที่การ์ด" ไม่รู้ว่าเป็นปุ่มตั้งค่า)
