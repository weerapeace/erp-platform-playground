# 🧾 ใบกำกับภาษีเต็มรูป · ↩️ ขอคืน/เปลี่ยนสินค้า (เว็บร้าน · ชุด 4)

ค่าเริ่ม = ปิดทั้งคู่ · เปิดที่ ERP › เว็บไซต์ › ร้าน › 🏪 ข้อมูลร้าน

## 🧾 ลูกค้าขอใบกำกับภาษีตอนสั่ง

**ตั้งค่า** (กลุ่ม ออเดอร์): ✅ "ให้ลูกค้าขอใบกำกับภาษีเต็มรูปตอนสั่ง" + **รหัสบริษัทที่ออกใบ** (เช่น `LOUIS`, `ISG` — ดูที่ ERP › ตั้งค่า › บริษัท)
- ⚠️ ต้องตั้งรหัสบริษัทก่อนออกใบ — ระบบไม่เดาบริษัทหลักให้ (ใบกำกับผิดบริษัท = ปัญหาภาษี)

**ลูกค้า** (หน้าชำระเงิน): ติ๊ก "ขอใบกำกับภาษีเต็มรูป" → บุคคลธรรมดา/นิติบุคคล · ชื่อ · เลข 13 หลัก (ตรวจหลักตรวจสอบทันที) · สาขา (ว่าง = สำนักงานใหญ่) · ที่อยู่ = ที่อยู่จัดส่ง หรือกรอกเอง
→ เก็บที่ `store_orders.tax_invoice` (ร้านปิดรับไปแล้ว = ไม่เก็บ ออเดอร์ยังผ่าน) · เลขผิด = ไม่รับออเดอร์ บอกเหตุผล

**ร้าน** (แท็บ 🧾 ออเดอร์): รายการมีป้าย "🧾 ขอใบกำกับภาษี" → เปิดออเดอร์ → กล่องคำขอ → **ออกเลขใบกำกับภาษี** (ครั้งเดียว · แก้ไม่ได้ · audit) → **🖨 พิมพ์ใบกำกับภาษี**
- เลขที่: ชุดของเว็บต่อบริษัทต่อเดือน `<รหัสบริษัท>-TI<ปปดด>-00001` (แยกจากเลขใบสั่งขาย กันชน · unique ใน DB · กดพร้อมกัน 2 คนได้เลขเดียว)
- ใบพิมพ์ (`/print/web-tax-invoice?id=`): A4 ต้นฉบับ + สำเนา · หัวกระดาษบริษัท (ชื่อ/ที่อยู่/เลขผู้เสียภาษี/สาขา) · ลูกค้า · รายการ + ค่าส่ง/ค่าธรรมเนียม/ห่อของขวัญ/การ์ด · ส่วนลด (รวมแต้ม) · มูลค่าก่อนภาษี + VAT 7% (ราคาเว็บรวม VAT แล้ว) · ตัวหนังสือภาษาไทย · ช่องเซ็น
- บริษัทไม่ได้จด VAT = หัวเรื่อง "ใบเสร็จรับเงิน" ไม่แยกภาษี

ไฟล์: `lib/website-tax-invoice.ts` (ตรวจเลข · ล้างข้อมูล · vatSplit) · `lib/website-tax-invoice-print.ts` (HTML) · `/api/website/orders/tax-invoice` (POST ออกเลข · GET ข้อมูลพิมพ์) · `app/print/web-tax-invoice` · migration `202610292000_store_orders_tax_invoice`
เว็บร้าน: `src/components/checkout/TaxInvoiceBox.tsx` · `src/lib/tax-invoice.ts`

## ↩️ ขอคืน/เปลี่ยนสินค้า (ภายใน 14 วันหลังได้รับของ)

**ตั้งค่า** (กลุ่ม ↩️): เปิด · ขอได้ภายในกี่วัน (ค่าเริ่ม 14) · เงื่อนไขที่ลูกค้าเห็น
- "ได้รับของ" = วันที่ร้านเปลี่ยนออเดอร์เป็น **สำเร็จ** (`store_orders.completed_at` ตั้งให้อัตโนมัติ) · ยังไม่ได้ตั้ง (สถานะ "ส่งแล้ว") = ประมาณวันสั่ง + 7 วัน

**ลูกค้า**: หน้าตามออเดอร์ (เลขออเดอร์ + เบอร์) → ปุ่ม "↩️ ขอคืน/เปลี่ยนสินค้า" (ออเดอร์ส่งแล้ว/สำเร็จ) → หน้า `/returns?t=…` (ลิงก์มีลายเซ็น ชุดเดียวกับลิงก์รีวิว)
→ เลือกเปลี่ยน/คืน · ชิ้น + จำนวน · เหตุผล · รายละเอียด · รูป ≤ 3 → ส่ง · เปิดลิงก์เดิมดูสถานะ + หมายเหตุจากร้าน
- 1 ออเดอร์มีคำขอที่เปิดอยู่ได้ทีละ 1 (ไม่อนุมัติ/ปิดแล้ว = ขอใหม่ได้) · เลยกำหนด = บอกให้ทักแชท

**ร้าน** (แท็บ ↩️ คืน/เปลี่ยน): แยกตามสถานะ · กดแถวดูรูป/ชิ้น/เหตุผล · หมายเหตุถึงลูกค้า · ปุ่มเฉพาะขั้นที่ทำต่อได้
รอร้านตรวจ → ✅ อนุมัติ (ให้ส่งของกลับ) / ✕ ไม่อนุมัติ (ต้องใส่เหตุผล) → 📦 ได้รับของคืน → 🏁 ปิดคำขอ · ทุกขั้นลง audit
- **ระบบไม่คืนเงิน/ไม่ตัดหรือคืนสต็อกให้เอง** — ร้านทำต่อตามขั้นตอนปกติ (โอนคืน · ส่งของใหม่ · ใบลดหนี้)
