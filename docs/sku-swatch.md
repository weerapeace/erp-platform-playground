# 🎨 แผงผ้า (Swatch) — หลายรูป · ครอป · อ่านจากรูป · รหัสภายใน

หน้า SKU → แท็บ 🎨 Swatch · ของกลาง `components/sku-swatch-browser` (`SwatchBrowser`) · API `/api/sku-swatches`

## ใช้ทำอะไร
เก็บรูปแผงตัวอย่างจริง (การ์ดสีผ้า / ด้าย / หนัง / อะไหล่) แล้วตั้ง "ชิ้น" บนรูป — แต่ละชิ้นมี **รหัสภายใน** ใช้อ้างอิงได้ทันที
โดยยังไม่ต้องสร้าง SKU · พอพร้อมค่อยผูก SKU ที่มีอยู่ หรือสร้าง SKU ใหม่จากชิ้นนั้น

## ข้อมูลอยู่ไหน (migration `202612170100_sku_swatch_photos_codes`)
| ตาราง | ความหมาย |
|---|---|
| `sku_swatches` | แผ่น · `code` = รหัสแผ่น (SW-0001) · `next_chip_no` = เลขชิ้นถัดไป · `image_key` = สำเนาของรูปปก (หน้าเก่าที่อ่านรูปเดียวใช้ต่อได้) |
| `sku_swatch_images` | รูปของแผ่น เรียงตาม `sort_order` — **รูปแรก = ปก** |
| `sku_swatch_spots` | ชิ้น · `image_id` (อยู่รูปไหน) · `x/y/w/h` = % ของรูปนั้น · `code` · `color_hex` · `name` (ชื่อสี) · `label` (เลขที่พิมพ์บนแผง) · `source` manual/ai · `sku_id` ว่างได้ |

## รหัส
- รหัสแผ่น = ตัวออกเลขกลาง `erp_next_number('sku_swatch')` แบบ `SW-{0000}` (ไม่รีเซ็ต) — ตอนเพิ่มแผ่นพิมพ์รหัสเองได้ (A-Z 0-9 ขีด 2–20 ตัว ห้ามซ้ำ)
- รหัสชิ้น = รหัสแผ่น + `-01`, `-02` … **ออกที่ API ตอนบันทึกเท่านั้น** (`assignCodes`) เรียงตาม รูป → แถวบนลงล่าง → ซ้ายไปขวา
- หน้าจอโชว์ "รหัสที่จะได้" ก่อนบันทึกด้วยสูตรเดียวกัน (`previewCodes`) · บันทึกแล้วล็อกถาวร · ลบชิ้นแล้วเลขนั้นไม่ถูกใช้ซ้ำ
- เลขที่พิมพ์บนแผงของร้าน เก็บแยกใน `label` (ไม่ใช่รหัสภายใน)

## 🎯 คลิกที่สี = ตีกรอบให้ (วิธีหลัก · รอบ 2 2026-11-14)
- คลิกที่ชิ้นสีบนรูป → ไล่หาพื้นที่สีใกล้เคียงที่ต่อกันจากจุดที่คลิก → กรอบพอดีชิ้น + สีเฉลี่ยทั้งชิ้น (`floodFitRect` ใน `lib/sku-swatch.ts` · รูปย่อ 900px + เบลอ 3×3 ลดลายผ้า · ทำในเครื่อง ฟรี)
- "ความไวสี" (10–90 · ค่าเริ่ม 38) = ระยะสีที่ยอมรับ · ชิ้นติดกันสีใกล้กันให้ลด · ลายผ้า/หนังเยอะให้เพิ่ม
- คลิกพื้นหลัง/ขอบการ์ด (กินพื้นที่ > 30% หรือเป็นวงล้อมข้างในโล่ง) = เตือน ไม่สร้างกรอบ · คลิกชิ้นที่มีกรอบแล้ว = เลือกชิ้นนั้น
- 🎯 ตีกรอบใหม่จากสี (ปุ่มในแผงชิ้น) = คลิกบนรูปอีกครั้งแล้วกรอบ+สีของชิ้นที่เลือกเปลี่ยนตาม (รหัส/ชื่อ/SKU คงเดิม) · Esc = ยกเลิก
- ลากบนรูป = ตีกรอบเองได้ทุกโหมด · โหมด "ลากกรอบเอง" = คลิกที่ว่างไม่สร้างกรอบ
- ซูม: Ctrl + หมุนลูกกลิ้ง / ปุ่ม − % + (ของกลาง `ZoomBox` · `docs/zoom-box.md`)

## ✨ AI (บริการเสียเงิน `ai.swatch_read` · ~0.1 บาท/รูป วัดจริง)
`POST /api/sku-swatches/ai-read` (1 รูป/ครั้ง · ย่อด้านยาว 1600px) · เรียกผ่าน `aiChat` · รุ่นเริ่ม gpt-4.1-mini · เปลี่ยนรุ่น/ปิด/ตั้งงบ ที่ `/admin/paid-services`
- **อ่านเลข + ชื่อสี (ปุ่มหลัก)** `{ mode: "label", count, image }` — หน้าจอวาดกรอบพร้อมเลข 1..n (เรียงแบบอ่านหนังสือ) ลงรูปก่อนส่ง (`drawNumberedImage`) → AI ตอบ `{ items: [{ n, label, name }] }` (`normalizeAiLabels`) · เติมเฉพาะช่องที่ว่าง (ที่พิมพ์เองไม่ทับ) · ไม่แตะตำแหน่งกรอบ
- **ให้ AI หาชิ้นเอง (ทดลอง)** `{ image }` → ชิ้น `{x,y,w,h,label,name,unsure}` (`normalizeAiChips`) — GPT ชี้ตำแหน่งได้แค่ประมาณ · แทนชิ้นที่ยังไม่บันทึก/ไม่ผูก SKU ของรูปนั้น · ชิ้นไม่แน่ใจ = กรอบส้มเส้นประ
- ⚠ บั๊กที่แก้แล้ว (รอบ 2): เดิมเดาสเกล 0–1000 เมื่อค่าใดเกิน 101 → ชิ้นริมขวาที่ AI กะเกินขอบนิดเดียวทำให้ทุกกรอบหด 10 เท่า กองมุมซ้ายบน + ดูดสีได้แต่พื้นหลัง (สีเทา) · ตอนนี้ต้องเกิน 150 ถึงถือเป็น 0–1000
- **สีจริงไม่ได้มาจาก AI** — ดูดจากพิกเซลเสมอ

## ทางสำรองเมื่อชิ้นแยกยาก
ตีกรอบครอบทั้งแถว → ใส่จำนวน คอลัมน์ × แถว → "แบ่ง" (`splitRect`) ระบบแบ่งเท่า ๆ กัน + ดูดสีให้

## ครอป / หมุน
ของกลาง `ImageFreeCropModal` (`components/image-crop-picker.tsx`) — กรอบอิสระ + หมุน 90° · ครอปรูปที่มีชิ้นแล้ว ชิ้นเลื่อนตาม (`rotateRect90` + `remapToCrop`)
ชิ้นที่หลุดกรอบถูกเอาออก (เตือนจำนวน) · รูปที่ครอปแล้วอัปใหม่ตอนกดบันทึก (ไฟล์เดิมใน R2 ไม่ลบ)

## ข้อจำกัด
- คลิกที่สี: ชิ้นติดกันสีใกล้กันมาก (ดำติดเทาเข้ม) หรือผ้าลายเยอะ/มีเงา กรอบอาจรวมสองชิ้นหรือไม่เต็มชิ้น → ปรับความไวสี / ลากเอง / แบ่ง · ยังไม่ได้ลองกับรูปแผงจริงหลายแบบ
- กรอบเป็นสี่เหลี่ยมตรง หมุนกรอบไม่ได้ (หมุนได้ทั้งรูปทีละ 90°)
- "สร้าง SKU จากชิ้นนี้" เติมชื่อสีให้ แต่ยังไม่ใส่รูปชิ้นเป็นรูปปก SKU
