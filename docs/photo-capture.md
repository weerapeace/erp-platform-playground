# PhotoCapture — ถ่ายรูปจากมือถือ/กล้อง (ของกลาง)

`components/photo-capture` · เจ้าของขอ 2026-11-21 ("อยากให้ถ่ายรูปได้ด้วย ถ้ากดจากโทรศัพท์")

## ใช้ทำอะไร
- **มือถือ/แท็บเล็ต** (ดูจากชนิดตัวชี้ `useCanHover` ไม่ใช่ความกว้างจอ): ปุ่ม **ถ่ายรูป** เปิดแอปกล้องของเครื่องตรง (`capture="environment"`) · **เลือกจากคลัง** · ลิงก์ **กล้องในเว็บ** (มีเส้นกริด 3×3 + กรอบกลาง · ถ่ายต่อเนื่อง · สลับกล้อง)
- **PC**: หน้าตาเดิมทุกอย่าง · ถ้าเครื่องมีเว็บแคม → ลิงก์เล็ก "ถ่ายจากเว็บแคม"
- หลังถ่าย → ถาด **ตรวจรูปก่อนใส่**: ถ่ายอีกรูป · ครอป/หมุน (`ImageFreeCropModal`) · **ดัดให้ตรง** (ลาก 4 มุม → ยืดเป็นสี่เหลี่ยมตรง · `lib/perspective-warp` ไม่ใช้ไลบรารี) · ลบ (ย้อนกลับได้)
- กด "ใส่ N รูป" → ย่อรูปให้ด้านยาว ≤ `maxSide` (2400px) → `onFiles(files)` · รูปจากคลังย่อแล้วส่งทันที · PDF/GIF ส่งตามเดิม

## ใช้แล้วที่
- ช่องของกลาง: `ImageAttach` / `ImageAttachKeys` (ย่อเองอยู่แล้ว → `maxSide: 0`) · `FileInput` · `FileMultiInput` · `ImageInput` (ช่องรูปเดี่ยว ~23 จุด) · รูป SKU ลูก (`relation-multi/image-board` ปุ่มถ่ายต่อแถว) · `SellerBillIntake` · `SlipPicker` · แชตรวม (`chat-inbox/composer`) · รูปโปรไฟล์ (กล้องหน้า `facing: "user"`) · SAMPLE Images · กล่องรูปแผงผ้า Swatch
- หน้างาน (รอบ 2 · 2026-11-21 เจ้าของเลือกกลุ่ม ก+ข): โอนเงินจีน (สลิป 3 จุด · `zIndex: 220` เพราะป๊อปของแอปนี้ z-210) · ใบจดผลงาน · ป๊อปส่งงานย่อย (รูปสินค้า) · แจ้งปัญหา · คำสั่งซื้อจากไลน์ · ~~บรรจุภัณฑ์ตอนแพ็ค~~ (เลิกใช้ 2026-11-23 รอบ 7 — Set บรรจุภัณฑ์ใช้รูปจาก SKU แทน) · แกะแพทเทิร์นจากรูป (`maxSide: 0` คงความละเอียด) · อ่านจากรูปโน้ต · เติมรูปสินค้า (แดชบอร์ดจัดซื้อ)

## วิธีใช้
```tsx
const cap = usePhotoCapture({ onFiles: (fs) => handleFiles(fs), multiple: true, maxSide: 2400 });
{cap.touch ? <PhotoCaptureButtons capture={cap} size="sm" /> : <>ข้อความลากวางแบบเดิม <PhotoCaptureButtons capture={cap} /></>}
{cap.ui}   {/* ต้อง render — ช่องไฟล์ซ่อน + หน้าต่างถาด/กล้อง/ครอป · อย่าวางในกล่องที่มี onClick (คลิกในป๊อปจะทะลุขึ้นไป) */}
```
- รวมในตัว: `<PhotoCapture onFiles={…} />`
- ปุ่มเดียววางข้างปุ่มเลือกรูปเดิมของหน้า: `<CameraButton onFiles={…} label="ถ่ายรูป" />` (มือถือเท่านั้น · PC ไม่โชว์อะไร) · ตัวรับเก่าที่ต้องการ FileList → `toFileList(files)`
- เปิดจากป๊อปที่ทำเองซึ่งสูงกว่า z-50 → ส่ง `zIndex` (ถาด/กล้อง/ครอป/ดัดให้ตรงลอยเหนือป๊อปนั้น)
- ช่องที่รับ PDF ด้วย: `libraryAccept="image/jpeg,…,application/pdf"` + `libraryLabel="เลือกไฟล์"`
- หน้าที่เป็น overlay เต็มจอเอง (z สูงกว่า 50): ใช้ `cap.overlayOpen` ถอยตัวเองไปข้างหลัง (แบบ Swatch viewer `onOverlay`)

## ข้อจำกัด
- ไม่อัปโหลดเอง — แถบ `UploadProgress` ของช่องเดิมทำงานตามเดิม
- กล้องในเว็บคุณภาพด้อยกว่าแอปกล้องจริง (แฟลช/โฟกัสไม่ครบ) · ต้อง https + อนุญาตกล้อง · ไม่มีกล้อง = บอกเป็นภาษาคน
- ดัดให้ตรง: ทำในเครื่อง รูปใหญ่ย่อเหลือ ≤3200px ก่อนคำนวณ (กันมือถือค้าง) · มุมไขว้กัน = เตือนก่อน
- ไม่ย้าย (เจ้าของเลือกไม่เอา 2026-11-21): งานออกแบบ/ตั้งค่าบน PC ~45 ไฟล์ — ไอคอน โลโก้ ไอคอนแอป ธีม พื้นหลัง แต่งหน้าแรก แต่งเว็บ/รูปเว็บ Design Library คลังลาย ไฟล์พิมพ์ ตราประทับ GIF Pet บาร์โค้ด (ใช้รูปจากไฟล์งาน ไม่ได้ถ่าย)
- ช่องจิ๋ว `ImageInput compact` ในเซลล์ตารางไม่ได้ใส่ปุ่ม (ที่แคบ) — แตะแล้วมือถือยังเลือก/ถ่ายจากตัวเลือกไฟล์ของเครื่องได้
