# ตารางรายการบรรทัดกลาง — LineItemsGrid

`components/line-items-grid` = ตารางกลางสำหรับเอกสารที่มี "หัว + หลายบรรทัด" (สูตร BOM · ตีราคาใบงานออกแบบ · ใบสั่งผลิต · เสนอราคา ฯลฯ)
ความสามารถหลักอยู่ในหัวไฟล์ (เรียง/จัดกลุ่ม/ปรับขนาดคอลัมน์/ลากเรียง/ติ๊กเลือกหลายแถว/ทำซ้ำบรรทัด)

## หน้าตา 2 แบบ (`variant`)

| ค่า | หน้าตา | ใช้เมื่อ |
|---|---|---|
| `"boxed"` (ค่าเริ่ม) | กรอบรอบตาราง + หัวตารางพื้นเทา + ช่องกรอกเป็นกล่อง | ทุกหน้าเดิม (ไม่ต้องแก้อะไร) |
| `"lines"` | ไม่มีกรอบ เหลือแค่เส้นคั่นบรรทัด · ช่องกรอกไม่มีกรอบ (เส้นใต้จาง ๆ ตอนชี้ · สีฟ้าตอนพิมพ์) · ปุ่มลาก/ทำซ้ำ/ลบ โผล่ตอนชี้แถว | ตารางที่อยากให้อ่านง่าย ไม่รก — เริ่มที่ตารางตีราคาใบงานออกแบบ (เจ้าของขอ 2026-11-03) |

```tsx
<LineItemsGrid variant="lines" rows={rows} columns={cols} onChange={setRows} rowId={(r) => r.key} />
```

- ไม่ต้องแก้ class ของช่องกรอกในคอลัมน์ — สไตล์แบนอยู่ที่ `.lig-lines .lig-cell` ใน `app/globals.css` (ครอบ input/select/textarea ทุกตัวในแถว ยกเว้น checkbox/radio)
- ปุ่มเปิด dropdown ในแถว (ของกลาง `SearchableSelect`, `ComponentPicker` และปุ่มที่ใส่ `data-field-trigger`) แบนตามอัตโนมัติ — ปุ่มกล่องอื่นที่อยากแบนด้วย ให้ใส่ `data-field-trigger`
- แถวมี class `group` → ของในเซลล์ที่อยากโผล่ตอนชี้แถวใช้ `[@media(hover:hover)]:opacity-0 group-hover:opacity-100` (จอสัมผัสโชว์ตลอด)
- ช่องที่ "ชนิดนี้ไม่ใช้" แนะนำเว้นว่าง (ไม่ใส่ "—") ให้ตารางโล่ง

## ดับเบิลคลิกแถวเพื่อแก้ (`onRequestEdit`)

ตารางที่เปิดแบบดูอย่างเดียว (`readonly`) แล้วอยากให้ดับเบิลคลิกแถวเข้าโหมดแก้ได้เลย ไม่ต้องหาปุ่ม ✏️ (เจ้าของขอ 2026-11-03 — ตารางตีราคา)

```tsx
<LineItemsGrid readonly={!editing} onRequestEdit={canEdit ? () => setEditing(true) : undefined} … />
```

- ตารางเรียก `onRequestEdit(row)` เฉพาะตอน `readonly` — หน้าเจ้าของตารางเป็นคนสลับโหมด (และคุมสิทธิ์: ไม่มีสิทธิ์แก้ = อย่าส่ง prop นี้)
- พอ `readonly` เป็น false ตารางโฟกัสช่องที่ดับเบิลคลิกให้เอง (ช่องนั้นไม่มีที่กรอก เช่น ยอดรวม → ไปช่องแรกที่กรอกได้ในแถว)
- ช่องที่ล็อก (disabled) ไม่รับเมาส์ตอนเปิดใช้ (`.lig-dbl` ใน `app/globals.css`) เพราะเบราว์เซอร์ไม่ส่งดับเบิลคลิกจากช่อง disabled — tooltip ของช่องที่ล็อกจึงไม่โผล่ แถวโชว์ "ดับเบิลคลิกเพื่อแก้แถวนี้" แทน

## ห้าม / ข้อควรระวัง

- อย่าทำตารางบรรทัดเองในหน้า — ใช้ตัวนี้ แล้วเลือก `variant`
- จะเปลี่ยนหน้าอื่นเป็น `"lines"` ให้ถามเจ้าของก่อน (ตอนนี้ใช้แค่ตารางตีราคา)
- ไม่มี permission/audit ในตัว — หน้าที่เรียกใช้เป็นคนคุม (readonly / บันทึก)
