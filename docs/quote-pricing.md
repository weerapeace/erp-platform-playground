# ตัวช่วยตั้งราคา (แท็บเสนอราคา ใบงานออกแบบ)

เจ้าของขอ 2026-11-09: "ต้นทุน 100 กำไร 25%, 50%, 75%, 100%, 150%, 200% คือเท่าไหร่ + กดดูราคาของกระเป๋าใบอื่นใน brand นี้"

## ใช้ทำอะไร
ปุ่ม **ตัวช่วยตั้งราคา** บนแถบรอบเสนอราคา (เห็นเฉพาะคนที่มีสิทธิ์ดูต้นทุน `products.cost.view`) เปิดหน้าต่างที่มี 3 ส่วน:

1. **บวกกำไรจากต้นทุน** — ขั้น 25/50/75/100/150/200% + ใส่ % เอง · สลับ 2 แบบคิด:
   - บวกจากต้นทุน: ราคาขาย = ต้นทุน × (1 + %) → ต้นทุน 100 บวก 100% = 200
   - กำไรคิดจากราคาขาย: ราคาขาย = ต้นทุน ÷ (1 − %) → ต้นทุน 100 กำไร 50% = 200 (ตั้งได้ไม่ถึง 100%)
2. **งานอื่นในแบรนด์เดียวกัน** — ทุกรอบเสนอราคาของใบงานอื่นที่แบรนด์เดียวกัน (ต้นทุนตอนเสนอ · ราคาที่เสนอ · บวกกี่ % · ผ่าน/ไม่ผ่าน/รอ) + "กลาง ๆ" ของรอบที่ลูกค้าตกลง (ยังไม่มีรอบผ่าน = ใช้ทุกรอบ) · กดแถว = ใช้ % เท่างานนั้น · ด้านล่างมีราคาป้าย (ขายปลีก) ของรุ่นสินค้าในแบรนด์ ค้นได้ + บอกว่าต้นทุนงานนี้เป็นกี่ % ของราคาป้าย
3. **ตัวช่วยอื่น** — ปัดราคา (ไม่ปัด / ขึ้นหลัก 5 / ขึ้นหลักสิบ / ลงท้าย 9 — ปัดขึ้นเสมอ) · โชว์ราคารวม VAT 7% (แค่โชว์) · ย้อนจากงบลูกค้า (ต้นทุนต้องไม่เกินเท่าไหร่ / ตอนนี้กำไรหรือขาดทุน) · ราคาตามจำนวน (ต้นทุนแต่ละขั้นรวมค่าที่หารตามจำนวน เช่น ค่าบล็อก แล้ว)

กด **ใส่ราคาในรอบเสนอราคา** → ทุกไซส์ที่ติ๊ก × ทุกขั้นจำนวนในฟอร์ม = ตีราคาของช่องนั้น × ตัวคูณที่เลือก แล้วปัด (ยังไม่ได้เปิดฟอร์ม = เปิด "เสนอราคาครั้งใหม่" ให้) · ช่องที่ยังไม่ได้ตีราคา ไม่แตะ · ต้องกดบันทึกเองเหมือนเดิม

## ไฟล์
- สูตร (ไม่แตะฐานข้อมูล): `lib/quote-pricing.ts` · เทสต์ `lib/__tests__/quote-pricing.test.ts`
- หน้าต่าง: `components/design-sheet-detail/quote-pricing-helper.tsx` (ใช้ ERPModal)
- ต่อกับฟอร์ม: `components/design-sheet-detail/quote-rounds.tsx` (prop `pricingHelper` · `fill` ส่งเข้า RoundEditor)
- ข้อมูล: `GET /api/design-sheets/[id]/price-refs` (สิทธิ์ `products.cost.view` · อ่านอย่างเดียว)
  - `quotes` = design_sheet_quotes ของใบงานอื่นที่ brand_id เดียวกัน ที่มีทั้ง `price` (ตีราคาตอนเสนอ) และ `offered_price` (ล่าสุด 400 ช่อง)
  - `skus` = skus_v2.list_price > 0 ของรุ่นใน parent_skus_v2.brand_id เดียวกัน รวมต่อรุ่น (ใช้ fetchAllPages เพราะเกิน 1,000 แถว)

## ห้ามใช้เมื่อไหร่ / ข้อจำกัด
- ราคาที่ใส่ในรอบเสนอราคาเป็น **ก่อน VAT** เสมอ (ช่อง VAT แค่โชว์ให้บอกลูกค้า)
- ใบงานที่ยังไม่เลือกแบรนด์ = ส่วนที่ 2 ว่าง (บอกให้ไปเลือกแบรนด์)
- ตัวเลข "กลาง ๆ" แม่นเท่าที่ทีมกดผ่าน/ไม่ผ่านในรอบเสนอราคา (ตอน 2026-11-09 Good Goods มีรอบผ่านแค่ 5 จาก 52)
- ต้นทุนในรหัสสินค้า (standard_price) แทบว่าง เลยเทียบสินค้าในแบรนด์ได้แค่ราคาขาย
- ปัดราคาต่างจาก `lib/fake-price` (อันนั้นปัดราคาขีดฆ่าแบบลงท้าย 90/99 หลักร้อย)
