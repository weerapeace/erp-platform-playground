# 🔐 สิทธิ์เว็บไซต์ (ใครทำอะไรได้ · รายร้าน)

ตั้งได้ว่าแต่ละคน **เห็น / ดูได้ / แก้ได้** ส่วนไหนของเว็บไซต์ และ **เข้าร้านไหนได้** — ระบบกันทั้งหน้าจอและตอนบันทึก

## ใช้ทำอะไร

- แยกงานหลังร้าน: กราฟิกแก้หน้าตาเว็บได้แต่ไม่เห็นออเดอร์ · แอดมินตอบออเดอร์ได้แต่แก้ดีไซน์ไม่ได้
- แยกร้าน: คนดูแล Pixiedustie ไม่เห็นหลังร้าน Louis Montini
- เมนู "เว็บไซต์" อยู่ในแอป **จัดการงาน** (และช่องทางขาย/หน้าหลักเหมือนเดิม) — คนที่ไม่เห็นกลุ่มไหนเลย เมนูหายเอง

## ตั้งค่าที่ไหน

- หน้า **/website/access** — ปุ่ม "🔐 ใครทำอะไรได้" ในหน้าเว็บไซต์ หรือ ⚙️ ของแอปจัดการงาน → แท็บ "🔐 สิทธิ์เว็บไซต์"
- แถว **ตามตำแหน่ง** = ค่าเริ่มของทุกคนในตำแหน่ง (แก้ต้องมีสิทธิ์ `admin.roles`)
- แถว **ยกเว้นรายคน** = เฉพาะคน ชนะตำแหน่ง (ต้อง `admin.users`) · "↺ ตามตำแหน่ง" ล้างข้อยกเว้น
- ร่าง → กด 💾 บันทึกทีเดียว · มีผลภายใน ~1 นาที (คนนั้นรีเฟรชหน้า) · ผู้ดูแลระบบได้ทุกอย่างเสมอ

## ชิ้นส่วน (ของกลาง)

| ไฟล์ | หน้าที่ |
| --- | --- |
| `lib/website-access.ts` | กลุ่ม/แท็บ/คีย์สิทธิ์ · route API → กลุ่ม (`websiteApiGroups`) · ระดับ ↔ คีย์ (pure + เทสต์) |
| `lib/website-api-guard.ts` | `guardWebsite(request, "view" \| "edit")` — ใช้แทน guardApi(products.*) ใน `/api/website/*` · เช็กร้านจาก query/body |
| `components/website-access-settings.tsx` | ตาราง "ใครทำอะไรได้" |
| `app/api/website/access` | GET/POST ตั้งค่า (ใช้ RPC `erp_role_permission_toggle` + `erp_user_permissions` เดิม · audit) |

คีย์: `website.access` (เห็นเมนู · ตั้งอัตโนมัติ) · `website.<กลุ่ม>.view|edit` · `website.shop.<slug>` — อยู่ในตารางสิทธิ์กลางหมวด "เว็บไซต์" (เห็นใน Role Board ด้วย)

## กฎสำหรับคนเขียนโค้ด

- route ใหม่ใต้ `/api/website/` → ใช้ `guardWebsite` และเพิ่มใน `API_GROUPS` ของ `lib/website-access.ts` (ไม่ใส่ = ใช้กฎเดิม products.*)
- แท็บใหม่ในหน้าเว็บไซต์ → ใส่ใน `tabs` ของกลุ่มใน `WEBSITE_GROUPS`
- route ที่แอปอื่นใช้ด้วย (tag-categories · product-png · listings/images · video-upload) คงกฎเดิม — ไม่งั้นแอปอื่นพัง

## ข้อจำกัด

- กลุ่มที่ "ดูได้" แท็บยังกดปุ่มบันทึกได้ (มีแถบเตือน 👁) แต่ระบบปฏิเสธตอนบันทึก
- คำขอที่ไม่บอกร้าน (เช่น แก้ออเดอร์ด้วยเลข id อย่างเดียว) เช็กแค่กลุ่ม ไม่เช็กร้าน
- ตอนเปิดใช้ (2026-11-04) ทุกตำแหน่งที่เคยมี products.view/edit ได้สิทธิ์ใหม่ครบ = เหมือนเดิมทุกอย่าง — เจ้าของตัดเอง
