# ตัวตั้งเรทเงินวันนี้ (FxRateQuickModal) — ของกลาง

> ★ 2026-11-22 เจ้าของ: "ขอเปลี่ยนเรทเงินได้จากหน้านี้" (หน้าใบสำคัญรับ) → เลือกแบบ B (แตะเรทในกล่องยอดเงิน) + ข้อเสนอ 1, 2, 3

## ใช้ทำอะไร
- เปลี่ยนเรท ฿ ต่อ 1 หน่วยสกุลต่างประเทศของเอกสารที่เปิดอยู่
- ติ๊ก **"ตั้งเป็นเรทกลางวันนี้ด้วย"** (เฉพาะหยวน) = อัปเดตเรทหยวนกลาง `daily_rates` ของวันนี้ — ใบอื่นที่ออกตั้งแต่วันนี้ได้เรทนี้เป็นค่าเริ่มต้น (`fxRateForDate` ใช้เรทล่าสุดที่ไม่เกินวันที่ใบ)
- บอกเรทกลางล่าสุด + ป้าย **"เรทกลางเก่า n วัน"** (`RateStaleChip` · เกิน 3 วัน · `RATE_STALE_DAYS`) — ปุ่ม "ใช้ 5.21" เติมเรทกลางลงช่อง
- ตั้งเรทกลางแล้ว: แจ้งเตือนมุมจอ (toast.undo 10 วินาที) มีปุ่ม **ย้อนกลับ** = คืนเรทกลางเดิม (แก้กลับ หรือปิดแถวที่เพิ่งเพิ่ม) + คืนเรทของเอกสารเดิม
- เตือนเมื่อเรทที่พิมพ์ต่างจากเรทกลางเกิน 1.5 เท่า (พิมพ์ผิดหลัก เช่น 52.1)

## ใช้อย่างไร
```tsx
<FxRateQuickModal open={fxOpen} onClose={() => setFxOpen(false)} currency={currency} value={h.fx_rate}
  refDate={h.voucher_date} onApply={(r) => setHeader({ fx_rate: String(r) })} />
<RateStaleChip rateDate={refFxDate} refDate={docDate} />   // ป้ายเรทกลางเก่า (ไม่เก่า = ไม่โชว์)
```
- `onApply(rate)` = ใส่เรทลงเอกสาร — หน้าเอกสารบันทึกเองตามปกติ (ใบสำคัญรับ: กดบันทึกร่าง)
- ใบสำคัญรับ: แตะตัวเลข "× 5.21" ในกล่องยอดเงิน (ใบร่าง / ใบที่เปิดแก้) · ช่องเรทในหัวใบยังพิมพ์ได้เหมือนเดิม · API ใบส่ง `ref_fx_date` (วันที่ของเรทกลางที่ใช้) มาให้ป้ายเรทเก่า

## กติกา (lib/daily-rate)
- `planSetDailyRate`: `rate_date` ห้ามซ้ำ — วันนี้มีแถวแล้ว (แม้ถูกปิด) = PATCH แถวเดิม (`is_active: true`) · ยังไม่มี = POST · เรทเท่าเดิม = ไม่ทำอะไร
- เขียนผ่าน API กลาง `/api/master-v2/daily-rates` (เพิ่ม = สิทธิ์ products.create · แก้/ปิด = products.edit) ลงประวัติ audit ให้เอง · ไม่มีสิทธิ์ = บอก "ให้หัวหน้าตั้งในแอปโอนเงินจีน"
- เรทกลางเป็นเรทหยวนอย่างเดียว — สกุลอื่นเปลี่ยนได้เฉพาะเอกสารนี้

## ห้ามใช้เมื่อ
- เอกสารล็อกแล้ว (ยืนยันแล้วยังไม่เปิดแก้ / ไม่มีสิทธิ์แก้) — หน้าเอกสารไม่ส่ง `onEditFx`
- จัดการเรทเต็ม (ดูประวัติ/ลบ/แก้ย้อนหลัง) — ใช้แอปโอนเงินจีน แท็บเรท

## กระทบที่อื่น
- เรทกลางใหม่มีผลกับ: ใบสำคัญรับที่ออกใหม่ · เรทอ้างอิงเตือนเรทผิดปกติ · แอปโอนเงินจีน (เรทล่าสุด) · รายงานจัดซื้อที่อ่าน daily_rates (dashboard/monthly-report/po-list)
- ไม่ย้อนแก้เอกสารที่ออกไปแล้ว (เรทเก็บในแต่ละใบ)
