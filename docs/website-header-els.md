# 🧩 ตั้งค่าชิ้นส่วนหัวเว็บ (⚙ โลโก้ · ค้นหา · ตะกร้า)

ดีไซน์ → Header → ตำแหน่งชิ้นส่วน → กดชิ้นที่มี ⚙ เพื่อเปิดป๊อปตั้งค่า (เมนู · โซเชียล มีอยู่เดิม)

| ชิ้น | ตั้งได้ | เก็บที่ |
|---|---|---|
| 🏷 โลโก้ | เนื้อหาเดียวกับแท็บโลโก้ (แก้ที่ไหนก็เปลี่ยนทั้งคู่) | `theme.logo` |
| 🛒 ตะกร้า | แบบไอคอน 4 แบบ · คำข้างไอคอน · ขนาด · ป้ายตัวเลข/จุด/ไม่มี · สีป้าย | `theme.header.cart` |
| 🔍 ค้นหา | ไอคอน / ไอคอน+คำ / ช่องค้นหาในแถบ (ข้อความ · ความกว้าง) · ขนาด | `theme.header.search` |

- ข้อมูล + ตัวกรองค่า: `lib/website-header-els.ts` (ไม่มี import → **มิเรอร์ทั้งไฟล์** ไป storefront `src/lib/header-els.ts`)
- ป๊อป ERP: `components/website-header-els.tsx` (ตัวอย่างสดบนสีพื้น/ตัวอักษรของหัวเว็บจริง)
- เว็บร้านวาดที่ `Navbar.tsx` (`HdrIcon` ใช้เส้นไอคอนชุดเดียวกัน `HEADER_ICON_PATHS`)
- ค่าเริ่มต้น = หน้าตาเดิม (รถเข็น 21px + ตัวเลข · แว่นขยาย 20px) — ร้านที่ไม่ตั้งไม่เปลี่ยน
- มือถือ: คำข้างไอคอนซ่อน · ช่องค้นหาในแถบกลายเป็นไอคอน · กดค้นหาทุกแบบ = เปิดค้นหาเต็มจอเหมือนเดิม
- บันทึกธีม (saved themes) พาหน้าตาตะกร้า/ค้นหาไปด้วย (`HEADER_LOOK`)

## 🪟 โปร่งใสตอนอยู่บนสุด (รายประเภทหน้า)

ตั้งที่ ธีม → แท็บ Header → ตาราง "🪟 โปร่งใสตอนอยู่บนสุด" (`components/website-header-over-settings.tsx`)

- ค่าเก็บที่ `theme.header.overPages` = `{ home|product|listing|new|custom|other: { on, text: "light"|"dark" } }`
- ของกลาง `lib/website-header-over.ts` (mirror เว็บร้าน `src/lib/header-over.ts`): `normalizeOverPages`, `overPageKind(path)`, `OVER_PAGE_KINDS`
- ค่าเก่า `overHero` (หน้าแรกอย่างเดียว) = ค่าเริ่มของแถวหน้าแรก · ยังเขียน `overHero = overPages.home.on` คู่ไว้ให้เว็บรุ่นเก่าอ่านได้
- เว็บร้าน Navbar: หน้าที่เปิด → หัวลอย (กล่องสูง 0) + `.hdr-spacer`
  - Section แรกของหน้าเป็นรูปเต็มจอ (`data-hdr-under`) → ซ่อนช่องว่าง = หัวทับรูป
    - Section: hero · slideshow · canvas · image (กว้างเต็มจอ) — `blockWrapProps`
    - หน้าสินค้าแบบโชว์เคส: แกลเลอรีเอดิทอเรียลกว้างเต็มจอ เป็นส่วนแรก ไม่มี breadcrumb/ชื่อด้านบน
    - คอลเลกชันที่มีแบนเนอร์
  - ไม่มีรูปบนสุด → ช่องว่างยังอยู่ = หัวโปร่งใสแต่ไม่บังเนื้อหา
  - ตอนโปร่งใสใช้สีตัวหนังสือตามแถว (ไม่ใช้สีตัวหนังสือ Header ที่ตั้งเอง) · เลื่อนลง = พื้น/สีปกติ · ติดบนสุดเฉพาะเมื่อเปิด "ตรึงแถบเมนู"
- ข้อจำกัด: Section แรกซ่อนเฉพาะแท็บเล็ต/คอม → ตัดสินจาก Section แรกเสมอ (มือถือที่ซ่อนรูปแรกมีช่องว่างให้แล้ว)
