# ป๊อป "เพิ่มอะไหล่" แบบตะกร้า (PartsCartModal)

> เจ้าของขอ 2026-11-17 · ใบงานออกแบบ แท็บตีราคา → ปุ่ม **เพิ่มอะไหล่** ข้าง "＋ เพิ่มวัตถุดิบ"

## ใช้ทำอะไร
เลือกวัสดุตีราคาเฉพาะกลุ่ม **อะไหล่ / ซิป / เทป** แบบช้อปปิ้ง แล้วลงตารางตีราคาทีเดียว

- กรองกลุ่มจาก "วิธีคิด" ของกลุ่ม: `count` (นับชิ้น) และ `length` (ตามความยาว) — ผ้า/แผ่นไม่ขึ้น
- มุมมอง **ตาราง ↔ การ์ด** (จำต่อคน `useUserPref("parts_cart_view")`) · การ์ดใช้ไอคอนตามชนิด (วัสดุตีราคายังไม่มีช่องรูป)
- ตะกร้า: ปรับจำนวน · ซิป/เทปใส่ **ยาวต่อเส้น (ซม.)** → ลงบรรทัดเป็นยาวรวม (`length_cm`) + โน้ต "2 เส้น × 30 ซม."
- ลงตาราง: มีอะไหล่ตัวเดียวกันในแท็บแล้ว = **บวกเข้าบรรทัดเดิม** (นับชิ้น + จำนวน · ตามยาว + ความยาว) · ไม่มี = บรรทัดใหม่ → เข้าโหมดแก้ไขให้ตรวจแล้วกดบันทึก
- จัดการรายการ (สิทธิ์ `products.edit`): แก้ชื่อ/ราคา/หน่วย · เอาออก (ปิดใช้งาน `is_active=false` ไม่ลบจริง) · ตั้งชุด
- เพิ่มอะไหล่ใหม่ (สิทธิ์ `products.create`) = `MaterialQuickCreate` ตัวเดียวกับสตูดิโอ (โชว์เฉพาะชนิดนับชิ้น/ตามยาว)

## ชุดอะไหล่ (Set)
คอลัมน์ `design_price_items.set_items jsonb` (migration `202612180600_design_price_item_sets.sql`) = `[{ item_id, qty, on }]`
- ใส่วัสดุที่มีชุดลงตะกร้าครั้งแรก → ถาม "ลงอะไรด้วยไหม?" ติ๊กออกได้ (เช่น ไม่มีหางซิป) · `on` = ติ๊กไว้ก่อน
- ตั้งชุดที่ปุ่ม 🔗 ของแต่ละรายการ (สูงสุด 10 ตัว)

## ไฟล์
- หน้าจอ `components/parts-cart-modal` · สูตร `lib/parts-cart` (เทสต์ `lib/__tests__/parts-cart.test.ts`)
- อ่านรายการ: `GET /api/design-sheets/price-items` (ส่ง `set_items` มาด้วย · ไม่มีสิทธิ์ดูต้นทุน = ว่าง)
- เขียน: `/api/master-v2/design-price-items[/id]` (ด่านสิทธิ์ + audit ของกลาง)
- เงินคิดด้วย `lib/design-sheet-cost-row` ตัวเดียวกับตาราง — ห้ามเขียนสูตรซ้ำ

## ห้ามใช้เมื่อ
- วัสดุชิ้นตัด/ผ้าที่มีขนาด → ช่องวัสดุในตาราง / `MaterialAddSelect`
- ซิปตามขอบบนกระดานแพทเทิร์น → `TrimsModal`

## ข้อจำกัด
- หน้ามือถือ (`components/design-sheet-mobile`) ยังไม่มีปุ่มนี้
- การ์ดยังไม่มีรูปจริง (ถ้าจะเพิ่มต้องเพิ่มช่องรูปให้วัสดุตีราคา)
