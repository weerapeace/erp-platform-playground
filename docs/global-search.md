# Global Search (Ctrl+K / ⌘K) — ค้นข้ามโมดูล

กล่องค้นหากลางที่เปิดได้จากทุกหน้า (ปุ่ม 🔍 ในแถบซ้าย หรือกด `Ctrl+K`)
โค้ด: `components/global-search/index.tsx` (UI) + `app/api/global-search/route.ts` (API)

ข้อมูลธุรกิจทุกชนิดใช้ **ทะเบียนแหล่งค้น `SOURCES`** ใน route เดียวกัน (1 แถว = 1 ชนิด: ตาราง/คอลัมน์/สิทธิ์/ลิงก์) — เพิ่มชนิดใหม่ = เพิ่ม 1 แถว ไม่ต้องแตะ UI
ตัวจัดอันดับ = ของกลาง `lib/search-score.ts` (tokenize → token-AND ที่ DB ดึงผู้สมัคร 40 → scoreRow: รหัสตรงเป๊ะ 1,000,000 → ขึ้นต้น → มีคำ → ชื่อ) มาตรฐานเดียวกับ picker ทั้งระบบ

กติกาการจับคู่หน้า/คู่มือ: ตัดคำค้นด้วยเว้นวรรค **ทุกคำต้องเจอ** (AND) · ไม่สนตัวพิมพ์เล็ก/ใหญ่
คะแนน (มาก = ขึ้นก่อน): ชื่อขึ้นต้นด้วยคำค้น 100 → ชื่อมีคำค้น 85 → คำค้นเพิ่มตรงเป๊ะ 80 → คำค้นเพิ่มบางส่วน 70 → หมวด/ชื่อแอป 40 → ลิงก์ 30

## "คำค้นเพิ่ม" (คำพ้อง) — ให้คนพิมพ์คำที่นึกออกแล้วเจอหน้า

ปัญหา: ชื่อเมนูกับคำที่คนนึกออกไม่ตรงกัน เช่น อยากตั้ง "ค่าส่ง" แต่เมนูชื่อ "ร้านขนส่ง / เรทค่าส่ง" หรือ "ใบสำคัญรับ (ใบซื้อ)"

วิธีแก้: ไปที่ **⚙️ Settings → จัดการเมนู** กด `⋯` ที่เมนูนั้น → ช่อง **🔍 คำค้นเพิ่ม** พิมพ์คำคั่นด้วยลูกน้ำ เช่น `ค่าส่ง, ขนส่ง, shipping` → กดบันทึก
เก็บที่คอลัมน์ `erp_menu_items.search_keywords text[]` · เมื่อเจอผ่านคำพ้อง ผลค้นจะบอกว่า `ตรงกับคำค้น "ค่าส่ง"`

## ⚡ คำสั่งลัด + ⏱ เพิ่งเปิดล่าสุด (ก้อนที่ 3)

- **คำสั่งลัด**: พิมพ์กริยา + ชื่อเอกสาร เช่น `สร้าง PO` `เพิ่ม SKU` `เปิดใบขายใหม่` → กลุ่ม "⚡ คำสั่งลัด" ขึ้นบนสุด กด ↵ เด้งไปหน้านั้น **พร้อมเปิดฟอร์มสร้างใหม่ทันที**
  - ทะเบียนอยู่ที่ `lib/search-commands.ts` (`COMMANDS` 1 แถว = 1 คำสั่ง: ป้าย/คำพ้อง/ลิงก์/สิทธิ์สร้าง) จับคู่ฝั่งเครื่องทันทีไม่รอ API · เห็นเฉพาะคนมีสิทธิ์สร้างของโมดูลนั้น
  - หน้าปลายทางรับ `?new=1` ผ่านของกลาง **`useNewParam(ready, openCreate)`** ใน `lib/open-param.ts` (คู่กับ `useOpenParam` เดิม) — ใส่แล้วที่ MasterCRUD (ทุกหน้า /master/* และ /m/*), คู่ค้า, PO list, MO, ใบขาย, ใบเสนอราคา, ใบวางบิล, ใบส่งสินค้า, ใบลดหนี้, งาน Creative
  - หน้าใหม่ที่มีปุ่ม "สร้าง" ให้เพิ่ม 1 บรรทัด `useNewParam(canCreate, openCreate)` แล้วเพิ่มคำสั่งใน `COMMANDS`
- **เพิ่งเปิดล่าสุด**: เปิดกล่องค้นหาตอนยังไม่พิมพ์ → โชว์ 6 รายการที่เพิ่งกดเปิด (ทุกชนิด) กด ✕ เอาออกได้ · ใช้ของกลาง `lib/recent-picks` key `RECENT_KEYS.globalSearch` (เก็บในเครื่องผู้ใช้)

## 🎯 ค้นเฉพาะแอป (scope) — ใช้ตัวเดียวกันในแอปเดี่ยว

- แอปเดี่ยว (เช่น Payroll) ใช้ป๊อปอัปเดียวกัน แต่ "ค้นเฉพาะของแอปนั้น": `<GlobalSearch scope="payroll" />` + API รับ `?scope=payroll`
- ทะเบียน scope = `lib/search-scopes.ts` (1 แถว/แอป): แอปที่เมนูต้องสังกัด (`appKey`/`hrefPrefix`), ชนิดข้อมูลที่ค้น (`entities`), คำกรองคู่มือ, placeholder, **วิธีค้นหา (tips)** และปุ่มตัวอย่าง
- ในป๊อปอัปมีปุ่ม **❓ วิธีค้นหา** (มุมขวาช่องพิมพ์) กางคำแนะนำว่าพิมพ์อะไรได้บ้าง กดตัวอย่างแล้วค้นให้เลย · ตอนยังไม่พิมพ์ก็มีปุ่มตัวอย่างคำค้น
- คำสั่งลัดใส่ `scope: "payroll"` ใน `COMMANDS` → ค้นในแอปเห็นเฉพาะคำสั่งของแอป · ค้นรวมเห็นทุกคำสั่ง
- ชนิดข้อมูลที่โชว์เฉพาะตอนค้นในแอป (`SCOPE_ONLY_ENTITIES`): 📄 สัญญาจ้าง (เลขที่สัญญา → `/payroll/contracts?open=`), 📅 งวดเงินเดือน (ชื่องวด → `/payroll/manual-input?period_id=`) · พนักงานตอนค้นในแอปรวมคนลาออก/ปิดใช้งาน (มีป้าย 🔴/⚪) ค้นรวมยังเฉพาะคนทำงานอยู่
- เพิ่มแอปใหม่ = เพิ่ม 1 แถวใน `SEARCH_SCOPES` + ใส่ปุ่ม 🔍/Ctrl+K ในเปลือกแอปนั้น (ดู `components/payroll/payroll-shell.tsx`)

## ข้อจำกัด / สิ่งที่ยังไม่ทำ

- ค้นหน้า/คู่มือเป็นแบบ "มีคำนี้อยู่ไหม" ยังไม่ใช่ pg_trgm — ตารางเล็ก (~200 เมนู, ไม่กี่คู่มือ) จึงพอ; ทะเบียนเมนูแคชในหน่วยความจำ 60 วิ (แก้เมนูแล้วอาจต้องรอ 1 นาที)
- ทุกครั้งที่พิมพ์ยิง ~13 query พร้อมกัน (เฉพาะโมดูลที่มีสิทธิ์) — ตารางใหญ่ (skus_v2, partners_v2) มี trgm index แล้ว ตารางอื่น <400 แถว · ถ้าตารางไหนโตเกินพันแถวให้เพิ่ม `gin (col gin_trgm_ops)`
- ใบเสนอราคายังเปิดใบตรงไม่ได้ (หน้า /quotations เป็นแถวกางในตาราง ไม่มี `?open=`) · MO ที่เสร็จแล้วไปหน้ารายการเฉย ๆ (บอร์ดไม่โชว์ใบเสร็จ)
- RPC เดิม `erp_global_search` (ตาราง playground) เลิกใช้แล้ว — ลบทิ้งใน DB ได้เมื่อสะดวก
- คำสั่งลัดยังเป็นแค่ "สร้างเอกสารใหม่ / ไปหน้า" — ยังไม่มีคำสั่งที่ทำงานเอง (เช่น "ยืนยัน PO เลขนี้") · "เพิ่งเปิดล่าสุด" เก็บต่อเครื่อง ไม่ซิงก์ข้ามเครื่อง
- คู่มือมีแค่ที่คนเขียนไว้ (ตอนนี้ 5 เรื่อง เรื่องคลังไฟล์ทั้งหมด) — เพิ่มได้ที่ `/master/help-guides`
