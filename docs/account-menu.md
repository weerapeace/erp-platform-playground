# เมนูโปรไฟล์ (AccountMenu) — ของกลาง

ไฟล์: `components/account-menu.tsx` · ทะเบียนของกลาง key `account-menu`

## ใช้ทำอะไร

กดรูปหรือชื่อผู้ใช้แล้วเปิดเมนูจัดการบัญชี **ชุดเดียวกันทุกที่ในระบบ**
(เจ้าของสั่งรวมเมื่อ 2026-11-14 · เดิมการ์ดชื่อในแถบข้างมีเมนูแยกของตัวเอง สั้นกว่าและต่างกัน)

รายการในเมนู เรียงเป็นหมวด:

| หมวด | รายการ |
|---|---|
| (บนสุด) | อีเมล · มุมมองหน้านี้ (เฉพาะหน้าที่ลงทะเบียน) · Dashboard ของฉัน |
| บัญชีของฉัน | โปรไฟล์ (ป๊อป) · เปลี่ยนรหัสผ่าน/PIN · ความปลอดภัย (ป๊อป) · ผูก Discord |
| หน้าตา | สีธีมส่วนตัว · ภาษา TH/EN · คีย์ลัด (ซ่อนบนมือถือ) |
| การแจ้งเตือน | ป๊อปเตือนงาน (`WorkPopupFloatToggle`) · เด้งที่เบราว์เซอร์นี้ (`BrowserPushToggle`) |
| อุปกรณ์และแอป | ติดตั้งแอปบนเครื่อง — หรือในโหมดแอป: มุมมองอุปกรณ์ + ติดตั้งแล้ว + QR |
| ผู้ดูแลระบบ | นับถอยหลังขึ้นเว็บ (เฉพาะสิทธิ์ `admin.users`) |
| (ล่างสุด) | ออกจากระบบ |

## ต่างกันตามที่ / ตามสิทธิ์ (เท่านั้น)

- **Dashboard ของฉัน** ซ่อนในโหมดแอป (`onDark`) เพราะกดแล้วจะหลุดออกจากแอป
- **มุมมองอุปกรณ์ + QR** เฉพาะเมื่อเปลือกส่ง `device` มา (โหมดแอป `/app/<key>`) · ที่อื่นเห็นแถว "ติดตั้งแอปบนเครื่อง" แทน
- **นับถอยหลังขึ้นเว็บ** เฉพาะผู้มีสิทธิ์ `admin.users`
- **มุมมองหน้านี้** โผล่เฉพาะหน้าที่ลงทะเบียนผ่าน `usePageChrome` (เช่น บอร์ดจ่ายงาน)

## ใช้ที่ไหน

| เปลือก | วิธีเรียก |
|---|---|
| เชลล์แอปเดี่ยว `app/app/[appKey]/page.tsx` (แถบบนสีเข้ม) | `<AccountMenu onDark device={…} />` |
| แอปแยก `components/standalone-shell.tsx` (/tasks, /goals) | `<AccountMenu />` |
| เปลือกหลัก แถบบนจอเล็ก `components/playground-shell.tsx` | `<AccountMenu compact />` |
| เปลือกหลัก การ์ดชื่อล่างแถบข้าง (`UserSwitcher`) | `<AccountMenu placement="sidebar" collapsed={…} sync={false} />` |

## ค่าที่สำคัญ

- `placement` — `"topbar"` (ค่าเริ่ม: ปุ่มรูป+ชื่อ เมนูเลื่อนลงชิดขวา) · `"sidebar"` (การ์ดชื่อ เมนูเด้งขึ้น)
  - แบบแถบข้าง: เมนูวาดที่ `document.body` เพราะแถบข้างตัดของที่ล้นออก · กว้าง 288px เท่าแถบบน · สูงไม่เกินจอ เลื่อนในเมนูได้
  - z-index = 50 เท่าป๊อปกลาง: ป๊อปที่เปิดจากในเมนู (เช่น "เปลี่ยน" ตัว Pet) เปิดทีหลังจึงอยู่บนเมนู
- `collapsed` — แถบข้างพับ การ์ดเหลือแค่รูป (เมนูยังกว้างเต็ม)
- `compact` — แถบบนจอเล็ก โชว์แค่รูป
- `onDark` — แถบบนสีเข้ม (โหมดแอป)
- `device` — ส่งจากเชลล์แอปเดี่ยวเท่านั้น
- `sync` — ฝัง `ThemeSync` (โหลด/บันทึกสีธีมกับบัญชี) · หน้าเดียวกันมี 2 ตัว ให้ตัวที่ 2 ใส่ `sync={false}`
  - เปลือกหลักฝัง `LangSync` (ภาษาต่อบัญชี) ไว้ข้างการ์ดชื่อเหมือนเดิม

## ห้ามใช้เมื่อไหร่

- อย่าเขียนเมนูโปรไฟล์ / ปุ่มออกจากระบบแยกในเปลือกใหม่ — ใช้ตัวนี้
- จะเพิ่มแถวตั้งค่าส่วนตัว → เพิ่มในไฟล์นี้ที่เดียว ทุกที่ได้ตามอัตโนมัติ

## สิทธิ์ / ประวัติ

- แถว "นับถอยหลังขึ้นเว็บ" เช็กสิทธิ์ `admin.users` ด้วย `usePermission`
- ไม่มีการเขียนข้อมูลสำคัญที่ต้อง audit (ตั้งค่าส่วนตัวเท่านั้น)

## ข้อจำกัดที่รู้

- โปรไฟล์ และ เปลี่ยนรหัสผ่าน/PIN เปิดป๊อปเดียวกัน (`ProfileEditor`) — คง 2 แถวไว้ให้หาง่าย
- ปุ่มภาษา (`LangToggle`) สลับแล้วโหลดหน้าใหม่ เหมือนปุ่มบนแถบบน
