# ใบสั่งตัวอย่าง (Design Sheet) — หน้าพิมพ์ 2 รูปแบบ

หน้าพิมพ์ `/print/design-sheet/[id]` (ปุ่ม "🖨 ใบสั่งตัวอย่าง" ในป๊อปใบงาน) มีแถบ **"รูปแบบใบ"** ด้านบน (ไม่ติดไปกับกระดาษ) สลับได้ก่อนกดพิมพ์

| รูปแบบ | หน้าตา | ใช้เมื่อ |
|---|---|---|
| 📄 แบบปกติ | รูปหลักใหญ่ (เลือกได้ ≤4) · ตาราง Comment ลูกค้า รูปประกอบจิ๋ว | สั่งตัวอย่างรอบแรก เน้นแบบ |
| 💬 เน้น Comment ลูกค้า | รูปหลักย่อเล็กข้างรายละเอียดงาน · comment เป็นการ์ด + รูปแนบใหญ่ | ส่งแก้ตามที่ลูกค้าคอมเมนต์ |

## โหมดเน้น Comment ลูกค้า
- แผง **"💬 เลือก Comment และรูปแนบที่จะพิมพ์"**: ติ๊กออก = ไม่พิมพ์ comment นั้น · กดที่รูป = เลือก/เอาออกทีละรูป · ปุ่ม "ทุกรูป / ไม่เอารูป" ต่อ comment
- ค่าเริ่มต้น = พิมพ์ครบทุก comment ทุกรูป · เลข #1 #2 คงตามลำดับในใบงาน (ตัดบางข้อออก เลขที่เหลือไม่เลื่อน)
- ขนาดรูปใน comment: ใหญ่ (1 รูป/แถว สูงสุด 150 มม.) · กลาง (2 รูป/แถว 85 มม.) · เล็ก (3 รูป/แถว 60 มม.)
- หัวใบ/ช่องเซ็นท้ายใบ/CSS ยืมจากเทมเพลตตัวหลัก (`erp_report_templates` entity `design_sheet`) → แก้หัวใบที่เดียวได้ทั้งสองรูปแบบ
- อยากปรับหน้าตาโหมดนี้เองทั้งใบ: เพิ่มเทมเพลต entity `design_sheet` `template_key='comment_focus'` → หน้าพิมพ์ใช้ตัวนั้นแทน
  token เพิ่มจากแบบปกติ: `{{{main_thumbs_html}}}` (รูปหลักย่อ) · `{{{comment_cards_html}}}` (การ์ด comment ที่เลือก)

## จำค่าอะไรไว้
- **รูปแบบใบ + ขนาดรูป** จำต่อคน (`user_ui_prefs` key `ds_print_mode` / `ds_print_comment_cols` ผ่าน `useViewPref`) — เปิดครั้งหน้าได้แบบที่ใช้ล่าสุด
- **รูป/comment ที่ติ๊ก** ไม่จำ (เหมือนแถบเลือกรูปหลัก) — เปิดใหม่กลับเป็นค่าเริ่มต้น

## ใบตีราคาต้นทุน — ตั้งค่าได้ (2026-11-11)

หน้าพิมพ์ `/print/design-sheet-cost/[id]` = พรีวิวซ้าย + แผง **"ตั้งค่าการพิมพ์"** ขวา (ของกลาง `DocPrintPanel` · ตัวเดียวกับใบวางบิล)

- **ตัวเลือกของใบนี้** (`DOC_OPTIONS.design_sheet_cost` ใน `lib/doc-print-prefs`): รายการวัตถุดิบ ทุกบรรทัด / รวมตามวัสดุ / รวมตามชนิด / ไม่โชว์ตาราง · สรุปแยกตามชนิด · ค่าแรง (+ รายละเอียด วัสดุ × ชิ้น × ราคาตัด) · ค่าโสหุ้ย (+ รายละเอียด แพ็ค/QC/ถุง/ค่าส่ง) · ต้นทุนอื่น ๆ · ช่องเซ็น
  - ซ่อนหมวดไหน = ยอดรวมไม่นับหมวดนั้น และหัวข้อเปลี่ยนเป็น "ต้นทุนรวม (ไม่รวม…)" กันเข้าใจผิด
  - รายละเอียดค่าแรงตัด/โสหุ้ย คิดจากราคากลาง **ตอนพิมพ์** (สูตรกลาง `lib/design-cost-presets`) — รวมไม่ตรงยอดที่บันทึก = มีหมายเหตุบอก ยอดจริงคือที่บันทึกไว้
- **คอลัมน์**: เปิด/ปิด · ชื่อหัว · ลำดับ · ความกว้าง มม. (ลากขอบหัวบนกระดาษได้) — วัสดุ / รวม ปิดไม่ได้
- ไม่กดบันทึก = ใช้กับใบนี้ · **บันทึกเป็นค่าเริ่มต้น** = ทุกคน (`ui_config doc_print_design_sheet_cost` · สิทธิ์ products.edit)
