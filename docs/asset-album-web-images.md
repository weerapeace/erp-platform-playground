# 🌐 รูปบนเว็บ ในอัลบั้มสินค้า (คลังไฟล์)

> รูปที่ลงเว็บร้าน อยู่ในโฟลเดอร์ของรุ่นนั้นในคลังไฟล์ → ค้นรหัสรุ่นแล้วเจอครบ · คลังรู้ว่ารูปไหน "ใช้อยู่ที่เว็บ" (กันลบ)

## ใช้ทำอะไร

เดิมรูปที่อัปผ่านหน้า Parent SKU → แท็บเว็บไซต์ (แถวสี "SKU ในรุ่นนี้", "รูปบนเว็บ", Hero, แบนเนอร์, ลงรูปทีละมาก)
เก็บในหน้าขายบนเว็บ (`store_listings`) อย่างเดียว — ชื่อไฟล์เป็น `1.jpg` ค้นไม่เจอ และไม่อยู่ในอัลบั้มของรุ่น

## เฟส 1 — โฟลเดอร์ 🌐 รูปบนเว็บ

คลังไฟล์ → ดูตามแบรนด์ → Parent SKU → **🌐 รูปบนเว็บ** แยก **ร้าน → โฟลเดอร์**:
รูปบนเว็บ (รุ่น) · รูปเปิด (Hero) · แต่ละสี (รหัส · ชื่อสี) · แบนเนอร์

- อ่านตรงจากหน้าขายบนเว็บทุกครั้ง (ไม่ก๊อปไฟล์ ไม่ sync) — ลงเว็บแล้วกดบันทึก = โผล่เอง · เอาออกจากเว็บ = หายจากโฟลเดอร์ (ไฟล์ยังอยู่คลัง)
- ป้ายในรายการรุ่น `🌐 เว็บ N` · รุ่นที่มีแต่รูปเว็บก็โผล่ในรายการ · ยอดแบรนด์นับรวม
- ดาวน์โหลด zip ของรุ่น รวม `Web_<ร้าน>/<โฟลเดอร์>/`
- วิดีโอ Hero ไม่โชว์ในโฟลเดอร์ (รูปปกวิดีโอโชว์)

| ส่วน | ไฟล์ |
|---|---|
| ดึงทุกช่องรูปจาก 1 แถวหน้าขาย (ของกลาง · pure · มีเทสต์) | `lib/website-listing-images.ts` `listingImageSlots()` |
| โฟลเดอร์ของรุ่น | `lib/brand-album-web.ts` `webAlbumForParent()` → `GET /api/assets/brand-tree?mode=parent` (`web`) |
| ตัวนับในฐานข้อมูล | `erp_store_listing_image_keys()` + `erp_artwork_parents` (`web_img`) + `erp_artwork_brands` — migration `202611011500` · **ต้องนับแบบเดียวกับ listingImageSlots** |
| หน้าจอ | `components/asset-library/brand-album.tsx` |

## เฟส 2 — "ใช้อยู่ที่เว็บ"

ทุกครั้งที่บันทึกรูปหน้าขายบนเว็บ → `syncStoreListingUsages(sb, [{ shopId, parentId }])` (`lib/store-listing-usage.ts`)
เขียน `asset_usages` module **`store_listing`**: `record_id` = parent_sku_id · `field` = `<shopId>:<folder>[:<skuId>]` · `record_label` = `เว็บ Louis Montini · TTM114-01`

- ผล: การ์ดไฟล์ในคลังขึ้น "ใช้อยู่ N ที่" + ลบไม่ได้จนกว่าจะเอาออกจากเว็บ · ป๊อปรูปซ้ำโชว์ที่ใช้จากป้ายนี้
- จุดที่เรียก: `/api/parent-web-listings` (บันทึก) · `/api/website/listings` (บันทึก · เอาออกจากร้าน = ล้าง) · `/api/website/listings/images` (ลงรูปทีละมาก) · `lib/website-listing-undo` (ย้อนกลับ)
- **เพิ่มทางบันทึกรูปหน้าขายใหม่ → ต้องเรียก `syncStoreListingUsages` ด้วย**
- พังไม่ทำให้การบันทึกหน้าเว็บพัง (log `[store-listing-usage]`)
- รูปที่ไม่อยู่ในคลัง (key เก่าที่ไม่ได้นำเข้า) บันทึกไม่ได้ — ข้าม

### เติมย้อนหลัง

```bash
node scripts/backfill-store-listing-usages.mjs                 # ดูตัวเลขอย่างเดียว
node scripts/backfill-store-listing-usages.mjs --apply         # เขียนจริง (รันซ้ำได้)
node scripts/backfill-store-listing-usages.mjs --album TTM114  # ดูโฟลเดอร์ของรุ่น (อ่านอย่างเดียว)
```

## ข้อจำกัด

- ⚠️ ค้นรูปในคลังด้วย `.in("r2_key", …)` ทีละ ≤ 50 key — ทีละ 200 ทำให้ URL ยาวเกิน คำขอพังเงียบ (เคยเจอตอนทำเฟสนี้)
- ค้นชื่อไฟล์ในคลังด้วยรหัสรุ่นยังไม่เจอรูปเว็บ (ชื่อไฟล์ยังเป็น 1.jpg) — ค้นแล้วกดโฟลเดอร์รุ่นแทน
