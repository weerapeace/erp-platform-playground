# ตัวเลือกหน้าใน ERP (MenuPagePickerModal)

> ป๊อปเลือก "หน้าในระบบ" จากเมนูจริง — ผู้ใช้ไม่ต้องพิมพ์ลิงก์เอง
> โค้ด: `components/menu-page-picker` · ตรรกะล้วน + เทสต์: `lib/menu-pages.ts`, `lib/__tests__/menu-pages.test.ts`
> เพิ่มเมื่อ 2026-11-13 — เจ้าของอยากให้แผนผังการเก็บไฟล์บอกได้ว่า "หาไฟล์ได้จากหน้าไหนใน ERP"

## ใช้ทำอะไร

- ให้ผู้ใช้ชี้ไปหน้าใดหน้าหนึ่งในระบบ เช่น กล่อง **"หน้าใน ERP"** ในกระดาน flowchart (`components/flowchart-board`)
- รายการมาจากเมนูกลาง `erp_menu_items` + `erp_app_groups` ผ่าน `GET /api/menu` + `GET /api/menu/apps` (ใช้แคชเดียวกับแถบเมนู `lib/shell-cache` → เปิดป๊อปแทบไม่ยิงเน็ตเพิ่ม)
- จัดกลุ่มตามแอป (ลำดับเดียวกับแอปบนสุด) · ในแอปเรียงตามลำดับเมนูของแอปนั้น · ชื่อเมนูเฉพาะแอป (`app_overrides.label`) ใช้ตามแอป
- หน้าที่อยู่หลายแอป → โผล่ทุกแอป · เลือกจากแอปไหน ได้ชื่อแอปนั้น (เช่น Design Dashboard อยู่ทั้ง "ออกแบบ" และ "จัดการงาน")
- หน้าที่ไม่อยู่แอปไหน → กลุ่ม "ไม่อยู่ในแอปไหน" ท้ายสุด · เมนูที่ปิดทั้งระบบ (`is_active=false`) / ลิงก์นอกระบบ → ไม่โชว์

## ห้ามใช้เมื่อไหร่

- **เพิ่ม/เอาเมนูออกจากแอป** → แท็บ "เมนูและคนเห็น" ใน ⚙️ ตั้งค่าแอป (`components/app-settings-panel/menus-tab.tsx`) — ตัวเลือกในนั้นทำงานคนละแบบ (เติมเมนูเข้าแอป + สร้างลิงก์ใหม่ + บอกว่าอยู่แอปไหนแล้ว)
- ลิงก์ออกนอกระบบ (เว็บอื่น) → ช่องลิงก์ธรรมดา

## วิธีใช้

```tsx
import { MenuPagePickerModal, useMenuPages } from "@/components/menu-page-picker";

<MenuPagePickerModal
  open={open}
  onClose={() => setOpen(false)}
  current={{ href: box.href, app: box.app }}   // ไฮไลต์ "เลือกอยู่" (ไม่ส่งก็ได้)
  onPick={(p) => save({ href: p.href, app: p.app, appName: p.appName, label: p.label, icon: p.icon })}
/>

// เช็กว่าหน้ายังอยู่ในเมนูไหม / ชื่อแอปล่าสุด (โหลดเฉพาะตอน enabled = true)
const menu = useMenuPages(hasPageBox);
const now = menu.status === "ready" ? findMenuPage(menu.menus, menu.apps, href, app) : null;   // null = ไม่อยู่ในเมนูแล้ว
```

`p` = `{ href, label, icon, app, appName, appIcon }` — `app = ""` แปลว่าหน้านี้ไม่อยู่แอปไหน

## ตรรกะล้วน (`lib/menu-pages.ts`)

| ตัว | ทำอะไร |
|---|---|
| `menuPageGroups(menus, apps, query?)` | หน้าทั้งหมดจัดกลุ่มตามแอป + ค้น (ชื่อหน้า · ลิงก์ · ชื่อแอป · ไม่สนตัวพิมพ์) |
| `findMenuPage(menus, apps, href, app?)` | หาหน้าตามลิงก์ (แอปที่เลือกไม่มีแล้ว = แอปแรกที่อยู่ · ไม่อยู่ในเมนู = null) |
| `isErpPageHref(v)` | ลิงก์หน้าในระบบเท่านั้น: ขึ้นต้น `/` (ไม่ใช่ `//`) · ไม่มีช่องว่าง/แบ็กสแลช · ≤ 300 ตัว — กันลิงก์แปลก/`javascript:` |
| `isAppKey(v)` | รหัสแอป (ตัวเล็ก ตัวเลข ขีด) |

## สิทธิ์ / ประวัติ

- **ไม่กรองตามสิทธิ์**: โชว์ทุกหน้าที่เปิดอยู่ในเมนู — หน้าปลายทางตรวจสิทธิ์เองตอนเปิด (คนไม่มีสิทธิ์เห็นหน้าแจ้งไม่มีสิทธิ์ตามปกติ)
- ตัวเลือกอ่านอย่างเดียว ไม่เขียนข้อมูล → ไม่มี audit ของตัวเอง (ที่ที่เอาไปใช้บันทึกเอง เช่น กระดาน flowchart บันทึกผ่าน `/api/canvas-sketch` ซึ่งเขียน audit `canvas_update`)

## ข้อจำกัด

- ยังไม่กรองตาม "ใครเห็นเมนู" (`audience`) — ถ้าอยากให้ซ่อนหน้าที่คนนั้นไม่เห็น ใช้ `menuVisibleTo` (`lib/menu-audience`) เพิ่มทีหลังได้
- หน้าลึก ๆ ที่ไม่มีในเมนู (เช่น หน้ารายละเอียดรายการ) เลือกไม่ได้ — ตั้งใจ (ชี้ได้เฉพาะหน้าที่คนหาเจอจากเมนู)
