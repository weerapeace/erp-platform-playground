# 🔥 เทรนด์ (Creative Trends)

> ที่เก็บ "เทรนด์" ของทีม Creative — 1 เทรนด์ = กระดานวาด 1 หน้า (16:9) + เช็คลิสต์ว่าเทรนด์นั้นต้องมีอะไรบ้าง
> อยู่ข้าง ๆ 📚 คลังความรู้ ในแอปงาน (`/tasks` → ทางลัด 🔥 เทรนด์ → `/tasks/trends`)

## ใช้ทำอะไร

- เก็บ **โทนสี · ภาพอ้างอิง · เลย์เอาต์แบนเนอร์ · ฟอนต์ · ข้อความ** ของเทรนด์หนึ่ง ไว้ในหน้าเดียว
- ใครจะทำงานตามเทรนด์นั้น เปิดหน้าเดียวเห็นครบ ไม่ต้องไล่ถาม
- ส่งเทรนด์ขึ้น **กระดานแคมเปญ** เป็นการ์ดได้ (ทีมวางแผนงานเห็นภาพเดียวกัน)

## กระดาน "หน้าจำกัด"

- กระดานเปล่าครั้งแรก ระบบวาง **frame 16:9 ขนาด 1600×900** ชื่อ *หน้าเทรนด์ · 16:9* ให้อัตโนมัติ
  พร้อมช่องแนะนำแบบเส้นประ 4 ช่อง: 🎨 โทนสี · 🖼 ภาพอ้างอิง · 📐 เลย์เอาต์แบนเนอร์ · 💬 ข้อความ+ฟอนต์
- ลบ/ย้าย/เขียนทับได้ตามใจ · อยากได้กรอบใหม่กดปุ่ม **🖼 วางกรอบหน้า**
- ภาพถ่ายกระดาน (PNG ที่ `CanvasSketch` เซฟลง R2 อัตโนมัติ) = **รูปปกของเทรนด์** ทั้งในหน้ารายการและบนการ์ดกระดานแคมเปญ

## เช็คลิสต์ "สิ่งที่ต้องมีในเทรนด์"

- นิยามอยู่ที่ `TREND_CHECKLIST` (`lib/creative-trends-meta.ts`) — ปัจจุบัน 16 ข้อ, ข้อที่ `core: true` = "ควรมี"
- **เตือนอย่างเดียว ไม่บล็อก** — ยังไม่ครบก็ใช้งาน/ส่งขึ้นกระดานแคมเปญได้ แค่ขึ้นแถบเตือนสีส้ม
- แต่ละข้อติ๊กได้ + ใส่โน้ต/ลิงก์สั้น ๆ · เก็บใน `erp_creative_trends.checklist` เป็น `{ key: { done, note } }`
- % ความครบคิดจาก `trendProgress()` ใช้ทั้งการ์ดในหน้ารายการ แถบบนบอร์ด และการ์ดบนกระดานแคมเปญ

เพิ่ม/แก้ข้อในเช็คลิสต์ = แก้ `TREND_CHECKLIST` ที่เดียว (ทุกที่เปลี่ยนตาม)

## ส่งขึ้นกระดานแคมเปญ

ใช้ของกลาง `CampaignBoardPicker` ตัวเดียวกับใบงานออกแบบ:

```tsx
<CampaignBoardPicker open={open} onClose={close} trendIds={[trend.id]} />
```

→ พาไป `/tasks/campaigns/<id>?add_trends=<ids>` แล้วหน้ากระดานวางการ์ดเอง (ไม่เขียน scene ข้ามหน้า กันชนกับคนที่เปิดกระดานค้างอยู่)
การ์ดเทรนด์บนกระดาน = รูปหน้าเทรนด์ + ชื่อ + ความแรง + % ความครบ · **ดับเบิลคลิก = เปิดบอร์ดเทรนด์ในแท็บใหม่** · เปิดกระดานใหม่ทีไรการ์ดซิงค์รูป/% ให้เอง

## ข้อควรรู้

- เทรนด์ที่ "เก็บเข้ากรุ" (`is_active=false`) กระดานยังอยู่ครบ — ติ๊ก *รวมที่เก็บเข้ากรุ* ในหน้ารายการเพื่อดู
- ยังไม่มีการเตือนอัตโนมัติเมื่อเทรนด์หมดอายุ (`end_date` เลยวันนี้) — ตอนนี้ดูเองจากป้ายความแรง
