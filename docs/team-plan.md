# 📋 แผนงานทีม (Todo ตามความด่วน)

เจ้าของขอ 2026-11-01: "ระบบวางแผนงาน เหมือน Todo list จัดตามความสำคัญ งานด่วน/ไม่ด่วน + แจ้งเตือน"
หน้า **`/tasks/plan`** (เมนู "แผนงาน" ในแอปจัดการงาน)

## ใช้ทำอะไร
- งานที่ต้องทำของทีม ที่ไม่ใช่ใบงาน/สินค้า (เช่น สั่งผ้า, ถ่ายรูป, เตรียมคอนเทนต์, ประชุม)
- มอบงานให้คนในทีม → คนนั้นได้แจ้งเตือน (กระดิ่ง + มือถือ ถ้าเปิดรับ)

## หน้าตา
- **ตามความด่วน** 4 ช่อง: ด่วนมาก / ด่วน / ปกติ / ไม่ด่วน — ลากการ์ดข้ามช่อง = เปลี่ยนความด่วน
- **ตาราง 4 ช่อง** (สำคัญ × ด่วน): ทำเลย / นัดเวลาทำ / ให้คนอื่นช่วย / ไว้ทีหลัง — ลากเข้าช่อง = เปลี่ยนทั้งความด่วนและ "สำคัญ"
- **ทั้งทีม / ของฉัน** (ของฉัน = ผู้รับผิดชอบคือฉัน หรือไม่มีผู้รับผิดชอบแต่ฉันสร้าง) · จำมุมมองต่อคน (`user_ui_prefs` team_plan_view / team_plan_scope)
- ตัวกรอง: ⭐ งานหลักวันนี้ · รอคนอื่น · เกินกำหนด
- **⭐ งานหลักวันนี้**: ปักดาวได้สูงสุด 3 งานต่อคนต่อวัน (เกินวันแล้วดับเอง) · แถบด้านบนโชว์ของฉัน
- **รอคนอื่น**: ติ๊กในป๊อปแก้ + บอกว่ารออะไร → การ์ดขึ้น "รอ: … · N วัน"
- **ทำซ้ำ**: ทุก n วัน/สัปดาห์/เดือน — ติ๊กเสร็จแล้วระบบสร้างรอบถัดไปให้ (คงเวลาเดิม · ค้างนานข้ามไปรอบที่ยังไม่ถึง)
- **ลิงก์เรื่องเดิม** (`plan.source` — ภายในเว็บเท่านั้น) · เสร็จแล้ว 7 วันล่าสุดพับไว้ด้านล่าง

## ข้อมูล (ไม่มีตารางใหม่)
ตารางเช็กลิสต์กลาง `erp_record_tasks` · `module_key = "team_plan"` · `record_id = ""`
- คอลัมน์เดิม: title · description (โน้ต) · status (open/resolved) · priority (urgent/high/normal/low) · due_at · assigned_to · created_by
- `metadata.plan` = `{ important, star_date, waiting:{note,since}, repeat:{every,n}, remind, source:{label,href}, created_by_id }` (กฎ `normalizePlanMeta`)
- `metadata.links` = ลิงก์ (กฎเดิมของเช็กลิสต์กลาง)

## API
- `GET /api/team-plan` (tasks.view) — งานค้างทั้งหมด + เสร็จ 7 วัน
- `POST /api/team-plan` (tasks.create) — สร้าง · มอบคนอื่น = แจ้งเตือน `team_plan.assigned`
- `PATCH /api/team-plan/[id]` (tasks.edit) — แก้เฉพาะที่ส่ง · `star` ตรวจ 3 งาน/คน/วัน (409) · ติ๊กเสร็จงานทำซ้ำ → คืน `next`
- `DELETE /api/team-plan/[id]` — คนสร้าง หรือ tasks.delete
- ทุกครั้งเขียนประวัติ `audit_logs` (entity `record_task`)

## แจ้งเตือน (รอบ 2)
พ่วงกับตัวตั้งเวลาเดิม **`/api/cron/email-reports` (pg_cron ทุก 15 นาที)** → `runTeamPlanReminders` (ไม่มีตัวตั้งเวลา/ตารางใหม่)
| เรื่อง | เมื่อไหร่ | event_type |
|---|---|---|
| เตือนก่อนกำหนด | ตามที่ตั้งในงาน (ก่อน 1 ชม. / ก่อน 1 วัน / เช้าวันนั้น 9:00) · ครั้งเดียวต่อกำหนด | `team_plan.remind` |
| เลยกำหนด | ครั้งแรกที่เลย · ปกติ/ไม่ด่วน → เลื่อนเป็น "ด่วน" อัตโนมัติ (มีประวัติ) | `team_plan.overdue` |
| รอคนอื่นนาน | รอเกิน 2 วัน · ตามซ้ำทุก 2 วัน | `team_plan.waiting` |
| เลื่อนเตือนจากมือถือ | ถึงเวลาที่กดเลื่อน | `team_plan.snooze` |
| สรุปเช้า | 09:00–11:59 วันละครั้งต่อคน (มีงานหลัก/ครบวันนี้/เกินกำหนด) | `team_plan.summary` |
| มอบงาน | ทันที | `team_plan.assigned` |
- ผู้รับ = ผู้รับผิดชอบ (ไม่มี = คนสร้าง) · ส่งผ่าน `erp_notify` → กระดิ่ง + มือถือ (ประเภท "แผนงานทีม" ใน `lib/push-categories` ปิดได้ต่อคน)
- กันส่งซ้ำ: `metadata.plan_sent` (`remind_for` / `overdue_for` = กำหนดที่เตือนแล้ว · เปลี่ยนกำหนด = เตือนใหม่ · `waiting_on` · `snooze_until`/`snooze_sent`) · สรุปเช้ากันด้วยแจ้งเตือน `team_plan.summary` ของวันนั้น
- **ปุ่มบนแจ้งเตือนมือถือ** (อีก 1 ชม. / พรุ่งนี้เช้า / เสร็จแล้ว): `lib/push-server` ใส่ `actions` + รหัสลับ `act` (HMAC ผูกงาน+คน · 7 วัน · `signPlanAction`) → `public/notify-sw.js` ส่ง `POST /api/team-plan/push-action` · Android/คอมรองรับ · iPhone ยังไม่รองรับปุ่ม (กดแล้วเปิดแอปตามปกติ)

## ใส่แผนงานจากที่อื่น + AI แตกงาน (รอบ 3)
- **ปุ่ม "ใส่แผนงาน"** (ต้องมี tasks.create · ไม่มี = ไม่โชว์): ตั้งชื่อ/ความด่วน/กำหนด/ใคร/เตือน แล้วงานจะมี 🔗 ลิงก์กลับเรื่องเดิม (`plan.source` — รับเฉพาะลิงก์ในระบบที่ขึ้นต้น "/")
  | ที่ | ลิงก์กลับ |
  |---|---|
  | ป๊อปใบงานออกแบบ — หัวป๊อป + ทุก Comment ลูกค้า (ชื่องาน "แก้ตาม Comment: …") | `/master/design-dashboard?open=<id>` |
  | ตาราง SKU — ปุ่มรายแถว 📝 | `/master/skus?open=<id>` |
  | ตาราง Parent SKU — ปุ่มรายแถว 📝 | `/master/parent-skus?open=<id>` |
  | ป๊อปโพสต์คอนเทนต์ — เมนู ⋯ เพิ่มเติม | `/tasks/content-calendar?content=<id>` |
  เพิ่มที่ใหม่ = ใส่ `<AddToPlanButton title source />` (หรือคุม `<AddToPlanModal>` เองถ้าเป็นปุ่มรายแถว) — ห้ามทำป๊อปเพิ่มงานเอง
- **✨ AI แตกงาน** (ปุ่มข้างช่องเพิ่มงาน): วางแชท/โน้ตประชุม → `POST /api/team-plan/ai-split` (tasks.create + ai.caption · มีค่าใช้จ่ายต่อครั้ง · audit `ai_team_plan_split`) → AI แยกงาน เดาความด่วน/วันกำหนด/คน (จับคู่ชื่อจากรายชื่อทีมจริง ไม่เจอ = ให้ฉัน · วันที่ย้อนหลังถูกตัดทิ้ง) → **ยังไม่บันทึก** คนตรวจ/แก้/เอาติ๊กออกก่อน แล้วกด "เพิ่ม N งาน" (มีกำหนด = เตือนก่อน 1 ชม.)

## ปฏิทิน + แผนส่วนตัว + สรุปศุกร์ (รอบ 4)
- **📅 มุมมองปฏิทิน** (ปุ่มที่ 3 บนกระดาน · จำต่อคน): ของกลาง `ScheduleBoard` — ลากงานจากกล่อง "ยังไม่กำหนดวัน" / จากวันอื่น ไปวางบนวัน = ตั้งกำหนดวันนั้น (คงเวลาเดิม · ไม่มีเวลา = 18:00 — `dueOnDate`) · ลากกลับกล่อง = ไม่กำหนดวัน · กดชิปในวัน = เปิดป๊อปงาน · มือถือ/แท็บเล็ตตั้งวันด้วยช่อง 📅 ใต้การ์ด (ScheduleBoard ทำให้)
  - เปิดตรง: `/tasks/plan?view=calendar` (ไม่ทับค่าที่จำไว้) · **ปฏิทินรวม** (`/calendar`) มีแท็บ "📋 แผนงานทีม" (ฝัง embed=1 = ไม่มีหัวหน้า)
- **แผนส่วนตัว** (แดชบอร์ด → แผนงาน · `erp_plan_items`): งานแผนทีมที่ฉันรับผิดชอบโผล่ใน "กล่องงานเข้า" → ลากลง วันนี้/พรุ่งนี้/สัปดาห์นี้ ได้ · หรือกดในป๊อปงาน "ใส่แผนส่วนตัวของฉัน" · `source_type = task` + id งาน (ใส่ซ้ำไม่ได้) · ติ๊กเสร็จในแผนส่วนตัว **ไม่** ปิดงานในแผนทีม (เหมือนแหล่งอื่น)
- **📧 สรุปประจำสัปดาห์ทางอีเมล**: แหล่งข้อมูลอีเมลรายงาน `team_plan_weekly` (docs/email-reports.md) — ต้องสร้างรายงานที่ ตั้งค่า → อีเมลรายงาน → เพิ่มรายงาน → ข้อมูลที่ส่ง "สรุปแผนงานทีม (รายสัปดาห์)" (ตั้งศุกร์ 17:00 ให้เอง) → เลือกผู้รับ → เปิดใช้

## แท็บ "แผนงาน" ในศูนย์แจ้งเตือน (ตัว Pet) — 2026-11-11
- **งานของฉันเท่านั้น** (นิยามเดียวกับปุ่ม "ของฉัน") · ข้อมูล `GET /api/team-plan?mine=1` · กลุ่ม/คำพูด `lib/team-plan-pet` (pure + เทสต์ `lib/__tests__/team-plan-pet.test.ts`)
- กลุ่ม: เกินกำหนด → ครบวันนี้ → ถัดไป (7 วัน) → รอคนอื่น → ยังไม่ถึง/ไม่กำหนดวัน (พับ) · เสร็จวันนี้ (พับ) · แถบ "งานหลักวันนี้ x/3"
- ตัวเลขบนตัว Pet = เกินกำหนด + ครบวันนี้
- ปุ่ม: ติ๊กเสร็จ/เอากลับ · **เตือนอีก 1 ชม.** (กำหนดเดิม — `PATCH /api/team-plan/[id] { snooze: "1h" | "tomorrow" }` เขียน `plan_sent.snooze_until` ค่าเดียวกับปุ่มบนมือถือ `snoozeMetadata`) · เลื่อนไปพรุ่งนี้ (เวลาเดิม) · ดาวงานหลัก · เปิด (ป๊อปแก้งานเดิม วางนอกการ์ด) · เพิ่มงานด่วน (ของฉัน · ปกติ)
- **ตัว Pet พูด** (ฟองคำพูด · นาฬิกาในเครื่องเดินทุก 1 นาที ไม่ต้องรอถามเซิร์ฟเวอร์): เลยกำหนด · ถึงเวลาที่กดเลื่อนเตือนไว้ · ถึงเวลาเตือนตามที่ตั้งในงาน (`remindAt`) · มีคนมอบงานให้ (งานที่ขยับใน 24 ชม.) · สรุปเช้า 09:00–11:59 (`planMorningSummary`) — เปิดแท็บดู = เห็นแล้ว (จำ `fpet-plan-seen:<uid>`) · เคารพห้ามรบกวน
- เปิดแท็บนี้อยู่ → เรื่อง "แผนงานทีม" ในแท็บกระดิ่งของศูนย์ไม่ขึ้นซ้ำ (กระดิ่งบนแถบ + เด้งที่เครื่องเหมือนเดิม)
- เปิด-ปิด: ตั้งค่าการแจ้งเตือน → "แผนงานทีม: งานของฉัน" (key `plan` ใน lib/notify-sources) · จัดลำดับ/ซ่อนแท็บ = `CENTER_TABS` key `plan`
- โค้ด: `components/work-popup/plan-tab.tsx` (dynamic) · ต่อใน `components/work-popup/index.tsx`

## โน้ตแบบ bullet + เช็กลิสต์ในงาน — 2026-11-12
เจ้าของขอ "อยากได้ bullets lists และ checklists" (ดู widget แล้วสั่ง "ทำตามแบบเลย")
- **โน้ต** = กล่องพิมพ์จัดรูปแบบกลาง `RichTextEditor` แบบย่อ (bullet · ลำดับเลข · หนา · เอียง · พิมพ์ "- " ขึ้นต้นบรรทัด = bullet) เก็บเป็น HTML ใน `description` · โน้ตเก่า/ที่ AI แตกงานเป็นข้อความธรรมดา → `noteToHtml` แปลงตอนเปิด (บรรทัด "- " = bullet) · ที่โชว์เป็นข้อความ (ป้ายโน้ตบนการ์ด · อีเมลสรุปศุกร์) ใช้ `noteToText` (lib/rich-note) · ยาวสุด `PLAN_NOTE_MAX` 12,000
- **เช็กลิสต์ในงาน** = ของกลาง `RecordChecklist` ในป๊อปงาน (ติ๊ก/เพิ่ม/แก้/ลบ/ผู้รับผิดชอบรายข้อ/ลิงก์ — บันทึกทันทีทีละข้อ) · ข้อละ 1 แถว `erp_record_tasks` module_key `team_plan_check` record_id = id งาน (`TEAM_PLAN_CHECK` ใน lib/team-plan)
  - การ์ดบนกระดาน: ป้าย "เสร็จ 2/4" + แถบ (`RecordChecklistChip variant="progress"`) กดแล้วเด้งกล่องติ๊กได้เลย · แท็บแผนงานใน Pet โชว์ 2/4
  - ติ๊กครบทุกข้อ → ป๊อปถาม "ปิดงานนี้เลยไหม?" (ไม่ปิดเอง)
  - **แม่แบบหลายข้อ**: "บันทึกเป็นแม่แบบ" (ชื่อซ้ำ = บันทึกทับ) / "ใส่จากแม่แบบ…" (ข้อที่มีแล้วไม่เพิ่มซ้ำ) · เก็บที่ค่ากลาง erp_lookups ชนิด `team_plan_check_tpl` (metadata.items) · "จัดการแม่แบบ" = เปลี่ยนชื่อ/ลากเรียง/เอาออก · ข้อที่ใช้บ่อยรายข้อ = ชนิด `team_plan_check`
  - งานทำซ้ำ: รอบใหม่ได้เช็กลิสต์ชุดเดิม (ยังไม่ติ๊ก) · ลบงาน = ลบเช็กลิสต์ไปด้วย (รายการข้อเก็บในประวัติการลบ)
