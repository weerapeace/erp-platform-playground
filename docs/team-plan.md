# 📋 แผนงานทีม (Todo ตามความด่วน)

เจ้าของขอ 2026-11-01: "ระบบวางแผนงาน เหมือน Todo list จัดตามความสำคัญ งานด่วน/ไม่ด่วน + แจ้งเตือน"
หน้า **`/tasks/plan`** (เมนู "แผนงาน" ในแอปจัดการงาน)

## ใช้ทำอะไร
- งานที่ต้องทำของทีม ที่ไม่ใช่ใบงาน/สินค้า (เช่น สั่งผ้า, ถ่ายรูป, เตรียมคอนเทนต์, ประชุม)
- มอบงานให้คนในทีม → คนนั้นได้แจ้งเตือน (กระดิ่ง + มือถือ ถ้าเปิดรับ)

## หน้าตา
- **ตามความด่วน** 4 ช่อง: ด่วนมาก / ด่วน / ปกติ / ไม่ด่วน — ลากการ์ดข้ามช่อง = เปลี่ยนความด่วน
- **ตาราง 4 ช่อง** (สำคัญ × ด่วน): ทำเลย / นัดเวลาทำ / ให้คนอื่นช่วย / ไว้ทีหลัง — ลากเข้าช่อง = เปลี่ยนทั้งความด่วนและ "สำคัญ"
- **ทั้งทีม / ของฉัน** (ของฉัน = ผู้รับผิดชอบคือฉัน หรือไม่มีผู้รับผิดชอบแต่ฉันสร้าง) · จำมุมมองต่อคน (`user_ui_prefs` team_plan_view / team_plan_scope)
- ตัวกรอง: ⭐ งานหลักวันนี้ · รอคนอื่น · เกินกำหนด
- **⭐ งานหลักวันนี้**: ปักดาวได้สูงสุด 3 งานต่อคนต่อวัน (เกินวันแล้วดับเอง) · แถบด้านบนโชว์ของฉัน
- **รอคนอื่น**: ติ๊กในป๊อปแก้ + บอกว่ารออะไร → การ์ดขึ้น "รอ: … · N วัน"
- **ทำซ้ำ**: ทุก n วัน/สัปดาห์/เดือน — ติ๊กเสร็จแล้วระบบสร้างรอบถัดไปให้ (คงเวลาเดิม · ค้างนานข้ามไปรอบที่ยังไม่ถึง)
- **ลิงก์เรื่องเดิม** (`plan.source` — ภายในเว็บเท่านั้น) · เสร็จแล้ว 7 วันล่าสุดพับไว้ด้านล่าง

## ข้อมูล (ไม่มีตารางใหม่)
ตารางเช็กลิสต์กลาง `erp_record_tasks` · `module_key = "team_plan"` · `record_id = ""`
- คอลัมน์เดิม: title · description (โน้ต) · status (open/resolved) · priority (urgent/high/normal/low) · due_at · assigned_to · created_by
- `metadata.plan` = `{ important, star_date, waiting:{note,since}, repeat:{every,n}, remind, source:{label,href}, created_by_id }` (กฎ `normalizePlanMeta`)
- `metadata.links` = ลิงก์ (กฎเดิมของเช็กลิสต์กลาง)

## API
- `GET /api/team-plan` (tasks.view) — งานค้างทั้งหมด + เสร็จ 7 วัน
- `POST /api/team-plan` (tasks.create) — สร้าง · มอบคนอื่น = แจ้งเตือน `team_plan.assigned`
- `PATCH /api/team-plan/[id]` (tasks.edit) — แก้เฉพาะที่ส่ง · `star` ตรวจ 3 งาน/คน/วัน (409) · ติ๊กเสร็จงานทำซ้ำ → คืน `next`
- `DELETE /api/team-plan/[id]` — คนสร้าง หรือ tasks.delete
- ทุกครั้งเขียนประวัติ `audit_logs` (entity `record_task`)
