# ปรับของกลาง รอบพฤศจิกายน 2026 (เจ้าของเลือกจาก widget)

ทุกข้อ "เปิดเพิ่ม" — หน้าที่ใช้ของกลางอยู่แล้วหน้าตาเหมือนเดิม ยกเว้นข้อที่เจ้าของเลือกให้เปลี่ยนทั้งระบบ (โครงสีเทาตอนโหลด, ปุ่มคัดลอกในข้อความผิดพลาด, ปุ่มลัดวันที่)

## รอบ 1 (ต่อ) — ข้อเล็กชุดสอง

| ของกลาง | ความสามารถใหม่ | ใช้ยังไง | ปิดได้ |
|---|---|---|---|
| ลิ้นชัก MasterCRUD | ปุ่มลูกศร ← → = รายการก่อนหน้า/ถัดไปในลิสต์ที่แสดงอยู่ (ไม่ทำงานตอนพิมพ์ในช่อง / มีป๊อปซ้อน) | อัตโนมัติ (`lib/record-nav-keys`) | – |
| MasterCRUD | ปุ่ม "⧉ ทำสำเนา" ในลิ้นชัก (โหมดดู) — เปิดฟอร์มเพิ่มใหม่พร้อมค่าเดิม · รหัส/ช่องห้ามซ้ำ/ช่องคำนวณ/แท็ก เว้นว่าง · แจ้งว่าเว้นช่องไหน · ยังไม่บันทึกจนกดเอง · โชว์เมื่อมีสิทธิ์สร้าง | อัตโนมัติ (`lib/record-duplicate`) · โมดูลที่มีปุ่ม "คัดลอก" ของตัวเองอยู่แล้ว = ไม่โชว์ซ้ำ | `duplicate: false` · เว้นช่องเพิ่ม `duplicateExcludeKeys` |
| ตารางเล็ก MiniTable | ปุ่ม "⬇ Excel" — ส่งออกแถวที่เห็น (หรือที่ติ๊ก) · ตัดคอลัมน์ที่ไม่มีสิทธิ์ · บันทึกประวัติส่งออก | เปิดทีละหน้า: `exportOpts={{ filename: "stock", entityType: "sku_stock", permission: "products.export" }}` · คอลัมน์: `exportValue`, `noExport`, `exportPermission` | ไม่ใส่ exportOpts |
| ลากจัดลำดับ | แตะหูจับ ⠿ = เมนู ⤒ บนสุด / ↑ ขึ้น / ↓ ลง / ⤓ ล่างสุด (มือถือไม่ต้องลาก) | อัตโนมัติทุกจุดที่ใช้ `<DragHandle>` | `<DragHandle menu={false}>` |
| ชี้รูป HoverImage | หมุนล้อเมาส์บนรูปย่อ = ซูมรูปลอย 1–5 เท่า ตรงจุดที่ชี้ · หน่วงก่อนโชว์ ตั้งต่อคนที่เมนูโปรไฟล์ → หน้าตา → "ชี้รูป: หน่วงก่อนโชว์" (ทันที/0.2/0.4/0.7 วิ) | อัตโนมัติ · เฉพาะจุด `delay={300}` | `wheelZoom={false}` |
| SkuPicker | ยิงบาร์โค้ดเข้าช่องค้น — แป้นไทยเปิดอยู่ก็ได้รหัสถูก · ตรงเป๊ะตัวเดียว = เลือกให้เลย | อัตโนมัติ · ช่องค้นอื่นใช้ `useScanInBox(onScan)` (`components/scan-input/use-scan-in-box`) | – |
