# แท็บ "🏭 ผลิต" ของ Parent SKU

เจ้าของขอ 2026-11-11: เปลี่ยนแท็บ "ปัญหา" เป็น "ผลิต" — สูตรผลิตล่าสุด (หลายเวอร์ชัน = แท็บ) · รายละเอียดแบบหน้าทำสูตร · รายการปัญหา · ประวัติการผลิต (วันไหน เท่าไหร่ ใครทำ)

## ไฟล์
- หน้าจอ `components/parent-production-tab.tsx` · ผูกใน `components/master-crud/parent-sku-extra-tabs.tsx` (key `issues` เดิม → ตำแหน่ง/การซ่อนที่ตั้งไว้ใช้ต่อได้)
- ข้อมูล `GET /api/parent-skus/[id]/production` (products.view, อ่านอย่างเดียว)
- กฎ `lib/parent-production.ts` (+เทสต์): เรียงเวอร์ชัน · SKU ที่เปิดก่อน · รวมใบจ่ายงาน · สถานะในประวัติ

## ทำงานอย่างไร
1. **สี / SKU** — สูตร (`bom_headers.product_sku`) ผูกกับ SKU ลูก ไม่ใช่ Parent → เลือก SKU ก่อน · เปิดตัวที่สูตรแก้ล่าสุด · SKU ที่ไม่มีสูตรและไม่เคยผลิตพับไว้ ("+ อีก N SKU")
2. **สูตรผลิต** — แท็บเวอร์ชัน (เลขมากก่อน = ล่าสุด · ⭐ = สูตรหลัก) · ตารางวัตถุดิบ (รูป · ใช้/ชิ้น · เผื่อเสีย) · รายละเอียด: สถานะ · งานเหมา (`bom_piecework_lines`) · ค่าแรงประกอบปัจจุบัน (`bom_labor_rates`) · หมายเหตุ
   ปุ่ม "✎ แก้ในตัวทำสูตร" / "+ เวอร์ชันใหม่" / "+ สร้างสูตร" = `BomEditorModal` (สิทธิ์ products.edit)
3. **ปัญหาที่เคยเจอ** — `ParentIssuesPanel` ตัวเดิม (เพิ่ม/แก้ได้)
4. **ประวัติการผลิต** — ใบสั่งผลิตของทุก SKU ในรุ่น (ล่าสุด 100 ใบ) · ใครทำ = ชื่อในใบจ่ายงาน (`mo_work_orders.assignees` → `assignee_name` → แผนก) ไม่นับใบที่ยกเลิก · กดเลขใบ = `MoStatusModal` · ติ๊ก "เฉพาะ <สี>" กรองได้
