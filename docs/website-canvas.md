# ผืนผ้าใบอิสระ (Section ชนิด `canvas`)

> ของกลางสำหรับหน้าเว็บร้าน — วางรูป / ข้อความ / ปุ่ม / ของตกแต่ง **ตรงไหนก็ได้** แล้วแต่ละชิ้นกดไปหน้าต่าง ๆ ได้
> เปิดใช้: Pixiedustie (2026-10-14) · Louis Montini (2026-10-21) — สวิตช์ "🧪 ทดลองใช้ผืนผ้าใบอิสระ" ในแท็บข้อมูลร้าน

## ใช้ทำอะไร / ใช้เมื่อไหร่

- หัวเว็บหรือแบนเนอร์ที่อยากจัดแบบนิตยสาร (รูปทรงวงรี/โค้งประตู ข้อความลายมือ ของตกแต่ง ซ้อนกัน)
- หน้าแนะนำแบรนด์/คอลเลกชันที่อยากให้หน้าตาไม่เหมือนเทมเพลต

**ไม่ควรใช้** กับสิ่งที่ข้อมูลเปลี่ยนบ่อย เช่น ตารางสินค้า/หมวด — ใช้ Section สินค้าเดิม (ดึงจาก ERP อัตโนมัติ)

## วิธีใช้ (คนจัดหน้า)

1. ตัวจัดหน้า → `+ เพิ่ม Section` → 🎨 ผืนผ้าใบอิสระ (เห็นเมื่อเปิดสวิตช์ทดลองของร้านแล้ว)
2. เลือกผืน → **✏️ แก้แบบเต็มจอ** (หรือดับเบิลคลิกที่ว่างบนผืนในพรีวิว) → ป๊อปอัปเต็มจอ:
   - ซ้าย: 🖼️ รูป (อัปโหลดจากเครื่อง / คลังรูป / รูปสินค้าของร้าน) · 🔤 ข้อความสำเร็จรูป · 🔘 ปุ่มสำเร็จรูป · 🎀 คลังของตกแต่ง · 🗂️ ชั้น
   - กลาง: ผืนจริงของเว็บร้าน (/canvas-edit) · คลิกชิ้น = **แถบเครื่องมือลอย** (รูป: เปลี่ยนรูป/กรอบ · ข้อความ: แก้/ขนาด/สี/จัดชิด · ปุ่ม: แก้/แบบปุ่ม · ทุกชนิด: ลิงก์/สำเนา/ลบ)
   - ขวา: แผงตั้งค่าแบบภาพ (จุดสีของธีม · ฟอนต์โชว์ตัวอย่างจริง · แถบเลื่อน · กรอบเลือกจากภาพ) + "ตั้งค่าละเอียด" = ฟอร์มเต็มจาก schema
   - ไม่ได้เลือกชิ้น = ตั้งค่าทั้งผืน (ความสูง · สีพื้น · รูปพื้น · มือถือ)
   - **จัดวาง** (แถบลอย ▤ + แผงขวา): ชั้น ขึ้นหน้า/ถอยหลัง/หน้าสุด/หลังสุด · จัดชิดผืน บน/ซ้าย/กลางแนวตั้ง/กลางแนวนอน/ล่าง/ขวา (คำนวณจากขนาดจริงบนจอ)
   - **ครอป** (รูป): ✂️ = โหมดลากรูปในกรอบ + ซูม 100–400% · ตัดขอบ = ลากจุดจับของกรอบ · ค่าเก็บเป็น cropZoom/cropX/cropY · **พลิก** ซ้าย-ขวา/บน-ล่าง (รูป + ของตกแต่ง)
   - ป๊อปกรอบมี **สีเส้น + ความหนา + ระยะห่าง** (เมื่อกรอบมีเส้น) · แผงชั้นลากสลับได้ (useDragReorder ของกลาง)
   - รูปที่เพิ่มใหม่ **ไม่มีกรอบ** — แต่งกรอบทีหลังที่ตัวรูป (9 แบบสำเร็จ: วงรี/โค้งประตู/ลูกไม้/เส้นลอย/เส้นคู่ ฯลฯ)
3. ในพรีวิว (ทั้งในป๊อปอัปและพรีวิวเล็ก): ลากย้าย · จับมุมย่อ-ขยาย (รูป/ของตกแต่งรักษาสัดส่วน · Shift = อิสระ) · จุดกลมด้านบน = หมุน (Shift = ทีละ 15°)
   · มีเส้นชมพูช่วยจัดแนว (ขอบ/กึ่งกลางผืนและชิ้นอื่น · กด Alt ระหว่างลาก = ปิด) · ดับเบิลคลิกข้อความพิมพ์แก้ตรงนั้น · ลากแถบ ↕ ใต้ผืนปรับความสูง
4. คีย์ลัดในพรีวิว: ลูกศรขยับ 1 (Shift = 10) · Delete ลบ · Ctrl+D สำเนา · Ctrl+Z / Ctrl+Shift+Z ย้อน/ทำซ้ำ · Esc เลิกเลือก
5. แต่ละชิ้นตั้ง "กดแล้วไปที่" ได้: หน้าในเว็บ / หมวดสินค้า / สินค้า / เลื่อนไปส่วนอื่นในหน้านี้ / ลิงก์ภายนอก
6. ชั้นหน้า-หลัง: ปุ่ม ⤒ ↑ ↓ ⤓ ในแผงขวา (ในต้นไม้ด้านซ้าย บน = อยู่หลังสุด)

## มือถือ

- **เรียงอัตโนมัติ** (`mobileMode: "auto"` ค่าเริ่มต้น): จอ < 768px เรียงชิ้นลงมาตามตำแหน่ง บน→ล่าง แล้วซ้าย→ขวา · ข้อความจัดกึ่งกลาง (ตั้ง "มือถือ: ชิดซ้าย" ได้) · ดูอย่างเดียว ลากไม่ได้
- **จัดเอง** (`mobileMode: "custom"`): ผืนมือถือกว้าง **400 หน่วย** แยกจากคอม — ลาก/ย่อ/หมุน/ขนาดตัวอักษร/จัดข้อความ บนจอ 📲 มือถือ ในป๊อปอัปแก้เต็มจอ ไม่กระทบหน้าคอม
  - กด "✋ จัดเอง" = พรีวิว **วัดตำแหน่งจริงของแบบเรียงอัตโนมัติที่เห็นอยู่** แล้วเก็บเป็นจุดเริ่ม (`storefront-canvas-mobile-freeze`) → หน้ามือถือไม่กระโดด
  - กลับเป็นเรียงอัตโนมัติได้ (ตำแหน่งที่จัดยังเก็บไว้ กด "จัดเอง" อีกครั้งได้ของเดิมคืน) · "↺ เริ่มจัดใหม่" = วัดจากแบบอัตโนมัติใหม่
  - ชิ้นที่เพิ่มตอนเป็นแบบจัดเองได้ตำแหน่งมือถือให้เลย (`canvasMobilePreset`) · ชิ้นที่ยังไม่ได้จัด (`mw = 0`) = ย่อจากตำแหน่งคอม 1/3
- ของตกแต่งที่เพิ่มใหม่ตั้ง "ซ่อนบนมือถือ" ไว้ให้ (เปิดโชว์ทีหลังได้)

## เลือกหลายชิ้น / กลุ่ม / ยืดเต็มจอ

- **หลายชิ้น**: Shift/Ctrl+คลิก · ลากกรอบจากที่ว่าง · Ctrl+A · แผงชั้น Ctrl/Shift+คลิก → ลากย้ายทั้งชุด · ลูกศร · จัดชิดกัน (เทียบกรอบรวม) · กระจายระยะเท่ากัน (≥ 3 ชิ้น) · หน้าสุด/หลังสุด · สำเนา · ลบ · ซ่อนบนมือถือ/ล็อกทั้งชุด
- **กลุ่ม** (`group` = รหัสเดียวกัน): Ctrl+G / ปุ่ม ⛓ จับกลุ่ม → คลิกชิ้นใดก็ได้ = เลือกทั้งกลุ่ม · คลิกซ้ำ = เฉพาะชิ้นนั้น · Ctrl+Shift+G / ✂ แยกกลุ่ม
- **ยืดเต็มจอ** (`bleed`, รูป/ของตกแต่ง): กว้างซ้ายสุด–ขวาสุดของจอทุกขนาด (`left: calc(50% - 50vw); width: 100vw`) ใช้แค่ตำแหน่งแนวตั้ง · จุดจับเหลือบน/ล่าง · `.cv-sec` ตัดส่วนเกินแนวนอน (ไม่มีแถบเลื่อนข้าง)

## การเคลื่อนไหว (✨)

- **โผล่ตอนเลื่อนมาเจอ** (`anim`): fade-up · fade-in · slide-left/right · zoom · pop · spin-in · blur + `animDelay` (0–3000 ms) + `animSpeed`
  - ใช้ **CSS ของกลาง `[data-motion]`** ตัวเดียวกับลูกเล่นของ Section (ERP `MOTION_ENTRANCES` ได้ pop/spin-in/blur เพิ่มด้วย) · `MotionObserver` + ตัวจับของผืนเอง (ชิ้นที่เพิ่งได้แบบโผล่) ใส่ `data-inview`
- **ขยับตลอดเวลา** (`loop`): float · sway · pulse · spin · twinkle · bounce · wiggle · shine (รูป/ปุ่ม) + `loopSpeed` — **CSS ของกลางใหม่ `[data-loop]`** (ใส่ที่ element ไหนก็ได้) · หลายชิ้นเลื่อนจังหวะกันเอง (`loopOffset` จาก id)
- โครง: `.cv-body` (ความทึบ) > `.cv-anim` (โผล่) > `.cv-loop` (ขยับ) — แยกชั้นกัน transform/opacity ไม่ชนกัน
- ตัวจัดหน้า: ▶ ดูตัวอย่าง (`storefront-canvas-play`) · เลือกแบบโผล่แล้วเล่นให้ดูทันที (ป๊อปปิดเองจะได้เห็น) · ระหว่างลาก loop/hover หยุด (`data-dragging`) · "✨ โผล่ทีละชิ้น" (`canvasStagger`: บน→ล่าง หน่วงไล่ 0.15 วิ)
- **พิมพ์ทีละตัว** (`anim: "type"`, ข้อความ ≤ 400 ตัว · ยาวกว่า/ไม่ใช่ข้อความ = ค่อย ๆ ขึ้นมา): แยกตัวอักษรด้วย `Intl.Segmenter` (สระ/วรรณยุกต์ไทยไม่หลุด) เป็น `.cv-ch` + เคอร์เซอร์ · โชว์ด้วย **visibility** (opacity ใช้กับตัวหนังสือสีไล่ไม่ได้) · ความเร็ว ช้า/ปกติ/เร็ว = 90/55/30 ms ต่อตัว · หน่วงเวลาใช้ `animDelay` · ผู้อ่านหน้าจอได้ข้อความเต็มจาก `aria-label`
- **ตอนเอาเมาส์ชี้** (`hover`, ที่ `.cv-body[data-hov]`): lift ยกตัว · grow ขยาย · zoom ซูมรูปในกรอบ (รูป · ใช้ CSS `scale` ไม่ชน transform ของครอป) · glow เรืองแสง · tilt เอียงนิด — ชื่อ lift/zoom/glow เดียวกับลูกเล่น hover ของ Section · เฉพาะ `@media (hover: hover)` · เงา/แสงเป็น drop-shadow (ตามรูปทรงจริง)
- คนที่ตั้งเครื่อง "ลดการเคลื่อนไหว" = นิ่งทั้งหมด

## 🌀 ขยับตามการเลื่อนจอ + 🔍 กดรูปแล้วขยาย (2026-10-21)

> เจ้าของขอ (อ้างอิง Pinterest "Supera blog animation"): "เหมือนวางอิสระแต่เวลาเลื่อนจะมี animation" → ดูตัวอย่าง 4 แบบแล้วเลือก **แบบ 3** (เร็ว-ช้า + จาง + ค้าง + กดรูปขยาย) · มือถือ = เหมือนคอมแต่เบาลง

**ตอนเลื่อนจอ (ทุกชนิดชิ้น)** — เว็บร้าน `src/lib/canvas-scroll.ts` (`scrollFxAt` ฟังก์ชันคำนวณ + `attachCanvasScroll` ตัวฟังการเลื่อน)
- `sfxSpeed` -100..100: ลบ = ช้ากว่าการเลื่อน (ลอยค้าง) · บวก = เร็วกว่า (ขึ้นไปก่อน) · สูงสุด ±50% ของการเลื่อน ไม่เกิน 0.6 จอ
- `sfxFade`: `out` จางเมื่อกลางชิ้นขึ้นไปถึง 35% จากบน (หมดในครึ่งจอ) · `inout` + ค่อย ๆ ชัดตอนโผล่จากขอบล่าง
- `sfxZoom`: `grow` / `shrink` ตามระยะที่เลื่อนผ่าน · `sfxRotate`: องศาต่อการเลื่อน 1 จอ (ของตกแต่งหมุน)
- `sfxPin`: ค้างอยู่ที่เดิมบนจอ (ระยะเท่าที่อยู่ในผืน ไม่หลุดขอบล่างจอ) จนขอบล่างผืนดันออก · ค้าง + จาง = ค่อย ๆ จางตลอดช่วงที่ค้าง (หัวข้อตัวใหญ่ด้านหลังแบบในรูปอ้างอิง)
- **จุดนิ่ง** = ตอนชิ้นอยู่กลางจอ · ชิ้นในจอแรก = ตอนเปิดหน้า → โหลดหน้าแล้วไม่กระโดด
- วิธีวาด: เขียน CSS `translate/scale/rotate/opacity` ลง `.cv-item` ตรง ๆ (คุณสมบัติแยก ไม่ทับ `transform: rotate` ของชิ้น · ไม่กระทบเลย์เอาต์) · อ่าน `offsetTop/offsetHeight` (ไม่รวมค่าที่ขยับ) + กรอบผืน 1 ครั้งต่อเฟรม · ทำงานเฉพาะตอนผืนใกล้จอ (IntersectionObserver) · ฟัง Lenis ตรง (เลื่อนนุ่มแล้วไม่ช้ากว่า 1 เฟรม) · หน้าแก้เต็มจอเลื่อนใน `.cv-solo-page` (ฟัง scroll แบบ capture)
- มือถือขยับครึ่งเดียว · มือถือแบบเรียงอัตโนมัติไม่ค้าง (ชิ้นถัดไปจะเลื่อนมาทับ) · ลดการเคลื่อนไหว = ไม่ขยับ · `.cv-sec` ยังตัดขอบ (ชิ้นที่ขยับเลยขอบผืนถูกตัด — วางห่างขอบบน/ล่างผืนหน่อย)
- **ตัวจัดหน้าไม่ขยับ** (ลากวางต้องตรง) — กด "▶ ลองเลื่อนดู" ในแผงขวา (`storefront-canvas-scrollfx {on}`) = ขยับจริง + ซ่อนจุดจับ/ลากไม่ได้ + หน้าแก้เต็มจอเว้นที่บน-ล่าง (`html[data-cv-fx]`) ให้เลื่อนผ่านได้
- ปุ่มทั้งผืน "🌀 ทำทั้งผืนแบบเลื่อนแล้วมีมิติ" (`canvasScrollGallery`): รูป/คลิปความเร็วสลับ -30/35/15/-20/30/-10 + จาง · ข้อความ ≥ 72 = ค้าง+จาง · คำบรรยาย/ปุ่มติดรูปที่ใกล้สุด (≤ 360 หน่วย) · ของตกแต่ง ±55 · "ล้างการขยับ" (`canvasScrollClear`) · แถบลอยบนผืนมีปุ่มด่วน ช้ากว่า/ปกติ/เร็วกว่า · จางตอนออก · ค้าง
- ผืนสูงได้ถึง **6000** หน่วย (`CANVAS_MAX_HEIGHT` = เว็บร้าน `CANVAS_MAX_H`) สำหรับแกลเลอรียาวหลายจอ

**กดแล้วขยาย (รูป/คลิป)** — ช่อง `expand` ชนะทั้งการ์ดสินค้าและลิงก์ธรรมดา
- `full` = เว็บร้าน `src/lib/canvas-expand.ts`: รูปขยายจากที่เดิมจนเต็มจอ (DOM ล้วน อยู่รอดข้ามการเปลี่ยนหน้า) → `navigateCustom` (lib/page-transition) เปลี่ยนหน้าใต้ภาพ → ภาพจางออก · ลิงก์ติด `data-nav-self` ให้ NavProgress ไม่เฟดซ้อน · ใช้ได้เฉพาะลิงก์ในเว็บที่ไม่เปิดแท็บใหม่ (ไม่ใช่ = ลิงก์ธรรมดา + ตรวจก่อนเผยแพร่เตือน) · ลิงก์หน้าเดียวกัน (#ส่วน) = เลื่อนตามปกติ
- `story` = `CanvasStory.tsx`: รูปขยายครึ่งซ้าย (มือถือครึ่งบน 52%) · ฝั่งขวา `expTitle` (ว่าง = Alt) · `expText` · สินค้าในรูป (ใส่ตะกร้า = QuickView) · ปุ่ม `expCta` ไป `href` · ปิด ✕/Esc/ย้อนกลับ (เพิ่มก้าวประวัติ 1 ก้าว · ในตัวจัดหน้าไม่เพิ่ม) แล้วรูปหดกลับที่เดิม · ล็อกการเลื่อน (วัดขนาดจอหลังล็อก — หน้าที่ล้นแนวนอนบนมือถือจอจะแคบลง)
- ตัวจัดหน้า: "▶ ลองกดดู" (`storefront-canvas-expand-demo {childId}`) — เต็มจอ = ขยายแล้วหดกลับ ไม่เปลี่ยนหน้า

- **ชิ้นวิดีโอ** (`kind: "video"`): ปุ่ม 🎬 วิดีโอ ในแถบซ้ายของหน้าแก้เต็มจอ → คลังวิดีโอ (AssetPicker `typeFilter="video"` · อัปโหลดใหม่ในป๊อปเดียวกัน ≤ 200 MB) → วัดสัดส่วนคลิปจริง (`videoSize`) แล้ววางกลางผืน
  - ช่อง: `videoKey` (ชนิด `videoFile`) · `posterKey` (รูปปก) · `frame` (ทรงชุดเดียวกับรูป) · `fit` · `flipH/V` · `bleed` — เล่นวนแบบเงียบ (`muted autoPlay loop playsInline`) · เปลี่ยนคลิป = แถบลอย 🎬 / ดับเบิลคลิก / แผงขวา (`replace-video`)
  - ตอนจัดหน้าคลิปไม่กินการลาก (`html.pv-edit .cv-vid video { pointer-events: none }`) · ภาพย่อแม่แบบ = รูปปกหรือกล่อง ▶ (ไม่โหลดคลิป)
- **สินค้าในรูป/คลิป** (`products` ≤ 6 รหัสรุ่น + `shopIcon`): แผงขวา "🛍 สินค้าในรูปนี้" (WebsiteProductPicker) → บนเว็บกดชิ้น = **การ์ดสินค้าเด้ง** (`CanvasShopPop`) ชนะ "กดแล้วไปที่"
  - คอม: การ์ดลอยข้างชิ้น (ขวาก่อน → ซ้าย → ทับตรงจุดที่กด) · มือถือ: แผ่นเลื่อนขึ้นจากล่างจอ + พื้นหลังมืด · หลายตัว ‹ 1/3 › · "ใส่ตะกร้า" = QuickView ของกลาง · "ดูสินค้า" = หน้าสินค้า
  - ดึงสินค้าตามรหัสที่ `/api/search?codes=` (เว็บร้าน · ชุดเดียวกับหน้าเว็บ) · โหลดไว้ก่อนตอนเครื่องว่าง (requestIdleCallback) + แคชในหน้า · รุ่นที่ไม่ได้ขายบนเว็บ = ข้าม
  - ไอคอนถุงมุมขวาล่างของชิ้น (ปิดได้) · กด Esc / นอกการ์ด = ปิด · โหมดแก้ไขไม่เด้ง (ลาก/เลือกตามปกติ)

## กรอบรูป / สีไล่

- ทรงใหม่: หัวใจ · ดาว · หกเหลี่ยม · ก้อนเมฆ · ทรงอิสระ = **mask จากเส้นทาง SVG** (`FRAME_PATHS` เว็บร้าน = `CANVAS_FRAME_PATHS` ERP) + เส้นรอบทรง (`FrameRing`: เส้น/จุด/เส้นคู่) · ขอบหยัก/แสตมป์ = CSS mask · โพลารอยด์/ขอบหนาสองชั้น = padding+พื้น
- **กรอบจากรูปของร้าน** (`overlayKey` + `overlayInset` %): PNG พื้นใสวางทับรูป · อัลบั้ม "กรอบรูปเว็บ" ต่อร้าน (`/api/website/canvas-decor` kind `frame` → `store_settings.canvas_frame_album`) · นับเป็น "ถูกใช้" ในคลังไฟล์
- **สีไล่ = ของกลาง** (`lib/website-gradient.ts` ↔ เว็บร้าน `src/lib/gradient.ts`): จุดสี = ชื่อสีธีมหรือ #hex 2–3 จุด · ทิศ down/right/diag/diag-up/radial
  - พื้นหลังทุก Section: `style.bg = "gradient"` + `style.bgGrad` (แผง "รูปลักษณ์" → พื้นหลังบล็อก → ไล่สี · `GradientPicker`)
  - ข้อความ/ของตกแต่งบนผืน: `grad` + `color` (สีเริ่ม) + `color2` (สีปลาย) — ข้อความใช้ background-clip:text · ของตกแต่งใช้ SVG gradient

## รูปพื้นหลังผืน (ตำแหน่ง / ซูม / เห็นทั้งรูป)

- แผงตั้งค่าทั้งผืน → "รูปพื้นหลังผืน" → `CanvasBgPositioner` (`components/website-canvas-bg-position.tsx`)
  - **เต็มผืน** (`bgFit: cover`): รูปเต็ม + กรอบขาว = ส่วนที่เห็นบนจอคอม (อ้างอิงจอกว้าง 1440 · เส้นประ = มือถือแบบจัดเอง) → ลากกรอบ/คลิกตรงไหนของรูป = ย้ายส่วนที่เห็น · ซูม 100–300%
  - **เห็นทั้งรูป** (`contain`): รูปไม่ถูกตัด ที่ว่างเป็นสีพื้นผืน · เลื่อนชิดซ้าย/ขวา/บน/ล่างด้วยแถบเลื่อน
- เก็บ `bgX`/`bgY` (0–100%) + `bgZoom` — สูตรเดียวกันทั้งสองฝั่ง: `object-position: x% y%` + `scale(zoom)` รอบจุดเดียวกัน (`canvasBgWindow` ใน lib/website-canvas.ts คำนวณกรอบ "ส่วนที่เห็น" ให้แผง)
- เว็บร้านวาดเป็นชั้นรูป `.cv-bg` (LoadImg + กรอบรอรูป `sf-ph-nologo`) ใต้ผืน แทน background-image เดิม · เปลี่ยนรูป/ใช้แม่แบบ = กลับกลางรูป (`CANVAS_BG_DEFAULT`)
- **📲 มือถือปรับแยก**: กด 📲 มือถือ ในหน้าแก้เต็มจอ → แผงแก้ `bgMCustom` + `bgMFit/bgMX/bgMY/bgMZoom` (แก้ครั้งแรก = เริ่มจากค่าคอม · "ใช้ตามคอม" = ปิดปรับแยก) · กรอบมือถือ: ผืนจัดเอง = 400×ความสูงมือถือ · เรียงอัตโนมัติ = จอโทรศัพท์ 390×844 (โดยประมาณ)
  - เว็บร้านส่งค่าเป็นตัวแปร CSS (`--bg-pos/--bg-z/--bg-fit` + `--bg-m*`) แล้ว `@media (max-width: 767px)` สลับให้ — ไม่ต้องใช้ JS วัดจอ

## แม่แบบ (📐)

- บันทึกทั้งผืน (ชิ้น · ตำแหน่งคอม/มือถือ · ความสูง · พื้นหลัง · สี) ลงตาราง **`website_canvas_templates`** → ใช้กับผืนอื่น หน้าอื่น หรือร้านอื่น
- ใช้ = **คัดลอก**เนื้อแม่แบบมาแทนผืนนี้ (ชิ้นได้ id ใหม่ + กลุ่มได้รหัสใหม่ · ย้อนกลับด้วย ↶ ได้) — แก้ผืน/แม่แบบทีหลังไม่กระทบกัน
- แก้ชื่อ · บันทึกทับด้วยผืนปัจจุบัน · ลบ (ConfirmDialog) · ทุกการกระทำลง audit log (`entity_type = website_canvas_template`)
- แบบสำเร็จของระบบ 3 แบบ (`CANVAS_STARTER_TEMPLATES` — ไม่มีรูป สีตามธีม) ลบ/แก้ไม่ได้
- รูปในแม่แบบบันทึก "ถูกใช้" (`asset_usages` module `website_canvas_template` field `data`) → คลังไฟล์ไม่ให้ลบรูปที่แม่แบบยังใช้

## ข้อมูล (เก็บใน `shops.home_layout` / `store_pages.layout` เหมือน Section อื่น)

```ts
{
  id, type: "canvas", enabled, visibility, style,   // style.bg = สีพื้นผืน (เต็มความกว้างจอ)
  height: 560,              // ความสูงผืน (หน่วย)
  bgImageKey: null,         // รูปพื้นหลังผืน (r2 key)
  bgFit: "cover",           // รูปพื้นหลัง: cover (เต็มผืน ตัดส่วนเกิน) | contain (เห็นทั้งรูป)
  bgX: 50, bgY: 50,         // ส่วนที่เห็น 0–100% (object-position)
  bgZoom: 100,              // ซูม 100–300% (เฉพาะ cover)
  bgMCustom: false,         // มือถือปรับรูปพื้นหลังแยก (false = ใช้ค่าคอม)
  bgMFit, bgMX, bgMY, bgMZoom, // ค่าของมือถือ (จอ < 768px)
  mobileAlign: "center",    // มือถือแบบเรียงอัตโนมัติ: center | left
  mobileMode: "auto",       // มือถือ: auto (เรียงให้) | custom (จัดเอง)
  mobileHeight: 800,        // ความสูงผืนมือถือแบบจัดเอง (หน่วยผืนมือถือ 400)
  items: [{                 // ลำดับใน array = ลำดับวาด (ตัวแรกอยู่หลังสุด)
    id, enabled, kind: "image" | "text" | "button" | "shape",
    x, y, w, h, rotate, opacity, hideMobile, locked,   // หน่วยบนผืนกว้าง 1200 (จอ 1200px = 1:1)
    mx, my, mw, mh, msize, malign,                      // มือถือแบบจัดเอง (ผืนกว้าง 400) · mw = 0 = ยังไม่ได้จัด
    group, bleed,                                       // กลุ่ม (รหัส) · ยืดเต็มความกว้างจอ (รูป/ของตกแต่ง)
    anim, animDelay, animSpeed, loop, loopSpeed, hover, // โผล่ตอนเลื่อนมาเจอ (รวมพิมพ์ทีละตัว) · ขยับตลอดเวลา · ตอนเอาเมาส์ชี้
    grad, color2, color2Hex,                            // สีไล่ (ข้อความ/ของตกแต่ง)
    overlayKey, overlayInset,                           // กรอบจากรูปของร้าน (PNG ทับรูป)
    href, newTab,                                       // กดแล้วไปที่ (กรอง javascript: ทิ้งทั้ง ERP และเว็บร้าน)
    // ข้อความ/ปุ่ม: text | label, variant, font, size, weight, italic, uppercase, spacing, lineHeight, align, color, colorHex, bg, bgHex
    // รูป: imageKey, alt, frame (rect|rounded|ellipse|arch), fit, border (none|line|double|dotted|lace), borderColor, borderHex, borderWidth, borderGap
    // ของตกแต่ง: shape (bow|heart|sparkle|star|flower|pearls|lace|scallop|wave|line|arch|rect|ellipse), outline, strokeWidth, color
  }]
}
```

- สีเก็บเป็น **ชื่อสีของธีม** (`ink` `brand` `brandDeep` `brandSoft` `muted` `page` `surface` `white`) หรือ `custom` + hex → เปลี่ยนธีมแล้วผืนเปลี่ยนตาม
- ฟอนต์ `display`/`body` = ตามธีม · ชื่ออื่นต้องอยู่ในรายการ (`CANVAS_FONTS` ERP = `CANVAS_FONT_FAMILIES` เว็บร้าน) เว็บร้านโหลด Google Fonts ให้เอง

## คลังของตกแต่ง (แยกต่อร้าน)

- ลายในตัว 13 แบบ (SVG สีตามธีม) + **ของร้าน** = อัลบั้ม "ของตกแต่งเว็บ · <ชื่อร้าน>" ใน**คลังไฟล์กลาง** (`asset_collections`)
- id อัลบั้มจำไว้ที่ `store_settings.canvas_decor_album` ของร้าน · สร้างอัตโนมัติครั้งแรกที่เปิดคลัง (POST `/api/website/canvas-decor`)
- เพิ่ม = ⬆️ อัปโหลด หรือ **📁 เลือกจากคลังไฟล์** (AssetPicker หลายรูป → `/api/assets/bulk` action `move` = ใส่ไฟล์เดิมเข้าอัลบั้มนี้ ไม่ก๊อป ไม่หลุดจากอัลบั้มเดิม · เลือกรูปเดียว = วางลงผืนทันที)
- ✕ = **เอาออกจากอัลบั้มนี้เท่านั้น** (PATCH `collection_ids` ตัดอัลบั้มนี้ออก) — ไฟล์ยังอยู่ในคลังไฟล์/อัลบั้มอื่น · ลบไฟล์ถาวรทำที่หน้าคลังไฟล์ (กันรูปที่ใช้ที่อื่นหายไปด้วย)
- **รูปที่วางบนผืนถูกบันทึกเป็น "ถูกใช้"** (`asset_usages` module `website_home`/`website_page` field `draft`/`live`) ทุกครั้งที่บันทึกร่าง/เผยแพร่ → คลังไฟล์ไม่ให้ลบของที่ยังอยู่บนเว็บ (409)

## คุยกับพรีวิวแบบสด (ไม่โหลดหน้าใหม่)

| ทิศ | ข้อความ | เมื่อไหร่ |
|---|---|---|
| ERP → เว็บ | `storefront-canvas-update {block}` | ข้อมูลผืนเปลี่ยน (แก้ในแผง/undo/ลากเสร็จ) และหลังพรีวิวโหลดใหม่ |
| เว็บ → ERP | `storefront-canvas-change {blockId, items?:[{id,x,y,w,h,rotate,text}], height?}` | ลาก/ย่อ/หมุน/พิมพ์แก้/ปรับความสูง เสร็จ |
| เว็บ → ERP | `storefront-canvas-delete` / `storefront-canvas-duplicate {blockId, childId}` | กด Delete / Ctrl+D ในพรีวิว |
| เว็บ → ERP | `storefront-canvas-key {action: undo/redo}` | Ctrl+Z ในพรีวิว |
| เว็บ → ERP | `storefront-canvas-action {blockId, childId, action: replace-image/link}` | ปุ่มบนแถบลอยที่ต้องใช้หน้าจอ ERP |
| เว็บ → ERP | `storefront-canvas-open {blockId}` | ดับเบิลคลิกผืนในพรีวิวเล็ก = เปิดป๊อปอัป |
| ERP → เว็บ | `storefront-canvas-align {blockId, childId, to}` · `storefront-canvas-crop {blockId, childId}` | ปุ่มในแผงขวาที่ต้องใช้ขนาดจริงบนจอ / เปิดโหมดครอปในพรีวิว |
| เว็บ → ERP | `storefront-canvas-action {action: layer-up/down/front/back}` | ปุ่มชั้นบนแถบลอย — bridge เรียงลำดับใหม่ในข้อมูลเอง |
| ERP → เว็บ | `storefront-ui-scale {scale}` | พรีวิวถูกย่อเท่าไร → PreviewBridge ตั้ง `--cv-ui` ให้แถบลอย/จุดจับขยายกลับ |
| เว็บ → ERP | `storefront-canvas-multi {blockId, ids}` | เลือกเปลี่ยน (ตัวท้าย = ชิ้นหลัก) — ป๊อปอัปเก็บไว้แสดงแผงหลายชิ้น |
| ERP → เว็บ | `storefront-select-block {blockId, childId, childIds?}` | เลือกจากฝั่ง ERP · ไม่มี childIds + childId = ชิ้นหลักเดิม → พรีวิวคงการเลือกหลายชิ้นไว้ |
| เว็บ → ERP | `storefront-canvas-delete` / `-duplicate {blockId, childIds}` · `storefront-canvas-action {childIds, action: layer-front/back}` | คำสั่งกับหลายชิ้น (ย้อนกลับได้ในขั้นเดียว) |
| ERP → เว็บ | `storefront-canvas-align {blockId, childIds, to}` | หลายชิ้น = ชิดกันเอง + `distribute-h/v` |
| ERP → เว็บ | `storefront-canvas-mobile-freeze {blockId}` | วัดหน้ามือถือแบบเรียงอัตโนมัติ → ตอบ `storefront-canvas-change {mobileMode: "custom", mobileHeight, items:[{id,mx,my,mw,mh,msize,malign}]}` |
| ERP → เว็บ | `storefront-canvas-play {blockId, childIds?}` | ▶ ดูตัวอย่าง "โผล่ตอนเลื่อนมาเจอ" (ไม่ระบุ = ทั้งผืน) |
| เว็บ → ERP | `storefront-canvas-action {action: "pick-frame"}` | ปุ่ม "เลือก/อัปโหลดกรอบ" บนแถบลอย → ERP เปิดคลังกรอบรูปของร้าน |
| ERP → เว็บ | `storefront-canvas-scrollfx {blockId, on}` | 🌀 ลองเลื่อนดู เปิด/ปิด (ส่งซ้ำหลังพรีวิวโหลดใหม่) |
| ERP → เว็บ | `storefront-canvas-expand-demo {blockId, childId}` | 🔍 ลองกดดู — เล่นท่าขยายของชิ้นนี้ (ไม่เปลี่ยนหน้า) |

- เลือกชิ้น = `storefront-block-click {blockId, childId}` (CanvasSection ส่งเองด้วย เพราะหน้าเต็มจอไม่มีตัวห่อ Section) · แถบลอยมี `data-pv-ignore` ให้ PreviewBridge ปล่อยคลิกผ่าน
- ผืน (`.cv-stage`) ก็มี `data-pv-ignore` ตอนแก้ — CanvasSection จัดการคลิกเอง (ไม่งั้น PreviewBridge ส่ง "เลือก Section" ซ้อนแล้วการเลือกหลายชิ้นหลุด)
- ป๊อปอัปไม่ส่ง `select-block` ชุดที่พรีวิวเพิ่งบอกมาเองกลับไป (`lastFromFrame`) — กันวนเลือก
- iframe 2 ตัว (พรีวิวเล็ก + ป๊อปอัป) ใช้ข้อมูลชุดเดียวของตัวจัดหน้า · แต่ละ bridge ฟังเฉพาะ `e.source` ของ iframe ตัวเอง (กันแก้ซ้ำสองรอบ)
- บันทึกร่างอัตโนมัติแล้วตัวจัดหน้า **ไม่โหลดพรีวิวใหม่** ถ้าแก้แค่ในผืน (`previewStructureSig`) — พรีวิวรับสดอยู่แล้ว
- ⚠️ CSS ตำแหน่งชิ้นต้อง specificity สูงกว่า `html.pv-edit [data-child-id]{position:relative}` ของ PreviewBridge

## ข้อจำกัดที่รู้แล้ว

- ชิ้นทั่วไปอยู่ในกรอบกว้าง 1200 กลางจอ — ยืดเต็มจอได้เฉพาะรูป/ของตกแต่ง (`bleed`)
- หลายชิ้น: ย้าย/จัดชิด/กระจายได้ แต่ย่อ-ขยาย/หมุนทั้งชุดพร้อมกันยังไม่ได้ (ทำทีละชิ้น)
- แม่แบบเห็นได้ทุกร้าน (คนที่เข้าตัวจัดหน้าได้ = จัดการเว็บได้ทุกร้านอยู่แล้ว) — ยังไม่มีแม่แบบ "ส่วนตัว"
- ภาพย่อแม่แบบวาดคร่าว ๆ ใน ERP (ฟอนต์/ระยะอาจต่างจากเว็บจริงเล็กน้อย)
- ยังไม่ส่งให้ AI ช่วยจัดหน้า (ต้องจัดตำแหน่งด้วยตา)
