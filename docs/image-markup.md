# ImageMarkup — วาดบนรูป + หมุดเลข (ของกลาง)

`components/image-markup` (ตัววาด + `ImageMarkupToolbar`) · ชนิดข้อมูล/ตัวทำความสะอาด `lib/image-markup.ts` (ใช้ได้ทั้ง API และหน้าจอ)

## ใช้ทำอะไร

- ใบงานออกแบบ แท็บ **📐 รายละเอียดงาน**: วาดชี้จุดบนรูป + ปักหมุดวัตถุดิบ (ผูก SKU) — เจ้าของขอ 2026-11-05
- ใช้ซ้ำได้: ชี้ตำหนิบนรูป QC · ชี้จุดแก้งานบนรูปคอมเมนต์ลูกค้า

| เครื่องมือ | วิธีใช้ |
|---|---|
| เลือก / ย้าย | ลากของที่วาดเพื่อย้าย · ดับเบิลคลิกข้อความเพื่อแก้ · Delete = ลบที่เลือก · Esc = เลิกเลือก |
| สี่เหลี่ยม / วงกลม | ลากบนรูป (แค่คลิก = ได้กรอบขนาดตั้งต้น) |
| ข้อความ | กดบนรูป → พิมพ์ → Enter |
| วาดเส้น | ลากบนรูป (เส้นมือ) |
| หมุด | กดบนรูป → เรียก `onPinAdd` (หน้าเจ้าของสร้างข้อมูลหมุดเอง) · หมุดลากย้ายได้ทุกโหมด |

## v2 — ปรับได้แบบกระดาน (2026-11-06)

- เครื่องมือเพิ่ม: **ลูกศร** (ลากต้น→ปลาย) · **ปากกาเน้น** (สีจาง ทับแล้วยังเห็นของข้างใต้) · ซูม − / % / ＋ (`zoom` + `onZoom` ใน Toolbar)
- กดของที่วาด → **จุดดึงที่มุม** ลากขยาย/ย่อ (กรอบ/วงกลม) · ลากปลายลูกศร · จุดมุมขวาล่างของข้อความ = ปรับขนาดตัวอักษร · วาดกรอบ/วงกลม/ลูกศร/ข้อความเสร็จ → `onToolDone` (หน้าเจ้าของสลับกลับเครื่องมือเลือก ปรับต่อได้ทันที)
- `ImageMarkupStyleBar`: เลือกของอยู่ = ปรับชิ้นนั้น · ไม่ได้เลือก = ตั้งค่าของที่จะวาดใหม่ (`drawStyle`) — สี · บาง/กลาง/หนา · เส้นประ · พื้นจาง · ข้อความ A− / A＋ / พื้นขาว · ทำซ้ำ · ลบ
- คีย์ลัด: Delete ลบ · Ctrl+Z ย้อนกลับ (`onUndo`) · Ctrl+D ทำซ้ำ (`onDuplicate`) · Esc เลิกเลือก
- **ป้ายชื่อข้างหมุด**: `MarkupPin.tag` = { title, sub, imageUrl } โชว์รูปเล็ก + ชื่อ · ลากป้ายหลบได้ (`onPinLabelMove` → `ldx/ldy` % จากหมุด) · ปิดได้ด้วย `showPinLabels`
- วาดจริงเป็นพิกเซลตามขนาดกล่อง (เส้น/หัวลูกศร/เส้นประไม่เพี้ยนตามสัดส่วนรูป) · ใบพิมพ์วาดแบบเดียวกันเป็น มม. (`lib/design-sheet-spec`)

## กติกา

- พิกัดทุกตัว = **% ของรูป (0-100)** เหมือน `ImageRegions` → ตรงตำแหน่งทุกขนาดจอ/ตอนพิมพ์
- ตัวนี้**ไม่บันทึกเอง** — หน้าที่เรียกใช้เก็บ `shapes` / หมุด แล้วยิง API (สิทธิ์ + audit อยู่ฝั่งนั้น)
- `onShapesChange` ถูกเรียก **ครั้งเดียวต่อการกระทำ** (วาดเสร็จ / ปล่อยเมาส์หลังลาก) → เก็บประวัติย้อนกลับได้ตรง ๆ
- ฝั่ง API ต้องผ่าน `cleanMarkupShapes()` เสมอ (ตัดของผิดรูป/เกินขนาด: สูงสุด 300 ชิ้น · เส้นละ 1,500 จุด · ข้อความ 200 ตัวอักษร)
- หมุดสีส้ม = `muted` (เช่น ยังไม่ผูก SKU) · สีม่วง = สมบูรณ์

## ตัวอย่าง

```tsx
const [tool, setTool] = useState<MarkupTool>("select");
<ImageMarkupToolbar tool={tool} onTool={setTool} color={color} onColor={setColor} onUndo={undo} canUndo={hist.length > 0} />
<ImageMarkup src={url} shapes={shapes} pins={pins} editable tool={tool} color={color}
  selected={sel} onSelect={setSel} onShapesChange={setShapes}
  onPinAdd={(pt) => addPin(pt)} onPinMove={(id, pt) => movePin(id, pt)} onDeleteSelected={removeSelected} />
```

- ห้ามเขียนตัววาดบนรูปเองในหน้าโมดูล — ใช้ตัวนี้ (กรอบผูกข้อมูลแบบแผ่น Swatch ใช้ `ImageRegions`)
