# วางแผนตัดผ้า (เมนู ผลิต › จ่ายงาน) — เฟส 1

หน้า `/master/fabric-plan` · เจ้าของสั่ง 2026-11-13 ("ระบบคำนวณผ้า แบบ Nesting คุ้ม ๆ") · อ่านอย่างเดียว ไม่แก้ตัวเลขในใบสั่งผลิต

## ใช้ทำอะไร
วางชิ้นตัดของ **หลายใบสั่งผลิตที่ใช้ผ้าเดียวกัน** ลงผ้าผืนเดียวกัน (ชิ้นเล็กยัดช่องว่างข้ามใบได้) → รู้ว่าต้องใช้ผ้าเท่าไหร่ · ประหยัดกว่าตัดทีละใบเท่าไหร่ · สต็อกพอไหม · พิมพ์ใบตัดผ้า

## หน้าจอ
- **ผ้าที่ใบ "ยังไม่ตัด" ใช้อยู่** (ค่าเริ่ม = เฉพาะที่ใช้ร่วมกันตั้งแต่ 2 ใบ) — ผ้า · หน้ากว้าง · กี่ใบ · ชิ้นตัด · ตัดแยก (ตัวเลขเดิมของใบ) → กด "วางแผนตัด"
- **เลือกใบเอง** (MoMultiPickerModal ของกลาง) → วางทุกผ้าของใบที่เลือก
- ผลต่อผ้า: ตัดแยก · ตัดรวม · **ต้องใช้ (แนะนำ)** · ประหยัด · ใช้ผ้า % · สต็อก (พอ / ขาด) · กดแถว = ผังการวาง (FabricLayoutPreview) + แบ่งผ้าต่อใบ
- ปุ่ม: ใส่ตะกร้าขอซื้อส่วนขาด (addToPrCart) · พิมพ์ใบตัดผ้า (`/print/fabric-plan` · usePrintLog `fabric_plan`)

## กติกา (`lib/fabric-plan.ts` · เทสต์ `lib/__tests__/fabric-plan.test.ts`)
- กลุ่มผ้า = รหัส + หน้ากว้าง + ความยาวผืน (ผ้าผืน) · ตัววาง = `layFabric` → `packFabric` (lib/fabric-calc) ตัวเดียวกับใบสั่งผลิต · ไม่บวกเผื่อเสีย
- ตัดแยก = วางทีละใบ · ตัดรวม = วางทุกใบรวม · **best = ทางที่ใช้ผ้าน้อยกว่า** (ตัววางแบบกรอบไม่ได้ดีสุดเสมอ — เจอจริง เยื่อขาว 26 ใบ วางรวม 104.93 vs ตัดแยก 104.18) → ไม่มีวันแนะนำทางที่เปลืองกว่า
- แบ่งผ้าตัดรวมคืนต่อใบตามสัดส่วนพื้นที่ชิ้น (`alloc`)
- สต็อก = คงเหลือทั้งหมด (`lib/sku-stock` · ไม่หักที่จองไว้)

## ข้อมูล
- ชิ้นตัด = `mo_material_summary.lay_layout` (บล็อก กว้าง×ยาว×ชิ้นรวม ต่อใบ — explodeBom เก็บตอนเปิดใบ/อัพเดตวัตถุดิบตาม BOM) — API อ่านเฉพาะ `lay_layout->0/1->blocks/face/sheet` (ไม่ดึงผังทั้งก้อน)
- ⚠️ เปลี่ยนจำนวนสั่งแล้วยังไม่กด "อัพเดตวัตถุดิบตาม BOM" = ชิ้นตัดยังเป็นของจำนวนเดิม
- API `GET /api/mo/fabric-plan?suggest=1` · `?mo_nos=a,b[&sku=X]` (guardApi products.view)

## ข้อมูลจริงตอนทำ (2026-11-13)
- ใบยังไม่ตัด 332 ใบ · ผ้า 126 · ใช้ร่วมหลายใบ 45 ผ้า (มากสุด 61 ใบ — ซับใน FLYNOW ครีม 15,756 ชิ้น คำนวณ ~1 วิ)
- ล็อตใหญ่ที่แต่ละใบวางคุ้มอยู่แล้ว (~96%) ตัดรวมประหยัดน้อย (ซับในครีม 508.37 → 507.32 หลา) · ใบเล็กหลายใบ ประหยัดมากกว่า
