# Page Chrome — แถบบนแบบแอป (ของกลาง)

ไฟล์: `components/page-chrome.tsx`

## ใช้ทำอะไร
ให้หน้าเอา **ชื่อหน้า / ช่องค้นหา / ปุ่ม / ตัวเลือกมุมมอง** ไปวางบนแถบบนของเชลล์ — หน้าตาเหมือนแอปบน iPad/มือถือ
ไม่ต้องมีแถบหัวหน้าของตัวเองซ้อนอีกชั้น

## ใช้ยังไง
```tsx
usePageChrome({
  title: <ปุ่มชื่อหน้า ▾ สลับมุมมอง />,
  search: { value, onChange, placeholder: "ค้นในบอร์ด…" },   // ช่องค้นหามีปุ่ม "ทั้งระบบ" ให้เอง
  actions: <><button>＋ สร้าง</button><เมนู ⋯ /></>,
  viewOptions: <ตัวเลือกมุมมอง (อุปกรณ์ / หน้าตา / เต็มจอ) />,
});
const host = useChromeHost();      // มีเชลล์รับวาดให้ไหม
const isXl = useIsDesktopXl();     // จอคอม
{(!host || isXl) && <PageChromeBar variant="page" />}   // จอคอม / embed → หน้าวาดเอง
```
- หลายคอมโพเนนต์ลงคนละช่องได้ (เช่น หน้าใหญ่ลง title/actions · ตารางลง search/viewOptions) — รวมให้เอง ถอดออกเองตอน unmount
- ใครวาด: จอ < xl = แถบบนของเชลล์ (☰ · ของหน้า · ปุ่มผู้ใช้) · จอคอม/embed = `PageChromeBar variant="page"` ในหน้า
- `viewOptions` ไปโผล่ในเมนูผู้ใช้หัวข้อ "🎛 มุมมองหน้านี้" (`PageViewOptionsSection` — AccountMenu + UserSwitcher) · จอคอมมีปุ่ม 🎛 มุมมอง ในแถบของหน้าด้วย

## ห้ามใช้เมื่อ
- หน้าที่ไม่มีอะไรต้องวาง (ไม่ลงทะเบียน = แถบเชลล์เหมือนเดิม: โลโก้ + ค้นหาทั้งระบบ)
- อย่าวางของหนัก/ยิง API ใน actions หลายตัว — จอเล็กวาดในเชลล์ จอคอมวาดในหน้า (ไม่วาดซ้ำ แต่ re-render ตามหน้าทุกครั้ง)

## ความเร็ว (หน้าใหญ่)
- หน้าลงทะเบียนทุก render → ห้ามให้ชิ้นใหญ่ subscribe ของทั้งก้อน: เชลล์ใช้ `usePageChromeHas()` (boolean มี/ไม่มีของบนแถบ) — render ใหม่เฉพาะตอนค่านี้เปลี่ยน
- `usePageChromeSlots()` ใช้ได้เฉพาะชิ้นเล็กที่ต้องวาดของจริง (`PageChromeBar`, `PageViewOptionsSection`)
- UI ที่ขยับตามการเลื่อน (เช่น ซ่อนแท็บ/ตัวกรองตอนเลื่อนลงในบอร์ด) ใช้ ref + `data-*` + CSS ไม่ใช่ state — ไม่งั้นทั้งตารางวาดใหม่กลางการเลื่อน

- FloatingDropdown ตัวแปร `--fd-max-h`
