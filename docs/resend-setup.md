# 📖 คู่มือตั้งค่าระบบส่งอีเมล (Resend) — ทำครั้งเดียว

ระบบ ERP ส่งอีเมลผ่านบริการ **Resend** (ใช้ทั้ง "ส่งอีเมลรายงาน" และอีเมลแจ้งลูกค้าเรื่องออเดอร์)
คู่มือฉบับเดียวกันนี้โชว์อยู่ในหน้า **ตั้งค่า → ส่งอีเมลรายงาน** ด้วย

## 1. สมัคร Resend (ฟรี)
เข้า https://resend.com/signup → สมัครด้วยบัญชี Google ได้
แพ็กฟรี: 3,000 ฉบับ/เดือน (วันละไม่เกิน 100) — รายงานวันละฉบับถึง 5 คน ใช้ราว 130 ฉบับ/เดือน

## 2. ยืนยันโดเมนอีเมลของบริษัท
1. เมนู **Domains → Add Domain** → พิมพ์โดเมนบริษัท (เช่น pixiedustie.com) · Region: **Tokyo**
2. Resend ให้ "ระเบียน DNS" 3–4 บรรทัด (MX / TXT) → ใส่ที่ผู้ให้บริการโดเมน
   - ถ้าโดเมนอยู่ Cloudflare: มีปุ่มให้ Resend ใส่ให้อัตโนมัติ
3. รอจนสถานะเป็น **Verified** (ไม่กี่นาที – ไม่กี่ชั่วโมง)

## 3. สร้างกุญแจ (API Key)
**API Keys → Create API Key** · ชื่อ: ERP · Permission: **Sending access** · Domain: โดเมนที่ยืนยัน
คัดลอกกุญแจ (ขึ้นต้น `re_` · โชว์ครั้งเดียว)
> ⚠ กุญแจเป็นความลับ — ห้ามส่งในแชต / LINE / อีเมล ใส่ใน Vercel เองเท่านั้น

## 4. ใส่ใน Vercel
vercel.com → โปรเจกต์ **erp-platform-playground** → **Settings → Environment Variables** (Environment: Production)

| ชื่อ | ค่า |
|---|---|
| `RESEND_API_KEY` | กุญแจจากข้อ 3 |
| `EMAIL_FROM` | อีเมลผู้ส่งบนโดเมนที่ยืนยัน เช่น `erp@pixiedustie.com` (ไม่ต้องมีกล่องจดหมายจริง) |

## 5. Deploy ใหม่ 1 ครั้ง
Vercel → **Deployments** → อันบนสุด → **⋯ → Redeploy** (มีผลหลัง deploy ราว 2–3 นาที)

## 6. เช็กผล
หน้า **ตั้งค่า → ส่งอีเมลรายงาน** กล่องด้านบนต้องเป็นสีเขียว "ระบบส่งอีเมลพร้อมแล้ว" (ยังไม่เปลี่ยน = กด Ctrl+Shift+R)
