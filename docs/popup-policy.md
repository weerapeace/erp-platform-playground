# Popup Policy — ป๊อปกลาง (`components/modal`)

ใช้ทำอะไร: ทุกหน้าต่างเด้งในระบบใช้ของกลางชุดเดียว — `ERPModal` (ป๊อปทั่วไป/ฟอร์ม) · `ConfirmDialog` (ยืนยันสั้น ๆ / ลบ / อนุมัติ) · `Drawer` (แผงข้าง) · `BottomSheet` (แผ่นเลื่อนจากล่าง สำหรับจอมือถือ · เพิ่ม 2026-11-10) — ห้ามสร้าง modal เองในหน้า

## พฤติกรรมที่ได้ฟรีทุกป๊อป (ERPModal)
| เรื่อง | ทำงานยังไง | จำไว้ที่ |
|---|---|---|
| ⤢ ขยายเต็มจอ / ย่อ | ค่าเริ่มต้น = เต็มจอ (ส่ง `defaultExpanded={false}` ถ้าป๊อปนั้นควรเปิดขนาดปกติ) | ต่อคน ต่อป๊อป |
| ลากขอบ/มุมปรับขนาด | ขอบขวา = กว้าง · ขอบล่าง = สูง · มุม = ทั้งคู่ · ดับเบิลคลิกแถบลาก = ขนาดมาตรฐาน | ต่อคน ต่อป๊อป |
| **ลากหัวป๊อปย้ายตำแหน่ง** | กดค้างที่หัว (ไม่ใช่ปุ่ม) แล้วลาก · **ดับเบิลคลิกหัว = กลับกลางจอ** · ลากหลุดจอไม่ได้ (หัวค้างในจอเสมอ) · ใช้นิ้วบน iPad ได้ | ต่อคน ต่อป๊อป (`px/py`) |
| **ลากไปชนขอบซ้าย/ขวา = เกาะเป็นแผงข้าง** | ระหว่างลากใกล้ขอบโชว์กรอบเส้นประบอกที่จะเกาะ · เกาะแล้วสูงเต็มจอ ไม่มีพื้นหลังมืด หน้าด้านหลังเลื่อน/กดได้ · ลากเส้นขอบด้านในปรับความกว้าง · ลากหัวออกจากขอบ หรือปุ่ม ▭ = กลับเป็นป๊อปลอย · จอ ≥ 900px | ต่อคน ต่อป๊อป (`dk/dw`) |
| ↺ คืนขนาดเดิม | ลืมทุกอย่างที่จำไว้ของป๊อปนี้ (ขยาย/ขนาด/ตำแหน่ง/เกาะขอบ) | — |
| มีข้อมูลยังไม่บันทึก | `hasUnsavedChanges` → กดปิด/Esc/นอกกล่อง = ถาม "อยู่ต่อ / ออกโดยไม่บันทึก" | — |

"จำต่อคน ต่อป๊อป" = `lib/modal-layout-pref` (เก็บใน user_ui_prefs `modal_layout` ตามไปทุกเครื่อง) · ชื่อป๊อป = `storageKey` (แนะนำให้ส่งค่าคงที่) หรือระบบตั้งจากหน้า + หัวป๊อป

## ไม่ลากย้าย
- `size="sm"` (ยืนยัน/ถามสั้น) และ `ConfirmDialog` — อยู่กลางจอเสมอ ต้องตัดสินใจทันที
- ตอนขยายเต็มจอ · จอแคบกว่า 640px (มือถือ — ตำแหน่งที่จำไว้ไม่ใช้)
- ปิดเองได้: `draggable={false}`

## แจ้งเตือน + ย้อนกลับ (Toast กลาง `components/toast`)
- `toast.action("ซ่อนปุ่มแล้ว", "ย้อนกลับ", () => undo())` — ปุ่มบนแจ้งเตือน นับถอยหลัง 10 วินาที · ใช้หลังบันทึก/ซ่อน/ลบที่ย้อนได้ แทนการถามยืนยันก่อนทำ (ของที่ย้อนไม่ได้ยังต้องใช้ `ConfirmDialog`)

## หมายเหตุสำหรับหน้าอื่น
- ทุกกล่องป๊อปมี `data-erp-modal` — หน้าที่มีคีย์ลัด ให้เช็ก `document.querySelector("[data-erp-modal]")` แล้วงดคีย์ลัดตอนมีป๊อปเปิด

## ตัวเลือกอื่น
- `backdrop="light"` — พื้นหลังจาง สำหรับป๊อปตั้งค่าที่ต้องเห็นผลบนหน้าด้านหลังทันที (เช่น ⚙️ ตั้งค่ามุมมอง บอร์ดจ่ายงาน)
- `closeOnBackdrop={false}` — กดนอกกล่องไม่ปิด (ป๊อปที่ต้องกดปุ่ม/อันตราย) · ✕ / Esc ยังปิดได้
- `embedded` — ฝังในกรอบอื่น (iframe) ไม่มีหัว/พื้นหลัง/ลาก
- `zIndex` — ป๊อปที่เปิดจากป๊อป portal ชั้นสูง

## กฎปิด (จาก CLAUDE.md)
- ป๊อปดูข้อมูล: กดนอกกล่องปิดได้ · ป๊อปฟอร์มมีที่แก้: ต้องถามก่อนปิด · ลบ/อนุมัติ/ปฏิเสธ/ยกเลิก: `ConfirmDialog` + ยืนยันชัดเจน
- ข้อความเตือน: "คุณมีข้อมูลที่ยังไม่ได้บันทึก ต้องการออกโดยไม่บันทึกหรือไม่? [อยู่ต่อ] [ออกโดยไม่บันทึก]"

## ปิดแล้วหน้าข้างล่างโหลดใหม่ (กริ่งกลาง `lib/refresh-bus`)
- **Drawer / DrawerShell: ปิดเมื่อไหร่ = หน้าข้างล่างโหลดใหม่ทุกครั้ง** (เจ้าของขอ 2026-11-03) — ใน drawer มีหลายอย่างที่บันทึกเองทันที (รูป · SKU ลูก · แท็บแพลตฟอร์ม · AI/แปล) ระบบเลยไม่รอรู้ว่ามีการแก้
  - ยกเว้น **`DrawerShell modal={false}` (ลิ้นชักข้างหน้า · เพิ่ม 2026-11-10)** — ไม่มืดพื้นหลัง หน้าข้างหลังกด/เลื่อนได้ระหว่างเปิด (เช่น แผนผังการทำงาน: เปิดค้างแล้วกดกล่องอื่นต่อ) · ปิดด้วยปุ่ม ✕ / Esc เท่านั้น · ปิดแล้วรีเฟรชเฉพาะเมื่อมีการบันทึก · ใช้กับลิ้นชัก "ดูรายละเอียด" ที่ต้องสลับเรื่องบ่อย ไม่ใช้กับฟอร์มที่กลัวข้อมูลหาย
- **ป๊อป (ERPModal / ConfirmDialog / ApprovalDialog):** รีเฟรชเฉพาะเมื่อมีการบันทึก/ลบสำเร็จ (ผ่าน `apiFetch`) · แค่เปิดดู/ยกเลิก/เลือก Picker = ไม่โหลดใหม่
- `MasterRecordDrawer` ปิดแล้วเรียก `onChanged` ของคนเปิดทุกครั้งด้วย (หน้าที่โหลดข้อมูลเองได้ข้อมูลใหม่ แม้ไม่ได้ฟังกริ่ง)
- ใครฟังกริ่งอยู่แล้ว (โหลดใหม่เงียบ ๆ ไม่กระพริบ): `useSWRLite` · DataTable server mode · ตาราง MasterCRUD ทุกหน้า
- **หน้าที่โหลดข้อมูลเอง** (ไม่ใช่ข้างบน และไม่ได้เปิดผ่าน `MasterRecordDrawer`): วางบรรทัดเดียว `useRefresh(() => load())` จาก `@/lib/refresh-bus`

## BottomSheet — แผ่นเลื่อนจากล่าง (จอมือถือ · 2026-11-10)

- `import { BottomSheet } from "@/components/modal"` · `<BottomSheet open onClose title subtitle footer>…</BottomSheet>`
- ใช้กับฟอร์มสั้น/ตัวเลือกบนหน้ามือถือ (แก้บรรทัดตีราคา · เลือกวัสดุ) — จอคอมใช้ `ERPModal` ตามเดิม
- ไม่ portal: อยู่ในกรอบพรีวิวมือถือ (`DevicePreviewFrame`) ตอนดูบนจอคอม · แตะพื้นหลัง / Esc / ปุ่ม back ของเครื่อง (`useBackClose`) = ปิด · เปิดซ้อนได้ (Esc / back ปิดทีละชั้นบนสุด)
- footer ติดล่างเผื่อขอบจอ iPhone · เนื้อหายาวเลื่อนในแผ่น · ไม่มีถามก่อนปิด — ของที่แก้ในแผ่นควรเก็บเป็น "แก้ค้าง" ที่หน้าแม่ (หน้าแม่เตือนก่อนออก)
- ใช้แล้วที่: หน้าใบงานมือถือ แท็บตีราคา (`components/design-sheet-mobile/cost-tab.tsx`)
