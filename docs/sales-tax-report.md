# รายงานภาษีขาย (Sales Tax Report) — `/sales/tax-report`

รายงานรายเดือนสำหรับส่งบัญชี/ยื่น ภ.พ.30: ใบกำกับภาษีทุกใบของเดือน เรียงตามเลขที่ + หักใบลดหนี้ → ยอดสุทธิ

## ใช้ทำอะไร
- เลือก **บริษัทผู้ออกใบกำกับ** (หัวบิล จาก `companies`) + **เดือน** → ตารางตามแบบรายงานภาษีขายของกรมสรรพากร
  (ลำดับ · วันที่ · เลขที่ใบกำกับ · ชื่อผู้ซื้อ · เลขประจำตัวผู้เสียภาษี · สถานประกอบการ · มูลค่าก่อน VAT · VAT · หมายเหตุ)
- พิมพ์ A4 แนวนอน (ระบบพิมพ์กลาง) · ดาวน์โหลด Excel (Export กลาง มี audit log)
- ตรวจให้ก่อนยื่น: เลขใบกำกับ**ซ้ำ** / **ขาดหาย** (ระหว่างเลขต่ำสุด-สูงสุดของเดือน) / **ใบร่างที่มีเลขแล้ว** / ลูกค้า**ไม่มีเลขผู้เสียภาษี**ในทะเบียน

## กติกาตัวเลข (อยู่ใน `lib/sales-tax-report.ts` — มีเทสต์)
| กรณี | ในรายงาน |
|---|---|
| ใบกำกับ confirmed ขึ้นไป | นับปกติ |
| ใบ **ยกเลิก** | ยังโผล่ (ยอด 0 + หมายเหตุ "ยกเลิก (เดิม ฿…)") เพื่อให้เลขที่เรียงครบ |
| ใบ **ร่าง** ที่มีเลขใบกำกับแล้ว | นับรวมในยอด + เตือนบนจอ (ควรยืนยัน/ยกเลิกก่อนยื่น) |
| **ใบลดหนี้** (issued) | บรรทัดติดลบ ต่อท้ายใบกำกับ · ใบลดหนี้ที่ยกเลิก = 0 |
| **บิลไม่มี VAT** (`BILL-…`) | ไม่อยู่ในรายงาน — บอกจำนวนไว้ในการ์ดสรุป |
| ยอดสุทธิ | ใบกำกับ (ไม่ยกเลิก) − ใบลดหนี้ = ตัวเลขที่เอาไปกรอก ภ.พ.30 |

- เดือนของใบกำกับ = `order_date` (ระบบยังไม่มีช่องวันที่ใบกำกับแยก) · เดือนของใบลดหนี้ = `cn_date`
- เลขผู้เสียภาษี/สาขาของลูกค้าดึงจาก `partners_v2` (ใบขายไม่ได้เก็บไว้บนเอกสาร) — ใบลดหนี้ที่ไม่มีทะเบียนจะแกะจากข้อความบนใบ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `app/sales/tax-report/page.tsx` | หน้าจอ (permission `so.view`) — MiniTable + MonthNav + KPI + คำเตือน |
| `app/api/sales/tax-report/route.ts` | `GET ?month=YYYY-MM&company=<uuid>` — ดึงข้อมูลแล้วประกอบด้วยตรรกะกลาง |
| `lib/sales-tax-report.ts` | ตรรกะกลาง: `invoiceRow` / `creditNoteRow` / `sortSalesTaxRows` / `summarizeSalesTax` / `analyzeInvoiceSequence` / `branchLabel` |
| `lib/sales-tax-report-print.ts` | ใบพิมพ์ A4 แนวนอน (`buildReportHtml`) — คำเตือนไม่ติดไปตอนพิมพ์ |
| `lib/__tests__/sales-tax-report.test.ts` | เทสต์กติกาข้างบน |

## ของกลางที่เกิดพร้อมกัน
- **`lib/month.ts`** — `thisMonth` / `shiftMonth` / `monthRange` (ใช้ `Date.UTC` กันกับดัก timezone ไทย) / `monthLabelTh` / `TH_MONTHS`
- **`components/month-nav`** — ตัวเลือกเดือน ◀ [เดือน] ▶ + ปุ่ม "เดือนนี้" → ใช้แล้วที่ `/sales/monthly` และ `/sales/tax-report`
  (หน้าอื่นที่ยังมี `<input type="month">` ของตัวเอง: work-board/labor-summary, print/purchasing-monthly, subscriptions — ค่อยย้ายเมื่อแตะหน้านั้น)

## ข้อจำกัดที่รู้อยู่
- เลขที่ "หายท้ายเดือน" (ตัวนับเดินไปแต่ไม่มีใบ เช่น ISG2569-08-018/019) ตรวจไม่ได้ เพราะไม่มีใบไหนถือเลขสูงกว่านั้น
- ยังไม่มีรายงานภาษีซื้อ (ฝั่งจัดซื้อ) — ถ้าทำ ให้ใช้โครงเดียวกัน (lib + print + MonthNav)
