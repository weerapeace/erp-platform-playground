# 👥 จัดคนในโต๊ะ (DeskStaffPanel) — บอร์ดจ่ายงาน

ใช้ทำอะไร: ดู/ย้ายพนักงานเข้า-ออก "โต๊ะ" (= แผนกในข้อมูลพนักงาน) ได้ในป๊อปจ่ายงานเลย ไม่ต้องไปหน้าผังพนักงาน

## อยู่ที่ไหน
- ป๊อปจ่ายงาน (บอร์ด · ทีละใบ) และป๊อป "จ่ายงาน N ใบ" (ตาราง) — เลือกโต๊ะแล้วมีแถว "👥 N คนในโต๊ะ · จัดคนในโต๊ะ ▾" (แผงในตัว ไม่เด้งป๊อปซ้อน)
- ช่องเลือกโต๊ะบอกจำนวนคน เช่น "โต๊ะขาล · 9 คน" / "จับกลุ่ม · ยังไม่มีคน"
- ป๊อป 👥 ของบอร์ดแผน (dispatch-plan-board) ใช้ตัวย้ายกลางเดียวกัน (`moveDeskStaff`) + สิทธิ์เดียวกัน

## ทำอะไรได้
| อย่าง | ใครทำได้ | API |
|---|---|---|
| ดูรายชื่อคนในโต๊ะ | ทุกคนที่เปิดป๊อปจ่ายงานได้ | `/api/mo/assignees` (GET เดิม) |
| ย้ายคนไปโต๊ะอื่น / เอาออก (ไม่ระบุโต๊ะ) · ดึงคนจากโต๊ะอื่นเข้าโต๊ะนี้ | **เฉพาะสิทธิ์ฝ่ายบุคคล** = `app.payroll` + `employees.edit` | `POST /api/mo/dept-staff` (guardPayroll employees.edit) |
| เพิ่มช่างใหม่ที่ยังไม่มีในระบบ | สิทธิ์จ่ายงาน (`work_board.dispatch`) — ของเดิมของบอร์ด | `POST /api/mo/assignees` |

- ย้ายแล้ว = เปลี่ยน `employees.department_id` จริง → ผังพนักงาน/เงินเดือน/เงินเดือนรวมต่อโต๊ะเห็นตาม · เขียน `employee_dept_history` + audit (`move_dept`, source work-board)
- ย้ายแล้วมีปุ่ม **ย้อนกลับ 10 วินาที** (`toast.action`) = ย้ายกลับโต๊ะเดิม
- `/api/payroll/board/move` (หน้าผังพนักงาน) ก็ขอ `employees.edit` แล้ว (เดิมขอแค่ดู) — ตอนเปลี่ยน คนที่มีสิทธิ์แอปเงินเดือนทุกคนมี employees.edit อยู่แล้ว

## โต๊ะใหม่ · เปลี่ยนชื่อ · ปิดโต๊ะ (หัวหน้าลาออก) — เฉพาะสิทธิ์ฝ่ายบุคคล
ปุ่มบนหัวแผง: **＋ โต๊ะใหม่** · **✏️ เปลี่ยนชื่อ** · **🔒 ปิดโต๊ะนี้…** (เจ้าของสั่ง 2026-10-28)
- โต๊ะใหม่ = `POST /api/mo/departments {name}` → เลือกโต๊ะใหม่ให้ในป๊อปเลย
- เปลี่ยนชื่อ = `PATCH {id, name}` — คน/งาน/ประวัติอยู่ที่เดิม · ใบงานเก่าที่เก็บชื่อโต๊ะ (`department_name`) ยังเป็นชื่อเดิม
- ปิดโต๊ะ 3 ขั้นในแผง:
  1. คนในโต๊ะไปไหน: สร้างโต๊ะใหม่แล้วย้ายทั้งทีม / โต๊ะที่มีอยู่ / แยกย้ายเอง (ปิดได้เมื่อโต๊ะว่างแล้ว)
  2. งานค้าง (ใบที่ยังไม่ done/cancelled): ย้ายตามไป (`PATCH /api/mo/work-orders {id, department_id, department_name}` แบบเดียวกับลากการ์ด) / จบที่โต๊ะเดิม
  3. สรุป → ยืนยัน → ทำตามลำดับ สร้างโต๊ะ → ย้ายคน (`moveDeskStaff`) → ย้ายงาน → `PATCH {show_on_board:false, status:"inactive"}` · พลาดกลางทางบอกว่าทำอะไรไปแล้ว
- ปิดแล้ว: ไม่ขึ้นในช่องเลือกโต๊ะตอนจ่ายงานใหม่ · **คอลัมน์บนบอร์ดยังโชว์ถ้ามีงานค้าง** (`boardDesks` ในหน้า) จนส่งคืนครบ · ไม่ลบ ประวัติเดิมอยู่ครบ
- เปิดกลับ: ⚙️ ตั้งค่าแผนก → เปิด "โชว์ในบอร์ด" (ตั้ง status active ให้ด้วย · มีป้าย 🔒 ปิดโต๊ะแล้ว)

## ห้ามใช้เมื่อ
- ย้ายแผนกพนักงานจากหน้าอื่นที่ไม่ใช่บอร์ด → ใช้ผังพนักงาน (`/payroll/board`)
- ห้ามทำปุ่มย้ายแผนกใหม่ที่ไม่ผ่าน `moveDeskStaff` / API 2 ตัวข้างบน (จะไม่มีประวัติ/สิทธิ์ไม่ตรง)
