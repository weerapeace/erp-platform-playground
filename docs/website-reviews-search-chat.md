# ⭐ รีวิวสินค้า · 🔍 ค้นหาฉลาด · 💬 ปุ่มแชทลอย (เว็บร้าน · ชุด 2)

ตั้งค่าทั้งหมดที่ ERP › เว็บไซต์ › 🏪 ข้อมูลร้าน (ค่าเริ่ม = ปิด) · ตรวจรีวิวที่แท็บ **⭐ รีวิว**

## ⭐ รีวิวสินค้า

| ตั้งค่า | ความหมาย |
|---|---|
| เปิดรีวิวสินค้าบนเว็บ | ปิดทีหลัง รีวิวไม่หาย แค่ซ่อน |
| เฉพาะคนที่ซื้อแล้ว (ค่าเริ่ม เปิด) | ยืนยันด้วยเลขออเดอร์ + เบอร์ หรือกดลิงก์ในอีเมลขอบคุณ · ได้ป้าย ✓ ซื้อจริง · ปิด = แขกรีวิวได้ (ต้องตรวจทุกอัน) |
| อนุมัติอัตโนมัติ | เฉพาะคนซื้อจริงที่ให้ 4–5 ดาว · ที่เหลือรอตรวจ |
| แต้มเมื่อรีวิวผ่าน / แต้มเพิ่มถ้ามีรูป | สมาชิกที่ซื้อจริงเท่านั้น · ครั้งเดียวต่อรีวิว · ต้องเปิดระบบแต้ม |
| โชว์ดาวบนการ์ดสินค้า | เฉพาะรุ่นที่มีรีวิวแล้ว |
| ชวนรีวิวในอีเมลขอบคุณ | อีเมล "สำเร็จ" มีปุ่ม ⭐ รีวิวสินค้า (ต้องเปิดอีเมลแจ้งออเดอร์ + มีโดเมน) |

**ลูกค้ารีวิวได้จาก 3 ทาง:** ปุ่มในอีเมลขอบคุณ · ปุ่ม "รีวิวสินค้า" ในหน้าตามออเดอร์ (ออเดอร์ที่ส่งแล้ว/สำเร็จ) · ปุ่ม "เขียนรีวิว" ในหน้าสินค้า (กรอกเลขออเดอร์ + เบอร์)
→ ทุกทางไปจบที่หน้า `/review?t=<รหัส>` รีวิวทุกชิ้นในออเดอร์ได้ทีเดียว (ดาว · ข้อความ · รูปสูงสุด 4 รูปต่อชิ้น ย่อรูปให้เองก่อนส่ง)

- รหัสลิงก์ = id ออเดอร์ + วันหมดอายุ (180 วัน) + ลายเซ็น (`lib/review-token.ts`) · ไม่มีเบอร์/ชื่อในลิงก์
- หน้าสินค้า: สรุปดาว + แท่งแต่ละดาว + รีวิว (รูปกดดูเต็มจอ · ✓ ซื้อจริง · คำตอบร้าน) วางเหนือ "คุณอาจชอบ" ทุก Style
- Google: `aggregateRating` + รีวิวล่าสุด 5 อัน ใน JSON-LD (ดาวขึ้นในผลค้นหา)
- ชื่อบนเว็บ = ชื่อแรก + อักษรแรกของนามสกุล · อีเมล/เบอร์ ไม่โชว์

**แท็บ ⭐ รีวิว (ERP):** รอตรวจ / ขึ้นเว็บแล้ว / ซ่อนอยู่ · ขึ้นเว็บ (ครั้งแรก = ให้แต้ม) · ซ่อน · ตอบกลับ (โชว์ใต้รีวิว) · ลบถาวร (ลบรูปด้วย · แต้มที่ให้ไปแล้วไม่ดึงคืน) · ทุกการเปลี่ยนลง audit

ตาราง `store_reviews` (migration 202610291300) · ไฟล์: `lib/website-reviews.ts` (กฎ) · `lib/website-reviews-server.ts` (DB/รูป/แต้ม) · `/api/public/storefront/reviews` (+`/verify`) · `/api/website/reviews` · `components/website-reviews-panel.tsx`
เว็บร้าน: `src/components/shop/ProductReviews.tsx` · `ReviewOrderClient.tsx` · `ReviewInputs.tsx` · `Stars.tsx` · `src/app/review`

## 🔍 ค้นหาฉลาด (`src/lib/search.ts` เว็บร้าน · ใช้ทั้งช่องค้นหาเต็มจอและหน้ารวมสินค้า)

- ค้นจากชื่อ · รหัสรุ่น (พิมพ์ไม่มีขีด/เว้นวรรคก็เจอ) · ชื่อสี · หมวด · คอลเลกชัน · คำอธิบาย
- หลายคำต้องเจอทุกคำ · ภาษาไทยติดกันแยกคำให้เอง ("กระเป๋าหนัง" = กระเป๋า + หนัง)
- พิมพ์ผิดเล็กน้อย (ตก/เกิน/สลับ 1 ตัว · คำยาว 2 ตัว) ยังเจอ → ขึ้น "หมายถึง …?" ให้กด · ใช้เฉพาะตอนหาแบบตรงตัวไม่เจอ
- **คำพ้อง** (ช่อง "คำที่หมายถึงกันเอง"): บรรทัดละกลุ่ม คั่นด้วย , เช่น `กระเป๋าสตางค์, wallet, กระเป๋าเงิน`
- **คำที่ลูกค้าค้น** (กล่องใต้กลุ่ม 🔍): 30 วันล่าสุด · สีแดง = ค้นแล้วไม่เจอ → เอาไปเติมคำพ้อง หรือเพิ่มสินค้า · นับรายวัน ไม่เก็บว่าใครค้น ไม่เก็บอีเมล/เบอร์ (ตาราง `store_search_terms`)

## 💬 ปุ่มแชทลอย (`src/components/layout/FloatingChat.tsx`)

- ปุ่มกลมมุมขวา (หรือซ้าย) ทุกหน้า ยกเว้นหน้าชำระเงิน · กดแล้วเห็นข้อความทักทาย + ปุ่ม LINE / Messenger / โทร
- ลิงก์มาจากกลุ่ม 📞: ลิงก์ LINE (ไม่มี = สร้างจาก LINE ID) · Messenger (ไม่มี = สร้างจากลิงก์ Facebook เป็น m.me/ชื่อเพจ) · โทร (ติ๊ก "มีปุ่มโทร")
- หน้าสินค้ามือถือที่มีแถบซื้อค้างล่าง ปุ่มยกขึ้นเองไม่ทับ

## ข้อจำกัด

- รีวิวแบบแขก (ปิด "เฉพาะคนซื้อ") ยังไม่มีกันสแปมนอกจากจำกัดจำนวนครั้งต่อเครื่อง + ต้องตรวจทุกอัน
- ยังไม่มีอีเมลชวนรีวิว "หลังส่ง X วัน" (ชวนในอีเมลตอนพนักงานกดสำเร็จ) — ทำได้ในชุด 5 (ข้อความอัตโนมัติ)
