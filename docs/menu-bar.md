# แถบเมนูชี้แล้วเด้ง (MenuBar)

เจ้าของขอ 2026-11-07: แถบเครื่องมือ Design Dashboard ปุ่มเยอะจนรก — "จับกลุ่มแล้วทำเป็นแบบเมนู เอาเมาส์ไปวางแล้วมีเมนูโผล่มา เอา Icon สีๆ ออก ใช้แบบเส้น" + "filter กำลังทำ ด่วน ... อยู่ใน menu เช่นกัน จะได้ไม่รก"

## ใช้ทำอะไร
รวมปุ่มหลายปุ่มในแถบเครื่องมือเป็น "หัวเมนู" ไม่กี่หัว ชี้แล้วรายการโผล่ — แถบสะอาด แต่ทุกอย่างยังอยู่ครบ

## การทำงาน
- **จอคอม (มีเมาส์)** ชี้หัวเมนู = เปิด · เลื่อนออก = ปิดเอง (หน่วง 0.2 วิ ให้เลื่อนเข้าแผงทัน) · ชี้ข้ามหัวเมนูได้เลย
- **จอสัมผัส** กดหัวเมนูเพื่อเปิด/ปิด
- เปิดได้ทีละเมนู · กด Esc หรือกดที่อื่น = ปิด
- เลือกรายการแล้วเมนูปิดเอง — ยกเว้นติ๊ก/สวิตช์ (เปิดค้างให้กดหลายอันได้) หรือรายการที่ตั้ง `keepOpen`
- เมนูที่ "กำลังใช้งาน" (`active` เช่น กรองอยู่) = ปุ่มสีฟ้า + ปุ่ม × ล้าง (`onClear`)
- เมนูย่อยซ้อน (`submenu`) ชิดขอบจอขวาแล้วพลิกไปเปิดด้านซ้ายเอง
- ไอคอนเป็นเส้นจากชุดไอคอนกลาง (`i:filter`, `i:bolt` ...) — ไม่ใช้อีโมจิสี

## ชนิดรายการ
| type | ใช้ทำอะไร |
|---|---|
| `item` (ตั้งต้น) | ปุ่มสั่งงาน เช่น "ส่งขึ้นกระดาน" |
| `radio` | เลือก 1 อย่างในกลุ่ม เช่น ตัวกรอง / มุมมอง |
| `check` | ติ๊กได้หลายอัน |
| `toggle` | สวิตช์ เปิด/ปิด เช่น แถบสีแบรนด์ |
| `section` | หัวข้อเล็กคั่นกลุ่ม |
| `divider` | เส้นคั่น |
| `submenu` | เมนูย่อย — ใส่ `items` หรือ `render(close)` วาดแผงเอง (เช่น ตัวเลือกคอลัมน์) · `bare` = แผงที่วาดมีกรอบเองแล้ว |

ทุกรายการใส่ `icon` (ชื่อไอคอนกลาง) · `hint` (ตัวเลข/ข้อความเล็กด้านขวา เช่น จำนวนงาน) · `title` (คำอธิบายตอนชี้) · `disabled` ได้

## ใช้ยังไง
```tsx
import { MenuBar, type MenuDef } from "@/components/menu-bar";

const menus: MenuDef[] = [
  { key: "filter", label: f === "all" ? "ตัวกรอง" : `ตัวกรอง: ${label}`, icon: "filter",
    active: f !== "all", onClear: () => setF("all"),
    items: [
      { type: "radio", key: "all", label: "ทั้งหมด", icon: "list", checked: f === "all", onSelect: () => setF("all"), hint: 58 },
      { type: "radio", key: "urgent", label: "ด่วน", icon: "alert-triangle", checked: f === "urgent", onSelect: () => setF("urgent"), hint: 7 },
    ] },
  { key: "view", label: "มุมมอง", icon: "layout-dashboard", items: [
    { type: "toggle", key: "strip", label: "แถบสีแบรนด์", on: strip, onSelect: toggleStrip },
    { type: "submenu", key: "cols", label: "คอลัมน์ที่โชว์", render: () => <ColumnChecklist /> },
  ] },
];
<MenuBar menus={menus} />
```
- เมนูที่ไม่มีรายการ (เช่น ไม่มีสิทธิ์สักปุ่ม) ให้กรองออกก่อนส่ง — หน้า Design Dashboard ทำแบบนี้

## ห้ามใช้เมื่อไหร่
- เมนูเล็กกดเปิดข้างปุ่มเดียว → `Popover` (components/popover)
- เนื้อหายาว / ฟอร์มหลายช่อง → ป๊อปอัปกลาง
- มือถือ: หน้าที่มีเมนู ⋯ อยู่แล้วให้ใช้ตามเดิม (MenuBar ใช้ได้แต่แถบแคบ)

## ใช้ที่ไหนบ้าง
- Design Dashboard (`components/design-dashboard/index.tsx`) — ตัวกรอง · ทำงาน · มุมมอง · ตั้งค่า (จอคอม/แท็บเล็ต · มือถือยังใช้เมนู ⋯ เดิม)
