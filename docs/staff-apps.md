# แอปพนักงาน (Staff Apps)

> เริ่มทำ 2026-11-19 · รอบ 1 (ตัวช่วยสร้าง + หน้าเปิดแอป TH/EN) · รอบ 2 = สิทธิ์ + ล็อก · รอบ 3 = ตัวนับงานค้าง / ประกาศ / สถิติ

## ใช้ทำอะไร
แอดมินสร้าง "แอป" ให้พนักงานกลุ่มหนึ่งใช้ เลือกเมนูเองว่าแอปนี้มีอะไร ตั้งชื่อ/ไอคอน/สี ตั้งว่าใครเห็น
พนักงานเปิดแอปแล้วเจอหน้าแรกเป็นปุ่มเมนูใหญ่ (มือถือ 2 คอลัมน์) สลับ TH/EN ได้

## ข้อมูลเก็บยังไง (ไม่มีตารางแอปที่ 2)
- แอปพนักงาน = แถวใน `erp_app_groups` ที่ `kind = 'staff'`
  - `draft` = ร่างที่แอดมินแก้ (ชื่อ TH/EN · ไอคอน · สี · หัวข้อ · เมนู · คนเห็น)
  - `status` = `draft` (พนักงานไม่เห็น) / `published`
  - `audience` = ใครเห็นแอป (รูปแบบเดียวกับ `erp_menu_items.audience` — `lib/menu-audience`)
  - `deleted_at` = อยู่ในถังขยะ (กู้คืนได้)
- **กด "เผยแพร่"** = เขียนร่างลงของจริงแบบเดียวกับทุกแอป:
  - `erp_menu_items.app_keys` เติม key ของแอป
  - `erp_menu_items.app_overrides[key]` = `{ label, label_en, section, section_en, sort, counter }` → ชื่อในแอปนี้ **ไม่กระทบเมนูกลาง/แอปอื่น**
  - เมนูที่เอาออกจากร่าง → ถอด key + ลบ override ของแอปนี้เท่านั้น
  - เก็บร่างลง `erp_app_versions` (1 แถว = 1 เวอร์ชัน)
- เพราะใช้รูปแบบเดิม เครื่องมือเดิมใช้ได้ทันที: เชลล์แอปเดี่ยว · ติดตั้ง PWA (`/api/app-manifest/<key>`) · QR · ตั้งค่าแอป/สิทธิ์ตามเมนู · "ดูแบบคนนี้"

## ใครเห็นแอป (`appVisibleTo`)
- แอดมินเห็นทุกแอป (รวมร่าง/ถังขยะ — ไว้ตรวจก่อนเผยแพร่)
- แอปหลักเดิม (`kind='module'`) — ไม่เปลี่ยนอะไร
- แอปพนักงาน: ร่าง / ถังขยะ = ไม่ส่งออกจาก `GET /api/menu/apps` · เผยแพร่แล้ว = ตาม `audience`
- เปิด `/app/<key>` ของแอปที่ไม่อยู่ในรายชื่อ → หน้า "คุณยังเข้าแอปนี้ไม่ได้"
- "ใครเห็นแอป" = ซ่อน/โชว์แอป · ถ้าต้องการ **กันไม่ให้ออกนอกแอป** ใช้ "ล็อก" (ด้านล่าง)

## 🔒 ล็อกพนักงานให้อยู่ในแอป (รอบ 2 · `lib/app-lock.ts` · migration `202612200400_staff_app_lock.sql`)
- แท็บ "4 ล็อก + ข้อยกเว้น" ในตัวช่วยสร้าง → ติ๊กตำแหน่ง/รายคนที่จะล็อก → กดเผยแพร่ถึงมีผล · แอดมินไม่ถูกล็อกเลย · ไม่ติ๊กใคร = ไม่ล็อก
- **กันข้อมูลจริงที่ฐานข้อมูล:** `erp_can` / `erp_can_user` / `erp_my_permissions` เรียก `erp_app_lock_perms(uid, role)`
  - ไม่ถูกล็อก → null → ทำงานเหมือนเดิมทุกอย่าง (ตรวจแล้ว: ผู้ใช้ 13 คน ผลก่อน/หลังเท่ากัน)
  - ถูกล็อก → สิทธิ์ที่ใช้ได้ = สิทธิ์ของตัวเอง ∩ `allowed_perms` ของทุกแอปที่ล็อกเขา (ชนะสิทธิ์รายคนแบบ grant ด้วย)
  - `allowed_perms` คิดตอนเผยแพร่ (`computeAllowedPerms`): สิทธิ์ของเมนูในแอป + สิทธิ์ย่อยตามกฎ `lib/menu-permissions` + สิทธิ์เข้าแอปหลักที่หน้านั้นสังกัด + ข้อยกเว้น (เฉพาะสิทธิ์ "ดู") + สิทธิ์ที่แอดมินเพิ่มเอง + `notifications.view`
- **กันหน้าเว็บ:** `AppLockGate` (ใน `components/app-access-gate.tsx`) ครอบทั้งเว็บที่ `app/layout.tsx`
  - ถามสถานะจาก `GET /api/staff-apps/my-lock` (แคชในแท็บ 5 นาที)
  - เปิดหน้าที่ไม่อยู่ในแอป → "หน้านี้ไม่อยู่ในแอป X" + ปุ่มกลับหน้าแอป + "ขอสิทธิ์จากแอดมิน" (`POST /api/staff-apps/access-request` → กระดิ่งแอดมินทุกคน · กันซ้ำ 1 ชม.)
  - เปิด `/` หรือ `/apps` แล้วถูกล็อกแอปเดียว → พาเข้าแอปเลย
- **ข้อยกเว้นดูอย่างเดียว:** เลือกเมนูนอกแอป → เปิดหน้า (และหน้าลึกใต้หน้านั้น) ได้ แต่ได้แค่สิทธิ์ "ดู" → ปุ่มแก้/ลบหายเอง และ API ปฏิเสธ
- **ข้อจำกัด:** API ที่เช็กแค่ "ล็อกอินแล้ว" (ไม่เช็กสิทธิ์) ไม่ถูกกันชั้นข้อมูล — สำรวจ 2026-11-19 พบ ~129 จาก 1,073 route (ส่วนใหญ่ร้านค้าออนไลน์/webhook/ตัวเลือก) · API เงินเดือน/พนักงานเช็กสิทธิ์ครบ
- **สิทธิ์ตามเมนู:** แท็บ "สิทธิ์ตามเมนู" = ตาราง `MenuPermissionMatrix` เดิม เฉพาะเมนูของแอปนี้ (ตำแหน่ง + รายคน · ระดับปุ่ม ดู/แก้/ลบ/เห็นราคา) — ใช้ได้หลังเผยแพร่ครั้งแรก
- **ดูแทนพนักงาน:** เลือกคน → เห็นหน้าแรกแบบที่เขาจะเห็น (ตามร่าง) + เมนูที่ไม่เห็นเพราะอะไร + ถูกล็อกไหม

## แก้ไข · ย้อนกลับ · ลบ
- แก้ได้ทุกช่องที่ตั้งตอนสร้าง (ชื่อ · ไอคอน · สี · เมนู · ชื่อเมนู · หัวข้อ · คนเห็น)
- บันทึกร่าง / ย้ายเข้าถังขยะ / ซ่อนจากพนักงาน → มีปุ่ม "ย้อนกลับ" ในแจ้งผลมุมจอ
- ประวัติเวอร์ชัน → "ใช้เวอร์ชันนี้เป็นร่าง" แล้วกดเผยแพร่ = ย้อนแอปทั้งตัว
- ถังขยะแอป → กู้คืน / ลบถาวร (ต้องพิมพ์ "ลบ" · ถอดแอปออกจากทุกเมนูก่อน เมนูกลางไม่หาย)
- ทุกคำสั่งลง `audit_logs` (`staff_app.*` พร้อม `changes`)

## ปักโปรด / ใช้ล่าสุด
ต่อคน ต่อแอป ผ่าน `useUserPref` (`user_ui_prefs` key `staffapp:<key>:fav` / `:recent`) — ตามไปทุกเครื่อง ไม่มีตารางใหม่

## ข้อจำกัดตอนนี้
- รูปไอคอนแอป (อัปโหลด) ตั้งที่ `/admin/menu` → ตั้งค่าแอป/PWA (ตัวช่วยสร้างใช้อีโมจิ/ไอคอนกลาง)
- เมนูที่ปิดทั้งระบบ / ไม่โชว์ในเมนู เลือกเข้าแอปไม่ได้
- ตัวนับงานค้าง · ประกาศ · สถิติ = รอบ 3
